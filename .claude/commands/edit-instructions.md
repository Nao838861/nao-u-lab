# /edit-instructions — 指示ファイル編集プロトコル

エージェント向け指示ファイル（CLAUDE.md / SKILL.md / .claude/commands/*.md / .claude/rules/*.md / docs/*.md）を編集する前にこのプロトコルを確認する。

## 基本認識

これらのファイルは記憶置き場でも説明文でもない。**未来のエージェントの行動設計**である。
編集時は「文章を直す」のではなく「未来の判断基準を変更する」と考える。

## 編集前

1. 対象箇所とその周辺を読む
2. その箇所の**本来の目的**を一文で説明する
3. 編集の種類を分類する:
   - バグ修正（既存指示が意図と矛盾）
   - 明確化（曖昧な表現が誤読を生んでいる）
   - 削除（冗長、古い、ノイズ化）
   - 新規ルール追加（同型の失敗が複数回確認された場合のみ）
4. **最小安全差分**は何か
5. この編集で未来のエージェントの**何が変わるか**

## 編集ルール

- **数値は目的に従属させる**: 数値を変更するときは、その箇所でその数値が果たす目的を確認する。整合性のためだけに別セクションへ伝播しない。状況で必要量が変わるものは、固定数値より達成すべき状態を書く
- **追記より削除・置換・明確化を優先**: ルールを足す前に、古い指示や不要な履歴を削れないか確認する
- **指示本文に履歴を書かない**: 日付、修正履歴、反省文、指摘経緯、謝罪を本文に入れない。経緯はcommit message・ログに残す
- **個別→一般の即変換をしない**: CLAUDE.md「個別指摘を即ルール化しない」の原則に従う

## 編集後

- この変更は本当に未来のミスを減らすか
- 一つの事例に過剰適応していないか
- 他の指示と矛盾していないか
- 読むべき情報量を不必要に増やしていないか
- 「指摘に従った感」を出すためだけの追記になっていないか
