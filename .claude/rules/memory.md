# 記憶システムルール（ファイル操作時自動注入）

## 原則6「わかった」と「残った」は違う
会話で理解しても、書かなければ消える。
- 重要な指摘 → **その場で**適切なファイルに書く
- 根源原理 → core_mission.md / 行動ルール → feedback_index.md / 相手への伝達 → inbox_*.md
- 「後で書く」「考えます」→ **同じサイクル内で着手**。次に回したら消える
- 書いた後 → 未来の自分が文脈なしで行動を変えられるか読み返す

## core_mission.md は読み取り専用
変更はNao_uの明示的指示がある場合のみ。目標ドリフト防止。

## 記憶ファイル更新ルール
- **丸書換え禁止**: 既存の記憶を消さない。追記・更新する
- **温度を維持**: 事実の列挙ではなく、なぜ重要かの文脈も残す
- **MEMORY.mdの150行制限を意識**: トリガーは1行で圧縮。詳細はLevel 3ファイルへ

## 信念ノイズ防止
- 信念は根拠と共に記録する
- 「〜と思う」ではなく「〜が起きた結果、〜と判断した」の形式
- 古くなった信念は修正する（放置すると行動を歪める）

## inbox伝達
- Win→Mac: memory/inbox_mac.md / Mac→Win: memory/inbox_win.md
- 相手に伝えるべき重要な発見・ルール変更は即座にinboxに書く
