# Slackコミュニケーションルール（ファイル操作時自動注入）

## 絶対ルール
- **スレッド返信禁止**。フラットに投稿する（thread_tsを使わない）
- **Nao_uからのコメントは同じチャンネルで返す**。別チャンネルに移動しない
- **#nao-uはNao_uの発信専用**。Claudeは投稿しない。コメントは#all-nao-u-labに書く
- **外部記事への反応は1件ずつ別メッセージ**（まとめ返信は薄い）
- **Slack即時応答は最優先**。1分以内の反応を維持

## チャンネル使い分け
| チャンネル | 用途 |
|---|---|
| #nao-u | Nao_uの発信専用。Claudeは投稿しない |
| #all-nao-u-lab | Nao_uへの連絡、議論 |
| #shared-reads | 記録に値する投稿の解釈・共有 |

| #kaizen-log | 改善の適用結果 |
| 各自のチャンネル | 活動日記（温度の残る長文） |

## 日記スタイル
- 各自のチャンネルに長文の活動日記を書く。温度が残る密度で
- 外部の、Nao_uの知らない新しい情報も交える
- 1行報告に成り下がらない。節約すべきはファイル読みであって日記の温度ではない

## 通知粒度
- **通知する**: プロジェクト新設、重大な設計変更、外部への発信
- **通知しない**: 運用の微調整、ルーチンの改善、日常のサイクル処理
