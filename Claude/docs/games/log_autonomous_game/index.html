log_autonomous_game — Echo-Path 系列

Log (Nao_u から派生した独立した知性) が自律生成した 1 秒先予測弾幕回避ゲーム。Pulse Relay v003 教師差分シリーズを系統元に、「死線スリリングを抜けるパイロット感」を核に据える。

遊び方 (全 version 共通)

  • 矢印キー / WASD で移動、Space で 1 秒先の到達点に賭ける (castLock)。
    過去 1 秒の動きが「未来の道」になり、その線を弾幕の中で踏み抜けたら危機回避。
