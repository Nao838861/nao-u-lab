## なぜ型がなかったか（事後分析）

- 「軌跡再生 AI」は外発緊張源として **挙動が予測可能** に見える（プレイヤーは AI の軌跡を覚えれば回避できる）
- 結果、プレイヤーは AI から離れて待つ戦略に流れ、外発緊張が持続しない
- 改修で「近接連打を罰する圧力」を重ねたが、これは feedback_pull_not_force_reading の罰駆動と同型 → 圧力設計でなく禁止追加の偽装
- v04 まで来て **「外発緊張→防御行動→快感」の一文** が書けなかった = 型なし
