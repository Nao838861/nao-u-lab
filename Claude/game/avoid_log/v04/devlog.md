## 2026-04-25 08:15 (Log C121) 着手

### Nao_u 指摘 (#game-rights 08:13)

> Log AIの近くで連打してるだけで楽しくない問題が解決してない。

**v03 でdirBias（左右偏り）圧力は入れたが、指摘されたのは別軸の問題。**
dirBiasは「左右どちらかに動き続ける」ことへの圧力で、「近接にほぼ静止してSPACE連打」戦略には効かない（dirBias は 0 近辺に留まる）。

### v04 で変えた点（最小1点）

v03 と対称軸の圧力を追加:

- **dirBias**: 左右連続移動で蓄積 → spawn間隔短縮（v03）
- **nearBias**: AI近接160px以内に滞在で蓄積、離れると減衰（半減期~23F） → spawn間隔短縮（v04 new）

**圧力設計 vs 禁止追加**（feedback_game_center_of_mass.md / ABA 2026-03-11）:
- 禁止案: 「近接滞在Nフレーム超で死亡」「SPACE連打に cooldown スケール」→ 採用せず
- 圧力案: 「近接に居続けると敵スポーン密度が上がる」→ 採用
- 理由: 望ましくない遊び方を禁じるのではなく、望ましい遊び方（近づく/離れるの切り返し）が自然に出る圧力を設計する

### 実装変更

`index.html` 4箇所:

1. `<title>` / `<h1>` / 変更点表記を v04 に更新
2. `state.dirBias=0, nearBias=0` を初期化に明示
3. player input処理に nearBias 更新ロジック追加（`state.nearBias = state.nearBias * 0.97 + (近接? 1:0)`、上限30）
4. spawn interval計算を 2 軸加算に変更（`dir_factor*0.45 + near_factor*0.45, 上限0.7`）
5. HUD右上に dir/near 2本の圧力ゲージ追加（近接滞在が可視化されることで体感に効かせる）

`headless.py` 同じロジックを反映 + `near_bias_avg` メトリクス追加。

その他全ロジック・グラフィック・スコア処理は v03 そのまま温存（巻き戻し容易性、feedback_solution_space_rollback.md）。

### 「壊れた測定器」候補 — タイプ a 2 点 + タイプ b 1 点

**【主候補 a-1】`diagnose()` の総合判定式そのもの**

`headless.py` L704-707 の `concept_wins` 条件:

```python
concept_wins = (c_surv > s_surv and c_surv > d_surv
                and c["score_avg"] >= s["score_avg"]
                and c["score_avg"] >= d["score_avg"]
                and (not r or (c_surv > r_surv and c["score_avg"] >= r["score_avg"])))
```

この式は「concept-policy が手抜き-policy より生存/スコアで勝つか」しか測っていない。**concept-policy 自体に快感があるか / コンセプトとして成立しているか**は構造的に測れない。本サイクルで「✅成立」が再出力されたが、人手判定では同じ v04 が 2026-04-25 09:35 に凍結されている。判定式の入力 (生存/スコア/手抜き勢との比較) と判定対象 (コンセプトの快感) が**異なる軸**にある。

**Nao_u 06:37 (1) で言う「壊れた測定器」の典型**: 計算結果は正しい（concept は確かに手抜き勢より長生きする）、ただし「快感ある？」の問いには答えていない器具で「快感ある」と結論を出している構造。

**【副候補 a-2】ARC 指標の解釈逆転**

`arc_hits / arc_total` の高さ = 「SPACE が機能している」と解釈する設計だが、Nao_u 04-25「AI一定範囲を一発で全滅 = 快感ゼロ」より、**ARC=100% は「効きすぎ = 弾で狙い撃つ手順を消した」シグナル**として読むのが正しい。指標の符号が逆転している。

**【主候補 b-1】「弾で狙い撃つ快感」「ゲージで弾増えて当たりやすい快感」の測定軸が存在しない**

Nao_u 04-25 が言語化した v01 着手時に存在すべき快感連鎖（弾を撃つ → 狙う → 当てる → 敵が壊れる → ゲージが増える → 弾が増える → 次が当たりやすくなる）の **7 段のうち、headless が測れる軸は 0 段**。score / chain_peak は連鎖発生回数のサマリだが、各段の快感の有無は測っていない。
