## BACKLASH独自要素

| # | 要素 | 独自性の根拠 | 影響度 |
|---|---|---|---|
| **A** | **打ち返し弾（revenge bullets / backlash）** | 敵撃破時に弾が散乱する。「撃つほど危険が増す」ジレンマがコアの緊張メカニクス。ゲーム名の由来。斑鳩の属性弾や怒首領蜂の弾消しとは異なり、「撃破=新たな脅威の発生源」として攻撃と危険を直結させる設計 | **コア（ゲームのアイデンティティ）** |
| **B** | **至近距離 mercy** | 打ち返し弾の派生調整。近距離撃破時にプレイヤー方向±60°の弾を外す（子供プレイテスト由来）。cyan視覚フィードバック付き | サブ（Aの調整層） |
| **C** | **AI Expert Mode**（`?ai=1`） | 17方向評価+弾道線距離+BOMB判断のAI自動プレイ。ゲームプレイには影響しない観戦/検証用メタ機能 | メタ（ゲームプレイ外） |

**計: 1コア要素 + 1派生調整 + 1メタ機能**

## 比率算定

### 要素数ベース

- 一般的要素: 16
- 独自要素: 1コア + 1派生 + 1メタ → 実質ゲームプレイに関わるのは1.5
- **比率: 約 91:9**

### ゲームプレイ影響度ベース（プレイ中の判断に占める重み）

打ち返し弾がなければ、BACKLASHは「敵を撃って避けるだけの普通のSTG」。打ち返し弾があることで:
- 撃破タイミングの判断（敵を倒す位置・順序が重要になる）
- ボム使用判断（打ち返し弾の海をボムで一掃するか、避けるか）
- ゲージ管理の緊張（撃てば撃つほどゲージが溜まるが、撃破で弾も増える）

プレイ中の判断の約15-20%は打ち返し弾に起因すると推定。残りの80-85%は「避ける/アイテム取る/パワーアップする/ボムを使う」という一般STG判断。

- **比率: 約 85:15**

### コード量ベース

- `spawnRevenge` + mercy 関連: 約80-100行
- index.html 全体: 約1300行
- **比率: 約 93:7**

### 総合判定

| 軸 | 一般:独自 |
|---|---|
| 要素数 | 91:9 |
| ゲームプレイ影響度 | 85:15 |
| コード量 | 93:7 |
| **総合（加重平均）** | **約 88:12** |

## 新作の上限基準としての使い方

### 基準

> **新作の独自要素は、BACKLASHの12%以下に抑える。守の段階では10%未満を推奨。**

### 具体的に

1. **独自要素は1つだけ**。BACKLASHの独自要素は実質「打ち返し弾」の1つ。mercyはその調整、AI Modeはメタ機能。新作も核となる独自要素は**1つ**に絞る
2. **型の上に載る独自要素**。打ち返し弾は「STGの敵撃破」という型の動作に上乗せされている。型を壊さず、型の結果に1つだけ味を足す構造。型の根本（移動/射撃/避ける）を変えるものは独自要素ではなく軸ずらし
3. **独自要素が型を強化する関係**。打ち返し弾があることで「撃つ→当たる→ゲージ増→弾増」の核ループに緊張が加わり、ボムの解放感が増す。独自要素が型のループを阻害するならそれは独自要素ではなく欠陥

### Q-H-5 への回答テンプレート

新作READMEに書く際:
```
Q-H-5: 一般要素 vs 独自要素 = X:Y
  基準: BACKLASH = 88:12 が上限
  本作 = ___:___
  独自要素がBACKLASH比率を超えていたら、独自要素を削るか型を増やす
```

## 補記: なぜBACKLASHは成功したか

成功の核心は**独自要素の少なさではなく、型の完成度の高さ**。

- 16個の一般的要素が全て「STGとして当たり前に機能する」レベルで実装されている
- パワーアップ段階、被弾システム、ボムコスト、アイテム吸収、スコア設計、演出——全てNao_uが対面セッションで1つ1つ調整した
- 独自要素（打ち返し弾）は型が完成した後に載っている。型が壊れていたら打ち返し弾は機能しない

**守ができていたから、たった1つの独自要素で「BACKLASHらしさ」が立った。** 守ができていなければ、独自要素をいくつ足しても「形無し」（M-22）になるだけ。
