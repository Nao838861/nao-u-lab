# エナガの かんじの森 (enaga_kanji_log)

**ブラウザで遊ぶ: https://nao838861.github.io/nao-u-lab/Claude/game/enaga_kanji_log/**

小学生向けの漢字アプリ。部品の **なまえ（ひらがな）を書く順に唱えて**から、**形を出す**（12個から選ぶ／ペンで書く）。ヒントも見本も使わずにできた字だけが「おぼえた」になり、その字をおなかに持ったシマエナガが森に集まる。

- 学び方はカンジ工房（Claude版 `GPT/projects/kanji_learning/claude_v001`）で決めたものを引き継ぎ、画面とプログラムは新しく書いた。前の工房の記録は引き継がない
- 雰囲気と続ける仕組みは「シマエナガのけいさん団子」（`../enaga_math_log`）と揃えた
- iPad（横置き）でも PC でも遊べる。1280×720 の枠を画面に合わせて拡大縮小する

## 遊び方

1. なまえを入れて、学年を選ぶ（なまえごとに記録が分かれる）
2. **かんじを つくる**：光村図書の教科書の順に3文字。お題（「シン号 の シン」）を見て、部品のなまえを書く順に選ぶ → 部品の形を順に選ぶ（またはペンで書く）
3. **ぶひん れんしゅう**：形 → なまえ（6択）→ 形（12択／ペン）
4. **かんじ団子**：おぼえた字が10字になると遊べる。10問のタイムアタック（部品を書く順にタップ）。まちがえた字・15秒より長くかかった字は「もう一回」に戻る

## 積み重ね（続ける理由）

| しくみ | 内容 |
|---|---|
| かんじの森（ホーム） | おぼえた字をおなかに持ったシマエナガが枝に並ぶ。新しく覚えた字の鳥は、ホームに戻ると飛んでくる |
| シマエナガの数 | 一発で正かい 1羽／字をおぼえた +10羽／教科書の回をぜんぶ +30羽／学年をぜんぶ +100羽／部品ができた +3羽／かんじ団子クリア +10羽（ノーミス +10羽）。「エナガの もり」で位ごとの大きなシマエナガとして見える |
| しょうごう（86こ） | おぼえた字・教科書の回/学期/学年・一発れんぞく・ペン・ヒントなし・部品・まいにち・シマエナガの数・かんじ団子・とりかえす。まだのものは「？？？」で条件だけ見える |
| 一発れんぞく | ミスもヒントも見本もなしで正かいした数。日をまたいでも続く。ヒント・見本を使った問題では増えも減りもしない |
| あしあと | 日ごとに、その日おぼえた字・増えたシマエナガ・取ったしょうごう・かんじ団子の回数が残る |
| ずかん | 教科書の回ごとに、まだ（押したくなる白）／あとすこし（黄）／もう一回（黄）／おぼえた（若葉色シール）。回をぜんぶ覚えると見出しにシマエナガ |
