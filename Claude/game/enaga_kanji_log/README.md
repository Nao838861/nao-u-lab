# エナガの かんじの森 (enaga_kanji_log)

**ブラウザで遊ぶ: https://nao838861.github.io/nao-u-lab/Claude/game/enaga_kanji_log/**

小学生向けの漢字アプリ。部品の **なまえ（ひらがな）を書く順に唱えて**から、**形を出す**（12個から選ぶ／ペンで書く）。ヒントも見本も使わずにできた字だけが「おぼえた」になり、その字をおなかに持ったシマエナガが森に集まる。

- 学び方はカンジ工房（Claude版 `GPT/projects/kanji_learning/claude_v001`）で決めたものを引き継ぎ、画面とプログラムは新しく書いた。前の工房の記録は引き継がない
- 雰囲気と続ける仕組みは「シマエナガのけいさん団子」（`../enaga_math_log`）と揃えた
- iPad（横置き）でも PC でも遊べる。1280×720 の枠を画面に合わせて拡大縮小する

## 遊び方

1. **タイトル**：なまえと学年を選んで「はじめる」（なまえごとに記録が分かれる。起動するとかならずここから）
2. **森（ホーム）**：じぶんの森。ここから3つのあそびと、きろく（エナガの もり・しょうごう・あしあと）へ
3. **かんじを つくる**：「まだ おぼえていない字／あとすこしの字／おぼえた字」から選ぶか、下のずかんで字を選ぶ。光村図書の教科書の順に3文字。お題（「シン号 の シン」）を見て、部品の名前を書く順に選ぶ → 部品の形を順に選ぶ（またはペンで書く）
4. **ぶひん れんしゅう**：にがてな部品3つ、または下のずかんで部品を選ぶ。形 → なまえ（6択）→ 形（12択／ペン）
5. **かんじ団子**：おぼえた字が10字になると遊べる。10問のタイムアタック（部品を書く順にタップ）。まちがえた字・15秒より長くかかった字は「もう一回」に戻る

## 積み重ね（続ける理由）

| しくみ | 内容 |
|---|---|
| かんじの森（ホーム） | おぼえた字をおなかに持ったシマエナガが枝に並ぶ。新しく覚えた字の鳥は、ホームに戻ると飛んでくる |
| シマエナガの数 | 一発で正かい 1羽／字をおぼえた +10羽／教科書の回をぜんぶ +30羽／学年をぜんぶ +100羽／部品ができた +3羽／かんじ団子クリア +10羽（ノーミス +10羽）。「エナガの もり」で位ごとの大きなシマエナガとして見える |
| しょうごう（86こ） | おぼえた字・教科書の回/学期/学年・一発れんぞく・ペン・ヒントなし・部品・まいにち・シマエナガの数・かんじ団子・とりかえす。まだのものは「？？？」で条件だけ見える |
| 一発れんぞく | ミスもヒントも見本もなしで正かいした数。日をまたいでも続く。ヒント・見本を使った問題では増えも減りもしない |
| あしあと | 日ごとに、その日おぼえた字・増えたシマエナガ・取ったしょうごう・かんじ団子の回数が残る |
| ずかん | 教科書の回ごとに、まだ（押したくなる白）／あとすこし（黄）／もう一回（黄）／おぼえた（若葉色シール）。回をぜんぶ覚えると見出しにシマエナガ |

## 記録

localStorage `enaga_kanji_v1`。なまえごとに、学年・学年ごとのいまここ・漢字と部品の記録・シマエナガの数・しょうごう・れんぞく・あしあと・かんじ団子のベストとゴースト。筆跡は保存しない。

## 家族と共有するオンライン保存

通常URLでは従来の端末内保存を使う。左下の「この端末に保存」から、Firebaseの保存先URLを入力して家族用リンクを作れる。既存記録をコピーするか、空で始めるかを選べる。同じリンクをPC・iPadで開けば、同じ記録を使える。家族のログインは不要。

初回だけFirebase Realtime Databaseの作成とルールの設定が必要。[設定画面](./cloud-setup.html) の手順に従う。[詳しい運用・競合時の扱い](./cloud-save-setup.md) も参照。

- 家族用リンクは `#save=<自動生成キー>&db=<FirebaseのURL>`。共有用キャッシュと従来の `enaga_kanji_v1` を分ける。
- 通信断では未送信分を端末に残し、復帰時・再起動時に再送。同時更新では自動上書きを止め、書き出しまたは別リンクへの退避を選べる。
- 主な実装は `js/save-store.mjs`（保存・条件更新）と `js/cloud-save.mjs`（保存先・状態表示・リンク作成）。Firebase用ルールは `database.rules.json`。
- 検証：`node --test test_cloud_save.mjs`。公式Database Emulatorに本ルールを読み込み、`FIREBASE_DATABASE_EMULATOR_HOST` を指定すれば `node --test test_cloud_emulator.mjs` と `node test_cloud_flow.mjs` で実通信・ルール・ブラウザー2台の流れも確認できる。
