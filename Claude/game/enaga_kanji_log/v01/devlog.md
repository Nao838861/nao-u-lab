## 「積み重ねが記録に残る」ための判断

最後の指示を受けて、積み重ねが **目に見えて・消えずに・日付つきで** 残ることを優先した。

1. **ホームを森そのものにした**：おぼえた字ごとに、その字をおなかに持ったシマエナガが枝にとまる（1段8羽・最大48羽、それ以上は「ほかにも○羽」）。学習から戻ると、新しく覚えた字の鳥が順に飛んでくる。数字のメーターより「自分の字が集まっている」感じを出すため。
2. **あしあと（日ごとの記録）を足した**：企画になかったもの。けいさん団子は「何回クリアしたか」で積み重ねが見えるが、漢字は「どの字を覚えたか」が積み重ねの中身なので、日ごとに覚えた字そのものを並べる。しょうごうも取った日に残す。
3. **しょうごうは細かく刻んだ（86こ）**：おぼえた字は 1/5/10/20/30/50/75/100/… と最初を細かくし、1回目の3文字で必ず1つ取れるようにした。取った瞬間に右下へ通知、まとめ画面に NEW のカード、ホームの「しょうごう」に NEW 件数。
4. **おぼえた の価値を守る**：一発（ミス・ヒント・見本なし）の正かいだけが羽になり、ヒントで正かいすると小さい子エナガがとまるが数えない。当たるまで押す・すぐヒントを見る、が得にならない。ヒントを使っても一発れんぞくは減らない（ヒントを使うことを罰しない）。
5. **一度取ったものは消えない**：しょうごう・教科書の回の達成・あしあとは、かんじ団子で字が「もう一回」に戻っても残る。戻った字を覚え直すと「とりかえした！」と通知し、専用のしょうごうがある。
6. **かんじ団子**：けいさん団子と同じ見せ方（カウントダウン、ゴースト、ランク E〜SSS、ファンファーレ、BGM）。ランクの基準（10問で SSS 25秒〜D 100秒）は仮。実際のタイムで合わせる。

### 画面の流れの整理

> タイトル画面が碁茶ついてるのを整理したい。
> タイトル画面は、人の選択と学年の選択で、必ずここがスタートになるようにして、今のタイトルから名前と学年を分離して。
> 図鑑は今の重さよりは重要なのでしょうごうなどと分けた場所にいた方がいい。
> 「かんじをつくる」に入った後は、覚えてない漢字、あと少しの漢字、覚えた感じのどれを練習するかのメニューをだして、下に図鑑相当のものを出すのはどうか？

→ 画面の流れを「タイトル → 森 → あそび方ごとのメニュー」に分けた。
- **タイトル**：なまえ・学年だけ。起動（再読みこみ）するとかならずここ。前回のなまえ・学年はえらんだ状態で、「たろう・4年 で はじめる」を押すだけで入れる。きろくを けす・出典もここ
- **森（ホーム）**：じぶん（なまえ・学年・「なまえ・学年を かえる」）、おぼえた数のメーター、大きいボタン3つ、「きろく」（エナガの もり・しょうごう・あしあと・一発れんぞく）。ずかんは きろく の並びから外した
- **かんじを つくる**：入ると「まだ おぼえていない字／あとすこしの字／おぼえた字」の3つのカード（それぞれの字数つき、0なら押せない）。その下に漢字のずかん（教科書の回ごと）。字を押すとそこから
  - まだ：いまここから教科書の順に、まだ手をつけていない字を3文字
  - あとすこし：一度できたがまだ「おぼえた」でない字・「もう一回」に戻った字を、いまここからの順に3文字
  - おぼえた：かんじ団子で最近出ていない字を優先して3文字（ふくしゅう）
  - まとめの「つぎの 3文字」は同じえらび方で続く。「えらびなおす」でメニューへ
- **ぶひん れんしゅう**：同じ形にそろえた（「にがてな ぶひん」カード＋下に部品のずかん）。ずかんボタンが森から消えるので、部品のずかんの置き場としてこちらにも移した
- 問題のとちゅうの「ずかん」ボタン（もどるつき）はそのまま

### かんじ団子で 字が できた瞬間

> かんじ団子で、文字が完成した瞬間に完成した文字を見せて気持ちのいい正解音を出して。うろ覚えの漢字を正解した時に完成形が見えないまま次の漢字に進むのは良くない

→ 最後の部品を押した瞬間に、枠へ完成した字を緑の枠でぽんと出し、お題の語例の □ にも字を入れて（野□ → 野菜）見せてから次へ進むようにした。
- 見せる時間：一発なら0.75秒、まちがえてから組めた字（うろ覚え）は1.3秒。うろ覚えの字ほど長く見せる
- 見せている間は部品を押せず、**タイムを止める**（見る時間でタイムが悪くならないので、急いで飛ばす理由がない）。ゴーストのシマエナガも止まる
- 音：完成専用の「ピロリン♪＋和音」（`sfx.solved`）。部品ごとのさえずりとは分け、れんぞくで少しずつ高くなる

> 成功した音はピロリロン！みたいな嬉しい正解音にして。

→ `sfx.solved` を「ピ・ロ・リ・ロ・ーン！」に作り直した（ソ→ド→シ→ミと はずんで上がり、最後に高い和音をのばす。四角波＋1オクターブ上の正弦波で明るく）。

### データの直し：ハ と ソ

> 説明の説が、ごん便にハと言われたが、ハではない

→ 調べると、上の2画が内向き（ソの向き）なのに「ハ」と名付けられていた字が6つあった：前・弟（2年）、説（4年）、税（5年）、並・尊（6年）。いずれも「ソ」に直した（前の工房のデータからのコピーなので、元にも同じ誤りがある）。筆の向き（1画目が右下へ・2画目が左下へ＝ソ、逆＝ハ）で全学年を確かめるチェックを test_flow に足した。

### 2画の くみ の 呼び方を そろえた

> 飛もノノはちょっと違和感があるが、これは他にもっといい呼び方ないの？ミチムラ式でこれはノノ？
> 説にソが出てくるなら、岡もソでいい？厳密にはソじゃないから点とノの組み合わせの方がいい？この辺統一見解が欲しい。案を出して。
> その案で進めて。

飛の「ノノ」は前の工房で手で決めた推定で、公式の唱えは未確認。公式資料では「ソ」は公式の部品で、豆の上（すぼまる点とノ）もソと唱えている（頭＝一、口、ソ…）。「ノノ」は勿のように同じ向きのノが2本ならぶ形。これにそろえて：

| 形 | 呼び方 |
|---|---|
| 上で すぼまる（点が右下へ・ノが左下へ） | ソ |
| 下へ ひらく | ハ |
| 同じ向き・同じくらいの長さの ノ が2本 | ノノ |
| どれでもない | 1画ずつ |

直した字：米・平・業（後半）・岡・樹・火 の「てん・ノ」→ ソ。飛・火・脈・派 の「ノノ」（短いノと長いノで向きも長さも違う）→ ノ、ノ。火は ノノ を分けたら左の点と右の短いノが すぼまる形になったので ソ・ノ・はらい。test_flow のデータチェックで この3つの決まりを筆の向きと長さで確かめる。

### ペン：お手本を なぞる

> ペンで書くモードには、お手本をなぞるモードも欲しい。

→ ペンで書く欄に「✎ お手本を なぞる」を足した（かんじを つくる・ぶひん れんしゅう の両方）。書く欄に うすい お手本と 書き順の数字（ピンク）が出て、その上をなぞって「書けた！」で判定する。なぞりは「見本を 見た」と同じあつかいにした：「おぼえた」にはならず、羽も増えない（子エナガは とまる）。まとめのタグは「✎ なぞって 書けた」。なぞりは その問題だけで、次の字では 見ないで書く に戻る（ずっと なぞったまま おぼえた にならない、を防ぐ）。

### 唱えの順を 書き順に・語例のない字

> 飛ぶののてんもここでしか見ない名前？
> 成 は の　ほこがまえ かぎ と言われたが、書き順と合ってない.
> あきらめてのてんで。
> B
> あと、画像のやつは何の漢字かわからないので補足がいる（「グン部 の グン」だけで語例がない画面）

- 飛の「ノてん」（飛にしかない名前）はそのまま。
- 唱えの順と書き順がちがう字が36字あった。囲む形（くにがまえ・はこがまえ・ぎょうがまえ等、21字）は「囲んで、中、さいごに とじる」として そのまま。ほこがまえ・しきがまえで 最初の「一」だけ先に書く15字（成・我・感・減・域・機・械・識・織・職・蔵・裁・式・試・武）は、その「一」を いち として書き順の位置に出し、のこりを「ほこがまえの一なし」「しきがまえの一なし」とした（公式の「羊の一本なし」と同じ呼び方の作り）。成＝ノ、いち、かぎ、ほこがまえの一なし。
- 語例が なかった6字（妹・池・勉・郡・媛・陛）に手で語例を足した。郡・媛は語例だけでは分かりにくいので、お題の下に小さく補足（郡「じゅうしょで『〇〇□ 〇〇町』と つかう字」）を出す（データの `h`）。
- test_flow：唱えの順＝書き順（囲む形だけ例外）、どの字にも語例がある、部品の形がそろっている、をデータで確かめる。

> にじゅう たて の流れ、おかしくない？みちむらしきにあるやつ？

→ 帯の上は「横・たて3本・横」の5画で、にじゅう（廿）より たてが1本多い。そこから まん中のたてだけを抜いて「にじゅう、たて」と分けていた（公式の唱えではない）。公式の「祭＝一本多いタ」と同じ作りで「一本多いにじゅう」（5画まとめて）にした：帯＝一本多いにじゅう、わかんむり、はば。同じく いちじゅう が ソ を はさんでいた 平 は「いち、ソ、じゅう」に。唱えの順と書き順がちがってよいのは、囲む形（くにがまえ・はこがまえ・ぎょうがまえ・ははのかん・ふしづくり）だけ。

> （栃の画面で）これはがんだれなのか？
> A

→ 栃は「木＋厂＋万」と説明される字で、がんだれ（厂）は字の成り立ちとして正しい（画数も 4＋2＋3＝9）。形が かたむいていて分かりにくいが、ユーザーの判断で「がんだれ」のまま（A）。

> （井の画面で）これもいわかんがある

→ 井が「いち、にじゅうあし」だった。にじゅうあし（廾）は横の下に短いあしが2本たれる形（算・鼻・弁）で、井のように横を2本ともつらぬく ノ・たて ではない。同じく 曲・冊 は「たて、たて、横」の順で 廾 ではないのに にじゅうあし にしていた。井＝に、ノ、たて／曲＝たて、かぎ、たて、たて、いち、いち／冊＝どうがまえ、たて、たて、いち に直し、にじゅうあし の形（横が先・あしは横の近くから下へ）をデータチェックに足した。
