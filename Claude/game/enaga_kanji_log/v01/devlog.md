## 「積み重ねが記録に残る」ための判断

最後の指示を受けて、積み重ねが **目に見えて・消えずに・日付つきで** 残ることを優先した。

1. **ホームを森そのものにした**：おぼえた字ごとに、その字をおなかに持ったシマエナガが枝にとまる（1段8羽・最大48羽、それ以上は「ほかにも○羽」）。学習から戻ると、新しく覚えた字の鳥が順に飛んでくる。数字のメーターより「自分の字が集まっている」感じを出すため。
2. **あしあと（日ごとの記録）を足した**：企画になかったもの。けいさん団子は「何回クリアしたか」で積み重ねが見えるが、漢字は「どの字を覚えたか」が積み重ねの中身なので、日ごとに覚えた字そのものを並べる。しょうごうも取った日に残す。
3. **しょうごうは細かく刻んだ（86こ）**：おぼえた字は 1/5/10/20/30/50/75/100/… と最初を細かくし、1回目の3文字で必ず1つ取れるようにした。取った瞬間に右下へ通知、まとめ画面に NEW のカード、ホームの「しょうごう」に NEW 件数。
4. **おぼえた の価値を守る**：一発（ミス・ヒント・見本なし）の正かいだけが羽になり、ヒントで正かいすると小さい子エナガがとまるが数えない。当たるまで押す・すぐヒントを見る、が得にならない。ヒントを使っても一発れんぞくは減らない（ヒントを使うことを罰しない）。
5. **一度取ったものは消えない**：しょうごう・教科書の回の達成・あしあとは、かんじ団子で字が「もう一回」に戻っても残る。戻った字を覚え直すと「とりかえした！」と通知し、専用のしょうごうがある。
6. **かんじ団子**：けいさん団子と同じ見せ方（カウントダウン、ゴースト、ランク E〜SSS、ファンファーレ、BGM）。ランクの基準（10問で SSS 25秒〜D 100秒）は仮。実際のタイムで合わせる。

## 前の工房から引き継いだ学び方

部品名を書く順に唱える → 形（12択／ペン）、暗黙のモード切り替え（状態を消さない・設定を保存）、場所ごとの段階ヒント → 部品れんしゅう → お題に戻る、見本で進んだ字は おぼえた にしない、光村図書の順・いまここ・ずかんで選んだ字から始める、部品れんしゅうでは一般の部首名をそえる、飛（nd）はダミーなし。

## 見つけて直したこと（実画面）

- ヒントの欄が、下のヒントボタンを覆って押せなかった → 左のお題の下の枠に出すようにした
- 「◯◯を おぼえた！」の通知が問題文・まとめの見出しに重なっていた → 右下（団子の枝の上）に出す
- 森のシマエナガのおなかの字が小さくて読めなかった → 鳥を大きくし（半径21→26）、字も大きく
- ホームの大ボタンで「ぶひん れんしゅう」が折り返していた → 文字を小さくし折り返し禁止
- かんじ団子でしょうごうを一度にたくさん取ると結果画面があふれた → 3つまで出して「ほか○こ」
