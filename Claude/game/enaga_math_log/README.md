小学4年生向け、タイピングソフト感覚の計算練習。20問をできるだけ速く解いてタイムを競う。

| 版 | 内容 |
|---|---|
| [v01](v01/index.html) | たし算・ひき算コース（★1〜★3）、Enter確定、自己ベストのゴースト、れんぞく正かいで「エナガ団子」、なまえ別の記録 |
| [v02](v02/index.html) | ようちえんモード（こたえ10以下・かず20まで）、エナガのもり（あつめた数を位ごとの大きなシマエナガで表示）、しょうごう、ミスなし連続の記録、かけ算コース |
| 最新（index.html） | ★1を足し算・引き算・混合の3種類に分離。記録とタイム称号を独立させ、各13段の動物称号を表示。★2は鳥、★3は宇宙の称号。★1のタイム基準はF70・E60・D50・C45・B40・A35・S30・SS28・SSS26秒。結果に「つぎは○○まで あと何秒」。古い記録と取得済みの称号は引き継ぐ。テスト: `node test_titles.mjs`、`node test_split_courses.mjs` |

遊び方: `index.html` をブラウザで開く。★1は「足し算」「引き算」「足し算と引き算」の3種類。どれも20問で、ベストタイム・ゴースト・上位記録・ランク・クリア数を別々に保存する。旧★1の記録は「足し算と引き算」に引き継ぐ。★2・★3と、かけ算の出題は従来通り。

数字キーの7で足し算★1、8で引き算★1、1/2/3で足し算と引き算★1〜★3、4/5/6でかけ算★1〜★3を選び、Enterで開始する。ボタンを直接押しても開始できる。答えは数字キーかテンキーで入れてEnter。

足し算・引き算にも、それぞれ13段の動物タイム称号とデビュー称号を追加。タイム基準は元の★1と同じ。全制覇は★1の3種類＋★2＋★3の5種類、かけ算込みなら8種類で判定する。取得済みの旧制覇称号は残し、新しい制覇とは別に扱う。幼稚園にも3種類の別記録と専用称号がある。確認: `node test_split_courses.mjs`。指示原文と判断は [design_log.md](design_log.md) を参照。

森に増えるシマエナガは、ゲームやブラウザの再起動をまたいで保存される連続正解数に応じて増える。クリア時に「連続正解数×2羽」と通常報酬（正解数＋10羽、ノーミスならさらに10羽）の多い方を加算する。通常モードは1回の上限が800羽で、20連続で＋40羽、40連続で＋80羽、400連続以降は＋800羽。幼稚園モードはセッションをまたいで連続正解が増えても、1回の報酬は最大40羽。ミスで連続正解数は0に戻るが、森の累計数は減らず、800羽を超えて蓄積する。かけ算★3はこれまで通り1問を2問分として数える。確認: `node test_rewards.mjs`。
