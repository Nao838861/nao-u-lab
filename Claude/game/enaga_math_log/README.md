# シマエナガのけいさん団子 (enaga_math_log)

**ブラウザで遊ぶ（最新 v02）: https://nao838861.github.io/nao-u-lab/Claude/game/enaga_math_log/v02/**

小学4年生向け、タイピングソフト感覚の計算練習。20問をできるだけ速く解いてタイムを競う。

| 版 | 内容 |
|---|---|
| [v01](v01/index.html) | たし算・ひき算コース（★1〜★3）、Enter確定、自己ベストのゴースト、れんぞく正かいで「エナガ団子」、なまえ別の記録 |
| [v02](v02/index.html) | ようちえんモード（こたえ10以下・かず20まで）、エナガのもり（あつめた数を位ごとの大きなシマエナガで表示）、しょうごう、ミスなし連続の記録、かけ算コース |

遊び方: `v02/index.html` をブラウザで開く。1/2/3で★を選んでEnter。答えは数字キーかテンキーで入れてEnter。
