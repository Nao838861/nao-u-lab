# v01 設計メモ

## 一番楽しい瞬間
問題を見た瞬間に答えが浮かび、指で打ってEnter → パッと次へ。正解が続くとシマエナガの仲間が枝に並んで「団子」になる。

## 型（借りたもの）
- 寿司打: コース選択、結果画面のランク＋一言
- ポップタイピング: 連続成功で盛り上がる演出
- 独自要素は1つ: 自己ベストのゴースト（半透明のシマエナガ）と並走

## 仕様
- 20問。たし算10・ひき算10。★ごとにくり上がり・くり下がりの問題数を固定（タイムを比べて公平にするため）
  - ★1: 1けたどうし（くり上がり5／なし5、くり下がり5／なし5）
  - ★2: 2けた±1けた（くり上がり7／なし3、くり下がり7／なし3）
  - ★3: 2けた±2けた 6問＋何百±何百 4問 をたし算・ひき算それぞれ
- Enterで確定（Nao_u指示：Enterあり）。BackSpaceで消す
- 入力はキーの `code`（Digit/Numpad）で判定し、input要素を置かない → 日本語入力ONでも数字が入る
- まちがえた: 打ち直し。れんぞくは0に戻り、団子はふわっとほどける（罰は打ち直しにかかる時間だけ）
- 2回まちがえた: 答えを1.5秒表示して次へ進む。その問題は最後に「もういちど！」として出る（もう一度まちがえても先へ進む）
- なまえ: タイトルで入力（10文字まで）。一度入れたなまえはボタンになり、マウスで選べる（最近つかった順に8人まで表示）。なまえ未選択ではスタートできない
- 記録: localStorage `enaga_math_v01` = {players, last, recs:{なまえ:{addsub_★:{best,ghost,top}}}}。なまえ×★ごとにベスト・ゴースト・上位5件
- 結果画面に「みんなの★ベスト」（なまえごとのベストの上位5人）
- ランク（秒）: ★1 S≤35/A≤50/B≤75、★2 50/70/100、★3 70/100/140（仮。子どもに遊んでもらって調整）

## 見た目
- 画面は1280×720の固定枠を窓に合わせて拡大縮小（広い画面でもスカスカにしない）
- シマエナガは正面向き・お餅形・細い輪郭線・離れた黒目・ピンクのほっぺ・横からのぞく羽・ななめのしっぽ（よくあるかわいいイラストの描き方に合わせた）
- 下の枝のまん中に大きな「きみ」。正解でにっこり跳ねる、まちがいで「><」と汗。なかまは左右交互にならぶ
