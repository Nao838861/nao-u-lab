# v02 設計メモ

v01（入力・ゴースト・エナガ団子・なまえ別記録）に、続けて遊ぶ理由を3つ足した版。記録は v01 と同じ localStorage `enaga_math_v01` を使い、v01 のデータを引きつぐ。

## ようちえんモード
- なまえの横のトグルで切りかえ。なまえごとに ON/OFF を覚える。ONのあいだは画面がピンクになる
- こたえは かならず 1〜10、でてくる数は 20まで
  - ★1: こたえ5まで（たし算10・ひき算10。組み合わせがちょうど20通り）
  - ★2: こたえ6〜10のたし算10・10までのひき算10
  - ★3: こたえ10までのたし算6・「11〜20 − 1〜10」のひき算14
- 記録・ゴーストは通常モードと別（`k_addsub_★`）

## エナガのもり
- 増え方: 正かい1つで1羽、クリアで+10羽、ノーミスならさらに+10羽（1回のクリアで20〜40羽）
- 位ごとの列で表示する。1羽／10羽ぶん（マフラー）／100羽ぶん（王冠）／1000羽ぶん（大きい王冠＋キラキラ）／10000羽ぶん（光の輪＋後光）。位が上がるほど体も大きい
- 開くたびに「前回見た数」から今の数までカウントアップする。くり上がりでは小さいシマエナガが上の位の列へ飛んでいき、大きいシマエナガが生まれる（位取りが目で見える）
- まだ届いていない上の位は秘密（列もシルエットも出さない）。一万の位まで用意してあり、届いたときに初めて列が増える

## しょうごう（75こ）
- 分類: はじめて（クリア回数）／正かい（累計正かい数）／れんぞく（ゲームをまたぐミスなし連続正かいの記録＋ノーミスクリア）／ランク（S・A・B、★ごとのS、全★クリア）／ようちえん／はやさ（1秒未満の正かい、1問平均）／がんばり（もういちど問題の正かい、ベスト更新、1日のクリア数）／まいにち（遊んだ日数・連続日数）／エナガ（あつめた数）
- まだ取っていないものは名前が「？？？」で、条件だけ見える
- 結果画面に新しく取ったしょうごうを出す。タイトルの「きろく」に NEW 件数を出す
- v01 で遊んだ分は、残っている上位5回の記録からつみあげ・しょうごうを引きつぐ

## ランク（9段階）
- E → D → C → B → A → AA → S → SS → SSS。初回はEかD、SSSは大人が本気でやって届くくらい
- 基準（秒、SSS/SS/S/AA/A/B/C/D。それより遅いとE）
  - 通常 ★1: 24/28/33/39/46/53/60/80、★2: 48/60/75/95/120/150/185/250、★3: 65/78/92/110/130/150/170/250
  - ようちえん ★1: 27/32/38/45/54/64/76/95、★2: 32/38/45/54/65/78/95/120、★3: 38/45/54/65/78/94/112/140（仮）
- 校正の根拠: 小4の初回タイム ★1 65.4秒・★2 213.1秒・★3 176.5秒 → どれもD
- 結果画面に「つぎの C（170秒）まで あと ○秒」を出す。タイトルの★にもベストのランクを出す

## 結果画面の整理
- ランク＋しょうごう → タイム → ベストとの差 → つぎのランクまで → 数字3つ（1問の秒数・れんぞく・ミス。良い値は金色）→ みんなのベスト
- 点線の下に「ごほうび」（シマエナガ・大きなシマエナガ・新しいしょうごう）
- 自分の上位5回の一覧は消した。時間がかかった問題は1問だけ（ごほうびが多い回は省く）

## ミスなし れんぞく（ゲームをまたぐ）
- 正かいで+1、1回でもまちがえると0。次のゲームでも続きから数える。なまえごとに「いまの数」と「きろく」を保存
- 画面上の「れんぞく」はこの数。タイトルのきろく欄に「ミスなし れんぞく 15（きろく 45）」
- プレイ中に記録をこえたら「れんぞく きろく こうしん！」、50ごとに「ミスなし ○れんぞく！」
- しょうごう: 10/20/30/50/75/100/150/200/300/500/1000 れんぞく。1ゲーム内の5/10/20れんぞくと「ノーミス5回」は簡単すぎるので外した
- 下の枝の団子は1ゲーム内の連続のまま（枝に20羽まで）

## しょうごうの名前・エナガの段階
- 名前は小学生が喜ぶ方向（ぼうけんしゃ→ゆうしゃ→大まおう、はかせ→かみさま、スーパー/ハイパー/ウルトラ/ギガ/テラ/ゴッドエナガ など）。ランクごとのしょうごうも同じ並び
- エナガの数: 10羽は外し、100/200/300/500/700/1000/1500/2000/3000/4000/5000/7000/10000（クラス→学年→小学校→…→町→…→王国→大りく→わくせい→ぎんが→うちゅう）
- 見積もり: 1回のクリアで20〜40羽、1回2分ほど → 1時間で約1000羽、10時間で約1万羽。1万羽は「エナガ うちゅう」と、エナガのもりの一万の位（光の輪のシマエナガ）が同時に来る

## かけ算コース
- ★1: 九九（2〜9の段、順番バラバラ）20問
- ★2: 九九の逆「□ × 7 = 56」「8 × □ = 64」10問＋何十×1けた（40×6、7×80）10問
- ★3: 2けた×1けた を10問（くり上がりあり7問、なし3問。10の倍数は出さない）。1問を2問ぶんとして数える（シマエナガ・累計正かい数・ミスなし連続・団子が2ずつ）。画面では説明しない
- 基準（秒、SSS〜D、仮）: ★1 22/26/31/37/44/52/62/90、★2 30/36/44/54/66/80/100/140、★3 30/38/48/60/75/93/115/160（10問ぶん）
- 記録は `mul_★`、つみあげのキーは m1〜m3。ようちえんモードではかけ算を出さない
- キーボードは 1〜3 がたし算・ひき算、4〜6 がかけ算
- しょうごう: かけ算 デビュー／九九 マスター／九九の まほうつかい／かけ算 ドラゴン／かけ算 コンプリート／かけ算の ゴッド／けいさん オールスター（全82こ）

## 音
- スタート: カウントダウン 3・2・1 に合わせて2音ずつ上がるジングル、「スタート！」で和音＋キラキラ＋さえずり
- プレイ中BGM: 128BPMのポップ調ループ（ベース・裏打ちの和音・小さいハイハット）を小さめの音量で。1ゲーム内のれんぞく5でオルゴールのメロディ、10でキラキラが加わる。結果画面・タイトルでは止める。BGMだけ別にON/OFF（なまえに関係なく保存）
- クリア: 弾む「タタタ・タッタ・ターン！」
- ベスト更新（2回目以降）: ドラムロール → 金管風の和音 → 長い和音＋キラキラ＋さえずり（約3.4秒）
- 新しいしょうごうの音はファンファーレが終わってから鳴らす

## きろくを けす（なまえごと）
- タイトルの「きろく」欄の一番下に、目立たない文字リンク「きろくを けす」
- 4段階: なまえを選ぶ → 消えるもの（ベスト・シマエナガの数・しょうごう数・れんぞく記録）を見せて確認 → 「もとに もどせません」で再確認 → なまえを打ちこんだときだけ「けす」が押せる
- どの段階も「やめる」が初期フォーカス（Enterでやめる）。Escでも閉じる
- 消すのは そのなまえの recs / stats / ようちえん設定 / なまえ一覧の項目。ほかの人とBGM設定は残す
