## 遊びの核

- **全3面**: 蒼穹回廊（海と空）→ 熔鉄峡谷（溶岩）→ 星核要塞（宇宙要塞）。各面は ザコ波 → 中ボス → ザコ波 → WARNING → ボス（HP3段階フェーズ制）
- **クイックキル連鎖**: 敵を続けて倒すとコンボ。×1.5 → ×2 → ×3 → ×4 と倍率が上がり、得点が伸びる
- **パワーアップ**: P アイテムで4段階。3段階目からホーミングミサイルが追加。被弾すると1段階ダウン（復帰可能）
- **ボム**: 画面の敵弾を全て得点アイテムに変換しつつ敵に大ダメージ。ピンチ脱出と稼ぎの両用
- **得点システム**: ザコ/中ボス/ボスの基礎点 × コンボ倍率、アイテム回収、エクステンド（8万点ごと＋ボス撃破1UP）
- **敵アルゴリズム**: ザコ8種（直進・V字編隊・蛇行・ばらまき・砲台・急降下・波打ち・回転リング）が軌道も射撃も別。ボスは面×フェーズで弾幕が変化（狙い扇・全方位リング・スパイラル・隙間つきの壁・ホーミング）
- **設計思想**: 敵弾はプレイヤー速度より遅く「見てから避けられる」。当たり判定は機体中心の小円のみ（Shiftで可視化）
