# FABLE STRIKER v01 devlog

2026-06-11 / Fable 5（fable_swing, fable_tunnel に続く3作目）

Nao_u 指示: 縦STG・全3面・ザコ/中ボス/ボスのアルゴリズム・パワーアップと得点システム・凝った絵とBGM/SE・「そのままインディーで発売できる製品レベル」「コストはかけていい」。

## 全体設計

- 540×720 仮想解像度、Canvas 2D + WebAudio、外部依存ゼロ、index.html + game.js のみ。オフライン動作
- seeded PRNG（xorshift32、Math.random 不使用）で再現性確保 → ヘッドレステストが決定論的に回る
- ゲームロジックと描画を分離（headless フラグで描画/音声をスキップ可能）

## 製品レベルを口だけにしないための品質ゲート

「製品レベル」を主張する以上、動く証拠が要る。描画/音声をスタブ化し、**回避AIオートパイロットで全3面を実際に完走させる自動テスト**（headless_test.js）を書いて、それが通るまで出さないと決めた。

開発中、このテストが実バグを2件検出した:
1. **wave2 ソフトロック**: turret/spinner が画面上に静止し続け、「敵が掃けたら次へ」条件が永久に満たされず詰む → 静止敵に寿命（一定時間後に退避）+ 猶予タイムアウトを追加
2. **ボスHP過剰でのバランス崩壊**: 初期HPだとボス戦が90秒超に伸び、その間の被弾でパワーが落ちて火力が下がる死のスパイラル → ボス/中ボスHPを約4割削減、ミサイル火力を上げて適正化

最終的にAIは約145秒で全3面クリア・3ボス撃破・被弾1回・スコア26万。全9アサーション PASS。

## 敵アルゴリズム

ザコ8種は軌道と射撃を関数で持たせ、全種で挙動が異なる:
| 種別 | 軌道 | 射撃 |
|---|---|---|
| stream | 縦一列直進 | 狙い単発 |
| vee | V字編隊 | 急降下 |
| sine | 横から蛇行 | 散発狙い |
| popcorn | 高速直進・低HP高得点 | なし |
| turret | 進入して居座る | 3way扇 |
| diver | 加速突入で弧を描く | 狙い |
| weaver | 左右に波打ち降下 | ばらまき |
| spinner | 進入して回転 | 8方向リング |

ボスは `frac = hp/maxhp` で0/1/2の3フェーズに自動遷移。面×フェーズで弾幕パターンを切り替え（面1=守護機: 扇→リング→スパイラル+狙い／面2=巨蟲: 高速スパイラル→隙間つき壁→全方位／面3=支配者: 全部の複合）。

設計の肝は「全弾プレイヤー速度より遅い」こと。弾速175〜300px/s に対しプレイヤーは330px/s。壁弾も必ず通れる隙間を作る。「見てから避けられる」を全パターンで守った。

## システム

- パワー4段階（0:単発 / 1:2way / 2:3way+ミサイル / 3:5way+強ミサイル）。被弾で1段ダウン
- ボム: 敵弾を全て得点アイテム化 + 敵に大ダメージ + 短時間無敵。ピンチ脱出と稼ぎ両用
- クイックキル連鎖（コンボ）: 3/8/20/40 ヒットで ×1.5/×2/×3/×4。2.2秒で途切れる
- エクステンド: 8万点ごと + ボス撃破で1UP。コンティニュー2回（スコア半減）

## 演出

- プレイヤー: 多角形ストライカー + 排気炎 + バンク回転。当たり判定点を Shift で赤可視化（東方型の小判定）
- 敵: 楔形メカ（被弾フラッシュ）、ボスは多角スパイク殻 + 脈動コア
- 背景: 面別（海面のうねる線 / 溶岩の縦割れ / 要塞のスクロールグリッド）+ 3層星
- WebAudio: ステップシーケンサで面別BGM6曲（title/stage1-3/boss/clear）を半音列データから合成、SE 12種を合成（ショット/爆発/パワー/ボム/エクステンド/コイン/警告/被弾…）
