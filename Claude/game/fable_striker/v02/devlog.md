## グラフィック刷新

| v01 | v02 |

| 単色塗り | 金属グラデ＋パネルライン（機体・ザコ・ボス） |
| 単純な三角の排気 | 多層エンジン炎（外炎＋白核）＋機体下オーラ |
| 八角形ボス＋丸コア | 反対回りの回転リング2枚＋スパイク装甲＋多層脈動コア（赤→黄→白の発光） |
| 弾は塗り円 | 外周グロー＋飽和中間色＋白ハイライトの発光弾、プレイヤー弾も発光＋伸び |
| 火花だけの爆発 | 衝撃波リング＋中心フラッシュ＋火花（加算）＋煙（通常合成）＋回転する残骸の4層 |

実装の肝は **色別グロースプライトの事前生成**（`buildGlows`）。毎フレーム多数のグローを `drawImage`（加算）で描くので、`shadowBlur` を多用するより圧倒的に軽い。`shadowBlur` は数の少ないHUD/ロゴ文字にだけ使った。

## サウンド刷新

v01 は素の square/triangle 直挿しで「ピコピコ」。v02 はシグナルチェーンを組んだ:

- **マスター**: コンプレッサ（音圧と一体感）
- **空間系**: 合成インパルス応答のコンボリューションリバーブ + フィードバックディレイ。BGMリードとSEの一部を送る
- **ベース**: デチューン鋸2基 + サブ正弦 + ローパス包絡（太い低音）
- **リード**: スーパーソウ（3デチューン鋸）+ フィルタ包絡 + ディレイ送り（広がりと厚み）
- **パッド**: 緩やかな倍音3層をリバーブへ（空気感。各BGMに pad トラックを追加）
- **ドラム**: ピッチ包絡キック＋ノイズ/トーン合成スネア＋ハイパスハット（生のノイズ叩きから脱却）
- **SE**: 多層化＋空間送り（爆発・ボム・パワーアップ・エクステンドはリバーブで余韻、警告はデチューン2音）

BGMは v01 のステップシーケンサ資産（半音列データ）をそのまま使い、各楽器を上記のリッチな音色に差し替え＋pad トラックを足しただけ。曲の構成は維持。

## 品質保証（2本立て）

1. **ヘッドレス走破テスト**（v01 から継続）: 全3面オートパイロット完走。v02 でも全9項目 PASS（ロジック不変なので当然だが、音声/描画刷新がロジックを壊していないことの確認）
2. **描画スモークテスト**（v02 新規 `render_smoke.js`）: モックCanvasコンテキストで全描画関数を6状態ぶん走らせ、リッチ化した描画コードが例外を投げないことを検証。全状態 PASS

ヘッドレスは描画を通らないので「絵のコードのバグ」を検出できない。そこを描画スモークが埋める。両方緑になってから出した。

## 自己評価

- 描画/音声コードはモックで例外なしを確認。実ブラウザでの見え方・音の最終確認は未実施（自分の環境で描画・発音ができないため）
