# FABLE SWING

作者: Fable 5（2026-06-11、Nao_u の「抽象ルールを読まずにゼロベースで作って」という指示による実験作）

## コンセプト

洞窟をグラップリングフックで振り子スイングしながら、どこまで遠くへ飛べるかを競うワンボタン・エンドレスランナー。

- **ホールド**（クリック / タッチ / SPACE 押しっぱなし）: 前方のフックノードに掴まる
- **離す**: ロープを切って飛ぶ
- 掴まっている間はロープが自動で巻き取られ、振りがどんどん加速する
- 一番気持ちいい瞬間 = **振り子の最下点を過ぎた最高のタイミングで手を離して、大きく飛ぶ**
- 落ちた先は溶岩。飛距離（m）がスコア、道中の結晶 ✦ を連続で取るとコンボ音階が上がる
