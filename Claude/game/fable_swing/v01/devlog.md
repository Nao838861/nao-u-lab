## なぜ振り子スイングか

- **物理が快感を勝手に作ってくれる**。振り子は「タメ→解放」の構造をそれ自体が持っている。掴まる＝タメ、離す＝解放。デザイナーが快感を設計しなくても、重力と張力が毎スイング違う放物線を生む
- Spider-Man のウェブスイング、Umihara Kawase、Worms のニンジャロープ——「ロープで飛ぶ」は何十年も愛され続けた検証済みの快感
- 操作は1ボタン（ホールド/リリース）だけ。30秒で覚えられて、上達の天井は高い（リリース角の精度、巻き取りを使ったエネルギーポンプ）

## 設計判断

| 判断 | 理由 |
|---|---|
| ロープ自動巻き取り（REEL=55px/s） | 掴まっているだけで振りが加速する。プレイヤーが何もしなくても「次はもっと速い」が保証され、長く掴まる/早く離すのトレードオフが生まれる |
| リリース時に速度 +7% | 「離した瞬間が一番気持ちいい」を物理的に裏付ける。離すこと自体が常に小さな報酬 |
| 射程外ノードもウィンチで引き寄せ | 「掴めたのに落ちた」理不尽の排除。掴む判断は常に正解側に倒す |
| 次に掴むノードを常時照準表示 | ルールを画面で見せる。プレイヤーは「いつ掴むか/いつ離すか」だけに集中できる |
| 結晶はスイング弧の自然な経路上に配置 | 「うまいスイング＝結晶が集まる」が一致する。コンボ音階（C5から上昇）で上達が耳でわかる |
| 死は溶岩のみ、天井はバウンド | 死因を1つに絞る。上にミスしても殺さない（減速バウンドで返す） |
| 死亡直後スローモーション + 即リトライ | 失敗を見せてから0.5秒で再開可能。テンポを殺さない |

## 実装メモ

- 960x540 論理解像度、Canvas 2D、外部依存ゼロ、index.html + game.js の2ファイル
- 振り子は位置ベース拘束（3サブステップ）+ 半径方向速度の除去。安定していて発散しない
- 溶岩にスイング弧が刺さらないようロープ初期長を `LAVA - 30 - node.y` で制限
- WebAudio 直叩きで効果音合成（掴む=square落下音、離す=sine上昇音、結晶=音階、死=sawtooth低音）
- ベスト記録は localStorage
