# FABLE SWING v02 devlog

2026-06-11 / Fable 5

## 改修対象

Nao_u フィードバック（初プレイ）: 「操作がわからないと最初いきなりゲームオーバーになる」

v01 の問題: タイトルでクリックした瞬間に既に横へ飛び出していて落下が始まる。操作を理解する前に溶岩に落ちる。

## 改修内容（オンボーディング3点セット）

1. **ホバー待機 — 最初のホールドがゲーム開始**
   タイトルを閉じても落下しない。その場に浮いたまま「押しっぱなしで フックに掴まる」の表示と最初のノードへの照準線が出る。最初のホールドでフックに掴まった瞬間からゲームが動き出す。静止状態からの振り子は重力が自然に加速を作るので、最初のスイング自体が操作の教師になる。リトライ後も同じ（焦って連打しても即死しない）

2. **「離すと飛ぶ！」— 体験直後の1行ヒント**
   最初の掴まり（attaches===1）で振りの速度が 420 を超えた瞬間にだけ表示。読ませる説明ではなく、「今離したら飛べそう」と感じるタイミングに合わせて出す。一度でも離したら二度と出ない

3. **落下レスキュー表示**
   開始30秒間、未接続で落下中（vy>180 かつ画面下半分）になったら画面中央に大きく「ホールド！」を点滅。何をすべきか分からないまま死ぬ経路を塞ぐ

付随調整: 最初の4ノードは高さ 130-210 / 間隔 215-255 の素直な配置にして、序盤のスイングを安定させた（v01 は最初から y=90-310 の振れ幅があり、初手の難度ブレが大きかった）

## 変えなかったこと

- 物理パラメータ（G/REEL/RANGE/WINCH）は全て v01 のまま。今回の問題は「ルールが伝わる前に死ぬ」ことで、ルール自体の手応えは未検証のため
- 溶岩死・スコア・コンボの仕様も不変

## 自己評価

- 構文チェック済み。「最初のホールド = 開始」により、操作未理解のままのゲームオーバーは構造的に起きなくなった
- 残る検証事項: 振り心地そのもののチューニング（v01 から持ち越し）
