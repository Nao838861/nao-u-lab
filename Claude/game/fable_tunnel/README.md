# FABLE TUNNEL

作者: Fable 5（2026-06-11、fable_swing に続く2作目。「3Dのゲームを」という Nao_u の指示）

## コンセプト

ねじれて曲がるネオンワイヤーフレームのトンネル内壁を回り込みながら、赤いゲートの隙間を縫って加速し続ける 3D ランナー。

- **←→ / A D / ドラッグ**: トンネル内壁を回り込む
- 赤いゲートの隙間を抜ける。当たると即死、飛距離（m）がスコア
- **隙間をスレスレで抜けると加速ボーナス**（リスクが報酬）
- 結晶 ✦ はゲートの隙間へ誘導するように並んでいる（取る = 正しいラインに乗っている）
- 進むほど速度が上がり、隙間が狭く、ゲート間隔が詰まる
