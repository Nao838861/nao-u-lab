## 4. 経済コアの原理(v0.10で確立・信念システム全廃の結果)
1. **原価の床**: `cost(h,g)=家族の生計費(eat×staple)÷(日産YD×mult×scar)+原料費(px評価)`。原価割れでは売らない・売れ残り続くと休業
2. **使用価値の天井**: 買い手の上限=用途から導出(輸入パリティ・変換の採算等)。starving時のみ99
3. **記憶なしの試行**: 売値は毎回`cost×(1.05+rng×1.25)`で抽選。エージェントに価格の学習・信念を持たせない
- **per-agent信念は病巣として全廃済み**。「エージェントはバカでいい、市場がバランスを取る」の正しい実装は
  Gode-Sunder(制度=床と天井が本体)——これはNao_uと合意済みの設計哲学
- `px[g]` = 成約価格のEMA(α=0.1)。世界で一本(信念ではなく観測)
- **staple()の床1.0は「名目の錨」**: 信用枠-30・文化購買門purse>15等の名目定数群がこの物価水準前提。
  撤去実験は全名目閾値を壊して失敗(v0.17)。デフレ対策の遺物ではないので消さないこと
- 貨幣保存則: 毎日assert(`treasury+Σpurse-money0-(mainlandIn-mainlandOut)`)。金の湧き/蒸発は即クラッシュ=最強の検証装置

## 5. 主要システム(実装済み・v0.20.1時点)
- **地形拘束**(v0.11): 漁師=水際/木こり=森の際/採石=岩場。森はタイル実体(WOOD0=350/枯れると禿山/6%月次で再生)。localWood→希少性地代がcost()に乗る(クランプ≥0.5=転嫁は2倍まで、超えたら休業で現れる)
- **一次産業のmultキャップ2.0**: 島の扶養能力を文化Lvの人質にしない(漁/菜/麦/牧/菜種)
- **材木チェーン**(v0.15): 木こり(伐採集約・Y_LOG16)→丸太(重い財・運搬半分)→木工(丸太1.5/道具)・炭焼(丸太1.0/炭)。原価連鎖が自動伝播
- **文化ラダー**: 職業クラス別要求(LADDER)。Lv上げ=UP_DAYS45日充足。消費はCMULT=1.35^Lvで増える
- **労働市場**(v0.13-14): needy(purse<eat×0.8&&fd<4)→公共普請現場(道: 3人日/区画・賃金は金庫)→私雇用(purse>賃金×4の世帯へ。賃金=eat×staple×1.0 ※0.6から引き上げ「働けば家族が食える」)。雇主はboost1.4
- **移動**(v0.16で大修理): stepToMarket=経路場(ダイクストラ・道0.6/獣道0.85/草1/森1.4/水∞)。
  **移動速度は経路場と同じ地形尺度**(道の速度剰余は多段ホップで消化)——これが崩れると「探索が選ぶのに速くない道」へ全員迂回して村が貧しくなる(v0.16で3シード-15〜23万の実害を修理済み)。stepTo(帰宅等)は直線・道の上のみ加速・地形で減速しない(水際の入植者が速度0で餓死する)
- **餓死の島**(v0.17): 配給・公共調達・御蔵は制度ごと撤廃。生存線=採集の床(不足分の75%・金庫非関与)+日傭+転職。飢え60日連続で家族が死に、2人以下で離散(相続は近所3世帯へ・無相続は金庫へ)
- **商館**(v0.19・Nao_u設計): 全品目に買上げ目標→市で**2日売れ残った余剰だけ**を言い値で調達(必須の人が先に買う)→本国注文は商館在庫から自動出荷→予約分以外は蔵出し棚(px×1.2・輸入より安い)で市に還流。**麦備蓄はプレイヤーの仕事**(テストは人口×2を模写)
- **本国注文**(v0.18改名): 不定期(15日毎p=0.5・productionある品)に注文状(30-80荷・本国相場GP固定・90日期限)。達成で本国が価格×1.25を金庫へ=外貨の入口
- **建築リズム**(v0.20): 区画指定=支度金2,500デナリ(BUILD_COST250)・市場口銭FEE4%(金庫収入=取引量の鏡)。E16=漸進建築が一括に勝つことの常設監査
- **専有**(v0.20.1): 1タイル1建物・道/市場タイル建設不可・建物への道敷き不可・右クリックで建設キャンセル
- 財政の弧: 信用限度limit()・無利子42ヶ月→月利1.2%・本国支援3回(BAIL)・破産=最終通告オーバーレイ
- 分家(90日毎・飢えゲート)&破綻転職: **pickJob=直近12ヶ月ローリング年収(incMonths)の2乗重み抽選**(v0.16.1)。30日窓argmaxは年1回収入の麦を0に見せ・全員が最高職に殺到する測定バグだった
