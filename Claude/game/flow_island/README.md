# 流通の島 v0 (プレイアブルモック)

生産と消費のシミュレーション(projects/production_consumption_sim)の最初の遊べる盤。
経済エンジンは空間シミュ(design/spatial/engine.py)の較正値をJS移植したもので、
**同じengine.mjsがブラウザ(このUI)とNode(ヘッドレス検証)で動く**。

## 起動
```
cd game/flow_island
python3 -m http.server 8420
# → http://localhost:8420 を開く
```

## ヘッドレス検証(Mir用)
```
node smoke.mjs
```

## v0.9.5 市場機構の大修理——御蔵撤廃と価格発見の再設計(2026-07-16)
- **発端はNao_uの2つの指摘**: 「炭価格が1に張り付くのはなぜ」「御蔵の買取は不健全なので無くせるなら無くしたい」
- 炭1張り付きの因果: 御蔵の床値1.2が唯一の確実な買い手→3日落ちのたび信念×0.9→売れ残り値下げが信念を道連れ→上がる経路ゼロ
- **御蔵の自動買付を全廃**。ただし撤去だけでは村の通貨が枯渇する(輸入に金を吸われ全職無一文)ことが判明——御蔵は歪んだ形ながら通貨注入の主経路だった。代替: **配給の現物を市場の最安屋台から調達**(実需そのものが市場需要になる。床値・備蓄・信念干渉なし)
- **価格発見の再設計**: 生鮮/保存財の区別・探索的値付け(±15%)・高札成約のみ学習(選択バイアス対策)・最良成約の記憶(120日)・売れない季節は店を畳む——試行錯誤の失敗3件(完売+15%は魚で複利爆発/資力調査配給は飢餓8倍/全財クールダウンは市場窒息)も対話ログに記録
- **職人経済の成立条件を発見**: 産量×価格≧9人家族の食費(約18単位/日)。塩12/道具8/炭8荷/日に引き上げ+塩の輸出台+仕入れ信用買い(-30)で全職が貨幣経済に参加

## v0.10 経済コアの再設計——信念の廃止と3原理(2026-07-16)
- **Nao_uの設計転換指示**: パッチの積み重ねをやめ全体設計へ。「エージェントはバカでいい、市場がバランスを取る」の正しい実装=Gode-Sunder(バカでいいのは試行、制度の枠=原価の床と使用価値の天井が本体)
- **3原理**: ①原価の床 cost()=生計費÷日産+原料費(px評価)・売れ残り10日で休業・休耕 ②使用価値の天井(正典ルール2) ③記憶なしの試行(売値は毎回抽選)。per-agent信念と派生特例6種を全廃
- **消費のLv階段(×1.35)**: 高Lvほど大量消費(C3原型)——菜園34万デナリ死蔵の根本解
- **貿易**: 輸出=特産3品(保存食/漬物/油)のみ・輸入=懲罰価格。→村の通貨が枯渇するデフレ螺旋(px麦0.05)を踏み、**人夫(日雇い・公費賃金)**=労働市場と**主食指数の床1.0**で解決
- **資源の希少性地代**: 森/湾の枯渇度が原価に乗る(共有地の悲劇の内部化)。森の枯渇が価格で自制されるようになった
- 結果: 監査17/24・6シードで破産ゼロ・飢餓 年25-40相当・Lv中央4/最高5・全職黒字・助言追従プレイ+2.8万
- **残課題(次ブロック)**: ①E13配給11.8人(閾値9) ②E7麦/道具/野菜の滞留200-450荷 ③E11麦農家の納屋8.7k荷(休耕1.2収穫でも残る→売り速度) ④E10冬の魚価: 高Lv漁師の生産性が魚をほぼ無料化(湾が枯渇しない=希少性地代が効かない。BAY_R/RESEEDの再検討) ⑤E3借金123日 ⑥UIの信念参照残無し確認済みだがpx表示への置換(市場ポップアップ) ⑦BELIEF0はpx初期値として存続——名前をPX0に改名したい

## v0.11 地形拘束生産(2026-07-16)
- **Nao_u指示「地形拘束は必須。徹底的に検証を」**の実装。森=タイル実体(伐ると禿山が見える)・漁師=水際・木工炭焼=森の際・採石=岩場
- 3段フロンティアの地理: 雑木林(近・1年で禿げる)→森の腕(中距離・道が要る)→大森林(遠・取りきれない)。択伐(種木15%残し)が標準、乱獲時のみ皆伐→禿山(正典⑦)
- **検証で得た大きい知見**: 島の扶養能力を文化Lv(生産倍率)の人質にしてはならない。地形拘束で炭が細る→暖炉→Lv→倍率→食料の連鎖で島全体が縮む。一次産業は倍率Lv2キャップ+「倍率1で島が食える」基礎収量が正解だった
- こまごま: 遠い家は大きな貯蔵(まとめ買い)・菜園は休業則除外・自家用キープは家族人数比・伐採業は森パッチごとに分散
- 監査20/24・破産ゼロ・全職黒字。**残(次ブロック)**: ①ラダーLv2-3天井=冬の炭欠乏の季節鋸歯(秋の炭の冬支度・世帯の燃料備蓄行動が未実装) ②配給40人/日の貧困層 ③借金381日世帯 ④health.mjsの新地形移植 ⑤UI: 森の残量の可視化(タイルの色の濃淡)と禿山の説明
