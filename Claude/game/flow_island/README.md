# 流通の島 v0 (プレイアブルモック)

生産と消費のシミュレーション(projects/production_consumption_sim)の最初の遊べる盤。
経済エンジンは空間シミュ(design/spatial/engine.py)の較正値をJS移植したもので、
**同じengine.mjsがブラウザ(このUI)とNode(ヘッドレス検証)で動く**。

## 起動
```
cd game/flow_island
python3 -m http.server 8420
# → http://localhost:8420 を開く
```

## ヘッドレス検証(Mir用)
```
node smoke.mjs
```

## v0の範囲
- 入植(7職)・道敷き・海運投資・速度4段・財政の弧(配給/支援3回/無利子M42→月利/限度/破産→リプレイ)
- 文化ラダー(建物の上のLvピップ)・季節(色調)・湾/森の残量・市場価格・イベントログ
- 未実装: 対岸/石材/菜種/家普請/分家/行商(エンジンには実装済み・UI未接続のもの多数)

## v0.10 経済コアの再設計——信念の廃止と3原理(2026-07-16)
- **Nao_uの設計転換指示**: パッチの積み重ねをやめ全体設計へ。「エージェントはバカでいい、市場がバランスを取る」の正しい実装=Gode-Sunder(バカでいいのは試行、制度の枠=原価の床と使用価値の天井が本体)
- **3原理**: ①原価の床 cost()=生計費÷日産+原料費(px評価)・売れ残り10日で休業・休耕 ②使用価値の天井(正典ルール2) ③記憶なしの試行(売値は毎回抽選)。per-agent信念と派生特例6種を全廃
- **消費のLv階段(×1.35)**: 高Lvほど大量消費(C3原型)——菜園34万デナリ死蔵の根本解
- **貿易**: 輸出=特産3品(保存食/漬物/油)のみ・輸入=懲罰価格。→村の通貨が枯渇するデフレ螺旋(px麦0.05)を踏み、**人夫(日雇い・公費賃金)**=労働市場と**主食指数の床1.0**で解決
- **資源の希少性地代**: 森/湾の枯渇度が原価に乗る(共有地の悲劇の内部化)。森の枯渇が価格で自制されるようになった
- 結果: 監査17/24・6シードで破産ゼロ・飢餓 年25-40相当・Lv中央4/最高5・全職黒字・助言追従プレイ+2.8万

## v0.19 商館——プレイヤーの金の使い道(2026-07-16, Nao_u設計)
**「全部の物品に自分の在庫を設定できる必要がある。余剰だけを集める。麦の備蓄はプレイヤーの仕事。本国注文はそこから出す。大きな問題は、プレイヤーが金を使うところがないこと」**
- **商館**: 全品目に買上げ目標を設定→市で**2日売れ残った余剰だけ**を店の言い値で買上げ(必須の人が先に買う機会を保証・金庫から支払い=金の使い道)
- 本国注文は商館在庫から自動出荷(市場直買い台は廃止)。在庫の注文予約分以外は蔵出し棚(px×1.2・輸入棚より安い)として市に並ぶ=**麦備蓄が飢饉の保険として商売の形で機能**
- 撤廃した配給の還流機能が「プレイヤーの選択」として帰ってきた——構造の完成形: 自動給付(悪)→プレイヤーの調達(ゲーム)
