# アセット台帳 — ドット絵の完全チェックリスト

> **これは想像で数えた表ではなく、描画コード(index.html draw())の全drawSpr呼び出しから機械的に列挙した表。**
> ここに無い絵は現行ゲームに存在しない。逆に、この表の「必須」を全部描けば現行ゲームの絵は完成する。
> (初回ビジュアライズで不足分が多発した反省: レンダラから数える、を規約化)

## 使い方(絵師/エージェント)
1. PNGを `assets/<名前>.png` に置く(透過PNG)
2. `assets/manifest.json` の `sprites` 配列に `"<名前>"` を追加
3. リロード(キャッシュが強い時はハードリロード)——**その絵だけ差し替わり、無い絵はベクタ描画のまま**
- 部分納品OK。1枚from完成まで、どの順でも壊れない

## 描画規約
- 1タイル=幅40×高20pxの菱形。ズームはエンジン側(canvas変換)が処理するので**等倍で描く**
- アンカー: **画像の水平中心=足元菱形の中心 / 画像の下端=菱形の南端**(下端に接地感を持たせる)
- 建物の推奨サイズ: 幅40×高44px(足元20+立ち上がり24)。人: 8×14px。荷の山: 24×20px
- 冬差分(`_winter`)は任意。無ければ通常版が使われる(エンジンの色調変更は絵には掛からない)

## 台帳の保守規約
- **drawSpr呼び出しを追加/変更したら、必ず本台帳を同じcommitで更新する**(台帳と描画コードの乖離=不足分の再生産)
- R1等でスプライトの規格(サイズ・アンカー)を変える場合は本台帳の規約節を先に改訂してから実装する
