## 3 ミミクリ候補

### 候補 A: 熟練パイロットごっこ (CAVE 系継承)
**1 行**: 「敵 wave を読み切って、最小被弾で突破するパイロットになるごっこ」
- 操作 = 機体の流れる挙動 + 弾発射の連射感、敵 wave パターン認識が報酬
- 報酬の見え方 = wave 突破時の「読み切った」フィードバック (敵全滅 + 残機保持の演出)
- 失敗の見え方 = 弾に当たった瞬間「読み損なった」を再生 = 自己責任の感触
- カイヨワ軸 = ミミクリ (パイロット) + アゴン (スコア) + イリンクス (弾速で残るが薄れる)
- 関連リファレンス: 怒首領蜂 / DonPachi 系 = 「腕利きパイロットごっこ」(Log 5/20 13:13 引用)
- 強み = STG ジャンルの王道、5 秒で受け取れる、graze はサブ層 (擦った時 +α) に降ろせる
- 弱み = 「マニア軸ではないが普通すぎる」可能性、Downwell/Gungeon の現代 niche 突破例と整合させにくい

### 候補 B: 因果操作ごっこ (gozahand「STGは破壊」系)
**1 行**: 「自分の弾が世界を即座に変える因果の手触りを楽しむごっこ」
- 操作 = 撃つ → 敵が崩れる即時フィードバック、画面が常に変化する感触
- 報酬の見え方 = 撃ち抜いた瞬間の演出 (敵の崩落・破壊 SE・画面変化) が連鎖
- 失敗の見え方 = 弾を撃てなくなる (被弾 → クールダウン) = 因果操作の停止が罰
- カイヨワ軸 = ミミクリ (世界変容者) + アゴン (スコア) + アレア (敵生成のランダム性)
- 関連リファレンス: gozahand 2026-05-19 22:46 (Nao_u 共有)「STGの快感は破壊」、Downwell の連鎖破壊感
- 強み = 「自分の操作が世界を変えた因果の手触り」(Log 5/19 既反応) = 普通プレイヤーが 5 秒で受け取れる、ミミクリ軸が明確
- 弱み = 「破壊」を全面に出すと敵配置の読み・避けが薄まる可能性、graze 軸とは直交 (graze をサブ層に置きにくい)

### 候補 C: 異変解決ごっこ (東方系継承、ストーリー軸)
**1 行**: 「異変が起きた世界に飛び込んで、原因 (=ボス) を倒して解決するごっこ」
- 操作 = 機体操作 + 弾幕回避 + ボスへの撃ち込み = ストーリー進行の手段
- 報酬の見え方 = ボス撃破 → ステージ遷移、世界が「解決した」状態に進む演出
- 失敗の見え方 = 撃墜 = 「異変を解決できなかった」物語的敗北
- カイヨワ軸 = ミミクリ (解決者) + アゴン (スコア) + アレア (弾幕パターン)
- 関連リファレンス: 東方 Project = 「弾幕を踊る巫女が異変を解決するごっこ」(Log 5/20 13:13 引用)
- 強み = ミミクリ軸が物語で立つ、graze はサブ層 (擦ると爽快) として残せる
- 弱み = ストーリー設定が必要 = brainstorm から実装までの距離が遠い、Log 環境では絵素材も難航

## 第 3 候補の代替案

candidates A/B/C のうち、graze_log 後継として最も「現状の小さなプロトタイプから 1 mm で動く」のは **候補 B (因果操作ごっこ)**。理由:
- 既存の small/medium/large 敵挙動を「破壊フィードバック強化」軸でリビルドできる (差分が小さい)
- gozahand ツイート (Nao_u 5/19 22:46 共有) と Log 5/19 既反応「自分の操作が世界を変えた因果の手触り」が既に書かれている = 文脈の温度が残っている
- graze をサブ層に降ろすのではなく**直交させる** (graze =「擦ると一瞬画面が止まる、因果操作の集中時間」) = graze 軸を保存しつつ core を別軸にできる可能性

ただしこの**結論はまだ仮置き**。N=1 (本ファイル) では決め打ちしない。次サイクル以降で:
1. 候補 B を 1 段降ろし (操作 / 報酬 / 失敗の見え方 + 30 秒プレイの想像実験)
2. 候補 A/C も 1 段降ろし
3. 3 候補を並列比較してから core を選ぶ
