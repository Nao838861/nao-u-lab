## 1. 観点5項（v02/predicted_play.md と同型、v03 候補A 実装後想定）

### テンポ

- v02 と同じ基本テンポ（1プレイ 60秒〜数分、Nao_u 想定）。基本ループは変えない
- **追加要素**: SPACE が文脈で `B`(BOMB) / `D`(active 防御) に切り替わる → SPACE 押下前に「今どっちが出るか」を確認する 0.3〜0.6 秒の認知負荷が乗る
- **テンポへの影響**: Lv3 到達後、v02 では「単調」化していた区間に **active 防御の発火タイミング選択**が新規発生 → ゆるい意思決定が常時 1 個 + α 入る = メリハリの 1 段階増加
- **裏目**: 認知負荷 0.3〜0.6 秒は弾密度ピーク時に **判断遅延 → 被弾**を生み得る。HUD 1文字表示で軽減される想定だが、Nao_u 1プレイ目では混乱の可能性 30〜40%

### 初動（プレイ開始 5秒以内）

- v02 と同じ：intro_med 遅延スポーン（1.2s）で最初の near-miss → graze ポップアップ +10
- **追加**: grazeStreak HUD 表示が 0 → 1 → ... と増える視覚フィードバック開始
- **問題**: 初手 5 秒で grazeStreak 5 到達は構造的に困難（intro_med 1〜2発しか発射しない）→ active 防御の存在を初手で**見せない**設計になっている。これが「能力解放の遅さ」として刺さるか「発見の喜び」として刺さるかは Nao_u 体感依存
- **予測**: 「最初の 5 秒は v02 と同じ感覚」(Nao_u コメント無しで通過 60%)

### 停滞 — **v03 の核命題**

v02 の停滞ピークは「30秒目で 3段階パワーアップ完了 → graze を取りに行くインセンティブ消失」だった。v03 候補A はこの直接打開を狙う。

- **0〜15秒**: graze 累積 → grazeStreak 5 到達 → 1回目 active 防御発火（gauge は未MAX想定）。**「avoid から短時間 attack に切替えられた」触感**が初発。これは v02 にはなかった
- **15〜30秒**: gauge も並行進行、Lv2 到達。SPACE 押下時の HUD 表示が `D` の間は active 防御、gauge MAX で `B` に変わったら BOMB 優先
- **30〜60秒**: Lv3 到達後 = v02 で停滞ピークだった区間。**v03 仮説**: 「graze で gauge 復活 → BOMB → graze で grazeStreak 再蓄積 → active 防御 → ...」のループが発生して、graze する理由が継続的に再生成される
- **60秒以降**: active 防御の発火タイミングを「次の弾密度ピークに合わせる」strategy 軸が登場

**仮説の弱さ**: Lv3 後の動機継続が成立するかは「grazeStreak 5 到達速度 vs SPACE 発火クールダウン」の tuning 一発勝負になる。初手の 5/8/12 のような閾値設定が外れると、Lv3 後の発火頻度が低すぎて v02 と同じ単調化を起こす。**確信度 55%**

### 解釈負荷

- v02 から増える要素: HUD に **grazeStreak 表示** + **SPACE 文脈表示 (B/D)** の 2 個
- v02 既存: gauge bar / score / Lv 表示
- **解釈負荷の総量**: HUD 5要素 = 認知容量境界に近づく（Miller 7±2 の下限近辺）
- **問題**: SPACE 文脈表示は 1 文字でも、状況が緊迫した時に「今どっち？」を確認する余裕が無くなる → 押し間違い事故が出る可能性
- **予測**: Nao_u 1〜2 プレイ目で「`D` のつもりで押したら `B` が出た」事故 1〜2 回（40%）

### 終局

- **v02 と同じ問題が残る**: 60s 過ぎても自然な終局装置なし。time limit / boss 区切り / 難度上昇 wave は v03 では追加しない（戦略レイヤーは brainstorm.md §1 守段階制約で除外）
- **ただし**: v03 候補A で Lv3 後の動機が継続する仮説が当たれば、「面倒になってわざと死ぬ」までの時間が v02 比で延びる（v02 は ~60-120秒で自殺、v03 は ~180-300秒に延びる仮説、確信度 50%）
- **延びるが終わらない**: 結局自然終局装置は無いので、Nao_u プレイは「面倒になって自殺」で終局する**確率はまだ 60% 残る**。ただし「面白くなった上で自殺」と「面白くなくて自殺」は質が違う

## 2. 30〜60秒予測（時間帯別、A/B/C 確率付き）

### 0〜5秒
- **発生**: 「お、graze ポップアップは v02 と同じか」（Nao_u 想定、コメント無しで通過）
- **問題**: なし。grazeStreak HUD は導入されているが値0なので意識されない
- **予測 A（80%）**: v02 と同じ初動感、コメントなしで通過
- **予測 B（20%）**: HUD に何か新要素があることに気づく（grazeStreak 0 表示）

### 5〜30秒
- **発生**: grazeStreak 5 到達 → 1回目 active 防御発火（10〜15秒地点想定）。HUD で SPACE = D 表示 → SPACE 押下 → 1秒の自機無敵 + 周辺弾消去半径発動
- **予測 A（55%）**: 「graze 続けてたら能力が出た」発見の喜び。「面白い、graze する理由が継続する」想定の最良ケース
- **予測 B（25%）**: 「あれ、SPACE 押したら BOMB じゃないやつが出た」混乱。HUD 表示を見落としていて、何が起きたかすぐには分からない
- **予測 C（15%）**: 5 閾値が低すぎて、graze 5回到達が易しく、active 防御が「乱発できる安いスキル」として処理される → 価値感低下
- **予測 D（5%）**: 5 閾値が高すぎて、5〜30秒区間で active 防御が**一度も発火しない**。「v02 と何が違うのか」評価

### 30〜60秒（v02 で停滞ピークだった区間）
- **発生**: Lv3 到達後、gauge MAX → SPACE = B（BOMB）。BOMB 撃つと gauge 0 → SPACE = D に戻る。同時に grazeStreak も新規蓄積中
- **予測 A（45%）**: 「graze で gauge 復活 → BOMB → graze で active 防御 → graze で BOMB ...」のループに入る = **v02 停滞問題の直接打開、v03 の核仮説が当たる**
- **予測 B（30%）**: ループは発生するが「ボタン同じで意味が変わる」が認知負荷として疲れる → 30秒 ~ 1分で「単調ではないが疲れる」評価
- **予測 C（20%）**: SPACE 文脈切替が事故起因の死亡を 1〜2 回起こす → 「混乱する」評価。v02 の単調と v03 の混乱、どっちがマシかは Nao_u 体感依存
- **予測 D（5%）**: 候補A の機構が tuning ハマって「神プレイ感」を出す = v03 が brick_log 同等以上に届く想定上限

### 60秒以降
- **予測 A（40%）**: 自然終局装置なしの問題が残り、最終的に「面倒になって自殺」で終わるが、**v02 と違って「面白かった上で自殺」**になる。終局時のコメントが「もっと続きの仕組みが欲しい」になる
- **予測 B（30%）**: A の延長線上で、Lv4 以降の演出が無いことが目立つ → 「Lv 上限が低い」フィードバック（戦略レイヤー D が次サイクル候補に上がる）
- **予測 C（20%）**: ループが疲れて、v02 同様「面倒で自殺」（v02 とほぼ同じ評価で終わる = 候補A 失敗）
- **予測 D（10%）**: 「死ねない」感じが v02 より強くなる。active 防御が強すぎて死亡リスクが下がりすぎる場合 → 「ぬるい」評価

## 3. v02 で的中した予測 vs v03 で何が違うか — 差分明示

v02/predicted_play.md §2 で 6/6 項目が遡及で的中していた。v03 候補A 実装後、**何が変わって何が変わらないか**を明示する。

| 観点 | v02 で的中した予測 | v03 候補A 実装後の予測 | 差分の根拠 |
|---|---|---|---|
| 0-5秒 | オンボーディング刺さる | **同じ**（変わらない） | 初動構造は触っていない |
| 5-30秒 | 3段階まで取りに行く | **同じ + active 防御 1〜2回発火**（追加体験） | grazeStreak 5 閾値が機能すれば 10〜15秒地点で初発 |
| 30-60秒 | Lv3 後ループ単調化、A or B | **ループ発生で単調打開（45%）or 混乱で疲労（30%）or 事故死（20%）** | 候補A の核命題、tuning 一発勝負 |
| 終局 | 自殺で終局 (B) | **自殺で終局するが「面白かった上で」(40%)** | 自然終局装置は v03 でも未追加（戦略レイヤー除外） |
| 報酬非対称 | 取りに行く価値が消える | **active 防御という新報酬が継続的に発生（55%）** | grazeStreak 経路追加で「graze する理由」が二経路化 |
| ゲーム成立 | 「ぎりぎりゲームにはなっている」 | **「面白くもなり得る + 面倒で自殺」が共存** | v02 の素地は崩していない |

**核差分**: v02 は graze → gauge → BOMB の二段だけ。v03 候補A は graze → grazeStreak → active 防御 を**並行経路**として足す。30秒以降に「graze する理由」が再生成される構造になっているか、Nao_u 実プレイで検証する対象 = 上の予測 30〜60秒区間の予測 A/B/C/D 確率分布。

## 4. 着手前にわかる懸念 3 点（v03 固有 / brainstorm.md §2 から導出）

### 懸念1: SPACE 文脈切替の混乱

- **設計根拠**: SPACE が gauge 状態で意味を変える（gauge MAX なら B、それ以外 D）
- **影響**: Nao_u 1〜2 プレイ目で「`D` のつもりで押したら `B` が出た」事故が出る確率 40%
- **対策候補**（v03 着手時に検討）: HUD 1文字（B/D）表示を**自機のすぐ近く**に置く / SPACE 押下前に短い予告音を鳴らす / 別ボタン（M でなく Z など）に分離する選択肢を残す
- **本懸念は v03 出荷前に潰せるか**: HUD 配置の選択は実装時にできる。完全には潰せないが軽減できる

### 懸念2: grazeStreak 閾値 5 の妥当性が tuning 一発勝負

- **設計根拠**: brainstorm.md §6 で「閾値は Lv 非依存で 5 から開始」、brainstorm.md §3 §限界で「Lv3 到達前に 5 到達してしまうと達人プレイの強度が早く落ちる」可能性に言及
- **影響**: 5 が易しすぎ/難しすぎだと、active 防御が乱発される or 一度も発火しない、どちらでも候補A の核仮説が崩れる
- **対策候補**: 実装後 1〜2 サイクルで Nao_u 体感を聞いて閾値を動かす。Lv 連動（Lv1=5 / Lv2=8 / Lv3=12）も予備案として残す
- **本懸念は v03 出荷前に潰せるか**: 着手前は潰せない。Nao_u プレイで初めて分かる種類の懸念

### 懸念3: 自然終局装置の不在は v02 から継続

- **設計根拠**: 戦略レイヤー（time-attack / boss / Lv 上限拡張）は brainstorm.md §1 守段階制約で除外
- **影響**: Nao_u プレイは「面倒になって自殺」で終わる確率 60% 残る（v02 と同じ）。ただし「面白かった上で自殺」と「面白くなくて自殺」は質が違うので、コメント文言で差を見る
- **対策候補**: v03 では追加しない。v03 候補A の actual play 評価を受けてから初めて、戦略レイヤー着手の可否を v04 以降で議論する（brainstorm.md §4 確信宣言と整合）
- **本懸念は v03 出荷前に潰せるか**: 構造的に潰さないと決めている。v03 の評価が「面白かった上で自殺」になるかが、戦略レイヤー着手の判定材料になる
