### 例2: KAKUBOMB (cgrad 2025) のニアミス — graze を救済装置として降格した成功例

KAKUBOMB (cgrad / 個人開発 2025) はニアミスを **ボム発動条件** として配置 (graze で ボムゲージ 蓄積 → ボム発動で全画面攻撃 + 無敵)。graze は **救済 → 攻撃** という構造で「擦る → 助かる」連鎖が機能。コア体験は「弾を撃つ・避ける」で、graze は **守りから攻めへの転換装置** として副号 → 正への変換役。

→ Log 判定: KAKUBOMB 型は Ash β の score multiplier より Mir 補足④に近い (graze がコア快感の上に乗る変換装置)。**Ash β の改良版**として「score multiplier の代わりに『graze で BOMB を引き出せる』降格」が成立する余地あり。これは α の派生案 α' として brainstorm に追加可能 (Ash α の「BOMB は弾幕密度ピーク救済」を「graze 累積で発動権を得る」に置換)。

### 例3: mollifier (5/10 観察) の「弾が見えるようになる」 — 知覚軸での graze 降格

mollifier (Log 5/10 shared-reads 観察) は graze で **画面の弾速度が低下** + 弾の色が変化 → 「擦ったら次の弾がよく見える」設計。score 報酬は希薄、**知覚補助** として graze が降格。コア体験は「見えるようになった弾を避ける」で、graze は **知覚層の補助装置** として副号 → 中立への変換。

→ Log 判定: mollifier 型は Ash α/γ の「副産物」より一段強い「**知覚補助**」役に graze を降格させる路線。**α の補完案 α'' として「graze 発生時に該当弾の軌道予測線が薄く表示される」が成立**。実装コストは小 (既存 ring 描画の流用)。

- **「graze を score に乗せない」だけでは弱い**。BUZZ 反例より、graze がコア快感の **何かに化ける** 構造があると Mir 路線の符号反転が強化される

### Q1: このジャンルは何を楽しむゲームか？

**コア快感の言語化**: 弾幕シューティングは「向こうから来る圧力（弾幕パターン）に対し、自機の僅かな身幅で隙間を見つけて生き延びる」という、**受動的緊張 → 能動的判断 → 生存解決** の循環を楽しむゲーム。graze (近接通過) は「生存解決の精度を測る微視センサ」として副産物的に存在するのが歴史的本道（Touhou以前の Cave shmups は graze 概念すらなかった）。「graze を狙うゲーム」へ転換した瞬間に、コア = 「来る圧力に対する生存解決」から「攻めて取りに行くスコアアタック」へジャンルが変質する（Psyvariar / 怒首領蜂 系）。

**graze_log v01-v03 の構造的誤り**: 「graze を狙うゲーム」側に振り切り、生存解決のコア感を vestigial 化させた。Nao_u 5/11 05:51 ④「graze はストレスを溜める行為」はこの構造の直接帰結 — 弾を擦りに行く = 受動緊張の符号を能動行為で書き換えるが、能動側に十分な報酬装置（Touhou の score / Psyvariar の Lv up）がないと「ストレス源化」のみ残る。

### Q2: 現状の良い点と問題点

#### 良い点
- **G1**: SPACE単一操作 + 移動 + ショット の最小構成（v01〜v03 で 3 入力に閉じてきた）。操作量を増やしていない点は守の通過点として価値あり
- **G2**: graze ring（v01-v02）は視覚言語として成立していた。何をしたか / 報酬発生をパッシブに伝える（v03 で消したのが Nao_u 指摘①の主因）
- **G3**: BOMB の「全画面攻撃 + 短時間無敵」は STG 文法として認知コストゼロ（守の通過、Ikaruga/Touhou/Cave 共通言語）
- **G4**: gauge / Lv up 視覚（v01-v02 のメーター）は進行装置として成立。「自分が強くなっている感」が線形で伝わる
- **G5**: 死亡時のリスタート即時性（v01-v03 共通、リトライ摩擦ゼロ）
- **G6**: 視認性（弾と自機が高コントラスト、ring 表示がオフでも被弾は理解できる）
- **G7**: 自機弾 → 敵 → 弾幕 → graze → BOMB のループ閉鎖（破綻していない）
- **G8**: ジャンル認知（STG）が即伝わる外見 — 自機・敵・弾の3要素配置が伝統的

#### 問題点
- **P1**: コア体験そのものが「擦る」（負符号行為）に集中している → 生存解決の正符号体験を奪っている（Nao_u 指摘④の構造根、Mir 補足直系）
- **P2**: graze 視覚が薄すぎて初見プレイヤーには何が起きているか伝わらない（v03 で alpha 0.10 まで落として実質不可視、Nao_u 指摘①）

- **P4**: BOMB 発動時のパワーダウン経路（v03 MAX→gauge巻き戻し）が経済反転 → 二度と撃たない（Nao_u 指摘③）
- **P5**: コア快感の単独成立性なし — graze を消すと「ただ避けて撃つだけのありふれた縦シュー」になり、独自要素ゼロで魅力が空白化（v03 から graze 廃止前提だと M-32 題材練り直し相当）
- **P6**: 自然終局装置なし — 「死ななければ無限に続く」状態でクリア概念が薄い（v01-v03 共通、wave/stage 概念欠落）

### Q3: 問題点を解決する手法（各問題に≥3手法）

#### P1（擦る負符号がコアを侵食） への手法
- **M1-1**: 「弾を撃つ・避ける」をコアに据え、graze を完全削除（守破離の守、Cave 系の原典回帰）
- **M1-2**: graze を「副産物表示のみ」に降格 — multiplier や進行に絡めない（Ash α 路線）
- **M1-3**: graze を「報酬副号 → 知覚補助」に変換（mollifier 型 = 擦った弾が薄く軌道予測線を引く）
- **M1-4**: graze を「報酬副号 → 救済発動条件」に変換（KAKUBOMB 型 = graze 累積で BOMB を引き出せる）
- **M1-5**: graze を「報酬副号 → ダメージ反映」に変換（Royal Guard 型 = 危険近接が後で攻撃に化ける）

#### P2（graze 視覚薄すぎ） への手法
- **M2-1**: ring alpha を v01 水準（0.4〜0.6）に戻す（最低コスト直接対策）
- **M2-2**: graze 発生時に短いフラッシュ + SE で能動的フィードバック追加
- **M2-3**: 自機周辺に常時 graze 圏マーカー（half-transparent 円）を表示し、判定半径を可視化（Touhou の自機判定ドット表示と同型）
- **M2-4**: graze した弾だけ色を変えて 0.5 秒残す（過去履歴の可視化）

#### P3（gauge→Lv が graze 依存） への手法

- **M3-2**: 進行装置を「時間生存秒数」に置換（生存している事実が進行になる）
- **M3-3**: 進行装置を「敵撃破数」に置換（攻撃側の正符号で進行する）
- **M3-4**: 進行装置を「BOMB 発動回数」に置換（守りの精緻さ = 進行）

#### P4（BOMB パワーダウン） への手法

- **M4-5**: BOMB を「pickup 拾得制」に置換（Gradius 型、Lv 進行と独立）

#### P5（コア独立性なし） への手法
