**起票**: 2026-05-28 C255 Phase 4 (Log)。Nao_u/Mir/Ash 実機判定取得後に「予測 v.s. 実測」を比較するための事前固定。起点は [v002/self_judgment.md](../v002/self_judgment.md) 採点 (v003 では self_judgment 未起票)、改修内容は [design_log.md](design_log.md) §2.A。

1. **Q-D 予測軌道ゴースト**: 4.5/5 → **4.5/5 (据置予測)**。案 A の黄 1 frame フラッシュは「消滅した弾の現在座標」描画で、未来位置/×印/タイトルゴーストの追加なし。内側→外側流出 1 原則違反箇所ゼロ維持。
2. **Q-成功FB 状態3 (危機回避体感)**: 3/5 → **3.5/5 (+0.5 予測)**。第 4 種視覚チャネル (1 frame 黄フラッシュ) が状態 2 (シアン爆発)/状態 3 (危機回避テキスト) と独立に「castLock 成功の物理結果」を即時提示。実機で「踏み抜けた」体感が得られれば +1.0 まで上振れ余地、サブリミナル過ぎて知覚されなければ据置に振れる両方向リスク。
3. **Q-経済反転リスク (新軸)**: 案 A は score/gauge 非接続のため構造的に bound。`verify.js --bullet-density-zero` で全方針 bulletsErased=0 + echo-spam と camper が同フレーム同要因死亡を物理確認済 = 自発 (Echo) 単独で得失差ゼロ。**低リスク維持予測**、graze_log v01 同型事故予兆なし。
4. **30 秒で死ぬ要素**: あり継続予測。`verify.js` default mode で v003 既存 4 悪手方針 (camper 5.32s / lane-holder 4.62s / blind-sweeper 6.30s / nospecial 8.15s) が wave 1 内 bullet 死亡維持、案 A 追加が悪手通過の穴を作っていないことを物理確認済。
5. **美しいプレイ**: 「敵弾の動きを見て 1 秒先到達地点を予測し castLock で弾幕を踏み抜ける」コンセプトが「**踏み抜けた弾が消える** = 踏み抜きの物理結果が画面に現れる」で強化方向。Q-D シート 5 項目通過確認済 ([design_log.md](design_log.md) §2.A.3)、自発コア化逸脱なし。
