# v004 → v005 (連続 erase 視覚段階化) Log 自己予測

**起票**: 2026-05-28 C256 Phase 4 (Log)。Nao_u/Mir/Ash 実機判定取得後に「予測 v.s. 実測」を比較するための事前固定。起点は [v004/log_self_prediction.md](../v004/log_self_prediction.md) (v004 予測)、改修内容は [design_log.md](design_log.md) §1。

## v004 自己予測 5 項目に対する v005 上振れ/据置/下振れ予測

1. **Q-D 予測軌道ゴースト**: v004 4.5/5 → **v005 4.5/5 (据置予測)**。連続 erase の段階化追加は描画 size/color のみで未来位置/×印/タイトルゴースト追加なし。内側→外側流出 1 原則違反箇所ゼロ維持。N=1 の描画が v004 と完全同一なため、低密度プレイ時の見た目は変化なし。

2. **Q-成功FB 状態3 (危機回避体感)**: v004 3.5/5 → **v005 4/5 (+0.5 予測、上振れ余地あり)**。第 4 種視覚チャネルが 3 段階化されることで「弾幕の中を踏み抜けた強度」の物理表現が増えた。N=4+ の橙化が知覚されれば「**確かに弾幕を踏み抜けた**」の体感が v004 比で明確化される予測。ただし N=4+ 発生頻度は低い可能性 (verify.js では弾源 0% で 0 発火、実プレイでも castLock 1 秒内に 4 発以上重ねるのは中盤以降の高密度域に限られる) = 下振れリスクは「橙が滅多に出ない = 段階化に気づかない」方向。

3. **Q-経済反転リスク**: 案 A は依然 score/gauge 非接続のため構造的 bound 継続予測。**verify.js `--bullet-density-zero` で全方針 bulletsErased=0 維持** = Echo 単独で得失差ゼロ = 段階化追加で報酬経路が拡張されていないことを物理確認。低リスク維持予測、graze_log v01 同型事故予兆なし。

4. **30 秒で死ぬ要素**: v004 と完全同型、あり継続予測。`verify.js` default mode で 4 悪手方針が wave 1 内 bullet 死亡維持を継承。段階化追加は描画のみで game ロジック不変 = regression 0% (= 死ねる条件が変わらない)。

5. **美しいプレイ**: 「敵弾の動きを見て 1 秒先到達地点を予測し castLock で弾幕を踏み抜ける」コンセプトが「**踏み抜いた弾数の強度が画面に現れる**」で更に強化方向予測。Q-D シート 5 項目通過確認済 ([design_log.md](design_log.md) §2)、自発コア化逸脱なし。**段階化が「Echo を打ちたくなる動機」になっていないかが最重要監視点** (実機で「橙を出したくて Echo 連打したくなる」感覚が生まれたら自発コア化兆候 = v005 巻き戻し判定発火)。

## 検証視点 (Nao_u/Mir/Ash 実機判定時の観察軸)

- **段階差の知覚可能性**: N=1 (黄 12px) と N=2-3 (黄 16px) の半径差 4px が短時間 1 frame で識別できるか。識別できなければ次サイクルで 12/18/24 への半径差拡張を検討
- **N=4+ 橙の発生頻度**: 中盤 (phase 1 = 20-50s, A+D ローテ) 以降で 4+ 連続 erase が castLock 1 秒内に物理的に発生するか。発生しないなら段階化 3 段の最上層が形骸化
- **自発コア化兆候の有無**: 段階化された flash を見て「**もう一回派手なやつを出したい**」衝動が起きるか。起きれば v005 巻き戻し判定発火点 (Q-D 経済反転リスク再評価)
- **N=1 体感の v004 比据置確認**: 低密度プレイで N=1 の見た目が v004 と同一に感じられるか (= v004 実機判定の継承可能性確認)
