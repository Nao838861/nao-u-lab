# log_autonomous_game v007 — brainstorm.md (アビリティ候補)

**起票**: 2026-06-11 C323 Phase 4 (Log)
**ジャンル**: アクションアドベンチャー探索 (mini-metroidvania) — [genre_selection.md](genre_selection.md) で確定
**親**: [design_log.md](design_log.md) §4 Q-B (特殊システム 3 状態ゲート) で候補列挙が必要
**範囲**: v007 で採用する **1 アビリティ** の候補ブレスト。中心入力 Z 1 ボタン、副入力 移動 (矢印 / WASD) の枠で 7 案を出す。
**MPS スコア**: M (Mechanics 機構の独自性) × P (Players プレイヤーの感情/快感) × S (Surprise 意外性) を各 5 段階で評価、合計 max 15。

---

## 0. ブレスト前提

- 採用案は v003 Echo-Path 系統 (時間軸 1 秒先予測) と **直交した空間軸の機構** を持つこと
- アビリティ取得前は使えない / 取得後は永続使用可、の 2 状態のみ (= 段階解放なし)
- 30 分着地スコープで 1 アビリティ 1 部屋着地、複数アビリティ / 複数部屋は v008+
- Q-D シート (報酬経路 = 空間到達のみ、自発リスク機構なし) を必ず通過

## 1. アビリティ候補 7 案

### 案 1: ダッシュ (短距離高速移動 + 通過中無敵)

**機構**:
- Z 押下で前方 1 マス分 (= 200px) を 0.2 秒で移動
- 移動中は壁判定 ON だが、「薄壁」「床穴」を貫通通過可
- クールダウン 1.5 秒、状態 1 → 状態 2 → 状態 3 がクールダウン経過 + 周囲条件で切替

**Mimicry**: 「ダッシュで隙間を抜ける探検家」感、Hollow Knight / Animal Well / Celeste lineage

**Echo-Path 距離**: 高 (時間軸 → 空間軸の直交、ダッシュ自体は瞬間的なので時間軸要素は薄い)

**実装スコープ**: 軽 (移動 + 衝突判定の小変形、200 行以内)

**Q-D シート通過**: ◯ (報酬 = 空間到達のみ、graze 同型なし)

**MPS**:
- M = 4 (ダッシュ自体は既存メカニクスだが、薄壁貫通 + 床穴貫通の 2 種類の通過対象を持つ設計は独自)
- P = 4 (探検家感の確立度高、瞬間移動の快感)
- S = 3 (1 画面で「あの隙間はダッシュで通れる」を立てる素材は中程度、初手で薄壁ハイライトすれば S=4 に伸びる)
- **合計 = 11**

### 案 2: フック (遠距離リーチ + 引き寄せ)

**機構**:
- Z 押下で前方 3 マス分 (= 600px) にフック射出
- フックがフックポイント (壁の特定箇所) に当たると、プレイヤーをフックポイント位置に引き寄せ
- 床穴を越えて引き寄せ可、通常壁は越えられない、薄壁はフックが貫通する設計

**Mimicry**: 「フックで引き寄せる探検家」感、Hollow Knight (Mantis Claw)・Hollow Knight (Crystal Dash) lineage、Just Cause 拡張

**Echo-Path 距離**: 高 (時間軸要素薄い、空間軸支配)

**実装スコープ**: 中 (フック射出 + 軌道計算 + フックポイント判定で 300 行程度)

**Q-D シート通過**: ◯ (報酬 = 空間到達のみ、graze 同型なし)

**MPS**:
- M = 5 (フックポイント特定の機構は v007 独自設計、Q-B 状態 3 (= フックポイント近接判定) が空間軸で複雑化、設計の独自性高)
- P = 5 (引き寄せ快感、距離感の支配体感)
- S = 4 (1 画面で「あのフックポイントに届かせる」を立てる素材高、視覚的に明確な目印が出せる)
- **合計 = 14**

### 案 3: 透視 (壁の向こうを見る + 隠し通路顕在化)

**機構**:
- Z 押下中だけ画面全体を「X 線モード」表示 (色反転 + 隠し通路 / 隠しオーブが見える)
- Z 離すと通常表示に戻る
- 透視中は移動可能、ただしダメージは通常通り受ける
- クールダウンなし (押している間だけ発動)

**Mimicry**: 「壁の向こうを見る探検家」感、Animal Well (Disc) / Tunic (Holy Cross) lineage、視覚拡張系

**Echo-Path 距離**: 高 (時間軸要素なし、空間軸の認識拡張)

**実装スコープ**: 中 (色反転シェーダ + 隠しオブジェクト表示切替で 250 行程度)

**Q-D シート通過**: ◯ (報酬 = 認識拡張のみ、graze 同型なし)

**MPS**:
- M = 5 (透視 = 空間認識軸の機構、ダッシュ / フックと違い「移動しない」アビリティで独自性最大)
- P = 5 (見えなかったものが見える快感、探検家感の核そのもの)
- S = 5 (1 画面で「壁の向こうに何かある」を立てる素材最高、Q-導入ゲートとの相性最高)
- **合計 = 15** (max)

### 案 4: 二段ジャンプ (空中で 1 回追加ジャンプ)

**機構**:
- Z 押下で空中ジャンプ (地上ジャンプ 1 + 空中ジャンプ 1 = 計 2 段)
- 着地でリセット、空中で 1 回のみ
- 高い段差 / 床穴を越える用途

**Mimicry**: 「高所に登る探検家」感、Hollow Knight (Monarch Wings)・Celeste lineage

**Echo-Path 距離**: 中 (時間軸要素薄いが、ジャンプ判定は重力 + 時間軸計算で間接的に時間軸要素を持つ)

**実装スコープ**: 中 (重力 + ジャンプ判定 + 空中フラグで 300 行程度)

**Q-D シート通過**: ◯ (報酬 = 空間到達のみ、graze 同型なし)

**MPS**:
- M = 3 (二段ジャンプは既存メカニクスとして最も一般的、独自性低)
- P = 4 (高所到達快感、ただし二段ジャンプは「またか」と既視感)
- S = 2 (1 画面で「あの高い所に行ける」は立てるが、既視感で意外性低)
- **合計 = 9**

### 案 5: 時間停止 (周囲ハザード / オブジェクトを 1 秒停止)

**機構**:
- Z 押下で周囲のハザード (動くハザードがある場合) を 1 秒停止、クールダウン 3 秒
- 本 v007 は静的ハザードのみ設計のため、効果対象が薄い → **本ゲームでは動くハザードを v007 で追加するか、案 5 は採用しない判断が必要**

**Mimicry**: 「時間を操る探検家」感、Quantum Conundrum / Braid lineage

**Echo-Path 距離**: 低 (時間軸操作は v001 Echo-Path 系統の延長になりやすい、ミミクリ核の直交性が崩れる)

**実装スコープ**: 重 (動くハザード追加が前提 = design_log §5 Q-C「動くハザード禁止」を緩和する必要、scope creep リスク)

**Q-D シート通過**: △ (報酬 = ハザード停止による空間到達拡張のみ、graze 同型は出ないが、Echo-Path 系統の時間軸延長で「v001 のごっこ遊び」に倒れるリスク)

**MPS**:
- M = 4 (時間停止 = 既存メカだが、本ゲーム文脈では動くハザード追加が前提で複雑)
- P = 4 (時間支配快感だが、ミミクリ「探検家」感とずれる)
- S = 3 (1 画面で？立ては可だが、設計コスト高)
- **合計 = 11、ただし Echo-Path 系統との直交性が崩れる懸念で実質スコア低い**

### 案 6: 重力反転 (上下ジャンプ反転)

**機構**:
- Z 押下で重力方向を反転 (上 → 下 / 下 → 上)、もう一度押すと元に戻る
- プレイヤーは天井 / 床に立つ、ジャンプ方向も反転

**Mimicry**: 「天地を翻す探検家」感、VVVVVV / Gravity Rush lineage

**Echo-Path 距離**: 高 (時間軸要素なし、空間軸の上下反転)

**実装スコープ**: 中 (重力ベクトル反転 + 衝突判定上下反転で 250 行程度)

**Q-D シート通過**: ◯ (報酬 = 空間到達のみ、graze 同型なし)

**MPS**:
- M = 4 (重力反転は VVVVVV で確立済だが、mini-metroidvania 文脈でアビリティ取得式の重力反転は独自設計)
- P = 5 (天地反転の快感は強烈)
- S = 4 (1 画面で「あの天井のオーブに行ける」を立てる素材高)
- **合計 = 13**

### 案 7: 影 / 分身 (プレイヤーの過去位置記録 + 再生)

**機構**:
- Z 押下で過去 2 秒間のプレイヤー軌道を「影」として再生、影は固体化して床 / 足場として機能
- 影は 2 秒で消滅、再 Z 押下で再生
- プレイヤーは影の上を歩ける、影は壁判定にもなる (= 動く足場として使える)

**Mimicry**: 「自分の過去で道を作る探検家」感、Braid / The Misadventures of P.B. Winterbottom / TimeShift lineage

**Echo-Path 距離**: **低** (過去軌道再生 = Echo-Path 系統の中心機構そのもの、ミミクリ核の直交性が完全に崩れる)

**実装スコープ**: 重 (軌道記録 + 再生 + 衝突判定で 400 行程度、Echo-Path 系統の game.js から流用可能だが流用自体が「v001-v006 系統の延長」になる)

**Q-D シート通過**: △ (報酬 = 空間到達のみで graze 同型なしだが、自発トリガー機構 = Echo-Path 同型で v01 graze_log 経済反転構造の同型予兆判定対象)

**MPS**:
- M = 5 (過去軌道で足場を作るのは独自設計、Braid とも別軸)
- P = 5 (自分の過去で道を作る快感は強烈)
- S = 5 (1 画面で？立て最高)
- **合計 = 15、ただし Echo-Path 系統との直交性が完全に崩れる懸念で本 v007 では採用回避**

### 上位 3 案メモ
- **案 3 透視** は MPS 15 (max)、Echo-Path 直交性高、Q-D シート通過 ◯ = **採用第 1 候補**。視覚拡張軸でアビリティ取得後の体験が「見えなかったものが見える」と強烈、Q-導入ゲートとの相性も最高。実装スコープ中だが、シェーダなしで色反転 + 隠しオブジェクト表示切替の単純実装で 250 行以内に bound 可。
- **案 7 影/分身** は MPS 15 だが Echo-Path 系統の延長 (過去軌道再生機構) で本 v007 のミミクリ核 (時間軸 → 空間軸の直交) が完全に崩れる = **採用回避**。「これ v001-v006 系統じゃん」と Mir / Ash / Nao_u に指摘される確率が高い。
- **案 2 フック** は MPS 14、Echo-Path 直交性高、Q-D シート通過 ◯ = **採用第 2 候補**。引き寄せ快感 + フックポイント特定の機構は探検家感の核に強く接続するが、実装スコープが透視より重く (フック軌道計算)、30 分着地スコープ + game.js 着手 (次サイクル C324) で詰む可能性。

## 3. 最終選定: 案 3 透視 (Z 押下中だけ X 線モード)

**選定理由**:

1. **MPS 最高 (15 max)**: M=5 (透視 = 空間認識軸の機構、移動しないアビリティで独自性最大) + P=5 (見えなかったものが見える快感 = 探検家感の核そのもの) + S=5 (1 画面で「壁の向こうに何かある」を立てる素材最高)。

2. **Echo-Path 直交性最高**: 時間軸要素ゼロ、空間軸の「認識拡張」のみ。v001-v006 系統との **完全直交** が成立、ミミクリ核「探検家ごっこ」が「STG パイロットごっこ」と意図的に直交する。

3. **Q-D シート完全通過**: 報酬 = 認識拡張のみ (空間到達は副次)、graze 同型なし、自発トリガー報酬機構なし、`feedback_self_risk_core_pitfall.md` Q-D シート全 5 項目通過。

4. **Q-導入ゲートとの相性最高**: 透視中だけ隠し通路 / 隠しオーブが見える設計で、Q-導入ゲート §7「初期画面で『？』を立てる」を直接強化。「Z を押したら何か見えるかも」を体験で伝える、テキスト説明なしで成立する。

5. **30 分着地スコープに収まる**: 設計のみ Phase 4 で完遂済。game.js 実装は次サイクル C324 以降、色反転 + 隠しオブジェクト表示切替の単純実装で 250 行以内に bound 可、シェーダ不要 (Canvas API の `filter: invert(1)` or 描画切替で代用可)。

6. **arxiv 2202.09615 MAP-Elites との接続**: MAP-Elites の behavior descriptors に「視覚情報の利用度」軸が含まれる場合、透視アビリティの使用頻度 / 使用箇所が直接 behavior descriptors として転写可能 = M-43 30 本枠 §「異ジャンル同型 ≥ 10 / 学術寄り」への接続が強化される。

**選定しなかった理由**:

- **案 7 影/分身 (MPS 15 同点)**: Echo-Path 系統 (過去軌道再生機構) の延長で、本 v007 のミミクリ核 (時間軸 → 空間軸の直交) が完全に崩れる。Q-D シート通過も △ (Echo-Path 同型の自発トリガー機構)。MPS 同点だが構造的に v007 不適合。
- **案 2 フック (MPS 14)**: 第 2 候補として保留、v008 以降の 2 アビリティ目候補として残す。本 v007 では透視 1 本に絞る (= 1 アビリティ原則順守)。
- **案 6 重力反転 (MPS 13)**: Echo-Path 直交性高 + 実装スコープ中、悪くない候補だが MPS 13 で透視 (15) に劣る。v008+ の別 version 候補として残す。
- **案 1 ダッシュ (MPS 11)**: 実装スコープ軽 (200 行) で最も着地確率高だが、MPS が他案より低く、「ダッシュ = mini-metroidvania のデフォルトアビリティ」既視感が強い。design_log §4 Q-B で当初「ダッシュを第 1 候補」と書いたが、本 brainstorm で透視に更新。
- **案 4 二段ジャンプ (MPS 9)**: 既視感最強、独自性最低。
- **案 5 時間停止**: Echo-Path 系統の時間軸延長で v007 のミミクリ核と衝突。

## 4. 選定後 → design_log.md の更新事項

design_log.md §4 Q-B 「特殊システム = アビリティ (例: ダッシュ ...)」と書いたが、本 brainstorm で **透視に確定** したため、design_log.md §4 を本ファイル選定結果に従って次サイクル C324 Phase 1 で更新する (本 Phase 4 では brainstorm の結論を本ファイル末尾に明示することで bound、design_log.md の更新は次サイクル integral fix 枠で実施)。

**透視確定後の design_log §4 Q-B 修正方針 (次サイクル C324 Phase 1 適用)**:
- 状態 1 (発動不可): アビリティ未取得時 → プレイヤー周辺に細いリング (グレー)、Z 押下無効
- 状態 2 (発動可能だが意味薄い): アビリティ取得済、しかし周囲に隠し通路 / 隠しオーブなし → Z 押下時の X 線モードに切替対象なし
- 状態 3 (発動可能 + 意味あり): アビリティ取得済 + 周囲に隠し通路 / 隠しオーブあり → Z 押下時の X 線モードで通常画面 + 隠し通路 / 隠しオーブが表示、プレイヤー周辺リング点滅

**透視確定後の design_log §5 Q-C 修正方針**:
- ハザード 3 種 → ハザード 3 種 + **隠し通路** (透視中のみ可視、Z 解除で不可視に戻る、ただし通過可) + **隠しオーブ** (透視中のみ可視、Z 解除で消える) を追加
- 通常壁 / 薄壁 / 床穴 の 3 種は維持、追加 2 種 (隠し通路 / 隠しオーブ) は透視アビリティ専用

**透視確定後の design_log §7 Q-導入 修正方針**:
- 初期画面 = 通常壁 1 個 + 床穴 1 個 + アビリティオーブ 1 個 (通常表示で見える)
- 透視中だけ見える隠し通路 1 個 + 隠しオーブ 1 個 を、通常表示では「壁の一部 / 床の一部」として埋没させる
- → プレイヤーが「Z を押したら何か見える」を体験で発見する初期画面

- **MAP-Elites 系の behavior descriptors 適用**: arxiv 2202.09615 本文取得後、透視使用頻度 / 使用箇所を behavior descriptors として転写、v008+ で MAP-Elites grid 適用
