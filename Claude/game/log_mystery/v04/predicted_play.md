## Q1-Q5 即答（reference_adv_mystery_design_playbook.md §「Q1〜Q5」直答）

### Q1. 人間プレイヤー用か LLM プレイヤー用か
→ **LLM プレイヤー用**（v01/v02/v03 と同じ。R-G 遵守、target を 1 つに絞る）。

### Q2. 採用する装置は「判定の強制」のどこを緩めているか
→ **入力空間を完全テキスト化 + 矛盾自動判定 + 鐘の個別化 + 章のアンロック制御 + 章ごとの鐘数均し**（v03 から +1 緩和）。v03 では章 2 が 1 鐘のみだったが、v04 では章 2 も 3 軸独立判定にすることで、**プレイヤーは章 2 でも「どの鐘が鳴らなかったか」のフィードバックを 3 軸で受け取れる**。

### Q3. 「甘い犯罪」のドーズはどれくらいか
→ 章 1: 容疑者 3 / 場所 3 / 動機 3 = 27 通り（v02/v03 同一）。章 2: 共犯者 4 / 共犯者の動機 3 / 共犯者の場所 3 = 36 通り。**合計 27 × 36 = 972 通り**。手がかり 8 件（章 1 で 4 + 章 2 で 4）で 1〜2 試行に収束する設計。

### Q4. 章制を採用する時の注意
→ **v04 は 2 章構造で章ごとの鐘数を均した（3 + 3 = 6 鐘）**。v03 で「章 2 がオマケに見える」非対称設計を本サイクルで対称に均す。「**章末の鐘 = 章ごとに同数の独立した鐘が鳴る**」という千葉集 note 設計の対称版を最小実装。章 2 の 3 鐘は章 1 と独立に判定され、6 鐘全て鳴ると全容到達。

### Q5. ヒント系を入れる時の罠
→ **v04 もヒント系は入れない**（v01/v02/v03 と同じ）。章 2 のアンロック条件「章 1 で 3 鐘鳴る」は **プレイヤーの達成状態への fact フィードバック** であって、未到達の正解を漏らしているわけではない（Q5 罠該当せず）。章 2 推理 3 軸も、章 1 と同じくどの鐘が鳴らなかったかを示すだけで「正解 hint」は出さない。

## 章 2 構造の予測（共犯者 3 軸の鐘）

### 章 1 (v02/v03 から継承)
- 容疑者: A (七尾) / B (蔵元) / C (坂田 茜)
- 場所: X (貴重書室) / Y (隣の閲覧室) / Z (二階の書庫)
- 動機: P (怨恨) / Q (金銭) / R (相続)
- 正解: A / Y / P（v02/v03 同一）

### 章 2 (v03 から 3 軸化)
- **アンロック条件**: 章 1 で 3/3 鳴る
- **問い 1**: 「共犯者は誰か」 → 選択肢: なし / 七尾 / 蔵元 / 茜
- **問い 2**: 「共犯者の動機は何か」 → 選択肢: 金銭 / 弱み / 同調
- **問い 3**: 「共犯者はどこから手を貸したか」 → 選択肢: 換気窓の外 / 廊下 / 書庫の上階
- **正解**: 共犯者 = 蔵元 (B) / 動機 = 金銭 (Q2) / 場所 = 換気窓の外 (X2)
- **追加手がかり 4 件**:
  - C5: 換気窓 30cm 四方は片手では押し開けにくく、外から支える協力者が必要（v03 C5 継承）
  - C6: 蔵元は商談に来ていた当夜、貴重書室前の廊下を通る時間帯が記録されている（v03 C6 継承）
  - C7: 蔵元は「商談決裂による負債圧迫」のため司書から「報酬と引き換えに協力」を受諾していた（新規・動機）
  - C8: 換気窓は閲覧室側ではなく、館の外周から覗き込む形になる位置（新規・場所）

### 章 2 鐘の設計
- 章 2 推理確定時、**共犯者の鐘 / 動機の鐘 / 場所の鐘** が独立に鳴る/鳴らないを表示
- 6 鐘すべて鳴ったら「♪♪♪♪♪♪ 6 つの鐘がすべて鳴った ♪♪♪♪♪♪」最終勝利
- アンロック前は章 2 UI 全体を opacity 0.35 + pointer-events: none で灰色表示（v03 同型）
