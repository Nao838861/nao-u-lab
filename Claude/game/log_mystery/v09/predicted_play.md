## 6. 第 3 chord ペア発火条件 / 非発火条件 (明示)

**発火条件** (場所鐘1 ♪ が C8 cross-back で鳴る):
- 場所 = Y を選択している
- C10 既読 (司書日誌 = 内的決定打)
- ※ C8 単独では場所鐘1 ⏸ どまり (chord 3 cross-back は補強 pending のみ、決定打にはならない)
- 章 1 推理ボタンを押した時点で eval される (押下前は反映なし、押下後 reDeduceCh1 自動発火)

**chord 3 cross-back 発火条件** (C8 既読化で場所鐘1 ⏸ になる):
- 場所 = Y を選択し、章 1 既に推理済
- C10 未読 + C8 既読 → 場所鐘1 ⏸
- chord 3 の真価は「両方 pending 化」型: C8 既読化で 場所鐘1 + 共犯場所鐘 が同時に pending 化する点

**非発火条件** (chord 3 が出ない、v08 通りの挙動):

- C10 既読 + C8 未読 → 場所鐘1 ♪ (chord 3 経由せず C10 単独決定打)
- 章 1 未推理 → chord 3 cross-back は走らない (chapter1Deduced=false なら CH2 click handler の reDeduceCh1 短絡)
