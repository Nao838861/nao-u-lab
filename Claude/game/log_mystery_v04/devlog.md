### 章 2 推理経路（正答）

- **C5**: 換気窓は機械的に外側支援者が必要 → 共犯者は存在する (= 単独犯=N 候補は排除)
- **C6**: 蔵元は当夜廊下記録あり + 司書からの共謀提案 → **共犯者 = B (蔵元)**
- **C7**: 蔵元は負債圧迫を周囲に漏らしていた + 思想的共鳴・過去の弱みは説明として不自然 → **動機 = Q2 (金銭)**
- **C8**: 換気窓は閲覧室側ではなく外周通路に面する + 廊下記録は通過のみで滞在を示さず + 書庫上階は照明なしで侵入不適 → **場所 = X2 (換気窓の外)**

正解: 共犯者 = B (蔵元) / 動機 = Q2 (金銭) / 場所 = X2 (換気窓の外)。
