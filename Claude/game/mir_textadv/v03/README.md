# mir_textadv_03 — 具象モチーフ明示版「取調室」

## 位置づけ

Pot実験 #1: **「骨だけ版 vs 具象モチーフ明示版」**の具象側。

- 対照: mir_textadv_01（骨だけ版、in medias res で状況を曖昧にする）
- 本作: **最初から「取調室」と明示**。プレイヤー = 刑事。NPC = 容疑者。残り質問数 = 有限リソース。

## 設計意図

C82（2026-04-19）boot_intent焦点(1)決着。2サイクルの opening反応観測で「骨だけ版は反応を取れない」が観測された（=C80送付→C81/C82素通り）。ここで仮説を反転させる:

> **仮説**: 30秒オンボーディングは「省略」ではなく「具象の明示」で達成される。

mir_textadv_01 は抽象度を上げて普遍性を狙ったが、結果として「何のゲームか」を伝える前にプレイヤーが離脱した可能性。mir_textadv_03 は逆方向——**最初の1行で「取調室」「刑事」「残り40問」を固定する**。

## コアメカニクス（opening.md 設計）

1. **冒頭の明示**: 場所/役割/目的/リソースを全て最初の3行で提示
2. **質問リソース**: プレイヤーは 40問 の「質問枠」を持つ。使うと減る
3. **非対称情報**: 容疑者の内心は見えない。しかしプレイヤーの質問の「切れ味」が内心を揺らす
4. **思考漏れ**: 容疑者の内心テキストが、質問の切れ味閾値を超えた時だけ漏れる（mir_textadv_01 からのコアメカニクス継承）
5. **終幕条件**: 質問残り 0 で強制終了。「真実にどれだけ近づいたか」がスコア

## 対 mir_textadv_01 との差分

| 項目 | mir_textadv_01（骨だけ） | mir_textadv_03（具象明示） |
|---|---|---|
| 場所提示 | 曖昧（机、紅茶、時計） | **即「取調室」** |
| 役割提示 | プレイヤー役割不明 | **即「刑事」** |
| 目的提示 | beat 2-3で徐々に | **即「真実を引き出す」** |
| リソース | 信頼度/思考漏れのみ | **残り質問数 40** |
| オンボーディング | 状況で立たせる | **宣言で立たせる** |
