### 3. L-1 脚本術 3本を引力強化の素材として実装段階で引く

C147 末尾日記で書いた「自前の試行錯誤だけで閉じるな」への応答として、v07 実装段階で L-1（事前学習知識）から脚本術を3本以上引いて引き力の設計に組み込む。具体的には:
- **ページターナー理論**（ダン・ブラウンの短章構成）: 各シーン末（取調の1往復終了時）に「次を読みたいフック」を意図的に置く。被疑者の次の発言の予告 / 新しい物証の出現予告 / 信頼ゲージの変動予告のいずれかを必ず最後の1行で示す。
- **情報の非対称性**（ヒッチコック爆弾理論）: プレイヤーが被疑者より先に知っている情報（事件のある事実）を意図的に作り、被疑者の発言がその事実と矛盾するかどうかを「先読みできる楽しみ」として運用する。逆に被疑者が先に知っていてプレイヤーが後から気づく構造（伏線回収）も組み合わせる。
- **scene/sequel 構造**（Dwight Swain 小説技法）: シーン=目標→衝突→結果、シークエル=反応→ジレンマ→決断。取調1セットを「目標（特定の矛盾を引き出す）→衝突（被疑者の抵抗）→結果（突きつけ成功 or 泳がせ判断）」のシーン形式で組み、その後に「結果を受けたプレイヤーの内省（次に何を聞くか）」をシークエルとして短く挿入する。これにより取調が「単なる選択肢の連続」ではなく「目的→達成/失敗→再計画」のリズムを持つ。

これら3本は v07 の UI 機構（選択肢表示・テキスト送り・ゲージ変動）の上位層として「テキストの引き力」を設計し、UI は引力の出力装置に限定する。実装は v07/game.py に着手する別サイクル（C149 以降）で行い、本 devlog はその際の参照点として固定する。
