# 関ヶ原 1600 — 設計

歴史学習用の関ヶ原合戦シミュレータ。何も操作しなければ通説どおりに推移し、武将の判断ルールを差し替えれば if（小早川が動かない等）を試せる。

## 構成（3層）
1. **史実意思決定層** — 武将ごとの判断ルール＋史実タイムライン。史実を固定アニメにせず「史実を生む条件」として書く（例: 小早川＝東軍優勢＋催促＋時刻で寝返る／脇坂ら＝小早川が寝返ったら連鎖／吉川＝動かず毛利秀元を塞ぐ／島津＝近づく者は敵味方なく撃つ、西軍崩壊で前方突破）。
2. **部隊シミュ層** — 備単位の兵数・士気・隊形・交戦。決定論（固定シード, 10Hz）。
3. **個人描画層** — 兵一人ずつ（InstancedMesh）。部隊の隊形スロットに追従。1体あたり 1/4/10 人を切替、将来は距離LOD。

史実再現は自動テストで守る（無操作で 12時±30分 小早川寝返り、13時台 大谷隊壊滅、14時前後 西軍総崩れ、島津生還は数十〜百名規模）。

## データ
- `data/dem.*` 国土地理院 DEM10B z14（`tools/fetch_dem.py` → `tools/bake_dem_js.py`）
- `data/ground.js` 1600年10月想定の地表（刈田・里山・森・川=DEM流量累積・街道）（`tools/bake_texture.py`）
- `data/geo.json` 街道・集落（概略）
- `js/units.js` 布陣（通説概略。部隊ごとに典拠確認して verified を付ける）
- 予定: `events.json`（時刻/発生条件/演出/解説/典拠）、通説⇔新説（問鉄砲・開戦直後寝返り説 等）切替

## 段階
| 段階 | 内容 | 完了条件 |
|---|---|---|
| M0 | 地形＋布陣の静的表示 | 布陣図と照合して位置が合う（照合は未了） |
| M1 | 部隊シミュ＋タイムライン | 無操作で史実再現テストが通る ← 10/10 合格 |
| M2 | 個人描画のLOD・歩行/戦闘アニメ | 全景60fps・寄りで個人が動く |
| M3 | イベント演出・解説カード・霧/硝煙 | 6時間を早送りで通して見られる ← 初版 |
| M4 | if（武将ルール上書き） | 小早川不動で別の結末になる ← UIあり・結末の妥当性は未調整 |

## M0 の既知の課題
- 布陣座標・兵数は未照合（通説の概略値）。表示色は識別用で旗色ではない（井伊の赤備え等を除く）
- 街道・集落は概略。1600年の村落規模は未調査
- 兵の造形は箱組み。具足・旗指物の造形は M2 で作り直す
- 島津・大谷の兵数構成など諸説ある部分は通説値のみ

## 実装メモ
- `js/sim.js` 部隊シミュ（2秒刻み・決定論）。戦闘力 ∝ 質×士気×√兵数、側面・背後は割増、陣地の堅さ（柵）で被害減、士気崩壊で潰走→周囲に動揺が伝播。
- `js/scenario.js` 武将ごとの判断ルール（時刻・条件で発火）、イベント解説文、もしもの選択肢、部隊能力の調整値。
- 描画は兵一人ずつの部隊内位置を固定し、部隊の中心・向き・散開・損耗をシェーダの uniform で渡す（DEMテクスチャで接地）。戦死者は倒れた兵としてその場に残る。陣幕は陣所に残る。
- もしもの結末（小早川が西軍参戦でも西軍が勝てない等）はモデルの粗さによるもので、未調整。
