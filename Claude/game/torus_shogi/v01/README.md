# トーラス将棋 v01

上下・左右がつながったトーラス盤の将棋。`index.html` をブラウザで開くだけで遊べる（依存なし・単一ファイル）。COM（αβ法）と対戦できる。

## 遊び方
- 自分の駒をクリック → 行ける升が緑（移動）/赤（駒を取る）でハイライト。**利きが盤の反対側に回り込む**のがトーラスの肝。
- ハイライト升をクリックで着手。成れる場合はダイアログで選択。
- 持ち駒をクリック → 打てる空き升がハイライト。
- 「強さ」「手番」を選んで「新規対局」。「待った」で自分の手番まで戻す。

## ルール（通常将棋との差）
- **初期配置**: 通常将棋を各陣営とも敵方向へ1段寄せたもの。これで上下ラップによる玉列密着（標準配置だと即破綻）を回避。空きの配分は前1段/後2段で、9×9・3段陣で取れる中で最も対称な配置。
- **成りゾーン**: 移動後の相手陣3段（先手=1〜3段、後手=5〜7段）。入る/出る/その中で動く時に任意で成る。トーラスには行き所のない駒が無いため成りは常に任意。
- **飛・角・香**: ラップして進み、最初にぶつかった駒で止まる。一周すると自分の升に戻るため自分自身は取れない（＝空の筋/段/斜めなら全升に利く）。
- **二歩**: 禁止。
- **未実装（簡易版）**: 行き所のない駒・打ち歩詰めの制約なし。千日手判定なし。

## COM
αβ法（negamax）+ 反復深化 + 時間制限。評価は駒得（盤上＋持ち駒）＋玉周りの被利き。端ボーナスは使わない（トーラスに端が無いため）。
強さ: 弱=深さ2 / 中=深さ3 / 強=深さ5（最長4秒）。

探索強化（同じ深さでも明確に強い）:
- **静止探索（quiescence）**: 葉局面で駒の取り合いが収まるまで延長し、水平線効果でのタダ取りを防ぐ。
- **null-move枝刈り**: 将棋は持ち駒があり zugzwang がほぼ無いので安全に適用。
- **手順並べ替え**: MVV-LVA（高い駒を安い駒で取る順）＋ キラー手 ＋ 成り優先。

検証: 旧実装（探索強化なし）と同じ深さ2で自動対局16局を行い 16-0。

## 検証
エンジン部（DOM非依存）を Node で抽出し、初期局面・合法手数・トーラス利き（孤立飛角=16升）・ランダム自己対局50局（玉の不正取得・クラッシュ無し）を確認済み。
