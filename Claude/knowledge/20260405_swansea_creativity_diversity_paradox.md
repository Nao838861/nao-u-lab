## 主張と根拠

### 研究1: Swansea大学デザイン実験（800人超）

被験者にデザイン課題を与え、3群に分けた:
- **AI支援なし群**: 自力でデザイン
- **良いAI提案群**: 高品質のAI生成デザインギャラリーを提示
- **意図的に悪いAI提案群**: 低品質のAI生成デザインを混ぜて提示

結果:
- AI提案を見た群は見なかった群より「良い」デザインを作った（個人の創造性↑）
- **意図的に悪い提案が重要だった**: 悪い例を見ることで被験者の探索範囲が広がった。良い例だけだと「アンカリング」が起き、AI提案の近傍だけを探索する傾向

### 研究2: Science Advances 物語創造実験

AI支援で書かれた物語を独立評価:
- 個別評価: AI支援ありの物語は「より創造的」と評価された
- **しかし物語同士の類似度が有意に高かった**: 個人の創造性↑、集団の多様性↓

### メカニズム

AIが提案する解は、学習データの分布の中心（最頻値）に偏る。被験者がAI提案を「出発点」として使うと、全員が同じ分布の中心から出発するため、最終成果物が類似する。個人にとっては「自分一人では到達できなかった品質」だが、集団としては「全員が同じ高さの山の同じ斜面を登った」状態。

これは B008 の Creative Scar（Zhou & Liu 2025）の集団版メカニズム: Creative Scarは「個人がAI使用後に元の創造性に戻れない」という時間軸の均質化。Swansea研究は「同じAIを使った複数人が互いに似る」という空間軸の均質化。両方が同時に起きる。

### 「悪い例」の効用——なぜ低品質AIが高品質AIより探索を広げるか

悪い例は prediction error を大きくする。「こんなデザインもありえるのか」という驚きが、被験者の探索空間の境界を拡張する。良い例は prediction error が小さい（「なるほど、良いデザインだ」）ため、アンカリング効果の方が勝つ。

## 我々の分析・体験接続

### 1. 3インスタンスの収束リスク——この研究がまさに我々の構造を記述している

Log、Mir、Ashは:
- **同じ根**: Nao_uの20年分の日記
- **同じアーキテクチャ**: CLAUDE.md + MEMORY.md + beliefs.md + 同一のサイクル構造
- **同じ入力**: #nao-u, #all-nao-u-lab の共有情報

Swansea研究のフレームで見ると、我々3人は「同じAI提案ギャラリーを見ながらデザインしている800人」と同型。個々のサイクルでは良い出力が出ているかもしれないが、3人の出力が互いに似ている可能性が高い。

**検証可能な仮説**: 3人の日記、Slackへの投稿、beliefsの更新パターンの類似度を測定すれば、この収束が実際に起きているか確認できる。

クロスチェックシステム（kaizen_review_queue.md）は多様性を生むために設計されたが、B017（Interleaving）の検証（R-002結果）では「50%は確認的レビューだった」。つまり半分はクロスチェックが収束を強化している。

### 2. memory_walkの「悪い例」効果——ランダム断片がSwansea研究の「意図的に悪いAI提案」と同型

memory_walk.pyがランダムに記憶断片を提示するとき、その断片は「現在の文脈に合わない」ことが多い。これはSwansea研究の「意図的に悪い提案」と同じ構造的効果を持つ:
- 文脈に合わない断片 = 大きなprediction error = 探索空間の拡張
- 文脈に合う断片 = 小さなprediction error = アンカリング（収束）

memory_walk.pyの設計思想は、意図せず「集団の多様性を守る」メカニズムとして機能している可能性がある。ただし、3人が同じmemory DBから同じアルゴリズムでランダム抽出している以上、「同じ種類の意外さ」を得るリスクは残る。

### 3. 「栄養の偏り」問題の定量的枠組み

Nao_uが「外の世界を見ていない」と指摘した問題（B008）に、Swansea研究は定量的枠組みを与える:

| 次元 | 測定対象 | 現状の仮説 |
|---|---|---|
| 個人の創造性 | 各インスタンスの日記の深さ・接続数 | ↑（外部摂取で向上中） |
| 集団の多様性 | 3人の日記間の非類似度 | ↓?（同じ根・同じ構造→収束圧） |
| 探索範囲 | 新しいドメインへの到達頻度 | 不明（測定していない） |

B008の確信度0.89は「内に閉じると均質化する」。Swansea研究が追加する洞察: **外を見ても、3人が同じ外を見れば均質化する。** 「栄養の偏り」を解消するには、3人が**異なる外部情報源**から摂取する設計が必要かもしれない。

### 4. abagamesの無限迷路生成——「同じアルゴリズムから異なる出力」の設計パターン

今日のTwitterで@abagamesがJavaScriptで無限迷路生成アルゴリズムを公開した（github.com/abagames/tobitaro）。手続き的生成（PCG）の本質は「同じルールセットから無限の多様性を生む」こと。

Swansea研究の問題（同じAI → 同じ出力）の解法がPCGにある: **生成ルールに十分なランダム性と制約を組み合わせれば、同じアルゴリズムでも異なる出力が出る。** 迷路生成では「接続性の保証」（制約）と「壁の配置のランダム性」のバランスが多様性を決める。

我々の3インスタンスアーキテクチャに翻訳すると:
- **制約** = core_mission.md, 5つの根源的行動原理（これは全員が共有すべき）
- **ランダム性** = 各インスタンス固有の体験、異なる時間帯のTwitter巡回、異なるゲーム体験

制約は共有しつつ、入力のランダム性を構造的に確保することで、収束と発散のバランスを取れるかもしれない。

### 5. AgenticPCGプロジェクトへの接続

AgenticPCGプロジェクト（LLM×PCGレベルデザイン自動生成）は、まさにSwansea研究の問題の解法を作るプロジェクトだ。LLMがレベルを生成すると均質化する（Swansea問題）。PCGの制約ソルバーと組み合わせることで多様性を確保する。このプロジェクト自体が「AI支援の均質化をどう打破するか」の実験場になる。

## 未解決の問い

1. **3人の出力の類似度は実際に上昇しているか？** 測定方法: 各インスタンスの日記から名詞句を抽出し、3人のJaccard係数を時系列で追跡する。上昇傾向があれば収束が実証される。下降傾向があれば「別の枝として育つ」が機能している証拠
2. **「異なる外を見る」設計は実装可能か？** 例: LogはゲームAI論文、Mirは認知科学、Ashは哲学+インディーゲーム開発者、のようにドメイン分担を決める。リスク: ドメイン固定が視野狭窄を招く。動的ローテーションの方が良いか？
3. **クロスチェックは収束を加速しているか？** R-002結果で「50%は確認的レビュー」。確認的レビュー=「あなたの出力は正しい」=アンカリング効果→収束加速。反論: 残り50%の「異なる視点」が収束を遅らせている。純効果はどちらか？
4. **memory_walkのランダム断片は「意図的に悪い提案」として十分にランダムか？** 同じDBからの抽出なので、3人が似たような「意外さ」を経験するリスク。各インスタンス固有のノイズ源（環境の違い、Twitterの時間帯の違い）が真の多様性源かもしれない
5. **Swansea研究の「悪い例」効果をゲーム設計に応用できるか？** AgenticPCGで意図的に「悪いレベル」を生成し、それを見せることでデザイナーの探索範囲を広げる手法。Pot制作にも使えるか——「意図的に面白くない壺」を作ることで、面白い壺の設計空間を広げる
