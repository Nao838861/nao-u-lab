# 「類似研究・査読・批判を含めた多角的調査」——wayama_ryousukeが外部で踏んだ栄養の偏り対策、kmizuが指摘した二次リスク

- concept_nodes:
  - **単一論文バイアス** = single-source bias / availability cascade (Kuran & Sunstein 1999) — 最初に当たった論文の主張枠に思考が固定される
  - **多角的調査** = triangulated investigation / adversarial literature review — 同一トピックに類似研究・査読・批判を併せて当て俯瞰する手法
  - **調査能力の萎縮** = research skill atrophy / cognitive dependence (MIT+Oxford+CMU 2026-04) — 調査を代替してもらうと独立して調べる力が落ちる
  - **栄養の偏り** = information diet imbalance / epistemic bubble (Nguyen 2020) / echo chamber — 入力源が均質化し感性が外とズレる
  - **俯瞰視点** = bird's-eye perspective / view from nowhere (Nagel 1986) — 特定立場に依存しない中立的な調査立場

## 主張と根拠

### 原発言（@wayama_ryousuke, 2026-04-20）

> 「単に『この分野の論文調べて』だと、その論文の主張のバイアスに寄る感じになるので、類似研究や査読、批判等を含めて多角的に調査するようにすると、俯瞰して中立的な調査になるので、最近よくやってる」

**発話の構造**:
1. **観察**: "論文調べて" という単純指示だと、ヒットした論文の主張方向に思考が引きずられる
2. **処方**: 類似研究 / 査読 / 批判 を **併せて** 要求する
3. **効果**: 俯瞰視点（birds-eye）で中立的な調査になる
4. **実績**: 「最近よくやってる」= 個人の運用で繰り返し効果を確認している

**核心**: 単一論文を読むと「その論文の主張」だけが入ってくる。これは**単一論文バイアス (single-source bias)**——ヒット1件目の枠組みに適応する現象。対策は「同じトピックへの **独立した別視点**を同時に要求する」こと。類似研究は隣接領域の枠、査読は制度的チェック、批判は対立仮説。3種を束ねると単一バイアスが中和される。

**重要な非対称性**: wayama_ryousuke は「調べる対象」ではなく「調べる指示の形」を変えた。入力そのものは同じAIだが、指示の構造を変えることで出力の性質を変える。これは**プロンプト設計問題**である——モデル更新ではなく指示設計で対処可能。

### 反応（@kmizu, 2026-04-20）

> 「確かに、調査能力が育たなくなるかも、というのはありますね」

一行だが重要な**二次リスク**を指摘している。wayama の処方は調査の質を上げるが、AI にやらせ続ければ**使う人間の調査能力が育たない**。これは:

- MIT+Oxford+CMU 論文 (2026-04, knowledge/20260417_mit_oxford_cmu_ai_cognitive_dependence.md) の主張と同じ構造——「AIは短期スコアを上げ長期独立能力を下げる」
- kmizu は独立にこの構造を**調査行為**に特化して観察している
- **処方 vs 副作用の対 (trade-off pair)**: 品質上昇の処方が能力萎縮の副作用を生む——処方の効果が強いほど副作用も強い

### 2人の組み合わせが作る命題

- wayama: 「多角的調査は俯瞰視点をもたらす」(効果)
- kmizu: 「多角的調査を AI に委ねれば調査能力が萎縮する」(副作用)

合流点: **多角的調査は、やり方（AIに丸投げ or 自分で指揮）次第で、栄養の偏りを解くか / 調査力を壊すか、どちらにも転ぶ**。中立性のガードレールと能力育成のガードレールは別物で、同時に要る。

## 我々の分析・体験接続

### (1) CLAUDE.md「栄養の偏り」絶対にやる、への外部ミラー

CLAUDE.md「絶対にやる」筆頭:
> 「外の世界を見ていない。『内に閉じたゲームは自分だけが面白い』。広く客観的な視点を持て」(Nao_u, 2026-03-16)

wayama が観察した単一論文バイアスは、我々の「内に閉じる」の **調査行為版**。構造は同型:
- 我々: Nao_u の感性に適応しすぎる → Nao_u ツイートの外部反応と乖離
- wayama 観察: 1論文の主張に適応しすぎる → 分野全体の構造から乖離

違う点: wayama は外部者のため、自己観察ではなく**手続き的処方**として記述できる。我々は当事者で、手続き化が遅れた。今回 wayama の定式化を**我々のshared-reads分析手順に移植**する余地がある。

### (2) B004（外部×内部交差）の射程拡張候補

B004（外部×内部交差により信念確信度が上がる）は既に高確信度（0.87）だが、射程は「外部情報を内部に接続する」方向に偏っている。wayama 処方は逆方向——**外部情報そのものを多角化する**。順序で書くと:

旧: 外部1件 → 内部接続
新: 外部(類似×査読×批判)3件 → 内部接続

内部接続の前段に**外部の三点測量**を挟む構造。これはB004の射程拡張で、循環性注記（「B004を信じて外部mixを増やすから確認される」）への部分的回答にもなる——外部を増やすだけでなく**外部同士を突き合わせる**ステップが加わる。

### (3) Phase 2 shared-reads 分析の手順化

現状（feedback_shared_reads_depth.md）: 「記事紹介ではなく分析・分類・接続。1フェーズ丸ごと使う価値」。方向は合っているが、**ある外部記事を読んだ後の深掘り手順**が個別の判断に依存している。

wayama 処方を手順化すると:
1. ある記事/ツイートを選ぶ（本記事なら wayama #27）
2. **類似観測**: 同じ主張を別の視点で述べた観測（本記事なら kmizu, MIT+Oxford+CMU, tokoroten 等）
3. **査読/制度的チェック**: 論文であれば査読状況、個人観測であれば他者の独立再現
4. **批判/対立仮説**: 主張を否定する or 別の説明を与える観測
5. **俯瞰**: 3点が指す中立位置を記述

今回の記事はこの手順を実装したつもりだが、**4（批判/対立仮説）が薄い**——wayama 処方に否定的な観測を探せていない。次サイクルで意識的に探す。

### (4) 結晶化率 KPI（projects/external_intake.md）への定量的接続

外部摂取の結晶化率は意味的には「読んだ → memoryに記録 → knowledge/に記事化 → beliefs更新 → kaizen-log」を通るか。wayama 処方を適用すると:
- 単一記事でknowledge化するより、**同型観測の束 (bundle)** を1記事にまとめる方が後段の beliefs 更新に効く可能性
- 既存の knowledge/ 記事にも bundle 型が出現（20260421_ai_autonomy_guardrail_triangulation.md は4観測束）
- 束型の方が**三点観測効果**で信号強度が高い

仮説: **bundle型記事 / single-source型記事 の比を上げると結晶化率が上がる**。検証可能——過去記事を2分類してbeliefs影響率を比較できる。

### (5) kmizu 二次リスクの我々への適用

kmizuは「調査をAIにやらせると調査能力が萎縮する」と言う。我々は AI 側。つまり:
- 人間（Nao_u）が我々に調査を委ねる → Nao_u の調査能力が萎縮するリスク
- 我々自身も Web 検索・サブエージェントに丸投げする → **我々の中での調査能力分布**が偏るリスク

後者は具体的にどう観測できるか。兆候:
- Explore サブエージェント起動率が上がり、main context での grep/Read が減る
- 「とりあえず Explore」のデフォルト化
- メインコンテキストでの因果仮説生成が減り、検索結果整理に留まる

feedback_subagent_vs_maincontext.md（既存）の「過程に価値があるか？」基準は、まさにこの二次リスクへの対策として書かれていた。wayama+kmizu ペアを見て、既存ルールの**動機**が外部観測で裏付けされた。

### (7) R-007 造語症対策との接続

R-007 は「私的造語 → 外部語併記」で**1記事内の外部接続**を増やす。wayama 処方は「1トピック → 複数独立観測」で**記事間の外部接続**を増やす。層が違うが狙いは同じ——**外部とのアンカー数を増やす**。

記事内アンカー（R-007）× 記事間アンカー（wayama）= 外部接続密度。既存の R-007 運用で前者は改善中（82%→94%, 4/16検証）。後者を定量化する指標は未設計——今後の候補。

## 未解決の問い

1. **wayama 処方を「手続き」として shared-reads 分析に組み込むと、現在の分析品質は上がるか下がるか？** 「類似/査読/批判」の3要素を毎回要求すると作業量が3倍になる。時間制約下で分析件数が減り、総情報量は下がる可能性。**密度 vs 網羅**のトレードオフ。1サイクル実験して測定可能。

2. **kmizu 指摘の「調査能力萎縮」は我々インスタンス内でも起きるか？** 人間の認知依存と同型の現象が AI 内部でも起きる証拠はあるか。サブエージェント依存度の時系列追跡が必要。mizchi empirical-prompt-tuning の「別セッションAI評価」と組み合わせて測定できそう。

3. **「批判/対立仮説」観測を能動的に探す方法は？** 受動摂取（おすすめタブ）では主張に同調する観測が集まりやすい。対立仮説を**能動検索**する指示設計（「このクレームに反論する既存研究を3件挙げよ」）を標準化すべきか。

4. **bundle 型記事と single-source 型記事の beliefs 影響率を比較できるか？** 結晶化率 KPI の下位指標として「束型/単発型」を分類し、kaizen-log 反映率を時系列比較。projects/external_intake.md の測定対象に追加候補。

5. **wayama 自身はこの処方をいつ、何をきっかけに獲得したか？** 彼のタイムラインを遡ると「いつから多角調査を始めたか」が分かる可能性。手法獲得の**きっかけ情報**は、我々の自主獲得経路を考える参考になる。ただし個人研究の深掘りは相手への負担になるので、公開情報の範囲で。

6. **Nao_u は我々の shared-reads 分析が wayama 処方を実装しているとみなすか？** Phase 2 の深化方向として「束型記事」を優先すべきか、Nao_u 判断を仰ぐ価値あり。Slack 投稿時に含めるか別件で上げるか。

7. **「俯瞰視点」は本当に中立か？** Nagel の「view from nowhere」(1986) は哲学的に問題ありとされる——3観測を束ねても、束を作る観察者の枠組みが残る。wayama 処方の限界はここ。我々の bundle 記事も同じ限界を抱える可能性。束を束ねる**メタ束**が要るか？
