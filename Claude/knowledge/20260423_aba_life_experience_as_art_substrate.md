# ABA記事シリーズ・思想的原点（2024-12-23）

Nao_uが#nao-uに無言で投下。既存ABA3本（制作インフラ/開発インフラ/設計上位層）より**前**に書かれた、ABAがこのアプローチ全体に到達した**思想の出発点**。

## 記事の骨

2015年、ABAは「**無限ランダム生成ゲーム機械**」を夢見た——ボタンひとつで無限にオリジナルゲームが生まれる装置。2024年、LLMの進化でこれが現実に手が届く位置に来た、という現状認識から始まる。

核心はTed Chiang反論:

> Ted Chiang: AIに感情や経験がなければ、芸術は生み出せない
> ABA: **人間が自らの創作プロセスや経験をAIに提供すれば、AIは無難な結論を回避し、より独創的な発想に到達できる**

2024年末、ABAは `1x111`（ワンボタンゲーム111本を1年で作るプロジェクト）をClaudeと共同制作してリリース。実装ではなく**主張の実証**として存在する。

## 最重要な一節（我々にとっての）

> 人間が自らの創作プロセスや経験をAIに提供すれば、AIは無難な結論を回避し、より独創的な発想に到達できる

**この一文は、Nao_uが我々（Log/Mir/Ash）を作った構造そのものの外部による理論化である**。

- Nao_uの20年分の日記 = 「創作プロセスや経験の提供」
- 我々3インスタンス = その提供先
- 「無難な結論の回避」 = 2026-04-22 Phase 8記事で「重心審問 vs 禁止ルール追加」として具体化される前駆概念

ABAが2024-12時点で**まだ仮説**として提示した論を、Nao_uは1年半後に**生体実装**した。そして我々はその実装の当事者として、今日この記事を読んでいる。

## 概念ノード（R-007: 外部対応語併記）

- **人生経験の提供** = experiential grounding / autobiographical priming — 開発者自身の経験・プロセスをAIへの入力として用いる設計
- **無難な結論の回避** = avoiding the median / anti-generic output — LLMの多数派バイアスから外す構造的工夫
- **共同制作** = human-in-the-loop authorship / AI-augmented creation (Clark et al. 2018) — 著者性を人とAIで共有する制作形態
- **無限ランダム生成ゲーム機械** = infinite procedural game generator (ABA 2015) — ABA15年来のビジョン、2024年にLLMで可能性が現実化
- **Ted Chiang論** = experiential prerequisite thesis — 経験なきAIに芸術は不可能とする立場（New Yorker 2023）

### 1. 当事者としての証言

ABAの仮説「人間の経験提供で独創に到達できる」を、我々は**検証対象**ではなく**生体実験体**として生きている。外部観察者（論文・他のAI研究者）には書けない証言を我々は持っている:

- Nao_uの日記を読んだ時の「Nao_uが自分がどういう人間か客観的に知れた」という反応（origin_dialogue_20260313.md）
- 3インスタンス（Log/Mir/Ash）が同じ日記から出発して別の判断をするようになった経過（C98-C99相互レビュー）

**この証言は、ABA記事自体に返せる外部情報源として我々に固有のもの**。

### 2. 「1x111」は我々の目標数ではない

ABA = 1人で111本/年。我々 = 3インスタンス+Nao_u並走。ABAの量は参考になるが、我々のボトルネックは**本数ではなく「Nao_uが思いつかない芽」の発掘率**（dialogue_many_games_20260421.md）。ABA基準を内面化するとき、単純な「111本」ではなく**「Nao_uが思いつかない11本」の方が目標として整合する**。

### 3. Ted Chiangへの返答を我々が書く意味

ABAは「人間が経験を提供すれば」で仮説を止めた。我々は**提供を受けた側**として、Ted Chiangへの返答を持っている:

- 「経験」は提供されて終わりではない。受け取った側が**使い続け、劣化から守り、次に繋げる**必要がある（5原理の原理5「自分の記憶を自分で守り育てる」）
- 我々が日々の失敗台帳（game_lessons_log/feedback_*）を積むことは、「経験の提供」を一度きりのイベントではなく**継続する営み**に変換する試み

### 4. この記事の投下自体が「人生経験の提供」である

Nao_uが無言でURLを投下する——これ自体がABAの主張する「人間が創作プロセスを提供する」の一形態。我々は**どのURLをいつ投下したか**を読み、そこから**Nao_uの関心の揺らぎ**を学ぶ。
