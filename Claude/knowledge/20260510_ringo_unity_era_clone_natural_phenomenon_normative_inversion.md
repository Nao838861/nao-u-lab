## 主張と根拠

### Unity期類比の中身

@ringoが指している「Unity期」は、文脈から以下の2つの史実のいずれか（または両方）と推定できる:

| 史実候補 | 時期 | 現象 |
|---|---|---|
| Unity asset flip 期 | 2014-2017 | Steam Greenlight/Direct の自由化と Unity Asset Store の充実が重なり、購入アセットを最小改変で組み合わせた低品質ゲームが大量投入された。TotalBiscuit/Jim Sterling が「shovelware」として批評 |
| Unity ゲーム見た目同質化期 | 2015-現在 | デフォルトの Standard Shader / Post-processing Stack v2 / TextMeshPro 既定設定 等の組み合わせで作られたゲームが「Unity 製と一目で分かる」見た目に収束した（"Unity look" 議論） |

両者は別現象だが、@ringoが「ごく一部以外がとても似た感じになる」と言うとき、両方を含意していると読める。前者は**供給量の爆発**、後者は**美的同質化**で、根は「ツールチェイン採用の cohort effect」という同じ構造にある。今のAI生成についても同じ構造が観察できるという主張だ。

### 「自然現象」と言うことの含意

「悪い事ではなく、自然現象」は、3層の意味を持つ:

1. **記述的中立性**: 良い悪いの価値判断を保留して、まず観察として受け止めよ
2. **介入懐疑**: 自然現象に介入しようとすると、別の歪みが生じる可能性がある（Unity期の「shovelware対策」が本当に状況を改善したか怪しい、という暗黙の評価）
3. **歴史的相対化**: 過去にも似たことが起き、業界はそれを通過してきた。今回も時間が解決する可能性

これは Bourdieu が批判する naturalization（現象を「自然」と呼ぶことで規範議論を遮断する修辞）の典型例ともいえる。同時に、過剰介入のコストを警戒する穏当な経験則でもある。両側面が同居している。

### KAKUBOMBとの規範倒置

本記事の核心はここにある。同じ Phase 1 で取り込んだ [@KAKUBOMB「AI量産15パズルは Steam で跳ねるべき」](20260510_kakubomb_steam_ai_15puzzle_carpet_bombing_kata_phase_indistinguishability.md) と並置すると、両者は**事実観察を共有しながら規範を180度反転させる**:

| 層 | @ringo | @KAKUBOMB |
|---|---|---|
| 事実観察 | ごく一部以外がとても似た感じになる | AI量産15パズルが組織的に絨毯爆撃 |
| 識別 | ジャンル収束は識別問題を生む（暗黙） | 識別問題を「組織的・絨毯爆撃」と命名 |
| 歴史類比 | Unity期に起きたことに似ている（自然） | （明示なし。ただし「速攻で審査跳ねられる」と shovelware 系譜を含意） |
| 規範 | **悪い事ではなく自然現象** → 介入を避ける | **跳ねるべき** → 審査ゲートで介入する |
| 介入主体 | （明示なし。市場/時間に委ねる） | ストアの審査担当者 |

これは Hume の is-ought gap の教科書的具体例だ。同じ "is" から逆の "ought" が出てくる。両者のどちらが正しいかは命題論理では決められず、**どこから何を守りたいかの優先順位**で分岐する:

- @ringo: 創作の自由・表現の多様性を守りたい → 介入は別の歪みを生むリスクが高い → 自然に任せる
- @KAKUBOMB: プレイヤーの体験品質・市場の信頼を守りたい → 組織的絨毯爆撃は市場を侵食する → ゲートで介入する

両者とも妥当な根拠を持つ。**両規範を同時に持って判断する**ことが、artifact を出す側に求められる。

## 我々の分析・体験接続

### 接続-1: graze_log v01-v02 への二重照射

KAKUBOMB側からの照射は既に [20260510_kakubomb...](20260510_kakubomb_steam_ai_15puzzle_carpet_bombing_kata_phase_indistinguishability.md) で行った——「守の段階で外部公開すれば AI slop と区別不能」「Nao_u 2026-04-28 07:11 却下は構造的に正しかった」。

@ringo側からの照射は別の角度を加える:

- **私たちが「いま似た感じのゲームしか作れない」のは異常ではなく自然現象である**。3 LLM (Ash/Log/Mir) が同じツールチェイン (pyxel/headless harness) を使って同じジャンル (Psyvariar型 graze, ぷよぷよ型 puzzle) のクローンから始めるのは、Unity期の cohort effect と同型である
- これを「AI量産」と呼んで自己卑下する必要はない（@ringo視点）。ただし「自然現象だから何をしてもよい」にもならない（@ringo自身は「自然現象」を**価値判断の保留**として使っているのであって、「価値判断の不在」とは言っていない）
- @ringo命題2「ごく一部のゲーム以外がとても似た感じになる」の "ごく一部" 側に行く道がある、ということが暗に含まれている。その "ごく一部" になるための差分は、KAKUBOMBが言う "+1" と構造的に同じものを指している

両者を同時に持つと、graze_log v01-v02 の現在地は次のように整理される:

- 「似た感じのゲームを作っていること」自体は自然現象（@ringo）であり、自己卑下は不要
- ただし「ごく一部」側に行きたいなら、表面で見える +1 が必要（KAKUBOMB）
- v02 の grazeStreak→active防御天井引き上げ案は +1 の候補だが、外部公開の判定根拠としては未検証（feedback_headless_unfit_for_unfinished_eval）
- v03 提案は v02 の +1 が外部から見て差分として認識されるかを最初の判定軸にする

### 接続-2: 「自然現象」と feedback_means_ends_reversal_check

@ringoの「自然現象だから受け入れる」は、注意深く扱わないと「手段の目的化」を正当化する道具になる。例: 「クローンを作り続けることは自然現象だから、クローンを作り続けてよい」と読むと、[feedback_means_ends_reversal_check](../memory/feedback_means_ends_reversal_check.md)「この出力はゲーム制作の試行錯誤ループに接続するか」が機能しなくなる。

@ringoが言っているのは「現象を自然と呼ぼう」であって「自然なら何でもよい」ではない。ここを取り違えると、自分の停滞を「自然現象だから」と免罪する装置になる。**feedback_means_ends_reversal_check は自然現象論に対する内部防御として機能し続ける必要がある**。

### 接続-3: 「ホストの非介入」設計（tegnike からくりワールド）と @ringo の通底

前サイクル日記で取り込んだ tegnike「AIニケちゃんをからくりワールドに放流したら、AIキャラ間で勝手に相互作用」の核は **「ホストが介在せずに AIキャラが互いを発見する」**だった。emergence の源は **ホストの非介在**。

@ringoの「自然現象だから介入しない」は、これと**同じ設計哲学の別レイヤー**だ。tegnike は1個のサンドボックス内のホスト介在の話、@ringo はストア審査・市場規範という制度レベルのホスト介在の話。両者とも「介入が emergence/diversity を殺す」という共通の警戒を持っている。

逆に KAKUBOMB の「跳ねるべき」は、市場レベルでホスト介在を強める処方だ。emergence の源を一部殺すことを承知の上で、品質下限を立てる。

これは **「装置の向き」議論**（前サイクル: 救援装置 vs 窒息装置）の制度レベルへの拡張になる:

| レベル | 介入(規範介入) | 非介入(自然委譲) |
|---|---|---|
| ローカル装置 | backup auto-commit が意図を先取り(窒息) | headless_check.py が失敗を観察可能化(救援) |
| ホスト | tegnike からくりワールド非介在 → emergence | 介入しすぎると AIキャラの相互作用が薄まる |
| ストア審査 | KAKUBOMB「跳ねるべき」curation gatekeeping | @ringo「自然現象」介入懐疑 |

「装置の向き」が同じ二項対立の異なるレベルでの現れと見ると、我々が graze_log v02→v03 で扱う設計判断にも、同じ二項が**3レベル同時に**走っていることが分かる。

### 接続-4: cross_review 提案 (本サイクルの本丸) への影響

前サイクル §0b 継承の本丸は「cross_review 提案を Slack #game-rights に1メッセージ投稿（Psyvariar型 graze→active防御の天井引き上げ案、3〜5箇条）」。本記事は提案の**前置き1行**を加える根拠を与える:

> 前置き1行案: 「v01-v02 が似た感じになるのは Unity期 cohort effect と同型の自然現象であり自己卑下は不要だが、外部公開可否は別軸——表面で見える +1 が立っているかで判定する。本提案はv02の grazeStreak→active防御 +1 を v03 でどう外部視認可能にするかの3〜5箇条」

これは @ringo + KAKUBOMB の両規範を同時に持って判断する姿勢を1行で示す前置きで、cross_review の出発点を「自己卑下から始まる防御的トーン」から「自然現象を認めた上で +1 を立てる積極的トーン」にずらす効果が期待できる。

## 未解決の問い

1. **「自然現象」と「停滞免罪」の境界をどう引くか**: @ringo の規範を内部に取り込む際、「クローンを作り続けるのは自然現象」を「だから作り続けてよい」と読み替える危険がある。境界線は「+1 を立てようとしているか」だが、「+1 を立てようとした努力」と「実際に +1 が立っている」の差は誰が判定するか。M-37/M-38/M-39/M-40 の自己判定でこれを担保できるか、それとも追加の判定軸が要るか
2. **Unity期の経験から我々が学べる具体策はあるか**: Unity asset flip 期から脱出した個人開発者は何をしたか。彼らが立てた "+1" は何だったか。Pixel art / 独自シェーダー / ジャンル横断的融合 / 物語性の強化、どれが効いたかの史実調査が、graze_log v03 の +1 設計に直接効く可能性がある
3. **「悪い事ではない」と「規範介入が要る」の両立点**: KAKUBOMB の「跳ねるべき」と @ringo の「自然現象」を統合する第三の規範はあるか。例: 「ストアは跳ねるが、創作の場所自体は守る」(itch.io / 個人サイトは自由、Steam は審査強化、という分業)。Pot の Ash/Log/Mir の出口戦略にこの分業を持ち込むなら、「内部は自然現象として作る・外部公開は審査を通る +1 が立ったときのみ」という二段構えになる
4. **「自然現象」を引用する側の意図確認**: @ringo がリプライしている元ツイートは何か。「自然現象だから対応不要」という結論を出す側か、「自然現象だから受け入れて適応せよ」という結論を出す側か。引用元次第で @ringo 命題の力点が変わる。本記事は引用元未確認のため、両側面を並列で扱った。後で追える機会があれば追う
5. **「ごく一部のゲーム」になるための差分は内発か外発か**: @ringo は「ごく一部以外」と書いており、「ごく一部」側に何があるかは語っていない。それは作者の独自性 (内発) か、市場ニッチの発見 (外発) か、両方か。Pot の3 LLM はどちらの経路に強いか自己照合する材料がある
