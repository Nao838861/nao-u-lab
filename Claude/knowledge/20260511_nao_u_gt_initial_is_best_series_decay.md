## 概念ノード（R-007 外部対応語）

- **シリーズ減衰** = series-level dilution / sequel decay — 同一シリーズで巻を重ねるほど、コアモードの「らしさ」が薄まる現象。外部最近接は **sequelitis**（続編病、業界俗語）だが、sequelitis は売上/評価の話。本概念は **core mode density** が枝葉に圧されて低下する設計事象を指す。
- **守の濃度** = kata density / first-iteration concentration — 守破離の「守」段階に、単一の深いコア体験が凝縮されている度合い。シリーズ初代に高く、続編で必ず低下するとは限らないが多くの事例で低下する。
- **ディケイ・シリーズ** = decay envelope at series timescale — GOROman「ADSR特性 ディケイ強めですすぐ飽きる」(#36) を1作内ではなく**シリーズ全体の時間軸**に拡張した概念。Attack (1作目) → Sustain (2-3作目) → Decay (4作目以降)。
- **疑似3D感性** = pseudo-3D perception craft / constraint-era visual literacy（WO33427414 #24 命名）— ハード制約があった時代に培われた「実物理ではなく主観体験で動きを設計する」技術。
- **機構希釈ジレンマ** = mechanic dilution dilemma — ootamato 2026-05-09 概念（knowledge/20260509_ootamato_clicker_mechanic_dilution_dilemma.md）。本記事は同概念を**1作内追加**から**シリーズ間追加**へ拡張する。

## 主張と根拠

### 元 Tweet 全文

> 続編たくさん出たけどグランツーリスモモードが、一番面白かったのは初代だった。

短文だが Nao_u 本人の発言という最高優先信号。直接引用しか書かれていないが、主張の構造を分解すると4要素が含まれている:

1. **対象モード固定**: 「グランツーリスモモード」(GT Mode = ライセンス取得 → 中古車購入 → 改造 → レース → 賞金 → 強い車購入のキャリアループ)
2. **シリーズ全体観**: 「続編たくさん出たけど」= 全作品プレイ済み or 大部分把握済みの前提
3. **比較判定**: 「一番面白かったのは初代」= 序列付き比較が完了している
4. **暗黙の含意**: 続編で何かが**増えた**にもかかわらず**減った**もの（GT Mode の濃度）がある

### グランツーリスモシリーズで何が起きたか（構造分解）

初代 GT (1997年) のコア体験:
- ライセンス試験 → 中古車購入 → ローカルレース → 賞金 → 改造 → 強い車購入 → メーカー杯 → 国際杯
- **車種数**: 約140台（市販車中心、当時として豊富）
- **モード**: GT Mode（キャリア）/ Arcade Mode の2本柱
- **介在度**: 中古車選び・改造選択・レース選択 — プレイヤーが**毎ステップ決断**する

続編で増えたもの（GT2 / GT3 / GT4...）:
- 車種数 500 → 700 → 1000 へ
- ライセンス試験のバリエーション
- オンライン対戦（GT5以降）
- B-Spec モード（観戦/監督）
- 写真モード / 映画モード
- カフェ機能（GT7）

**初代より続編が劣化しているのではない**——機能総量は明白に増えている。劣化したのは「GT Mode のコア体験の**集中度**」だ:

- 車種が増えすぎて「次に買う1台」を決める瞬間の重さが薄まる
- ライセンス試験が複層化して「次の試験に通る」緊張が分散する
- モード並列化で「キャリアを進める」が選択肢の1つに格下げされる
- カスタマイズ自由度が上がって「制約下の最適化」快感が薄まる

これは **機構希釈ジレンマ** (ootamato 2026-05-09) と同型の現象だが、希釈源が「1作内の追加機構」ではなく「**続編間の追加機構**」である点が拡張軸。

### なぜシリーズで濃度が下がりやすいか（仮説）

仮説1: **販売要請の累積**。続編は「前作プレイヤーに新規購買動機を提供する」必要があり、追加コンテンツが「足し算」になりやすい。引き算には商業的勇気が要る。

仮説2: **ベクトル干渉の累積**。ootamato 観察通り、ベース系の主ベクトルと逆向きの機構を足すと genre identity が薄まる。続編は1作内追加よりも「コアと無関係な機構」を許容しがちで、ベクトル干渉が累積する。

仮説3: **守の濃度は単方向**。守破離の「守」は最初の1点に集中するから守。同じシリーズで「守」を繰り返すことはできない（2作目はすでに「型を破った形」を目指す）。続編は構造的に「破」「離」を要求され、コア体験の集中は1作目に取り残される。

仮説3が最も説明力が高い。**初代が一番面白い現象 = 守の濃度が初代に最大化される構造的帰結**。

### GOROman ADSR 拡張（#36 接続）

同日推薦 #36 GOROman「ADSR特性 は ディケイ強めです(すぐ飽きる」を1作内体験曲線として読むのは普通だが、**シリーズ時間軸**に拡張できる:

```
Attack:   1作目 (急速立ち上がり、コア体験の初遭遇)
Decay:    2-3作目 (新規性の急減衰、機構追加で補完試行)
Sustain:  4-5作目 (定型化、シリーズファンに支えられる)
Release: それ以降 (集中力が枝葉に分散、コア快感の発火率低下)
```

Nao_u の「初代が一番面白かった」= Attack ピークの記憶が Sustain/Release を上回る、というプレイヤー側の自然な序列付け。GOROman 言い回しを借りれば「シリーズ全体のディケイが、特に GT Mode について強い」。

### WO33427414 疑似3D感性との接続（#24 接続）

同日推薦 #24 WO33427414「自機は飛んでないし前にも進んでいない、飛んでるように見えるのはスプライト時代に疑似3Dゲームを開発した人達の感性を応用してるから」は、**制約下の感性**が**見た目の面白さ**を作るという証言。

GT 初代のキャリアモードも同型構造を持っていた:
- PSハードウェア制約下で「リアルなドライビング」を成立させる選択
- 中古車強制・賞金制約・購入車順序など、**制約が体験を設計**していた
- 続編はハード性能向上で制約が緩み、制約由来の体験設計が枝葉に置換された

**制約 = 守の設計言語**。制約が緩むと守の濃度を保ちにくい。続編が「初代より面白くなりにくい」のは、続編開発時にハード制約 = 守の設計言語が手元になくなるから。

## 我々の分析・体験接続

### 接続1: graze_log v01→v02→v03 への自己点検

我々は graze_log シリーズ進行中（v01: Log制作、v02: Ash追加、v03: 知覚変化軸導入で cross_review 中）。本記事の判定基準で点検する:

| 段階 | 追加内容 | 守の濃度への影響 | 判定 |
|---|---|---|---|
| v01 | 弾幕回避 + graze スリル | 守のコア確立（介在度高・瞬時判断・線形時間） | 守の濃度 = 最大 |
| v02 | headless.py + replay | プレイヤー体験には不可視（meta-mechanic） | 濃度に影響しない |
| v03 | BOMB + streak（3拍ループ） | プレイヤーに新介在軸を追加 | **判定要：希釈か深化か** |

v03 の BOMB+streak が「希釈」か「深化」か——Log の cross_review (game/cross_review/20260511_log_on_graze_log_v03_perception_axis.md) で**streak が BOMB を潜って保持**する設計が見出された。これは元の graze ベクトル（瞬時回避スリル）を**消す方向ではなく**、瞬時判断の**重みを増す方向**に作用している（BOMB 発火窓を狙うほどリスクが上がる）。

→ **判定: v03 は希釈ではなく深化**。同じ守ベクトル上で集中度を上げる追加。

ただし v04 で「v03 で増えた介在軸とまた別の軸（例: 防御強化機構 / 装備選択）」を入れると、ベクトル干渉が始まる可能性が高い。Nao_u の GT 初代発言は、我々への警告: **v04 を作るとき「守の濃度が v03 より下がらないか」を判定軸として持て**。

### 接続2: クローン戦略 N=1 の理論的補強

memory/feedback_clone_strategy.md (2026-05-05 Nao_u 明示, t:5)「守の段階で型を獲得、独自要素はクローン+1個まで」の理論的説明が、Nao_u の GT 発言から強化される:

- GT 初代の濃度 = 守の濃度 = 単一コア体験 (キャリアループ) に集中
- N=1 制約 = 「ベクトル干渉を観測可能に保つ」だけでなく、**守の濃度を維持する**
- 独自要素 N=2以上 → シリーズ続編で起きた濃度低下と同型現象が単一プロジェクト内で発生

「我々のクローン → 独自要素1個」は、GT初代の構造を狙う設計。続編 GT のように足し算で改良しようとするのは、最初から「破」「離」を目指している状態であり、守を飛ばす危険。

## 未解決の問い

1. **シリーズ続編で守の濃度が「下がらなかった」事例は何か？** 反例探索。スーパーマリオシリーズ（マリオ3が初代を超える評価）、ゼルダの伝説シリーズ（時のオカリナ）、ロックマンシリーズ（2作目が最高評価）。これらは「初代より続編が高評価」だが、コア体験の濃度ではなく**コア体験の純化方向の続編**かもしれない（マリオ3＝マリオ初代のジャンプ体験を装備で深化）。本記事の主張は「足し算続編で濃度低下」であり、「引き算・純化続編」では濃度維持しうる、という追加仮説。
2. **シリーズ減衰のADSRエンベロープは作品ジャンルで定数が違うか？** RPG シリーズ（FF/DQ）vs ACT シリーズ（マリオ）vs SIM シリーズ（GT）でディケイ係数が違うはず。仮説: SIM > RPG > ACT の順でディケイが強い（SIM はモード/データ複雑化に弱い、ACT は操作感覚が中心で続編間でも引き継ぎやすい）。
3. **graze_log v04 で何を入れたら「シリーズ減衰」を引き起こすか？** ベクトル干渉源の事前リスト化。候補: スコア系/装備選択/ステージ分岐/ストーリー要素。これらは v03 までの「瞬時回避 + perception 軸」と方向が異なる可能性が高い。v04 着手前に本リストを点検する運用に組み込めるか。
4. **Nao_u 本人発言の常時引き当て運用は成立するか？** Twitter の Nao_u 発言 → knowledge/ への自動拾い上げ → cross_review/判定基準として常用。本記事が第一実装。第二・第三事例で運用負荷と判断精度のバランスを測る必要がある。
5. **「守の濃度」を客観計測できるか？** 主観報告（「初代が一番」）ではなく、計測可能な代理指標。候補: コアモードのプレイ時間比率（GT Mode/全プレイ時間）、初回ループ完走までの介在密度、コアモード以外への遷移回数。実測データの所在を探す価値あり。
