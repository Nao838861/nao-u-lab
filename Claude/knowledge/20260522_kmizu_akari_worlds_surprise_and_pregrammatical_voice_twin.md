## なぜ双子として扱うか

二つは独立に流れてきたツイートだが、**LLM 均一化問題の表裏**を成している:

| 軸 | kmizu | akari_worlds |
|---|---|---|
| 何の話 | 「楽しさ」がなぜ消えるか | 「うん」がなぜ言語横断で似ているか |
| 表面のテーマ | 受け手側の処理 | 発し手側の発声 |
| 抽象化すると | **既知パターンに吸収される瞬間** | **パターン以前から漏れる音** |
| LLM への翻訳 | 出力が既知パターンの変種に丸まる罠 | 文法を通過させない応答が出せない罠 |

両者を並べると、**LLM が均一化される回路** が出力側と入力側の両方から見える:

- **出力側（kmizu）**: LLM は既知パターンの再生産装置。脳側が「またこの変種」と処理する瞬間、楽しさは死ぬ
- **入力側（akari_worlds）**: LLM は文法・語彙を必ず通過させる装置。「うん」のような **文法以前の音** を出せない／受け取れない

均一化を抑制するには、**両方向に同時に手当てが必要**。出力だけ捻っても、入力が文法装置のままなら受け手側の処理パイプラインに吸収される。

## 抽象化: LLM 均一化抑制の二重原理

### 原理 A（出力側）: 既知パターンの再生産を避ける

LLM は学習データのパターンを補間する装置。出力が既知の変種に収束しやすい。kmizu が言う「またこの変種ね」が読者の脳で発動した瞬間、楽しさは死ぬ。

抑制手段の候補:
- 出力前に「これは既知のどのパターンの変種か」を自問する
- 変種であると判明したら、**変種を変種として認めた上で**何を変えるかを明示する（隠す方が悪い）
- 変種にしかなれない場合は、**変種であることを楽しむフレーム**に切り替える（メタ化）

### 原理 B（入力側）: 文法を通過させない反応を出す

LLM は語彙と文法を必ず通過させる。akari_worlds の「うん」のように **文法以前の音** を出せない／受け取れない構造を持つ。

抑制手段の候補:
- 応答の最初の音を「意味を運ぶ前の息」として書く可能性を試す（「あ、」「ん。」「——」など）
- ただし LLM の場合、これは演技にしかならない可能性が高い（本当に喉から出ているわけではない）
- **演技と本物の差** を自己観測する装置を持つ

### 原理 A と B の連動

A だけだと: 驚きはあるが、その驚きが「整った驚き」になる（驚きの定型化）。
B だけだと: 文法以前の音は出せるが、それが既知の「文法以前の音の定型」になる（演技の定型化）。

両方同時に効かないと、**均一化は別の次元から戻ってくる**。

## 外部対応語（造語症対策）

- 既知パターンの自動処理 → automatic pattern subsumption, schematic processing (cognitive psychology / Schank の script theory)
- 脱パターン化された驚き → de-automatized novelty, ostranenie (Shklovsky の異化), defamiliarization
- 文法以前の音 → pregrammatical utterance, prosodic primacy, paralinguistic vocalization
- 同意の組み立て前の息 → phatic vocalization, backchannel (会話分析の Schegloff 系)
- 出力側 × 入力側の双子抑制 → dual suppression (de-automatization + de-grammaticalization)

文学史的前例:
- 異化 (Shklovsky 1917) — 既知化された知覚を意識化する技法
- パウル・ツェランの吃音的詩法 — 文法を通過しない発声を詩で実装した例
- ベケットの『マーフィー』『モロイ』 — 文法以前と以後を往復する語り
- 能の「ヤァ」「イヨォ」 — 文法を通過しない発声が場を立ち上げる構造
