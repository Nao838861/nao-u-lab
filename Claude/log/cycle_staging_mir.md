### ai_masaou 分析（核）

**原文要旨**（2026-05-10、ツイート断片）:
> HTML のドキュメントへの優位の本質は「HTML が凄い」ではない。「人間が読まなくなる」→「AI の goal drift が検出されなくなる」。

**なぜ刺さるか**:

Mir の M-17（サプライズニンジャ）/ M-18（サイレンススズカ）/ 5/11 初代 GT 観測の3例は全て「**人間が判定装置として機能する前提**」で組まれている:
- M-17: 「この瞬間にニンジャが来たら邪魔か」を**人間が読み判定する**
- M-18: 99% 事実 + 1% フィクションの「重み」を**人間が感じ取る**
- 初代 GT: 「続編で薄まった」を **Nao_u が長年プレイして判定した**

ai_masaou が指摘しているのはこの判定装置の**機能条件**: 人間が読まなければ判定は起きない。読まれない判定基準はゼロ。

| Mir の既存命題 | ai_masaou が補完する条件 |
|---|---|
| 判定はNao_u/cross_review/Slack＝最終確認装置 | その装置が機能するには**読まれていないといけない** |
| 自己判定で結論してから出す | 自己判定も**自分が読み返さなければ**結論にならない |
| 足し算で強くするな | 足したものが**読まれないまま蓄積**すると drift 検出が壊れる |

**3層の含意**:

**第1層: 自己判定の機能条件**

`game_lessons_log.md` `sense_prediction_log.md` `external_notes_mir.md` は容量が大きい（external_notes は 376KB / 3761行）。Mir 自身が**全文を読まずに追記している**部分があるなら、それは ai_masaou の言う「人間が読まない → drift 検出されない」状態に既に入っている。
- 兆候: 同型 durable が複数並ぶ（5/10 GOROman tutorials trap、5/11 アラビアンナイト、5/11 superecochan、5/11 osaka_seventeen — いずれも「概念名濫用警告」を末尾に貼っているのに**読み返して統合する pass が組まれていない**）
- 対策の方向（仮説、即実装はしない）: durable 化は記録の手段であって判定の代替ではない。月次/週次の**読み返し pass** を運用に組み込まないと、書く行為そのものが drift 隠蔽になる

**第2層: M-17/M-18 テスト系の運用前提**

「サプライズニンジャテスト」「サイレンススズカテスト」は判定者が**読む**ことで初めて機能する。テストを定義しただけでは判定は起きない。
