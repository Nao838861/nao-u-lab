### 検出して修正した詰まり（3件、いずれも C167 差分内の wiring 抜け）

1. **SyntaxError（致命的）** game.py:831
   - `print("    店員供述: 『修平さんは"姉のところに寄る"と言って店を出ていきました』")` で ASCII 二重引用符が外側の `"..."` を破壊
   - 修正: 内側を日本語鉤括弧 `「...」` に置換（外側 `『...』` と階層整合）
   - 影響: そもそもファイルが import 不能。C167 commit 前に気づくべき初歩ミス

2. **main() の dispatch 抜け** game.py:1016 周辺
   - sequel_2_evidence は `next_subject = "物証・固め"` を返すが、main() に対応 elif がなく、第3セット物証・固めパスは**到達不能**だった
   - C167 ヘッダコメントに「セット3 三分岐そろい完了」と書いていたが、**実態は嘘**だった
   - 修正: `elif next_subject == "物証・固め":` 分岐を追加し scene_3_evidence_lock + sequel_3_evidence_lock + chapter_hook_3 を呼び出す

3. **chapter_hook_3 の文章分岐抜け** game.py:969 周辺
   - sequel_3_evidence_lock が返す `"物証同席"` / `"詩織の沈黙待ち"` のどちらも条件に該当せず、else 節「修平召喚への切替」テキストにフォールバックしていた
   - 修正: 該当する 2 ブランチを追加
