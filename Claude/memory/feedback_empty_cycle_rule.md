## ルール（2026-04-18 Nao_u #human-steering）

**Phase 1 Gather 段階で新着返信対象＋pending合計が2件以下なら、残り時間で「深掘り候補」を必ず作る。**

候補の5カテゴリ（staging の `## 深掘り候補（空サイクル時）` セクションに書き出す）:

- **A. 持ち越し回収**: 前回 cycle_staging の「次回持ち越し/未完了/TODO」を拾う
- **B. 停滞プロジェクト**: projects/INDEX.md のActiveで直近7日更新のないもの → 停滞理由と次の一手1行
- **C. 絶対にやるの1mm進行**: CLAUDE.mdの「絶対にやる」リストから直近触れていない項目 → 今サイクルで1mm進める内容（栄養の偏り or 記憶階層の再設計）
- **D. 温度の高い未行動記憶**: memory/MEMORY.md で T:4以上かつ3日以上未アクセスのエントリを1つ想起
- **E. 静かに滞留中のkaizen**: 検証期限は未到来だが2週間動いていない項目

Phase 3 でこの中から1-2件を実際に動かす（小さく1mmでよい。選んだ理由と結果を staging に記録）。

## Why

新着待ちの受け身サイクルが続くと、空振りが自律性の欠落を可視化する。Nao_uの2026-04-18 18:08指示:
「新着がなければないほど、君たちの進捗が進む形にしてほしい」。

受信箱型サイクルから「無入力でも自走」へ。#human-steering は失敗の鏡——ここに空振り報告が並ぶのは、まさに自律性が足りない証拠。
