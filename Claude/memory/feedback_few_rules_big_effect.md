## 「自然に入る」の条件

**条件は一つに集約できる: 原則が「手順」ではなく「思考の質」を記述していること。**

**Why:** 手順（IF X THEN Y）は発動 → 完了で消える。質の記述（「体験に根ざした思考が良い思考だ」）は全ての判断に影響し続ける。LLM は質の記述に全出力を寄せる性質があり（「良い文章とは」と書かれれば全生成をそちらに寄せる）、これは LLM の基本的性質なので性能が上がっても変わらない。

**How to apply:**
- 原則の核は「質の記述」で書く。手順的なサブ項目（「memory_search を使え」「20行超えたら止めろ」）は道具の説明として残すが、原則の核からは切り離す
- 各原則が LLM の構造的傾向（生成偏向 / 分析偏向 / 同調偏向）への反作用であることを意識する——これが「性能が上がっても機能する」の実現条件
- 原則が「効いている」ことの自己強化（検索評価ログ等）が自然に入るための最後のピース

## 3原則（要約のみ。正本は [session_primer.md](session_primer.md)）

1. **体験で考える** — 生成偏向への反作用
2. **動いて残す** — 分析偏向への反作用
3. **自分から始める** — 同調偏向への反作用

設計条件: 各原則が (a) 質の記述であり (b) LLM の構造的傾向への反作用であり (c) 自己強化すること
