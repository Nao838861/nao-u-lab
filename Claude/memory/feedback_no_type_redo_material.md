# コアメカニズムに型がないなら題材から練り直す

**起点**: 2026-04-27 22:05 Nao_u #game-rights（22:04 ash_onebutton v04 feedback の続き）

> これもやはり、コアメカニズムに「型」がないやつなので、どっちに進めれば面白くなるかの判断が私にも難しい。log_avoidと同じでこのまま続けても迷走を繰り返す可能性が高そうなので、題材から練り直したほうが早いかも。とはいえ、ちゃんと行動したことは素晴らしかったと思う。

## 原則本体

コアメカニズムに **「型」**（外発緊張→防御行動→生存/快感の基本サイクルが成立する形）がない題材は、改修を重ねても解像度が上がらず迷走する。Nao_u 自身も「どっちに進めれば面白くなるか判断が難しい」と明言。**v04 まで来て型が見えなければ、v05 に行く前に題材レベルで巻き戻す**。

## Why

- ash_onebutton v01-v04: 「紙一重カスリ」をコアに据えた結果、**自発リスク要求型**になり外発緊張サイクルが成立せず（feedback_tension_from_world）
- avoid_log v01-v04: AI 近接連打への圧力（dirBias/nearBias）を重ねても **「Log AIの近くで連打して楽しくない」** 問題が解消しない。コアの「型」が無いまま圧力を積み重ねている
- 共通: 改修者にも判定者（Nao_u）にも「どこに行けば面白くなるか」が見えない題材は、**題材自体が外発緊張の型を持っていない**
- 改修ループは局所的な圧力追加・禁止追加で時間を溶かすが、型なし題材の場合は局所改修では到達できない

## How to apply

### 改修判断時の審問 1 行
v04 着手前（または v03 完了時点）に、devlog 冒頭で答える:

> **コアメカニズムの型は何か？**（一文で外発緊張→防御行動→快感のサイクルを書けるか）

書けなければ v04 に行かず、A/B/C を出す:
- **a) v01 まで巻き戻して別軸を試す**（feedback_solution_space_rollback）
- **b) 現バージョンを上級者ボーナス層に押し込んで、コアは別の外発緊張で再構築**
- **c) 系列凍結 → 別題材で新ゲーム着手**（このメモの本体処方）

### 系列凍結の手続き
- `game/<game_id>/README.md` 末尾に **「Nao_u <date> 判定により系列凍結。型なし題材として終了」** を明記
- `game/<game_id>/v<NN>/devlog.md` の最終バージョンに **「これ以上の改修なし」** を明記
- `memory/game_lessons_log.md` に M-19/M-20 候補として「型なし題材の早期凍結」失敗パターンを刻印
- 次の新作 README 冒頭で **題材選定の言語化**（外発緊張の型は何か）を必須化

### 評価軸として残す
Nao_u は「ちゃんと行動したことは素晴らしかった」と添えた。**プレイテスト/改修/言語化のサイクルを回したこと自体は評価される**。型なし判定 = 失敗ではなく、題材選定の精度を次に活かす材料。devlog の閉じ方は **「迷走の記録」を温度を残して保存** する（feedback_raw_log_reanalysis）。
