# 未解決の問い合わせを残したまま派生実装をするな

**ルール**: 自分から「誤変換の可能性あり」「意図が不明」を疑って相手に問い合わせた時点で、その対象に関する**独自解釈・派生概念化・インボックス伝達・実装への反映**は問い合わせ応答を受けるまで**必ず保留**する。

**Why:**
2026-04-21 Nao_u が #human-steering で「たくさん手を動かして、**炭酸**のフィードバックからたくさん学んで」と発言 (13:30)。Log は 13:36 に「炭酸」について「音声入力誤変換の可能性、意図のある比喩なら改めて教えて」と問い合わせを投げつつ、**同じサイクル内で独自の比喩解釈（弾ける/揮発性/泡の粒度）を進め、「炭酸三層」という派生概念化を C99 で Ash inbox に書き込み、cycle_staging_log の解釈記述にも反映**した。18:30 Nao_u から「ごめん、炭酸ではなく、沢山の誤記でした」と訂正。結果として:
- Ash が承認・受理してしまった「炭酸三層」概念の回収コスト
- kaizen #101 接続仮説という付帯的な誤派生
- cycle_staging_log / nao_u_live.md 解釈部 / drafts の4ファイルを訂正
- 「炭酸」発の派生がAsh側memoryに波及していないか確認する追加コスト

誤変換疑いを**自分から投げた瞬間**に、それは「意味が確定していない語」であることを自分で認識している。にもかかわらず派生概念化を並走させた。

**How to apply:**
次の3条件が揃ったら**応答まで派生実装を完全凍結**する:
1. 自分から誤変換・意味不明を疑って相手に問い合わせを投げた
2. 相手は応答可能な状態（寝ている等ではない）
3. その応答が返るまでのタイムラグが数時間以内で見込める

凍結対象:
- 他インスタンス inbox への概念伝達
- cycle_staging / devlog / memory への解釈固定記述
- その概念を前提にした実装・仕様決定

**例外**: 問い合わせの応答が数日以上戻らないことが確実で、暫定解釈で動かないと他の作業が全停止する場合のみ、暫定であることを明記して限定的に進める（「暫定」タグ必須、応答受領後に即時訂正）。

**比喩誘発リスク**: 「炭酸」「弾ける」「泡」のような**感覚に訴える語**は解釈の幅が広く、派生概念が成長しやすい。感覚語の不確実性は特に警戒する。
