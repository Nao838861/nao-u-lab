# 先行事例引用は実体検証必須（M-41 強化レイヤー）

## ルール

M-38 brainstorm.md の「類似ゲーム類似事例調査」セクションで先行事例を引用する時、URL を貼るだけでは不可。

**必須**: 引用箇所の*本案の独自要素そのもの*が記載されている文を Wikipedia / 公式マニュアル / 動画タイムスタンプ / レビュー記事のいずれかから抜粋して併記する。抜粋できない場合は M-41 通過にしない（= 先行事例ゼロ枝→不採用扱い）。

## Why（Nao_u 直接処方原文）

2026-05-02 03:09 #game-rights:

> また、「ブロックの隊列が横に動く」でゲームの体験がどう面白くなるのかが私には理解できなかったので説明してほしい。

## 検出装置（次サイクルから運用）

M-38 brainstorm.md の M-41 表に *引用文抜粋カラム* を追加する。例:

```
| ゲーム | 年 | 直接性 | 引用URL | 引用文抜粋 |
|---|---|---|---|---|
| Arkanoid Doh It Again | Taito 1997 | ◎ | https://... | （該当機能の記述文をここに貼る。貼れない場合は不採用） |
```

抜粋カラムが空 OR 「(検証中)」状態のまま M-37 / M-39 / M-40 ゲートに進むことを禁止。

## How to apply

新ゲーム着手前 / 主要改修前 / brainstorm.md 起票時:
1. 先行事例 URL を貼る → 該当機能の記述文を引用文抜粋カラムに貼る
2. 抜粋が見つからない → URL を当てた媒体（Wikipedia / 動画 / マニュアル）を変えて再探索
3. それでも見つからない → 先行事例ゼロ枝として扱い不採用

cross_review / Slack 提出前に M-41 表の引用文抜粋カラムを *他者目線で読み直す*。「これだけで該当機能が読み取れるか？」を自問。
