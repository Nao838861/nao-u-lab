# 敵弾を資源化するとコアサイクルが崩壊する

**起点**: 2026-04-27 22:59 Nao_u #human-steering siphon_mir v01 フィードバック

> ゲージが増える一方で駆け引きはなく、脅威になるはずの弾もむしろアイテムみたいなものになっていてリスクは極めて低く、むしろ弾を撃つ敵は倒さない方がパワーアップアイテムを大量に吐いてくれるのでよい、みたいな本末転倒まである。

## 原則本体

STGにおいて敵弾は「脅威」であることがコアサイクル（弾が怖い→避ける/撃つ→生存快感）の前提。敵弾を**資源化**するメカニクスをコアに据えると:

1. 弾の脅威性が蒸発 → 外発緊張が消える（feedback_tension_from_world）
2. 弾が飛んでくる = 嬉しい → 弾を撃つ敵は倒さない方が得 → **本末転倒**
3. パワーアップは増える一方で**駆け引きがない** → サイクルが拡散して崩壊

## avoid_log（Logの磁石）との同型性

| | avoid_log | SIPHON |
|---|---|---|
| 構造 | 磁力場に近づく動機がない | 弾を怖がる理由がない |
| 結果 | コアメカの圧力源が存在しない | コアメカが脅威を消す方向に働く |
| 共通 | **コアサイクルが自己矛盾** | 同左 |

## 罰で調整するな（快感を減らす方向の改修禁止）

> クールダウン延長とパルス半径縮小は、程よい調整が必要な要素だし絶対にダメとは言わないが、どちらもプレイヤーを罰する方向で、快感は減る。このタイミングで快感を減らす方向にシフトすると、何が楽しいのかわからないゲームになりそう。

サイクル崩壊に対して「快感を減らして圧力を上げる」は対処療法であって解決ではない。M-11「問題を潰す改修は対処療法の積み重ね」の具体例。

## 方向性の選択が必要

Nao_u提示の4方向:
- **(a) 普通のSTG + ボム**: 弾は脅威のまま、吸収はボム溜め手段に限定
- **(b) 斑鳩型コアルール**: 属性切替のような二面性をゲーム全体に浸透
- **(c) STGサブ要素**: 基本は普通のSTG、上級者向けスコアアタック手段
- **(d) STG捨て**: Every Extend Extra等、弾吸収ベースの別ジャンル

**選択前に「美しいプレイの理想像」を書け。**
