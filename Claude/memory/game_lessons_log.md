# ゲーム制作教訓 (M-xx) INDEX

**位置づけ**: ゲーム開発タスク（新作着手 / 改修判断 / cross_review / Nao_u 評価受領）で本ファイルを起点に該当 M-XX を引く。本体は `memory/lessons/M-XX.md` に分割済み。系統マップ→ID 想起ハーネスは `skills/lessons-recall/SKILL.md`。**起源・段階別経緯は本ファイル末尾「歴史」節。**

## LLM 向け使い方

1. **ゲーム開発タスク (新作着手 / 改修判断 / cross_review / Nao_u 評価受領) で本ファイルを読み込む**
2. 各行のサマリは **太字キーワード + 核 + 処方** の3パート構成。文脈に合致するキーワードでスキャン → サマリで「開く価値ありか」判定
3. 該当 M-XX のみ `memory/lessons/M-XX.md` を読む（全件は読まない）
4. **新規エントリ追加時**: (a) 本表に1行追加 (b) `memory/lessons/M-XX.md` 作成 (c) 重複ID 禁止、後発刻印を次番号にリネーム
5. **本文の参照スタイル**: `[M-22](M-22.md)` 形式リンク（段階5 で全本文一括変換済）。LLM はリンクをトリガーに連鎖読み
6. **想起ハーネス**: 判断手前に `skills/lessons-recall/SKILL.md` を起動。系統マップから関連 ID を3秒で引く構造。Q-A〜H シート / brainstorm.md / cross_review コメント記入時に並行起動
