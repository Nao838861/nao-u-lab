# ミステリゲームメカニクス進化史 — 設計パターンの抽出

**出典**: 遊星歯車機関「正解に三つの鐘が鳴る――プレイヤーを名探偵にするメカニクスについて」(note)
**URL**: https://note.com/planetary_gear/n/nd75f0dd32f06

## 核心パターン: 強制判定の段階的緩和

ジャンルに内在する「プレイヤー能力を超える強制判定」に対し、各世代が1つの設計装置で突破する系譜。

| 作品 | 装置 | 本質 |
|---|---|---|
| かまいたちの夜 | 繰り返しプレイ | 試行回数で能力差を吸収 |
| 逆転裁判 | 矛盾指摘のみ | 判定対象の極小化 |
| Return of the Obra Dinn | 3人1組正解 | 部分正解の許容 |
| The Case of the Golden Idol | 2D化 | 探索負荷の削減 |
| Roottrees Dead / Type Help | テキスト検索 | 外部ツールの正規化 |

記事はこの進化を「甘い犯罪」と呼ぶ — 不完全さを認めて装置で覆う。

## R-A / R-D との直接接続

- **R-A 実証**: 逆転裁判 = 「矛盾を指摘する瞬間だけが楽しいなら、そこだけ残す」。不要な工程を削ることが設計。
- **R-D 実証**: 全作品が前世代の型を継承して1点だけ変えている。型なしの飛躍は系譜に存在しない。

## 障壁分類（汎用診断道具）

プレイヤーが詰まる障壁を4種に分類。ジャンル不問で使える:

| 障壁 | 内容 | 処方 |
|---|---|---|
| (1) 能力障壁 | 推理力/反射神経が足りない | 判定対象を絞る（逆転裁判式） |
| (2) 探索障壁 | 情報を見つけるコストが高い | 探索空間を狭める（Golden Idol式） |
| (3) 判定障壁 | 正解/不正解の判定が厳しい | 部分正解を許す（Obra Dinn式） |
| (4) 試行障壁 | やり直しコストが高い | 試行回数を安価に（かまいたち式） |

## 次に作る時の使い方

1. プレイテストで「ここで詰まる」場面を (1)-(4) で分類
2. 対応する処方を検討
3. 処方が核体験を強化するか確認（R-A チェック）
4. 処方が型の継承+1点改善になっているか確認（R-D チェック）
