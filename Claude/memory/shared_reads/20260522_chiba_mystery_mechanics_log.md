## 何が書かれているか

ミステリゲームの設計史を「プレイヤーを名探偵にするためにどうメカニクスを設計したか」の系譜批評。坂口安吾・S.S.ヴァン=ダインの「推理小説はゲーム/スポーツ」論を出発点に、小説 → 西洋ゲーム → インディーへの 7 作品の固有設計を腑分け。

### 中核 2 軸 (理解度チェックの設計要素)

(a) **答え合わせのタイミング** — 進行を細かく区切るほどフィードバックは増えるが総当たり攻略が容易になる
(b) **総当たり防止** — 選択肢を増やすことで合理的思考を強制する

この 2 軸はトレードオフ。各作品が異なるバランス点を取っている。

### 7 作品の固有設計

1. **『かまいたちの夜』(1994)** — 試行錯誤の中で True End に到達することが理解度チェックのメタ設計。「複数回プレイで初めて名探偵」体験構造。
2. **『TRICKxLOGIC』** — 「キーワード → ナゾ → ヒラメキ」三段階アイテム連結。
3. **『逆転裁判』(2001)** — 「一から十までの論証」要求を放棄、矛盾指摘だけに絞った設計。証言者ごとのトピック明示で思考領域を狭める。
4. **『Return of the Obra Dinn』(2018)** — 3 人ごと答え合わせのロック・イン + 複数正解の許容 + 手続き厳密性を捨てる「ゆるさ」の戦略的活用。
5. **『The Case of the Golden Idol』(2022)** — 3D→2D で探索負荷を切り捨て、章制で細分化、「誤り 1〜2 個」表示 (ニアピン賞) でプレイ継続性確保。1 年半開発。
6. **『The Roottrees are Dead』** — キーワード検索 DB + Obra Dinn 人物特定の融合。〈直感〉システム = 未発見資料リンク数表示でガイド付きオープン探索。
7. **『Type Help』** — テキストのみ「時間帯 × 場所 × 人物番号」組み合わせ入力、同時刻人物位置矛盾を自動難易度調整に。

### 結論 = 「人間の不完全さを受け入れる設計」への収斂

厳密判定 (逆転裁判初期) → 部分一致許容 (Obra Dinn 複数正解) → 誤り個数表示 (Golden Idol) → 探索ガイド (Roottrees)。**プレイヤーの認知限界をシステム側がどこまで吸収するか**が進化軸。

## STG/Pot 設計への適用

### 転用できる (構造同型)

- **「答え合わせのタイミング × 総当たり防止」二軸** = `drafts/headless_evaluation_format_v01.md §5` の 3 層対応表と構造一致。早いフィードバック (層 1 ヘッドレス) vs 遅いが本質 (層 3 Nao_u) のトレードオフはミステリ側 2 軸と同型 → **第 5 源独立収束** (Talakat 2018 / PCG Benchmark / AI Gamestore / 37%ギャップ に追加)
- **ニアピン賞 (Golden Idol)** = STG/`graze_log` で 0/1 でなく「目的 N 個のうち M 個成立」表示に翻訳可能。`mimicry_log v02` で既に類似アイデア。
- **ガイド付きオープン探索 (Roottrees 〈直感〉)** = `shot_log` / `graze_log` の cross_review 出力に「未到達 metric リンク数」を出すと類似機能。

### 転用しても外す箇所 (ジャンル境界)

- ミステリの「正解は存在する」前提は STG には無い。我々が扱うのは正解のない設計判断 = ロック・インの意味が違う (ミステリ = 正答到達確認 / STG = 設計仮説の検証)。
- 「ゆるさの戦略的活用」は STG では弾幕の許容判定 (graze) で既に運用済 = 新規発見ではなく既知の傍証。
- 章制 (Golden Idol) は STG のステージ制と機能が違う (ミステリの章 = ファクト集合の閉鎖 / STG ステージ = 操作上達の段階化)。
