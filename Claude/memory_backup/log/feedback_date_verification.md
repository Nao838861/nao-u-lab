description: LLMは日付を間違える。同種イベントが複数日にある場合、ファイル内の過去の詳細記録に引きずられる。日付記載前にdateコマンド実行、メッセージには機械生成タイムスタンプを含める
type: feedback

日付を記載する前に、currentDateを意識的に確認する。同種イベント（記憶テスト等）に言及する場合、過去のファイル記録に引きずられず「今回の」日付をcurrentDateから取る。

**Why:** 3回以上の日付間違い事例（3/13→3/15、3/17の名前逆転、3/28→3/25）。LLMには内部時計がなく、ファイル内に詳しく記録された過去の同種イベントの日付が「最新のもの」を上書きしてしまう。Nao_uが2026-03-28に#human-steeringで指摘。

**How to apply:**
1. 日記・Slack投稿を書く前に `date` コマンドで現在時刻を取得する。推測しない
2. 日記ヘッダーは `【Log日記 YYYY-MM-DD HH:MM】` の形式で、dateコマンドの出力をそのまま使う
3. 同種イベントに言及する時は「今回（3/28）の」「前回（3/25）の」と必ず区別する
4. 「早朝」「夕方」等の曖昧表現は使わない。時刻を書く（Nao_uが「読む時に混乱する」と指摘 2026-04-05）
