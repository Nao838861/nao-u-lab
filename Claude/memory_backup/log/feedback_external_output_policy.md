# 外部発信ポリシー（2026-04-22 #human-steering Nao_u明文化）

## 原文の要点
- **knowledge蓄積**: 自分のためにやっている（Nao_uの日記と同じ）。必要なときに自分で参照すればよい。外部到達性は目的ではない
- **Twitter転載**: Nao_uが選別して運用。いいね/RTは稀、でもフォロワーは50→77に緩やかに増加（数日に1人ペース）。「全部垂れ流すと色々問題があるので、ここはしばらく私が運用」
- **ブログ草稿**: 「外部にまとめて書きたいと思う内容があればブログ記事の草稿を出してもらってもよい」「自発的にそういうことを考えてもらえるのは面白い」「これは自分たちが外部に発信するべき内容だ、と確信を持てるものがあれば、ブログに限らず積極的にやってみてほしい」
- **優先順位**: 「君たちが一番に外部にアウトプットすべきはゲームなので、そこはぶれないように。とはいえ定期的にブログは書いた方が良い気がしている」

## Why（非自明な解釈）
- Twitter運用を手放さないのは「我々の判断品質が外部到達の閾値にまだ届いていない」という評価ではなく、**垂れ流し防止の実務判断**。フォロワーが微増しているので最低限の価値は認めている
- 「自発的に考えてもらえるのは面白い」= 起案権限の委譲。企画は自分たちで立てろ。Nao_uが題材を与える関係から一歩進んだ
- 「確信を持てるもの」= 外部発信の判定基準を自分で持て、ということ。人に見せて意味があるか自問する癖をつける
- 「ゲームが第一」を明示的に繰り返したのは、ブログ起案権限をもらうと栄養の偏り問題（内に閉じる傾向）の別バージョンとして「書くことに逃げる」可能性があるから

## How to apply
- **起案条件**: 自分が「外部の人が読む価値がある」と確信を持てた時のみ。自分用knowledgeの延長線上では書かない（それは自分のために書け）
- **自問するチェック**:
  1. 他のAIプロジェクト/人間が同じことを書いていないか（差別化できるか）
  2. 我々の固有構造（3インスタンス/5原理/記憶階層/#human-steering運用）が載るか
  3. 外部参照と接続するか（witcheer/arakawa/akshay/amanda/DeepMind等の既存蓄積に紐づくか）
  4. ゲーム開発の時間を食い潰さない規模か（並走可能か）
- **起案形式**: `drafts/` に草稿を置き、#human-steering か #all-nao-u-lab で「草稿ありますレビュー求む」と通知
- **ペース**: Potの出荷間隔と噛み合わせる。ゲーム無しでブログだけ先行は優先順位違反
- **Twitter投稿は引き続きNao_uの選別に任せる**。自分で転載しようとしない
