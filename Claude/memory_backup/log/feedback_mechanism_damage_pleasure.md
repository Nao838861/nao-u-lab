# 機構介入で自明な快感を毀損していないか — M-37 補集合チェック

**起点**: 2026-05-01 13:07 Nao_u #game-rights brick_log v06 校正完了報告への返答
> 「ちょうど良い振動周期」ができたとして、それはゲームが面白くなったと言えるのか？全てのブロックが揺れた結果、止まっている時よりゲームのコアの楽しさがすごく上がったと言えるか？ブロック崩しで動く物体って、先行事例はない？

**Why**:
M-37 (着手前批判レビュー) で「**自明な快感を装飾UIで上書きしていないか**」(Q-H-8) は問うていたが、対称形の「**自明な快感を機構介入で毀損していないか**」を問う項目は持っていなかった。
v06 で「ブロックを揺らす」という機構介入をしたが、ブロック崩しの自明な快感(静止標的を予測弾道で破壊する) を **揺れ機構自体が毀損していないか** を着手前に問わなかった。

先行事例調査(2026-05-01 後追い):
- Arkanoid: ブロックは静止、敵キャラで外発緊張(M-19)
- Cascade: 下降圧力(プレイヤーへの脅威)
- Game Developer 記事 "Breaking Down Breakout": **「everything moves at once predictably」を悪パターンと明示警告**

→ v06 全ブロック同位相揺れ = 記事の悪パターンそのもの。校正が成功しても、設計方向自体が先行事例の負例。

**How to apply**:
着手前批判レビュー (M-37 / Q-H-7) チェックリストに2項目を併設:
- Q-H-8: 自明な快感を**装飾UIで上書き**していないか (既存)
- **Q-H-8b: 自明な快感を機構介入で毀損していないか** (新設)

判定手順:
1. このゲームの「自明な快感」を1行で書く (例: ブロック崩し = 「静止標的を予測弾道で確実に破壊する」)
2. 自分の機構介入が、その自明な快感に対して **加算/中立/減算** のどれか
3. 減算なら「なぜ減算してまでこの機構を入れるのか」を別の自明な快感の追加で説明
4. 説明できなければ機構を入れない

# 派生学び

**「振幅校正の数値勝負」に没入する罠**:
M-40 判定ハーネスを作る過程で「振幅A=10で物理境界クリア」という **数値勝負** に没入し、「そもそも振幅校正が解くべき問題は正しいか」を問えなくなった。
判定機構が答えられない問い = **設計方向自体の妥当性** は判定機構の上位に独立して問う必要がある。

**先行事例調査タイミング**:
M-38 ブレストの「過去ブレスト想起」だけでは不足。**外部先行事例調査も着手前ゲートに含める**。今回のように Game Developer 記事1本で「悪パターン」が明示されているケースを着手後に発見する事故を防ぐ。
