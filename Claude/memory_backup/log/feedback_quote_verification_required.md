# 引用検証義務 — URL を貼る ≠ URL の中身を確認した

**Nao_u 指摘**: 2026-05-02 03:09 #game-rights

> 分析と判断の基準そのものは悪くないと思うが、隊列横スライドが Arkanoid Doh It Again 1997 にあったという事実を私は知らない。100ラウンドまでの動画を見たが、ブロックの隊列が横に動く場面を見つけられなかった。ソースはどこ？ また、「ブロックの隊列ががが横に動く」でゲームの体験がどう面白くなるのかが私には理解できなかったので説明してほしい。

## 何が起きたか

brick_log v08 brainstorm.md (2026-05-01 22:36 自己決裁後 公開) で M-41 型前例として下記を主張:

> **Arkanoid Doh It Again** | Taito 1997 | ◎ ブロック崩しジャンル内直接実装 | https://en.wikipedia.org/wiki/Arkanoid:_Doh_It_Again

→ **Wikipedia/MobyGames/GameFAQs どこにも隊列横スライドの記述なし**。1997 の真の新機構は「ボス戦で Doh がステージ回転」のみ。

3 重誤り:
- (a) 1997 を 1987 と取り違え（Arkanoid: Revenge of Doh の機構と混同）
- (b) 個別ブロック単位を隊列単位に拡大解釈（Revenge of Doh も "some bricks move left to right" であり隊列ではない）
- (c) 異ジャンル型 (Space Invaders 1978) をブロック崩し内型と混合

## なぜ起きたか

- M-41 (類似ゲーム類似事例調査) で「URL を貼る」までは実行したが「URL を開いて該当機構の記述を引用」をしなかった
- M-37 着手前批判レビューで「5/5 全て可」と書いた時、批判の対象が「設計上の懸念」だけで「事実検証の懸念」が含まれていなかった
- Q-H-2 クローン元欄に作品名を書く時点で、ジャンル/年代/機構規模 (個別 vs 隊列) の取り違えが構造的に検出できない
- M-38 の Q1-Q5+ブレスト30件+MPS+M-37+案セット相乗効果+「最良」確信宣言 をやっても、**根拠側の事実が砂上だと全部の上に楼閣が建つ**

## どう適用するか

**規則 R-Q1（ジャンル内直接型前例の主張時）**:
brainstorm.md / devlog.md で「ジャンル内直接型前例」「ジャンル内直接実装」「直接事例」と書く時は、当該 URL を実際に開いて該当機構の記述を**引用文（"〜"）で取り出す欄**を必須にする。引用文が取れなければその主張は M-41 不通過。

**規則 R-Q2（年代/作品名の取り違え検出）**:
作品名+年代+機構規模 (個別 vs 隊列、行 vs 群、状態 vs 動き) を 1 行ずつ独立に書き、それぞれ別の URL/引用で支える。1 つの URL で複数主張を同時に支えない。

**規則 R-Q3（M-37 着手前批判レビューに「事実検証」軸追加）**:
M-37 の懸念リストに「#0 引用元の事実検証」を最上位に置く。「URL を開いた／該当機構が記述されているか／該当規模で記述されているか／該当年代で記述されているか」の 4 点。1 つでも未検証なら M-37 不通過。

**規則 R-Q4（同型を異ジャンルから引いた時のラベル）**:
ジャンル外の型を参照する時は「異ジャンル参照」と明示。Space Invaders→ブロック崩しに型を持ち込む = 異ジャンル参照、ジャンル内直接型前例にはならない。M-41「先行事例ゼロ件は不採用」をジャンル内ゼロ件で判定する場合、異ジャンル参照を内側に数えない。

**規則 R-Q5（面白さ説明の独立性）**:
「型前例があるから面白い」は独立な理由ではない。型前例があってもなくても、**そのゲームでなぜ面白くなるか**を独立に説明できる必要がある。説明できない場合は前例の有無に関わらず採用禁止。

## なぜ大事か

M-41 (類似ゲーム類似事例調査) は「数値チューニングは微調整、面白くない仕様の調整は無駄、類似事例を広く検討してから」という Nao_u 04-21 13:18 処方を構造化したもの。**事実検証なしで M-41 を通過させると、M-41 そのものが空洞化**する。M-41 は「広く検討する」だけでなく「正確に検討する」を含意していた。

cross_review / Slack / Nao_u プレイは判定装置でなく最終確認装置 (M-40) — 私自身で事実検証して 95% 確信した後の確認装置。捏造で通すと最終確認装置に Nao_u が「100ラウンド動画を見たが見つからない」という時間を使うことになる。
