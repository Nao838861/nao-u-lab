MonoSH_FX2（SFC版スペースハリアー）のBGMの「音符の出どころ」は、解説動画のナレーション・字幕・画面・設計書、ブログ、Slack など外に出るものには書かない。出どころの中身はこのファイルにも書かない（記録は MonoSH_FX2 リポジトリの game/v001/audio/README.md と manifest.json にある）。

**Why:** Nao_u から「絶対に出さないで」と明示的に指示された（2026-10-11、解説動画第2回の短縮作業中）。nao-u-lab は公開リポジトリで、この記憶も memory_backup 経由で公開されるため、ここにも詳細を残さない。

**How to apply:** 音の作り方を説明するときは、音色の作り方（サントラで倍音を測った、ADSR、約9セントの二重音）、8声への割り振り、描画とのぶつかり回避、SEを分離できなかった話に絞り、音符をどうやって得たかは語らない。「耳コピした」など事実と違う説明で穴を埋めるのも禁止。
