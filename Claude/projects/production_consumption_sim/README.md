## 確定事項（2026-07-12 第1回）
1. プレイヤー = 経済圏の設計者。生産設備を置くと人が住み着く
2. テーゼ: 流通が社会を成立させる
3. 価格は創発させる（本物の経済）
4. 価格方式は純粋創発路線 — ミクロの個別取引のみ実装し、空間価格勾配・商人の裁定はその結果として創発（在庫関数などの設計者価格式は使わない）
5. 設備は建てたら住民のもの（に近い）
6. 経済圏はマップ内で閉じる。外部交易は細く高コスト
7. 舞台は島への入植（が良いかもしれない）
8. 成長エンジン = 道具（資本財）の連鎖。「他人の仕事の集積が、自分の仕事の効率を上げ、社会全体が進歩する」
9. 複数種の食糧で文化レベルが上がる
10. 終盤に第3次産業が創発して文化レベルが上がる

## 検討中: 時間の設計（現在の主戦場・大きく前進）
- 問題: A列車のジレンマ（歩行スケールの移動 × 世代スケールの発展）。嘘のつき方がゲームの印象を決める
- ファクトチェック済み: Caesar 3=二重時計・移民主+背景コホート人口。C:S=同構造（出生は本物にあるが転入が主）。Songs of Syx=単一時計高速回し（明滅の原因）
- 確定寄り: 二重時計を基礎に。経済ティック=市場セッション=1日。昼夜表現なし。カレンダー年数は重要でない（Nao_u確認済み）
- **フローリボン案は却下（2026-07-13）**: 実体は抽象化しない。荷車が走るのが見える・市場に財が物理的に積み上がる（A列車資材方式×Caesar 3市場方式）。高速時もデフォルメで実体を見せる
- Mirのデフォルメ解: (1)**視覚速度キャップ+残像/スピード線**（描画がシミュを最大視覚速度で追う→明滅が構造的に起きない） (2)**市場=積み上がる財の山**（在庫計器・価格の直感表示・崩壊の可視化を兼ねる） (3)フロー俯瞰はポーズ中のオーバーレイ計器に降格
- **人口ハイブリッド確定（2026-07-13）**: 入植船=主蛇口（魅力で出入り・排水口兼用・外部交易と同じ船着き場）、出生/加齢/死/相続=完全背景。マルサスの弧はテーマから背景の質感へ降格
- **最高速=荷車が視認できる速度に留める（確定）**。理想は「待ち時間が少なく速度が要らないゲーム」（やりながら検証）

## 次の主戦場: 残る大物6つ（2026-07-13 Mir棚卸し）
1. ★**誰が建てるのか** — **ほぼ決着（2026-07-13）**: B理想+資金源のみの差で実現。(i)完成後の建物は全て住民所有（プレイヤーの所有はインフラのみ。官営という中間状態は不採用——「非効率つまみ」は恣意的としてNao_uが却下） (ii)建設コスト=**材料の市場価格**（公費でも住民貯蓄でも等価。建設需要が経済に還流→景気循環の創発） (iii)B理想は国庫の有限性から自然に創発（ペナルティ不要） (iv)君主=税で吸い上げ公共事業で戻す貨幣循環の一部（金詰まりレバーがプレイヤーの手に）。※確定事項1は要改訂（「設備を置くと人が住む」→「条件を設計し、住民が建てる」）
   残り: 生産設備=常時住民所有の最終確認 / 税の形（人頭・売上・関税）
2. 労働の移動 — **(b)摩擦あり で確定（2026-07-13）**。主摩擦=設備の乗り換えコスト（自営経済では転職=設備乗り換え。市場価格+沈没費用から創発、恣意つまみはランプアップ最小限）。判断=職業信念（観察した他人の稼ぎのみ・情報は徒歩速度→クモの巣振動が自然減衰）。区画割当が構造転換のレバー。残: 廃業設備の行方（中古市場か朽ちるか）
   **流通レイヤー確定（2026-07-13）: C（役割=資本の組合せから創発）を終着点に段階導入**（MVP=A統合商人→C対応データ構造→分化は証拠が出てから解禁）。詳細: [design/distribution_models.md](design/distribution_models.md)。判断基準=整合性・成長性・わかりやすさ
   **季節**: 入れる前提の最小形で保留棚（農産物のみ・弱め・**食料4種を逆位相に設計=ポートフォリオが季節ヘッジを兼ねる**）。ヘッドレスで「蔵ゼロの1年目を生き延びるか」検証後に採否確定。豊凶（年変動=飢饉・流民の引き金）は別機能として後段
   **備蓄=無主の在庫を無くす**: 生産者手元/世帯パントリー/問屋の蔵（時間の裁定=季節平準化・飢饉バッファ）/プレイヤー御蔵（港のみ・囲米）。→ 新設計点: **季節（収穫サイクル）を入れるか**（問屋の存在理由に必要）
3. プレイヤーの分単位ループ — 介入手段・財政（税?）含む
4. ゴール構造 — **確定（2026-07-13）: サンドボックス主・シナリオは後から。理想=Factorio**。支援要請=能動・信用枠1本・破綻=特許取り消し（柔らかい敗北）。**2つ目の島**構想: 島1の経済が自走する=完成の証明（テーゼの最終試験「あなたがいなくても流通は社会を支えるか」）→島1が島2の本国になる**再帰構造**（支援機構がそのまま再帰）。Mir提案の柔らかい頂上=**独立（特許の買い戻し・自由都市化）**——同じ特許状が失敗では奪われ成功では買い戻される。「船の日」=心拍
5. ショックの源泉 — **本土価格の変動+イベントで確定（2026-07-13）**: 事前に瓦版（新聞）が船で届き、読む者が先回りできる（価格ボードは常に前便時点の古値=情報は船の速度）。島外世界は「価格+テキスト」のみで存在（輸出入として表現、外交画面なし）。新聞は本土瓦版+島内報（=可観測性計器のdiegetic版）の二紙構成案。見出しで9割/精読でedgeの二層。残り: 森林/鉱脈枯渇・嵐・火事の採否
6. マップ — **確定（2026-07-13）: 手作り先行・プロシージャルは後**（段階導入パターン。手作り群島=生成規則の教師データ）。**群島は1枚マップで最初から見える**（島間の船の流れ=テーゼがフローとして見え続ける・次の島が水平線に見える動機可視化）。**特許買い戻し→次の島の特許購入**の進行=終盤の巨大貨幣シンク（金余り病の排水口とゴールが同一機構）。船=資本の新しい段（船+在庫=廻船商人=高田屋エンドゲーム）。未決: 島間交易は内部化(a)か商館独占(b)か
