## 確定事項（2026-07-12 第1回）
1. プレイヤー = 経済圏の設計者。生産設備を置くと人が住み着く
2. テーゼ: 流通が社会を成立させる
3. 価格は創発させる（本物の経済）
4. 価格方式は純粋創発路線 — ミクロの個別取引のみ実装し、空間価格勾配・商人の裁定はその結果として創発（在庫関数などの設計者価格式は使わない）
5. 設備は建てたら住民のもの（に近い）
6. 経済圏はマップ内で閉じる。外部交易は細く高コスト
7. 舞台は島への入植（が良いかもしれない）
8. 成長エンジン = 道具（資本財）の連鎖。「他人の仕事の集積が、自分の仕事の効率を上げ、社会全体が進歩する」
9. 複数種の食糧で文化レベルが上がる
10. 終盤に第3次産業が創発して文化レベルが上がる

## 確定事項（続き・2026-07-12 第2回 Mir）
14. **道具は消費財**（耐久財＋摩耗ではない）。世帯・工房が木製品/鉄製品を消費し続け、消費の質・種類が文化Lv→効率UPを決める（Caesar 3住宅進化の生産効率への一般化。摩耗メカニクスは不要に）
15. 資源チェーン: [森]→丸太→材木→木製品 / 鉄鉱石→製鉄→鉄製品 / **燃料2系統**: 丸太→炭・炭鉱→石炭（=代替財ペア。エネルギー転換の創発候補）
16. 食料は漁・小麦・野菜・畜産の4種。複数種の消費が文化Lv条件
17. 陶器（粘土→陶器）は面白さにプラスにならないなら入れない（スコープ規律）。Mir基準案: 「新しい種類の意思決定」を足すなら採用（例: 貯蔵の解禁）
18. 文化レベルの効果 = 世帯・工房の効率UP（回答済みとして閉じる。入植船誘引は保留オプション）
19. **「一定以上の文化Lvには財の流通が必須」が世界観の核**。文化Lv=定常消費ポートフォリオの階段（維持にフローが要る）。**文化Lvが上がると効率の桁が変わる**設計
20. 燃料: 家庭は低Lv帯不要、一定Lv以上の到達に家庭燃料必須。産業は必須投入財（産業ごとに必須レベル・消費量が異なる）→ 需要が「必須投入財(非弾力)」と「階梯財(弾力)」に分化
21. 食料の腐敗は一旦なし → 陶器は当面凍結
22. 相続: 国庫なし。子→近所→近場に広く薄く（思いつきレベル・後で柔軟に変更可の留保つき）
