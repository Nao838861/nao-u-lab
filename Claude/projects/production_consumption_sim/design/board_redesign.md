## 主題の再確認(Nao_u 2026-07-18): 「辺境に全ての物資を流通させることが難しい」
これがこのゲームの元々の主題(だから「流通の島」)。現状は全てを一箇所にまとめるのが最適解で、
道は面白い味付け以上の意味を持てていない——主題が盤の上に存在していない状態。
なぜ集約が勝つか: 全世帯が中央市場へ**自分で買いに行く**モデル+移動が安い+地形の錨が弱い。
「流通」がゲームになる条件: ①辺境に居るべき理由(地形拘束=生産の錨) ②辺境まで物資を届ける難しさ(距離・道・移動コスト)
③届ける手段がプレイヤーの意思決定(道・行商・分市場・配達圏)。C3で言えば市場のおばさん(配達ウォーカー)が
道網に沿って家々へ物資を配る——「家が買いに行く」でなく「物流が家に届く」から、道と圏がゲームになる。

### 流通レイヤーの機構候補(R5として追補)
- **行商人**: 市場から道沿いに巡回し辺境世帯に売る(C3の市場ウォーカー相当)。届く範囲=道網の質
- **分市場/出店**: 辺境の集荷・小売拠点(プレイヤーが建てる=金の使い道)。商館在庫の支店
- **配達圏の可視化**: 「この家にはどの物資が届いていないか」を圏として描く(わかりにくさ対策と一体)
- 家の購買を「市場まで行ける範囲」に制限する段階(H案と連動)が入って初めて、辺境の物資欠乏が実際に起きる

## 設計の背骨: 「生産は辺境を求め、文化は都心を求める」
C3のジレンマの正体。木こり・漁師・採石は地形(森・水・岩)が辺境にあるから稼げるが、
文化(=豪邸=ラダー上位)は市場・サービスの近くでしか成立しない。プレイヤーの仕事は
この引っ張り合いの中で「どこまでインフラを辺境へ伸ばすか」を予算と相談しながら決めること。
距離の呪い(v0.20で仕込んだ建築リズム)はこの背骨があって初めてゲームになる。

## 職住分離 vs 合一の判断
- **フルC3分離**(住宅と職場が別建物・労働者が通勤): 世帯=建物=生業という現エンジンの根本前提を壊す大手術。経済較正も全部やり直し
- **推奨: 職住合一のまま「住環境」を家の場所の属性にする**
  - 家のLv上限(豪邸化の上限)=住環境スコアで決まる: 市場への実効距離(道込み)+サービス被覆(将来: 教会・居酒屋等)+負の隣接(煙・悪臭)
  - 木こりの山小屋は収入が良くても環境上限でLv2どまり→「木こりや漁師は豪邸に住めない」がそのまま出る
  - 辺境を引き上げる手段=道・第二市場・サービスの出店=全部プレイヤーの金の使い道
  - 開拓地の実史とも合う(辺境の伐採小屋 vs 港町の商人屋敷)
  - フル分離は将来も選べる(環境スコアの仕組みは分離モデルでもそのまま使える)

## 市場近くみっちりの対策(4の答え)
単独の対策でなく、上の背骨+以下の複合で「属性ごとの適地」が生まれる:
1. **地形拘束**(既存): 漁師=水際・木こり=森・採石=岩場——辺境側の錨
2. **マルチタイル化**(下記): 畑3x3・牧場3x3は物理的に核に入らない
3. **負の隣接**: 炭焼・塩屋の煙は近隣の住環境を下げる→工房は風下・外周へ(C3のdesirability)
4. **住環境スコア**: 核の一等地は豪邸に使いたくなる→生産建物を核に詰めると機会費用
5. 口銭(既存): 取引量が金庫収入なので、詰めて村が回らなくなるのはプレイヤーの損

## 建物サイズのたたき台(絵が入る前提のフットプリント)
| 建物 | サイズ | 備考 |
|---|---|---|
| 道 | 1x1 | 幅1のまま(荷車1台の道) |
| 住家(全職共通の家部分) | 2x2 | Lvで見た目が豪邸化(C3の住宅進化と同じ絵の文法) |
| 麦畑・牧場 | 3x3 | 母屋+圃場。物理的に郊外へ |
| 菜園 | 2x2 | 集約農業は狭くて良い |
| 木工・炭焼・塩屋・採石小屋 | 2x2 | 作業場+住 |
| 市場(核) | 3x3 | 町の核=取引の場。**物資の山は持たない**(下記) |
| 市の広場(可変) | 1x1×n | 市場に隣接して敷く舗装タイル。屋台が広場に立つ=取引量が増えると市が物理的に育つ(絵になる) |
| 蔵(倉庫) | 3x3 | **積み上がる資材の絵はここ**。C3倉庫と同じくスロット(8口)に品目が見える。商館在庫の実体。満杯なら次の蔵を建てる=保管容量がゲーム(金の使い道) |
| **港複合=商館** | 4x3(岸接) | 桟橋+商館事務所を一体化。**本土との境界の全フロー**(輸出入・本国注文・移民の上陸)はここを物理的に通る。商館を別置きにすると荷がテレポートする(偽物) |

### 港と商館の統合(Nao_u問い「商館と港は同じ?」への答え)
- 統合する。歴史的にも商館=港の施設(出島・VOCファクトリー)。絵=桟橋に船が着き、荷が蔵と船の間を動く
- 役割の線引き: **市場=村の内需の場**(村人同士の取引) vs **港複合=本土との境界**(輸出入・注文・移民の全フロー)
- ゲーム的な獲物: 荷は 辺境→市場→港の蔵→船 と物理的に流れる。**市場-港の道が島の大動脈**になり、主題(流通)が盤の上に常時見える
- 会社の最初の蔵は港脇に建つ(輸出の荷積み場)。以後の蔵は集荷拠点として内陸・辺境へ(R5)

### 市と蔵の分離(Nao_u指摘「市場3x3で積み上がる資材をどう表現? マスが足りない」への答え)
- 誤りは「市(流れ)と蔵(ストック)を同じ建物に押し込める」こと。C3も市場は小さく、物資の山の絵は倉庫・穀倉が担う
- **市**: 屋台=その日の売り物(流れ)。市場核+隣接する広場タイルに屋台が立つ。広場は可変なので賑わいがそのまま面積に出る
- **蔵**: 商館在庫(積み上がるストック)の実体。スロット絵で「何がどれだけ積まれているか」が一目で見える。蔵の容量上限→「腐る財は腐敗が上限・腐らない財は在庫が上限」の原則が絵になる
- 副産物: 蔵をどこに建てるかが流通(R5)の集荷拠点設計と直結する(辺境の蔵=分市場の種)
- マップ: 48x40では2x2〜3x3が10数軒で満杯→**96x80へ拡大**(地形生成のスケール調整込み)。デフォルトズームを引きで開始
- 実装: canPlace/findSpot/描画/配置ゴーストの矩形化。アンカー=フットプリントの南角、スプライトは菱形足元+高さ
