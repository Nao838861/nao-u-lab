# 建築の経済——「建てる→貯まる→また建てる」ループ (2026-07-18 Nao_u提起)

**ステータス: 骨格はv0.20で実装済み**(支度金2,500デナリ・市場口銭4%・E16監査)。実測: 漸進建築が飢餓半減・人口+26%・口銭+46%で一括に勝つ。残: 支度金の資材+賃金化(家普請と同時)・距離の呪いの手触り検証・第二の港。

Nao_u: 「今は静的な建物を立てて後は待つだけのゲームになってる。初期資金で最低限の建築をしてしばらく待つと資金が貯まり、良い建築ができていたら資金の溜まりが早くなる、みたいな構造が必要ではないか。その上で、今想定している初期配置が安定した先には距離の呪いが出てくる」

## 診断: なぜ今「待つだけ」なのか(コード上の事実)
1. **建築が安すぎる**: 入植1軒=渡航費600デナリ vs 初期金庫30,000。一括全建築が常に最適解で、以後の意思決定が消える
2. **金庫収入が配置の質と連動しない**: 収入=輸入マージン+注文口銭のみ。村の経済がどれだけ上手く回っても金庫の貯まりはほぼ変わらない→「待ち」に意味がない
3. リズムの不在: 都市建設ゲームの基本拍「支出(建築)→蓄積(待ち)→支出」の蓄積側が空

## 提案の骨格(2本柱)
### 柱1: 建築費を主要支出にする
- 1軒=数千デナリ級(渡航費+支度金+建設資材)。初期金庫で建てられるのは最低限の数軒だけ
- 将来形(家普請・材木Phase2と同一機構): 建設費の一部を**実資材(材木・石)+人夫の賃金**に——道普請と石畳(PAVE)のプロトタイプが既にあるので自然に拡張できる
- **妙**: 建築費が商館買上げ・普請賃金として村に落ちる=建築そのものが会社→村の還流。「建てるほど村が潤い、村が潤うほど貯まる」が閉じる

### 柱2: 金庫収入を村の経済の鏡にする——市場口銭(市座料)
- 市場の全取引額の数%を口銭として金庫へ(中世の市場税そのもの・東インド会社の設定にも合う)
- これで「良い配置→生産と取引が多い→口銭が速く貯まる→次の建築が早く打てる」が成立
- 注意(v0.17の教訓): 口銭は村からの通貨吸い上げなので、建築支出・商館買上げでの還流とセットで収支を較正する(吸うだけだと通貨枯渇の再演)

## 距離の呪いはこのループから自然に生える
- 建築が高価になると「近い土地から順に使う」が自動的に成立→成長すれば必然的に遠くへ
- 遠さ=移動時間=生産低下は既に物理として実装済み。v0.16で道が本当に速くなったので「呪いへの解=道・石畳への投資」の弧が機能する
- 中盤以降の解の拡張候補: 第二の港/分市場(遠隔地の集荷点)——これは呪いが実際に痛くなってから

## 検証の設計
- 取引量の実測→口銭率→建築費の逆算(数字は測ってから決める)
- 監査に **E16「漸進建築が一括建築に勝つ」** を追加: 同じ建築リスト・同シードで(a)全部即建て(借金) vs (b)資金を待って順建て、(b)が生存/成長で上回ること=ループ成立の意図監査
- 「待ち時間に見るものがあるか」(金庫が貯まる様子・次に建てたいものの値札)をUIで確認
