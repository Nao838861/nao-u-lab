# キャッチーさの方向性 (2026-07-17 Nao_u指示・将来課題)

Nao_u: 「こんな感じのキャッチーさを持たせたい。すぐではないけど考えて記録しておいて。今のはわかりにくくて地味すぎる」
参照例: GOROman氏「THE EVENT DIRECTOR」(https://x.com/goroman/status/2077769745022284020)
——渋谷のホテルに300人を急遽集めるイベント運営シム。1日開発・60秒動画・即プレイリンク。

## 参照例から抽出したキャッチーさの構成要素
1. **一行で伝わる使命**: 「300人を今すぐ集めろ」= 具体的な数字+締切+場所。ルール説明が要らない
2. **役割を与えるタイトル**: THE EVENT DIRECTOR——プレイヤーが「何者か」を名乗れる。ゲーム名=職名
3. **60秒動画で伝わる画**: 数字が跳ね、人が動き、危機が起きる。「見て面白い」が撮れるか
4. **即プレイ**: リンク踏んで3秒で遊べる(これは既に満たしている)

## 流通の島への適用案(未実装・要Nao_u相談)
- **本国注文をドラマの主軸に**: 「90日以内に保存食100樽。さもなくば——」という無理難題の連続をゲームの背骨にする。締切カウントダウンを画面の主役に(今は出来事ログの1行)。C3のシーザーの要求も「怒られる」演出込みでキャッチーだった
- **タイトル=役割名**: 「流通の島v0」は地味。案:「DIRECTEUR(ディレクトゥール)——東インド会社の支配人」「支配人」「THE COMPANY MAN」。プレイヤーに肩書きを与える
- **開幕の一行使命**: 起動3秒で「本国の期待は重い。島を300人の街にせよ」等、数字つきの目標を出す
- **画のドラマ強化**: 船の入出港(注文の品を積む絵)・冬の雪と炊煙・餓死の葬列・市場の喧騒。今は小さなドットが歩くだけ
- **数字の可視化**: 人口・金庫・締切を大きく。跳ねる数字はそれ自体が画になる
- **試金石**: 「60秒の画面録画だけで面白さが伝わるか」をキャッチーさの合格基準にする

## 現状の弱点(Nao_u指摘の分解)
- わかりにくい: 目標がない(何をしたら勝ちか画面が言わない)。パネルの数字は economist 向けで一見さんに読めない
- 地味: 危機も達成も出来事ログの小さい文字列。絵と音の報酬がない

## 実装順の考え(たたき台)
1. 開幕使命+注文締切の大型表示(安い・効果大)
2. タイトル改名(Nao_u裁可待ち)
3. 船の入出港アニメ(注文経済の絵)
4. 60秒トレーラーが撮れる状態を確認して初公開
