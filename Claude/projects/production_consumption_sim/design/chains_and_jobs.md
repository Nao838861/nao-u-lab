# 財と職の全チェーン統合表 — 漏れの総点検

作成: 2026-07-14（Mir） / 状態: 統合版（Nao_u「色々漏れてる気がするので一回まとめて」）
発端の指摘: 持参道具=木製品? / 木製品を作る仕事はあるか? / 塩と炭は? / **塩には燃料が必要**

## 検出された漏れ（4つ・正直に）
1. **木工房がシミュに不在**: チェーン上は きこり→製材所→**木工房**(材木→木製品=道具・家具・荷車)だが、シミュは製材所止まり。tier1の道具維持には木工房まで要る（シミュの「製材所でtier維持」は誤り）
2. **塩の燃料が未モデル**: 欧州の製塩は鹹水を煮る=**燃料を食う**（リューネブルクの塩と森）。塩→燃料→森の連鎖が丸ごと抜けていた
3. **鍛冶が暗黙**: 「製鉄→鉄製品」と書いてきたが、鉄から道具を打つのは**鍛冶屋**（燃料も食う）。木側が3段(きこり/製材/木工)なら鉄側も3段(鉱夫/製鉄/鍛冶)
4. **塩作りと干物作りの混同**: シミュの'salt'職が保存食を作っていた。正しくは**塩=専業**、**干物・漬物=漁家/農家の兼業**（塩を買い、干場/漬物蔵という小設備で加工）→専用職を増やさない簡素化

## 道具の流れ（tier維持の正確な条件）
- **持参道具=木製品相当**（tier1）。消費財なので摩耗→**維持には きこり→製材所→木工房 の3段が揃って初めて国産供給**（製材所だけでは不足・シミュ要修正）
- tier2=鉄製品: 鉱夫→製鉄→鍛冶の3段+燃料。木3段と対称
- 序盤の道具輸入: 木工房が立つまで木製品も輸入されうる（建材と同じ輸入代替の構図・第五のドレイン候補）

## 開幕チェーンの正しい順序（修正版）
1. 漁+菜園（食料）
2. きこり→製材所（建材自給）
3. **木工房**（道具自給=tier1維持）←シミュに欠けていた段
4. **炭焼き→塩職人**（燃料+塩=保存の解禁）
5. 麦収穫・保存で越冬
6. （中盤）鉱夫→製鉄→鍛冶（tier2）
