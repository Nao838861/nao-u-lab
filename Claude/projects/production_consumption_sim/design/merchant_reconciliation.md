# 商人C案 × 現行実装(v0.24) 整合性の徹底突合 (2026-07-18)

Nao_u: 「商人は原典のは仮に決めた仕様なので、最新と突き合わせると整合性の取れないところもあると思うので徹底的に見直して」
C案(創発分化)の前提は2026-07-13時点のもの。以後に確定した実装(3原理・商館・建築リズム・人口動態・1日圏)と一項目ずつ突合する。

## 前提の変化と整合判定
| C案の前提(07-13) | 現在(v0.24) | 整合判定と解決 |
|---|---|---|
| 価格信念+ダブルオークション | **3原理(信念全廃・記憶なし試行)** | **要再設計→解決あり**: 商人=「空間の変換業」として3原理がそのまま使える。原価の床=仕入値+移動日数分の生計費 / 天井=行き先の使用価値(現地px) / 売値=記憶なしの抽選。**信念は不要**——判断材料は公開px(市場の観測値)のみ。「エージェントはバカでいい」が商人にも通る |
| 情報は徒歩・船の速度 | pxは世界共通(実装)→R5で市場別 | 市場別px化と同時に「他市場のpxは行商・瓦版が運ぶ(遅延つき)」を入れるか【未】。MVPは公開px参照で開始し、情報遅延は後段 |
| 賃金労働なし(血縁自営のみ) | **賃金あり**(普請・民間日傭=Nao_u承認) | **好転**: C案最大の実装リスク「運送契約市場のコールドスタート」が消えた——問屋は既存の雇用機構で運び手を日傭できる。B/C分化の敷居が大幅に下がった |

## 統合後の商人像(v2 spec反映案)
1. **商家区画**(プレイヤーが置く)に世帯が入る→徒歩+手荷車の行商(近隣市場間・1日圏)から開始
2. 稼ぎで**荷馬車(16荷)を購入**(木工房の高額製品=材木チェーンの出口)→行動半径と利鞘が跳ねる
3. さらに稼ぐと**私蔵を増築**(資産型昇格)→問屋化(季節の時間裁定・運び手の日傭)——「高田屋」の成長物語
4. 会社の荷役はこの民間が育つまでの代替+自社注文物流に限定。民間の採算区間から撤退
- 監査候補: **E21「経済の自立」=住民同士の取引額が商館との取引額を上回った日**(opening_sequence原典のマイルストーン計器)・E22「商人の成長」=荷馬車保有世帯の出現
