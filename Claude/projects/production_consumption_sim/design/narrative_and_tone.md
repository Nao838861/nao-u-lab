# 物語とトーン — 債務のプレッシャー・怒る本国・秘書・ペーパープリーズ的な毒

作成: 2026-07-14（Mir） / 状態: 検討中（序盤フックの提案）
親: [../README.md](../README.md) / 発端: Nao_u「積み重なる借金のプレッシャー、経営が安定せず怒る本国、慰めつつ前向きな提案をする秘書(女性)、ペーパープリーズみたいな毒と外連味を序盤のフックの一つに」

**位置づけ: 既存の仕組み(船の日・信用枠・御用・ガゼット・ファクター)に「声と感情」を被せる層。新システムを足さない=新しい意思決定ゼロ=複雑さ予算を食わない。** 感情フックはシステムでは届かない層に届く(原体験=崩壊のドラマ / ミッション=広い人に)。

## 数字に顔をつける
- 抽象的な「信用限界→特許取り消し」に顔をつける: 本国の督促状(船で届く)が債務とともに冷たく険しくなる
- 秘書がそれを和らげ前を向かせる=プレイヤーの人間的な錨
- 船の日(心拍)が経済ビートだけでなく感情ビートになる

- 「見出しで9割」原則を守る(壁テキストにしない)

## 秘書(女性) — ファクターを人間化
- 境界の再整理: 以前の「守りは番頭・攻めはプレイヤー(最適手は教えない)」と噛ませる → **慰め・士気・方向は示すがパズルは解かない**。感情の支え+目標の指差し。最適手や配線はプレイヤーが解く(発見/診断の喜び=Clippy回避を維持)
- 例: 「また都からの書状です。封蝋は少し和らげておきました。三袋の種と祈りだけで我らをここへ送ったのは、あちらでしょうに。——でも、いつまでも乞う必要はありません。自前の炉を持てば、あの鉄の値がこちらの血を吸うのを止められます。測量士に東の丘を見させましょうか？」(=製鉄で鉄輸入を止める方向を指差すが、何をどう建てるかはプレイヤー)
- 個性: 皮肉と温かさ・忠実・毒を含む warmth。彼女の口調が島の状態を映す

## 毒 = 道徳的圧力の瞬間(収奪vs持続のnarrative化)
- ペーパープリーズの毒=遠い権力が生存に無関心に要求する。本作: 債務が嵩むと王室を満足させるため島を犠牲にする選択
  - 民が飢えるのに貢納穀物を本国へ積むか / 破滅的高利の借金を負うか / 住民を酷使するか
- 既定「収奪→崩壊 vs 持続開発」を数字でなく人間のジレンマに。秘書が一言添える=外連味の源泉

## 感情の弧: 自立をカタルシスに
督促が険しくなる依存と不安の序盤 → 秘書が希望を繋ぐ → 転回(製鉄が立ち鉄輸入停止・赤字が黒字化) → 安堵と誇り。**債務のプレッシャーが強いほど自立の瞬間が効く**(前回の「自立のカタルシス」が物語としても成立)

## 注意
- 必読にしない(見出しで毒が伝わる・精読任意)=カジュアル脱落防止
- トーン=「温かさ+毒」(慰めが圧力と釣り合う)≠ペーパープリーズの絶望一辺倒。Nao_u「慰めつつ前向き」に忠実
- 勝てるレースに調整(債務は緊張であって詰みでない)。秘書の温かさはゲームフィールの調整弁
- 声と感情の層で新システムでない(新意思決定ゼロ)
