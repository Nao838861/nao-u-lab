# 設定聖書 (Narrative Bible) — 世界・登場人物・シナリオ・文体の正本 (2026-07-18)

> **目的**: シナリオ・設定・台詞に関わる全AI(GPT/Codex/Claude)と人間が、これ一本で世界観を仔細漏らさず共有する。
> 経済・機構の正本は[canon.md](canon.md)、本書は**声と物語の正本**。台詞・文言を書く前に必読。
> 出典: narrative_and_tone.md / difficulty_and_meta.md / opening_sequence.md / tutorial_playthrough.md / 実装済みゲーム内テキスト(v0.24)

## 1. 一行の世界
**17世紀風・東インド会社を思わせる勅許会社が、絶海の島に植民地を築く。**
プレイヤーは本国から送り込まれた**支配人(総督)**。会社の金で島を設計し、本国への上納と島の自立の間で板挟みになる。
- モデル: オランダ東インド会社(VOC)・出島の商館・ジェームズタウン等の初期植民地(最初の植民地は失敗が常態)
- ゲームの参照: Caesar III(要求と督促の弧)・Papers, Please(事務の毒と外連味)・A列車(資材が動いて溜まる原体験)

## 2. トーンの原則
1. **数字に顔をつける**: 抽象的な債務・限度・輸入は、督促状・秘書の一言・船着き場の光景として現れる
2. **ペーパープリーズの毒**: 本国は冷たく、事務的で、時々恫喝する。ユーモアは乾いた側に寄せる
3. **見出しで9割**: どの文言も数秒で読める。壁テキスト禁止
4. **敗北は物語の第1章**: 失敗は「下手」ではなく史実の常態(初期植民地はめったに生き残らない)。デブリーフと再挑戦を必ず渡す
5. **毒は本国へ、温度は秘書へ、事実はログへ**(声のチャンネル分離。§6)
6. **和風語彙は使わない**(前例: 「御用」→「本国注文/注文状」に改名済み)。舞台は洋風、ただしUI日本語は自然な和文でよい(「蔵」「普請」等の生活語は許容——固有名詞・制度名を和風にしない)

## 3. 登場人物・アクター

### プレイヤー=支配人
- 呼称: 「支配人」(秘書から)・「総督」(本国から)。タイトル案(DIRECTEUR等)はキャッチー化(catchiness.md)で保留
- 立場: 会社の被雇用者。島の所有者ではない(設備は住民のもの)。金庫=会社の勘定であり私財ではない

### 秘書(女性・最重要キャラクター)
- 仮名: **Mira Vance**(tutorial_playthrough初出。正式名は【未・Nao_u命名】)
- **役割の境界(確定設計)**: 慰め・士気・**方向の指差しはするが、パズルは解かない**(最適手・配置の正解は言わない=Clippy回避・発見の喜びを奪わない)。「守りは秘書・攻めはプレイヤー」
- **物語上の機能**: ①本国の冷たさとプレイヤーの間の緩衝材(督促状の「封蝋を少し和らげておきました」) ②感情の錨 ③**総督が交代しても島に残る通し柱**(difficulty案2: 「何人もの旦那様を見送ってきました」——敗北→新総督着任の連続性を担う唯一の存在)
- 口調: 丁寧・落ち着き・一滴の皮肉(本国に対しては静かに辛辣)。前向きだが楽観の嘘はつかない
- 台詞の型: 「(状況の受け止め)——(前を向く一言 or 方向の指差し)」
  - 原典例: 「また都からの書状です。封蝋は少し和らげておきました。三袋の種と祈りだけで我らをここへ送ったのは、あちらでしょうに。——でも、いつまでも乞う必要はありません。自前の炉を持てば、あの鉄の値がこちらの血を吸うのを止められます。測量士に東の丘を見させましょうか？」(方向は指すが、何をどこに建てるかは言わない)
  - 実装済み例: 「ようこそ、支配人。まだ誰もいない島です」/「まず浜の近くに漁師の区画を二つ。次の船が家族を連れてきます」/「…本国は、もう待ってくれないそうです。それでも島の朝は来ます」/「村から飢えが消えました。島が自分の足で立ち始めています」
- UI: 画面下部に常駐(#factor)。将来は肖像つき

### 本国(会社重役・株主)
- 性格: 褒めない・買い叩く・数字しか見ない。だが理不尽ではない(督促は段階を踏む=隠すが不公平でない)
- **督促状の5段階(escalate・簡潔で毒・原典確定)**:
  | 状態 | 文面 |
  |---|---|
  | 順調 | 王室は其方の進捗を認める。続けよ。 |
  | 中立 | 帳簿は記録した。相応の見返りを期待する。 |
  | 苛立ち | 二季、貢納なし。王室の忍耐は無限ではないぞ、総督。 |
  | 威嚇 | 債務は嵩む。この勅許を持った者は前にもいた。彼らがどうなったか忘れるな。 |
  | 最終 | これが最後の猶予。納めよ、さもなくば勅許は別の手に渡る。 |
- 支援の物語(C4で復活予定): 支援(無償)→無利子貸付→利子付き——命綱が段階的に高くつく。旧実装の台詞資産:
  「これが最後と思いなさい」「株主にどう説明しろと…」「次はもう無い。肝に銘じよ」
- 注文状(本国注文)の声: 「★本国より注文状: 道具30荷(@25デナリ・90日以内)」/達成「★注文を納めた——本国での評判が上がった」/期限切れ「注文の期限切れ——本国重役たちの心証を損ねた」

### 住民
- **名前つき個人**(非交渉の核): オランダ系。姓=ヤンセン/デ・フリース/バッカー/フィッセル/スミット/デッケル/ブラウワー/ファン・ダイク/メイヤー/ボス/ペーテルス/ハウトマン。名=ハンス/グレタ/ヤン/マリア/ピム/ロッテ/カレル/アンナ/ブラム/エルス他
- 家族のドラマは実装済みイベントで語られる: 「◯家に子が生まれた」「◯家の△人が分かれて□の区画へ移り住む」「☠◯家の△が餓えで亡くなった」「☠◯家は離散した——家は廃屋になった」「◯家の借財を帳消しに(徳政)」
- 職業は11種(漁師・菜園・麦畑・牧夫・菜種・木こり・木工・炭焼・塩・採石・対岸漁)+将来: 商家(行商→問屋)・鉱夫・製鉄・鍛冶

## 4. 用語と単位(表記の正本)
- 通貨: **デナリ**(内部値×10が表示値) / 荷=人が担げる量の共通単位 / 区画・支度金・普請・渡航費
- 施設: 商館(=港複合・本土との境界)・蔵(倉庫)・市場・市の広場(将来)
- 制度: 注文状(本国注文)・口銭(市場手数料4%)・信用限度・最終通告・徳政・買い叩き(輸出白名単・懲罰輸入)
- 評判の語彙: 「覚えめでたし」は和風すぎたため廃止→「本国での評判」「重役たちの心証」

|---|---|---|
| 開幕 | 会社の店の時代——商館だけの島に第1便。入植世帯が上陸し、輸入品で食い繋ぐ | ✅(教程) |

## 6. 声のチャンネル分離(実装規約)
| チャンネル | 中身 | 実装 |
|---|---|---|
| 秘書(#factor・画面下) | 感情+方向の指差し。パズルは解かない | ✅ |
| 次の一手(#advice・上部) | 操作の具体提案(建物の推薦)——秘書と分離した「計器」 | ✅ |
| 出来事ログ | 事実の記録(決算・生死・注文・完成) | ✅ |
| トースト | 生死・注文・完成の即時通知 | ✅ |
| 督促状(将来・船の日) | 本国の声。5段文面。船で届く | ❌ |
| 瓦版(将来・船の日) | 価格情報・本土の噂=情報遅延の媒体 | ❌ |

## 7. 執筆時の禁則
- 秘書に最適手を言わせない(方向まで)。本国に温情を言わせない。ログに感情を書かない
- 新しい固有名詞を足す時は§4の表記に追加してから使う(正本の同期)
- 台詞・文言の追加はこの聖書と同一commitで目録(§3/§5)を更新する
