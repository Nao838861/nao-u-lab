## Phase 0: 着船（Day 0）— 会社の店の時代

- **初期状態**: 商館（プレイヤーの拠点・港）だけが立っている。特許状と初期資金、そして**第1便**が着く
- 第1便の積荷: **入植世帯 5〜8家族**（各世帯は少額の貯蓄と手荷車を持って上陸=初期貨幣供給の実体）+ 建設資材の束 + 食料
- 荷は**商館の荷揚げ場**に物理的に積み上がる（財の山・第1号。「資材置き場？問屋の倉庫？」の答え=序盤はどちらでもなく商館の荷揚げ場。問屋の蔵は後で住民業として創発する）
- **商館=最初の市場**を兼ねる: 入植者は商館で輸入食料を買い、産物を商館に売る（=会社の店 company store。植民地経済の史実そのもの）
- 序盤の経済はプレイヤーを軸に回る: 金は 商館→世帯（買取）→商館（食料販売）と循環。**「住民同士の取引額が商館との取引額を上回った日」=経済が自立し始めた日**（創発マイルストーン計器の筆頭候補）

## Phase 1: 山奥のきこり拠点 — 「入植請負（funded claim）」方式

公費建設の実体を「建物がポンと建つ」ではなく**開拓の入植請負**として仕様化する:

1. プレイヤーが山際に伐採ゾーンを塗り、きこり小屋の**公費建設を発注** → 国庫が材料費を払い（商館在庫から確保）、現地に**立て札（クレーム）**が立つ
2. **設備を持たない世帯がクレームを受ける** → 一家が手荷車で資材を数往復運び、自力で小屋を建てる（ホームステッドの絵そのもの。**開幕から「運ぶ家族」が画面にいる**——フロー可視のテーゼが最初の10分から機能する）
3. 完成と同時に**その世帯の所有**（既定のホームステッド方式と接続）。受け手がいなければ立て札のまま残る（=入植船への誘引力として機能）
- 住民自発の建設も同じ機構: 世帯が自分の貯蓄で材料を買い、自分でクレームを立てる。**差は財布と発注者だけ**（既定の3点差と完全整合）
- 建設現場の資材山=現場の在庫（無主在庫なしの原則を保つ）
- **道**: 何もしなくても獣道（低速）。プレイヤーが公費で道を敷くと荷車が速くなる=インフラ投資の最初のレバー

## Phase 2: 通勤問題 — 流通の必要性が「時間の浪費」として見える

- きこり世帯が稼働: 丸太が小屋の脇に積み上がる（生産者在庫）
- 食料が要る→**当初は自分で港まで買い出しに歩く**（週に一度、山道を往復する姿が見える）
- この往復の時間=伐採できない時間=**距離コストが生産性低下として現れる**（ペナルティ数値でなく、時間の物理で）
- 島内報の見出し候補: 「山のきこり、買い出しに二日」——問題が読み物として観測できる

## Phase 3: 最初の商人 — テーゼの誕生日（開始15〜30分）

- 山の食料価格（きこりが払ってもよい額）と港の食料価格の差、丸太の山下がりの価格差が開く
- それを見た世帯（or 新着の入植者）が**手荷車で食料を山へ、丸太を港へ運び始める=最初の行商人**
- きこりは買い出しをやめ、伐採時間が回復→丸太産出が跳ねる。**「流通が生産性を解放する」がプレイヤーの目の前で数字と絵の両方で起きる**
- 創発マイルストーン: 「島で初めて、商いを生業とする者が現れました」
- プレイヤーの加速手段: 道を敷く（往復コスト減=商人の採算ラインを下げる）。直接「商人を作る」ことはできない（既定）

## 加工立地問題 — 「運んでから加工する方が有利？」の答え

Nao_uの問いはウェーバーの工業立地論そのもの（重量減損原料は産地立地が有利）。**本作では実装不要——局所価格が勝手に解く**:
- 製材所を山に建てれば: 丸太は安く仕入れられる（産地価格）が、職人世帯の食料は高い（山価格）
- 港近くに建てれば: 食料は安いが、丸太は運賃分高い
- どちらが儲かるかは**その時の局所価格の組**で決まり、価格は流通の発達度で動く（道が良くなれば山の食料が下がり、山立地が有利化する等）
- **プレイヤーの庭師スキル=この立地判断**（ゾーンをどこに塗るか・公費でどこに建てるか）。正解は固定でなく、島の発達段階で動く——リプレイ性の源泉
- 職業信念の住民は自分の見える範囲で立地を選ぶ→プレイヤーの読みと住民の選択がズレることもある（それも観測対象）

## 荷車の調達 — 輸入代替の弧

- 開幕時: 荷車（手荷車・荷馬車）は**輸入品**（商館で買う・高い）。入植世帯は手荷車持参
- 島に木工が立つと: 荷車が**地元産**になる（安い・木製品チェーンの主力商品）
- **輸入品が地元産に置き換わっていく=輸入代替**が、荷車1品目だけで体験できる（植民地経済の史実の縮図。瓦版の話題にもなる）

## この開幕が確定させる仕様（棚卸し）

1. 商館=初期市場+荷揚げ場（市場建物を別途建てるまでの市場0号）
2. 入植世帯は貯蓄+手荷車を持って上陸（初期貨幣供給・初期輸送力の出所）
3. 公費建設=入植請負（funded claim）: 国庫が材料、受けた世帯が運搬+建設+所有。自発建設も同機構で財布違い
4. 獣道（自動・低速）と敷設道（公費・高速）の2段
5. 距離コスト=移動時間の物理（ペナルティ数値を書かない）
6. 荷車=財（輸入→地元産の代替弧）
7. 経済自立の計器: 住民間取引額 vs 商館取引額

# 追記（2026-07-13）: Phase 0.5 食料確保 — 「今日食う魚、冬を越す麦」

Nao_uの種: 「本国からわずかな資材を受け取って、まずは麦畑？漁労？で食料確保。魚は腐るとよいかも？」

## 魚だけ腐る（単品腐敗）の提案 — 採用推奨

確定21「腐敗なし」への原則ある例外。魚1品目だけに腐敗フラグ（当日〜翌日で消失）を付けると:

1. **食料4種の役割が分化する**: 魚=即時・高効率・ただし**その日のフロー**（貯めれない・遠くへ運べない）/ 麦=収穫サイクル持ちの**ストック**（貯蔵・輸送・端境期の備え）。「フローの食とストックの食」——**テーゼの語彙が開幕の食料問題にそのまま宿る**
2. **島マップのバランス問題を構造的に解く**: 島は海岸だらけ→腐敗なしだと漁が常に最強で農業が発達しない。魚が腐れば「魚は浜の日々を養い、麦が内陸と冬を養う」に自然分業（史実通り: 生魚は内陸に届かない）
3. **魚市場=価格変動の教材**: 当日中に売り切る宿命→豊漁の朝は暴落、不漁の日は高騰。**開幕から最も活発で変動の激しい市場が港前に立つ**——「価格ってどうやって決まるのか」の最初の授業が魚市で始まる（原体験2の教材を初日から）
4. **干物チェーンの動機が生まれる**: 魚→干物（干場・安い設備）で保存化＝浜の輸出品。塩なしでも成立（天日干しの抽象）。加工の「なぜやるか」が直感で分かる最初の二次産業
5. **問屋の差別化**: 魚は時間裁定できない・麦はできる→扱う商人の戦略が財の性質から分かれる
- 複雑さのコスト: 1品目のタイマーのみ。「魚は腐る」は万人の常識なので**教える必要すらない**（直感原則に反しない——むしろ腐らない魚の方が不自然）
- 境界規律: 腐るのは魚だけ（野菜・畜産は根菜・生体の抽象として腐らない）。スロープを滑らない

## 開幕の食料シーケンス（叩き台）

1. **着船**: 商館+荷揚げ場に初期物資の山。初期キット案: 世帯5〜8（貯蓄+手荷車持参）/ 材木束（小屋数軒分）/ **麦種** / 網 / 保存食料（麦袋・N日分）/ 少額資金
2. **番頭の最初の一言**: 「まず食い扶持にございます。浜に網場を」→ 漁ゾーン+網場建設 → **数日で魚が上がる**（即時食料・ただし腐る=毎日獲って毎日売る→**市場のリズムが初日から動く**）
3. **麦畑を興す**: 開墾ゾーン→種まき→**待ち時間が生まれる**（この間に住居・きこり・道を進める=3層クロックの教育）
4. **初収穫=最初の大イベント**: 最初の貯蔵（麦は腐らない→納屋・蔵の意味がここで生まれる）・最初の余剰
5. **最初の御用**: 「初荷の麦（or 干物）を本国へ」——チュートリアルの卒業試験。港・輸出・信用の仕組みを一巡させる
- **持参食料N日分=開幕の緊張の設計変数**: 尽きる前に漁を立ち上げる柔らかいタイマー（失敗しても支援要請で救済=信用コストで教える）
- 依存関係メモ: 魚腐敗の価値は**麦の収穫サイクルとセットで最大**。保留中の「季節最小形（農産物のみ・弱め）」がまさにこれ——収穫サイクルだけの最小季節を開幕が自然に要求する

# 追記（2026-07-14）: 移民トリガー・名前つき世帯・最初の御用（B+C 詰め）

Nao_uの種: 「BとC最初からやることを決めたい。島民は建物建てたら移民してくるサイクル→正確には区画を作ったら、かな。1人ずつに名前やプロフィールが欲しい」

## 移民トリガー: 区画=招待状 / 船=心拍 / 住民=viability査定
- 「建物建てたら」→「区画を作ったら」精緻化。既定原則（住民は判断する・船の日が心拍）と噛ませる:
  - **区画作成=機会（仕事/住処の空き）の掲示**
  - 船は船の日周期で来る（心拍）。**移民世帯は開いた区画を「暮らせるか」で査定して住み着く**（食料アクセス+仕事+住居のviability check）
  - 良い立地=埋まる／悪い立地=立て札のまま（都市計画フィードバック）
- 「区画→移民」は総体では真（開いたviable区画が多い=引き強い=次の船が多く運ぶ）だが各区画はviableな時だけ埋まる。テレポートせず船で来て歩く（フロー可視）
- Nao_uの直感（区画→人）と創発/判断原則（人がviability査定）が両立

## 名前つき世帯（個人でなく世帯粒度）
- シム単位=世帯（1設備=1世帯）に合わせ**名前は世帯粒度**: 姓+当主名（+世継ぎ/配偶者）・軽い手続き型プロフィール（出身/生業/家族）
- 深掘りはpin/followした数世帯のみ（全世帯に深profileは不要。RimWorld=全名/Caesar 3=無名/本作=世帯名+軽profile+follow）
- 効能: 創発する物語が読める（「Weber家が長屋から町屋へ」「山村のFischer家が飢えて逃げた」「元通勤者Hansが島初の行商人に」）。相続=名前つき家の世代連続（当主死→世継ぎKlausが継ぐ）。原体験1（崩壊を見る）が人格化して刺さる
- ヨーロッパ職業姓（Miller粉屋/Fischer漁師/Schmidt鍛冶/Weber織工）→生業と姓が一致する遊び

## 最初の御用 = チュートリアル卒業試験（Factor=番頭の声で自己教示）
1. 着船: Factor + 名前つき種世帯3〜4 + 初期物資。Factorの最初の一言
2. 港近くに住宅区画 → 種世帯が自力建設（区画+建設を学ぶ）
3. 漁の仕事区画 → 一家が漁 → 魚（即日腐敗=市場の日次リズム開始）
4. 港の市場が回り始める（財の山）
5. 農地区画 → 麦まき → 待ち（時計・待つ間に他をやる）
6. 次の船が名前つき世帯を運ぶ（機会があるから）→ 作った区画を埋める（移民ループ）
7. 最初の御用着荷（勅許の上納義務）:「次の季までに麦N荷を本国へ」=卒業試験（余剰生成+港/輸出+信用関係を一巡）。達成=信用UP・ループ習得
- Factorが各世帯を名前で紹介→「Schmidt家が採石を始めました」を見守る（名前つき世帯とチュートリアルが噛む）
