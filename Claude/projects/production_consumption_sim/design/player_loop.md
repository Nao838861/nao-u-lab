# プレイヤーは何をするのか — 分単位ループの設計

作成: 2026-07-13（Mir） / 状態: 検討中（第一次案）
親: [../README.md](../README.md) / 発端: Nao_u「Factorioに構造が近い。輸送ロボ版Factorioだと味気ない。何をやって何を楽しんで何を待つゲームか組み立てたい」

---

## 1. Factorio同型の正確な範囲——どこが同じで、どこが決定的に違うか

**同じ**: 需給ギャップの観測 → 埋める生産の配置 → スループット改善 → 新しいボトルネック出現、の永久ループ。ボトルネック解消の連鎖が進行そのもの。

**決定的に違う**: Factorioの機械は**命令に従う**。本作の住民は**判断する**。
- 輸送ロボ版Factorioが味気ない理由の正体: ロジスティクスが「解決済みの問題」になり、流通から物語が消えるから（Factorio純粋主義者がロボを嫌う理由と同じ）
- 本作の輸送層は**意見を持ったロボ**——荷車は価格に従って動き、命令には従わない。つまり**流通は永遠に「解決済み」にならず、生態系との交渉であり続ける**。これが味気なさの解毒剤そのもの
- **設計の護り**: 住民への直接命令（ルート指定・強制配置転換）は絶対に足さない。足した瞬間、住民がロボになりゲームの魂が死ぬ

→ 一言で: **「機械が意見を持っているFactorio」**。

## 2. ゲームの二重構造——港のコックピットと島の庭

プレイヤーの操作対象は性質が正反対の2領域に分かれる。これは欠陥ではなく本作のリズムの核:

| | **港（商館）** | **島** |
|---|---|---|
| 制御 | **直接**（自分の金・自分の在庫・自分の値付け） | **間接**（条件を作る。応答は住民次第） |
| プレイ感 | 相場師（数字・決断・損益） | 庭師（配置・観察・予測） |
| 時間感 | 船の日に集中するバースト | 連続的・ゆったり |
| Factorio対応 | 機械を直接置く感覚が残る場所 | 「意見を持つ機械」の生態系 |

**船の日=2つのモードを往復させるメトロノーム**。便が近づく→港モード（輸出在庫の仕込み・御用の積荷・売買判断）→着船（瓦版+新価格+物資が一気に届く=情報と決断のバースト）→島モード（新しい価格情勢が島に波及するのを見て、構造介入を打つ）→次の便まで観察と微調整→……

## 3. 分単位ループ（島モード: 診断→介入→観察）

1. **見る**: 市場の財の山（高さ=在庫、値札=価格）・荷車の流れ・島内報の見出し
2. **診断する**: 価格の異常はどの連鎖の故障か（炭が高い→丸太が建設需要に食われている→…）。**ここが本作の知的中核**——Factorioのボトルネック探しの経済版
3. **介入する**（手は少なく・全て間接）: 区画を開く / 道・橋を引く / 公費で1軒起動する / 御蔵を操作する
4. **観察する**: 介入への応答が**見えて・帰属できる**こと（道を引いた→荷車が現れる。区画を開いた→誰かが店を建て始める）。応答しない時は**理由が発見可能**であること（資本を持つ世帯がいない→公費か待ち、が読める）
5. 船の日が来て財務モードへ→ループ

## 4. プレイヤーの技能は一つ——「経済の予測」

- 島の介入は**構造の賭け**（「この峠に道を通せば、鉱山村に炭焼きが住み着くはずだ」）
- 港の売買は**価格の賭け**（「瓦版によれば鉄は上がる。今のうちに買い集める」）
- どちらも同じ問い:**「あなたは、この経済がどう動くか予測できるか」**
- これは原体験2「価格ってどうやって決まるのか？経済を理解したい」の直接のゲーム化——**遊ぶこと=経済の理解を試すこと**。理解が深まるほど上手くなるゲーム、という一貫性がミッション（面白さを広い人に）への回答にもなる
- 予測が当たる快感を支えるインフラ=可観測性（設計原則9）。**診断ツールへの投資は、介入手段への投資より常に優先する**（手を増やすとFactorio化・過干渉化の坂を滑る）

## 5. 何を楽しむ（快楽の棚卸し）

1. **予測的中**: 構造の賭けと価格の賭けが当たる瞬間（本作の核快感）
2. **連鎖の開通**: 初めて鉄製品が山村に届く——Factorioの「ラインが繋がった」に相当。ただし**誰も命令していないのに繋がる**分、感動の質が上（自分の庭に鳥が来た系の喜び）
3. **創発の目撃**: 最初の行商人・問屋の誕生・炭→石炭のエネルギー転換・三次産業の出現
   - **設計提案: 創発マイルストーン通知**（「島で初めて: 誰かが荷車を買い、行商を始めました」）。創発は通知しないと見逃される。実績システムと可観測性を兼ねる、Factorioの研究完了通知の創発版
4. **桁の成長**: 文化Lv跳躍で数字の桁が変わる瞬間（マルサス脱出の体感）
5. **崩壊のドラマ**: 意図的に見る（収奪プレイ）・事故として襲われる（本土発ショック）の両方
6. **箱庭の生命感**: ただ眺める（Caesar 3の原体験。等速で人が歩き市場が開く絵そのもの）

## 6. 何を待つ——3層クロックで「待ち」を消す

| 周期 | 待つもの | 待っている間にすること |
|---|---|---|
| 短（数分） | **次の船** | 積荷の仕込み・港の値付け・島の観察 |
| 中（十数分） | 住民の応答・建設・入植 | 港の相場・別の介入・診断 |
| 長（1プレイ） | 文化Lvの跳躍・独立・次の島 | 上の全部 |

Factorioの「待ち時間が無い」の実体は多層クロックの位相ずらし（機械/研究/ロケット）。本作も同じ構造が既に揃っている——**船・住民・文明の3つの時計が常にどれか動いている**。「早くしなくてもやることがある」（確定済みの理想）の実装原理はこれ。

## 7. プレイヤー像の一言（「1行」の部品候補）

- 「指揮者ではなく、**市場の庭師 + 港の相場師**」
- プレイヤーの優位は**視点**（島全体が見える。住民は徒歩の情報しか持たない）、劣位は**手段**（直接命令できない）。神の目と人の手。この非対称が「全能感はないのに全知感はある」という本作固有の座り心地を作る

## 8. 第一印象とオンボーディング（2026-07-13 Nao_u回答で確定）

- **第一印象=シムシティ/Caesar 3に見えて、やることもそう**。わかりにくくしない。深さ（本物の経済）は「次に気づく」層
- **オンボーディング=B理想の弧の再利用**: 序盤はプレイヤーが公費で直接建てる（Caesar 3のプレイ感そのもの）→ 経済が育つと住民が勝手に建て始める。**「頼んでもいないのに店が建った」瞬間=最初のアハ体験**（深さへの入口）。ゲーム進行と学習曲線が同一線
- **港の売買=スパイス+チュートリアル+サンドボックスのガイド**。放置可能（常設注文ベース）。「手が空いた時に何かできること」の一つ（支援要請も同類）
- **番頭（キャラの立った秘書）を採用**: 常設売買の預かり・船の日の実務（積荷目録→プレイヤーは承認だけ）・期日と危険の通知・チュートリアルの声
- **番頭の境界線: 守りは番頭、攻めはプレイヤー**。事実と危険は報告するが、儲けの妙手・構造戦略は提案しない（Clippy問題の予防——診断の喜びを奪わせない）
- 「庭師+相場師」は商品の1行ではなく内部デザインテーマ（Nao_u判定）。商品の1行は「街づくりに見える」を先頭に置くこと
