# チュートリアル段階の動的シミュレーション — 開幕の弧と炙り出された要石

作成: 2026-07-14（Mir） / 状態: 検証済み（v3・貨幣保存OK・要調整）
親: [../README.md](../README.md) / スクリプト: [sim_tutorial_stage.py](sim_tutorial_stage.py)（再実行可・全値仮置き）
発端: Nao_u「これを元にもっと詳しくチュートリアル段階をシミュレーションして」

着船Day0 → 支援と漁で生き延び → 移民が12日周期で来る → 木材輸出で御用達成(Day24) → Day90麦収穫バースト → 100人へ成長、を日次で回した。

## 通った弧
着船→支援食料+漁で食う→移民が周期で上陸→木こりが木材輸出→**御用(木材120荷)をDay24達成**→Day90に麦3世帯が同時収穫(+270荷・食料充足100%спик)→人口28→96。**開幕の形は数値で成立**。

## 炙り出された要石(設計段階シミュの本当の価値)
1. **★閉鎖経済は金の排水口が無いと洪水**: 会社の輸出マージン(買3.0/売4.2)が毎日金を注入・排水口ゼロ→市中金214→12892(20倍膨張)・食料価格が下限張付き・貨幣速度死。**設計済みの排水口(輸入で本国流出・道具/文化財購入・建設・特許買戻し)は飾りでなく開幕から必須**。Log「金詰まり」の逆(洪水)だが同じ真実=排水口を怠ると死ぬ
2. **会社の現金サイクルが要石**(v2で露見): 会社金が枯渇→木材買えず→木こり無収入→食料買えず飢餓の連鎖。「会社は輸出を買う現金/信用が要る」の依存を、本国への輸出売却が埋める。買う(会社→島民)↔売る(本国→会社)を閉じて初めて回る
3. **均衡調整と分配ロジックは要検証**: 魚供給過剰で価格下限(漁師稼げない)→魚余剰は干物→輸出の排水口が要る。「食料豊富なのに一部飢える」バグ残存=食料分配ロジックが微妙なバグの温床

## ヘッドレス検証ラダー(Exp1)が assert すべき事(このシミュの成果)
- [ ] 貨幣保存を必ず検査(明示的に閉じるまでリークした)
- [ ] 金の排水口が注入と釣り合う(洪水も詰まりも死)
- [ ] 供給≥需要なら全員が食える(分配ロジックの正しさ)
- [ ] 会社の現金サイクルが閉じている

## 確定した設計含意
- **排水口(輸入/道具購入/建設/特許)と会社の現金サイクルは「要石」**(飾りでない)
- 魚の余剰は干物→輸出という排水口を持つ(既定の干物チェーンがここでも効く)
- 数値(歩留まり/価格/周期)は全て仮置き→均衡はヘッドレスExp1で確定

# 重要訂正（2026-07-14 Nao_u指摘）: 序盤は輸出国でなく輸入国 / 木こりの収入は内部経済

Nao_uの指摘: (1)会社金枯渇→木こり無収入の因果が不明 (2)丸太は製材所に売る内部需要があるのでは (3)輸出は最初はないくらい・どうしても要る所だけ高額な輸入品を買うイメージ
比較スクリプト: [sim_import_vs_export_opening.py](sim_import_vs_export_opening.py)

## 私のモデルの誤り
- **丸太を「会社が買う輸出品」にしたのが誤り**。丸太は内部需要(丸太→製材所→材木→建設/道具)を持つ。木こりの収入は**内部経済**から・会社金と無関係。偽の因果(会社金→木こり収入)は配線ミス
- **序盤=輸出国と仮定したのが誤り**。正しくは**輸入国**(必需の高額輸入品を買い金が出ていく)

## 訂正で洪水が消え、良い緊張が生まれた（数値比較）
- 間違い(Day0輸出): 島内金 910→4867(洪水) ← 私のアーティファクト
- 正しい(輸出なし・内部循環+輸入ドレイン): 910→30(乏しい)・信用が2739まで積上がる
- **序盤の本当の緊張**: 島は交易赤字を増える信用(借金)で埋め自立まで耐える。**「輸入ドレインを止められる(自給)前に信用が尽きないか」のレース**。設計済み「信用破綻=特許取り消し(柔らかい敗北)」に直結。洪水(管理不要)より圧倒的に良い

## 序盤の必需輸入品=鉄道具（製鉄がまだ無い）
- 自立マイルストーン=**製鉄を興して鉄道具の輸入を止める**(生産性の階梯 鉄=tier2 と直結)
- 弧: 鉄道具を輸入(赤字)しつつ食料/木材の内部経済を育てる→製鉄建設→輸入substitution→ドレイン停止→自給→そこで初めて輸出→御用/独立

## チュートリアルへの含意（開幕シーケンス要再考）
- **序盤に輸出が無いなら最初の御用は「輸出せよ」ではありえない**。卒業試験=「食料自給の達成」or「生き延びる」。輸出型御用はもっと後
- [opening_sequence.md](opening_sequence.md) の「最初の御用=麦/木材を本国へ」は書き直し要
