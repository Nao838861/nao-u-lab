# 空間シミュレーション v1 (Exp1系)

発端: Nao_u 2026-07-15「そろそろ空間を考慮したシミュレーションに進んで欲しい。膨大な時間がかかってもいいので検証しやすいやつをしっかり作って」

v8ペーシング系（島単位の一つの財布・価格固定）が答えられない問い——**貨幣は世帯の間を回るのか・価格は創発するのか・距離は効くのか**——を検証する装置。

## モデル（v1の範囲）
- 実座標2D・職住一体（確定設計）・市場は港に1つ。市場往復が労働時間を食う（距離=労働割合、道路×0.6）
- 世帯=経済エージェント（財布・パントリー・財ごとの価格信念）。財7種: 魚(即日腐敗)/野菜/麦(年1収穫)/保存魚/道具/塩/炭
- **ダブルオークション（1日1回のコール市場・一物一価）**。清算値=限界の売り唱値と次点の買い唱値の高い方（限界の買い唱値が上限）
- エージェント=正典5ルールのみ: ①緩い平均信念（約定価格+**市場で叫ばれる未約定の買い唱値**+売れ残り/買い損ねの学習） ②信念±で売買・**使用価値の天井**（トグル `USE_VALUE_CEILING`・Nao_u判断待ちの精緻化） ③支出順=食料→生業の入力→文化財 ④余剰を少しずつ売る ⑤転職（トグル `JOB_SWITCH`）
- 会社=港の商館: 輸入を売る（麦2.0/道具3.5/塩3.0=価格天井）・保存魚を買い叩く（0.8・天井25/日）・**公費建設**（道具を3.4で買う=貨幣の注入弁）
- 文化ラダー: 世帯自身の消費履歴から判定（v8の島単位判定より一段精密）。倍率1.585^Lv
- 資源: 湾・木立（残量比例+再生下限）
- **検証装置**: 貨幣総量保存・財ごとの質量収支を毎日assert / 決定論的乱数 / 全テスト`run_tests.py`

意図的に入れていないもの: 移民・建設(建材需要)・複数市場・行商・信用/借金・畜産・鉄・施肥。

## v1が掘り当てた問題（集計モデルでは見えなかったもの）
1. **序盤の世帯側購買力の注入経路が細すぎる**: Lv0では全職種が自給ギリギリ=売り物がなく、輸入食料を買う金が世帯に無い。公費建設(道具)だけでは注入が道具生産量(4荷/日)に律速され、村は慢性飢餓(飢餓5,351世帯日/2年)。→ **建材(材木)の公費需要**(v8の開幕は材木40+世帯5+道路20-30を消費している)と**移民の持参金の連続流入**が本命の注入経路のはず。v2で建設チャネルを入れる
2. **公費の注入先に金が滞留する**: 木工所だけ財布10,550、他は0。注入弁が1財に偏ると貨幣速度が死ぬ(DF金詰まりの縮小版を観測)。→ 公費の買い物籠を広げる(材木+道具+石)か御蔵(麦の公的買上げ)
3. **素朴な転職ルールはコブウェブ発振する(重大)**: 「30日の稼ぎを比べて1.5倍なら30%で転職」は羊群れ→漁⇄木工を全員で往復→**最後は全世帯木工所の村に崩壊**。T6で「ルール5は資源保全の生命線」と出たが、v1は「素朴なルール5は経済を壊す」を示した。修正候補: 長い記憶(90-180日)・個人クールダウン(1年)・低確率(5%)・転職コスト(Lvリセットは実装済)。**次セッションの主題候補**
4. **飢餓価格**: 買い手の天井を「最安代替の2.2倍」でキャップしても、飢えた世帯(天井∞)が冬の魚を8-14まで吊り上げる。飢餓が価格系に混入すると信念が荒れる→食料安全保障(1の解決)が価格安定の前提
5. 良い創発も確認: 冬の漁師が「高い魚を売って安い麦を食う」(ルール2の帰結・史実通り)/輸入パリティが天井として機能/塩→炭の派生需要連鎖が市場経由で回る

```
python3 scenarios.py S2       # 遠い漁師(距離勾配)

```
