## 問題の構造: 3つの時間スケールが別々の実時間を要求
- 1日（市場・荷車の動き）: 観察できる長さ=秒〜1分
- 季節（麦収穫・冬）: リズムとして感じたい=分〜数十分
- 年/世代（加齢・長い弧）: 妥当な実時間で過ぎたい
「360日=1年」だと日と年が360:1で縛られ両方を良くできない → **二重時計で切り離す**（年を360観察日にしない・意味あるサイクルを feel で選び年/世代は緩い背景に）

## 提案1: 1日 ≈ 20秒（通常速・15〜30調整可）＋早送り
| 出来事 | 経済日 | 実時間(20秒/日通常) |
|---|---|---|
| 1日(市場・荷車) | 1 | 20秒 |

| チュートリアル卒業 | 〜35 | 〜12分 |

| 冬周期 | 60〜70 | 20〜23分 |
- 早送り2/4/8倍で待ち圧縮(麦60日を4倍=5分)。荷車も観察可(D0.5往復=10秒・視覚速度キャップで早送り時も見える)
- プレイヤーは日数を数えず流れを眺めリズムを感じる(市場の鐘が1日1回程度)

## 提案2: 「作物年」≈60〜80日にする（360日は捨てる）
- 暖季(育てる)→収穫→冬(蓄えで生きる)→暖季 の約60〜80日を「1年」に。麦サイクル=季節と一致
- 麦を暖季にまく→Day60収穫→ちょうど冬→蓄えた麦で越冬
- 冬=魚/野菜(生鮮)が落ち麦/保存食(塩漬け/干物)が要る=**食料備蓄の試練**(約20分ごとの季節ビート)
- 360日4クォーターの長い暦は不要。**冬という一つの試練が周期的に来ればいい**(park済み「季節の最小形」の具体化)

## 提案3: 加齢/世代は作物年から切り離す
- 加齢は背景・イベント式(既定)で作物年と別の遅いペース。生育1年ごとに1歳だと死にすぎる→加齢はもっと遅く、ゲーム全体(数時間)で1〜2世代が回る程度に独立チューニング。「年の数は重要でない」既定方針のまま

## まとめ
現実的な年数を数えない。**意味あるリズム(日≈20秒/船≈4分/作物年≈20〜25分/冬のビート)を気持ちよさで選び、暦上の年・年齢は緩い背景に**。→「360日が長い」は構造的に消える(年を360日にしない)。数値仮置き・構造(切り離す・サイクルは feel で選ぶ)が答え。

# 追記（2026-07-14）: 昼夜・麦短縮・冬の労働（Nao_uフラッシュアイデアへの応答）

## 昼夜は捨てる → 季節のライティング
- 20秒/日で昼夜は数秒点滅=不可能かつ二重時計の嘘が露見→**昼夜は捨てる（確定裏付け）**
- 代わりに**季節の光**: 作物年(≈40日)にわたり暖色(夏・金色)→寒色(冬・青)へゆっくり変化。点滅せず季節=冬ビートを視覚化=「正しい光の嘘」（昼夜=速い嘘は捨て季節=遅い嘘を光に載せる）

## 麦20分は長すぎ → 麦の個性は「貯蔵性」で保ち短縮
- **麦が野菜と違うのはサイクル長でなく貯蔵できること**（野菜=腐る/麦=∞貯蔵→冬と輸出）→麦は暖季一度収穫≈30日(10分)でよく役割は保たれる
- 締めた暦: **暖季≈30日(育てる)＋冬≈10日(蓄えで生きる)＝作物年≈40日(約13分)**。麦=暖季末収穫30日/野菜=暖季中ちびちび/魚=毎日

## 冬の人は何をするか → 冬は「建てる・作る季節」
- 前近代の冬=屋内仕事の季節(建設・道具作り・脱穀・修繕)。**夏=育てる(屋外)/冬=建てる作る(屋内)**
- 野菜農家は冬に暇にならず建設・運搬・加工へ移る=**既存の労働メカニクスから創発**(冬に畑産出0→機会費用下がる→他の仕事を取る→稼ぐ→蓄え食料を買う)
- おまけ: **建設が自然に冬に集中**(農閑期に人手が空く)。夏は畑が伸び冬は街が育つ=記憶に残る季節リズム
- 漁は冬も継続(減may)→冬の食料=魚＋蓄えた麦/保存食。**冬は短く(≈10日=3分)「ちゃんと蓄えたか」を問うpunchyな試練**(長い死んだ季節にしない)

## 更新した数値(仮置き)
- 1日≈20秒 / 暖季≈30日 / 冬≈10日 / 作物年≈40日(≈13分) / 麦≈30日 / 野菜≈暖季中ちびちび / 船≈12日(4分)

# 追記（2026-07-14）: 暦の単位を「月」にする案（Nao_u提案・有力）

Nao_u「季節があるのに一年が365日でないのは違和感。昼夜がないので暦を1ヶ月単位にしたら？」→ 複数問題を一気に解く良い筋・設定にも史実的に合う

## 提案: 暦=月/年、「日」は内部シミュ刻みに降格
- **暦=月/年**(12ヶ月=1年・季節は月範囲・プレイヤーは「2年目の3月」を見る)=自然で違和感なし
- **「日」は内部のシミュ刻みに降格**(プレイヤーは日数を見ない)。経済は連続的な流れ＋月の暦
- 実時間: **1ヶ月≈1分 → 1年≈12分**。40日問題も365ティック問題も消える(プレイヤーは月だけ見る・内部刻みは実装詳細)

## 一番の収穫: チュートリアル=「最初の一年を生き延びる」
- 春:上陸・畑を興す / 夏:漁と野菜で繋ぎ麦が育つ / 秋:麦初収穫(蓄え) / **冬:試練=蓄えで越せるか=山場** / 翌春:生き延びた=卒業
- 最初の冬=チュートリアルのクライマックス=植民地物語の王道(プリマス/ジェームズタウン「最初の冬を越せるか」)。日数より圧倒的にthematic

## 市場=「月の市(フェア)」— 史実に完璧
- 中世市場はperiodic(週市・季節の大市)→市場セッションを**月一度の市(フェア)**に=史実そのもの。町に人と財が集まり価格が立つ見える町イベント
- 月の間の日々の需要は既設計の**行商人・常設店の小売層**が捌く。魚=「翌月の市まで持たない=新鮮なうちに売る」で腐敗の役割維持。月に強いビート(市の日)

## 正直なトレードオフ
- 失う=日次の市場ドラマ(豊漁の朝→夕方地面)。代わりに市は月次
- でも(a)連続的な流れは月の中でずっと見える (b)月の市という強いビート (c)ジャンル標準(Caesar 3/Anno=連続生産＋暦)に合う。魚腐敗の役割は保たれる
- **これまでのシミュ結果は無効にならない**(距離=労働・貨幣・食料均衡は単位非依存→「日」を「月の内部刻み」と読み替えるだけ・暦ラベルが変わるだけ)

## 更新した数値(仮置き・月暦案)
- 1ヶ月≈1分 / 1年=12ヶ月≈12分 / 麦=春まき秋収穫(≈半年=6分) / 野菜=1〜2ヶ月で実り継続 / 冬=2〜3ヶ月 / 船=月1〜2回 / 市=月1(フェア)
- チュートリアル=最初の1年(≈12分)・最初の冬が山場

# 追記（2026-07-14）: 実装の簡潔形 = 「日はそのまま、30日を1ヶ月に束ねる」（Nao_u）

「月を原子に変える」必要はなく、**日はユニットのまま・月は表示とシーズンのくくり**にするだけ:
- **日=内部シミュ刻みのまま**（全シミュ結果と日次メカ=魚腐敗/荷車がそっくり生きる）
- **30日=1ヶ月・12ヶ月=1年を暦表示+シーズングループとして被せる**（`month=day//30`, `year=month//12` で導出）
- プレイヤーは「2年目の3月」と季節を見る/日は見えない内部ステップ

## 固める数字: 1日≈2秒
- 年≈12分にしたいなら 年=360日 → **1日≈2秒**(12分÷360)。日は個別に眺めず速く流れる内部ステップ。荷車は日をまたいで連続移動→2秒/日でも滑らか(視覚速度キャップ+残像)

## 小技: 「日」を画面に出さない
- **表示は月と年だけ・月内の日付は見せない**(「3月」であって「3月14日」でない)→30/31/365の違い完全不可視・「360vs365」違和感も消える・日は純粋に内部定数=実装が自由
- 月の市(フェア)は必須でなく味付けの装飾(ベースは連続的な流れ)

## 結論（時間スケール・確定寄り）
- **日=内部ステップ(≈2秒)/30日=1ヶ月/12ヶ月=1年を暦表示/日付は見せない/季節=月範囲**
- チュートリアル=最初の一年(≈12分)・最初の冬が山場
- 全シミュ結果は日ベースのまま有効(暦は表示の被せ物)

# 訂正（2026-07-14 Nao_u指摘）: 「冬=建築の季節」は取り下げ

Nao_u「冬が建築の季節も違和感ある。夏と冬の違い、建築は誰がどうやるのか考えたい」→ 正しい（冬の建築は史実的にも困難＝凍土/雪/短日照。冬の屋内仕事は織物/修繕であって普請でない）。**「冬=建てる作る季節」は取り下げ**。

## 夏と冬の違い = 食料と燃料（労働の役替えではない）
- 季節の本質: **屋外の食料生産が冬に止まる**（作物休眠・漁は嵐と寒さで激減）。消費は続く→**夏=作って蓄える/冬=蓄えで生きる**。緊張は「ちゃんと蓄えたか」の一点
- 冬は**食料(麦/保存食/塩漬け)＋燃料(炭/石炭で暖房)**の両方を試す（燃料チェーンが季節的に意味を持つ・冬に暖房需要が跳ねる）
- 冬は短くpunchyな試練
- **役替えは強制しない**: 冬は自然な小休止。食料生産者(農/漁)は活動が緩み休み/軽い屋内仕事/消費で春を待つ（忙しい夏の呼吸）。全員フル稼働させる必要はない
- **止まるのは屋外の食料生産だけ**: 木こり/鉱夫/職人/建設/交易は年間継続（冬は伐採の適期ですらある=凍土で運びやすい）。暇になるのは人口の一部（食料生産者）のみ・プレイヤーも冬は計画の静かな時間

## 建築は誰がどうやるか（季節と無関係・年間通した需要駆動）
| 建てるもの | 誰が | どうやって |
|---|---|---|
| 簡素な建物(家・基本工房) | **所有世帯が自力建設**(棟上げ式) | 自分の労働＋材木を市場で買い→運搬→工期で建てる |
| インフラ(道/港/橋/公共) | **会社の普請隊** | 公費で材料調達→施工(所有者いない建造物は専任建設主体が要る) |
| 大型/石造/専門建築 | 当面は会社普請隊(公費)/将来は職人 | 石工・大工の専門職は後の創発(賃金労働=運送契約と同じく保留) |
- 材料は必ず「丸太→製材所→材木→市場購入→運搬→工期で消費」のフロー(無主在庫なし・建設需要が経済還流=景気)
- **建築は需要のある時に年中起きる**(家普請も工房も稼ぎと材木があれば季節問わず)。冬に寄せない
