## R1: 盤の基盤(マルチタイル+マップ拡大)

### マップ
- 【未】96x80へ拡大(現48x40の4倍面積)。時間スケールは不変(SCALE=2で歩行・空間定数を同時スケール=呪いの強度は現状維持。強化はR3で段階的に)
- 地形生成の再設計【測】: 資源(森・岩・水)の配置=距離の呪いの較正そのもの。中継蔵を置ける間隔の陸地・南岸の水域と橋の要否を要件に含む
- 1日圏の帰結を明記: R5(分市場)まで、実効的な入植可能半径は現行相当。外側は「見えるが使えないフロンティア」として意図的に見せる

### 建物フットプリント(サイズ表・【未】裁可対象)
| 建物 | サイズ | 備考 |
|---|---|---|
| 住家(全職共通) | 2x2 | Lvで外観進化(絵はフォールバック連鎖) |
| 麦畑・牧場 | 3x3 | 母屋+圃場(圃場絵は装飾。機構は世帯単位のまま) |
| 菜園 | 2x2 | |
| 木工・炭焼・塩屋・採石 | 2x2 | |
| 市場(核) | 3x3 | 物資の山を持たない |
| 市の広場 | 1x1×n | 舗装タイル。屋台が立つ。**初期広場8-12タイルを市場に付属**(開幕デッドロック防止)。通行コスト0.6 |
| 蔵 | 3x3 | 事務小屋1+山スロット8(1品目50荷・充填4段階)=400荷/棟。非生鮮のみ。スロットは自動割当 |
| 港複合(=商館) | 4x3岸接 | 桟橋2(水にせり出す)+事務所+荷揚げヤード2。本土との全フロー(輸出入・注文・移民)の物理的境界 |
- 建物サイズ別の支度金表【測】(3x3>2x2。現行2,500デナリを基準に実測較正)
- **通行**: 建物タイルは不可侵(U1)。経路場は建設/撤去時にも無効化。盤レイアウトの通行保証テストを常設
- **専有・撤去**: 配置は確定タップ(ゴースト→確定)or直後アンドゥ(同日内全額返金)。撤去ツール必須
- **廃屋の再入居**(W11): 離散した家は「空き家」に戻り、修繕費【測】で再充足可能な区画になる
- 屋台は**世帯単位**(1世帯1台・定位置・実測15-25台)。engineの財別屋台は変えず描画のみ集約(C5)

### 人口(v0.22の仕組みをそのまま継承)
- 出生(月12%)→8人以上の家族が空き区画に分かれて入る(納屋・財布持参)→移民は余剰なし+非飢餓時のみ
- 分家の湧きに空き区画が無い時は「土地が無い」をイベント+秘書で名指し(土地圧=拡張動機)

## R2: 道パッケージ
- **線引きUI**: 起点クリック→ドラッグで8方向スナップの直線プレビュー(費用=人日×賃金と完成見込み日数を表示)→離して一括計画
- **8方向の道**: 対角は直線区間のみ・交差点は直交に限る(SC4制約=描画の組合せ爆発も防ぐ)
- **オートタイル描画**: 中心+8方向枝の合成方式(土/石畳×9枚=中心1+枝8)。幾何的に2^8通りの接続を全被覆
  - **交差の正規化(ツール側の義務)**: 対角線が他の道と交わる/接続する時、線引きツールが自動で直交ジャンクションタイルを挿入する(SC4制約「対角は直線のみ・交差は直交」を描画でなく配置で保証)
  - 獣道(road_trail)はオートタイル対象外(踏み分けの有機的パッチは接続しない方が自然)
- **撤去ツール**(返金なし・撤去人日ゼロ【未】要確認)
- **S案移動**: 道外の移動コスト増(草1.0→1.6目安【測】)+帰路も経路場化→「人が道を歩く絵」
- 森タイルの道は伐採込みで人日増【測】
- 飯場(泊まり込み普請・W9)はこの段階で設計だけ固定し、実装は道が1日圏を超えるR5前でよい

## 通貨フェーズ: 家普請+材木Phase2(W14の実体・X1の結論を反映)
- **昇格を「消費の維持」型から「資産の取得」型へ**: Lv N→N+1に、従来の充足維持に加えて
  **建材の実消費(材木・石・道具の一定量)による「家の増築」を要求**。貯めれば確実に進む(市場の揺らぎで
  降格しない)・貯蓄の意味・建材需要の常設化(=職人チェーンへの通貨環流)の三役
- 増築の建材はプレイヤーの商館経由でも市場経由でも買える(どちらも金の使い道)
- **材木Phase2**: 丸太→製材所→材木(建材)を分離。炭焼は丸太購入と自伐のハイブリッド化
- 必要量・価格帯【測】。監査: E8の定義を「資産型昇格でLv5到達」に改訂
- 環境上限(R3)より先に入れる(D1の順序)

## R3: 住環境スコア(辺境ジレンマの起動)
- 家のLv上限=住環境スコア: 市場への実効距離(道込み)+負の隣接(炭焼・塩屋の煙)+サービス被覆(将来)
- 木こりの山小屋は収入が良くても環境上限で頭打ち=「木こりは豪邸に住めない」
- 富裕世帯の資金出口は家普請が先に用意済み(D2)。負の隣接の遡及は基準村再設計で吸収(D3)
- 距離の呪いの強化(時間スケール調整)はここで段階的に【測】

## R4: 接道義務+道限定移動(H案)
- 全建物に接道義務(市場ネットワークへの接続)。孤立検出と「繋がっていません」の可視化
- 移動は道の上のみ。例外: 建設人夫(道外OK)・自宅=作業場の一次産業(家までの道で足りる)・採集
- 既存無接道建物は祖父条項【未】

## R5: 流通レイヤー(主題の本体)
- **分市場**: プレイヤーが建てる第二の市場。世帯は最寄り市場に固定(比較購買させない)
- **市場別px**: 成約EMAを市場ごとに。costのstapleは自市場px(辺境の生計費は現地物価)。staple床1.0は全市場共通
- **輸入棚は港市場のみ**→辺境の価格は流通だけが抑えられる(蔵出し=プレイヤーの流通が天井を作る)
- **荷役=worksite型の商館機能**(新職にしない・W3)。蔵ごとに「集める/配る」の2値指示のみ。
  **中継制約: 蔵は1日行程以内の間隔**(W10)——中継蔵の鎖=物流網の設計
- **荷車(2026-07-18 Nao_u指摘で仕様化——散文にだけ存在し機構も絵も未定義だった)**:
  - 商館の資産としてプレイヤーが購入(【測】価格。金の使い道)。蔵に配備し、荷役worksiteが使う
  - 容量=人の運搬の5倍目安【測】・**道の上しか走れない**(ハード制約)——道限定移動(R4)の第一適用者。
    人の移動はソフト制約(道外コスト増)のまま→「人は野を歩けるが、荷は道がないと動かない」の段階設計
  - 絵: cart(空)/cart_load(積載)+牽き手。assets/MANIFEST.mdのR1以降に追加済み
  - 農家の収穫運搬等の民間荷車は将来拡張(まず商館の荷役のみ)
- **行商=民間の新職**(裁定者)。市場2つ以上になるまで転職候補に出さない
- 辺境の成立条件(第6精査A)を較正基準に: 中核の資源価格>辺境の現地原価+運送費
- 監査: E17(流通整備で辺境食料価格が港の1.5倍以内)/E18(行商の年収が正)/E19(未整備なら2倍超に開く)
