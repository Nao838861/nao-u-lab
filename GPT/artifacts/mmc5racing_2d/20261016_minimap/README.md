# MMC5Racing 2D：ミニマップ復活版

GPTフォルダーの `play_mmc5racing_minimap.cmd` で起動する。ROM単体もこのフォルダーに保存した。専用3D版ではなく、通常のMMC5版である。

右下に固定向きの32×32pxコース図、自車を赤い中心と白い縁のマーカーで表示。地図外の座標は端へ制限する。既存の主画面とfine Xを共有するため、地図全体は最大7px横に移動し、自車マーカーも同期する。

DRIFT／GRIP各1,100framesの状態・位置・公開数を旧版と比較し一致。10画面の地図外画素も一致。座標変換は実6502で6,144ケース、追加109〜146cycles。転送／割り込みの追加時間と追加RAMは0。実機、手動プレイ、全負荷姿勢、全ソース再ビルドは未実施。基準ROMからの最終overlay再生成はbyte一致。

ソースは `source.json` の専用ブランチへpush済み。mainへの直接pushは自動承認レビューで拒否されたため、リモートmainは更新していない。ローカルの `MMC5Racing/play_latest.cmd` も新ROMを選ぶ。
