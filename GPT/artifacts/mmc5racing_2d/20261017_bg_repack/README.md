# コースCHRの再配置によるBG番号確保

2026-10-17、「他に影響がないならやってみて」という依頼に対する配置実験。**使える番号を23個から82個へ増やせた。現在のミニマップ16個＋TIME/TOTAL 7個を引いて59個残る。** LAPの静的BG表示には3個を使うため、その後も56個残る。

通常版・mainの配布ROM・起動スクリプトは変更していない。今回の成果は、既存表示と走行が変わらない再配置候補、および通常LAPの背景表示試作。GO/BAD LAP/GOALなど状態別ラベルの本実装は別工程。

## 何を変えたか

従来は、使ってはいけない番号にある絵だけを、未使用の場所へ順番に移していた。今回は四半周ごとにコースの同一ビットマップをまとめ、各絵に必要なパレットを維持できる配置先を最大流で割り当てた。絵の保存場所と辞書参照のみを変更する。色指定、ゲームコード、毎フレームの命令数、RAM、ROM容量は増やさない。

画面の角度によって共有される辞書参照・一様セルの固定参照は維持。スプライト・タイトル・結果画面に使うCHRページ0/1/62/126/190/255は全byte一致を必須とした。最初に従来手法で見つかった追加番号63は保護ページ1を変更するため不採用。旧手法の「空き」の判断だけでは安全性を保証できなかった。

既存の退役番号に119/120/122を追加して配置を解いたところ、配置の集約により他の番号も空いた。82個は今回見つけた配置での確保数であり、理論上の最大値ではない。また、空いた番号はBGグラフィック用であり、表示領域・初期化コード量など別の制約が消えるわけではない。

## 検証結果

- 全128方向、1,722,368セルで、元のコースの16byteの絵とパレット指定が一致。
- 保護CHR 6ページの全byte一致。split用8ページへのコース参照なし。
- Mesenで既存B2版と再配置版を比較し、522枚の全画面が画素単位で一致。
- DRIFT/GRIP各1100フレームで状態・座標・描画更新・棄却値などの記録が一致。走行、旋回、再スタート、結果画面遷移を含む。
- fine X 0〜7 × coarse X 4位相 × CHR 4四半周 × 2時点 × 両モードで一致。
- 自車マーカー座標計算6144ケース、スクロール選択18ケースも既存検証に合格。
- LAPの静的BG試作は別ROM。512画面で灰色ラベルの全画素と固定位置、およびラベル矩形外の画素一致を確認する。試験開始時のGOが重なるため、この表示試作だけGO字形も消している。本実装には状態切替対応が必要。

エミュレーターと全コースデータの検証範囲では副作用は見つからなかった。実機での検証は行っていない。
