# MMC5Racing：B2 HUD＋ミニマップ統合版

`GPT/play_mmc5racing_minimap.cmd` を再起動すると、このROMを開く。

- TIME／TOTALを灰色の背景ラベルとして横並びに配置。
- 小さい `LAP 1 / 5` で字間を確保し、分数字の下のL/Tを廃止。
- 振動しない灰色のミニマップと自車マーカーを維持。
- BEST行は追加しない。

モックのラベル位置はコース用ExRAMと競合するため、横並びを保ってラベルをx168、数字をx200へ移した。LAPは既存スプライトパレットの白色。通常走行中のスプライト数・表示準備時間・割り込み時間は増えていない。

両モード各1,100framesの走行比較、全fine X8通りを含む512画面の固定位置・字形検証、10表示状態と分数字22ケースのCPU検証を通過。実機・手動プレイ・全負荷条件の保証は未実施。

ソースはMMC5Racingのmainへ統合・push済み。詳細は `source.json` と `design_log.md`。
