# LAPを灰色にするパレット比較

専用パレットの2台について、3色のいずれか1色をミニマップ／TIME／TOTALと同じ灰色 `$00` にする全6案。2026-10-17のユーザー依頼によるモック。採用版ROMと起動先は変更していない。

- [6案の拡大比較](options.png)
- [現在との比較・両モードの全画面](comparison.png)

| 案 | 変更 | 見た目の影響 |
|---|---|---|
| A1 | P0の白い車体 → 灰色 | 車体が道路と同色になり、輪郭が弱まる |
| A2 | P0の黒 → 灰色 | タイヤ・影が道路へ溶け込む |
| A3 | P0の緑 → 灰色 | 白い車体と黒いタイヤを維持。緑の識別色を失う |
| B1 | P1の水色の車体 → 灰色 | 車体が道路と同色になり、輪郭が弱まる |
| B2 | P1の黒 → 灰色 | タイヤ・影が道路へ溶け込む |
| B3 | P1の青 → 灰色 | 水色の車体と黒いタイヤを維持。青い差し色を失う |

候補としてはB3を推す。水色の識別色と黒いタイヤを残し、白／緑の車も維持できる。A3も成立するが、白／赤の最速CPUと同じ白い車体となり、差し色による区別が弱まる。

前の会話の「緑／黒／白、水色／黒／白」は誤り。実装と完成ROMで確認した現在の専用パレットは、P0が白 `$30`／黒 `$0F`／緑 `$1A`、P1が水色 `$3C`／黒 `$0F`／青 `$11`。P2は自車・ゴーストとHUD、P3は最速CPUと摩擦円などが共有する。

## 生成と確認

`python artifacts/mmc5racing_2d/20261017_lap_palette_mock/generate.py`

現行 `MMC5Racing_HudB2_136x184.nes` のコピーに、パレット表1byte、LAP2枚の属性と絵の色番号だけを変更し、MesenでDRIFT／GRIPの実画面を取得した。現在＋6案×両モードで14画面。スクリーンショットは通常LAP行が表示されるフレーム450。モード、変更したPPUパレット、LAPのOAM属性と表示Y位置をアサートしている。

拡大した車は完成ROMの他車CHR・角度表・反転属性から復号した角度0／8／16。色はMesen標準パレット、背景は実際の道路色 `$00`。生成画像への手塗りによる色変更は行っていない。

モック用ROMは `.tmp/MMC5Racing/build/lap-palette-mock/` のみに生成する。通常LAP行を比較するためのモックであり、BAD LAP時の追加配置など全状態への対応は採用後に行う。現在の全画面も同じ入力・フレームで撮影した。比較対象は「1組の1色だけを固定灰色へ変更」の6案であり、2台同時変更や別の灰色の明度までは含めない。
