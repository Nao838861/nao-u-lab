MMC5Racing 3D v005 / N8 Pro 最適化試験版 r002（2026-10-18）

実機動作は未確認。r001 と同じ FPGA 回路（gsu.rbf）を使い、GSU の命令だけを最適化。
地面、空、車、木、家、LOD、音、物理、6502プログラムは変更していない。
パレット自動選択の提案は保留。実機用メモリと25MHz設定もそのまま。

実機での起動
1. 本体の電源を切り、sdcard/GSU-RACING-V005-R002 をフォルダーごと SD にコピー。
2. 中の GSU_MMC5Racing3D_v005_N8Pro_r002.nes を選び Start Game。
3. 5秒程度待っても黒いままなら本体RESETを一度押す。
4. メニューには電源を入れ直して戻る。
ROMと同じフォルダーの gsu.rbf が必要。従来の立方体版とr001は保持する。

A: 加速、B: ブレーキ/ドリフト、左右: 操舵、SELECT: 視点切替。
上: ポリゴン表示切替、下: GRIP/DRIFT、START: 走行リセット。

PC確認
このワークスペース内では play_pc_25mhz.cmd で専用Mesenを起動できる。
pc/ のROMはPC専用。SDには sdcard/ 側を使用する。
PCとFPGAは待ち時間のモデルが異なり、同じ25MHz指定でも描画時間は同じではない。

変更
- 頂点変換の固定小数点乗算をループ内に置き、命令キャッシュ外への往復を削減。
- 中間座標と積をレジスタに保持し、RAMへの書き戻しと読み直しを削減。
- 上端クリップ不要の辺は、端点・符号・除数をレジスタに保持してDDA初期化を短縮。
- 固定14/15ビット右シフトの上位8ビット分をHIB命令で処理。
- FPGA回路、外部メモリ転送量、RAM容量、コードの4KB領域は維持。

検証
- 通常1,412条件＋景物2/4回描画の8条件、計1,420フレームの全16KBが旧版と一致。
- 25MHzのGSU RTLで開始4視点と重い4場面の全画素を照合。
- 4回描画の重い1場面も旧版/最適化版をRTLで照合。
- 実6502の起動/NMI外部バス再生、GSU、DSP、完成画像のPSRAM転送を確認。
- 回路はr001のバイナリと完全一致。r001の合成・タイミング資料を同梱。

限界
計測はGSUのGO〜STOP。消去、CPU処理、DSP待ち、画像転送、VBlank待ちは含まない。
描画反復は同じ景物を重ねる合成負荷試験で、異なる物体を4倍置いた試験ではない。
全場面30fpsや実機起動の保証ではない。重い場面の数値はverification/timing-summary.json参照。
外部バスタイミングと実機での継続走行は未確認。r001の黒画面原因を直す変更ではない。
