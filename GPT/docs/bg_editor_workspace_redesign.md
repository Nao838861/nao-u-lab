## 方針

各画面に一つの主作業を割り当て、選択材料を左、編集結果を右へ置く。背景データの構造をそのまま全画面へ露出させない。パレットの下に無関係な管理操作を集めない。

現在の「ブロック」と「ブロックセット」は「ブロックを組む」へ統合する。一覧で編集対象を選び、個別編集／一覧表示を画面内で切り替える。作業切替は4種類に整理する。

| 作業画面 | 左 | 中央 | 右・主編集領域 |
|---|---|---|---|
| タイルを描く | タイル一覧、常時表示のパレット | なし | 拡大ドット編集 |
| ブロックを組む | タイル一覧 | ブロック一覧、新規・複製 | 選択ブロックの組み立て、区画の配色 |
| マップに配置 | ブロック／破壊可能BG／スタンプの素材一覧 | なし | マップ、配置・消去・範囲選択 |
| 破壊可能BGを作る | 使用場所を示すマップ | 破壊可能BGのセット一覧 | 破壊前・破壊後の編集、耐久値・破壊単位 |

## 作業切替

既存の上段タブは「BASIC／BG／スプライト…」というエディタ種類の切替に使う。その下に、通常の小さなラジオボタンとは明確に異なる、大きな文字付きの作業切替ボタンを横に並べる。

```text
BASIC  [BG]  スプライト  音楽・効果音 …

[タイルを描く]  [ブロックを組む]  [マップに配置]  [破壊可能BGを作る]
 ↑ 選択中は背景色＋太い下線

タイルを描く                         ← 作業名と短い操作説明
┌────────────────┬───────────────────────────┐
│ タイル一覧     │ 拡大ドット編集            │
│                │ ペン・消しゴム等はここ    │
├────────────────┤                           │
│ パレット       │                           │
└────────────────┴───────────────────────────┘
```

色だけで選択状態を示さず、下線と作業名を併用する。選択中のボタンを押しても解除しない。Tabで到達しEnter／Spaceで切り替えられるようにする。狭い幅では2行に並べ、文字を切らない。

タブをもう一段置くこと自体が誤りではない。ただし今回は上段との役割差を出すため、動詞付きの作業切替を採用する案とする。縦のナビゲーションは左右配置の編集幅を削るため採らない。

切替時は左の材料と右の編集領域がまとめて変わる。選択対象・スクロール位置・拡大率は各画面で保持する。モードを変えただけで素材や履歴を変更しない。

## タイル画面

- ペン、消しゴム、塗りつぶし、範囲選択などの描画アイコンはタイル画面だけに表示する。編集領域の直上に置く。
- パレットは左下に固定し、一覧のスクロールや「属性を隠す」で消えない。番号だけでなく選択色の枠も表示する。
- 編集サイズ、コピー・貼付、反転、色置換も描画ツールの近くへ置く。
- 画像取込み・書出しはタイル一覧の見出しにある「タイル操作」へ、列数は一覧の表示設定へ置く。
- ブロック作成、破壊設定、マップ採用、開始位置、マップ層などは表示しない。
- ブロック画面から絵を直したい場合は「このタイルを描く」で対象を引き継いでタイル画面へ移る。

パレットを閉じられる現行の属性パネルと分離する。画面が小さくてもパレットを先に確保し、タイル一覧とキャンバスをスクロール可能にする。

## ボタンの配置

| 操作 | 配置先 |
|---|---|
| 新規・複製・名前変更・削除 | 対象一覧の見出し／操作メニュー |
| 選択区画の配色 | 組み立て領域の近く |
| タイルの共有解除 | 区画の操作メニュー。影響を短く表示 |
| 属性・耐久値・破壊単位 | 選択対象の編集領域に隣接した設定欄 |
| 破壊前から破壊後へコピー | 破壊前／破壊後の切替の横 |
| マップへの採用・開始位置・テスト | マップ画面の操作列 |
| 保存・実行・Undo/Redo | IDE共通の操作とショートカット |

削除や共有解除は無関係な場所に常時並べず、対象を選んだ位置から操作する。

## マップ画面

タイル一覧とブロック組み立て欄は表示しない。左の素材一覧から選び、右へ敷き詰めることに集中する。左側で素材種別を選ぶと、配置対象も対応する種類へ変わる。別の場所にある「層」の設定との二重指定を避ける。

描画用のペンアイコンを流用せず、「配置」「消去」「範囲選択」と表示する。必要な塗りつぶしも「範囲を埋める」として配置操作へまとめる。表示専用の層のON/OFFは、配置対象の選択と区別する。

固定画面も同じ配置操作にする。画面の用途やサイズによる制約は対象選択時に表示する。

## 破壊可能BG画面

「左がマップ」は、完成した部品を置くキャンバスではなく、使用場所から編集対象を探すためのマップと解釈した提案。左から右へ「使用場所 → 部品 → 詳細」を辿る。

1. 左のマップで配置済みの破壊可能BGをクリックする。
2. 中央の一覧で対応するセットが選択され、同じセットの使用場所を左で強調する。中央から直接選ぶこともできる。
3. 右で破壊前・破壊後を切り替えて編集する。小さな比較表示で両状態を確認できるようにする。
4. 右の組み立て領域の左端にブロック一覧を置き、ここでも「左から選んで右へ置く」を保つ。
5. 耐久値・破壊単位は右の設定欄、複製・削除は中央のセット一覧、配置は「マップに配置」へ移って行う。

未配置の新規セットは中央から作成できる。左のマップに配置がないことを理由に作成を妨げない。

左のマップは折り畳み可能とする。常時フルサイズのマップとセット一覧と編集面を並べると右の編集幅が不足するため、初期状態では小さな使用場所プレビューとし、必要時に広げる。この画面でのマップクリックは選択だけにして、誤配置を防ぐ。

もし意図が「左のマップから範囲を拾ってセットに登録する」なら、その操作も「選択範囲から作成」として同じ導線に追加できる。主機能は使用場所と部品の対応確認、登録は明示操作とする。

## 実装と確認の順序

1. タイル画面の常時パレット、描画専用ツール、マップ関連操作の除去。
2. マップ画面を素材一覧＋配置領域へ整理。共通の作業切替を導入。
3. ブロックの2モードを統合し、区画へのタイル割当を主操作にする。
4. 破壊可能BGに使用場所の表示・セット選択・詳細編集の連動を追加。

各段階で、既存プロジェクトの保存／再読込、中ボタン交換、Undo/Redo、各画面へ戻った際の選択復元を確認する。タイルのパレット常時表示、マップでタイル一覧が出ないこと、非タイル画面で描画アイコンが出ないことを表示試験で確認する。

今回の検討は現行の `bg_studio.py` と `bg_composer.py` にある操作・依存関係を基にした。データ形式の変更はこの再設計の前提にしない。
