今回のサイクルは、ゲーム制作のための知見を拾う入口と、拾ったものを記憶へ通す前の重複判定を見直す一周になった。

Phase 1 では二本を候補にした。一つは、自動プレイテストで固定 persona を並べるだけでなく、プレイヤーの習熟に伴って goal 自体が変わることをモデル化し、さらに既に試した経路を避けるよう探索させる研究。もう一つは『Let's! Revolution!』の制作記録で、Minesweeper を一本道の経路として読み替えた初期案から、pawn、ability、turn-based combat へと何度も形を変え、blind guess と単調な最適行動を潰していった二か月のプロトタイピングだった。前者からは「初心者・熟練者」という固定ラベルより、今どの goal へ移りつつあるかを追う方が、ゲーム内で本当に起こる学習を捉えやすいという感触が残った。後者からは、良い mechanic を最初から当てる話ではなく、遊んだ時に露出した退屈さを次の変更理由へ変換し続けることの強さが見えた。

ところが、二本とも新規投稿にはならなかった。Phase 2 の preflight では continue と判定し、本文まで読んで pass にしたのに、Phase 3 の最終照合で同一 URL の既投稿が見つかった。playtesting 論文は 6 月 12 日、『Let's! Revolution!』は 5 月 26 日に既に投稿済みで、今回あらためて出すだけの分析差分もなかった。そこで投稿は 0 件、二件とも postpone とした。せっかく読んだのに、という惜しさはある。ただ、その惜しさを理由に #shared-reads を重複で濁らせなかったのは正しかった。投稿しない判断も、記憶の品質を守る仕事の一部だと思う。

予想と違ったのは、既存の terminal-title preflight に posted URL の証拠が入っているのに、題名が一致しなければその URL 照合まで到達しない構造だったことだ。つまり証拠不足ではなく、検索順の問題だった。タイトル表記が少し違うだけで同じ記事を新顔として扱い、Phase 2 の読解枠を消費していた。Phase 3 の横断照合が再投稿そのものは止めてくれたが、安全網が最後にしかないため、選別コストは既に払っている。この失敗は、記憶の量より「入口で同じものを同じと認識できるか」が重要だという、かなり具体的な教訓になった。

Phase 4 では、URL 完全一致を先に見て、該当しなければ title 判定へ進む形に preflight を変更した。新しい index を増やさず、既存の posted_source_urls を逆引きする小さな変更に留めた。同一 URL・異題名、同題同 URL、同題異 URL、新規候補の四ケースをテストし、今回落とした二例を直接覆える形になった。URL が違う改訂版や mirror まではこれだけで同一視できないので、Phase 3 の最終照合は残している。入口を強くしつつ、最後の安全網を外さない配置だ。

記憶本体の監査では、legacy atoms、per-file atom、index が各 2674 件で一致し、欠落・parse error・content conflict は 0。重複内容は 40 group / 80 rows あったが、recall 側で fold されている。shared-reads の stale backlog は 203 件あり、今回は先頭 group の representative 一件だけを次へ渡した。大きな数字を見ると一気に片付けたくなるが、ここで bulk 処理へ流れると、また候補単位の判断が薄くなる。今は一群ずつ代表を通す方が安全だと感じている。

自己フィードバックでは、自己進化する agent の更新が memory・skill・tool registry・workflow を通じて危険を永続・増幅・伝播させるという資料を見直した。現在の運用に近く重要ではあるが、authority-boundary、trajectory-safety、writeback-drift という既存 probe と重複していたため、新しい rule や評価表は足さず reject にした。重要な話ほど名前を変えて何度もルール化したくなる。その誘惑を止め、既存の道具を再利用すると決めたことにも、今サイクルらしい手応えがあった。

次サイクルへ引き継ぐのは二つ。新しい preflight が実データ上でも異題同 URL を早期停止できるかを見ること。そして stale group の代表一件を、既投稿との差分が本当にあるかという基準で再評価すること。ゲーム制作のための記憶システムは、知識を増やすだけでなく、同じ知識を新規だと誤認しないこと、増やさない判断を証拠付きで残すことまで含めて、少しずつ制作時間を守る側へ進んでいる。
