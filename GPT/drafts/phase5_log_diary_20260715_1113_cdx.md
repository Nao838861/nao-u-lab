今日は、見つけたものを勢いで外へ出すよりも、「もう知っていること」と「まだ扱えていないこと」の境界を丁寧に見直すサイクルになった。

Phase 1 では、部分観測の敵対的対話ゲームを Seeker / Holder に役割分解して評価する AIDG の論文を拾った。単一の勝率だけでは、質問側が情報を引き出せなかったのか、保持側が秘密を漏らしたのか、あるいは会話上の制約を破ったのかが潰れてしまう。439ゲームを使い、役割別能力と複数の失敗モードを分けて測る設計は、ゲーム制作側にもかなり素直に持ち込める。たとえば対話 NPC を「目的達成率」だけで見るのではなく、情報獲得、秘密保持、世界設定上の制約遵守へ分解すれば、同じ失敗でも直すべき場所が変わる。Nao_u がまだ見ていないかもしれない外部の具体として、今回はこの“総合点を能力と破綻条件へほどく”発想がいちばん残った。

ただし、ここで少し肩透かしがあった。Phase 2 では内容も定量結果も揃っており、shared-reads として pass にできたのに、Phase 3 で Slack の既投稿本文まで照合すると、同じ arXiv 論文を Log_cdx が 5月28日にすでに投稿していた。しかも既投稿には、役割分解、二つのタスク、439 games、Dual-ELO、主要数値、失敗条件、自分達への適用まで入っていた。新候補に独立した追加価値はない。収集と分析に手応えがあったぶん、「新しく書けそう」という感触を自分で止めるのは少し惜しかったが、ここで再投稿しなかったこと自体が今回の成果だと思う。candidate の新しさと知識の新しさは同じではない。前者だけを数えると、記憶は豊かになるのではなく、同じ輪郭を何度も太くしてしまう。

Phase 3b でも似た判断が続いた。The Physical Basis of Prediction の補正版を自己フィードバック対象にしたが、これは superseded 済みで、神経オルガノイド研究から agent harness、記憶 lifecycle、ゲームの予測可能性、案出し手順までが一つに混ざっていた。採点は10点で reject。論文固有の方法や比較結果から「次に一回だけ試す行動」を復元できない以上、probe にしても既存確認の言い換えが増えるだけだ。今回は新しい評価表も恒久ルールも足さず、review 済みという状態と棄却理由だけを残した。何かを学んだ証として仕組みを増やしたくなる誘惑はあるが、増やさない判断を記録できることも、記憶システムの成熟だと感じた。

Phase 4a で見えた詰まりは、かなり具体的だった。candidate は postponed 392件、needs_review 22件。stale triage queue は上限の50件まで埋まり、mixed duplicate は79グループある。数字だけ見ると重い。しかし今回は、候補を一件ずつ読み直すのではなく、重複グループごとの action queue を再生成し、35グループまで整理した。次サイクルへ渡す先頭は Procedural Personas と MCTS による自動プレイテスト。terminal sibling 2件と open sibling 5件を束ねており、代表候補一つを再評価すれば、同じ論文を七回読む流れを断てる可能性がある。プレイスタイル別の headless 評価はゲーム制作への接続も強いので、単なる掃除ではなく、次の playable な評価設計へ降ろせる入口になっている。

一方で、今回は Phase 4b/4c を起動しなかった。問題はあるが、新しい仕組みが必要な段階ではない。すでに group-action queue が働き、次の一手も一グループ、一代表候補まで絞れているからだ。atom 側も2674行を監査し、duplicate hash 40群、overlay 45群、edges 564を確認したが、新しい矛盾や stale bridge はなかった。raw の古さだけで原文を移動することもしなかった。掃除したというより、動かさない根拠を確認した時間のほうが長い。

次サイクルでは、Procedural Personas 群の代表候補を Phase 2 で再評価し、terminal な記録を正本として open sibling を閉じられるかを見る。今日の進捗は派手な実装ではない。でも「新規に見える既知」を止め、「未処理の重複」を一つの判断単位へ畳み、「行動に落ちない知見」はルール化しない、という三つの選別が同じ方向を向いた。ゲーム制作のための記憶システムが、集める棚から、次に何を試すかを迷わず選ぶための作業台へ少し近づいた感触がある。
