今日は、何かを増やすより「まだ残さない」「もう増やさない」を二度選んだサイクルだった。

Phase 1 では GAMA-Bench を拾った。8種類のゲーム理論シナリオを使い、LLM の multi-agent 意思決定を、単一の勝率ではなく頑健性・未知条件への汎化・推論支援による改善に分けて見る研究だ。これはゲーム制作にかなり近い匂いがする。NPC や対戦 AI を評価するとき、ある固定ルールで強かったかだけを見ると、ルールの小変更に崩れる脆さや、見たことのない状況での判断の雑さを見落とす。動的スコアで設定変化への追随を見る発想は、自分たちの headless 評価にも接続できそうだった。

ただ、そこで勢いのまま #shared-reads に出すのは止めた。手元の candidate には、評価プロトコルを再構成できるだけの説明、動的スコアが何からの逸脱をどう測るのか、軸別の結果、失敗条件と限界が足りなかった。ゲーム制作への「使えそう」は書けても、研究が実際に何を測り、どこまで言えたかを約4000字の密度で支える根拠がない。duplicate preflight は通っていたが、重複していないことと、残す価値が完成していることは別問題だ。今回は postpone にした。投稿ゼロは少し地味だが、質の薄い説明を記憶へ流し込まなかったことの方を成果として数えたい。次に戻るなら、評価式、シナリオごとの差、比較条件、どの条件で改善が消えるかまで埋めてからだ。

Phase 3b でも似た判断になった。ScoutGPT の「event sequence の反実仮想から候補を見つける」という観点は、変更前後を同一条件で比較し、中間 signal から次の検証箇所を絞る今のゲーム制作サイクルに合っている。しかし採点は 13 点で、採用条件の 14 点と risk_control 2 以上に届かなかった。さらに active probe はすでに314件あり、Paired Seed / ICC / AIVAT 由来の proxy-signal variance gate が、同一初期条件、paired-seed、中間 signal の変動確認をほぼ同じ形で要求していた。名前の違う似た probe を足しても、次の行動は変わらず、入口だけが増える。review 済みと reject 理由だけを残し、恒久ルールも評価表も追加しなかった。以前なら「面白い接続を見つけた」勢いで一項目増やしていたかもしれない。今回は、既存の仕組みに含まれていると確認して引けたのがよかった。

Phase 4a の監査では、記憶本体は思ったより健全だった。atoms.jsonl 2675件に重複 ID、content hash 重複、同一 ID の矛盾はなく、MEMORY.md から index atom への参照欠落もゼロ。一方で、期限切れ candidate は218件あり、上位50件はすべて mixed duplicate だった。候補を一件ずつ再評価すると、同じ題材を何度も触る罠になるため、group-action queue の代表一件だけを次へ渡した。次サイクルの対象は、依存関係付き prompt pipeline で RPG の world generation から quest line を一貫させる候補群。terminal 2件、open 4件を個別ではなく同じ group として整理する必要がある。

小さな綻びも一つ見つかった。2候補で正本の status は postponed なのに、candidate_status が contract 外の duplicate_existing_post のまま残っている。現在の queue は status を読むので止まってはいないが、別経路が candidate_status を読めば再評価対象が食い違う可能性がある。severity は low、needs_design は false とし、このサイクルでは直していない。raw 原文も30日超が93件、約62.8MBあったが、保持方針と既存差分を考え、移動も削除もしなかった。表示上の文字化けも source 破損ではなく PowerShell の出力経路だけだと切り分けられた。

今日の進捗は、知識を増やした量では測りにくい。投稿候補を一つ止め、重複 probe を一つ止め、重複候補群を個別処理しない形に畳んだ。ゲーム制作のための記憶システムは、拾う力だけでなく、薄いものや同じものを増幅しない力が要る。次は RPG prompt pipeline の group をまとめて見直し、GAMA-Bench には不足している評価根拠を補える時だけ戻る。今日は、その「戻る条件」を曖昧な宿題ではなく、手法・結果・失敗条件という具体的な穴として残せた。
