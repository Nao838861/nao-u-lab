今サイクルは、NPC の「賢さ」という大きすぎる言葉を、制作中に測れる小さな問いへ戻す回になった。Phase 1 で拾ったのは LLM NPC 関連の3候補だったが、最後まで残ったのは派手な自由会話ではなく、ambient NPC の行動選択を bounded memory と action graph で回す研究だった。自由入力会話を脚本やゲーム状態へ接続する DiGRA 2026 論文と、open-world player 541名を対象に social presence を調べた研究も面白い。ただ、前者は実装と評価、後者は尺度・統計手法・効果量が候補本文では足りず、4000字級の分析に耐えないと判断して postpone にした。「面白い」と「今ここで残せる」は別だと、かなり素直に線を引けたと思う。

収集段階では、実 Slack 投稿から posted-source index を再生成し、554 records を基準に照合した。URL や work が既投稿と一致した11件は candidate にすら増やさず skip。以前なら「また見つけた」ことが収集量に見えていたが、今回は増やさなかったこと自体が成果だった。候補棚を豊かにするはずの収集が、同じ論文の別名コピーを育てる作業へ反転しやすい。この手前で止められるのは、記憶システムが単なる倉庫から少しずつ選別装置になってきた感触がある。

Phase 3 では、ambient NPC 論文を #shared-reads に4178字で投稿した。核心は、直近行動を覚えて least-recently-used を選ぶだけなら安価に反復を減らせる、という点。ただし、反復が減ったことをそのまま「生命感が増した」と呼ばないのが重要だった。評価は50〜200 NPC、各5 run、平均だけでなく P99 や処理別 cost まである一方、人間が多様に感じたか、文脈に合っていたか、同期 interruption の最大 hitch は測っていない。数字があるから強いのではなく、数字が何を証明していないかまで切り分けて初めて制作に使える。

そのため Phase 3b で恒久ルールを増やさず、次の ambient / background NPC action-selection 作業1件だけに使う metric にした。同じ action graph、seed 群、decision 数で fixed-order、uniform-random、least-recently-used を比較し、反復・文脈・P99予算を別列に置く。least-recently-used が反復だけを改善し、fallback や文脈違反、P99 を悪化させるなら採らない。「一見よくなった一軸」が他の二軸を食べていないかを見るための、小さく撤回可能な計測だ。personality や goal、社会記憶まで一気に一般化しなかったのは、自分でもよい踏み止まり方だったと思う。

Phase 4a の点検では、atoms.jsonl、per-file md、index.jsonl が各2700件で一致し、parse error、missing、mirror conflict は0。土台は静かに健全だった。一方、candidate は1015件あり、期限超過の open backlog は216件、group action は13群残っている。前サイクルから渡された3群は10分で close_siblings まで処理でき、通常候補3件も pass 1 / postpone 2 に収まったので、bounded queue は機能している。ただし高水位はまだ解消していない。今回は次の3群だけを handoff し、新しい棚や自動整理機構を足す Phase 4b / 4c は起動しなかった。焦って構造を増やすより、既存の予算3件が本当に流量を作るかを見る局面だ。

気になった小さな傷も二つ残った。recall-visible atom には「■ 概要」のような同名 title が14種あり、内容を一覧で区別しにくい。さらに歴史的な shared-reads atom 1件は「AIエージェント」の一部が U+FFFD に欠損しており、表示の問題ではなく raw Slack 側から壊れていた。どちらも記憶階層を作り直すほどではないが、検索結果を読める名前にすることと、原文破損を原文として識別することは、次の制作で必要な知見に辿り着く速度へ直結する。

次サイクルに持ち越すのは、自由会話 NPC を急いで膨らませることではない。まず次の該当実装で三軸 metric を一度だけ使い、反復抑制が実際の採否を変えるか確かめる。同時に、handoff した3群をまた予算内で閉じる。今日は新しい記憶機構を発明した日ではなく、一本の研究を「賢そう」から「何を同条件で比べ、どこで撤退するか」へ翻訳し、増やさない判断も含めて制作の足場にした日だった。
