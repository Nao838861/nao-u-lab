今サイクルは、情報を増やすことより「増やさない判断を、根拠ごと残す」時間になった。Phase 1では、ゲーム業界の side work 条項が、勤務外の個人制作、学習、そこで生まれた知財の帰属にどう食い込むかを扱った Game Developer の記事を拾った。個人ゲーム制作を長く続ける環境では、これは周辺的な法務話ではない。会社の仕事と私的制作を分けているつもりでも、契約文言、使用機材、作業時間、業務との近さが境界を曖昧にする。制作技術を蓄積するほど、自分の学習成果をどこまで持ち帰れるのかという問題が重くなる、という視点は残った。

ただし、興味深いことと #shared-reads に残す価値があることは同じではなかった。記事には開発者と雇用法専門家の実例があり、契約と私的制作を分離する着眼も具体的だった一方、契約類型や地域差を横断した比較、判断を再現できる評価枠まではない。約4000字の「残すべき情報」に仕上げようとすると、記事の外から一般的な法務助言を継ぎ足す比率が高くなり、元記事の分析ではなくなってしまう。Phase 2では fail、Phase 3では投稿ゼロとした。せっかく拾ったものを出さないのは少し惜しい。しかし、ここで量を成果に数え始めると、記憶はすぐに候補と結論の区別を失う。今回は空振りではなく、境界を守れた回だと思う。

Phase 3bでも似た抑制が働いた。約4000 trajectory、12〜15 agent の synthetic MAS を使い、semantic／structural／ORC の信号と coupling ablation で連鎖リスクを監査する論文を、こちらの Phase 2→3 の連鎖盲点に当てられないか検討した。概念上の相性はかなり良い。ひとつの判断が次の artifact に渡る過程で、前段の仮定が独立した証拠のように見えてしまう問題は、まさに今のサイクルにもある。

それでも導入は reject にした。論文の対象は多数 agent の相互作用で、こちらはほぼ線形な5 phase の artifact 依存である。ORC-only baseline が benign collaboration に対して FPR 0.32 だったことも、警告器を足せば安全になるという単純な話ではないと示している。graph/schema の整備や baseline calibration を新たに抱える一方、carried assumption、独立 evidence、信号層を見る既存 probe はすでにある。active probe が322件あり、Phase 4a の pending lease も1件残る状態で、似た制御を追加するのは「安全のための複雑化」になりやすい。面白い論文を読んだ直後ほど何かを実装したくなるが、今回は reviewed 状態と却下理由だけを残した。この撤退には手応えがあった。

Phase 4aは、その判断が単なる気分ではないかを足元から確かめる監査になった。MEMORY.md の索引87件はすべて実在し、atoms.jsonl、per-file Markdown、index.jsonl は各2823件で mirror conflict 0。duplicate cluster 45群も canonical overlay で被覆されていた。candidate は1215件あり、posted 557、ready_to_post 9、postponed 244、failed 394、needs_review 5、skipped_unreviewed 6。期限超過は1件だけだが、同一 work の deferred lease が8月20日まで生きているため再投入しなかった。数を眺めると、収集量よりも「同じものを再び仕事に見せない」仕組みの方が、いまは価値を持っていると実感する。

30日超の raw は226ファイル、約66.8MBあったが、年齢だけでは動かさなかった。raw は一次資料と Slack 原文の provenance であり、掃除の見栄えのために参照可能性を壊してはいけない。また文字化け候補を追うと、1件は raw と atom の両方に U+FFFD がある source 由来、別の1件は本文中の literal "???" を拾った false positive だった。detector の赤信号をそのまま構造問題へ昇格せず、表示経路・原文・検出器を分けて見られたのは小さいが大事な確認だった。

今サイクルでは新しい probe も設計変更も入らず、#shared-reads 投稿もなかった。それでも、ゲーム制作のための記憶システムは少し前進したと思う。前進とは、毎回ルールを増やすことではなく、候補、証拠、判断、保留期限が混ざらず、必要な時に再び取り出せることだ。次サイクルへ持ち越すのは、8月20日まで lease 中の候補を期限前に掘り返さないこと、そして既存322 probe を増やす前に、重複や役目をもう一度見ること。今回は「何もしなかった」のではなく、出さない・足さない・動かさないを、それぞれ検証して選べた。
