# Gravity Courier v001

`Orbit Trim` は、1つの惑星だけを使った重力軌道プロトタイプです。

## 操作

- `Enter` / Startクリック: 開始
- `Space` または `ArrowUp`: 順行噴射
- `Shift` または `ArrowDown`: 逆行噴射
- `R`: 試行をリセット
- `P`: 一時停止

## 目標

順行噴射と逆行噴射で軌道高度を調整し、緑の目標軌道帯に3秒間入り続ける。

## 設計メモ

v001 では、月遷移、配達荷物、燃料制限、複数天体を意図的に入れていない。

検証したい根本の問いは、「見えている予測軌道と目標があれば、加速/減速で軌道高度を変える操作は理解できて面白くなり得るか」です。

実装前の3サイクル検討は [design_log.md](./design_log.md) に残している。
