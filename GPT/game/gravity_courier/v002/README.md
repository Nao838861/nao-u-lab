# Gravity Courier v002

`Orbit Gates` は、v001 の重力軌道操作を発展させたプロトタイプです。

## 操作

- `Enter` / クリック: 開始
- `Space` または `ArrowUp`: 順行噴射
- `Shift` または `ArrowDown`: 逆行噴射
- `R`: 最初からやり直す
- `P`: 一時停止

## 目標

順番に表示される3つの軌道ゲートを通過する。

ゲートは「半径」と「角度」の両方が合ったときに通過できます。予測線が青くなる点は、現在の入力を続けた場合に次のゲートへ入る見込みがある場所です。

## v001 からの変更

- 目標を「軌道帯に3秒滞在」から「軌道ゲートを順番に通過」へ変更。
- 噴射をよりアナログ寄りの連続噴射として扱う。押し始めは弱く、短時間で最大噴射まで立ち上がる。
- 燃料、耐久、時間制限などのペナルティは入れていない。
- 右端の情報バーは使わず、必要情報はゲーム画面内に収める。

## 設計メモ

この版の目的は、v001 で成立した「シンプルな重力ルールで予測可能、かつ、奥が深い」を壊さずに、次の目標構造を足せるかを試すことです。

実装前の3サイクル検討は [design_log.md](./design_log.md) に残しています。
