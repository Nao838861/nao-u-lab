# Gravity Courier v003

`Orbit School` は、重力軌道操作を段階的に覚えるためのチュートリアル型プロトタイプです。

## 操作

- `Enter` / クリック: 開始
- `Space` または `ArrowUp`: 順行噴射
- `Shift` または `ArrowDown`: 逆行噴射
- `R`: 最初からやり直す
- `P`: 一時停止

## レッスン

1. 慣性を見る: 噴射しなくても、数秒間は予測線どおりに軌道上を進むことを確認する。
2. 外へ上げる: 順行噴射で外側の軌道ゲートへ向かう。
3. 内へ下げる: 逆行噴射で内側の軌道ゲートへ向かう。
4. つなぐ: 複数の軌道ゲートを順番に通過する。

## 方針

燃料、耐久、時間制限などのペナルティは入れていません。目的は、プレイヤーが「シンプルな重力ルールで予測可能、かつ、奥が深い」操作を順番に理解できるかを確認することです。
