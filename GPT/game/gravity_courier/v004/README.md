# Gravity Courier v004

`Transfer Window` は、月遷移の前段階を試すプロトタイプです。

## 操作

- `Enter` / クリック: 開始
- `Space` または `ArrowUp`: 順行噴射
- `Shift` または `ArrowDown`: 逆行噴射
- `R`: 最初からやり直す
- `P`: 一時停止

## 目標

動く3つの軌道窓を順番に通過する。

1. 月: 外側を回る黄色い月へ接触する。
2. 帰還窓: 地球ぎりぎりの低い窓へ戻る。
3. 調整窓: 次の遷移に向けて中間軌道を整える。

## 方針

この版では、月をまだ重力源にしていません。重力源は一つのまま、月は黄色い丸そのものを接触目標として扱います。目的は、二体重力へ進む前に、動く目標へ軌道とタイミングを合わせる遊びが成立するかを見ることです。

燃料、耐久、時間制限などのペナルティは入れていません。
