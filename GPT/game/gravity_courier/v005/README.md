# Gravity Courier v005

`Lunar Orbit` は、月の影響圏で実際に月の周りを回ることを目標にしたプロトタイプです。

## 操作

- `Enter` / クリック: 開始
- `Space` または `ArrowUp`: 順行噴射
- `Shift` または `ArrowDown`: 逆行噴射
- `R`: 最初からやり直し
- `P`: 一時停止

## 目標

1. 月周回: 黄色い月の影響圏に入り、月の周りを360度まわる。
2. 帰還窓: 地球近くの低い帰還窓へ戻る。

## 方針

画面は正方形です。v005 の途中版より表示領域を広げ、月の影響圏の外側にも余白を残しています。軌道外れは半径ではなく、船が画面外へ出た時に判定します。

月は黄色い丸で、周囲に薄い影響圏があります。影響圏内では、船と月に共通してかかる地球重力を差し引き、月基準で回りやすい力学にしています。

月はスタート地点から離してあり、開始直後にそのまま月へ入ることはできません。まず地球をほぼ一周して、月と会うタイミングを作ります。

画面には `捕獲率` や `束縛率` は出しません。月の周りをどれだけ回ったかだけを `周回 0° / 360°` として表示します。速すぎると通過し、近すぎると月面衝突になります。

月周回後の再投入起動や追加の調整窓は入れていません。失敗時は進行を維持せず、最初からリセットします。燃料、耐久、時間制限などのペナルティはまだ入れていません。
