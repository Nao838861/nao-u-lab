## 実装前判断

v24 は wave の整理としては前進したが、橙強敵はまだ「硬い敵を長く撃つ」になりやすい。今回は敵配置を増やさず、橙強敵に弱点露出窓を追加する。FOCUS を、説明上の優先目標ではなく、画面上で明るくなった短い窓へ撃ち込む操作に変える。

採用する過去知見:

- `Playable / Headless 評価`: clear だけでなく、新しい焦点窓のダメージ差を focused probe で見る。
- `Balance / Rule Space`: 敵数・BOMB・DEF を同時に動かさず、橙強敵の根源仕様だけを変える。
- `Feedback / Rights / Human Judgment`: UI 追加ではなく、プレイ中の判断が変わる playable diff にする。
