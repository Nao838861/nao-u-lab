# graze_log v05.2_cdx_v25 design_log

## 入力原文

> v24も散漫な印象が全く変わらない。以前の延長でちょっとパラメータ変えるだけみたいなことをやっていないか？一旦敵のソースを全部消して、以前のをすべて忘れて、手順通りのブレストをやってから作り直して。まずは既存ゲームの動きの再現から。ランダムにゆっくりの動きの敵が出てきて、得に意志も意図もなくなんとなく動いてるだけの敵がほとんど。どうプレイヤーに動いてほしいかとか全然考えていなさそう。一旦ここで左の編隊を倒してる間に、右の編隊が出てきて弾を撃つからどのタイミングで切り替えるか、とか、この流れでプレイヤーが画面左にいるはずなので、次は右に移動してもらいながら、とかプレイヤーをどう動かさせるかが全く意識できていなくて適当にバラバラに出てるだけ。

> 例えば、ギャラがでは曲線軌道を編隊が飛んでくるので同じ場所で打ち地づけていたら連続で倒せる楽しさがあったりするし、右→左→別の場所から、みたいなテンポとリズムがあるが、そういうの全く考えられてない。しかし、現代の弾が連続で出るシューティングと単発の弾で狙う必要があるギャラガでは敵編隊の考え方は全く違う。そのあたりの歴史的な進歩や、現代の縦シューに合わせたパターン構築など、全く考察せずに適当に出してるのを感じるので、プレイヤーの性質に合わせた敵編隊の組み方をゲームデザインに合わせて考えてほしい。

## 既存ゲームから取る型

- Galaga: entrance pattern が固定で、予測して入口で倒す。曲線で同じ射線へ敵が流れ込むため、同じ場所に撃ち続ける快感がある。ただし単発射撃ゲームなので、そのまま現代縦シューへ移すと遅すぎる。
- 1942: 画面幅を使う編隊と色単位の全滅ボーナス。終盤には横幅の隊列が安全側への移動を要求する。これは「どこへ動かすか」の参考になる。
- DonPachi / DoDonPachi 系: 自動連射前提で、敵の出る順番がコンボ、優先撃破、次の位置取りに直結する。敵が「弾を撃つ置物」ではなく、プレイヤーの射線を次の場所へ運ぶ。

## ブレスト cycle 2: 改善案 30

1. 敵型は `drone / marker / pin / anchorCore / boss` だけにする。
2. `drone` は Galaga 入口列の現代化。曲線で同じ射線へ流れ込む。
3. `marker` は橙強敵。切り替え先を示す。
4. `pin` は 1942 的な幅圧。安全側を選ばせる。
5. `anchorCore` は中ボス。射線を中央に固定する。
6. wave は左から始める。
7. 左列を倒している途中で右に marker を出す。
8. marker が撃つ前に右へ切り替えるか、左列を完走するかを選ばせる。
9. 次 wave は右列から左へ戻す。
10. 画面中央を休憩ではなく「次の選択前の整列」にする。
11. Galaga の「同じ場所で撃ち続ける」快感を左 lane / 右 lane で作る。
12. 1942 の横幅圧は、横一列ではなく gap sweep として使う。
13. 自動連射なので、敵は遅く曲がるより射線へ入ってくる方が良い。
14. 曲線の目的は見た目ではなく「射線へ流し込む」。
15. 弾の目的は回避より「切り替え遅れへの圧」。
16. 中ボス前に左右 lane を一度ずつ練習させる。
17. 中ボス中は左 lane を処理中に右 marker を出す。
18. 中ボス後は赤 drone で BOMB を戻す。
19. 終盤は左 lane → 右 marker → gap sweep の順で組む。
20. 全 wave に player expected x を持たせる。
21. bot も expected x に寄せて検査する。
22. route intent は `LANE_LEFT / SWITCH_RIGHT / GAP / FOCUS / RESTOCK / BOSS` にする。
23. 敵数は少なすぎないが、同時に多すぎない。
24. 一 wave の目的は一つ。
25. 同じ型を二回出してから応用する。
26. 横から縦列を出すなら、縦列ではなく曲線入口列として出す。
27. 敵が散ったら失敗。射線にまとまる。
28. 右へ行かせた後は左へ戻す理由を作る。
29. BOMB は boss final に残す。
30. まずは 90 秒程度の短い stage grammar にする。

## ブレスト cycle 3: 採用案と捨てる案

### 採用

1. Galaga 型 entrance lane: 左上から曲線で x=125 に流れる。
2. 反対側 entrance lane: 右上から曲線で x=295 に流れる。
3. Modern switch: lane 処理中に反対側 marker を先出しする。
4. 1942 gap sweep: 横幅の敵列が安全側を示す。
5. Midboss shepherd: 中央 anchorCore が射線を固定し、左右 lane が切り替えを要求する。
6. Restock stream: boss 前に赤 drone を同じ射線へ流し込み、BOMB を戻す。

### 捨てる

1. V 字編隊を何度も出す。
2. 円弧旋回だけの見せ場。
3. 横から縦一列で出るが撃ち方が説明できない wave。
4. 敵の種類を増やす。
5. 目的のないサインカーブ。
6. 旧 `spawn1942*` / `redWing` / `orangeAce` 系の継ぎ足し。
