# Orbit Courier

惑星軌道から自由発射し、捕捉リングと軌道上の荷物を読んで配達する Canvas ゲームです。

## 遊び方

- 船は惑星の周りを回る。
- `Space` またはクリックで、現在の接線方向へ自由発射する。
- 見えている捕捉リングに入ると、その惑星の軌道へ捕まる。
- 荷物は惑星軌道上に出る。
- 荷物と同じ色の惑星へ捕まると配達。
- 画面外へ出ると空便扱いで短い救助復帰になり、Hull が少し減る。

## 今回の試作

レーン1本の仕様はゲームとして単調だったため、自由移動へ戻した。ただし破綻を避けるため、以下に限定している。

- 壁反射なし。
- 時間切れワープなし。
- 見えない端カーブなし。
- 発射前に短い予測線を表示。
- 捕捉リングを常時表示。
- 荷物はランダム空間ではなく、惑星軌道上に限定。
- 画面外はミスとして救助復帰。
