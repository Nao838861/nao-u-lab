# Playbook Football Lab v001

PlayMaker Football 的な「プレーを作って結果を見る」面白さを、現代的な戦術盤 UI に寄せた最小プロトタイプ。

## 起動

`index.html` をブラウザで開く。

## 操作

- `1` から `3`: プレー選択
- `Space`: スナップ
- `R`: 初期化
- `Edit routes`: WR / TE / RB のルート終点をドラッグ

## v001 の狙い

フル試合ではなく、1プレー単位で「設計 -> 実行 -> 分析」が成立するかを見る。プレイヤーはプレー名とルートを見て、守備がどう反応するかを予想し、結果ログから次のルート修正へ戻る。

## 実装範囲

- オフェンス5人、ディフェンス5人
- 3種類のプリセットプレー
- ルート終点の軽い編集
- 守備のマン/ゾーン/ラッシュ挙動
- QB の自動ターゲット選択
- 捕球成功/失敗と原因ログ
