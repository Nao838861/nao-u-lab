# Playbook Football Lab v004

PlayMaker Football 的な「プレーを作って結果を見る」面白さを、現代的な戦術盤 UI に寄せた最小プロトタイプ。

## 起動

`index.html` をブラウザで開く。

## 操作

- `1` から `3`: プレー選択
- `Space`: スナップ
- `R`: 初期化
- `Edit routes`: WR / TE / RB のルート点をドラッグ
- `Add point`: ルート線付近をクリックして中間点を追加
- `Throw timing`: QB が投げる時刻を調整

## v004 の狙い

v003 の読み合いに加えて、QB周辺の接触をフットボールらしくする。OLがラッシャーを一度受け止め、ポケットが保つ/崩れる/抜けられることで、投げるタイミングとスクリーンの意味を強くする。

## 実装範囲

- オフェンス5人、ディフェンス5人
- 3種類のプリセットプレー
- ルート中間点の追加とドラッグ編集
- 守備コール3種類
- 守備予想と実際の守備の照合
- スカウトレポート
- カウンター相性ボーナス
- 同じプレー連打ペナルティ
- Coach score
- QB接触時は投球せずサック、接触寸前の投球は hit-as-thrown として捕球判定に強いペナルティ
- 選手表示は丸型に戻し、向きは前方ノッチと腕/足の線で示す
- OL3人とラッシャーの簡易ブロック
- ポケット幅の表示
- ポケット崩壊時の捕球窓ペナルティ
- 投球タイミング調整
- デフォルトでは約2.2秒で投げ、飛球も0.75秒以上かけるため、プレー全体を観察できる
- 捕球成功時は即終了せず、`CATCH` 表示後にキャッチ後ランを行い、守備が詰めた時点でタックル終了する
- パス失敗時は結果カードに `incomplete` と原因守備者を表示する
- 選手は向き、旋回、カット、バックペダルの簡易モデルを持つ
- QB の自動ターゲット選択
- 捕球成功/失敗と原因ログ
- ダウン、距離、ボール位置の簡易更新
