# サイクル006 自己判断

日付: 2026-06-24

## 観察

v005 はサックやhit-as-thrownの判定を直したが、プレーの決定的瞬間が一瞬で流れる。ユーザーが以前に指摘した「QBがHに投げた直後に終わる」「何が起きたのか分からない」という問題は、判定だけでなく観察性の問題でもある。

## 判断

このサイクルでは新しい戦術要素を足すより、速度制御と結果バナーを優先した。以後の接触物理や守備AI改善を評価する土台として、まずプレーの瞬間を止めて見られることが必要。

## 実装

- 速度切り替え: `0.45x / 1x / 1.45x`
- 一時停止: `Pause` ボタンと `P` キー
- フィールド上バナー: サック、崩れた投球、ポケット崩壊、パス、捕球、インコンプリート、タックル
- デバッグ snapshot: `speedScale`、`paused`、`banner`
