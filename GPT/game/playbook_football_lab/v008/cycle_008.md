# サイクル008 自己判断

日付: 2026-06-24

## 観察

v007 で直前プレーのリプレイはできるようになったが、先頭から眺め直すだけでは接触判定の直前を正確に確認しづらい。今後ブロックやサックを改善するには、問題フレームへ戻れる検証道具が必要。

## 判断

このサイクルではリプレイのシークとコマ送りを優先する。新しい戦術要素より先に、プレー中の判定を確認できる基盤を固める方が、以後の改善の精度を上げる。

## 実装

- リプレイスライダーを追加
- `-1` / `+1` ボタンを追加
- `,` / `.` キーで1フレーム戻し/送り
- replay controls の有効/無効をフレーム数と同期
- snapshot に `replayIndex` を追加

## 次の候補

観察性を続けるならサック/捕球/タックルのイベントマーカー。ゲーム性を進めるなら RBパスプロとスクリーンリリース。
