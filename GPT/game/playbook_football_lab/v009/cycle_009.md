# サイクル009 自己判断

日付: 2026-06-24

## 観察

v008 で任意フレームへ戻れるようになったが、重要イベントがどのフレームかは自分で探す必要がある。これは検証道具としてまだ粗く、サックや捕球の瞬間を毎回探す手間が残る。

## 判断

次はイベントマーカー。既存のバナー表示は重要イベントを集約しているため、そこからリプレイマーカーを作るのが自然。新しいゲームルールを足さず、判定理解の精度を上げる。

## 実装

- フィールド上に replay event marker strip を追加
- `showBanner` 発生時に `replayMarkers` を記録
- マーカークリックで該当フレームへジャンプ
- スナップ開始/リセットで古いマーカーを消去
- snapshot に `replayMarkers` を追加

## 次の候補

観察基盤は一段落。次はゲーム性側へ戻し、RBパスプロとスクリーンリリースで Draw Screen を本当に意味のあるプレーにする。
