# サイクル010 自己判断

日付: 2026-06-24

## 観察

v009 でリプレイ観察基盤は整った。次に触るべきはゲーム性。Draw Screen は Blitz へのカウンターとして扱っているが、H が実際には最初から普通のルートを走っており、RBが守ってから遅れて出るスクリーンの動きになっていなかった。

## 判断

このサイクルでは RBパスプロ/スクリーンリリースを優先する。スコア上の相性だけでなく、画面上の動きとQBのターゲット評価に Draw Screen の意味を反映する。

## 実装

- Draw Screen 時、H はリリース前にパスプロ位置へ入る
- リリース前だけ H が LB ラッシュのブロッカー候補になる
- H のチップブロックを青リングで表示
- リリース前の H はQBターゲット評価を下げ、リリース後は Blitz 相手に評価ボーナス
- `SCREEN RELEASE` バナーとログを追加
- snapshot に `screenReleased` と `screenReleaseTime` を追加

## 次の候補

H が出るだけではスクリーンらしさはまだ足りない。次は捕球後に OL が前へ抜け、H の前方にスクリーン壁を作る。
