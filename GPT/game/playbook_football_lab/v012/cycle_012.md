# サイクル012 自己判断

日付: 2026-06-24

## 観察

v011 でスクリーン壁はできたが、守備者が近ければ減速する距離寄りの判定だった。これではブロッカーが相手を向いていない接触でも効いてしまい、アメフトらしさが弱い。

## 判断

次はブロック接触の質。ブロッカーの体の向き、守備者との前後関係、肩が入っているかを使い、正面で作ったブロックだけが強く効くようにする。

## 実装

- `facingDot()` と `blockContactQuality()` を追加
- パスプロとスクリーン壁の接触判定に `blockQuality` を導入
- blockQuality が高いほど守備者が止まりやすく、リングも太く表示
- replay frame と snapshot に blockQuality を保存
- HUD に最大 Block quality を表示
