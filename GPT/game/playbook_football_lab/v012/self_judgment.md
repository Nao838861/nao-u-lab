# Playbook Football Lab v012 自己評価

## 良いところ

- v001 より作戦ゲームになった。プレーだけでなく、守備コールと投球時刻を変えられる。
- ルート終点だけでなく中間点を足せるので、「少し曲げて空ける」調整ができる。
- 結果ログに QB 評価、セパレーション、プレッシャー距離が残るため、失敗理由を追いやすい。
- ダウンと距離が更新されるので、1プレーの実験がドライブに接続し始めた。
- v001/v002初版で早すぎたプレー終了を直し、ルート展開を見てから判定されるようにした。
- H などが捕った瞬間に止まって見える問題を直し、捕球後ランと `CATCH` マーカーを入れた。
- 丸い駒の直線移動から、向き、旋回減速、カット表示、ゾーン守備のバックペダルへ寄せた。
- v003では守備を伏せ、スカウトから予想してカウンターを当てる構造にしたため、プレイヤーの判断が結果に乗る。
- Coach score、相性ボーナス、連打ペナルティにより、ただ眺めるだけではなくなった。
- QBがN/LBに接触されても投げる破綻を直し、サックとhit-as-thrownを分けた。
- 長方形選手をやめ、丸い駒に前方ノッチを付けて向きを示す形に戻した。
- OL3人を追加し、ラッシャーがQBへ直行せず一度ブロックに受け止められるようにした。
- ポケット幅が狭いほど投球が苦しくなるため、投げるタイミングに意味が出た。
- 接触によるhit-as-thrownと、ポケットが狭いだけの足場ペナルティをログ上で分けた。
- 速度を 0.45x / 1x / 1.45x で切り替えられるため、接触と捕球の瞬間を観察しやすくなった。
- `P` と Pause ボタンで途中停止でき、サックや捕球の位置関係を確認しやすくなった。
- サック、崩れた投球、パス、捕球、インコンプリート、タックルをフィールド上バナーで出すため、ログを読まなくても大筋が分かる。
- デバッグ snapshot に速度、停止、バナー状態を入れたので、以降の自動検証で観察性を確認できる。
- 実行中の座標フレームを保存し、結果後に `Replay` / `L` で見返せるようになった。
- Replay はドライブやCoach scoreを再計算せず描画だけを再生するため、確認操作でゲーム状態が二重に進まない。
- リプレイスライダーと `-1` / `+1`、`,` / `.` のコマ送りで、サック直前や捕球直前のフレームへ戻れる。
- バナー発生点をリプレイイベントマーカーとして保存し、重要イベントへクリックでジャンプできる。
- Draw Screen で H が最初にパスプロへ入り、遅れてスクリーンへリリースするようになった。
- リリース前の H はQBの投げ先評価を下げ、リリース後は Blitz 相手にスクリーンとして選ばれやすくした。
- H のチップブロックを青リングで表示し、リプレイにも残るようになった。
- Draw Screen 捕球後に LT/C/RT が前へ抜け、H の前にスクリーン壁を作るようになった。
- スクリーン壁に近い守備者は追跡速度が落ち、壁に引っかかったことが赤リングで見える。
- ブロック接触が距離だけでなく、ブロッカーの体の向き、守備者との前後関係、肩の入り方を使うようになった。
- `blockQuality` を表示/保存し、正面で作ったブロックほどリングが太くなる。

## 弱いところ

- 守備 AI はまだプリミティブで、カバー受け渡しやブロックの説得力は不足している。
- ルート点の削除、保存、名前付けがない。
- ランプレー、ブロック、インターセプト、サック後の処理は簡略化している。
- 見た目は改善したが、アニメーション演出や音はまだ弱い。
- 実時間のテンポ、スロー、リプレイ、コマ送りは入ったが、まだ再生UIは最低限で見た目の完成度は粗い。
- パス失敗と捕球成功の視覚差は改善したが、タックルや落球の専用アニメーションはまだ弱い。
- 向きの概念は入ったが、フットワーク、ブロック接触、肩の入れ方はまだ簡略化している。
- 相手AIはまだスクリプト傾向で、長期的な適応やフェイクは弱い。
- OL/DLの本格的な押し合い、ポケット形成、ブロック責任はまだ仮想化している。
- ブロックはまだ1対1の簡易モデルで、スタント、ダブルチームはない。角度は見るようになったが、腕の伸び、押し込み、ホールディングはまだない。
- リプレイマーカーは入ったが、マーカーの位置はイベント発生時点の近似で、接触直前の数フレーム前へ自動補正する機能はまだない。
- バナーは結果理解を助けるが、落球/タックルの専用アニメーションや音はまだない。
- 50サイクルをまとめて書く形では不十分だったため、v006 以降は1バージョン1サイクルで実差分を積む必要がある。

## 次に直すなら

1. ブロックの押し込み/抜け/ホールディングを結果として分ける。
2. ブロッキングとサックをさらに独立した接触モデルにする。
3. ルート点の削除とプレー保存。
4. 守備側にもユーザー編集可能なプレーブックを入れる。
5. リプレイマーカーを接触直前フレームへ補正する。
