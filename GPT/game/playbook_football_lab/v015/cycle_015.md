# サイクル015 自己判断

日付: 2026-06-24

## 観察

v014 でブロック/反則まわりは最低限一貫した。次に弱いのは作戦編集。中間点を追加できるが消せず、作ったルートも保存できないため、試行錯誤がその場限りになっている。

## 判断

このサイクルではルート点削除とプレー保存を同時に入れる。削除だけでは編集結果を持ち越せず、保存だけでは誤操作の修正が弱いので、作戦盤としてはセットで必要。

## 実装

- `Delete point` ボタンを追加
- Add point と Delete point を排他的にした
- 中間点だけ削除し、始点/終点は守る
- `Save play` ボタンを追加
- 編集済みルートをプレー名別に `localStorage` へ保存
- 保存済みルートをプレー選択時に復元
- snapshot に `savedPlayNames` と `routeOverrides` を追加
