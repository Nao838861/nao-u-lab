# Playbook Football Lab v016

PlayMaker Football の「プレーを作って結果を見る」面白さを、現代的なフットボール試作盤として育てているプロトタイプ。

## 起動

`index.html` をブラウザで開く。

## 操作

- `1` から `3`: プレー選択
- `Space`: スナップ
- `R`: ドライブ初期化
- `P`: 一時停止/再開
- `L`: 直前のプレーをリプレイ
- `,` / `.`: リプレイを1フレーム戻す/進める
- `Edit routes`: WR / TE / RB のルート点をドラッグ編集
- `Add point`: ルート線付近をクリックして中間点を追加
- `Delete point`: 中間点だけを削除
- `Save slot`: 現在のルートを名前付きの新規案として保存
- `Quick save`: 選択中の保存案を上書き。保存案がなければ新規作成
- `Delete slot`: 選択中の保存案を削除
- `Throw timing`: QB が投げるタイミングを調整
- `0.45x / 1x / 1.45x`: 再生速度を変更

## v016 の狙い

v015 ではプレーごとに保存できるルート案が1つだけだった。実際に作戦盤として使うには、同じプレーに対して「浅いクロス」「少し深いクロス」「Hを早く外へ出す」など複数案を残して比較したい。

v016 では、各プレーに名前付き保存スロットを持たせた。左パネルでスロットを選ぶと、その保存案のルートがベースとして復元される。v015 の単一保存データが残っている場合は、初回読み込み時に `Saved 1` として移行する。

## 実装済み

- プレイ別の名前付き route slot
- `Save slot` による複数案保存
- `Quick save` による選択中slotの上書き
- `Delete slot` による保存案削除
- v015 `localStorage` データの移行
- Playbookカード上の保存数表示
- snapshot の `savedSlots` / `activeSavedSlot`
- 既存のルート編集、点追加/削除、リプレイ、holding処理、screen wall、block quality
