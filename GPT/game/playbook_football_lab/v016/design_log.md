# Playbook Football Lab v016 設計ログ

日付: 2026-06-24

## v016 自律サイクル

### 現状観察

v015でルート編集結果を保存できるようになったが、保存先はプレーごとに1件だけだった。これでは「少し浅い案」「Hを早く外へ逃がす案」「Yを残す案」を残して比べる遊びができず、作戦盤としての手触りが弱い。

### 判断

今回のサイクルでは、新しい接触モデルを増やすより先に、プレイヤーが作った案を残し、選び直せる土台を強くする。PlayMaker Football的な面白さは、プレーを作って試し、少し直してまた試す往復にあるため、保存スロットは基礎体験に近い。

### 実装

- v016として独立ディレクトリを追加。
- 左パネルに `Save name`、`Save slot`、`Delete slot`、slot一覧を追加。
- 保存形式を `playName -> { activeId, slots }` に変更。
- v015の単一保存形式を `Saved 1` として移行できる `normalizeSavedRoutes()` を追加。
- `routeRelative()` が選択中slotのルートをベースにするよう変更。
- `Quick save` は現在slotの上書き、`Save slot` は新規slot作成として役割を分けた。
- snapshotに `savedSlots` と `activeSavedSlot` を追加。

### 残った弱点

rename専用UI、import/export、守備側プレーブック編集はまだない。次は守備側にもユーザー編集可能な設計盤を入れると、攻撃案と守備案の読み合いに近づく。

過去サイクルの詳細は `v015` 以前の各ディレクトリを参照する。
