# Playbook Football Lab v016 自己評価

## 良くなったところ

- 同じプレーに複数のルート案を保存できるようになり、作戦盤としての試行錯誤が少し現実的になった。
- `Save slot` と `Quick save` を分けたので、「新しい案を作る」と「今の案を更新する」の操作意図が分かれた。
- v015 の単一保存形式を `Saved 1` として移行するため、前サイクルの保存成果を捨てずに済む。
- Playbookカードに保存数が出るため、どのプレーに自分の案があるか分かる。
- snapshot に保存スロット一覧と現在スロット名が入り、以後の自動検証で状態を見やすくなった。

## 弱いところ

- slotのrename専用操作はなく、Quick save時に入力欄の名前で上書きするだけ。
- 保存案のimport/exportがないため、ブラウザをまたいだ共有やバックアップはまだ弱い。
- ルート案は攻撃側だけで、防御側の調整プレーブックはまだない。
- 実際の面白さはまだルート編集とリプレイ寄りで、守備AIの読み合い、ブロックの責任分担、ランプレーは浅い。
- 見た目のUIは改善したが、保存スロットの比較は手動選択で、並列プレビューや差分表示はない。

## 次に直すなら

1. 保存スロットのrename/import/exportを追加する。
2. 守備側にもユーザー編集可能なプレーブックを入れる。
3. ブロッキングとサックをさらに独立した接触モデルにする。
4. holding の accept/decline 選択を入れる。
5. リプレイマーカーを接触直前フレームへ補正する。
