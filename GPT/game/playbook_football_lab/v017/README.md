# Playbook Football Lab v017

PlayMaker Football の「プレーを作って結果を見る」面白さを、現代的なフットボール試作盤として育てているプロトタイプ。

## 起動

`index.html` をブラウザで開く。

## 操作

- `1` から `3`: プレー選択
- `Space`: スナップ
- `R`: ドライブ初期化
- `P`: 一時停止/再開
- `L`: 直前のプレーをリプレイ
- `,` / `.`: リプレイを1フレーム戻す/進める
- `Edit routes`: WR / TE / RB のルート点をドラッグ編集
- `Add point`: ルート線付近をクリックして中間点を追加
- `Delete point`: 中間点だけを削除
- `Save slot`: 現在の攻撃ルートを名前付きの新規案として保存
- `Quick save`: 選択中の攻撃保存案を上書き
- `Edit defense`: 守備選手の初期位置をドラッグ編集
- `Save defense`: 現在の守備コール用に守備配置を保存
- `Reset defense`: 現在の守備コールの保存配置を削除
- `Throw timing`: QB が投げるタイミングを調整
- `0.45x / 1x / 1.45x`: 再生速度を変更

## v017 の狙い

v016 で攻撃ルートは複数案を保存できるようになった。次の弱点は、守備が固定配置のままで、攻撃側だけが作戦盤になっていることだった。

v017 では、守備コールごとに初期配置をドラッグ編集して保存できるようにした。Nickel Zone のセーフティを深く置く、Press Man のCBを内側に寄せる、Edge Blitz のLBを少し広く構える、といった調整を残せる。保存した配置はスナップ時の初期位置として使われる。

## 実装済み

- 守備選手のドラッグ編集モード
- 守備コール別の配置保存
- 保存済み守備コールのカード表示
- 守備配置のreset
- snapshot の `defenseEdit` / `savedDefenseCalls` / `defenseShape`
- v016の攻撃ルートスロット保存の継承
- 既存のルート編集、保存スロット、リプレイ、holding処理、screen wall、block quality
