# Playbook Football Lab v017 自己評価

## 良くなったところ

- 攻撃側だけでなく、守備側の初期配置も作戦盤として触れるようになった。
- 守備コールごとに配置を保存できるため、同じ攻撃ルートでも相手の形を変えて試せる。
- `Edit defense` は攻撃ルート編集と排他的にしたので、ドラッグ対象の混乱が少ない。
- 保存済み守備コールはカード上に `saved shape` と表示される。
- snapshot に守備編集状態と守備配置が入り、以後の検証で見える情報が増えた。

## 弱いところ

- 守備の役割そのものはまだ固定で、CBをzoneに変える、LBをmanにする、といった責任変更はできない。
- 保存配置の名前付けや複数スロット化はまだない。
- 守備編集は初期位置だけで、snap後のルールや読みはまだ簡易AIに依存している。
- 守備を動かした結果、実際にQBのreadやroute leverageがどれだけ変わったかを比較するUIはない。

## 次に直すなら

1. 守備選手ごとの責任プリセットを切り替えられるようにする。
2. 守備配置にも名前付きスロットを入れる。
3. スナップ前に攻撃/守備の噛み合わせを簡易予測する matchup preview を入れる。
4. holding の accept/decline 選択を入れる。
5. ランプレーとブロック責任を独立させる。
