# Playbook Football Lab v019 自己評価

## 良くなったところ

- スナップ前に、どのレシーバーが有利そうかを見られるようになった。
- 投球タイミング、ルート形状、守備位置、守備責任がpreviewに反映される。
- `rush` が多い時にhot riskとして表示されるため、QBが潰される前に投げる判断につながる。
- v018で入れた守備責任編集が、単なる設定ではなく事前分析に接続された。

## 弱いところ

- previewは静的な近似で、実際の動的なカット、接触、QB pressureまでは完全に予測していない。
- man/pressの対象割当はまだ粗く、LB/Sの責任変更に対する評価は限定的。
- previewと実プレー結果の差分説明がまだない。
- UI上でpreviewの根拠をフィールド線として表示していない。

## 次に直すなら

1. previewの根拠線をフィールド上に表示する。
2. 実プレー後にpreviewと結果の差分を出す。
3. zone責任をhook/curl/flat/deepに分ける。
4. LB/Sのman対象を選べるようにする。
5. holding の accept/decline 選択を入れる。
