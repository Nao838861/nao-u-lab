# Playbook Football Lab v021 自己評価

## 良くなったところ

- 事前previewと実結果がつながり、プレー後に何が起きたかを理解しやすくなった。
- サック時は「ルート以前にpressureで壊れた」と説明できるようになった。
- 失敗/成功時に、previewが推した対象と実際の対象が同じか違うか分かる。
- snapshotにpreview差分が入り、以後の検証で結果説明を追える。

## 弱いところ

- 差分説明は短文で、まだ詳細な時系列やフレーム位置までは示さない。
- previewと結果の比較は最有力ターゲット中心で、全ルートの差分分析はない。
- サック以外のpressure影響はまだ粗い。
- 文字化けが残っている古い文言はまだ完全には整理できていない。

## 次に直すなら

1. zone責任をhook/curl/flat/deepに分ける。
2. LB/Sのman対象を選べるようにする。
3. 守備保存にも名前付きスロットを入れる。
4. リプレイマーカーをpreview差分地点へジャンプできるようにする。
5. holding の accept/decline 選択を入れる。
