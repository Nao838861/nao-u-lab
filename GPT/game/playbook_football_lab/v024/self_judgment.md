# Playbook Football Lab v024 自己評価

## 良くなったところ

- 守備編集がクリック巡回だけではなくなり、選手・責任・対象を直接指定できるようになった。
- フィールド上で選択中 defender が青リングで見えるため、どの選手を編集しているか迷いにくい。
- クリック巡回を使った場合もセレクタが追従するので、既存操作と新操作が分断されていない。
- snapshot で `selectedDefender` を見られるため、次の検証で状態の取り違えを追いやすい。

## 弱いところ

- man target の線は setup 中の preview line としてまだ独立表示されていない。
- duty と target は直接選べるが、守備保存スロットはまだコールごと 1 つだけ。
- defender ごとの役割説明は薄く、`hook/curl/flat/deep` の違いを画面から学びにくい。
- 選択セレクタは便利になったが、戦術的な「なぜその設定が効くか」のフィードバックはまだ弱い。

## 次に直すなら

1. man target の線を setup 中にフィールドへ表示する。
2. 守備保存にも名前付きスロットを入れる。
3. duty ごとのゾーンランドマークをフィールド上に薄く表示する。
4. リプレイマーカーから preview 差分地点へジャンプできるようにする。
5. holding の accept/decline 選択を入れる。
