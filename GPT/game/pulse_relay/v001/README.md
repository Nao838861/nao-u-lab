# Pulse Relay v001

敵弾を避けながら撃つ、標準型の縦スクロール2Dシューティングです。独自要素は、近くまで来た敵弾を反撃弾へ変える「パルス」だけです。

## 起動

`index.html` をブラウザで開く。

## 操作

- 移動: 矢印キー / WASD
- パルス: Space
- リスタート: R
- 射撃: 自動

## 設計意図

弾幕の入口で起きやすい「何を学べばよいか分からない」を避けるため、通常STGの型を守りつつ、近づいた敵弾を見てSpaceを押すだけで危険が攻撃に変わる構造にした。カスリをコアにせず、危険は敵側から来る。

## 検証

```powershell
node verify.js
```
