# Pulse Relay v001 design log

## 分類

- 作業分類: new_prototype
- target: STGに慣れていない人でも30秒で「避ける、撃つ、近い敵弾を変換する」を理解できる層。
- 型: 縦スクロール2Dシューティング。移動、連射、敵編隊、敵弾、ボス、スコア、ライフを持つ。
- 独自要素: 敵弾を自機周辺のパルスで反撃弾へ変換する。
- 一番楽しい瞬間: 敵弾が近づいてきた瞬間にパルスを撃ち、危険だった弾が一斉に上へ返って敵を壊す瞬間。
- 緊張の発生源: 外発。敵が弾と接近編隊で押してくる。

## 使った記憶

- R-A: 一番楽しい瞬間から設計する。
- R-B: 緊張は外発に置き、自発リスクのコア化を避ける。
- R-C: ルールは画面で見えるものに限る。
- R-D: 型から始め、独自要素は1つだけにする。
- R-F: 指標は誰のどんな行動で取るかを書く。
- R-G: targetを1行で維持する。
- R-I: 実装前に批判レビューし、人間プレイ前に自己判定する。
- 弾幕衰退 atom: 問題は弾数ではなく、序盤で「何を学ぶと次へ進めるか」が見えるか。
- graze_log feedback: カスリをコアにすると、プレイヤーが自分から危険へ行く不自然な構造になりやすい。危険は向こうから来るべき。

## 類似事例メモ

実装では既存ゲームのソースは見ない。LLMの一般知識として、縦STGの基本型は Space Invaders / Galaga / Xevious / 1942 / TwinBee / Raiden / Toaplan系 / CAVE系 / Ikaruga / Radiant Silvergun などにある。敵弾を利用する発想は Ikaruga の極性、Mars Matrix の吸収、Giga Wing のリフレクト、Psyvariar のBUZZ、ZeroRanger の現代的導入などを参照対象にできる。ただし v001 は極性切替やカスリを増やさず、標準STGに「変換パルス」1個だけを載せる。

## 採用仕様

- Canvasの縦STG。
- WASD/矢印で移動、Z/クリック長押しなしで常時オートショット、Spaceでパルス。
- パルスはクールダウン1.8秒。範囲内の敵弾を消して白い反撃弾に変える。
- 反撃弾は真上へ飛び、通常弾より高威力。
- 敵は固定タイムライン + seeded PRNGの小さな揺らぎ。
- 45秒前後でボス。
- ライフ4、被弾後短い無敵。

## 着手前批判レビュー

1. 懸念: パルスがカスリ強要になる。解決可能性: 可。対策: 敵弾を自機方向へ自然に飛ばし、パルスは近づいた危険の処理として使う。
2. 懸念: 通常ショットが不要になる。解決可能性: 可。対策: 反撃弾は強いがクールダウンあり。雑魚処理は通常ショットが中心。
3. 懸念: ルールが伝わらない。解決可能性: 可。対策: パルス円、変換の色変化、最初のWaveで単発弾を近づける。

## 人間プレイ前予測

- 操作感: 標準STGとしてすぐ動ける。Spaceの使い時は最初の10秒で1回成功すれば分かるはず。
- 快感ピーク: ボスの扇弾をパルスで返してHPバーが大きく削れる瞬間。
- 想定離脱点: パルスを防御ボタンとしてしか認識できず、通常ショットだけの単調なSTGに感じる可能性。

## 指標

- 生存時間: 回避と被弾後復帰が機能しているか。
- 変換回数: 独自要素がプレイ中に実際に使われるか。
- 変換弾命中数: パルスが攻撃快感に接続しているか。
- ボス到達/撃破: 1プレイの山場に届くか。
