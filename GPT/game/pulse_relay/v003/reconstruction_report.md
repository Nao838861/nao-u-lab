# Pulse Relay v003 再構築記録

2026-05-25 に消失した `v003` を、残存していた `v001`、教師差分ログ、Slack投稿、会話記録から再構築した。

重要な復元点:
- サイドパネルを完全に消し、ゲーム画面を中央に置いた。
- タイトル開始、Pulse、リトライを Space に統一した。
- ブラウザではタイトル画面から始まり、Spaceを一度押して開始する。Node検証では従来通り即プレイ開始できる。
- Pulseゲージはゲーム開始後に空から始まり、チャージされる。
- Pulse範囲内の敵弾に対象物側マーカーを出し、発動可能かつ意味がある状態を文字ではなく視覚で示す。
- 常時文字による `PULSE READY` 表示を避けた。
- ゲームオーバー/クリア後は画面上の矩形ボタンではなく、Spaceでリトライする。
- `enemy_behavior_audit.js` を追加し、画面外射撃、長すぎる非ボス滞在、不自然な移動ジャンプを監査する。

この版は「v003の厳密な元ソース復元」ではなく、「v003相当の型を再現するための復元版」である。元ソースは未追跡のまま消失していたためgitから復元不能だった。
