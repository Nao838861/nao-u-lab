# Pulse Relay v005 / v006 / v007 体感差メモ

このメモの目的は、仕様名の違いではなく、プレイヤーが実際に何を考え、何を変えて遊ぶかの違いを残すこと。

## ユーザー指摘

以前の v006/v007 について、ユーザーは次のように指摘した。

- 「5と6と7の何が違うか全くわからなかった」
- 「言われてみると5は確かにpulseしたあとちょっとだけ判定が残るなと思ったが、6は体感が何も変わらず、7は説明されても違いが判らなかった」
- 「もっと大きく変えないと、体感の差が出ない」
- 「６も7も適当に弾を撃ち返して遊ぶだけで、何が変わったのかよくわからなかった」
- 「6は紫の敵がpulse発動時に死ぬ？」
- 「7は発動時に紫の敵の色が黄色に変わった気がしたが、一瞬で死んだのでよくわからなかった」
- 「どっちも理解できない謎ルールが微妙に増えてるけど意味が分からないし、やってることは何も変わらない」

この指摘から、単に数値や色や発射パターンを変えるだけでは不十分だと判断した。違いは、プレイヤーが押すタイミング、移動、狙い、リスクの取り方を変える必要がある。

## v005

v005 は「Pulse 後に短時間だけ残る判定を置く」版。

体感:

- Pulse を押したあと、その場に短く残るフィールドがある。
- プレイヤーは敵弾をその場に誘導し、残留判定で拾わせる。
- 主な面白さは「今押すと少し後の弾も取れる」という猶予。

v005 の弱点:

- v006/v007 と比べると変化量が小さい。
- その場で撃ち返す遊びから大きく離れない。

## v006

v006 は「MAX Pulse でストームを置き、敵弾を抱え込んでから遅れて放つ」版。

体感:

- MAX Pulse を押すと、自機周辺に大きな青いストームが出る。
- ストームが一定時間残り、自機に追従する。
- プレイヤーはストームを敵弾に重ねる。
- 捕獲された敵弾はすぐ返るのではなく、終了時にまとまって誘導サルボとして放たれる。

v006 の正しい差分:

- 押した瞬間の反射ではなく、発動後の数秒間をどう動くかが大事。
- 危険な弾幕へ踏み込むとリターンが大きい。
- `stormCaptures` と `stormSalvos` が主指標。

2026-05-25 の代表値:

- route clearRate: 1
- meanStormCaptures: 369
- meanStormSalvos: 6
- lane-holder clearRate: 0
- blind-sweeper clearRate: 0

## v007

v007 は「Pulse で敵を一時的な味方砲台にする」版。

体感:

- Pulse を当てた敵が黄色くなる。
- 黄色くなった敵はしばらく画面に残る。
- 黄色くなった敵は赤い通常弾を止め、黄色い味方弾を撃つ。
- 味方弾は別の敵やボスを狙う。
- プレイヤーは、敵弾をただ返すだけでなく「どの敵を味方化するか」を考える。

v007 の正しい差分:

- 横移動で狙った列に合わせてから Pulse しないと強い支配にならない。
- 中央で待って適当に Pulse する `lane-holder` はクリアできない。
- `rewriteActiveTime`, `alliedShots`, `alliedHits`, `alliedKills` が主指標。

2026-05-25 の代表値:

- route clearRate: 1
- meanRewrittenEnemies: 18
- meanRewriteActiveTime: 230.72
- meanAlliedShots: 1451
- meanAlliedHits: 919
- meanAlliedKills: 92
- lane-holder clearRate: 0
- blind-sweeper clearRate: 0

## 次回以降の判断基準

新しいバージョンを作るときは、次を満たさない限り「体感差がある」と判断しない。

- プレイヤーの移動が変わる。
- Pulse を押すタイミングが変わる。
- Pulse の対象選びが変わる。
- 成功時の画面上の結果が、説明なしでも見える。
- 悪い policy、特に中央待ち、無差別 Pulse、下部キャンプが強くならない。
- ヘッドレス評価に、そのバージョン固有の主指標がある。
- その主指標が route で十分に発生し、bad policy では成立しない。

「色が変わる」「数値が少し変わる」「謎ルールが増える」だけでは不十分。プレイヤーが何を狙うゲームになったかが変わっていなければ、別バージョンとしては失敗。
