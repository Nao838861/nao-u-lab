# Pulse Relay v005 / v006 / v007 体感差比較

この文書は、ユーザー確認で出た「v006は体感が何も変わらず、v007は説明されても違いが判らなかった。もっと大きく変えないと、体感の差が出ない」という指摘を受けて作った比較記録です。

## 重要な反省

内部仕様が違うだけでは、別バージョンとして弱い。プレイヤーが1回のプレイ中に見て、押して、結果を感じられる差分が必要。

悪い状態:

- charge 経済が入っているが、画面上ではいつもの Pulse と似ている。
- 敵の内部状態が変わっているが、敵の色、弾、攻撃停止、倒し方が変わらない。
- 説明されると違うが、プレイヤーが見ても分からない。
- ヘッドレス指標は増えているが、人間の体感差に直結していない。

良い状態:

- その版を一文で説明できる。
- その一文が画面上の見た目、敵の振る舞い、弾の軌跡、倒れ方に出ている。
- ヘッドレス指標が、その一文の成立を測っている。

## v005

体感の一文:

Pulse 後に短時間だけ場が残り、敵弾を拾い続ける。

画面上で見えること:

- Pulse の範囲が一瞬で消えず、短時間だけ場として残る。
- 敵弾が場に入ると Relay 化する。
- 敵が共鳴し、追加の燃料弾や Chain Relay へつながる。

この版の主役:

- 残留フィールド。
- 敵弾を受ける位置取り。
- Pulse を「その瞬間だけの反射」ではなく「置いた場所で拾い続ける」遊びにすること。

## v006

体感の一文:

charge を溜めて MAX Pulse を撃つと、画面中の弾と敵へショックウェーブが走り、敵から敵へ枝分かれする。

画面上で見えること:

- 敵弾の近くを通ることで `CHARGE` が溜まる。
- MAX Pulse で画面内の敵弾がまとめて Relay 化する。
- MAX Pulse で画面内の敵にもショックウェーブが当たる。
- ショックウェーブを受けた敵から近くの敵へ枝分かれ Relay が出る。
- 1回のMAX Pulseで画面全体が反転したように見える。

この版の主役:

- 危険へ近づいて溜めること。
- 溜めたMAX Pulseを吐くタイミング。
- 画面全体を一気に反転させる報酬。

修正後の代表指標:

- route meanConverted: 363
- route meanMaxPulseCount: 6
- route meanMaxShockwaveConversions: 363
- route meanMaxShockwaveHits: 44
- route meanChainHits: 43
- route meanRelayKills: 44
- offscreenShots: 0
- lingeringEnemies: 0

## v007

体感の一文:

Pulse を当てた敵が黄色い書き換え状態になり、通常の赤弾を止めて味方弾を撃つ。

画面上で見えること:

- 書き換えられた敵が黄色くなる。
- 書き換え中の非ボス敵は通常の赤い敵弾を撃たない。
- 書き換え中の敵は黄色い味方弾を撃つ。
- 黄色い味方弾が別の敵に当たり、敵を倒す。
- Pulse を押した結果として、敵の所属が一時的に反転したように読める。

この版の主役:

- 敵を一時的に味方砲台へ変えること。
- どの敵をPulse範囲に入れるか。
- 敵弾が少ない場面でも、敵本体にPulseを当てる意味を作ること。

修正後の代表指標:

- route meanRewrittenEnemies: 23
- route meanRewriteFuelShots: 114
- route meanRewriteKills: 29
- route meanRewriteBossPatternCount: 2
- route meanAlliedShots: 46
- route meanAlliedHits: 46
- route meanAlliedKills: 25
- offscreenShots: 0
- lingeringEnemies: 0

## 今後の自律サイクルで必ず確認すること

新しいバージョンを作る時は、実装前と実装後に次を確認する。

- この版は、既存版と比べて体感の一文が違うか。
- その一文は、画面上の記号、敵の動き、敵弾、味方弾、倒れ方に出ているか。
- その一文は、説明なしでもプレイヤーがある程度気づけるか。
- その一文に対応するヘッドレス指標を追加したか。
- 指標が pass しても、人間に「違いが分からない」と言われそうな状態ではないか。
- UI微修正や微小パラメータ変更を、大きなゲーム性の違いとして扱っていないか。

特に避けること:

- v006を、単なる「chargeがあるv005」にしない。
- v007を、単なる「敵内部状態が少し変わるv006」にしない。
- 「説明されれば違う」で完了にしない。
