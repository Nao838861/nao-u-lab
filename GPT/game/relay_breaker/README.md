# Relay Breaker

ブロック崩し系の小さな完成版です。通常の「全部壊す」だけではなく、赤/黄色の障害ブロックを壊しながら、水色の Relay を残して信号を保つことを目的にしています。

## 記憶から使ったもの

- `sr-1777620970-5aa3829614`: brick breaker variation の先行事例。「守る blocks / 壊す bricks」の二重目的を採用。
- `sr-1777411453-ee79528ff7`: Breakout の trajectory controller 問題。パドル上の当たり位置で角度を明確に変える。
- `sr-1777840717-8fbdcca6a5`: 表層チューニング偏重を避ける。単なる数値調整ではなく、Relay を残す基板仕様を入れた。
- `sr-1777678483-258c1df4a1`: M-40 自己判断。プレイの上手さより、狙いが機能しているかを見る。

## 実行

`index.html` をブラウザで開く。
