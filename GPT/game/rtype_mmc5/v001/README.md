# R-Type風 MMC5 レーザー試作 v001

`play.cmd` でMesenを起動。ほかのMapper 5対応エミュレータでは `rtype-mmc5.nes` を開く。十字キーで移動、Aで対空レーザー、Bで反射レーザー。押し続けると連射する。フォースと上下のビットを装着した固定一画面の試射場で、敵に光を重ねると撃破できる。

通路で反復する24種類のタイルにだけ24種類の光マスクを合成する。通常の背景は壁込みで116タイル。バンク0に通常背景、1〜24に各マスクと通路を合成したCHR、31にスプライトを置いた。合成済みの各バンクでは先頭24タイルだけを使う。CHR ROMは128 KiBで、MMC5の選択単位は各4 KiB。発射中はネームテーブルを固定し、VBlankにExRAMの旧位置をクリアして新位置へバンクと色を書き込む。転送中は $5104=2、表示時は1。壁は反射の境界に使う。

ビルドはPython 3、Pillow、PATH上のcc65・ca65・ld65を用意して `python build.py`。任意の動作確認はMesen 2を使い `python verify.py`。実機での動作確認は未実施。
