# R-Type MMC5 試射 v002

[play.cmd](play.cmd) で起動。十字キーで移動、Aで赤青の対空レーザー、Bで青の反射レーザー。どちらも押し続けると連射できる。[Mesenで撮影した動き](preview.gif)。

録画冒頭の一画面を横に送る試射場。通常背景に通路454種、周縁の装甲182種のタイルを持ち、ExRAMで静止画用3バンクとレーザー合成用バンクを選ぶ。各タイルの通常属性は消灯時に戻す。射撃中のネームテーブル転送は0。R-9、フォースの外殻と発光部、ビット、敵はスプライトで描く。

録画とROMの違いとして、256×208の場面をNESの配色に減色し、録画で物体に隠れる箇所を隣の模様から補った。背景は一画面でループする。原作のレーザーと発射位置にはタイル単位の近似がある。色を重ねるタイルでは一部の背景色を共通化し、145種の対空レーザー断片を57種類にまとめた。

ビルドにはPython、NumPy、Pillow、PATH上のcc65・ca65・ld65を使う。`python build.py` でROMを再生成する。`art/` に変換済みの素材があり、録画本体は不要。Mesen 2のある環境では `python verify.py` で両武器の撮影と背景復元の検査を繰り返せる。
