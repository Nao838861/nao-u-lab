# R-Type MMC5 試射 v003

[play.cmd](play.cmd) で起動。十字キーで移動、Aで対空レーザー、Bで反射レーザー。長押しで連射する。[発射のスロー再生](launch-slow.gif) と [全画面の通常再生](preview.gif) はMesenの出力。

対空レーザーはフォースを起点に上下に伸び、最初の大きな円を描いてから正面で交差する。青は下側、赤は上側を通って次の小さな円弧に入る。2発分の進行位置を別々に持つ。背景のパネルの継ぎ目と通風孔の暗部は黒にした。

光の形とパレットをタイル単位でExRAMに書く。白い芯のある赤、白い芯のある青、交差用の赤青を使い分ける。発射直後の1本の弧から飛行中の交差までを32段階で格納した。細部は57種の合成マスクに近似している。

ビルドはPython、NumPy、Pillow、PATH上のcc65・ca65・ld65で `python build.py`。Mesen 2を使う検査とGIF撮影は `python verify.py`。
