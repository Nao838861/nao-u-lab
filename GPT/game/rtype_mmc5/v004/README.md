# R-Type MMC5 試射 v004

[play.cmd](play.cmd) でMesenを起動。十字キーで移動、Aで対空レーザー、Bで反射レーザー。押し続けると連射する。[実行画面](preview.gif)。

画面を縦に64走査線ずつ分け、MMC5のIRQでCHR ROMの256 KiB窓を切り替える。4区間の合計は1 MiB。各区間は、次の区間の先頭タイル行も同じ番号に用意して先読みを受ける。高さごとにネームテーブルのタイル番号を使い直すことで、通路428種と周縁182種を元の絵のまま共存させた。

合成CHRはその位置の背景から生成する。表示灯を含むタイルでは赤と青を背景と光で共用するため、そのタイル内の光には白い芯が付かない。点灯していない背景画素は全て維持する。レーザーの移動と消去はExRAMの属性書き換えで行う。

ビルドはPython、NumPy、Pillow、PATH上のcc65・ca65・ld65で `python build.py`。Mesen 2による単独連射・スクロール・画素検査は `python verify.py`。
