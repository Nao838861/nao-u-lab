# R-Type MMC5・録画区間の移植 v004

[通常ステージを起動](play.cmd) ・ [通常版ROM](rtype-mmc5-v004.nes) ・ [ボス開始版ROM](rtype-mmc5-boss.nes)

|操作|通常ステージ|
|---|---|
|十字キー|R-9を移動。上下入力で機体が傾く|
|A|射撃。フォース装着中は赤結晶で対空、青結晶で反射。長押しして離すとR-9から波動砲|
|B|フォースを前方へ射出。もう一度押すと回収|
|Select|通常操作と試射を切り替える。試射中はA長押しで対空、離して波動砲、B長押しで反射。機体は無敵|

通常版は録画冒頭に合わせてフォース装着・ビットなしで始まる。録画の配置を追いながら、敵を撃つか見送るか、結晶を取りに行くかを操作できる。結晶を重ねて取ると、最初の球形フォースに砲身が付き、ついで大きな回転外殻が付く。ビットは上方に追従し、射撃と敵弾の防御を行う。[自機・フォース・ビットの実行画面](r9-force-bit.gif)。ボス開始版はすぐに両レーザーを比較できる試射状態から始まる。Selectで通常操作に戻すと、フォースを腹部の頭に撃ち込める。

[ミサイル・ビット弾・通常弾の原作とROMの比較動画](player-weapons.mp4)。左が指定録画、右が通常プレイのROM。発射と追尾開始をそろえ、等速と1/3倍速で再生する。

通常操作ではAを押すとR-9の機首から白い粒弾が出る。ビット取得後はビットからも水色の尾のある弾が出る。赤・青いずれかの結晶を取ると、A射撃に上下1対のミサイルが加わる。ミサイルの再発射は約1.6秒後。上下に少し開いて前へ加速し、前方近くの敵や砲台に向けて1発ずつ曲がる。フォースを射出中も機体とビットから撃てる。

**波動砲はAを約0.4秒ためて離すと短い弾、約1.1秒以上で最大弾。** 機首の光と充填音が変わる。最大弾は倒した敵を貫通する。フォースを射出していても発射位置はR-9の機首。通常操作とボス開始時の試射のどちらでも使える。[波動砲で床砲台を壊す動画](wave-cannon.mp4)

天井と床に固定された21基の砲台は、自機のほうに砲口を向けて発砲する。通常弾、波動砲、装備レーザー、フォースが当たり、撃破後は台座の下の地形が現れる。

[歩兵の原作・ROM同時再生](walker-comparison.mp4)。床に沿った移動、踏み込み、停止、上昇を同じ時刻・同じ画面幅で並べた。自機の入力は左右で異なる。[実際の通常プレイ全編](stage-scroll.mp4) と [レーザーの試射](preview.gif) も収録した。

背景は指定録画の冒頭から停止位置まで進む。30 fpsの録画で天井と床を追跡し、幅256画素換算のカメラ位置をNTSCの各フレームに割り当てた。約73秒で1,334画素進んで停止する。入口、円形の区画、上下のアーム、暗い区画が順に現れる。暗転はファミコンの4段階の配色で表し、円環の部品は背景として固定している。

横1,590画素の地図を199タイル列に格納し、右端に新しい列が現れるタイミングでネームテーブルとExRAMを更新する。折り返し列が重なる画面左端の背景8画素はPPUでマスクする。64走査線ごとに256 KiBのCHR窓を切り替え、隣接区間の境目に同じタイルを持たせる。4区間の合計は1 MiB。通路と装甲は区間ごとに代表タイルを選ぶ。

上下からせり出す装甲は8×8ごとに材質を選び、外板の白とクリーム色、関節の赤い目盛りを描き分ける。[アーケード録画・旧版・今回のROMの比較](background-palettes.png)。

レーザーはC案を採用。グレー・赤・青・明るい水色の同じBGパレットで対空と反射を描く。光が入るタイル内の黒い溝はグレーになる。[反射レーザーの拡大](reflection-detail.png)。

終盤には録画から復元したボスが現れる。[ボスから始まるROM](rtype-mmc5-boss.nes)は `python build.py --boss` で生成できる。[尻尾の1周期](boss-tail.gif)。固定胴体と尻尾、頭の緑の目、4個のケーブル先端の青いガラスはBGで描く。眼の黄緑とガラスの金色の縁にスプライトを重ねる。録画79コマから拾った節の軌跡を157姿勢に補間し、1 MiBのCHR中で本編が使わないタイルに格納した。レーザーはExRAM、尻尾はネームテーブルとExRAMの差分で動く。

## 録画から合わせた道中の敵

天井からの編隊は最初の区画で5機、次の区画で10機。各機は同じワールド座標から約9録画コマ間隔で降り、左へ曲がるにつれて姿勢を変える。赤い飛行敵は高さを揺らしながら翼を開閉する。最初の段差には小型の二足歩行敵が乗り、終盤の大型歩兵は空中から床に降りて歩き始める。[原作とROMの同時刻比較](enemy-movement.mp4)

原作とROMで撃ち方を変えた比較動画では、原作側で敵が撃破された後もROM側の飛行を見られる。録画で敵を識別できた区間の中心位置を [計測表](art/encounter-paths.csv) に残した。Mesenでの照合は `python verify_encounters.py`、比較動画の生成はデコード済みの `build/stage.rgb` を用意して `python verify_encounters.py --film`。録画から再計測する場合はOpenCVを入れて `python encounter_capture.py` を実行する。

## ボスのコアと泡

[ボス戦の実行動画](boss-attack.mp4) では、腹部の赤い目が現れてあごが開き、泡を3列吐いてから引っ込むところまで見られる。[ボス開始ROM](rtype-mmc5-boss.nes) は入力をしばらく待つだけでも同じ攻撃を繰り返す。

アーケード版の50 fps録画から頭部を6姿勢切り出した。スクロール停止後に腹から少しずつ顔が現れ、露出した部分に弾やフォースが当たる。口から出る泡は1列9発。クリーム色の膜に赤い粒が付き、水平に進んだ列が画面左で上に曲がる。フォースとビットは触れた泡を1発ずつ消す。録画では3列目の後に撃破されるため、生存時に頭を引く速さと次の攻撃までの待ち時間は推定した。[T-0815のアーケード版プレイ録画](https://archive.org/details/Longplay-R-Type_Arcade)

泡はボス室の軌道上の82セルで描く。輪郭がセルに入る時と抜ける時にネームテーブルを更新し、留まっている間はExRAMで絵を切り替える。隣の泡と重なった場合は、消えた側に合わせて単体の絵に戻す。軌道と尻尾が交差すると尻尾が手前に来る。コアの6姿勢は専用スプライトページ1枚に収めた。ROMはPRG 512 KiB、CHR 1 MiB。

## 制作と検証

ビルドにはPython、NumPy、Pillow、SciPy、PATH上のcc65・ca65・ld65を使用する。通常版を `python build.py`、ボス開始版を `python build.py --boss` で生成する。画像と座標は同梱している。

Mesen 2の実行ファイルを環境変数 `MESEN_EXE` に設定する。`python verify.py` はレーザーの画素・反射経路・毎フレームのDMA・スクロールを検査する。`python verify_actors.py` は通常操作での取得・射出・防御・復帰・ボス撃破を検査する。`python verify_actors.py --boss-only --film` でボス撃破、泡の防御と被弾、レーザー連射時の転送を検査し、ボス戦の動画を書き出す。`--film` のみなら通常プレイの動画も更新する。

`python verify_weapons.py --film` は床砲台の発砲・撃破・背景復元、フォース射出中の最大波動砲、試射中の波動砲、全21基を離れた位置から射撃で破壊できることを実行ROMで検査する。

録画から抽出し直すにはFFmpegを用意し、`python stage_capture.py "録画ファイルのパス"`、`python actor_capture.py` を実行する。OpenCVを使う `python actor_analysis.py` で [敵と弾の追跡座標](art/actor-tracks.csv) を再計測できる。比較動画を再生成する場合は検証を両方実行し、通常プレイのコマ画像を残してから `python compare_walker.py` を実行する。

撃破前に録画から消えた敵の退場、砲台の発射間隔、ボスの腹部が引っ込む時間と耐久は近似している。ミス後は装備を失い、その場で復帰する練習仕様。円環の回転・射撃は保留している。
