# R-Type MMC5 試射 v004

[play.cmd](play.cmd) でMesenを起動。十字キーで移動、Aで対空レーザー、Bで反射レーザー。押し続けると連射する。[実行画面](preview.gif)。

背景は指定録画の冒頭から停止位置まで進む。[全区間のスクロール動画](stage-scroll.mp4)。30 fpsの録画で天井と床を追跡し、幅256画素換算のカメラ位置をNTSCの各フレームに割り当てた。約73秒で1,334画素進んで停止する。入口、円形の区画、上下のアーム、暗い区画が順に現れる。暗転はファミコンの4段階の配色で表し、円環の部品は背景として固定している。

横1,590画素の地図を199タイル列に格納し、右端に新しい列が現れるタイミングでネームテーブルとExRAMを更新する。折り返し列が重なる画面左端の背景8画素はPPUでマスクする。64走査線ごとに256 KiBのCHR窓を切り替え、隣接区間の境目に同じタイルを持たせる。4区間の合計は1 MiB。通路と装甲は区間ごとに代表タイルを選ぶ。

レーザーはC案を採用。グレー・赤・青・明るい水色の同じBGパレットで対空と反射を描く。光が入るタイル内の黒い溝はグレーになる。[反射レーザーの拡大](reflection-detail.png)。

終盤には録画から復元したボスが現れる。[ボスから始まるROM](rtype-mmc5-boss.nes)は `python build.py --boss` で生成できる。[尻尾の1周期](boss-tail.gif)。固定胴体と尻尾はBG、胴体の緑の目とケーブルの反射光はスプライト。録画79コマから拾った節の軌跡を157姿勢に補間し、1 MiBのCHR中で本編が使わないタイルに格納した。レーザーはExRAM、尻尾はネームテーブルとExRAMの差分で動く。

ビルドはPython、NumPy、Pillow、PATH上のcc65・ca65・ld65で `python build.py`。Mesen 2による単独連射・スクロール・画素検査は `python verify.py`。背景素材とカメラ位置は同梱している。指定録画から再抽出する場合はFFmpegを用意し、`python stage_capture.py "録画ファイルのパス"` を実行する。
