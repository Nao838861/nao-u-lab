# 録画区間の遭遇設計

録画の開始時点からボス部屋までを対象にした。各列を一回の設計として上から順に検討した。矢印の左は見えている利点・問題、右は実装または検証の方針。

|対象|第一回・画を読む|第二回・操作した場合|第三回・実機相当の制約|
|---|---|---|---|
|開始|途中の映像 → 初期装備を合わせる|既にフォースがある → 最初から装着|起動直後の重なり → 自機と運搬機を別の高さへ|
|出現|映像には休止区間がある → 配置表にする|倒さないと占有する → 同時枠を設ける|生成処理の集中 → 編隊を時間差で出す|
|位置|スクロールで座標がずれる → カメラを引く|上下移動と敵の進入を独立させる → 地点で起動|一周で再出現する → 16ビット地点を使う|
|運搬機|床に近い → 脚の位置を読む|撃ち漏らせる → 退場時は落とさない|多色 → 胴と脚の輪郭を優先|
|小型編隊|縦に並ぶ → 先頭との間隔を測る|一機ずつ撃てる → 独立した当たり判定|群全体は重い → 小型タイルを共有|
|赤い敵|横から入る → 右端の高さを読む|同じ敵が連続する → 周期生成をやめる|端で折り返す → 画面外で退場|
|大型歩兵|歩行後に浮く → 離陸地点を測る|射撃前に倒せる → 生存時だけ発射|大きな絵 → 足元基準で配置|
|歩兵の脚|床段差で浮く → 接地面を採る|移動の途中で床が変わる → 毎歩再参照|全画素走査が高価 → 高さ表|
|歩兵の噴射|横・縦速度が違う → 別々に測定|自機が別の高さにいる → 離陸を自機操作と独立させる|浮動小数は重い → 位相で分ける|
|敵弾|小さな橙の粒 → 発光核を抽出|弾を避けられる → 発射時に方向を固定|角度計算が高価 → 量子化速度|
|弾の寿命|同じ色の表示灯あり → 移動で判断|退場後に戻ると不自然 → 境界で消す|弾幕でOAM不足 → 枠数を限定|
|波動砲|通常弾と大きさが違う → 発射例を読む|長押しを離す理由 → 蓄積時間で威力を変える|横幅が増える → タイルをつなぐ|
|レーザー|赤・青の結晶が見える → 取得と種類を結ぶ|取り逃がすと変化しない → 接触で変更|色揺れ → 共通パレットCを維持|
|検討用操作|両方撃てる既存版がある → 操作を残す|通常進行と比較できる → 試射モードを分ける|従来の試験入力 → 同じシーンを選ぶ|
|結晶|スクロールと並走 → 座標差を測る|近くを通るだけで取ると不自然 → 機首近傍で接触|複数ドロップ → 別々の生存状態|
|ビット|銀色の面が続く → 点灯と消灯を採色|取得前に浮くと不自然 → 所持フラグで表示|短周期が騒がしい → 録画の周期を使う|
|フォース|コアの周囲を横棒が通る → 遮蔽を採る|明るさだけだと回転に見えない → 別姿勢を切り出す|スプライトが競合 → 不透明部分だけ出す|
|自機|上下で機体の幅が変わる → 異なる姿勢を採る|停止時に傾きが残る → 中立に戻す|タイルの浪費 → 空白を共有|
|自機判定|キャノピーと尾の幅が違う → 中央に小さな核|かすめて避けられる → 絵より狭い箱|全画素不要 → 中心差で比較|
|地形|装甲が歯状に張り出す → 高さを列ごとに採る|機首だけで死亡は唐突 → 胴の核で検査|背景灯に当たる → 壁と装飾を別データに|
|接触|爆発が敵と重なる → 中心を固定|撃破済の敵は無害 → 状態を一回だけ遷移|毎フレームの重複加点 → 状態を先に確定|
|防御|フォースが前に張り出す → 別形状|真正面の弾を受ける → 機体より先に判定|判定数 → 生きた弾だけ更新|
|復帰|やられた後の録画がない → 近似を明記|復帰直後の再死亡 → 点滅猶予|スプライト浪費 → 非表示フレームを交互に|
|ボス|胴体と尻尾は既に表示 → 同じ地図を参照|尾に接触すると危険 → 現姿勢で検査|別の軌道表は無駄 → 表示用データを再利用|
|弱点|頭・腹・尾の先が近い → 腹部の露出箇所をボス座標で扱う|連続命中が急すぎる → 被弾間隔を設ける|装甲と弱点に同じ判定 → 弱点を別枠に|
|スプライト端|左端にワープする → 端を検査|画面外の弾が命中 → 画面内だけ検査|OAMが一周 → 末端を予約する|
|BG|リングは後回し → 新規パターンを予約しない|動かない絵で死ぬ → リングを判定から除く|CHR残量だけで判断しない → 更新帯域も最後に測る|
|記録|一度のプレイしかない → 位置と推定を区別|別の入力で変わる → 録画再生で代用しない|ROM検証 → 異なる入力を入れる|
|性能|対空連射が過去に重かった → 最悪区間を測る|敵との交差中が重い → 弾・編隊を同時に試す|VBlank超過 → DMAと表示中書換を監視|
|成果物|実機の見え方が目的 → ROM画面を撮る|起動後に操作が必要 → 操作を同梱する|改変範囲が広い → 比較用ボス開始版も更新|

第一回ではスクロールに登録した出現と録画の追跡を組み合わせる。配置・高さ・間隔を同じ物差しで比較できるが、撃破後の軌道は観測できない。第二回では取得・撃破・被弾をプレイ中の接触で起こす。取り逃しも遊びになる一方、検証用の固定入力は別に必要となる。第三回では時刻・姿勢・床の輪郭をROM側に表として持たせる。描画と判定の食い違いを減らせるが、メモリ配置と走査線の制限を実行時に確かめる必要がある。
