## 1. プロジェクトの正体
**「生産と消費のシミュレーション」** — Nao_uの長年の構想(2026-07-12起票)。
- 主題(Nao_u原文): **「辺境に全ての物資を流通させることが難しい」**
- 元ネタ: Caesar III。「きこり、米作り、漁業、石炭採掘、鉄鉱石採掘…生産品を荷車で運び、商人が集積して、経済が産まれる」(kickoff原文)
- 2つの実装が並走してきた:
  - **Claude/game/flow_island** — 経済(エージェント・価格創発・会社・人口)の先行実装。約24版。未完成の土台
  - **GPT/game/shioji** — 可視物流(道路・占有・荷車・到着時確定)の先行実装。経済は未着手
- **現在の合流点 = `shioji/engine/`**: 両者の強い方を組み合わせたヘッドレス経済エンジン(ENGINE_SPEC.md)

## 2. Nao_uの確定事項(正典の要約——原文は§4のパスで必ず確認)
- 変わらない核: プレイヤー=経済圏の設計者 / 流通が社会を成立させる / **価格は創発**(設計者が価格式を与えない) / 閉鎖経済(輸出白名単・懲罰輸入) / 餓死はある / 人口は自然増 / **住民への直接命令を絶対に足さない**
- 実装検証を経た合意済みの進化(それぞれNao_u承認の記録つき): 3原理の価格(信念廃止) / 賃金労働(普請+日傭) / 人口=出生+家督相続+条件付き移民(自動分家は廃止) / 商館(買上げ・蔵出し・本国注文) / 配給・御蔵の廃止 / 支度金+口銭の建築リズム / 一次産業の生産倍率キャップ2.0(**原点の2/8/32への回帰は却下済み**)
- ドキュメント規約: **規範=Nao_u原文のみ**。AIの補完は【案】と明示して分離(出典3分類)
