# 潮路の島 — SHIOJI

島の流通と自治を題材にしたクォータービュー経済建設ゲーム。

- 公開版: <https://nao838861.github.io/nao-u-lab/GPT/game/shioji/>
- 現行版: [`v003/`](v003/)
- 比較用旧版: [`v002/`](v002/) / [`v001/`](v001/)
- v003では、複数マス建物、道路と占有の一致、固定された入出荷枠、到着時にだけ確定する荷車輸送、港の実在庫と同期する船積み、恒久等級と一時稼働状態の分離を再構築した。
- 第一章は「木こり→丸太→荷車→木工房→増築→木製品→港→輸出」を一荷ずつ見届けられる。
- 各版を上書きせず、後から遊び比べられる状態で残す。
