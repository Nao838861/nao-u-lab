## GPT相談結果の原文（全量・無編集）

設計書の方針が正しく、現行実装が追いついていません。確認すると、少なくとも次の乖離があります。

- 建設費は現地資材ではなく「本土建築資材」として現金だけ消える
- Lv維持は木製品・塩・木炭・布・鉄だけで、石材と建物修繕がない
- 魚粉屋は魚を買わず、別の漁場から直接魚粉を生産する
- 牧場は設計上「麦や野菜を食べる加工職」だが、実装では無投入で肉を生産する
- 全職共通の「木の道具・鉄の道具が摩耗する」案が未実装
- 石材は島全体の石畳を一度完成させると、ほぼ需要が消える

基本原則は、すべての品目に次のうち最低二つ、可能なら三つの需要先を持たせることだと思います。

1. 日常消費・操業投入
2. 建設・投資
3. 維持・摩耗
4. 加工原料
5. 輸出・本国注文

輸出だけを第二需要として数えず、少なくとも二つは島内需要にします。

### 建物維持の仕組み

単なる日次の不可視な維持費ではなく、実物を運ぶ「修繕」として扱うのがよいです。

- 建物ごとに修繕棚を持つ
- 30日ごとに次回修繕品を要求する
- 必要量は敷地面積・建物種・Lvで決まる
- Lv1はほぼ不要、Lv2から木製品、Lv3から石材、Lv4から鉄材や布も必要
- 実際に市場で購入し、誰かが修繕棚まで運ぶ
- 不足しても即停止せず、建物状態が徐々に低下する
- 状態低下で生産量、保管量、運搬効率が落ち、長期間放置するとLvが下がる
- ひび、傷んだ屋根、足場などを盤面に出す

維持需要は二種類に分けます。

- 経年修繕：Lv・敷地面積に比例。停止中の建物にも発生
- 操業摩耗：実際の生産量・運搬距離に比例。働かなければ発生しない

これなら「高Lvだから毎月石材が消える」だけでなく、なぜ消費したか説明できます。

建物ごとの材料も変えます。

| 建物系統 | 主な経年修繕 |
|---|---|
| 漁師・港 | 丸太、木製品、布、鉄材 |
| 畑・牧場 | 丸太、木製品、布 |
| 木工・荷車 | 木製品、石材、鉄材 |
| 塩田・炭焼き | 木製品、石材 |
| 製鉄・鍛冶 | 石材、鉄材 |
| 市場・倉庫 | 木製品、石材、布、鉄材 |

製鉄所などは、操業量に応じて炉の内張り用石材も消費させられます。

### 基礎資源の複数需要

| 基礎資源 | 島内需要案 |
|---|---|
| 丸太 | 木工房、炭焼き、荷車、船、橋・港、低Lv建物修繕、冬の非常用燃料 |
| 石材 | 道路区画ごとの舗装、建設、Lv3以上の修繕、炉の内張り、港の護岸 |
| 魚 | 食事、保存食、魚粉、船の食料、本国注文 |
| 野菜 | 食事、漬物、牧場の飼料、翌年の種苗 |
| 麦 | 食事、牧場・馬の飼料、種麦、船の食料、保存備蓄 |
| 肉 | 食事、塩漬け保存食、船の食料、注文 |
| 石炭 | 製鉄、鍛冶、塩田、冬の暖房 |
| 鉄鉱石 | 主に製鉄。無理に直接用途を増やさず、銑鉄・鉄材側へ複数需要を持たせる |
| 綿・羊毛 | 布、漁網、帆、荷車の覆い、建物修繕 |

特に重要なのは次の三択です。

- 丸太：木製品にするか、冬の木炭にするか、建物を直すか
- 石材：道路を延ばすか、高Lv建物を維持するか、製鉄所を動かすか
- 魚：今日食べるか、保存するか、肥料へ回して将来の収穫を増やすか

同じ資源を奪い合うため、価格と物流に意味が生まれます。

### 加工品の継続需要

- 木製品：全職の木の道具、建設、修繕、荷車、船
- 鉄材：鉄の道具、建物修繕、鉄荷車、船、将来の軍備
- 布：衣類、漁網、帆、日除け、荷車、建物維持
- 木炭：暖房、燻製、塩田、製鉄
- 塩：世帯消費、魚・肉・野菜の保存、家畜
- 魚粉：麦・綿花だけでなく、野菜畑と牧草地にも使う
- 保存食・漬物：世帯、船、会社備蓄、支援、本国注文
- 銑鉄：鍛冶だけでなく、製鉄所・港・倉庫の重修繕にも使う

道具は設計書どおり、全職共通の資本財にするのが特に有効です。

- 素手：常に働ける最低効率
- 木の道具：木製品を購入し、生産効率上昇
- 鉄の道具：鉄材を購入し、さらに上昇
- 実働日数に応じて摩耗
- 壊れても停止せず素手へ戻る

荷車と同じ「なくても生きられるが、あれば強い」構造です。

### 石材需要の具体案

現在の「石材200荷で島の全道路が一括舗装」はやめた方がよいです。

- 道路1区画ごとに石材を投入する
- よく使う道から部分的に舗装できる
- 橋、坂、港周辺は多く必要
- 建物建設にも石材を使用
- Lv3・Lv4建物は定期修繕で石材を消費
- 製鉄所・鍛冶屋は操業量に応じて石材を消費

これなら採石場は町の成長中だけでなく、成熟後も2〜3軒が働けます。

### 優先して戻すべき設計（実装順）

1. 現地建設資材と修繕棚を接続する
2. 道路を区画単位の舗装へ変える
3. 全職の木製品・鉄製道具と摩耗を実装する
4. 魚粉屋を「魚を買う加工職」へ直す
5. 牧場を麦・野菜を買う加工職へ直す
6. 船・漁網・帆へ丸太、木製品、布、鉄を接続する
7. 生産量と施設軒数を再較正する

先に日産だけを下げるより、この需要網を接続してから「人口200で加工施設2〜3軒」を測る方が正確です。需要がないまま生産量だけ下げると、今度は単に全施設が低稼働になる可能性があります。

## Mir注記（設計との整合）

- 「実物を運ぶ修繕・不可視の維持費にしない」は本物の経済の正体と一致。「不足で即停止せず状態が徐々に低下」は無音の崩壊の禁止と整合（状態低下は盤面に出す=絵で出す）
- 道具の「壊れても停止せず素手へ戻る」は荷車・R-B（罰駆動にしない）と同型で正しい
- 需要網はSPEC第6章（経済）の骨格になる。隊商縦切りWORK ORDERの前提§1もこの実装順に合わせて改訂する
