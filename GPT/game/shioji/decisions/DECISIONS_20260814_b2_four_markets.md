# 決定ログ 2026-08-14 — B-2の具体形: 256×256・4市場の相互補完（Nao_u指示）

**状態**: 凍結
**Nao_u原文**: 「市場4つ・母港近くと、漁港、中央盆地の農耕地帯、山間部の鉱山地帯の4つの市場を256x256マップで作って、それぞれ足りない資源を補い合う感じにできないか。全てが終わった後のタスクとして積んでおいて欲しい」

**決定**: B-2（手設計256×256マップ）の初期市場構成を4つで確定。

| 市場 | 持つもの | 欠くもの（＝路線の需要） |
|---|---|---|
| 母港 | 金・輸入品・本国航路 | 土地・資源全般 |
| 漁港 | 魚・塩 | 穀物・木材 |
| 中央盆地（農耕地帯） | 麦・野菜・綿 | 海産・燃料・鉱物 |
| 山間部（鉱山地帯） | 鉱石・石炭・石材・木材 | 食料ほぼ全部 |

- どの圏も自給不能＝多角の路線が必然になる（「補い合う感じ」の機構的な実現）
- Q8の「選択の多様性」原則は維持: 4市場は**種付けされる初期集落**であり、マップには同タイプの未開発候補地（第二の盆地・別の入江等）も置いて「どこを育てるか」の迷いを残す
- 位置: 全キュー・B-1様式スライス・B-0基盤の後（Nao_u指示「全てが終わった後」）。前提のMirマップ設計データはこの4市場表を骨格に作る
- 山間部市場は「食料全輸入の町」としてゲーム後半の試験（Caesar3の鉱山シナリオ型）。峠道の開通が前提の立地にする
