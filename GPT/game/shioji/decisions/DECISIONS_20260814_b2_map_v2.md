# 決定ログ 2026-08-14 — B-2マップv2の要件（Nao_u指示・v1レビュー）

**状態**: 凍結
**Nao_u原文**: 「母港の近くは小規模な漁場と木があるが、3年くらいで採り尽くす。農地の適地も少ないので人口を150人くらいしか支えられない感じ。北の山は海際を除いて大部分を減らして、広大な農地にできる盆地と、わずかな海、少しの木と少しの鉱床があって、最後はここを開発するのが目的になる感じにしたい」

**決定**:
1. **母港圏=枯渇するスターター**: 小規模な漁場と森を持つが約3年（1080日）で採り尽くす較正。畑適地も少なく**人口上限≒150人**を地形で縛る。「成長すると必ず外へ出る」の機構化
2. **北の再設計=終盤の約束の土地**: 山塊は**海際の稜線だけ残して大部分を撤去**。内側に(a)中央盆地を超える**広大な畑適地** (b)**わずかな海**（稜線を切った北の潟。将来の海路・漁の口）(c)少しの森 (d)少しの鉱床。ゲームの最終目標=北の開発
3. **玉突き（Mir設計判断・要Nao_u確認）**: 4番目の初期市場「山間鉱山」は北から**西の山地**へ移設（v1の候補7を主鉱山に昇格・峠ロックは維持）。北の鉱床は小規模のまま残す
4. 距離の階段は維持しつつ、北の大盆地は最遠帯（4日超）に置く
