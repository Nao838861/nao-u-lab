# 決定ログ 2026-08-15 — 森の復活を当面ゼロに（Nao_u裁定・同日の枯渇較正裁定を上書き）

**状態**: 凍結
**Nao_u原文**: 「木はもっと早く枯れても良い。復活が早過ぎる。基本復活なしでスタートして、ゲームが完成したところで考える。将来的には、ゼロになっても一定期間復活せず、生え変わるまで何年もかかるくらいが良い。枯渇したら新しい木を切って、島全体で見たら詰まない程度に復活するイメージ」

**決定**:
1. **当面、森の復活は完全にゼロ**: WOOD_R=0（日次回復なし）・禿げタイルへの再播種なし。伐った森は戻らない。マップに描かれた森が島の木材の全量であり、「枯渇したら次の森へ道を伸ばす」が遊びになる
2. 同日の較正裁定（DECISIONS_20260815_port_forest_depletion）の「3軒で3年」目標と副作用ガード（0軒なら減らない）は本裁定で単純化される: 復活ゼロなら **母港北東の小森(53タイル=7,950荷)は木こり3軒で自然に約1〜1.3年、1軒なら約3年で枯渇**（伐採能力の算術のまま）。受け入れは「3軒常勤で500日以内に全タイルbald」「木こり0軒の森は不変(自明)」へ差し替え
3. **将来枠（ゲーム完成後に設計）**: ゼロになった森は長期間復活せず、生え変わりに数年〜。島全体では「詰まない程度」のゆっくりした循環。実装は今しない——構想として棄却台帳でなくここに保存
4. 実装メモ: regenerateForest の成長・再播種を無効化（薄化予告の仕組みと木段階の絵は残す）。段14系の再生テストは新仕様に更新。マップ側の森の総量が島の寿命を決めるため、B-2の森配置は「枯渇したら次へ」の動線（圏間の森の帯）を意識して維持
