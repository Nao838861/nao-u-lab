# 決定ログ 2026-08-15 — 母港の森の分離とv1.3・枯渇較正の数値目標（Nao_u指示）

**状態**: 凍結
**Nao_u原文**: 「港に森が隣接しているのが良くないのと、森が大き過ぎる。いまの森を撤去して平原にして、いまの森の右上にいまの森の規模の1/3くらいのすぐ枯れる小さな森を作って欲しい。また、森の木が全然減らないので、いまの森の1/3の規模の森は、木こり三件で3年で完全に枯渇するように、どんどん木が減るようにして欲しい」

**マップ(v1.3・Mir実施済み)**: 港隣接の森2つを撤去し平原へ。北東(115,183)に約1/3規模の小森を新設——実測**53タイル=7,950荷(WOOD0=150)**。港15タイル圏の森禁止規則は小森だけを例外に維持。

**枯渇較正(GPT実施)**: 受け入れ基準を数値で固定する——
1. **この小森(53タイル級)+木こり3軒常勤 → 1080日(3年)以内に全タイルがbald(完全枯渇)**
2. 検証は市場の状態と独立に(在庫過剰の生産停止で伐採が止まると較正が測れない。ヘッドレスでは丸太の消費先を確保するか停止を無効化して伐採能力そのものを測る)
3. 概算の指摘: 現行WOOD_R=0.25/日は53タイルが部分回復し続けると3年で約14,000荷再生し、3軒の伐採能力(約21,000荷)と拮抗して枯れない。**WOOD_R・再播種条件(隣接30%・6%/30日)・seedFloor(15%)のどれかを大きく削る必要がある**。手段はGPTの較正に委ねるが、副作用(全島の森が数年で消える)を防ぐため「木こり0軒の森は8年帯で減らない」も同時にassertすること
4. 「どんどん減る」の見た目は実装済みの木段階(深/薄/疎+切り株)が担う——数値が動けば絵は付いてくる
