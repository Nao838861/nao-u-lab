## この文書の使い方(GPTの弱点への処方箋)
Nao_uの診断: 「GPTは詳細を1ステップずつ積み重ねようとして、**大局的な進捗がゼロに減衰していく**傾向がある」。
本書はその対策として設計されている:
1. **全40段が最初から見えている**。今どこにいるか(N/40)を毎セッションのdesign_log冒頭に書く
2. 各段に「**大局への寄与**」を1行で明記——この段がゴール(E-Stable+鉄チェーン)の何を進めるか
3. **段の完了=完了条件のテストが通ること**。磨き込み・リファクタ・見た目は完了条件に含まれない=やらない
4. **計画外の段を挿入したくなったら、実装せずに本書へ「提案段」として追記して止まる**(次セッションのNao_u/Claude確認へ)
5. 1セッションで2〜4段進むのが目安。1段も進まないセッションが2回続いたら、その段を分割してよい(分割は記録)

各段の2行目は補足: **参照**=その段で読む箇所(§=ENGINE_SPEC / 検索キー=flow_island engine.jsの目印) / **罠**=`../v003/econ_pitfalls.md`の該当番号(着手前に読む) / **完了**=この段を閉じるテスト。

ゴール = ENGINE_SPEC.md §7(E-Stable 20年+移植監査25/28相当+鉄E-Fe+物理不変条件)。
