# 潮路の島 — SHIOJI v001

既存実装を流用せず、GPT/Codex 側でゼロから設計・実装した港町経済ゲームの製品縦切りです。固定マップ上に区画と道を置き、住民の自律売買、実在貨物の輸送、二市場を往復する商人を育て、約15分相当で島の独立を目指します。

## 起動

追加パッケージは不要です。

```bash
cd game/shioji/v001
npm run serve
```

ブラウザで `http://localhost:8420/` を開きます。`?seed=29` のように付けると同じ条件を再現できます。

## 最初の遊び方

1. 「新しい島をひらく」を押す。
2. 黄色い肥沃地に畑区画を置く。
3. 必要なら市場から畑の隣まで道を引く。
4. `Space` または上部の再生ボタンで時間を動かす。
5. 船の日に次の契約を選び、食・材・商の三章印を灯す。
6. 港の帆印が光ったら、独立を申請する。

住民の職、売値、買値、運搬先、商人の荷は直接指定しません。プレイヤーが作るのは「命令」ではなく、流れが生まれる地形です。

## 操作

- クリック / タップ: 区画を置く、建物を選ぶ
- ドラッグ: 道を引く、道具未選択時は地図を移動
- ホイール: 拡大・縮小
- `Space`: 再生・一時停止
- `Esc`: 建設計画を解除。船便の必須選択は閉じない
- `1`〜`9`: 建設カード選択
- `+` / `-`: 速度変更

モバイルでは横スクロールできる下部建設ドックと、大きな再生ボタンを使います。

## 実装した製品要素

- 三章構成と明示的な独立エンディング
- 穀物、魚、丸太、材木、道具の保存則つき経済
- 売り注文、買い注文、予約貨物、代金エスクロー
- 道外を歩ける住民と、連続道路だけを使う荷馬車
- 自資金・自在庫・最終観測価格を持つ商家AI
- 余剰を買い不足時に戻す共同蔵
- 船契約、新世帯、食卓安定、緊急信用
- 自動保存、再開、seed再現
- Canvas描画、WebAudio、デスクトップ / モバイルUI
- 実貨物だけを描く状態完全な輸送表現

## 構成

- `src/world.js`: 描画から独立した日次経済エンジン
- `src/pathfinding.js`: 徒歩・荷馬車経路
- `src/render.js`: 地形、建物、船、貨物、荷馬車、演出
- `src/main.js`: 入力、UI、保存、章進行
- `product_spec.md`: 根源仕様と合格条件
- `design_cycle_1.md`〜`3.md`: 実装前の設計サイクル
- `design_log.md`: 制作判断と検証記録
- `tests/run.mjs`: 保存則、方針比較、セーブ復元
- `tests/browser_smoke.mjs`: Chromeでタイトルから独立まで実操作

## テスト

```bash
npm test
```

決定論テストは3 seedのbalanced方針、道路なし、港依存、輸出偏重、保存復元、自己売買禁止、荷馬車経路、共同蔵、緊急信用を検証します。

ブラウザテストは、ChromeをDevToolsポート `9224` で起動し、サーバーを立てた状態で実行します。

```bash
npm run test:browser
```

画面証跡は [`tests/artifacts/`](tests/artifacts/) にあります。

## v001で意図的に残した範囲

- 建設は外部建設キットの定額契約。国産材による建設費置換は次版候補。
- 道路は新設のみ。完成道路の撤去と直前アンドゥは次版候補。
- 共同蔵は市場バッファまで。品目別の手動備蓄目標はまだ持たない。
- 独立後は自由継続できるが、第二シナリオや実績は未実装。

これらは遊びの主経路を壊さず追加できる要素として切り分け、v001の流通・商人・独立の縦切りを優先しました。
