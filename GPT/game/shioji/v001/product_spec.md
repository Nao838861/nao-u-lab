# 潮路の島 v001 製品縦切り仕様

## 一文

船が戻るまでに島の流れを一本整え、住民と商人が自分の判断で動き出すのを見届ける、10〜20分の港町経済ゲーム。

## プレイヤーの役割

プレイヤーは勅許会社の島支配人。住民へ直接仕事や経路を命じない。決めるのは以下だけ。

- どこを生産・商業区画として開くか
- 道、市場、蔵へいつ投資するか
- 船が提示する二つの契約のどちらを受けるか
- 危機時に本土信用を使うか
- 条件達成後に独立を申請するか

## 中心ループ

1. 次の船契約と島の最大の詰まりを見る。
2. 区画または道を一つ計画する。
3. 住民の生産・売買・運搬を観察する。
4. 船の日に実在貨物を積み、契約結果を得る。
5. 新世帯と新しい投資手段を受け入れる。
6. 二市場を結ぶ商人の荷馬車を育てる。
7. 三章印を灯し、独立を申請する。

## 代表プレイカーブ

### 0〜30秒: 第一視界

- 港、市場、魚屋、二世帯が通常ルールで小さく動いている。
- 船が沖に見え、上部に「初便まで44日」。
- 肥沃地が二箇所見え、秘書が「食卓をもう一本」と一文だけ話す。
- 畑カードが発光する。配置すると建設隊が動き、食の流れが増える。

### 30秒〜3分: 第一章「食卓」

- 食料契約を達成し、最初の章印を得る。
- 道を引くと運搬日数が減り、市場棚が満ちる。
- 近場の小畑か、遠い大農地かを選ぶ。

### 3〜7分: 第二章「森への道」

- 森、木こり、製材所、蔵が開く。
- 食料契約か材木契約の二択。
- 遠い森は市場圏と道を作らないと商流へ参加できない。
- v001では材木契約が第三章の建設資金を生む。国産材による建設費置換は次版候補。

### 7〜12分: 第三章「二つの市」

- 第二市場と商家が開く。
- 港市場と森市場に価格差が生まれる。
- 商家が最後に見た価格を元に荷馬車で裁定する。
- 荷馬車が往復すると島内商い章印が灯る。

### 12〜20分: 独立

- 三章印、食卓安定30日、島内取引比率55%以上を満たす。
- 港の会社旗が独立申請旗へ変わる。
- 申請すると船、住民、荷車が港へ集まり、独立演出。
- 終了後は同じ島を自由継続できる。

## 品目と役割

| 系統 | 品目 | 役割 |
|---|---|---|
| 食 | 穀物 | 安価、保存可能、基礎食 |
| 食 | 魚 | 高価、翌日劣化、即時食 |
| 材 | 丸太 | 森で生産、製材入力 |
| 材 | 材木 | 建設と道具の入力 |
| 具 | 道具 | 一次産業の生産性を最大2倍まで高める消耗品 |

## 区画

| 区画 | 地形 | 入力 | 出力/機能 |
|---|---|---|---|
| 畑 | 肥沃地推奨 | 労働、任意の道具 | 穀物 |
| 魚屋 | 海岸 | 労働 | 魚 |
| 木こり | 森隣接 | 労働、任意の道具 | 丸太 |
| 製材所 | 陸地 | 丸太 | 材木 |
| 道具工房 | 陸地 | 材木 | 道具 |
| 市場 | 道沿い | なし | 市場圏、注文帳、価格 |
| 蔵 | 市場圏 | 組合資金 | 余剰購入、最低備蓄、不足時の再販売 |
| 商家 | 市場隣接 | 資金、荷車 | 市場間裁定 |

## 経済原則

### 価格

- 売り手は原価未満では売らない。
- 買い手は使用価値を超えて買わない。
- 重なる注文を価格優先・同値時seed順で成約する。
- エージェントは価格信念を持たず、毎日注文を作り直す。
- 市場表示は直近成約値と当日取引量。成約なしは前回値と明示する。

### 取引と輸送

- 成約時に財を `reservedCargo`、代金を `escrow` へ移す。
- 貨物は売り手→市場→買い手の到達可能経路を進む。
- 到着時に財と代金の所有権を同時移転する。
- 同一路線の小口は描画上の一隊に束ねるが、会計上の所有権は維持する。
- 買い手と売り手が同一なら成約しない。

### 商人

- v001は統合行商から開始する。
- 商家世帯は自分の資金、自分の荷車、自分の在庫を持つ。
- 自市場の現在価格と、最後に訪問した他市場価格だけを知る。
- 期待利益から仕入、生活費、往復日数を引き、正なら自律出発する。
- プレイヤーは経路も品目も指定しない。

### 会社

- 港で外部との境界取引だけを行う。
- 島内一般物流を自動代行しない。
- 建設契約、船契約、緊急信用をエスクローで記帳する。
- 市場取引の4%口銭を得る。

## 建設

- 配置時に会社資金を建設契約エスクローへ移す。
- v001は船から届く建設キットの定額契約として扱い、内部財へ架空の建築需要を発生させない。
- 国産材を建設費の同一総額内で優先購入する仕組みは、二重課金を避けた上で次版に検討する。
- 3〜6日で完成し、建設隊と資材が地図上を移動する。
- 完成しても世帯は即時出現せず、船の日に空き区画へ入る。

## 道

- ポインタのドラッグで直交経路を一筆計画する。
- プレビューは有効・無効と直交経路を色と形で示し、単価は建設カードへ常時表示する。
- 徒歩は道外も可能だが遅い。荷馬車は連続した道だけを使う。
- v001は新設だけを扱う。配置直後アンドゥ、完成道路の撤去、孤立警告は次版候補。

## UI

- 地図を常に画面の主役にし、固定右サイドパネルを作らない。
- 上部HUDは資金、人口、食料日数、船までの日数、速度だけ。
- 下部は建設カード。未解禁カードは理由だけ見せる。
- 建物選択時は下部ドロワーに `入力→仕事→出力→行先` を表示する。
- 港の三枚の旗章が契約、章目標、独立申請を兼ねる。
- 色だけに依存せず、穀袋、魚、丸太、板、歯車の形を併用する。

## 入力

- ポインタ: 選択、建設、道路ドラッグ、地図移動。
- `Space`: 開始、一時停止、結果画面から続行。
- `Esc`: 現在の計画をキャンセル。
- `1`〜`9`: 建設カード。
- `+`/`-`: 速度変更。
- モバイルは44px以上の建設カードと中央下の再生・停止を使う。

## 演出と音

- 実貨物だけを運搬として描く。架空の繁栄貨物を禁止する。
- 波、鳥、煙、旗、木の揺れは非会計の環境動作として使う。
- 残り10日、接岸、契約成功、章印、飢餓、独立で異なる音と画面反応を持つ。
- 音がなくても帆、鐘の輪、旗色で同じ状態が分かる。
- タイトルには港と道の期待を一枚で伝える専用イラストを使う。

## 保存

- 建設・契約などの主要操作時と5日ごとにlocalStorageへ自動保存。
- schema version必須。
- タイトル画面に「新しい島」「続きから」。
- テスト用seed指定はURLクエリで可能にする。

## 合格条件

### 食卓安定の定義

- その日に食べられた世帯が全世帯の75%以上。
- 世帯ごとの累積空腹の平均が2未満。
- 両方を満たした日が30日連続すると独立条件の「食卓安定」が成立する。
- 一軒の配達が一日遅れただけで全島の30日を無効にしない一方、複数世帯の慢性的飢餓は通さない。

### 不変条件

- すべての財は、初期量+生産+外部流入-消費-腐敗-外部流出と一致する。
- 貨幣は、島内主体+エスクロー+会社+外部境界台帳で一致する。
- 一つの財に同時に二人の所有者がいない。
- 自己売買が成立しない。
- 到達不能経路へ貨物を生成しない。

### 方針比較

- `balanced`: 三章を進み、独立可能になる。
- `noRoad`: 遠隔材木契約と第三章を達成できない。
- `portOnly`: 第一章は進めるが、島内商い章印を得られない。
- `exportAll`: 契約収入は得ても生活章印を維持できず、独立できない。

### 視覚・操作

- 1440×900と390×844で主要操作が切れない。
- 最初の建設、第一便結果、契約選択、独立をブラウザで実操作する。
- コンソールエラー0。
- 主要状態のスクリーンショットを `tests/artifacts/` に残す。
