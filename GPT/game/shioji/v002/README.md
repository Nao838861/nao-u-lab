# CHARTER ISLE — 潮路の島 v002 / road network v0.25

Claude側で実装検証された「流通の島」v0.24の経済コアと序盤バランスを土台に、GPT側で表示・操作・船便・ナラティブをゼロベース再構成したブラウザゲーム。

## 遊ぶ

- 公開URL: <https://nao838861.github.io/nao-u-lab/GPT/game/shioji/>
- v002固定URL: <https://nao838861.github.io/nao-u-lab/GPT/game/shioji/v002/>

サーバー処理、ビルド、インストールは不要。GitHub PagesからPC・スマホのブラウザで直接遊べる。

## この版で実装した核

- 固定方位の2:1クォータービュー
- 森、水際、岩場を使う地形拘束の生産
- 魚、野菜、麦、丸太、木製品、炭、塩の序盤経済
- 住民の名前、家族、所持金、食料、現在行動
- 市場からの連続性を持つ8方向道路網と、道路に接した区画だけが育つ町
- 完成道路だけを往復する、徒歩の4倍容量の積荷付き手荷車
- 生産地、市場、商館に積み上がる品目別の現物在庫
- 第一便の出港、15日ごとの入港、荷役、再出港
- 顔付き女性秘書エレナ・ヴァンスと本国書状
- 輸入・輸出・口銭・支度金を符号付きで示す会社帳簿
- PCと390×844スマホのレスポンシブ操作

## 経済コアの継承範囲

`src/engine.js`はClaude側 `game/flow_island/engine.js` v0.24を基礎にしている。次の合意・較正済み要素を巻き戻していない。

- 原価の床 / 使用価値の天井 / 記憶なし試行
- 一次産業の生産性倍率キャップ2.0
- 地形拘束と資源枯渇
- 木こり→丸太→木工・炭焼の連鎖
- 支度金、口銭、本国の買い叩き、懲罰輸入
- 餓死、出生、大家族から空き区画への移住
- 住民へ職業や経路を直接命令しない原則
- 貨幣保存則の毎日検査

## 操作

- 盤面ドラッグ: カメラ移動
- ホイール / ピンチ: ズーム
- 建築ボタン→盤面タップ: 区画指定
- 道路ボタン→始点から終点へドラッグ、または2タップ: 8方向へ吸着して道普請を計画
- 道路撤去ボタン→線をドラッグ、または2タップ: 孤立影響を確認して撤去（返金なし）
- 盤面の家族、道路、市場、港をタップ: 接道・運搬量・交通量などの詳細表示
- スペース: 一時停止
- 1 / 2 / 3: 時間速度

## 範囲

v002は最終製品の第一章相当。既設道沿いの食料街から雑木林へ道を延ばし、木こりの丸太を最初の手荷車で市場へ届け、食料自給と材木連鎖、本国注文の入口まで遊べる。第二市場、鉄の完全な島内生産、商人の資産成長、独立エンディングは経済コアと設計上の接続先を残しているが、盤面操作としては次版の範囲。
