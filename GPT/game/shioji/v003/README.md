# CHARTER ISLE — 潮路の島 v003

数字の裏で処理されていた物流を、島に積まれる荷、道を走る荷車、港で荷役する船として経済の正本へ戻したブラウザゲーム。

## 遊ぶ

- 公開URL: <https://nao838861.github.io/nao-u-lab/GPT/game/shioji/>
- v003固定URL: <https://nao838861.github.io/nao-u-lab/GPT/game/shioji/v003/>

サーバー処理、ビルド、インストールは不要。GitHub PagesからPC・スマホのブラウザで直接遊べる。

## 第一章で遊べること

1. 町外れから雑木林へ8方向の道を通す。
2. 3×3の木こり仕事場を、森かつ完成道路沿いへ置く。
3. 出荷場へ丸太が平積みされるのを見る。
4. 3×3の木工房を道沿いへ置く。
5. 丸太を積んだ荷車を任意で追跡する。
6. 木工房で木製品を作り、等級0の野外作業場から等級1の掘っ立て小屋へ増築する。
7. 木製品を港の輸出ヤードへ運び、定期船が実際の山から積むところを見る。
8. 輸出収入と輸入支出を別符号の会社帳簿で確かめる。
9. 第一章後、中継倉庫と上位等級を使って流量を増やす。

## 見える物流

- 入荷棚: 空なら原料不足。
- 出荷場: 満杯なら搬出停滞。
- 輸入ヤード: 本国から島へ降ろされた荷。
- 輸出ヤード: 島から本国へ積む荷。
- 工事置き場: 建物等級を恒久的に上げる資材。

通常画面では空棚、山の5段階、作業者、煙、荷車、船を見る。建物を選ぶと正確な量、容量、増築条件、運搬中の量を確認できる。

## 操作

- 島をドラッグ: カメラ移動
- ホイール / ピンチ: 拡大縮小
- 道: 完成道路を始点にして終点までドラッグ、または始点・終点を2回タップ
- 建物: 建築ボタンを選び、完成道路沿いの土地をタップ
- 建物をタップ: 稼働状態、固定在庫枠、次の増築を確認
- 「荷を追う」: 通常速度で荷車を追跡し、到着後に元の場所と速度へ戻る
- 定期船表示: 任意で港を見る。通常入港ではカメラを奪わない
- スペース / 1〜4: 一時停止と時間速度

## 技術

- HTML / CSS / Canvas 2D / ES Modulesのみ
- 外部ランタイム依存とビルド工程なし
- 1440×900と390×844で実ブラウザ検証
- 荷車到着時だけ在庫移動を確定
- 港の輸出ヤード減少と輸出帳簿を同じ状態から生成
