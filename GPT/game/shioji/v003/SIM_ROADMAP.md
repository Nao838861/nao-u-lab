## 大目標(これだけは常に画面の先に置く)

> **「生産と消費のシミュレーション」**: 住民という自律エージェントの取引から価格と流通が創発し、
> 「辺境に全ての物資を流通させることが難しい」を遊ぶゲーム(Nao_u原文・2026-07-12/07-18)。
> 現在のv003は"台本の物流"。到達点は"住民が自分の都合で動いた結果として同じ物流が創発する"こと。

### 非交渉の原則(Nao_u確定・違反したら差し戻し)
1. **エージェントはバカでいい。市場(制度)がバランスを取る**——住民に賢いAI・学習・価格信念を持たせない
2. **住民への直接命令を絶対に足さない**(ルート指定・強制配転の禁止)
3. **自動の給付・湧き・テレポートの禁止**——金・物・人の増減は「プレイヤーの選択」か「明示の外部境界(本国船)」だけを通る
4. 場当たりの特例・罰則・閾値いじりの積み重ね禁止(個別症状より構造で直す)
5. ドキュメントの規範=Nao_u原文のみ(AIの補完は【案】と明示)

## ステージ構成(順序に意味がある。飛ばすと後で全部やり直しになる)

### Stage 0: 嘘発見器を先に置く(検証装置)
**なぜ先か**: flow_islandの最重要教訓。保存則assertが数十件のバグを「実装した瞬間に」検出した。後から入れると、既に入り込んだ嘘を探す作業になる。
- [ ] **貨幣保存則**: `会社資金+Σ住民財布-初期額-(本国流入-本国流出)=0` を毎日assert(1e-4超で即throw)
- [ ] **物資出納**: 財ごとに `在庫変動=生産-消費+輸入-輸出±輸送中` を検査(まず報告のみ・10%超で警告)。v003の量保存テストの拡張として実装できる
- [ ] ヘッドレス4年走行(`tests/run.mjs`拡張): シード3本で完走・保存則無違反
- **受け入れ基準**: 3シード×4年、保存則違反ゼロ。`npm test`に組み込み
- **やらないこと**: UI変更・経済ルール追加(このステージは計器だけ)

### Stage 1: 住民(世帯)が生きる
- [ ] 建物=1世帯(家族5-11人・名前つき)。**財布とパントリー(手元在庫)**を持つ
- [ ] 食事: 家族人数ぶん/日をパントリーから。不足日が続くと餓死(家族が減る→2人以下で離散・廃屋)
- [ ] **採集の床**: 不足分の75%は野外採集で凌げる(金の関与なし)——即死ゲーを防ぐ生存線
- [ ] 食料職を1つ追加(漁師: 水際制約・日次産出)。木こり系は既存のまま
- **受け入れ基準**: 4年ヘッドレスで「食える村は生き、食料職を建てない村は餓死者が出る」がテストで示せる
- **やらないこと**: 取引・価格(まだ物々交換すら入れない。生産物は自家消費と平積みのみ)

### Stage 2: 市場と価格の創発(経済コアの心臓)
**flow_islandのv0.10で確立した3原理をそのまま移植する**(これが「エージェントはバカでいい」の正しい実装):
- [ ] **原理1 原価の床**: `原価 = 家族の生計費(人数×主食価格)÷日産 + 原料費(市況評価)`。原価未満では売らない。売れ残りが続けば休業
- [ ] **原理2 使用価値の天井**: 買値の上限は用途から導く(変換業=製品市況から逆算・生活財=輸入価格等)。飢餓時のみ天井解除
- [ ] **原理3 記憶なしの試行**: 売値=毎回 `原価×(1.05+乱数×1.25)` で抽選。**学習・信念・値下げ戦略を持たせない**
- [ ] 市場(既存3×3)に屋台: 世帯が余剰を持ち込み、他世帯が安い順に買う。成約価格のEMA(α=0.1)=公開市況px
- [ ] **主食価格の床=1.0**(名目の錨。信用枠等の名目定数の前提になる——外すと全部壊れる。罠図鑑#5)
- **受け入れ基準**: ①漁師と木こりが互いの産物を買って生きる ②飢えると食料価格が上がり、豊漁で下がる(需給応答のテスト) ③保存則無違反
- **やらないこと**: 会社の売買・輸出の経済化(既存の台本輸出はそのまま置いておく)

### Stage 3: チェーンの経済化と職業の成立
- [ ] 既存チェーン(丸太→木工)を市場経由に: 木工房は丸太を**市場で買う**(仕入れは小額の信用買い可・下限-30)
- [ ] 原価連鎖: 丸太市況が上がれば木製品の原価と売値も上がる(自動伝播・追加ルール不要)
- [ ] 職業監査: 全職業の年収を計測し「全職が食える」をテスト化(最良世帯の年収>閾値)
- [ ] 破綻転職: 長期困窮世帯は職を変える(候補=**全職業**・12ヶ月観測年収の重み抽選・地形制約を尊重。罠図鑑#2,#3)
- **受け入れ基準**: 4年×3シードで全職業が存続し年収>0。チェーン職が絶滅したシードでも再参入が起きる
- **やらないこと**: 新しい財・新しい職の追加(既存の財だけで経済を回す)

### Stage 4: 会社の経済(プレイヤーの金の使い道)
- [ ] **商館の買上げ**: プレイヤーが品目ごとに目標量を設定→**その日の住民の買い物が終わった後**、安い屋台から順に会社が買う(順序が重要。罠図鑑#1の逆選抜=350%過払いの実測あり)
- [ ] **蔵出し**: 会社在庫は仕入原価×1.2で市場に並ぶ(市況連動にすると飢饉の便乗値上げになる。罠図鑑#4)
- [ ] **本国注文**: 既存の定期船に載せる——「◯◯を△荷・90日以内」の注文状。達成で本国が割増を払う=外貨の入口
- [ ] **建築リズム**: 建設に支度金(会社資金から)+市場取引の口銭4%が会社収入=「良い町ほど早く次が建つ」
- **受け入れ基準**: 「一括で全部建てる」より「資金を待って順に建てる」方が飢餓が少なく人口が多い、をテスト化(flow_islandのE16)
- **やらないこと**: 補助金・自動救済(困窮者への自動給付は一切入れない——Nao_u指示「餓死させて」)

### Stage 5: 人口動態(Nao_u確定設計・2026-07-18)
- [ ] **出生**: 飢えていない家族(11人未満)に月12%で子が生まれる
- [ ] **家督相続**: 空き区画(プレイヤーが指定)を、8人以上の大家族が割れて埋める。**納屋と財布を頭数比で持参**(無からの物資湧き禁止)
- [ ] **移民は代替のみ**: 島に余剰人口が無く、かつ島が飢えていない時だけ本国船で来る
- **受け入れ基準**: 人口がプレイヤーの区画供給を経由してのみ増える。出生・相続・移民・餓死がイベントとして画面に出る
- **やらないこと**: 自動で家が湧く仕組み(罠図鑑#6)

### Stage 6: 統合と意図監査スイート
- [ ] flow_islandの監査思想を移植: 「実装したか」でなく**「設計意図どおり動いているか」**を期待値でテスト(例: 麦自給が立てば輸入が消える/冬の魚価>夏/全職業の存続/漸進建築が勝つ/飢餓が年々減る)
- [ ] 受け入れ帯を数値で固定(監査N/M・飢餓年間帯・人口帯)——以後の変更はこの帯を割らないこと
- [ ] ここまで来たら、v003の可視物流とflow_islandの経済が**一つのゲーム**になっている。以降の拡張(複数市場・行商・鉄チェーン)は `Claude/projects/production_consumption_sim/design/v2_implementation_spec.md` の裁可済み項目に従う
