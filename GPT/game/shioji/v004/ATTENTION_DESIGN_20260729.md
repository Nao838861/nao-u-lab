# 注意と時間の設計憲法（2026-07-28〜29 Nao_u対話の結論。表示・書状・時間密度の正本）

Nao_u診断「早送りしたくなったら負けだが、今は完全に負けている」「変動が多くどこに意味があるか掴めない」「家族名は理解を妨げるノイズ」「書状は情報量がなく読みたくないのに多い」への回答として合意した原則。UI・書状・イベントを触る前に必ず読む。

## 1. 時間密度（等速を濃くする=本線）
- 入れ子リズム「1日1手・3日1結果・30日1節目・1年1物語」。等速1日に〈今日の一手(意思決定1)・今日の見どころ(可視イベント2〜3)・進行中の賭け(1以上)〉が常在することを密度予算とする。判断のない日を作らない
- 密度は変動を増やして稼がない。**境界の設計**で調整する(下記2)
- 現状の1日に各要素が何個あるかの実測から着手し、ギャップ順に装置を足す

## 2. 変動と意味 — 境界跨ぎの原則
- 変動は〈ゆらぎ(平均回帰・沈黙させる)/傾向(向きだけ示す)/事件(境界を跨いだ瞬間)〉の三分類。**意味は境界跨ぎにだけ宿る**(不足へ転落・原価割れ・冬必要量割れ・便の赤字転落)
- 「だから何?」に答えない変動は表示しない。動く数字には境界までの距離を添える(「あと4日で不足」)
- 三分類は熟練の階段でもある: 初心者は事件を受け取り、中級者は傾向から予期し、上級者はゆらぎを読む。ゆらぎは隠すが、望む者には掘れる場所(グラフの奥)に残す
- 「今日の一手」は境界跨ぎから生成する。ゆらぎで忙しく見せるのは偽の密度

## 3. 意味の源泉と個の扱い
- 本線は二本: **境界**と**自分の痕跡**(自分が置いた・値付けた・送ったものに関わる変動は他人事の10倍重い。「あなたの木工房の丸太が尽きかける」は事件、「どこかの丸太が減った」はノイズ)
- 固有名詞は意味の源泉ではなく**関係の器**。無差別な名前表示はノイズ(Nao_u実証済み)。個は**昇格制**: 境界跨ぎ×自分の痕跡と交差した時だけ統計から固有名詞へ昇格(最初の入植者・支援で生き延びた家・危機札の家・相続)。昇格に儀式(一言で関係開始を宣言)、降格に余韻(一言で閉じる)
- 関係の予算は常時2〜4枠。三層を混ぜない: 「島は大勢で動き、画面は少数を語り、あなたは数人と関係する」
- ゲームは編集者である。表示設計=何を黙らせるかの決定の集積。沈黙は最も高価な演出資源

## 4. 注意の経済学
- プレイヤーの注意は通貨、表示は請求書。意味の薄い請求を重ねるとプレイヤーは全無視を学習する(=「適当に置く」「早送り」の正体は注意の破産)
- 請求を絞り、支払いに見合う意味を返す。情報を増やすことは仕事ではない

## 5. 書状とメディアの階層
- 書状の成立条件(全て満たす時のみ発行): **新情報**(画面から読めない)×**帰結**(行動が変わりうる)×**希少**(月数通)
- メディアの格: ①常設計器(押し付けない)②一言(流れて消える・自動既読)③書状(開封を要求)④儀式(時を止める)。**情報が要求してよい注意量と器の格を一致させる**。②で足りる中身を③で送らない
- 形式は約束: 書状の価値は個々の中身でなく形式の信用残高で決まる。乱発はインフレで、一度の駄文が全通スキップを招く
- 書状は情報でなく**差出人の判断**を運ぶ(エレナが何を重要と考え何を勧めるか)。品質は差出人の見識の一貫性に還元される
- 執行: 既存書状を三分し、契約・危機・決算だけ書状に残す(HANDOFF既存正典の執行)。状況報告は一言へ降格、残りは削除。月1の「読まないと損する一通」(期限・選択つき)で形式の信用を回復する

## 6. 検証
- 面白さの計器:「早送り中に自発的に等速へ戻した回数」。装置追加の効果はこの指標と体験判定(2便目を欲でやったか等)で測る。構造論で面白さを断定しない
