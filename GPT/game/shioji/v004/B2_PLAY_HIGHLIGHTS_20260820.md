# 潮路の島 B2版 — 起動と見どころ

## 起動

リポジトリの`GPT`ディレクトリで次を実行する。

```bash
python3 -m http.server 8420
```

ブラウザで `http://localhost:8420/game/shioji/v004/` を開く。開始画面の「エレナと開拓する」は全章教程、「自由に開拓する」は256×256島の自由プレイである。古いJSONは「保存」から読み込めば、旧96×64／48×40のまま続けられる。

## 最初に確かめること

1. 母港の周囲を見て、茶色い畝の肥沃地、湾内の魚影、北東の小森を探す。農場4種は肥沃地にしか置けず、山には建物も道路も置けない。
2. 母港だけで閉じず、day120前後までを目安に中央盆地への道・市場・麦の路線を作る。初期資源は枯渇するスターターで、森は自然回復しない。
3. 漁港へ麦を送り、魚を帰り荷にする。教程の最初の一便だけは、選んだ麦8荷を母港の生活留保より優先して送る。通常路線は積出地の当座分を守る。
4. 鉱区や盆地の施設をLv3以上へ育てる。低Lv期の赤字路線は開発費になりうるが、高Lvの余剰が母港へ届けば、港の「島の余剰を輸出する」で本土売上へ変えられる。
5. 食料HUDの生産収支と輸入合図を見る。通常輸入は裏で自動発生しない。必要なら会社帳場から品目と数量を自分で発注する。

## 現在のバランスの読み方

母港だけを無操作で3年置くと人口は56人から17人へ減った。序盤の余りと不足を消した安定箱庭ではなく、有限資源と地力差を読み、市場間貿易へ出るゲームである。のんびり母港だけを育てたい遊び方にはまだ厳しい。逆に、漁港・盆地・鉱区を結ぶ5年戦略は3通りとも4市場を維持し、Lv3以上の生産者と港湾輸出まで到達した。

見たい物語は「赤字路線をいつ育成投資として引き、どの産地を先にLvアップし、二便目を欲で送るか」である。会社全体では、高効率化した島内余剰を明示輸出して開発費を回収する。
