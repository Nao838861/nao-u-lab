# 首都圏表現・名称・発展図 設計案（2026-07-24）

## 魚粉屋の名称（裁可待ち）

現行の魚粉は食料ではなく、魚を加工して畑の肥料へ渡す中間材である。「干物小屋」は食料加工に見え、実際の流れとずれる。推奨名は **魚肥小屋**。短く一般性を優先するなら現行の「魚粉屋」を維持する。

裁可があるまで表示名とgoods名は変更しない。

## 首都・本国側の到着演出

島から出た船は、注文の残りが0荷になった時だけ完遂扱いにする。将来の首都演出は次の順で足す。

1. 島の港で最終荷を積む。
2. 船が画面外へ出る。
3. 取引カードを「航海中」にする。
4. 短い時間後、首都港の一枚絵または小窓で荷下ろしを見せる。
5. 最終決済と完遂書状を出す。

首都の完全なシミュレーションは作らず、島の物流結果を受け取る視覚的な終点とする。到着前に売上を立てないこと、失効した残荷を首都到着として描かないことを不変条件にする。

## 発展図の原則

- 研究・ロック・恒久補正は入れない。
- 既存の産業連鎖と、将来建設予定の場所を一画面で理解させる。
- 各ノードは「何から」「何を作る」「どこへ届く」だけを表示する。
- 将来ノードは破線と「構想」で区別し、押しても建設や支払は起こさない。

## 発展図の画面構成

ラン3では、スマホでも枝単位で読める四本の横道として実装した。

1. 港と流通: 港 → 市場 → 倉庫
2. 食と暮らし: 漁師 → 野菜畑 → 麦畑 → 保存食工房
3. 森と手仕事: 木こり → 木工房 → 荷車工房 → 造船所
4. 地と火: 採石場 → 炭焼き小屋 → 鉱山開発 → 鉄製荷車

現存施設は緑、いま建てられる未建設施設は生成り、将来構想は灰色破線で表す。スマホは各枝を横に送って読める。ノード内にボタンを置かず、建設・支払い・研究ロックを一切発生させない。
