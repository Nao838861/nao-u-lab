# v004.33.0 食料到達・セーブ対応報告

## 結論

塩はもともと食事処理へ入っていなかった。食料に見えた原因は、塩を含む生活用品を「家の食料庫」に混載表示していたためだった。表示を食料庫と生活用品へ分けた。

加工施設の食料0は再現した。加工原料を食料より先に買い、原料だけ掛け買いできる順序が一因だったため、食料6日未満では食料を先に積むよう修正した。加えて、帰宅前の荷と当日食べ切った食料が0表示から見分けられなかったため、各家へ到達状態と理由を出した。

## 変更内容

- 塩・木炭・木製品などを「家の生活用品」、魚・麦・保存食などを「家の食料庫」へ分離
- 食料6日未満では、食料を加工原料より先に購入
- 買い順から漏れていた漬物を追加
- 30tickを超える有限経路でも市場へ複数日で往復
- 食料緊急便は市場に買える品がある時だけ、最低2日ぶんを運べる人数を目安にする
- 家ごとに次を表示
  - 入居の普請中
  - 市場へ買い出し中
  - 食料を持ち帰り中
  - 今日買ったが一日分に届かず食べ切った
  - 財布不足
  - 値段不一致
  - 運搬枠不足
  - 市場棚が空
  - 会社倉庫にはあるが市場へ未搬入
  - 次の朝便待ち
- 食料0.5日未満だけ、盤面へ品目アイコン付きの静かな警告
- 段階低下間際へ、不足している暮らしの品目アイコンを最大2個表示
- Lvアップの菱形3個を、連続ゲージ、経過日、残り日数へ戻した
- 上部「保存」へ端末保存、JSON書き出し、JSON読み込みを追加
- 開始画面へ「つづきから」「保存ファイルを読み込む」を追加
- 5日ごとに端末へ自動保存
- 完全snapshot、乱数状態、入力journal、チュートリアル状態、統計180日を同時保存

## 再現計測

修正前のseed11・720日では、炭焼き・塩田・木工に「食料0.1日未満、財布あり、市場食料あり」が631件あった。

修正後240日の同じ見かけ124件は、普請中2、当日に購入して食べ切った98、市場在庫なし13、財布不足8、一部購入3だった。購入していない状態だけでなく、購入後の即日消費と移動中を画面で区別できるようになった。
