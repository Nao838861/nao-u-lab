## 開始方法

最初に次の3つから選ぶ。

- **チュートリアルから**: 「ゼロから開拓」と同じ未開拓島へ、実際の島況に沿う書状と目標だけを重ねて始める。現在は第一章の初輸出、木こりの道路効果、第二章の食料自給、第三章の季節在庫と蔵出し、第四章の注文採算判断まで実装済み。
- **ゼロから開拓**: 港だけがある島。人口・市場・蔵・職建物・道路はゼロで、市場と蔵から自分で配置する。
- **テスト配置で観察**: 従来どおり、人口・道路・産業が動く安定監査済みの都市から始まる。

プレイ中も観測パネルの「最初から」で開始方法を選び直せる。

チュートリアルの書状を読んでいる間は時間が止まり、閉じると元の速度へ戻る。「案内を終える」を選ぶか現在の第四章を完了すると、その島を一切作り直さず自由プレイへ移る。

## 遊び方

- 地図はドラッグ／スワイプで移動し、ホイール／ピンチで拡大縮小する。
- 上部のボタンで一時停止・通常・四倍・一日毎秒を切り替える。「1日進める」は停止中にも使える。
- 下部から市場・蔵・職建物の配置・撤去、道路の敷設・撤去を選ぶ。建物は入口にしたい区画を指定する。港だけは固定施設。
- 荷車を押すと、荷の中身・出所・行き先・経路を追跡できる。
- 「会社」で買上げ目標、蔵出し、本国注文、台帳を操作し、「出来事」で島のイベントを確認する。

獣道、実寸建物、文化Lv、在庫の山、市場の屋台、徒歩家族、荷車、船の接岸と一荷ずつの荷役は、すべてエンジンのsnapshotと観測イベントから描画している。
