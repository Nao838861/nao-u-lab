## 開始方法

最初に次の3つから選ぶ。

- **チュートリアルから**: 「ゼロから開拓」と同じ未開拓島へ、実際の島況に沿う書状と目標だけを重ねて始める。第一章の初輸出、木こりの道路効果、第二章の食料自給、第三章の季節在庫と蔵出し、第四章の注文採算判断、第五章の変換産業と暮らしを経て、終章の卒業書状まで遊べる。
- **ゼロから開拓**: 港だけがある島。人口・市場・蔵・職建物・道路はゼロで、市場と蔵から自分で配置する。
- **テスト配置で観察**: 人口・道路・産業が動く安定監査済みの「見本の町」から始まる。

プレイ中も観測パネルの「最初から」で開始方法を選び直せる。

チュートリアルの書状を読んでいる間は時間が止まり、閉じると元の速度へ戻る。「案内を終える」を選ぶといつでも、また終章の卒業書状を受け取ると、その島を一切作り直さず自由プレイへ移る。卒業書状では町の人口・職・食料輸入・会社収支を安定監査の参照帯と並記するが、帯は合否判定ではない。

## 遊び方

- 地図はドラッグ／スワイプで移動し、ホイール／ピンチで拡大縮小する。
- PCではWASDでも地図を連続移動でき、斜め移動も同じ速さになる。Spaceは停止／直前速度への復帰、1〜4は速度変更、Escは開いている書状・sheet・工具・選択を順に解除する。入力欄やmodifier操作中は発火しない。
- 上部のボタンで一時停止・通常・四倍・一日毎秒を切り替える。「1日進める」は停止中にも使える。
- 下部の整備・流通・食料・採取・加工から、名称・費用・実寸を見て建物を直接選ぶ。建物は入口にしたい区画を指定する。港だけは固定施設。
- チュートリアル中は目標欄の操作ボタンが、その目標で明示された工具・建物・情報欄一つだけを開く。自由プレイでは建て方を推薦しない。
- 盤面の建物を押すと、道路接続、世帯の家族・財布・空腹・暮らし、区分棚、加工の投入と産出を確認できる。「この建物を画面中央へ」で位置へ戻れる。
- 荷車を押すと、荷の中身・出所・行き先・経路を追跡できる。
- 「会社」で買上げ目標、蔵出し、本国注文、台帳を操作し、「出来事」で島のイベントを確認する。「島況」では、区分棚・世帯食料庫・屋台の現物と所在、市場相場、最近の輸入・生産・消費EMAを確認できる。
- 観測パネルのエレナは、未読書状、現在目標、最新重要イベント、操作案内の順に実データ一件を示す。欄を押すと同じ対象を開く。

獣道、実寸建物、文化Lv、在庫の山、市場の屋台、徒歩家族、荷車、船の接岸と一荷ずつの荷役は、すべてエンジンのsnapshotと観測イベントから描画している。

## 検証

通常は変更した契約だけを検証する。詳細と昇格条件は [TESTING_POLICY.md](TESTING_POLICY.md)。第一章の導線変更なら次を使う。

```bash
cd /Users/Nao_u/nao-u-lab/GPT/game/shioji/v004
npm run test:tutorial-early
npm run test:focused -- "チュートリアル段5|チュートリアル段6|チュートリアル段7"
```

engineの軽微な修正は、該当unitだけを長期workerなしで実行できる。

```bash
cd /Users/Nao_u/nao-u-lab/GPT/game/shioji/engine
npm run test:focused -- "最初の生産適格注文"
```

経済定数、保存則、長期帯、複数章の契約を変えた時、または公開前の総点検だけ全件へ上げる。

```bash

npm test
```
