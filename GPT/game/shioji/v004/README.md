## 開始方法

最初に次の3つから選ぶ。

- **エレナと開拓する**: 「自分でゼロから開拓」と同じ未開拓島へ、実際の島況に沿う書状と目標だけを重ねて始める。建てる・つなぐ・設定するなど自分で確実に完了できる操作だけが進行の背骨で、季節の谷、相場変化、長期存続など発生時期が読めない教材は進行を止めないエレナの助言・報告として届く。
- **自分でゼロから開拓**: 港だけがある島。人口・市場・蔵・職建物・道路はゼロで、市場と蔵から自分で配置する。
- **見本の町を眺める**: 人口・道路・産業が動く安定監査済みの町から始まる。

プレイ中も上部メニューの「最初から」で開始方法を選び直せる。

チュートリアルの書状を読んでいる間は時間が止まり、閉じると元の速度へ戻る。誤操作から復帰できない常設の案内終了ボタンは置かず、終章の卒業書状を受け取ると、その島を一切作り直さず自由プレイへ移る。卒業書状では町の人口・職・食料輸入・会社収支を安定監査の参照帯と並記するが、帯は合否判定ではない。

起動中も開始画面を残し、読み込みが完了しなければ再読込ボタンを出す。公開キャッシュで新旧moduleが混ざらないよう、全ES moduleを同じbuild版のURLで読む。

## 遊び方

- 地図はドラッグ／スワイプで移動し、ホイール／ピンチで拡大縮小する。
- PCではWASDでも地図を連続移動でき、斜め移動も同じ速さになる。Spaceは停止／直前速度への復帰、1〜4は速度変更、Escは開いている書状・sheet・工具・選択を順に解除する。入力欄やmodifier操作中は発火しない。
- 上部のボタンで一時停止・通常・四倍・一日毎秒を切り替える。「1日進める」は停止中にも使える。
- 日付の下には、エンジンと同じ30日=1か月の「季節・月」を常時表示する。島況ボタンの「平穏／成長／注意／危険」は、連続空腹、直近の人口変化、会社資金をまとめた基調シグナルで、島況を開くと理由を文章とグラフで読める。
- 下部の整備・流通・食料・採取・加工から、名称・費用・実寸を見て建物を直接選ぶ。建物は入口にしたい区画を指定する。港だけは固定施設。
- チュートリアル中は、エレナ自身の言葉だけで「いま何をするか」と「なぜするか」が分かり、左上の「現在目標」は端的な作業一行と進捗を補う。その下のボタンは固定の［案内］ではなく、「道を敷く道具を選ぶ」「木こりを選ぶ」「会社を開く」のように、押した結果を表示する。目標を満たすと現在目標がいったん消え、エレナの達成発話、短いフェードの間、次の課題発話と目標欄の順に切り替わる。入植や注文を待つ目標では残り日数を示し、ボタン一回で一日毎秒へ変更できる。自由プレイでは建て方を推薦しない。
- 盤面の建物を押すと、道路接続、世帯の家族・財布・空腹・暮らし、区分棚、加工の投入と産出を確認できる。世帯の建物には、次のLvに必要な品、今日満たしたか、必要日数と現在の積み上げ、Lv低下の原因を表示する。Lv上昇時はエレナが祝い、何を何日満たした成果かを伝える。蔵では会社在庫と役割も読める。
- 最低3×3の敷地は、建屋だけで埋めず手前を作業ヤードとして空けてある。投入・産出・保管・家の食料を品目ごとの俵、木箱、丸太、鉱石として置き、12荷までは一荷ずつ、それ以上も量が増えるほど最大24個まで荷姿が増える。正確な数字は選択時の補助であり、通常は山の多寡を先に見る。
- 荷車を押すと、荷の中身・出所・行き先・経路を追跡できる。
- 「会社」で買上げ目標、蔵出し、本国注文、台帳を操作する。買上げ目標は入力後のEnterまたはフォーカス移動で適用され、未反映・設定済みを同じ行に示す。本国注文は「納品済み／残り／あと何日」を常時表示し、船出と全量完遂を区別する。
- 「島況」では直近30日の収支、市場と現物に加え、食料の生産・消費・本土購入、食料と蔵の備え、人口、会社資金と日々の差引、選択品の相場を最大180日分のグラフで確認できる。履歴はこのプレイ中だけ保持する。
- HUD直下中央のエレナは、v002の大きな肖像と語りの長所を戻した常設の主案内である。羊皮紙色の専用面に濃いインク色で発話を置き、会社・島況・建物ウインドウは必ずその下から始まるため、情報を開いたままでも読める。階層ラベル、見出し、操作リンクを発話から外し、人物名と最大三行の話し言葉だけを見せる。操作は現在目標、長い内容と再読は書状が受け持つ。報告と止めない情報は現在目標を奪わず、致命的な状態だけが時間停止の書状になる。連続空腹30日で死亡前に警告し、死亡時は「60日食べられなかった」原因と食料庫・道・食料職の予防先を、止めない報告で伝える。

獣道、実寸建物、文化Lv、在庫の山、市場の屋台、徒歩家族、荷車、船の接岸と一荷ずつの荷役は、すべてエンジンのsnapshotと観測イベントから描画している。家族列は実人数を描き、仕事・市場往復・普請を実状態の色と持ち物で分ける。新しい運搬は実搬出元から現れ、完了した運搬は実搬入先へ着いてから消える。建物は職別の常駐バッジ、切妻屋根、作業小物で見分け、長い名称と在庫文字は選択時または拡大時だけ出して、町の形とヤードを隠さない。

`v004.14.0-render-scene`では、この正直な表示数と連続移動を変えず、snapshotごとに静的な描画場面を一度だけ編成する。地形本体は地形・季節・camera・viewportが同じ間だけ再利用し、水面、人物、荷車、船、荷役は従来どおり動かす。同一実Chrome都市の描画中央値は13.02ms/frameから2.60ms/frameへ短縮した。

`v004.15.0-elena-first-seat`では、エレナの発話を右下から画面上部中央の専用席へ移した。PC・スマホとも操作ウインドウとの間に固定の余白を持ち、彼女の欄だけを書状と響き合う明るい羊皮紙色にして、他の計器より先に人物の言葉が目へ入る構成にした。

`v004.16.0-elena-written-voice`では、「もう一度言って」の表示と押下機能を撤去した。目標開始37件、達成37件、書状46件、適時助言、重要イベントを、システムの見出しや詳細文を連結せず、それぞれの状況のために書いたエレナの発話へ置き換えた。専用文がない情報をエレナに代読させず、彼女が話す時は操作と意味がその言葉だけで通じるようにした。

`v004.17.0-guidance-steps`では、最初の「森まで道を敷く」と「木こりを建てる」を独立した二目標へ分けた。システム文は端的な作業、ボタンは押した結果を表示し、達成から次目標の間には短いフェードを挟んで切替を見分けられるようにした。

`v004.18.0-elena-letters`では、未来章の観察が最初の本国注文へ先回りする問題を章ゲートで止めた。書状は契約・危機・章末・比較資料だけに絞り、重要書状はエレナの予告後に自動で開く。任意書状はエレナ欄の「書状を開く」から直接読め、軽い報告は履歴に残らない一言として切り替わる。予告と達成の間は島時間を止めるため、読んでいる最中に次章へ走り抜けない。

## 検証

通常は変更した契約だけを検証する。詳細と昇格条件は [TESTING_POLICY.md](TESTING_POLICY.md)。第一章の導線変更なら次を使う。

```bash
cd /Users/Nao_u/nao-u-lab/GPT/game/shioji/v004
npm run test:tutorial-early
npm run test:focused -- "チュートリアル段5|チュートリアル段6|チュートリアル段7"
```

段17だけを指定した場合は、同じ世界を作る段7〜16だけを自動で先に実行する。

```bash
npm run test:focused -- "^チュートリアル段17:"
```

engineの軽微な修正は、該当unitだけを長期workerなしで実行できる。

```bash
cd /Users/Nao_u/nao-u-lab/GPT/game/shioji/engine
npm run test:focused -- "最初の生産適格注文"
```

経済定数、保存則、長期帯、複数章の契約を変えた時、または公開前の総点検だけ全件へ上げる。

```bash
cd /Users/Nao_u/nao-u-lab/GPT/game/shioji/v004
npm test
```

`npm test`はv004のunit群、第一章〜終章の完走journal、3シードの各較正、全章非干渉と失敗許容、UI全8操作を含む150日ジャーナル再生テスト、`../engine/`の全件を順に実行する。

最高速は自由プレイ、テスト配置、教程完了後だけ3tickごとに表示を更新し、engineの全tickと全イベントを実行したままsnapshot／view model更新を3分の1にする。進行中教程は書状の発行時刻と証拠値を完全に保つため1tickごとに表示する。

実ChromeによるPC・スマホ確認は、リポジトリ直下のHTTPサーバーとデバッグポート9226のChromeを起動した後に実行する。

```bash
npm run test:browser
```

8年×3シードの安定監査は次で単独実行できる。

```bash
npm run audit:stable --prefix ../engine
```
