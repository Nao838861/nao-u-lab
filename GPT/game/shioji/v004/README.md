## 開始方法

最初に次の3つから選ぶ。

- **エレナと開拓する**: 「自分でゼロから開拓」と同じ未開拓島へ、実際の統計に沿う書状と目標だけを重ねて始める。建てる・つなぐ・設定するなど自分で確実に完了できる操作だけが進行の背骨で、季節の谷、相場変化、長期存続など発生時期が読めない教材は進行を止めないエレナの助言・報告として届く。
- **自分でゼロから開拓**: 港だけがある島。人口・市場・倉庫・職建物・道路はゼロで、市場と倉庫から自分で配置する。
- **見本の町を眺める**: 人口・道路・産業が動く安定監査済みの町から始まる。

プレイ中も上部メニューの「最初から」で開始方法を選び直せる。

チュートリアルの書状を読んでいる間は時間が止まり、閉じると元の速度へ戻る。誤操作から復帰できない常設の案内終了ボタンは置かず、終章の卒業書状を受け取ると、その島を一切作り直さず自由プレイへ移る。卒業書状では町の人口・職・食料輸入・取引収支を安定監査の参照帯と並記するが、帯は合否判定ではない。

起動中も開始画面を残し、読み込みが完了しなければ再読込ボタンを出す。公開キャッシュで新旧moduleが混ざらないよう、全ES moduleを同じbuild版のURLで読む。

## チュートリアルの流れ

第一章は道、木こり、市場、食料、木工房、倉庫、最初の本国注文までを、自分の操作で一つずつ進める。第二章は漁と畑を整え、食料を島内で作る意味を学ぶ。第三章は季節に備える買上げ目標と「市場へ出す」を扱う。第四章は本国注文と市場価格を比べ、引き受けるか見送るかを判断する。第五章は加工職を置き、材料・原価・暮らしのつながりを見る。終章の卒業書状を読み終えると、その島のまま自由プレイへ移る。

章を止めるのは、建設、接続、数値設定、注文判断など、プレイヤーが自分で確実に終えられる操作だけである。季節の谷、相場変化、長期存続、建物の成長など発生時期の読めない学びは、進行を止めないエレナの助言や任意書状として届く。

## 遊び方

- 地図はドラッグ／スワイプで移動し、ホイール／ピンチで拡大縮小する。
- PCではWASDでも地図を連続移動でき、斜め移動も同じ速さになる。Spaceは停止／直前速度への復帰、1〜4は速度変更、Escは開いている書状・sheet・工具・選択を順に解除する。入力欄やmodifier操作中は発火しない。
- 上部のボタンで一時停止・通常・四倍・一日毎秒を切り替える。「1日進める」は停止中にも使える。
- 日付の下には、エンジンと同じ30日=1か月の「季節・月」を常時表示する。統計ボタンの「平穏／成長／注意／危険」は、連続空腹、直近の人口変化、取引資金をまとめた基調シグナルで、統計を開くと理由を文章とグラフで読める。
- 下部の整備・流通・食料・採取・加工から、名称・費用・実寸を見て建物を直接選ぶ。建物は入口にしたい区画を指定する。港だけは固定施設。
- チュートリアル中は、エレナ自身の言葉だけで「いま何をするか」と「なぜするか」が分かり、左上の「現在目標」は端的な作業一行と進捗を補う。その下のボタンは固定の［案内］ではなく、「道を敷き始める」「木こりを選ぶ」「取引を開く」のように、押した結果を表示する。目標を満たすと現在目標がいったん消え、エレナの達成発話を文字数に応じて5.2〜10秒残し、短いフェードの後に次の課題発話と目標欄を出す。この間は島時間も止まる。入植や注文を待つ目標では残り日数を示し、ボタン一回で一日毎秒へ変更できる。自由プレイでは建て方を推薦しない。
- 盤面の建物を押すと、道路接続、世帯の家族・財布・空腹・暮らし、区分棚、加工の投入と産出を確認できる。世帯の建物には1始まりのLvを示し、Lv1は道具だけ、Lv2は小屋、Lv3は道具と装飾が増え、Lv4は石積みの大きな小屋として盤面だけでも成長を読める。無人区画は灰色、板打ち、雑草、置き去りの道具で見分けられる。詳細には次のLvに必要な品、今日満たしたか、必要日数と現在の積み上げ、Lv低下の原因を表示する。Lv上昇時はエレナが祝い、何を何日満たした成果かを伝える。倉庫では会社在庫と役割も読める。
- 最低3×3の敷地は、建屋だけで埋めず作業ヤードを空けてある。入口側は原料、仕事場の脇は製品、奥は保管の定位置で、空いた場所も詰めずに残る。同じ職の製品はどの建物でも同じ相対位置へ置かれる。1〜20荷は一荷ずつ、21〜60荷は小山、61〜180荷は中山、181荷以上は大山として、搬入・搬出に合わせて同じ場所で姿が変わる。正確な量は建物の選択時またはPCで山へ触れた時に読める。
- 運び手や荷車を押すと、荷の中身・出所・行き先・経路を追跡できる。大口輸送も一団の塊ではなく、実容量ぶんを担いだ個々の運び手が少しずつ時差をつけて道を流れる。
- 「取引」で買上げ目標、市場へ出す、本国注文、台帳を操作する。買上げ目標は入力後のEnterまたはフォーカス移動で適用され、未反映・設定済みを同じ行に示す。本国注文は「納品済み／残り／あと何日」を常時表示し、船出と全量完遂を区別する。
- 荷車工房を建てると、世帯が丸太と木製品を買い、作業ヤードで木の荷車を作る。世帯は自分の財布で自律購入し、市場往復に使って距離ぶん摩耗させる。会社用は「取引」からプレイヤーが購入する。荷車がなくても手運びは続き、買えば一便の積載が増える。
- 上部の「発展図」は、港と流通、食と暮らし、森と手仕事、地と火の四枝で、島にある産業と将来構想を一枚にする。現段階では見るための地図で、建設制限や研究支払いは発生しない。
- 「需給」は全18品目を不足の深刻順に並べ、在庫、純増減、残り日数、相場傾向を一画面で示す。通常時のHUDは静かで、不足時だけ品目アイコン帯が現れる。需給行を押すと、その品の相場推移を統計で開く。
- 「統計」は直近30日の収支を先頭に固定し、既定では食料と冬必要量、人口と開始時、取引資金とゼロの3グラフだけを示す。凡例ではなく線端の名称で読み、品目相場は需給から選んだ時だけ追加する。履歴はこのプレイ中だけ最大180日保持する。
- PCでは画面左上のエレナ、スマホではHUD直下のエレナが、v002の大きな肖像と語りの長所を戻した常設の主案内である。PCは最大640pxの横長な羊皮紙面、スマホは画面幅いっぱいを使い、取引・統計・建物ウインドウを開いたままでも読める。人物名と最大三行の話し言葉を主にし、現在目標は端的な操作と進捗だけを補う。重要書状は十分な予告時間の後に自動で開き、任意書状は発話欄の「書状を開く」から直接読める。出生・成長・その他の軽い報告は一度だけ表示して通常案内へ戻り、古い記録は出来事一覧で読める。連続空腹30日で死亡前に警告し、死亡時は「60日食べられなかった」原因と食料庫・道・食料職の予防先を伝える。

獣道、実寸建物、文化Lv、在庫の山、市場の屋台、徒歩の住民、荷車、船の接岸と一荷ずつの荷役は、すべてエンジンのsnapshotと観測イベントから描画している。財布と在庫は世帯で共有するが、各人は安定した個人ID、自分の仕事・経路・出発時刻を持つ。素手1荷、背負い4荷、木の荷車8荷の実容量と実積荷を描き、新しい運搬は実搬出元から現れ、実搬入先へ着いてから消える。建物は職別の常駐バッジ、切妻屋根、作業小物で見分け、長い名称と在庫文字は選択時または拡大時だけ出して、町の形とヤードを隠さない。接続警告と危機は建物や人物より後に描き、常に最前面へ出す。

`v004.14.0-render-scene`では、この正直な表示数と連続移動を変えず、snapshotごとに静的な描画場面を一度だけ編成する。地形本体は地形・季節・camera・viewportが同じ間だけ再利用し、水面、人物、荷車、船、荷役は従来どおり動かす。同一実Chrome都市の描画中央値は13.02ms/frameから2.60ms/frameへ短縮した。

`v004.15.0-elena-first-seat`では、エレナの発話を右下から画面上部中央の専用席へ移した。PC・スマホとも操作ウインドウとの間に固定の余白を持ち、彼女の欄だけを書状と響き合う明るい羊皮紙色にして、他の計器より先に人物の言葉が目へ入る構成にした。

`v004.16.0-elena-written-voice`では、「もう一度言って」の表示と押下機能を撤去した。目標開始37件、達成37件、書状46件、適時助言、重要イベントを、システムの見出しや詳細文を連結せず、それぞれの状況のために書いたエレナの発話へ置き換えた。専用文がない情報をエレナに代読させず、彼女が話す時は操作と意味がその言葉だけで通じるようにした。

`v004.17.0-guidance-steps`では、最初の「森まで道を敷く」と「木こりを建てる」を独立した二目標へ分けた。システム文は端的な作業、ボタンは押した結果を表示し、達成から次目標の間には短いフェードを挟んで切替を見分けられるようにした。

`v004.19.0-canon-performance`では、未来章の観察が最初の本国注文へ先回りする問題を章ゲートで止めた。書状は契約・危機・章末・比較資料だけに絞り、重要書状はエレナの予告後に自動で開く。任意書状はエレナ欄の「書状を開く」から直接読め、軽い報告は履歴に残らない一言として切り替わる。予告と達成の間は島時間を止めるため、読んでいる最中に次章へ走り抜けない。世界観の語彙をデナリ、取引、統計、倉庫、市場へ出すへ統一し、従来の油料作物を綿花畑の布生産へ改めた。長期履歴、港の待機船、表示用出来事を有限化し、1300日監査で成熟後の100日処理時間が横ばい、ヒープ増加2.1MBに収まることを確認した。

`v004.20.0-carts-development`では、荷車工房、世帯と会社が所有する木の荷車、距離摩耗と買い替えを追加した。会社の運搬も荷車未所有時は有限の運び手が担い、荷車を無限生成しない。人は実人数を一人ずつ仕事ヤードと経路へ描き、運搬品を持つ。最後の在庫は前後の状態間で小さくなって消えるため、品切れ時に山全体が跳ばない。羊皮紙の「発展図」は現存産業を点灯し、造船所、鉱山開発、鉄製荷車を将来構想として見せるが、建設ロックはまだ行わない。教程は、倉庫到着と同じ観測内に船積みまで終わっても調達記録から進行を復元する。

`v004.21.0-elena-reading`では、出生や成長報告をエレナが永久に繰り返す原因だった「出来事に既読がない」構造を修正した。一言と出来事は読了時間の後に既読となり、新しい出来事だけを次に伝える。教程の達成文・一言・書状予告は短文でも5.2秒、長文は最大10秒まで保持し、PCの発話欄を最大640pxへ広げた。「教程」「EMA」「input棚」など作り手側の語も、章・ならした相場・原料棚・1日あたりの生産量へ改めた。

`v004.22.0-building-levels`では、保存用の内部Lvを保ったまま表示をLv1〜4へ改めた。道具だけのLv1、小屋が建つLv2、道具と装飾が増すLv3、石積みを備えた大きなLv4まで、同じ敷地の中で暮らしの成長を読める。無人区画は荒廃表現を持ち、警告と危機は建物に隠れない最前面層へ移した。

`v004.23.0-readability`では、食料を「島全体であと何日分か」としてHUDへ常設し、秋には人口に応じた冬越し必要量・備蓄・不足を統計で予報する。建物シートは家の健康、食料・財布・収支、次の暮らしに足りない物、仕事、在庫の順へ整理した。旗は表示Lvと同じ1〜4本、警告は静止、餓死・離散の危機だけが点滅する。エレナは書状や家を見る参照操作だけを持ち、建設や数値変更は現在目標・各操作画面へ一元化した。

`v004.24.0-individual-logistics`では、経済の単位を世帯に保ったまま、仕事・市場往復・買物・普請を構成員一人ずつへ割り当てた。素手1荷、木製品を持つ背負い4荷、木の荷車8荷、将来の鉄荷車16荷を共通の容量段階とし、馬車32荷は発展図の将来案だけに留めた。売り便は一人分容量の8割から出発し、空腹・文化財・原料不足の買い便は満載を待たない。教程で一日毎秒へ上げた待機は、次の目標へ移る時に等速へ戻り、待つ間は港や道の運び手を観察する課題を示す。

`v004.25.0-supply-demand`では、全18品目を不足の深刻順に読む独立需給画面を追加した。食料は冬季3シード実測の人口1人46荷を統計と共通の必要量とし、在庫、純増減、残り日数、相場傾向を3段階で示す。統計は収支と食料・人口・資金の既定3グラフへ整理し、現物所在と一覧相場を撤去した。各グラフは必要量などの基準線と線端の直接名称を持ち、品目相場は需給行からだけ開く。

`v004.26.0-living-yard`では、在庫量による品目の並べ替えをやめ、原料・製品・保管の役割ゾーンと空き置き場を建物の入口方向に合わせて固定した。品目がゼロになった跡は裸の置き場へ戻り、残る山は動かない。1〜20荷は実個数、21荷以上は実都市の在庫分布から較正した小山・中山・大山で示し、搬入・搬出の補間中も同じ定位置で段階が切り替わる。

`v004.27.0-topology-cache`では、地形・道路の改訂番号を表示snapshotの境界まで通し、変化していない48×40地形、自然物、道路接続、道路描画列を前回の不変モデルから再利用する。地形が変わらない更新では地形配列そのものの再送も省く。公開モデル、描画順、現物数、経済規則、完全snapshotは変えず、同じseed11・day120の更新処理を隣接測定で9.14ms/回から6.57ms/回へ約28%短縮した。

## 検証

```bash

npm run test:tutorial-early

```

```bash

```

engineの軽微な修正は、該当unitだけを長期workerなしで実行できる。

```bash
cd /Users/Nao_u/nao-u-lab/GPT/game/shioji/engine
npm run test:focused -- "最初の生産適格注文"
```

経済定数、保存則、長期帯、複数章の契約を変えた時、または公開前の総点検だけ全件へ上げる。

```bash

npm test
```
