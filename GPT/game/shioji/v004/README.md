## 開始方法

最初に次の3つから選ぶ。

- **チュートリアルから**: ガイドはまだ準備中。現在は「ゼロから開拓」と同じ未開拓島で始まる。
- **ゼロから開拓**: 固定施設の市場・蔵・港だけがある島。人口・職建物・道路はゼロで、全て自分で配置する。
- **テスト配置で観察**: 従来どおり、人口・道路・産業が動く安定監査済みの都市から始まる。

プレイ中も観測パネルの「最初から」で開始方法を選び直せる。

## 遊び方

- 地図はドラッグ／スワイプで移動し、ホイール／ピンチで拡大縮小する。
- 上部のボタンで一時停止・通常・四倍・一日毎秒を切り替える。「1日進める」は停止中にも使える。
- 下部から建物の配置・撤去、道路の敷設・撤去を選ぶ。建物は入口にしたい区画を指定する。
- 荷車を押すと、荷の中身・出所・行き先・経路を追跡できる。
- 「会社」で買上げ目標、蔵出し、本国注文、台帳を操作し、「出来事」で島のイベントを確認する。

獣道、実寸建物、文化Lv、在庫の山、市場の屋台、徒歩家族、荷車、船の接岸と一荷ずつの荷役は、すべてエンジンのsnapshotと観測イベントから描画している。
