## 開始方法

最初に次の3つから選ぶ。保存済みの島があれば「つづきから」、共有されたJSONがあれば「保存ファイルを読み込む」も選べる。

- **エレナと開拓する**: 「自分でゼロから開拓」と同じ未開拓島へ、実際の統計に沿う書状と目標だけを重ねて始める。建てる・つなぐ・設定するなど自分で確実に完了できる操作だけが進行の背骨で、季節の谷、相場変化、長期存続など発生時期が読めない教材は進行を止めないエレナの助言・報告として届く。
- **自分でゼロから開拓**: 港だけがある島。人口・市場・倉庫・職建物・道路はゼロで、市場と倉庫から自分で配置する。
- **見本の町を眺める**: 人口・道路・産業が動く安定監査済みの町から始まる。

プレイ中も上部メニューの「最初から」で開始方法を選び直せる。

チュートリアルの書状を読んでいる間は時間が止まり、閉じると元の速度へ戻る。誤操作から復帰できない常設の案内終了ボタンは置かず、終章の卒業書状を受け取ると、その島を一切作り直さず自由プレイへ移る。卒業書状では町の人口・職・食料輸入・取引収支を安定監査の参照帯と並記するが、帯は合否判定ではない。

起動中も開始画面を残し、読み込みが完了しなければ再読込ボタンを出す。公開キャッシュで新旧moduleが混ざらないよう、全ES moduleを同じbuild版のURLで読む。

## チュートリアルの流れ

第一章は道、木こり、市場、食料、木工房、倉庫、最初の本国注文までを、自分の操作で一つずつ進める。第二章は漁と畑を整え、食料を島内で作る意味を学ぶ。第三章は季節に備える買上げ目標と「市場へ出す」を扱う。第四章は本国注文と市場価格を比べ、引き受けるか見送るかを判断する。第五章は加工職を置き、材料・原価・暮らしのつながりを見る。終章の卒業書状を読み終えると、その島のまま自由プレイへ移る。

章を止めるのは、建設、接続、数値設定、注文判断など、プレイヤーが自分で確実に終えられる操作だけである。季節の谷、相場変化、長期存続、建物の成長など発生時期の読めない学びは、進行を止めないエレナの助言や任意書状として届く。

## 遊び方

- 地図はドラッグ／スワイプで移動し、ホイール／ピンチで拡大縮小する。
- PCではWASDでも地図を連続移動でき、斜め移動も同じ速さになる。Spaceは停止／直前速度への復帰、1〜4は速度変更、Escは開いている書状・sheet・工具・選択を順に解除する。入力欄やmodifier操作中は発火しない。
- 上部のボタンで一時停止・通常・四倍・一日毎秒を切り替える。「1日進める」は停止中にも使える。
- 日付の下には、エンジンと同じ30日=1か月の「季節・月」を常時表示する。統計ボタンの「平穏／成長／注意／危険」は、連続空腹、直近の人口変化、取引資金をまとめた基調シグナルで、統計を開くと理由を文章とグラフで読める。
- 下部の整備・流通・食料・採取・加工から、名称・費用・実寸を見て建物を直接選ぶ。建物は入口にしたい区画を指定する。港だけは固定施設。
- 木こりと漁師は森や海から離れた場所にも建てられるが、資源現場までの往復ぶんだけ働く時間が短くなる。配置中の「片道・実働・予測日産」を見て、道を引くか近くへ建てるかを選ぶ。選択後は建物と現場を結ぶ点線と、30日実績／理想日産で結果を確かめられる。
- 木工房、炭焼き小屋、塩田などは、原料を売れる生産者が市場より十分近ければ直接買い付ける。買い手は実際に仕入先まで歩き、既存の素手・背負い・荷車容量で持ち帰る。近くで完結しない取引、家庭の食料・生活用品、会社取引は引き続き市場が集約する。
- チュートリアル中は、エレナ自身の言葉だけで「いま何をするか」と「なぜするか」が分かり、左上の「現在目標」は端的な作業一行と進捗を補う。その下のボタンは固定の［案内］ではなく、「道を敷き始める」「木こりを選ぶ」「取引を開く」のように、押した結果を表示する。目標を満たすと現在目標がいったん消え、エレナの達成発話を文字数に応じて5.2〜10秒残し、短いフェードの後に次の課題発話と目標欄を出す。この間は島時間も止まる。入植や注文を待つ目標では残り日数を示し、ボタン一回で一日毎秒へ変更できる。自由プレイでは建て方を推薦しない。
- 盤面の建物を押すと、道路接続、世帯の家族・財布・空腹・暮らし、区分棚、加工の投入と産出を確認できる。世帯の建物には1始まりのLvを示し、Lv1は道具だけ、Lv2は小屋、Lv3は道具と装飾が増え、Lv4は石積みの大きな小屋として盤面だけでも成長を読める。無人区画は灰色、板打ち、雑草、置き去りの道具で見分けられる。詳細には次のLvに必要な品、今日満たしたか、必要日数と現在の積み上げ、Lv低下の原因を表示する。Lv上昇時はエレナが祝い、何を何日満たした成果かを伝える。倉庫では会社在庫と役割も読める。
- 最低3×3の敷地は、建屋だけで埋めず作業ヤードを空けてある。入口側は原料、仕事場の脇は製品、奥は保管の定位置で、魚や丸太などの荷姿は建屋から余白を取る。空いた場所も詰めずに残り、同じ職の製品はどの建物でも同じ相対位置へ置かれる。1〜20荷は一荷ずつ、21〜60荷は小山、61〜180荷は中山、181荷以上は大山として、搬入・搬出に合わせて同じ場所で姿が変わる。正確な量は建物の選択時またはPCで山へ触れた時に読める。
- 運び手や荷車を押すと、荷の中身・出所・行き先・経路を追跡できる。大口輸送も一団の塊ではなく、実容量ぶんを担いだ個々の運び手が少しずつ時差をつけて道を流れる。
- 「取引」で買上げ目標、市場へ出す、本国注文、台帳を操作する。買上げ目標は入力後のEnterまたはフォーカス移動で適用され、未反映・設定済みを同じ行に示す。本国注文は「納品済み／残り／あと何日」を常時表示し、船出と全量完遂を区別する。
- 荷車工房を建てると、世帯が丸太と木製品を買い、作業ヤードで木の荷車を作る。世帯は自分の財布で自律購入し、市場往復に使って距離ぶん摩耗させる。会社用は「取引」からプレイヤーが購入する。荷車がなくても手運びは続き、買えば一便の積載が増える。
- 上部の「発展図」は、港と流通、食と暮らし、森と手仕事、地と火の四枝で、島にある産業と将来構想を一枚にする。現段階では見るための地図で、建設制限や研究支払いは発生しない。
- 「需給」は全18品目を不足の深刻順に並べ、供給（生産・仕入）と需要（消費・不足）、市場と島全体の在庫、在庫日数、相場傾向を一画面で示す。通常時のHUDは静かで、不足時だけ品目アイコン帯が現れる。品目行を押すと、需要源、不足理由、所在、作り方、相場推移を確認できる。
- 「統計」は直近30日の収支を先頭に固定し、既定では食料と冬必要量、人口と開始時、取引資金とゼロの3グラフだけを示す。凡例ではなく線端の名称で読み、品目相場は需給から選んだ時だけ追加する。履歴はこのプレイ中だけ最大180日保持する。
- 「統計」の島の生産性は、全生産世帯の30日実績を今の季節・Lvで距離損失がない理想日産と比べる。距離で失った日産、近距離仕入の回数・数量・短縮時間、30日前からの変化も同じカードで読める。市場を選ぶと片道14目盛り以内の生産圏だけを同じ尺度で集計する。
- PCでは画面左上のエレナ、スマホではHUD直下のエレナが、v002の大きな肖像と語りの長所を戻した常設の主案内である。PCは最大640pxの横長な羊皮紙面、スマホは画面幅いっぱいを使い、取引・統計・建物ウインドウを開いたままでも読める。人物名と最大三行の話し言葉を主にし、現在目標は端的な操作と進捗だけを補う。重要書状は十分な予告時間の後に自動で開き、任意書状は発話欄の「書状を開く」から直接読める。出生・成長・その他の軽い報告は一度だけ表示して通常案内へ戻り、古い記録は出来事一覧で読める。連続空腹30日で死亡前に警告し、死亡時は「60日食べられなかった」原因と食料庫・道・食料職の予防先を伝える。

```bash

```

```bash

```

