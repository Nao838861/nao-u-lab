# v004 ステップブック — エンジン可視化(ビュー/UI統合) (Claude作成・2026-07-20)

## この文書の使い方
engine/STEPBOOK.md と同じ運用: 全18段が最初から見えている。現在地 N/18 を毎セッション design_log 冒頭に記録。段の完了=完了条件のテストが通ること。計画外は「提案段」として追記して止まる。1セッション2〜4段。

## 大原則(正本=../engine/ENGINE_SPEC.md §10)
1. **エンジンが主**。v004は「snapshot+イベントを描くビュー層」と「操作APIを呼ぶUI」だけ。エンジン状態の直接変更・engine/配下のコード改変は**禁止**(必要が生じたら実装せずdesign_logに質問)
2. v003のビジュアル資産(タイル・建物・荷車・船・CSS)を最大限流用し、エンジンと矛盾したら**ビジュアル側で調整**する
3. **盤サイズ非依存**で作る(現48×40、将来96×80以上)。座標・カメラ・UIに盤寸法を焼き付けない
4. チュートリアル・章・書状・秘書は本レーン外(後続レーン)。公開中のv003はそのまま残す(v004は別ページ)
5. アニメーションはイベント(day/tick/座標)の**補間**で作る。描画フレームとworld.step()は分離し、アニメの都合でエンジンの時間を歪めない
6. 罠図鑑は `../v003/econ_pitfalls.md`。本レーンで特に効くのは**罠#15「見えないルールは存在しないのと同じ」**——エンジンの重要イベントは必ず画面に出す

ゴール = v003の見た目の水準で、エンジンの世界が動いて見え、プレイヤーが操作APIの全機能を画面から使え、エンジン非改変が証明されていること。
