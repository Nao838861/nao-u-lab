# チュートリアル知識地図（2026-07-24）

## 数え方

`TUTORIAL_GOALS` は38件で、実装上の必須目標は23件、任意観察は15件である。作業指示の「必須24件」は、任意化による目標列の組み替え前の数と判断し、実コードを正本として23件を全件監査した。

各必須目標は「知る → 望ましい状態 → 既存操作」の一方向で進む。待機を含む目標には上限または失敗完了を置き、偶然の発生だけで教程を止めない。
