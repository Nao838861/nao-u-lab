## 大原則
1. **チュートリアル=サンドボックス+ディレクター**。同じエンジン・同じルールの世界に、観測と助言の層を被せるだけ。**世界を台本で動かさない**——建物を湧かせない・資源を注入しない・失敗を防がない(餓死はある)。ディレクターは観測APIの購読と書状の生成と目標判定のみを行う
2. **書状はエンジンの実況**。エレナの台詞はテンプレート+実データ(実際のロット数・実際の帳簿・実際のイベント)で生成する。固定の日付トリガ・固定の数値の読み上げは禁止。文体と世界観の正本は `../../../../Claude/projects/production_consumption_sim/design/narrative_bible.md`(規範=Nao_u原文のみ・AIの補完は【案】)
3. **目標は宣言的な述語**(イベント発生 or スナップショット条件)で定義し、達成もエンジンの実挙動で判定する。プレイヤーが目標を無視したら、エレナは実際に起きた帰結を語る(進行は壊れない)
4. **engine/ 配下の追加改変は禁止**(必要が生じたら実装せず design_log に質問)。港だけ開始と市場・蔵の建設契約は2026-07-20にユーザー裁可済みの例外として実装済み。v004 のビュー/UI原則(STEPBOOK.md 大原則)をすべて継承
5. **いつでも離脱可**: チュートリアルを抜けるとその世界のままサンドボックスになる。第二章完了後も同じ世界で自由プレイが続く(モード切替であって世界の切替ではない)
6. 罠: `../v003/econ_pitfalls.md` #15(見えないルール)に加え、本レーン固有の罠=**台本への回帰**。「確実に見せたいから直接動かす」と思ったら停止して質問

## 章の設計(Nao_u決定・2026-07-20)
**開始シナリオ**(実装済みのサンドボックス開始と同一): **港だけが固定施設として既設**。市場・蔵・人口・職建物・道路は0で、市場と蔵を配置してから産業を組む。入植は職建物の配置→区画充足の移民で起きる。
**エンジンの輸出の現実**(設計の前提): 常時輸出の白名単は食料加工品(pres/pick/oil)のみで、**木製品が島を出る経路は本国注文だけ**。注文の品目は「島が実際に生産している財」(生産EMA>0.3)から選ばれるため、木工房が動けば道具の注文が来る——第一章の輸出は注文を器にする。荷車の初登場も会社物流(市場→蔵→港)であり、世帯の市場往復は徒歩。
**第一章=輸出先行**(v003「最初の一荷」の弧を注文ベースで再構成)。**橋=通勤問題**——木こりの実トリップが生産倍率を下げている事実を実測値で指摘し、帰結は**道を敷く**(単一市場では食料建物の近接はトリップを縮めない)。**第二章=食料自給**——蝕まれるのは会社でなく**島の銀**(食料の本土仕入=本土への流出)であることを帳簿の実データで見せる。

### 第一章「最初の一荷」の目標列(各目標=プレイヤー操作→実イベントで達成。**施設は必要が見えた瞬間に建てる**)
着任の書状(港だけの島) → 道を森の際へ+木こり(3×3)を置く → 入植船で最初の世帯が来る(実況) → 丸太の山 → エレナ「売る場所がありません」→**市場を置く**(港の近く・入植キットの食料が尽きる前に購買の場を) → 木こりが市場で初売り(徒歩トリップの実況) → 木工房を置く(入植→市場で丸太を買いinput棚へ→最初の道具) → 道具の生産に本国が目を留め**注文状が届く**(実イベント)→受諾 → エレナ「納めるには蔵が要ります」→**蔵を置く**+会社買付が「道が繋がっていません」で止まる→**市場・蔵・港を道で結ぶ** → 荷車の初運搬(市場→蔵→ヤード)→豆腐荷役→船出→達成ボーナスの実額 → 章締めの書状(実収入と、食料の本土仕入の累計を並記)

### 橋「木こりの二日」
ディレクターが木こり世帯の実トリップtickと生産倍率を観測し、閾値(実測から較正)を超えていたらエレナが実数で指摘。帰結=**森への道を敷く**→生産倍率の実回復を実況(道の価値の体験)。

### 第二章「島の食卓」の目標列
食料の本土仕入の累計(実帳簿・島の銀の流出) → 食料建物(漁師・菜園等)を**市場近くの適地**へ → 食料pxと輸入量の実変化を書状で → 食料輸入EMAが閾値未満(閾値は実測から較正・§9の帯ルール準拠) → 章締め(本土流出の減少を実況)→自由プレイへ
