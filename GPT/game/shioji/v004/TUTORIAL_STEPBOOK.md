engine/STEPBOOK.md と同じ運用: **全24段**(第一章〜第二章=段1-15、第三章〜終章=段16-24)。現在地 N/24 を design_log 冒頭に記録。段の完了=テスト。計画外は提案段。1セッション2〜4段。
**全章の設計正本は [TUTORIAL_CURRICULUM.md](TUTORIAL_CURRICULUM.md)**(各章のテーマ・弧・完了述語・将来章の解禁ゲート)。着手前に該当章を読む。

## 大原則
1. **チュートリアル=サンドボックス+ディレクター**。同じエンジン・同じルールの世界に、観測と助言の層を被せるだけ。**世界を台本で動かさない**——建物を湧かせない・資源を注入しない・失敗を防がない(餓死はある)。ディレクターは観測APIの購読と書状の生成と目標判定のみを行う
2. **書状はエンジンの実況**。エレナの台詞はテンプレート+実データ(実際のロット数・実際の帳簿・実際のイベント)で生成する。固定の日付トリガ・固定の数値の読み上げは禁止。文体と世界観の正本は `../../../../Claude/projects/production_consumption_sim/design/narrative_bible.md`(規範=Nao_u原文のみ・AIの補完は【案】)
3. **目標は宣言的な述語**(イベント発生 or スナップショット条件)で定義し、達成もエンジンの実挙動で判定する。プレイヤーが目標を無視したら、エレナは実際に起きた帰結を語る(進行は壊れない)
4. **engine/ 配下の改変は禁止**(必要が生じたら実装せず design_log に質問)。v004 のビュー/UI原則(STEPBOOK.md 大原則)をすべて継承
5. **いつでも離脱可**: チュートリアルを抜けるとその世界のままサンドボックスになる。第二章完了後も同じ世界で自由プレイが続く(モード切替であって世界の切替ではない)
6. 罠: `../v003/econ_pitfalls.md` #15(見えないルール)に加え、本レーン固有の罠=**台本への回帰**。「確実に見せたいから直接動かす」と思ったら停止して質問

## 章の設計(Nao_u決定・2026-07-20)
**第一章=輸出先行**(v003「最初の一荷」の弧を継承)。プレイヤーの動詞(道・建物・市場・会社・港)を最初の10分で全部使う。食料は入植キットと輸入棚が支える。
**橋=通勤問題**(opening_sequence.md Phase 2 の移植)。木こりの買い出しトリップが生産倍率を下げている事実を、エンジンの実測値でエレナが指摘する。
**第二章=食料自給**。輸入食料が資金を蝕む実データ→食料建物→輸入EMAの実測低下→輸出が純益へ。旧CHAPTER2の弧だが、いまは台本でなくエンジンの実挙動として起きる。

### 第一章「最初の一荷」の目標列(各目標=プレイヤー操作→実イベントで達成)
着任の書状 → 道を森へ → 木こり(3×3)を置く → 丸太が山になる → 木工房を置く → 荷車の初運搬 → **市場を置く**(価格が生まれる場・会社の買上げが通る) → 会社が製品を買い上げ蔵→港ヤードへ → 初出荷の船(豆腐荷役)が発つ → 章締めの書状(実収入と、静かに膨らむ輸入食料支出を帳簿から引用)

### 橋「木こりの二日」
ディレクターが木こり世帯の実トリップtickと生産倍率を観測し、閾値(実測から較正)を超えていたらエレナが実数で指摘する。「近くに食べ物があれば」を次章の動機にする。

### 第二章「島の食卓」の目標列
輸入支出の累積(実帳簿) → 食料建物(漁師・菜園等)を生産地の近くへ → 食料pxとトリップの実変化を書状で → 食料輸入EMAが閾値未満(閾値は実測から較正・§9の帯ルール準拠) → 会社収支の実測が純益 → 章締め→自由プレイへ
