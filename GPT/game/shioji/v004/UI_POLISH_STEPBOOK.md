作成日: 2026-07-21

現在地: **12/12**

## 大原則

1. エンジンが主であり、`engine/`配下は変更しない。必要になった時は実装せず質問化する。
2. 公開中の`v003/`は変更しない。視覚・操作知見だけをv004側へ移植する。
3. engineに無い値・制度・因果を描かない。矛盾は表示側の採否・文言・レイアウトで解消する。
4. 操作は既存の公開APIだけを通し、表示は不変snapshotから作る。UI有無でworldが変わってはならない。
5. 高速化はengineのtick、イベント、入力journal、教程状態を一つも省略・変更しない。
6. 1セッション2〜4段。各段はテストで閉じ、終了時に`npm test → commit → push`を行う。

ゴールは、v003とClaude版の実装済みだった優れた情報導線を現エンジンと矛盾なく再構成し、建築・観測・秘書・キーボード操作を一貫させ、高速再生の負荷を状態同値のまま削減すること。
