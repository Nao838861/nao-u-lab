| Q13 | 路線の操作モデル | **定期便型**: 起点⇄終点・出発間隔・行き荷/帰り荷の品目指定（量は積めるだけ）。在庫条件・価格条件は深さバックログ（退屈が観測されてから）。縦切り初版は陸路の隊商のみ、海路は次段 |
| Q14 | 開始地点 | **今は固定**（教程・ゲームデザインの都合）。エンジンは開始地点を世界データとして持ちハードコードしない——将来のランダムマップ/自由上陸に対応可能な作り（B-0受け入れ条件） |
| Q15 | 便の費用 | **実費モデル**: 荷車調達（既存の荷車経済）+便ごとの雇い賃+走行消耗。レシート=売上−仕入−雇い賃−消耗。距離の壁が損益に現れることが縦切りの検証本体。資金締め付けの第一歩は路線実費から |
| Q16 | 路線の成長 | **人を増やす増結**が第一軸: 編成の実体は雇い人数（1人1台で荷車を押す）。**荷車は消耗品として路線が消費し続ける資材**——耐久が尽きれば修理・買い替え、荷車の供給が絶えると隊商が止まる（境界跨ぎの事件）。物流網が島の産業（荷車工房、将来は鉄荷車→鉄の連鎖）に依存する内需の循環。第二軸=上位車両（鉄荷車）、増便は最後 |
| Q17 | 資金が尽きたら | **既定を再確認**: 左遷継続システム（Nao_u原案2026-07-23確定、[PLAYTEST_FEEDBACK_20260723.md](PLAYTEST_FEEDBACK_20260723.md) L328）。本国からの借入は限界まで可能、超えるとゲームオーバー→「新任の別人」で再開、エレナは同一人物で冷たい関係から。路線の実費はこの借入枠の中で回る |
| Q19 | 路線と圏内経済の接続 | **両端とも本物の経済**。路線の仕入は起点市場の実在の屋台・会社在庫から買い（住民の収入になる）、販売は終点市場の実需給へ売る（住民の暮らしになる）。抽象台帳は使わない。縦切りは数世帯が実在する第二集落を種付きシナリオで用意。路線は輸送であると同時に圏を富ませる/枯らす手段 |
| Q20 | 入植 | **自然充足＋実移動**。区画を置けば既存機構（分家/移民）で人が来るが、移動は本物（分家は元の家から、移民は母港から実際に歩く。数日かかる）。到達不能・食料の見込みが立たない区画には来ない。入植隊の編成操作は作らない。桟橋への移民直行は海路とセットで後日 |
| Q21 | 前哨と物流 | **市場一本化（荷寄せ場は作らない）**。市場は小さく生まれて育つ（見た目と機能のLv）。前哨には小さな市場を置けて路線の停車先になり、会社の集荷は既存の買上げ目標で行う。エンジン要件: 極小市場でも価格・需給が退化しない（可読規則の価格）——B-0/市場分離の受け入れ条件 |
| Q22 | 便の時間感覚 | **片道1〜3日の泊まりがけ**（隣接圏≈1日・最遠≈3日、荷車0.6刻/タイル×圏間60〜100タイルの素直な帰結）。定期間隔は往復日数より長く。道路改良・峠開通は日数の短縮として現れる。夜営の絵は眺めの深さバックログ |
| Q23 | 人口規模 | **最低: 世帯100〜150・人口700〜1000（B-0合格基準）。できれば数千人へ、現実にできる範囲で**——遠圏世帯の統計LOD化の道を塞がない設計をB-0要件に含める |
| Q24 | 個人シミュの境界 | **経済（財布・在庫・職・Lv）は世帯単位を維持**。気になりの正体は経済でなく描画の情報落ち: 内部は既に運び手だけが便に出て残りは実生産している（人数比の生産倍率）のに、残った家族の働く姿を描いていない。**対処=既に真実である内部を画面に正しく反映する振り付け**（役割の分化・時差の日課・残った働き手の作業描写）。帳簿と矛盾する量・品目は描かない。優先順位は縦切りの後の「眺めの質パス」（隊商の絵作りと同じ束）。兼業（世帯内の職分担）は深さバックログ |

## 原文（温度の保存）

- 「そもそも160×100は想定より非常に狭い。AAA的ではない、カイロソフトのゲームみたいに感じる。地続きでC3の複数マップが一つのワールドに入っている感じにしたいので、もっと無尽蔵に近い広さを想定していた」
- 「マップ構造は正しく設計することで未設計の荒野が連続しているような事態にはしない。最低256x256くらいからはじめて、ゲームの完成度が上がってきてもっと広いマップが必要になった時にエンジンはスケーラブルに対応できるようにしておく」
- 「どこから建物を置き始めるか迷うようにしたい。たとえば複数の盆地があって、こっちは近いけど狭い、あっちは広いけど遠い、とか、どこからどのように進めるのが最適解かわからない選択の多様性があるマップであるべき。なので最終的にはそんな単純な話にはならないと思う」
- 「（路線は）A列車の列車やアトラスの交易みたいな存在で、おそらくこのゲーム固有の一番楽しいところになるようにしたい」
