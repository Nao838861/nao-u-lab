# v004.55.0 世界基盤・局所漁場 受け入れ記録

## B-0 世界スケール基盤

- 256×256の世界寸法、開始注視点を`worldData`としてsnapshotへ持たせ、48×40／96×64の固定値から分離した。
- 性能fixtureは150世帯・750人・150建物を実体として作る。B-2の手設計地図ではなく、地図データを待つ間の性能・互換基盤である。
- 静的描画物を16タイル単位の空間bucketへ分け、毎frameは画面近傍だけを深度mergeする。移動中の人は個人のまま、1200人超では在宅者を世帯単位へ束ねるLODを追加した。
- 実Chrome 1440×900、day0、150建物・750人では、240frame×5回の中央値が4.720ms/frame。地形65,536セルのうち実描画4,761、静的450候補のうち近傍300・実描画203、動的実描画350。地形cacheの定常hit、pan時の無効化、canvas再利用、復帰後hitを確認した。
- 同fixtureで地形再送を省いたsnapshot＋差分view modelを10回×7組測り、中央値10.624ms/更新（9.487〜12.033ms）だった。空地形はB-2の経済シミュレーション代用品ではないため、資源探索職を混ぜず中立な麦畑世帯で人口・建物・表示負荷だけを測る。
- 通常都市のNode計測はview pipeline 5.021ms/回、view model 2.887ms/回、差分view model 1.649ms/回だった。

## A-3 局所漁場と魚影

- 水面タイルへ`bay`／`bay2`と魚影4段階を持たせ、漁師は実際の作業地点が属する入江だけを消耗する。
- 漁が行われなかった入江だけが日末に回復する。30%未満で一度だけ薄化を知らせ、55%超まで戻ると再通知可能になる。
- 魚影は段階に応じて1〜3尾を水面へ描く。地形cache keyへ段階を含め、変化時だけ描画revisionを進める。
- 旧48×40地形には局所漁場を後付けせず、従来の湾全体の生産式を保つ。旧保存で局所タグだけ存在する場合は初回更新時に地形から漁場一覧を復元する。
