# Tide Loom v001

中心ポストに結ばれたビー玉を、糸の長さだけで振り回して音符を拾うプロトタイプです。

## 操作

- `Enter` / クリック: 開始
- `Space` または `ArrowUp`: 糸を巻く
- `Shift` または `ArrowDown`: 糸をゆるめる
- `R`: 最初からやり直し
- `P`: 一時停止

## 目標

1. 画面上の音符をすべて拾う。
2. 出現した港へ戻る。

## 方針

直接移動はできません。糸を短くすると内側へ引かれ、糸を長くすると外側へ流れます。糸、目標糸長の円、予測線を見て、次にどこへ行くかを読むゲームです。

`捕獲率` や `束縛率` のような抽象表示は使いません。見えているビー玉が音符や港に触れたら成功です。
