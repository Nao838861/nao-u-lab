# Tide Loom v002

目標なしの操作感プロトタイプです。

v001 は音符を取る目標を置いたものの、操作そのものの気持ちよさが判断しづらい状態でした。v002 では目標、スコア、失敗条件を外し、中心に固定された弾性コードにつながれた玉を操作する感触だけを評価します。

## 物理モデル

- 玉は位置と速度を持つ。
- 中心から玉まで弾性コードが伸びている。
- `Space` / `ArrowUp` はコードの自然長を短くする。
- `Shift` / `ArrowDown` はコードの自然長を長くする。
- 玉の距離が自然長より長いときだけ、コードが中心へ引っ張る。
- 半径は直接変更しない。玉は慣性とばね力で遅れて動く。

つまり、これは硬い棒でも完全拘束された糸でもなく、「巻き取り機で自然長を変えられる弾性コード」を模しています。

## 操作

- `Enter` / クリック: 開始
- `Space` または `ArrowUp`: 巻く。自然長が縮み、張力が増えて内側へ引かれる。
- `Shift` または `ArrowDown`: ゆるめる。自然長が伸び、張力が弱まって慣性で外へ流れやすくなる。
- `R`: リセット
- `P`: 一時停止

## 見るべき点

- 巻いたときに「引っ張られて縮む」感覚が直感と合うか。
- ゆるめたときに「押し出される」のではなく、張りが抜けて流れる感覚に見えるか。
- 半径方向と接線方向の速度が、予測できる動きに見えるか。

この段階では、ゲーム目標やスコアは評価しません。
