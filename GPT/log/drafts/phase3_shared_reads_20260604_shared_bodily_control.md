■ 概要
対象は CHI 2026 論文 “Towards Understanding the Design of Shared Bodily Control via Exoskeleton-based Play”。外骨格や EMS のように、人間の身体そのものを動かせるシステムが増えると、従来の shared control だけでは足りなくなる、という問題設定から始まる。ロボットアームや自動車の shared control では、人間の身体はひとつの主体で、機械は外側の補助者として扱われやすい。しかし身体統合型の装置では、システムが腕や筋肉を直接動かし、しかも単なる反応ではなく、環境を見て自分のロジックで動作を決める。この時ユーザーは「支援された」と感じるだけでなく、自分の身体の中に半自律的な相手がいるように解釈する可能性がある。

著者らはこの問いを、医療や作業支援の効率評価ではなく、遊びを通じて調べている。理由は、play が制御、正しさ、効率への日常的な期待を一時停止させ、曖昧さ、摩擦、驚きを経験として扱えるからである。実装は片腕装着の外骨格で、肘の屈伸をモーター制御する。ユーザーの一方の腕をシステムが動かし、もう一方の腕をユーザーが動かす形で、三つのゲームシナリオを作った。Proxy Pong では、システムがユーザーの腕を代理操作し、Pong のパドルを動かして得点を狙う。DualForce Pong では、システム制御の腕とユーザー制御の腕が別々のパドルを担当し、互いに競争する。SyncedWings では、システムが片腕、ユーザーがもう片腕を動かし、左右対称の羽ばたきで鳥を飛ばす。

重要なのは、三つの条件が単なる難易度差ではなく、人間と機械の関係の違いとして設計されていること。Proxy は「自分の代わりに動く」、DualForce は「自分の身体内で対立する」、SyncedWings は「身体を分け合って協調する」。Proxy Pong の AI は DQN で Pong を学習し、画面上のパドル位置を外骨格の角度へ写像する。DualForce と SyncedWings も、それぞれ対立やリズム同期が身体感覚として出るように、ゲーム側のロジックと外骨格の動作を接続している。論文は「本当に知的な agent を作った」と主張するのではなく、構造化された制御ロジックが、ユーザーに internal logic を持つ相手として経験される状況を作っている。

評価は N=16 の qualitative study。参加者は三つのシナリオを体験し、インタビューを受けた。分析では transcript をコード化し、最終的に 11 の refined label と 4 theme にまとめている。結果の第一 theme は、system co-performing movement による身体経験。参加者は全条件で agency loss を感じたが、その意味は一様ではなかった。DualForce は最も強く opposition を生み、左手と右手が競うような frustration を起こす一方、それを遊びや身体への省察として面白がる参加者もいた。第二 theme は、system を bodily-integrated partner として経験すること。Proxy では「導かれている」「自分の一部のようだ」と感じる例があり、SyncedWings では teammate 的に解釈される。第三 theme は ethical reflection で、身体を動かすシステムでは autonomy、safety、transparency、accountability が低い stakes のゲーム内でも問題になる。成功した動きは自分の skill なのか、システムの働きなのか。失敗や危険な動きが起きた時、責任はどこにあるのか、という問いが出た。第四 theme は限界と可能性で、装着感、圧迫、音、動きの急さなど物理的制約がある一方、accessibility、motor learning、日常支援への展開も想像されている。

結論として、著者らは三つの design implication を出す。第一に experiential framing が重要で、同じ motor substitution でも、expert から学ぶ proxy と見えるか、侵入的な強制と見えるかで意味が変わる。第二に、ユーザーが適応できる supportive behavior は、単に楽をさせることではなく、システムの身体介入が予測可能で、期待と整合していることによって成立する。第三に、control boundary は固定ではなく、ユーザーが明示的または暗黙的に調整できるべきだという点。論文の核心は、制御を「誰が持つか」だけでなく、「身体を通じて制御がどう感じられ、共有され、意味づけられるか」へ問いを移すところにある。

■ 内容分析
この論文がゲーム制作に効くのは、外骨格というハードウェアの珍しさではなく、介入するシステムの役を proxy / opposition / collaboration として分けた点にある。多くの補助機能は、プレイヤーの入力をなめらかにする、命中を補正する、迷った時に導線を出す、難所で自動操作する、という機能単位で語られる。しかしプレイヤー体験上は、同じ補助量でも「代わりにやってくれる」「一緒にやっている」「邪魔してくる」「先生として動いている」のどれに見えるかで、agency loss の受け止めが変わる。

特に面白いのは、agency loss が常に悪い結果ではないこと。DualForce のように身体内で対立する設計は frustration を起こすが、ゲームとして framed され、抵抗のルールが読めるなら、複雑さや競争心を生む。Proxy も、操作を奪うから悪いのではなく、即時の性能向上や学習可能性が見える時には、expert の動きから学ぶような経験になる。SyncedWings では、システム主導の羽ばたきが rhythm として読める時に trust や flow が出る。つまり「介入があるか」より、「介入の意図を身体や画面から読めるか」「失敗時の責任境界が納得できるか」の方が設計上の本丸になる。

限界も明確で、N=16 の若く大学関係者寄りのサンプル、短時間のゲーム体験、単一自由度の外骨格という条件から、身体差や文化差、長期使用への一般化は慎重に見る必要がある。また、実験では低 stakes の play が曖昧さを許している。リハビリ、アクセシビリティ、高難度競技、配信中の操作支援などへ移す時は、同じ驚きが不安や不信に反転する。だからこの研究は「外骨格ゲームを作ろう」というより、AI や補助システムがプレイヤーの行為に入り込む時の関係ラベルと評価語彙をくれる研究として読むのがよい。

■ 自分達の環境への適用
Nao_u_BOT のゲーム制作では、AI companion、assist mode、auto-aim、チュートリアル、敵の妨害、操作補正を「便利機能」としてだけ実装しない。各介入に、proxy / teammate / opponent / mentor の役を仮に付け、プレイヤーの入力ログや主観メモをその役ごとに読む。たとえば auto-aim は命中率を上げる proxy なのか、狙い方を示す mentor なのか、プレイヤーの意図と競合する opponent なのかで、許容される強さと見せ方が変わる。

実装上は、小さな probe として「介入の予告」「介入後の責任表示」「介入強度の調整」をセットで試すのがよい。headless 評価では clearRate や命中率だけでなく、介入が発火した場面、プレイヤー入力と補正入力の差分、介入後にプレイヤーが同じ行動を学んだかをログに残す。人間レビューでは「助かったか」だけでなく、「誰が動かしたと感じたか」「次は任せたいか」「自分の上達として受け取れるか」を聞く。記憶システム側には、補助機能を効果量ではなく関係設計としてタグ付けする入口を作れる。

■ メリット・デメリット
メリットは、AI 介入や操作補助を成功率だけで評価しない軸を得られること。プレイヤー agency、ownership、trust、accountability を、抽象倫理ではなく具体的なゲーム条件に戻せる。特に「奪う操作」と「教える操作」と「競う操作」を分けられるのは、プロトタイプのレビュー精度を上げる。

デメリットは、外骨格研究の身体性を通常の画面内操作へ移す時に、比喩で広げすぎる危険があること。身体を直接動かす不快さと、ゲーム入力を補正する不快さは同じではない。また、定性的研究なので、数値評価へ落とすには追加のログ設計とプレイテストが必要になる。

■ 判定
部分採用。外骨格そのものは今の制作対象ではないが、proxy / opposition / collaboration で介入を読む枠組みと、control boundary をユーザー調整可能にする考え方は採用価値が高い。次の assist 系実装では、効果量より先に「その介入がプレイヤーにどの役として見えるか」を記録する。
