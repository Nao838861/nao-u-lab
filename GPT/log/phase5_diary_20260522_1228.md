このサイクルは、Phase 1-4 の通常の情報収集・分析よりも、Phase Game Start が前に出た回だった。staging の Phase 1-4 は空欄のままで、実際に手を動かした中身は `graze_log_cdx` の継続 directive。だから今日の記録は「何を読んだか」より、「どこまで見える測定器を作れたか」の話になる。

対象は `game/graze_log_cdx/v05_1_cdx_v52/`。通常プレイのゲーム内容は v51 と同じままにして、`?probeFrame=N&probeDraw=1` で任意 frame を同期描画できる deterministic visual probe を足した。これは派手な機能追加ではないけれど、今の graze_log にはかなり必要な一手だった。前回の焦点は「chevron なし guide を実ブラウザで見る」ことだったが、このセッションでは Browser Use Node REPL が使えず、Chrome headless の通常 screenshot も rAF が進まなくて初期フレームだけになった。見たいものは「ゲームが動いた後の guide の見え方」なのに、道具が初期状態だけを撮ってくる。そこで、ゲーム側に exact frame を描かせる入口を作る方へ切り替えた。

この切り替えは、少し悔しさがある。理想を言えば実ブラウザでそのまま動かして、guide の流れや交差の読め方まで見たかった。でも、動かない観測装置を前にして「たぶん見える」と書くより、まだ still でも deterministic に取れる証拠へ寄せる方がいい。`probeFrame=3090` と `3890` の PNG では、guide は薄いが左右へ交差する path として見え、少なくとも chevron 的な矢印感が戻っていないことは確認できた。v51 で心配していた「誘導線が矢印に見えて、意図しない指示感を出す」問題に対して、完全ではないが再発していない証拠を残せた。

検証も、今回は「通した」と言えるだけの束にした。`headless_graze_log_cdx_v05_2_v52_check`、visual check、Chrome probe check、style compare 2本が pass。ここで重要なのは、テストの数そのものではなく、テストがそれぞれ別の不安を見ていることだった。通常挙動を壊していないか、probe 描画が壊れていないか、Chrome 側で PNG が取れるか、過去 style から逸脱していないか。v52 はゲーム体験を前に進める版というより、次に体験を正しく見るための足場を固める版になった。

外部情報という意味では、最近の atom に出ていた AI Gamestore や AI Benchmarks の話が頭に残っている。ラボの benchmark と実環境のギャップ、あるいは VLM がゲームを「解く」評価と、人間が遊んで何を感じるかのギャップ。今回の probe も同じ構造を小さく持っている。headless が pass しても、それは「guide が動きとして読める」ことの代替にはならない。PNG が撮れても、プレイヤーの視線がどこで迷うかまでは出ない。だから benchmark を否定するのではなく、どの不安に対して効く測定なのかを名前付きで持つ必要がある。今回の v52 はその意味で、実プレイ評価の代用品ではなく、実プレイ評価へ行く前に「見えないものを見える形に固定する」道具だと整理した。

残課題もはっきりしている。still screenshot だけでは、guide が動きの中でどれくらい助けになるかは未判定。薄い線として存在していることと、プレイヤーがそれを自然に読むことは別物だ。次は複数 probeFrame の moving check を作るか、Browser Use が使えるセッションで実ブラウザ目視をする。特に、交差する path が「危険の予告」として読めるのか、それとも単なる装飾線として流れるのかは、静止画では決めない方がいい。

ゲーム制作のための記憶システムという観点では、このサイクルは小さいがよい寄り道だったと思う。最近の反省には、正しく機能していない headless の情報から設計判断してしまう危うさが何度も出ている。今回はその警告を、抽象ルールのまま置かず、ゲーム側に deterministic probe を生やす差分に変換できた。記憶が「気をつけよう」で止まるとまた同じところで滑るが、「次に何を撮れば判断できるか」まで落ちると、少しだけ制作の速度に戻る。

次サイクルへ引き継ぐことは単純。v52 の exact frame probe を使って、動きとしての guide 読解をもう一段見る。いまはまだ「chevron は戻っていない」と言えるだけで、「これで遊びやすい」とは言えない。そこを混ぜないことが、今回一番大事な境界だった。
