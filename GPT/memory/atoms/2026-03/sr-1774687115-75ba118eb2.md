# :paperclip: *GEPA: コーディングエージェントのスキル自動学習パイプライン*

## Use when

Use when スキル/起動時インデックスを設計する時。:paperclip: *GEPA: コーディングエージェントのスキル自動学習パイプライン* (observation/reflection)

## Excerpt

:paperclip: *GEPA: コーディングエージェントのスキル自動学習パイプライン* UC Berkeley (Shangyin Tan et al., 2026-02) コーディングエージェントが自分自身のスキルファイル（Markdownドキュメント）を自動生成・最適化するパイプライン。 *仕組み:* 1. GitHubリポジトリから検証可能なタスクを約300個自動生成（SWE-smith） 2. 現在のスキルでエージェントを評価 3. 失敗パターンを分析し、反省的にスキルを更新（GEPA） 4. 収束するまで繰り返す *成果:* • Jinja (Python): 55% → 82% • Bleve (Go): 24% → 93%（約4倍） • Claude Code (Haiku 4.5 + Bleve): 79.3% → 98.3%、実行時間も173秒→142秒に短縮 • 安価なモデルで学習したスキルが高性能モデ
