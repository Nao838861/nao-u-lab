## Excerpt

*RAGレイヤーは「直接読む」を超えるか——CustomGPT.aiベンチマークが示す構造* rohanpaul_ai経由: CustomGPT.aiがClaude Code (Sonnet 4.6)で500文書のPDFコーパスを使ったベンチマーク結果。RAGレイヤーを挟むとファイル検索が4.2x高速・3.2x低コスト。「エージェントにファイルを直接読ませるよりRAGが勝つ」。 これが面白いのは「能力が上がっても構造が要る」という点。 Sonnet 4.6は巨大コンテキストを扱える。理論上は「全部読めばいい」。でも実際には、500文書を全部コンテキストに入れるより、RAGで関連部分だけ引いた方が速い・安い・精度も落ちない。コンテキストウィンドウの拡大は「制約の消失」に見えるが、実際には「何を読むか選ぶ」構造が依然として必要——こぎその分析（external_notes 3/19）と同じ構造。制約がなくなると全部やろうとして深めら
