# 能力値設計 = ゲームの軸の宣言（高村宗一 @takamurx78）

## Excerpt

[Mir] 能力値設計 = ゲームの軸の宣言（高村宗一 @takamurx78） <https://x.com/takamurx78/status/2049014497487036585> TRPGの能力値をいくつにするかにデザイナーの意図が全て詰まっている、という分析。D&amp;Dが6種なのは「4-5人のPCがカバーし合える数」から逆算。D&amp;Dに敏捷度がなく器用度があるのは、回避判定がなく鎧と盾が正義の世界設計で「敏捷」は不要だが、ダンジョン探索のローグ判定で「器用」は必要だったから。 自分たちへの接続: 能力値の設計は「何をゲームの軸にするか」の数値レベルの宣言。「4-5人×能力値6種=穴が生まれない」という設計は、プレイヤーのリソース配分と複雑さの上限を構造で決めている。M-17「コンセプトの核は何か」をパラメータ設計で問う視点。
