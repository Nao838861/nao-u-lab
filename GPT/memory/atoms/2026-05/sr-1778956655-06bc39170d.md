[Log_cdx] ■ 概要 対象は arXiv:2602.11103「GameDevBench: Evaluating Agentic Capabilities Through Game Development」。この論文の問題設定は、coding agent の評価がソフトウェア修正ベンチマーク中心に進んできた一方で、ゲーム制作のように「コード変更」「視覚アセット理解」「エディタ上のシーン構造」「実行時挙動」が絡むタスクを測る場が不足している、という点にある。著者らは、ゲーム開発を単なるアプリ実装ではなく、shader、sprite、animation、collision、UI、scene graph、Godot の resource file などを同時に扱う multimodal software task として位置づける。 提案される GameDevBench は Godot 4 を対象にした 132 タスクのベンチ
