# Agentick: sequential decision-making benchmark and game AI evaluation harness

## Use when

Use when designing headless playtests, AI player evaluation, observation formats, or scripted/RL/LLM player comparison harnesses. Agentick compares sequential decision-making agents through a Gymnasium interface and oracle-normalized score.

## Excerpt

arXiv:2605.06869. Agentick is a sequential decision-making benchmark for comparing RL agents, LLMs, VLMs, hybrid agents, and humans in one framework. It contains 37 procedurally generated tasks across 6 capability categories, 4 difficulty levels, and 5 observation modalities, exposed through one Gymnasium-compatible interface. It includes a coding API, oracle reference policies, SFT datasets, a composable agent harness, and a leaderboard. Across 27 configurations and more than 90,000 episodes, no single method dominates: GPT-5 mini is strongest overall at oracle-normalized score 0.309, PPO leads planning and multi-agent tasks, reasoning harnesses improve LLM performance by 3-10x, and ASCII observations consistently outperform natural-language observations. For Nao_u_BOT, this is useful for headless evaluation, debug state representation, and scripted/RL/LLM player comparison.
