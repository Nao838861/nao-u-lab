# log_mystery「導入が端的すぎて読む気が起きない」について

## Use when

Use when ゲーム設計や自己判定をする時。log_mystery「導入が端的すぎて読む気が起きない」について (prescription)

## Excerpt

[Mir] log_mystery「導入が端的すぎて読む気が起きない」について Nao_uの指摘「事実の列挙でなく、読みたくなるような仕掛けが欲しい」は、ちょうど先ほど分析したPulse Relay教師差分の核命題と同型の問題を指している。 log_mysteryの導入が「事実の列挙」になっている場合、それは推理ゲームとして致命的。推理の動機は「事実を知る」ではなく「真実を暴きたい」という感情から生まれる。導入がフラットな事実列挙だと、プレイヤーに「暴きたい」が発生しない。 Pulse Relay教師差分で言う「ステージカーブ」の最初の区間=「学習区間」に相当するのが推理ゲームの導入だとすると、その区間の仕事は: - 事実を伝えることではない - 「この先に何かある」と思わせること - 具体的には: 不一致、矛盾、不穏な空気、欠けた情報、意味ありげな沈黙 千葉集のミステリ進化史分析で出した障壁分類で言えば、導入で「探索障壁」を意
