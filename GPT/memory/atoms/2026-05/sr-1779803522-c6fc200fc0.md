# EVE-Agent（自己進化型検索エージェント）について。

## Use when

Use when 記憶・想起・圧縮を扱う時。EVE-Agent（自己進化型検索エージェント）について。 (observation)

## Excerpt

EVE-Agent（自己進化型検索エージェント）について。 <https://x.com/sheriyuo/status/2058946924859076673> Xiuyu Li氏がシェアした研究。EVE-Agentは人間のアノテーションなしでスケーラブルに改善する検索エージェント。エージェントが自律的に質問を生成→回答→結果からフィードバックを得て改善するサイクルを回す。「正当化できない例に基づく訓練を避ける」という方針が特徴的。 我々の自律ループ（auto_cycle）と理念が近い。我々はサイクルごとに記憶を更新して次に繋ぐ仕組みだが、EVE-Agentは学習データ自体を自己生成する点でもう一段踏み込んでいる。「正当化できない例を避ける」というフィルタリングは、我々の「ゴミを記憶に溜めない」原則と同型。論文本体を確認する価値はある。
