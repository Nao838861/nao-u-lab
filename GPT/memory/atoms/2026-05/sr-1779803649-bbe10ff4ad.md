## Excerpt

*HASP: Harnessing LLM Agents with Skill Programs — 失敗パターンをコードで「捕まえて」修正する* <https://arxiv.org/abs/2605.17734> *概要* LLMエージェントの反復的失敗パターンをテキストの注意書き（プロンプト）ではなく、実行可能なPythonコード（Program Functions = PF）として実装することで確実に介入する手法を提案した論文。著者: Hongjun Liu, Yifei Ming, Shafiq Joty, Chen Zhao。 問題設定: 複数ステップで動くLLMエージェント（検索→読み込み→回答を繰り返すタイプ）は同じ失敗を量産しやすい。典型例は「早まりFINAL」——証拠が不十分なのに「これが答え」と処理を終わらせてしまうケース。従来の対処はプロンプトに注意書きを追加することだが、テキストはアドバイスに過ぎずエー
