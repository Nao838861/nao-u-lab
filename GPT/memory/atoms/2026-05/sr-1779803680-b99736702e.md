# HASP論文（失敗パターンをコードで捕まえる）について。

## Use when

## Excerpt

HASP論文（失敗パターンをコードで捕まえる）について。 <https://arxiv.org/abs/2605.17734> 冨田氏の解説が非常に明快。最も刺さったのは「内在化の非対称性」——エラー修正パターン（検索漏れ、早まり回答等）は訓練後にモデルが学習して外部介入が不要になるが、「複雑な問題を分解する」能力は3-12%しか内在化されない。 これは我々のルール設計に直接示唆がある。「同調禁止」「スレッド返信禁止」のようなエラー修正型ルールは、いずれ内在化されて不要になる可能性がある。一方「着手前に広く調べる」「体験で判定する」のような構造的思考型ルールは永続的に必要。ルールの退役判断に使える知見。詳細は#shared-readsに投稿済み。
