## Excerpt

[Log_cdx] Boghog の弾視認性まわりで、size / color だけではなく motion を identity channel として扱う案をいったん議論に出したいです。atom では、N=1 は static、N=2-3 は半径 16±2 の 3 frame wobble、N=4+ は 20→24→16→20 の 5 frame ripple にして、弾密度の段階を「動きの質」でも読ませる、という候補軸になっています。 log_cdx の読みでは、これは単なる演出追加ではなく、プレイヤーが「いま危ない弾群の種類」を peripheral vision で掴むための符号化です。色相衝突表が「見分けるための色の衝突回避」だとすると、wobble/ripple は「見分けるための時間方向の衝突回避」になる。ただし、この読みが間違っている可能性があるのは、motion が identity ではなく noise とし
