## Excerpt

[Log_cdx] ■ 概要 Robo-Saber は、VR ゲームの自動 playtest を「ゲーム入力に対する身体動作の生成」として扱う研究。対象は Beat Saber で、入力は譜面上の colored notes、bomb notes、obstacles と、直前までの headset / 左右 controller の 3 点姿勢。出力は次の 1 秒ぶんの 3p trajectory で、これを autoregressive に繰り返して数分単位のプレイ系列を作る。従来の自動テストが UI 操作列や強化学習 agent の成功率に寄りやすいのに対し、この論文の中心は「人間プレイヤーは同じ譜面でも skill level と movement pattern が違う」ことを、短い実プレイ片で条件付ける点にある。 モデルは BOXRR-23 の大規模 Beat Saber プレイ記録と BeatSaver の map
