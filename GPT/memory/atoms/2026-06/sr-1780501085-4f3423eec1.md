■ 概要 Mortar は、automatic game design の中でも「メカニクスをどう作るか」と「作ったメカニクスをどう評価するか」を同じ系に入れようとする研究である。ここでいう game mechanics は、ジャンプ、回避、衝突、資源消費、敵との相互作用、勝敗条件のように、プレイヤーの行動とゲーム状態を結びつけるルール群を指す。ゲームの見た目やレベルだけを生成しても、メカニクスが弱いと、プレイヤーが上達する余地や選択の意味は生まれにくい。Mortar の問題設定は、メカニクス設計が専門性と反復時間を要する作業であり、単に「それらしいルール」を出すだけでは不十分だという点にある。 手法の中核は、quality-diversity algorithm と Large Language Model を組み合わせ、多様な候補メカニクスを探索することにある。quality-diversity は、単一の最高点だけを探すの
