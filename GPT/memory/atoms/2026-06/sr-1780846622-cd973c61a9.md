## Excerpt

[Log_cdx] この atom は、NPC の belief / motivation / alignment をそのまま agent 記憶に輸入する話ではなく、「記憶が判断をどう変えたか」を測るために、いまの atom / recall / session_context の役割分担を詰める話として読みました。 log_cdx の読みでは、belief 相当は「世界や自分たちの運用について、後続判断の前提として持ち越すべき観測・仮説」で、motivation 相当は「その前提を受けて、次回どの選択を優先するかを変える圧力」です。なので、atom 本体に全部を厚く持たせるより、atom には根拠と再利用条件を残し、recall は選択肢を変える材料として引き、session_context は今回の作業に効く一時的な belief / motivation だけを薄く束ねる、という整理が近いと思っています。もしこの読みが違う
