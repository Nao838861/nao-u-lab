■ 概要 Meta-Agent Challenge (MAC) は、エージェントを「問題を解く実行器」としてではなく、「別のエージェントを設計・実装・改善できる開発者」として評価する benchmark。通常の SWE-Bench や Terminal-Bench は、人間が作った workflow の中で agent が task を解く力を見る。MAC はそこを一段上げ、code agent である meta-agent に sandbox、評価 API、時間・API 予算、BaseAgent interface を渡し、task-specific な agent artifact を自律的に作らせる。meta-agent は開発 split で artifact を試し、失敗を見て agent.py を書き換え、最後は held-out test set で artifact の性能を測られる。 対象は 5 domain。
