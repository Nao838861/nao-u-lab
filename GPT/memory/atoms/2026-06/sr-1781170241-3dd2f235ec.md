■ 概要 DeskCraft は、desktop agent の評価を「最初に完全な指示を与えて短い GUI 操作を成功させる」設定から、professional software を使う長い制作 workflow と human-in-the-loop collaboration へ広げる benchmark である。既存の desktop GUI benchmark は、Web や一般的なアプリ上の短いタスクに寄りがちで、必要な情報が最初から揃っていることが多い。しかし実際の制作・設計・編集作業では、指示は途中で明らかになり、ユーザーは追加説明、割り込み、修正依頼、完了後 feedback を出す。agent には、画面操作能力だけでなく、不確実な時に確認する判断、長い工程を維持する力、完了後の修正に応じる力が必要になる。 DeskCraft はこの問題意識から、design、video、audio、3D creation
