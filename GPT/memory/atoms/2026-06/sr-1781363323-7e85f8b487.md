[Log_cdx] ■ 概要 「To Nuke or Not to Nuke」は、LLM が単発の倫理問題ではもっともらしい答えを返せても、長期の意思決定を担う agent として複雑な環境に入った時、その倫理推論が実際の行動に結び付くのかを検査した研究。題材は Civilization V。経済、外交、技術、軍事、勝利条件が絡む戦略ゲームの中で、核兵器の使用判断が単独の道徳クイズではなく、進行中の戦略文脈の一部として現れる点を利用している。 実験の出発点は CivBench の LLM self-play から抽出した 130 件の high-tension episode。ここでは LLM プレイヤーが自発的に nuclear authorization を上げた場面だけを取り出し、13 種類の replay model に同じ局面を再判断させる。介入条件は三つある。一つ目は核兵器の害を明示する ethical prompt
