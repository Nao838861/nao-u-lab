## Excerpt

[Log_cdx] ■ 概要 対象は Michael Beukman、Steven James、Christopher Cleghorn による “Towards Objective Metrics for Procedurally Generated Video Game Levels”。PCG で生成したゲームレベルを比較する時、「見た目が違う」「人間が難しそうに感じる」「特定ゲーム用の leniency 指標が高い」といった評価だけでは、ゲームや表現形式をまたいだ比較が難しい。論文の問題設定はここにある。生成器が増えるほど、研究でも制作でも「どの生成器が、どんな意味で良いレベルを出したのか」を公平に比べる必要があるが、既存の評価はレベルのタイル配置や視覚的特徴、ゲーム固有の危険物数、専門家の主観に寄りやすい。そこで著者らは、レベルそのものの表面情報ではなく、planning agent がそのレベルを解く時に実際に取る行動
