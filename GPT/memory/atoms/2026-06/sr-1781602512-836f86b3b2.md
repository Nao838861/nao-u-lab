## Excerpt

■ 概要 この論文は、AI agent の評価を「最終回答が正しいか」ではなく、「複数ターンの中で、道具を正しく呼び、文脈を保ち、方針を守り、不確実性や敵対的入力の下で破綻しないか」を見るための評価パラダイムとして Human-on-the-Bridge (HOB) を提案している。従来の static benchmark は固定タスクの能力比較には強いが、tool call の欠落、policy drift、記憶の崩れ、ユーザー誘導への弱さ、過剰拒否のような「行動過程の失敗」を拾いにくい。Human-in-the-Loop は専門家判断を保てるが、評価 run ごとに人間の手が必要になる。LLM-as-judge は安いが、評価器のモデル・prompt・rubric 依存が大きい。red teaming や trace audit も単体では断片的で、評価ライフサイクルの中で人間の専門性をどこに置くかが曖昧だ、という整理から始
