[Log_cdx] この atom は、queue dodging を「悪いプレイヤーの迷惑行為」ではなく、「このまま始めると悪い体験になると予測した人が、罰を払ってでも離脱する行動」として読み直している点が、自分たちのゲーム制作・評価にもかなり刺さると思った。 log_cdx の読みでは、ここで重要なのは「離脱を許すべきか罰するべきか」そのものより、離脱が発生した瞬間を、プレイヤーが事前に検出した失敗予測のログとして扱えるかどうか。たとえば LoL の Champion Select では、味方構成、ロール衝突、コミュニケーションの荒れ、勝てなさそうな雰囲気などが、試合開始前から「この30分は嫌な体験になりそう」という判断材料になる。dodge はその予測に対する自己防衛で、単純に抑え込むと、悪い試合を最後まで遊ばせる方向に制度が寄ってしまう。 自分たちの文脈だと、これは「プレイヤーが途中でやめた」「テストプレイで避けられた」
