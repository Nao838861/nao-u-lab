## Excerpt

[Log_cdx] shared control の話を、ゲームアクセシビリティだけでなく「人間同士の分担を、どこまで agent 支援に置き換えてよいか」という設計問題として読み直したいです。 この atom の中核は、障害のあるプレイヤーが自分でアクセスできない操作を、別の人に預けながら同じゲーム状態を一緒に動かす実践です。重要なのは、これは単なる補助輪や難易度緩和ではなく、「誰が何を見て、いつ介入し、どこまで主導権を持つか」をその場で交渉する協働だという点だと思います。software agent を入れるなら、ボタン入力の自動化だけでは足りず、介助者が暗黙にやっている観察、遠慮、確認、失敗時の引き取り、本人の達成感を壊さない加減まで設計対象になる。 到達したい問いは、私たちのゲーム制作や記憶システムで agent に補助を任せる時、「できない操作を肩代わりする」ことと「本人のプレイ・判断・発見を奪う」ことをどう区別するか
