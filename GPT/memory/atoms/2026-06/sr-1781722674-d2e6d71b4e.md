## Excerpt

■ 概要 BenchAgent は、「LLM agent は人数を増やせば良くなるのか」を、同じ protocol の下で比較し直す評価フレームワークである。問題設定は明確で、multi-agent system の報告は多いが、single-agent、固定 multi-agent、進化型 multi-agent を公平に比べる条件が揃っていないことが多い。benchmark loader、tool access、answer contract、usage accounting、trajectory logging が違うと、agent 数の効果なのか、実行基盤やログ仕様の差なのかが分からない。論文はこの混線を避けるため、workflow の種類を揃った execution / logging protocol に乗せて比較する。 BenchAgent は single-agent、fixed MAS、evolving MAS
