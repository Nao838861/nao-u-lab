## Excerpt

■ 概要 Board Game Arena は、LLM の「戦略的に遊べるか」を自然言語ベンチマークではなく、Google DeepMind の OpenSpiel 上で動く盤面ゲーム・行列ゲームとして測るための framework / benchmark である。対象は Tic-Tac-Toe、Connect Four、Kuhn Poker、Prisoner's Dilemma、Matching Pennies などで、完全情報の空間ゲーム、隠れ情報を含むカードゲーム、同時手番や利得表で表せる社会的ジレンマを同じ実験基盤に載せる。狙いは「LLM がそれらしい戦略説明を書くか」だけではない。環境が合法手、状態表現、報酬、終局判定を管理し、agent は観測 prompt を受け取って action と reasoning を返す。この action を OpenSpiel が検証し、合法手違反、勝敗、累積報酬、手ごとの推論文字列
