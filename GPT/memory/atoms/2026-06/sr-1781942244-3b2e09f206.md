## Excerpt

■ 概要 CrawLLM は、ゲーム全体をゼロから発明する研究ではなく、固定された dungeon crawler の game template を残したまま、テーマに合わせて narrative / visual / gameplay-facing assets を一括で差し替える LLM 駆動の asset generation pipeline である。問題設定は、PCG がレベル、画像、物語、音、ルールのような単一 facet では成果を出してきた一方、複数 facet をまたいで「同じ世界の素材」に見えるよう揃えることが難しい点に置かれている。ゲーム素材は単に個別に良ければよいのではなく、カード名、敵名、部屋名、背景、タイル、アニメーション、カード絵が同じ setting / environment / epoch / visual style を共有して見える必要がある。 実験対象の CrawLLM は Unity
