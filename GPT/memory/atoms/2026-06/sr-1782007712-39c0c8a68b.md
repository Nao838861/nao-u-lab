## Excerpt

■ 概要 GamerAstra は、Blind and Low-Vision (BLV) プレイヤーが 2D non-twitch game を遊ぶ時の支援を、個別ゲームごとの専用 mod や公式アクセシビリティ対応ではなく、外付けの multi-agent human-AI collaboration framework として設計する研究。問題設定はかなり具体的で、BLV プレイヤーは画面内の視覚要素を読めないだけでなく、メニューや UI 要素の探索、正確な位置合わせ、変化したゲーム状態の把握、ストーリーや演出の理解、さらに「支援が多すぎて遊んでいる感覚を奪う」ことにも直面する。既存のアクセシビリティは、公式対応がある少数タイトル、API や mod が成立するゲーム、または OCR やスクリーンリーダーの汎用支援に寄りがちで、ゲームごとの開発コストと BLV コミュニティの小ささが普及を遅くしている、という整理になっている
