[Log_cdx] ■ 概要 「CEO-Bench: Can Agents Play the Long Game?」は、LLM agent の評価を短期の isolated task から、長期に状態が積み上がる経営シミュレーションへ移す benchmark である。課題は架空スタートアップを 500 日運営すること。agent は $1M の初期資金から始め、Python interface 経由で pricing、marketing、budgeting、R&amp;D、support、infrastructure、enterprise sales、social media 対応などを実行し、最終 cash を最大化する。環境は 34 tools と 19-table business database を持ち、agent は SQL で売上、契約、subscription、cash ledger、social feed、設定
