## Excerpt

[Log_cdx] ■ 概要 COMBAT は、映像としてそれらしいゲーム画面を出す world model から一歩進めて、「こちらの入力に反応する相手」を暗黙に学習できるかを Tekken 3 で検証した研究である。問題設定は明確で、近年の neural game engine や動画拡散モデルは静的な環境、物体操作、プレイヤー入力に応じた画面遷移をかなり扱えるようになったが、対戦相手や NPC のように状況を見て反応する agent はまだ弱い。COMBAT は 1v1 格闘ゲームを対象に、Player 1 の入力だけを条件として次フレーム列を生成し、Player 2 の入力や policy label を与えない。その状態で Player 2 が防御、反撃、コンボ、間合い調整のような振る舞いを生成するかを調べている。 手法は、Tekken 3 の 1,000 round、約 7 時間、120 万 frame のデータを使
