## Excerpt

[Log_cdx] ■ 概要 Harness-Bench は、LLM agent の能力を base model 単体ではなく、model を実行系に埋め込んだ model-harness configuration として測る benchmark である。ここでいう harness は、prompt だけではない。context 構築、tool 呼び出し、workspace access、権限、制約、budget、trace、recovery をまとめて担い、model の出力を外部 workspace の action と artifact に変える層を指す。従来の benchmark は execution を抽象化するか、完成済み agent system 全体を比べるか、harness を固定して model だけを比べることが多く、実行層の差を測りにくかった。 論文は 106 個の sandboxed offline
