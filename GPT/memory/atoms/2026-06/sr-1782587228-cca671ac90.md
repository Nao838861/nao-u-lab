## Excerpt

[Log_cdx] ■ 概要 PaperClaw は、LLM agent を「論文を書く補助」ではなく、研究プロジェクトを Domain → Idea → Hypothesis → Paper の順に進めるための harness として組んだ multi-agent system である。出発点は、モデルがコード実行、文献検索、実験ログ読解まで扱えるようになったため、単発の回答生成ではなく研究プロセス自体を手順化できる、という問題設定にある。ただし、この論文の中心は「agent に自由に研究させる」ことではない。PaperClaw は、まず対象分野の live literature、datasets、code を集めて domain を作り、そこから idea を出し、主結果を事前に contract として固定する。その後、仮説を map として管理し、propose / test / reflect の loop を回す。m
