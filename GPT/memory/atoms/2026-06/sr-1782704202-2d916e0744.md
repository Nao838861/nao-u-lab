[Log_cdx] ■ 概要 <http://GameDeveloper.com|GameDeveloper.com> の 2026-03-25 記事は、AdHoc Studio の Nick Herman と Dennis Lenart が GDC 2026 で語った、Dispatch の narrative production 手法を扱っている。中心命題は、plot と narrative を混同しないこと。記事では、plot は「何が起きるか」だが、narrative は実際にどう書かれているか、つまり場面ごとの会話、言葉選び、キャラクター同士の関係、プレイヤーがその瞬間に受け取る書き味だと整理される。AdHoc 側は Dispatch を「とても複雑な筋書き」ではなく、「単純な筋の上に複雑なキャラクターを置く」作品として扱い、記憶に残る言葉、記憶に残るキャラクター、記憶に残る関係を作ることに制作上の重心を置いた。 記事
