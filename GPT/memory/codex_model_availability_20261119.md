# VS CodeでGPT-6.2が表示されない原因調査

調査日: 2026-11-19（日本時間）。ユーザーから、再起動してもGPT-6.2が使えず、以前にも同様のことがあったため調査するよう依頼された。

## 結論

前回GPT-6.1 Solを利用するために設定した `chatgpt.cliExecutable` が、旧版 `0.159.2` の実行ファイルを指定したまま残っている。現在の拡張には新しい実行ファイルが付属しているが、この指定により旧版が起動され、新モデルの一覧が配信されない。

## 今回の確認結果

- VS Codeのユーザー設定: `C:/Users/owner/AppData/Roaming/Code/User/settings.json` の9行目。
- 指定値: `C:/Users/owner/.codex/packages/app-server-daemon/releases/0.159.2-x86_64-pc-windows-msvc/bin/codex.exe`。
- インストール済み拡張: `openai.chatgpt-26.51111.21308-win32-x64`。
- 拡張同梱の実行ファイル: `bin/windows-x86_64/codex.exe`。`--version` は `0.169.0-alpha.11.1`。
- 現在のセッションの `CODEX_VERSION` とモデル一覧取得ログは `0.159.2`。実行中プロセスにも指定先の実行ファイルが存在する。

同一のChatGPT認証・同一のVS Code識別ヘッダーで、モデル一覧API `https://chatgpt.com/backend-api/codex/models` の `client_version` だけを変えて読み取り比較した。認証情報は出力・保存していない。

| client_version | HTTP応答 | GPT-6.2 Sol / Astra |
|---|---|---|
| `0.159.2` | 200 | 両方なし |
| `0.169.0-alpha.11.1` | 200 | 両方あり、`visibility: list` |
| `0.170.0` | 200 | 両方あり、`visibility: list` |

返された両モデルの `minimal_client_version` は `0.166.0`。新版として問い合わせると現在のアカウントに一覧が返るため、今回の症状はアカウントへの配信待ちでは説明されない。APIによる一覧比較であり、6.2への推論リクエストは実行していない。

なお、`debug models --bundled` では現在の拡張同梱版にも6.2は入っていない。静的な同梱一覧だけで利用可否を判定せず、認証済みのオンライン一覧を確認する必要がある。

## 前回とのつながり

過去チャット `01a0f3c0-d58a-7762-aef3-bd7e70a96c27`（2026-09-30〜10-01、日本時間）をローカルの会話履歴から確認した。

1. 当時、6.1 SolはCLIで利用できたが、VS Code拡張では一覧に出ず、再起動・拡張更新・モデル名指定でも直らなかった。
2. 当時の拡張同梱版は `0.155.0-alpha.16.3`。同じ認証で一覧APIのバージョンを変えると、旧系列には6.1 Solが返らず、`0.159.0` 以降には返ることを当時の調査で確認していた。
3. 前回のCodexが `chatgpt.cliExecutable` に `0.159.2` の実行ファイルを指定する回避策を設定した。
4. その後、ユーザーは「6.1solが使えるようになった」と報告した。
5. 今回は、その固定指定が拡張更新後も残り、新版への移行を妨げている。

前回の詳細なAPI比較は当時の会話記録に基づく。今回の6.2の比較は今回あらためて実行した。

## 対処と検証条件

VS Codeユーザー設定の `chatgpt.cliExecutable` 指定を削除して、拡張同梱の実行ファイルを使う標準状態に戻し、ウィンドウを再読み込みする。最初の調査依頼ではユーザー設定の変更・実行中サーバーの停止・キャッシュ削除は行っていない。

対処後はモデル一覧に6.2が表示されることと、実際の取得ログまたは新規セッションの本体バージョンが旧版から変わったことを確認する。別の常駐サーバーへ再接続される場合は、接続先の版も確認する。

公式資料は `chatgpt.cliExecutable` を開発用途の上書き設定と説明し、通常は設定不要としている。

- [GPT-6.2公開案内](https://learn.chatgpt.com/docs/whats-new/gpt-62-astra-sol)
- [IDE拡張の設定とcliExecutable](https://learn.chatgpt.com/docs/developer-settings#editor-settings-reference)

## ユーザーの修正依頼への対応

同日、ユーザーから「修正して」と明示指示があったため、VS Codeユーザー設定の `chatgpt.cliExecutable` だけを削除した。

- 編集前のファイル全体を同じディレクトリの `settings.json.bak-codex-model-20261119-232808-118241` にバイト単位でバックアップした。
- 編集前後のJSONを比較し、当該キーの削除以外に設定値の変化がないことを確認した。
- 改行とBOMの有無を維持した。`config.toml` の既定モデルは変更していない。
- 設定変更は保存済み。実行中の拡張への反映にはVS Codeウィンドウの再読み込みが必要。
