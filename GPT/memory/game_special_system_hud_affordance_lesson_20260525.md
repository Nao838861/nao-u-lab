# 特殊システム HUD / 入力導線 / 記号化レッスン

このファイルは、欠落していた `memory/game_special_system_hud_affordance_lesson_20260525.md` の最小再アンカーである。詳細な判断材料は `source_atom_ids` と `fallback_recall_query` から辿る。

## 使う場面

- 特殊アクション、クールダウン、反射、変換、ダッシュ、ガード、ショット、スキルを持つゲームを作る時。
- タイトル開始入力、リトライ導線、チュートリアル、HUD を実装する前。
- 「説明を足せば伝わる」と判断しそうな時。

## 核

特殊システムは、常時文字やサイドパネル説明で教えるのではなく、ゲーム自身の入力、対象物状態、記号化で教える。

特に次の 3 状態を混ぜない。

- 発動不可
- 発動可能だが意味が薄い
- 発動可能かつ意味がある

この 3 状態が同じ見た目なら、プレイヤーは「いつ押すべきか」を読めない。

## 対象物側マーカー

プレイヤー側 HUD だけで状態を伝えると、視線がプレイヤー、HUD、戦場を往復する。効果対象がある場合は、対象物側に小さく不快でない記号を置き、視線を 1 経路にする。

例:

- 反射できる弾に小さな記号を出す。
- ロックオン可能な敵に短いマーカーを出す。
- インタラクト可能な対象だけ輪郭や短い pulse を出す。

## 入力導線

- 中心入力を 1 つ決める。
- タイトル開始、特殊入力、リトライをできるだけ同じ入力体系へ寄せる。
- タイトル画面は中心入力の安全な試打場所として使う。
- リトライ導線を画面外や小さな説明へ逃がさない。

## 禁止

- 常時長文説明で特殊システムを教える。
- サイドパネルへ重要情報を逃がす。
- 発動不可と発動可能を同じ HUD にする。
- 「押せるが意味がない」と「押す価値がある」を同じ表示にする。
- デバッグ情報を通常プレイ画面に残す。
