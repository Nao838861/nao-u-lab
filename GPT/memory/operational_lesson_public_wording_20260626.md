# 投稿文ではローカルフォルダ名を組織名のように使わない

`Nao_u_BOT` はローカルのフォルダ名であり、Slack 投稿や shared-reads の本文では環境名・組織名のように使わない。

公開投稿では「我々の環境では」「我々のゲーム制作」「こちらの headless 評価」のように、読み手に自然な表現へ置き換える。ファイルパスや source of truth の所在を示す必要がある時だけ、コード表記やパスとして `D:\AI\Nao_u_BOT\...` を使う。
