# 遠距離の段差前で走り続ける CPU の修正

ユーザー原文: 「遠距離のときに、ジャンプで超えられる段差に向かってずっと走り続けていることがあった。どういう条件でそうなる？そうなったら回避して。」

ゲーム commit `c2cd8a4`、main へ push 済み。

`ComClimbStep` はダッシュを許可していたが `ComPlannedCrossing` が `CH_FDASH` を拒否して直後に計画を取り消していた。停滞検出も歩き／立ち・上位難易度のみだった。SHION ULTIMATE の左右・高さ2000/4500で600フレーム跳ばない状態を再現。

計画ジャンプにダッシュを許可。全難易度で接近失敗を検出し、遠距離（5500以上）の安全な段差前で同じ500以内の範囲に60フレーム停滞した場合、既存の軌道予測による一段／二段ジャンプを行う。短い停止・攻撃を挟んでも履歴を保持し、移動・方向変更・近距離・空中／被弾／ダウンでリセット。爆弾・落下の回復優先は維持。

全4キャラ×全5難易度×左右×高さ2種×立ち／ダッシュの160ケースで、開始時86成功から160成功へ。全ケースで復元後ハッシュ一致。今回のstage済みファイルだけの独立ビルドも160成功。既存段差越え48ケースと床・落下・受け身チェック合格。EdgeでSHIONのダッシュ→二段ジャンプ→着地を確認。対戦勝率の不変は測定していない。
