# CPUの未使用技を適切な場面で見せる

ゲーム側commit: `cafdd401d86ba35bb7236415a8e7d5daed788e69`、mainへpush済み。

依頼は全キャラの未使用・低頻度技を、単発・コンボ・派生として適切な場面に入れ、勝率低下を抑えること。前の「強化ではなく、NORMAL以上で時々攻略例を見せる」を継続。原文はゲーム側 `faithful/docs/cpu-moves-20260908/design_log.md` に保存した。

`com_moves.h` で24種類の選択と箱空中Hの方向分岐を追加。下前H／下H／前H、弱強必殺、対空弱サマー、空中L系・上H、ダッシュ、ガードへの投げ、適切な超必殺、箱とブーメランの技。弱強必殺は実測基礎ダメージ比REI5:8、SHION11:16、KAI26:26、GOU17:26。空中Lは実ヒットからH、KAI上Lは弱サマー。SHION通常Lは早い上Hにし、既存の未コミットの通常H強化に依存しない。不安定な相手／方向の組み合わせは単発で止める。

NORMAL～HARDESTは機会20%、ULTIMATEは途中2組で約3ポイント低下が続いたため10%。外れ90tick、開始後は従来の紹介と共通600tick待つ。重なる機会は新旧どちらを試すか半々に分ける。EASYは変更なし。既存の紹介機能を無効にした下位難易度では新規紹介も止める。ULTIMATEを含む今回の追加だけのON/OFFには `jou_test_cpu_moves` を使う。

最終同一ビルド比較は各設定704戦、全11ステージ・4対4・左右入替・2seed、相手は同難易度の追加OFF。NORMAL303→327勝（+3.41ポイント）、HARD316→313（-0.43）、HARDEST335→339（+0.57）、ULTIMATE340→348（+1.14）。SHION/ULTIMATEは79→71勝（各176戦）など個別低下が残り、全員が強くなったとは言わない。新規選択が出る試合は順に185/704、170/704、108/704、81/704。

別の使用調査は各設定704戦、4難易度・4対4・全ステージ、左右固定。手入力で識別した158モーション中、観測139→143。キャラ別はREI34→35/40、SHION34→35/39、KAI33→33/38、GOU38→40/41。今回一覧の素手基本技は全キャラで実戦観測。未観測は主に武器の特定姿勢と手榴弾L。モーション経路の存在と有限標本での観測を区別し、完全網羅を主張しない。

1,424局所条件の実発動・命中・相手回復前の追撃、128,160tick復元、ガード／空振り32条件、開始版との198,000tick一致、旧紹介2,304条件、安全検査、ブラウザ画面を確認。stageしたソースだけの独立ビルドも1,424条件通過。既存未コミットの技・AI変更は保持し混ぜていない。勝率表はそれらを含む作業ツリーの結果。詳細・raw・ソース差分・ハッシュは `faithful/docs/cpu-moves-20260908.md` と同名フォルダ。

技使用集計は状態番号だけでは不十分。同じ番号の弱強／上下／武器を分ける `jou_player_motion_id` と、ビルドごとに再生成する手入力一覧を使う。ポインタ値はビルド間で対応づけない。`jou_test_set_airborne` は武器を外すので、武器の空中条件では配置後に持たせる。ヒットストップ中の一度だけの入力は消えるため、合法な派生開始まで保持する。
