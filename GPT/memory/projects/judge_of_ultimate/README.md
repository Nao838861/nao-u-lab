ユーザーはCPUの強化を主目的にせず、プレイヤーに「こんなこともできる」と低頻度で見せ、攻略やゲームの幅を楽しんでもらう方針を明示。NORMAL/HARD/HARDESTには全キャラの下L・実ヒットからのコンボ・投げ成功後の追撃・状況別の動きを、機会20%で一つずつ追加した。外れたら90tick再抽選せず、開始後は全種類共通で600tick（約10秒）次を始めない。途中のコンボ分岐は前述のダメージ比を使う。

CPUレベルは昇格させず、選んだ行動の呼び出し中だけ利用資格を渡す。ULTIMATEの防御・反応速度まで移植しない。EASYとULTIMATEは従来通り。追加を無効にした下位3難易度を含め、開始版と198,000tick一致。全対象難易度の接近/コンボ/投げ後2,304条件、状況別768条件、独立ビルド、NORMAL全キャラの画面を確認。
