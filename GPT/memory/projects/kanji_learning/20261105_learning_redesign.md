# 漢字学習アプリ：遊びの操作と記憶の再設計

設計相談中。採用仕様ではない。新しい学習方式の実装・公開は止め、目的と操作の対応を検討する。

## ユーザーの指摘原文

> 遊んでて思ったのは「読めるのに書けない」タイプの人には、読めるから雰囲気で組み立てられるが、それは読むときに使ってる既知の情報を使って組み立てているだけで、記憶に入れるのではなく単に見た目で組み立ててるだけなので、このやり方では記憶には残らないと思った。

> 「部品の候補も見本も隠して「何を、どこに置くか」を頭の中や言葉で思い出す。」ってのはアプリではなくあそんでるプレイヤーがやる事？

> 先にどうやればいいかを考えよう。アプリを無心に遊んでるだけで覚えれるのが理想

## 目標の読み直し

本人が「ここから暗記」「ここから想起」と学習を管理しなくても、遊びを進める操作の中に、漢字の部品・配置・細部を記憶から出す機会を含める。

候補を見て形を照合できることを、自由な再生や書字の成功と取り違えない。候補式の遊びが一切学習にならないとは断言しないが、現状の正答率から手書きへの効果は判断できない。

「頭の中で思い出してからボタンを押す」という自己申告方式は採用しない。思い出した内容が操作として出力されないため、実施・正確さをアプリで確認できず、今回求められる遊びへの組込みとして弱い。

## 検討中の共通構造

1. はじめは形を見せ、部品と配置を知る。
2. 同じ操作のまま、見える情報を少しずつ減らす。
3. 見えなくなった線・部品を、プレイヤー自身が出力して完成させる。
4. 別の問題を挟み、時間を空けて同じ字の再構築を要求する。
5. 失敗したときはヒントを戻し、成功に応じて再び減らす。ヒントを読まないことを罰にしない。

アプリが担うのは、問題の提示、手がかりの段階調整、生成された形の確認、後日の再出題。プレイヤーが担うのは遊びの直接操作であり、学習の手順の自己管理を求めない。

## 案A：消えた部品を直す遊び

仮称「漢字の修理工房」。指・ペンで短い線や部品を画面に描く操作が許容される場合の案。

「材」を見る→一画が消えるので直す→別の問題を挟む→右の「才」が丸ごと消えるので作る→後には漢字の見本もなく、読み・意味から必要な部品を出す。

描いた線が部品にはまり、部品の完成が漢字の完成へつながる。大きな書き取りを何度も課す構造にせず、短い補修から始める。きれいさを細かく採点するより、必要な線・部品・配置の確認を優先する。合体そのものの反応を気持ちよくし、無関係なミニゲームの前提作業にしない。

懸念：一画の補修だけなら、残った形から推測して解ける。徐々に見本全体を外す工程まで必要。描く操作に抵抗がある子には合わず、認識の誤判定も楽しさを損なう。この方式の学習効果は未検証。

## 案B：基本の線から部品を作る遊び

タップ・ドラッグだけに限る場合の案。完成した「木」「才」の選択肢は出さず、横線・縦線・はらいなど共通の線材を組んで部品を作る。

対象の完成形を候補から見つける操作から、どの線が何本・どこに必要かを自分で構成する操作へ移す。見本は段階的に減らす。

懸念：指で描くより操作が多く、線材の扱い方を別に覚える負担が生まれる。手書き動作への接続も直接的ではない。全字をこの方式で作らせると工作の手間が大きいため、苦手な部品に絞る案を検討する。

## 案C：組み立て・比較だけで覚える遊び

現在の部品パズルに、似た部品の差、誤字の修理、時間を空けた再登場を加える案。操作は最も気軽。

懸念：候補や残った字形を手がかりにした照合でクリアし続けられる。自由な出力を求めないまま、書字に必要な想起の訓練が成立したとみなさない。学習の導入や苦手箇所の発見には使えても、これだけで目的を達成したとは扱わない。

## まだ決めないこと

- 画面に短い線や部品を指・ペンで描くことが許容されるか、ユーザーへ質問中。紙を使わない条件は維持する。
- 世界観やコイン・図鑑の強化は、学習につながる中心操作が決まってから考える。
- 「無心に遊べば必ず覚える」という効果は保証しない。本人が暗記を意識せず遊べるかと、実際に後日出力できるかを分けて観察する。
- 操作修正の途中差分は未公開。今回の設計相談中は新しいアプリ版を公開しない。

## 調査した一次資料

- [勝二（2021）認知特性と書字エラーに基づいた書字困難児への漢字書字指導](https://www.jstage.jst.go.jp/article/ninchishinkeikagaku/23/1/23_19/_article/-char/ja/)：抄録確認。小学4年生・9歳の男児1名の支援で、字形の保持状況に応じて正字選択の確認課題と組合せパズル課題を使い分け、書字の改善を報告する。パズルを無効と一括りにはできないが、1事例であり、今回のアプリの有効性や無意識の学習を証明するものではない。
- [加地（2012）未知漢字の記憶における書字動作の効果](https://www.jstage.jst.go.jp/article/jjet/36/Suppl./36_KJ00008609762/_article/-char/ja)：抄録確認。大学生47名による未知漢字の形態・意味の学習では、書字が目視を一律に上回る結果ではなかった。小学4年生への直接適用はできず、「描かせれば自動的に覚える」という単純化を避けるための反証として扱う。
