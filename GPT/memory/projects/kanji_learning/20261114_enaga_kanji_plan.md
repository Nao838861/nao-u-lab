## 一言で

おぼえた漢字の数だけシマエナガが集まり、森がにぎやかになっていく漢字アプリ。学び方は「ひらがなの部品名で唱えてから、自分で形を思い出す」。雰囲気と続ける仕組み（シマエナガ・しょうごう）はけいさん団子と揃える。

## 学び方（前の工房から引き継ぐ考え方）

コードは引き継がないが、ユーザーとやりとりして決めた学び方は守る。

- お題（「労□者」と読み、タイトルの書式）→ ならび方 → **ひらがなの部品名を書き順に唱える** → 形を出す（12個の部品から選ぶ／ペンで書く）
- 「選ぶ／ペン」はいつでも切り替えられ、切り替えても途中の状態が消えない。最後に使った方を覚える
- ヒントは場所ごとに段階的に開く（なまえ → 形 → 書き順）。そこからその部品の練習へ行き、終わるとお題へ戻る
- 部品の練習：形 → なまえ（6択）→ 形（12択／ペン）。部品クイズでは一般の部首名を補足する（いう（ごんべん））。なまえの選択肢には付けない
- 出題は光村図書の順。「いまここ」から、おぼえた字を飛ばして3文字ずつ。ずかんで選んだ字からも始められる
- **「おぼえた」はヒントも見本も使わずにクリアしたときだけ**
- 学習中は時間を計らない

## 画面

全画面：雪の森の背景、まるいシマエナガ、BIZ UDゴシック、水色/ピンクの配色（けいさん団子の `drawEnaga` / `drawBg` を元に描き直す）。1280×720 の枠に収め、iPad でも PC でも同じ配置にする。

### タイトル＝かんじの森

- 森そのものがタイトル画面。おぼえた字の数に応じてシマエナガが枝にとまっている。森の中で字を覚えたシマエナガが、その字の札を持っている
- なまえ（ボタンで選ぶ／新しく入れる）→ 学年 → 「いまここ：1学期② の『辞』から」
- 大きいボタン3つ：**かんじを つくる**（3文字）／**ぶひん れんしゅう**（3部品）／**かんじ団子**（おぼえた字が10字になるまでは「あと○字で あそべる」と鍵つき）
- 小さいボタン：ずかん／しょうごう（NEW の件数つき）／音

### 学習画面

- 問題（お題・唱え・枠・12候補）は大きく真ん中に。左下に「きみ」（考え中は首をかしげ、正かいで喜び、まちがいでも「おしい！」の顔）、下に団子の枝
- 1回目で正かいするとシマエナガが1羽枝に飛んでくる。ヒントを使って正かいしたときは小さい子エナガ
- 3文字おわったら**まとめ**：きょう つくった字、とまったシマエナガ、新しい しょうごう、「つぎの3文字」／「森へ もどる」

### ずかん

- 漢字を先、部品を後。漢字は本体を大きく、読みは小さく
- 3段階：まだ＝押したくなる白いボタン／あとすこし＝うすい黄色／おぼえた＝若葉色のシール＋花丸＋小さいシマエナガ
- 教科書の回（1学期①…）ごとの見出しとメーター。回をぜんぶおぼえると見出しにシマエナガの家族がならぶ

### シマエナガの数（森の育ち方）

- 位ごとの表示（1羽／マフラー／王冠／大きい王冠／光の輪）はけいさん団子と同じ。森の画面から開く
- 増え方（案）：1回目で正かい1羽／1字おぼえた+10羽／教科書の回をぜんぶおぼえた+30羽／かんじ団子クリア+10羽・ノーミス+10羽。ヒントつきの正かいは子エナガがとまるが数えない
- 狙い：「急いで当てる」より「自分で思い出す」「おぼえ切る」が得になるようにする

## しょうごう（案、60こ前後）

まだのものは名前が「？？？」で条件だけ見える。名前の並び（ぼうけんしゃ→ゆうしゃ→大まおう、スーパー/ハイパー/…/ゴッドエナガ）はけいさん団子と揃える。

| 分類 | 例 |
|---|---|
| おぼえた字の数 | 10/30/50/100/200/…字 |
| 教科書の回 | 「1学期① クリア」、学期ぜんぶ、学年コンプリート |
| 一発で正かい れんぞく | 10/20/50/100/…（ゲームをまたぐ。ヒント・見本を使った問題では増えも減りもしない） |
| ペン | ペンでおぼえた字 10/50/100 |
| じぶんで思い出す | ヒントなしで1回3文字をぜんぶ |
| ぶひん | なまえと形の両方できた部品の数 |
| まいにち | 遊んだ日数・連続日数 |
| エナガ | あつめた数（けいさん団子と同じ段階） |
| かんじ団子 | はじめてクリア、ランク、ノーミス |
| とりかえす | にがてに戻った字をもう一度おぼえた |

## かんじ団子（タイムアタック）

- 出題：その学年で「おぼえた」字から10問。最近まちがえた字・しばらく出ていない字を多めに
- 1問：お題 → 12個の部品を唱えの順にタップして組む
- まちがい：その部品に×がついて続ける。タイムは止めない
- ゴースト：自分のベストと並んで走る。ランク E〜SSS は仮の基準で始め、実際のタイムで合わせる
- カウントダウン・BGM・ファンファーレはけいさん団子と同じ系統。BGM はこのモードだけ
- **にがて戻し**：まちがえた字・時間がかかった字は「おぼえた」を外して出題に戻す（ずかんでは「あとすこし」）。日をあけた復習の役目。責めずに「もう一回 つくろう」と出す

## 記録

- localStorage `enaga_kanji_v1`。`names[]` と、なまえごとに 学年・学年ごとのいまここ・漢字/部品の記録・シマエナガの数・しょうごう・れんぞく・かんじ団子の記録・選ぶ/ペンの設定
- 筆跡は保存しない
- 「きろくを けす」：森の画面の目立たない文字リンク。なまえ／学年を選ぶ → 消えるものを見せる → 「もとに もどせません」→ なまえを打ちこんだときだけ消せる。どの段階も「やめる」が初期フォーカス

## 気をつけること

- ごほうびが学びを食わない：シマエナガの演出は1秒以内で、次の操作を止めない。ヒントを損に感じさせすぎない（ヒントでも子エナガはとまる）
- 6択の総当たり：1回目で正かいしたときだけ数えるので、当たるまで押しても得にならない
- 1280×720 の中で、問題・枠・12候補を一画面に収める。「きみ」と団子は余白に置く
- iPad：ペンで書いている間に画面がスクロール・拡大しないようにする。PC：マウスでもペン欄に書けるが、選ぶ方を初期にする
