変更対象は `player.py` のみ。`Player.set_bg_at_mouse(tile_number)` は画面座標をカメラ経由でワールド座標に変換し、BGの原点とタイルサイズから対象セルを求める。空白は既存の `bg.EMPTY`（-1）。`BG.set_tile()` を使うことでセルのHPも既存仕様に従って初期化される。画面外・マップ外・BGなしでは変更しない。
