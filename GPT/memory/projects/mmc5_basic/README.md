# MMC5 BASIC コンパイラ

ファミリーベーシックに高いソース互換性を持ち、6502機械語へのコンパイルで高速に動くBASIC環境の設計。

- [初期設計書](design_20260916.md) — 言語互換性、コンパイラ、MMC5メモリ配置、実行環境、検証計画、段階的な実装範囲。
- 現在は設計段階。コンパイラ、ランタイム、動作ROMは未実装。
- 初期案はPCでコンパイルしてMMC5 ROMを出力する方式。本体上で編集・コンパイルする方式も将来構成として記載。ユーザーによる方式の確定前の提案である。

## 依頼原文

> ファミコンのMMC5で動くBASICコンパイラを作ってほしい。ファミリーベーシックに互換性の高いBASICを、MSXべーしっ君のようなBASICコンパイラで高速に動かすのがコンセプト。まずは設計をしてみて。
