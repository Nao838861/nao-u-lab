# シューティングサンプルの1画素差タイル統合・実現性

2026-10-05。依頼は8×8内で1画素だけ異なる後続タイルを最初の絵へ統合し、後続を削除して番号を詰める処理が可能か、現実的な時間で実行できるかの確認。

## 実測

この表は1点の星を保護する前の比較値。現行条件と再計測は次節を参照。

非破壊の比較ツールは `GPT/tools/analyze_bg_near_tiles.py`。色番号0〜3の64文字列を比較し、番号の昇順で既に残した絵だけを検索する。各画素を他の3色へ変更した192候補を辞書検索し、該当する残存タイルの最小番号を選ぶ。全組合せを比較しない。今回の計測では同一絵（差0）も統合対象に含む。

|対象|元の枚数|残る枚数|同一絵の統合|1画素差の統合|比較時間|
|---|---:|---:|---:|---:|---:|
|保存済み `build/basic_only/game/assets/stage.bg.json`|31,993|25,630|2,520|3,843|1.6348秒|
|配布原本 `experiments/single_basic_console/game/assets/stage.bg.json`|30,637|24,455|2,480|3,702|1.5403秒|

2件を並行実測した値。JSON読み込み・参照確認込みで保存済み版1.745秒、配布原本1.6134秒。保存済み版は6,363枚、約19.9%減。ROM上の容量削減・実行速度の改善は未計測であり、この枚数は編集原本の候補数。

詳細は同じフォルダーの `bg_near_tiles_saved_20261005.json` と `bg_near_tiles_sample_20261005.json`。入力SHA-256、候補例、保護番号、参照状況を保持。

## 現行条件：1点の星を除外

追加依頼「一点だけの星は一旦除外できるかな？」に対応し、非ゼロ色の画素が1点だけあるタイルを1画素差統合から除外した。統合元・統合先の双方に適用し、空白への消失、別の色への変化、2点の絵との統合を防ぐ。完全一致の重複は最初の同じ絵へ統合するため、表示は維持される。

ツールの既定値を星保護ありへ更新。前回条件を再現する場合のみ `--allow-single-pixel-merges` を付ける。

|対象|元の枚数|残る枚数|同一絵の統合|1画素差の統合|比較時間|
|---|---:|---:|---:|---:|---:|
|保存済み版|31,993|25,788|2,613|3,592|3.4314秒|
|配布原本|30,637|24,613|2,566|3,458|3.2430秒|

保存済み版は1点タイル251枚を対象に保護し、削減候補は6,205枚、約19.4%。前回から158枚分の削減を見送る。再計測の入力SHA-256は前回と一致。2件の並行実測であり、時間差の要因は切り分けていないが処理は数秒で終わる。

詳細は `bg_near_tiles_saved_keep_stars_20261005.json` と `bg_near_tiles_sample_keep_stars_20261005.json`。星と空白の両方向、星の色違い、星と2点の両方向、完全一致の統合を確認した。また200タイルの固定乱数入力で、星保護あり・なしの双方について総当たり比較との対応表一致を確認済み。原本への適用はまだ実行していない。

## 適用時の方針と未実施部分

- 「最初」はタイル番号の昇順。削除した絵を中継した連鎖統合を避け、最終的に残す絵との差を0〜1画素に収める。
- 保護タイル0、1、16、17は削除しない。1点の星は完全一致以外の統合から除外する。
- 画素はパレット内の色番号で比較。ブロック各区画のパレット番号を維持する。実表示RGB同士の比較ではない。
- 各マップの `block_defs[].cells[][0]` にある参照と `preview_palettes` を番号対応表で更新し、残存タイルを詰める。実装では疎な参照や特殊用途も検査する必要がある。現在の2原本に、定義のないタイルへのブロック参照はない。
- 同一絵・1画素差・最初の残存絵・保護番号維持・非推移的な統合を小さな合成入力で確認済み。
- 今回は実現性確認と比較のみ。画像原本、配置、BASIC、ROM、エディタは変更していない。番号再配置・参照更新・バックアップ・再ビルド・実画面照合はまだ実行していない。

現行本流には別作業の未commit差分が多数ある。比較ツールと本記録はGPT側だけに保存し、本流の既存差分は触らない。
