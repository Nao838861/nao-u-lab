# 星を保護した2画素差統合・実適用

2026-10-05。ユーザー原文：「もう星意外に1ピクセル差は残っていない？残っていないなら、また星を除いて2ピクセル差も統合してほしい。」

保存済みB版・B版再生成原本・基礎サンプルで、星を除く1画素差の候補0を確認してから2画素差統合を実施。星は前回どおり非ゼロ画素が1点だけの絵。統合元・先の双方を保護し、最初の残存絵へ直接統合する。

- 保存済みB版と再生成原本：25,788→23,204枚、追加2,584枚（10.02%）減。最初の31,993枚から累計27.47%減。
- 基礎サンプル：24,613→22,174枚。全3原本で適用後の1・2画素差候補0を再確認。
- 今回の道中表示差：破壊前5,108画素（0.20444%）、破壊後5,220画素（0.20892%）。今回の直前版との差は8×8内で最大2画素。
- 最初の原本からは前回分が累積し最大3画素。破壊前8,938画素（0.35773%）。この比較は別画像として保存し、今回の2画素差判定と混同しない。
- `famibasic/bg_optimize.py` とCLIに `max_difference` / `--max-difference 2` を追加。既定は1。3分割の一致索引と2ビット画素の整数比較で、2画素差を高速検索。
- 28テスト成功。準備後のBASIC・固定アドレス・構造化表・素材表の接続・音楽・スプライト一致。前後ビルド成功。通常ROMは候補と一致。前後各1,200フレームの自作コア実行で通常プレイ画面へ到達、最終CPUレジスタ・サイクル数一致。全編性能・実機は未検証。
- 通常ROM SHA-256：`7d347b9c5830e094536c10e2085adfaf9d3915d16733c795966199c798579799`。ROMサイズは固定1,572,880 B。
