2026-10-05。ユーザー原文：「次は星を除いて3ピクセル差も統合してほしい。」

前回の2画素差統合済み原本を対象に、非ゼロ画素が1点だけの絵を統合元・統合先の双方で保護し、最初の残存絵へ直接統合した。後続タイルを削除して番号を詰め、全マップのセル参照とpreview_palettesを更新した。保護番号0・1・16・17、部品属性、配置、配色は維持した。

- 保存済みB版・再生成用B版原本：23,204→21,367枚。追加1,837枚、7.92%減。最初の31,993枚から累計10,626枚、33.21%減。
- 基礎サンプル：22,174→20,469枚。追加1,705枚減。
- 1点の星158種類を全3原本で保持。処理前の1・2画素差候補は0。処理後の星を除く1〜3画素差候補も全3原本で0。
- 今回の道中表示差は破壊前7,209画素（0.28853%）、破壊後7,875画素（0.31518%）。直前版との8×8内の差は最大3画素。最初の原本からの累積差は最大6画素。
- 文字も統合対象のため、タイトルの「PRESS」のPがFに近い形になる。固定画面の比較にも明記した。星以外の小さい絵が空白へ統合される場合もある。
