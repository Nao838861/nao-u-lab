# ボス時間ボーナスを100点ずつ移す演出（2026-10-05）

ユーザー指示原文:

> タイムボーナスの加算は100点単位にして、加算時にプルプルみたいなスターフォースなどのファミコンのゲームでよくあるボーナス加算音も慣らしてほしい。加算時は、ボーナスの点数の方も順に減らして。減らす前に何点なのかわかるくらい見せてから減らす必要があるが。

現行は最初に90フレーム（約1.5秒）獲得額を見せ、1フレームに100点をTOTALへ移す。同時にTIME BONUS残額を100点ずつ減らす。矩形波2の短い音程変化 `BONUS_COUNT` を4加算ごとに繰り返し、通常完了・早送りで停止する。最初の待ち後はA／STARTの新しい押下で残額0・最終TOTALへ早送り、離して再押下すると進む。最大30,000点の移動は約5秒。

報酬計算は5秒以内30,000点、以後1秒ごと1,000点減、最低5,000点を維持。実スコアとハイスコア保存は結果入口で一度だけ更新し、演出中は表示値だけを動かす。999,900点で飽和しても残額は最後まで減る。
