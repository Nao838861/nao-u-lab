# ボス背景へ流れる星の追加（2026-10-05）

## 依頼と採用

依頼原文:

> ボス戦の背後にスクロールする星をスプライトで流してほしい。画面が真っ黒になったあたりから出し始めて、ボスがBGで背景が真っ黒なのが誤魔化せるように。とりあえずギリギリ処理落ちしないくらい、ちょっとくらい処理落ちしてもいいので何個くらいだせるか試してみて。背景の星の密度よりは落ちるが、なるべく違和感の内容に真っ黒が気にならないように繋いで。星はスプライトの数が足りなくなったら消えるような形で、演出として追加してほしい。

本流のSIDE ART B版へ追加した。道中の自動スクロールは縦下方向、横は自機追従なので、星も下へ流す。道中末尾のCAMERA_HI=0に入る最後の256フレームから候補数を徐々に増やす。上限24個・ボス戦の実測最大20個を採用。ゲーム用OAMを優先し、混雑フレームは星を消す。BGボスの非透明画素より後ろ、HUDには重ねない。

実装と検証の正本は [プロジェクト側の記録](D:/HomeBrew/FamiBASIC_Turbo_main/docs/boss_sprite_stars_20261005.md)。画像は同じdocs下の `media/boss_stars_20261005/`、JSON証拠は `benchmarks/boss_stars_20261005/`。
