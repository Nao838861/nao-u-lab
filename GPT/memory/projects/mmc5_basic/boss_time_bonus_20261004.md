# ボス時間ボーナス（2026-10-04）

最新依頼の現行仕様は、5秒以内MAXの30,000点、以降1秒ごと1,000点減、最低5,000点。5秒超の端数を切り上げ、30秒以降は下限。前の50,000点・0.5秒間隔の指定は今回の依頼で置換された。

- 登場演出終了（AZ 0→1）から致命傷までのNMI実時間を測り、撃破演出を除外する。
- 撃破時に報酬を確定し、クリア結果で一度だけ加点→桁変換→ハイスコア保存。TIME BONUS欄にも表示する。
- RAM4の26968～26975、8バイトを使用。経過1800フレームで飽和、時計下位8ビットの差分を積算。報酬のbit7を加算済みフラグに共用。既存の新ゲーム初期化範囲で消去。
- 本体BASICのWORD得点は100点単位。30,000点をBYTEのHIT_AMOUNTへ入れず、SCORE_VALUEへ300単位を直接加算する。999,900点上限を維持。
- 2048行・512変数を維持し、新しいDIMはない。分岐先ではない直列行のみを結合。計測BANK 4・撃破計算BANK 5はボスと同じBANK対。
- 固定画面CHRでは数字48～57のみ固定。32番はD字形だったため、結果数値の先頭空白を空タイル0へ修正した。
