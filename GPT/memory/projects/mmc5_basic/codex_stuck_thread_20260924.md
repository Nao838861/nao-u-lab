## 閉じる操作と停止の区別

インストール済み拡張のパネル終了処理は表示・通信の片付けをしており、`turn/interrupt` は別のAPI。スレッドタブを閉じたことだけで実行停止を保証しない。

公式App Server仕様でも `thread/unsubscribe` と `turn/interrupt` は別。現在の資料では最後の購読解除後、購読者も活動もない状態が30分続くとメモリからアンロードする。これはApp Serverの仕様であり、すべてのUIの閉じる操作やインストール版のタイミングを保証しない。

この構成の「サーバー」はPC内にも存在する。推論はOpenAI側、コマンド実行・スレッド管理・履歴保存はローカル側という分担で、画面を閉じるだけでクラウドの独立タスクへ移るわけではない。別ウインドウで履歴が見えることと、同じ実行プロセスを共有することも区別する。

一般の実行中スレッドを確実に止めたい場合は停止操作と完了・中断の確認を行う。VS Codeウインドウ全体の終了・再読み込みは同じ拡張ホスト上の別作業にも影響し得るため、他の作業が落ち着いてから行う。外部へ起動済みの独立プロセスやクラウド委任タスクまで止まる保証はない。
