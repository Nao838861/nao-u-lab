# EASY/HARDの実装とモード別ハイスコア（2026-10-05）

## 依頼原文と確定した仕様

> EASYモードを実装してほしい。現状をHARDモードとして、タイトルから上下で選んで始める。モードを切り替えるとハイスコアもそのモードのものに切り替わる。タイトル画面にハイスコアも出して。
> イージーモードの違いは、
> - ダメージを受けたときに、武器がなくなるのではなく一段階弱くなるだけ
> - ダメージで武器がなくなった時には、持っているなら自動で次の武器に切り替わる
> - 敵が弾を撃つ頻度を大幅に下げる。
> - 敵の弾の画面内最大数が半分(ボスは除く)
> - ボスの耐久値が半分
> この仕様で実装してほしい。疑問点があれば実装前に質問して。

追加回答：

> 1ははい、後、発射頻度の適切なmaxも決めて。値は任せる。
> 2は、真ん中の砲台の3方向弾を自機に向かってきそうな1発だけへらして。

EASYの道中射撃は有効な機会の4回に1回、1体につき最短32 NMIフレーム（約0.53秒、最大約1.875発/秒）。敵ごとに間引き位相をずらす。画面内上限4発、HARDは従来の8発。ボスの上限24発と通常の発射頻度は維持し、中央2基の3方向パターンだけ各1発の自機狙い弾へ変更した。4砲台HP33・コア36、HARDは66・72。

被弾は選択中の武器Lv2→Lv1→なし。なくなったら既存B操作と同じ循環順で次の所有武器へ切り替える。HARDは従来の選択武器全消失・通常弾に戻る動作を保持。初回はEASY、タイトル上でEASY・下でHARD、A/STARTで開始。再挑戦は選択を維持する。

## メモリと実装上の注意

選択モードは共通RAM2025（`$07E9`）の1バイト。1768付近はカメラ用、1773付近もコンパイラのZP退避と衝突するので使わない。道中RAM0の24779〜24796に敵9枠の射撃状態18バイト。タイトルは既存RAM4の30464から160バイトの転送バッファを使い、HIGHの数字とカーソルを更新する。

HARDの従来記録RAM3 `$7CF0..$7CFF` を維持し、EASYは `$7CE0..$7CEF` に追加。各モード8バイト記録2枠・チェックサム・最後に確定マーカーを書く方式。広域BANK用リンカの作業領域を16バイト縮め32バイトを保存専用にした。狭域構成までの一般保証にはしない。

実入力でEASYの有効記録を読み直してRUNすると、NMIが旧MMLのRAM4音源状態を誤読してrangeエラーになる問題を捕捉した。ゲーム開始時のWORKBANK4によるハイスコア読出しより前に `WORKBANK 0:BGM STOP:SFX STOP` を行い、現行音源を初期化して解消した。共通バンク切替・RUN処理を変更する必要はなかった。タイトルの入力経路は20280の分岐先を20305へ修正して新しい上下処理を通す。単なる静的タイトル描画では、この2点を検出できなかった。

行上限対策は副作用のない連続IFガードの同一出口をORへまとめるもの。呼出し・割込み入口やSTICK/STRIG/RND等を保護し、両モードで実機相当の生成6502と全編を検証した。
