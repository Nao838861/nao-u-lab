# PCエディタのサイズ・F5表示方式の確認

## ユーザーの依頼原文

> FamiBasicエディタの全体の仕様について検討したい。フルHDのモニタで使いやすくするのを前提にしたい。いま、デフォルトサイズはそのくらい？また、以前はF5で実行時に右端に画面が出たが、今はフローティングウインドウのみになってる。これはこれでよいと思っているが、ここっていつの間にか仕様変更した？

## コード・履歴で確認した現状

対象は `D:/HomeBrew/FamiBASIC_Turbo_main`。確認時HEADは `364ce45`、fetch後mainとorigin/mainの差分は0。既存の他作業の未commit差分があるため、本体は編集していない。

- `famibasic/editor.py:28` の初期サイズは1140×820、最小980×720。最大化やフルHDの作業領域への自動調整はない。`editor_workspace.py` のレイアウト復帰も1140×820へ戻す。
- プロジェクトを指定して起動すると、`editor_workflow.py:57` の `restore_display()` が保存設定を使い、未設定時は別ウインドウ・2倍を選ぶ。確認した利用者設定 `C:/Users/owner/.famibasic_turbo/desktop.json` も別ウインドウ・2倍。これはプロジェクトを指定しない起動や新規作成を含む全経路への一律の保証ではない。
- 別窓の2倍は映像512×480、3倍768×720、4倍1024×960。枠・タイトルバーは別。通常はSDLによるVSync描画、IDE内はTk描画。
- IDE内の右端表示は現存。表示メニューの「IDE内ゲーム画面を表示／折りたたむ」でパネルを出し、その中の表示先を「IDE内」に切り替えられる。
- 終了時に表示先・倍率を保存する。分割・選択タブ・ソース位置などのプロジェクト別復元はあるが、主窓のサイズ・位置・最大化状態の復元は実装されていない。

## 追加指示原文

> 右端表示  は仕様から消そう。デフォルトは三倍サイズにして。サイズはエミュレータウインドウのメニューから変えられるようにしてほしい。エミュレータウインドウには、キーコンフィグなど今後追加するので、一般的なエミュレータのメニューが欲しい。が、それは一旦後に置いておいて、ウインドウのサイズってフルHD前提にできる？

## 現行の仕様決定（未実装）

- 右端のIDE内実行画面は仕様から廃止する。実行表示は独立したエミュレータウインドウに統一する。
- エミュレータの初期倍率は3倍。NES映像部分は768×720で、タイトルバー・メニュー・窓枠が加わる。
- 倍率変更の入口はエミュレータウインドウのメニューへ移す。IDEの右端パネルは設定入口としても廃止する。
- エミュレータに一般的なメニューを設け、今後キーコンフィグ等を追加する方針。メニュー全体の詳細設計・実装は後回し。
- 編集ウインドウはフルHDモニタでの使いやすさを基準に仕様を検討する。

## 編集ウインドウのサイズに関する提案（未確定）

- 初回は最大化してモニタの作業領域を使う。1920×1080を窓の固定サイズに指定せず、タスクバー・窓枠・Windowsの表示倍率を考慮する。
- 次回から主窓のサイズ・位置・最大化状態を復元する。通常のリサイズも可能にする。
- BASIC／BG／スプライト／音楽・効果音／素材／テーブルの編集タブ、左右分割、下部の出力という現在の構成を基礎にする。
- フルHDで100%表示と125%表示を別々に実画面で確認する。エミュレータ3倍は映像の実ピクセル寸法として定義し、PCの表示倍率でさらに拡大しない設計を検討する。
- 編集窓を最大化し、ゲーム窓を前面に出す使い方はフルHDで成立する。編集領域と3倍ゲーム窓を常に左右に並べる配置は幅が限られるため、標準として保証するかは別途検討する。

今回は全体仕様の検討として決定事項と提案を記録した。アプリのコード・利用者設定は変更していない。確認はコード・git履歴・保存設定の読み取りであり、新規GUI起動や実画面のレイアウト測定は実施していない。
