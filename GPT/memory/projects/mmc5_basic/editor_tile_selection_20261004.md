# BG・スプライトの範囲操作修正

依頼は2026-10-04、完了は2026-10-05（日本時間）。本流は`D:/HomeBrew/FamiBASIC_Turbo_main`、
利用者の比較用フォルダーは`D:/HomeBrew/FamiBASIC_Turbo_stage_compare`。

## ユーザー原文

> FamiBasicのエディタの修正。
> BGのタイルエディタも、スプライトエディタのように左側のタイル欄にドット絵の表示範囲の枠線を出してほしい。
> ブロック編集は、1x1タイルだけでなく、2x2タイルを選択したら、それをドラッグしてタイルに割り当てたい。1x2と2x1も対応して。
> 左ドラッグで範囲選択しても問題ない場所では、右ドラッグだけでなく左ドラッグでも範囲選択できるようにして。
> スプライトエディタも一番左の縮小画面を右ドラッグで8x8単位で範囲選択して、タイル単位のコピーペーストができてほしい。右側のドット単位の範囲選択はそのまま使える。コピーしたら、コピー元の枠線の色は暗くなるなど、コピーしたことがわかる形で変化して、上にある「範囲選択」のボタンを選んだら、その時だけ左ドラッグでも選択できるが、デフォルト操作は右ドラッグにしたい。これは他のエディタでも同様。

## 実装と操作

- BGタイル一覧に右のドット編集画面の表示範囲を灰青の枠で表示。位置・編集サイズ・列数・倍率に追従。
- ブロック組み立ては1×1・1×2・2×1・2×2を選択内から左ドラッグで割り当てる。
  開始時の選択を保持し、途中で他タイルを通過しても運ぶ範囲は変えない。
  全体のプレビュー、既存区画パレット保持、1回のUndoに対応。収まらない範囲は一部も変更しない。
- BGの描画／配置／組み立て欄とスプライトは右ドラッグが標準。
  「範囲選択」を選んだ時は左でも選択。絵を変更しないBGのタイル・ブロック一覧は通常時も左選択可。
  ブロック組み立て欄には「範囲選択」「割り当て」の切替を追加。
- スプライト左一覧は8×8単位、右は1ドット単位。8×16表示でも左の単位は8×8。
  直前の操作面をコピー／貼付対象にする。単一タイルを右クリックして貼付先に選んでも、
  フォーカスを一覧へ保ってCtrl+Vが正しい面へ届く。
- コピー後の選択枠を暗くし、新しい選択を明るく表示。ツールボタンからCtrl+C／Vも有効。
  右クリックのスポイト、Space移動、破壊テストの左操作を保持。
