# F5のIDEクラッシュとビルド隔離（2026-10-06）

ユーザー原文：

> さっき D:\HomeBrew\FamiBASIC_Turbo_main\EditFlightLab.cmdを起動してF5を押したら、IDEごと落ちたんだが、なにかバグってる？たまにある。

本流main `51db44f` をpush済み。詳細と検証条件は [本流の調査記録](D:/HomeBrew/FamiBASIC_Turbo_main/docs/ide_f5_crash_20261006.md) を読む。

- 01:59:35に背景素材変換中のPythonアクセス違反。IDEログ `editor_20261006_015931_47732.log` とWindowsイベント1000のPIDが一致し、`python312.dll / 0xC0000005`。過去にも背景変換中の同種の異常終了あり。BASICやROM起動後の障害ではない。
- 原因は未確定。従来はビルド用スレッドがIDE内で動き、Python異常終了がIDE全体を落としていた。F5・構文チェック等を `IsolatedBuildService` のspawn子プロセスへ移した。CLI側のBuildServiceは従来どおり。
- 子の異常終了を通常のビルド失敗として表示し、未完成成果物を除去する。子ログは利用者データの `logs/build_<日時>_<PID>.log`。`EditFlightLab.cmd` の再起動で反映される。
- 関連8回帰が成功。実子に例外処理を通らない終了を起こし、同一IDEで編集・再F5が成功。実Flight Labでも02:11:22に子PID 55120のアクセス違反が発生したが、親IDEはエラー表示して生存した。続く別IDEの3連続F5はROM SHA一致・エミュレータのフレーム取得に成功。ユーザーの保存済み編集はコピーで検査し、変更していない。
- 既存BuildServiceの2試験はFRONT領域29バイト超過で失敗し、修正前commit `12d8038` の独立worktreeでも再現した。今回の変更には混ぜていない。
- この対処はビルドの巻き添え防止。アクセス違反自体やTk自身のクラッシュを解消したとは扱わない。
