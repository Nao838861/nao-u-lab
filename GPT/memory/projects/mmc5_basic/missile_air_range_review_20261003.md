# ミサイルの対空範囲と処理負荷（2026-10-03）

依頼原文：

> FamiBasicのシューティングサンプルのミサイル、ボスと中型的には強いが、雑魚戦で使えなすぎるので少しパワーアップしたい。空中物への攻撃範囲を増やすだけなら処理負荷にはほぼ影響しないと考えているが、その理解であっているか？

## 確認した実装

`D:/HomeBrew/FamiBASIC_Turbo_main` の HEAD `7bd2fa22ce63eb258f3131361ca8f6d450f508e5` と、保存済み入口 `build/basic_only/game/src/main.bas` を読み取り確認した。保存済みソースと旧サンプルは同一ではないので、現行入口を根拠にする。ゲームコード・ROMは変更していない。

- BASIC 3360行：対空爆風の半径相当 `C` はLv1=12、Lv2=20、威力 `R` は6/10。
- 3380〜3470行：小型8枠と中型1枠の計9枠を走査し、敵矩形と爆風のX/Y距離を比較する。爆風内の画素・地形セルを走査する処理ではない。
- 3400行：小型16×16、中型24×32の矩形へ `C` を加えた範囲を使う。
- 3350/3480行：処理済み爆風を除外し、1件の対空爆風を処理後はその更新の走査を終える。範囲を広げても継続ダメージにはならない。
- 3510〜3530行：命中時にはHP処理、撃破入口17050、敵の非活動化がある。範囲拡大で命中・同時撃破が増えれば、その処理は増える。X判定を通る敵が増えてY判定まで進む分も厳密には変わる。
- ボス用半径 `EY` は10850/10860行、爆風描画は24010行以降に別処理がある。対空の `C` だけを変えることは、ボス・地形・描画範囲の変更と分離できる。
- 3212行でミサイルの直撃から爆風状態へ移る。爆風範囲だけの拡大は、飛翔ミサイル自体の当たりやすさを直接変えない。

## 回答の根拠と限界

対空爆風の数値だけを広げるなら判定回数と計算構造は同じであり、判定そのものの負荷はほぼ据置き。実プレイの総負荷は撃破・爆発・効果音の増加で変わりうるため「処理落ちも不変」とは断言しない。地形範囲まで広げるとセル走査や破壊描画が増えうるので、この結論の対象外。

雑魚戦での弱さが「当たった後の巻き込み不足」なら対空爆風拡大は低コストな調整。弱さが「最初の1体に当たらず通り過ぎる」なら、爆風だけでは改善が限定的。強いボス・中型への影響を抑えたい場合は小型への判定だけ広げる選択肢がある。

今回は実装読解による回答。範囲変更版のCPU計測・プレイ検証は実施していない。関連根拠はプロジェクトの `tests/test_air_blast.py` と `docs/missile_air_optimization_20260928.md`。過去の計測値を今回の変更後負荷として流用しない。
