# MMC5Racing 右側表示の改善案

右上を「現在の周回と時間」、右下を「タイヤの状態」に分ける。走行中に必要な時間だけを固定位置へ置き、過去ラップの一覧で埋まっていた領域を摩擦円へ戻す。

対象は、走行ラインとアクセル・ブレーキを調整し、タイヤの限界を使って周回を速くしたいプレイヤー。守りたい体験は、減速から旋回、加速へつなぐ操作と、荷重・タイヤにかかる力の変化が対応して見えること。

## ユーザーの依頼原文

> MMC5Racingの改善を行いたい。
> 画面右に、いまはすべてのラップタイムが出ているが、ラップタイムは今の周回の情報と合計時間だけ出すようにして、右下に以前出していた摩擦円の表示を復帰したい。摩擦円は、「円の大きさ＝荷重、点＝タイヤにかかる力」という以前と同じ仕様にしたい。
> どんなﾚｲｱｳﾄで何を出すのが遊ぶ人にとって一番わかりやすいか、改めて検討して。

## 配置案

右側の時間領域では、周回番号、現在周回の経過時間、合計時間を上から固定位置に置く。現在周回と合計時間は `L` / `T` で区別し、数字の桁位置を固定する。現行5周モードでは `LAP 2/5`。実装では既存の数字サイズと `sss.hh` 秒表記を維持した。

概念図の数値は例示。画面の実寸・既存フォント・以前の表示単位を確認してからピクセル位置を決める。

```text
┌─────────────────┐
│ LAP  2/5        │
│ CURRENT         │
│   00:32.45      │
│ TOTAL           │
│   01:48.62      │
│                 │
│      FRONT      │
│   左前   右前   │
│    ○●     ○●    │
│                 │
│   左後   右後   │
│    ○●     ○●    │
│ ○ 荷重  ● 力    │
└─────────────────┘
```

摩擦円が以前から4輪別なら、上段を前輪、下段を後輪にした2×2配置を採る。車を上から見た位置関係と対応するため、内外輪と前後の荷重移動を読み分けやすい。以前が前後2輪相当のモデルなら、その単位を維持する。4輪の値がないモデルに左右輪を推定して追加しない。

時間領域の下端と摩擦円領域の上端に余白を置き、両者を一目で区別できるようにする。限られた画素は、装飾枠より数字と円の大きさに使う。既存の速度・ギアなどがある場合は、実画面を確認して重複表示を避ける。

## 比較した配置

| 案 | 良い点 | 懸念 | 判断 |
| --- | --- | --- | --- |
| 上に時間、下に摩擦円 | 読み取り位置が固定され、円にまとまった面積を渡せる | 時間の行間を広げすぎると円が小さくなる | 採用候補 |
| 時間と円を左右に並べる | 円を画面中央に近づけられる | 狭いサイド領域では時刻の桁と円の両方が窮屈になる | 見送り |
| 時間と円を自動切り替えする | それぞれを大きく描ける | 見たい瞬間に情報が消え、荷重移動を追えない | 見送り |

過去ラップ、ベスト、差分、荷重の数値、力の数値を常時追加しない。今回の依頼では現在周回と合計時間、摩擦円の読める大きさを優先する。

## 摩擦円の表示仕様

- 円の大きさは旧HUDと同じ容量（摩擦係数×垂直荷重）を参照し、同じ摩擦係数では荷重に対応する。点の位置は旧HUDと同じ前後・左右の要求力。円テーブルと力の符号・縮尺を凍結アセットから復元した。
- 各円の中心を固定し、円の大きさだけを変える。荷重が移ったときに表示全体が動かないようにする。
- 円と点に共通する力の縮尺を使い、各輪を別々に自動拡大しない。軽い輪と重い輪の違い、点と円周の位置関係を比較できることを優先する。
- 初期案では旧実装を確認せず「制限前の要求力を代入しない」と書いていたが、旧HUDは要求力を表示していた。ユーザーの「以前と同じ仕様」を優先し、その参照値を踏襲する。アクセル入力や滑り角、車体全体のGへ置き換えない。
- 座標系と軸の向きは以前の仕様を確認して維持する。4つの円の配置と、各円内の力の座標系は区別する。
- 円と通常の点は白、要求力が容量を超えた点は赤。点は2×2pxに統一し、円周と重なっても識別しやすくする。色数は実機の既存パレットを使う。
- 円周付近に点が来たことだけで「滑っている」と断定しない。物理処理が力を限界へ制限するモデルでは、余分な要求力が点から読み取れない。滑走色を復帰する場合は、以前の滑走状態・実際の判定値へ接続する。
- 凡例は短く `○ 荷重  ● 力` 相当とする。文字の制約がある場合は既存の文字セットに合わせる。操作方法を常時長文表示して円を圧迫しない。

## 確認する走行場面

| 場面 | 見ること |
| --- | --- |
| 静止・等荷重 | 円の基準サイズ、中心点、ラベルの重なり |
| 直進加速 | 荷重と力を別々に反映し、以前と同じ軸方向へ動くこと |
| 直進制動 | 加速から制動へ点の方向が切り替わり、前後の荷重変化を読めること |
| 左右の旋回 | 各輪の位置と左右の値が対応し、左右を取り違えていないこと |
| 制動しながら旋回 | 点が斜めへ動き、前後力と横力の合成を示すこと |
| 最大荷重・最大力 | 隣の円、数字、画面端に重ならず、点を表示都合で円周へ固定しないこと |
| 周回通過 | 次の周回番号と現在周回時間だけが切り替わり、合計時間は既存の計時仕様に従うこと |
| ポーズ・リセット・完走 | 計時値と周回番号がゲームの状態と一致すること |

## 参照と適用範囲

[BeamNG公式のDebug Tools](https://documentation.beamng.com/modding/vehicle/intro_jbeam/debugtools/)には、各輪の荷重を扱う表示がある。タイヤ状態を輪の単位で比較する類例として参照した。本案の位置・情報量・配色はMMC5Racing向けの設計判断であり、同資料から可読性の効果を実証したものではない。
