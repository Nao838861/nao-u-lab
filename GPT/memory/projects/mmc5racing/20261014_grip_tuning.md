# GRIPを上段・初期選択へ、惰性とブレーキの荷重を調整

## ユーザー原文

> タイトル画面でgrip mode が上に来るようにして、アクセルオフの減速を緩やかにして、ブレーキでしっかり荷重移動ができるようにしてほしい。

適用モードへの回答:

> GRIP MODEのみ

温度感は、完成した操作に対する具体的なプレイ感の調整要求。「操作感改善」だけでは、GRIPの優先表示、惰性を弱める方向、Bで前輪荷重を増やす方向、DRIFTには混ぜない条件を落とす。前版はDRIFTを初期選択にし、GRIPのアクセルOFFにも共通のエンジンブレーキを流用していた。今回の教師差分は惰性とBの役割の分離。

## 実装

GRIPを上段・初期選択、DRIFTを下段へ変更した。上はGRIP、下はDRIFTを直接選び、左右/SELECTで切替、A/B/STARTで決定。内部IDはDRIFT=0 / GRIP=1を維持し、旧DRIFTの記録を先に移行してからGRIPの保存を読み出す。

GRIPの制動要求はアクセルOFFで各輪1（合計20→4）、Bで前輪各42・後輪各28（合計120→140、約17%増）。低速上限と摩擦円を通り、実際のタイヤ力を既存ばね・荷重計算へ入れる。直接の速度/姿勢補正やドリフト用補正は足さない。E4の既存領域を再利用し、RAMは増やさない。DRIFTの制動と物理、GRIPのAのみの駆動は保持した。

## 検証と代表値

- 初速1280からアクセルOFF60更新の速度低下48→7、B60更新後の速度991→967。
- B15更新後の前輪荷重52/64→56/64。アクセルOFFでは34/64→32/64。
- B20更新後に離すと前輪荷重は56→56→54→52→50と徐々に戻る。進入20更新＋操舵30更新では惰性の回頭5356、ブレーキ進入5550（1周65536）。強制回頭ではなく実物理の結果。
- 前進4・逆走2の初速で惰性とBを比較。低速7条件でも120更新で逆転せず、停止中に動き出さない。全更新で4輪の摩擦円と荷重合計64を確認。
- DRIFT256入力＋3系列×200更新、GRIPのA/左右3系列×120更新が変更前と一致。GRIP256入力、正負10初速のB停止、補正なし、ジャーナル途中書込36ケースも合格。
- Mesen UI87項目で上下の文字・カーソル・初期選択、長押し、START、モード別ベスト100.00/120.00秒、車色を検証。部分表示になる選択直後のヘッドレス画像は提出せず、既定GRIPのタイトルを目視した。
- 最新mainへ合流後、両モード通常走行・DRIFT dense/turns/full・GRIP turns・DRIFTランダム入力・GRIPランダム視点の8試験で更新落ち/拒否0。最小余裕の固定条件DRIFT turnsは全1090区間で最小61サイクル。
- GRIP7200フレームの制御5周で6001tick保存、6001点記録、5298点再生座標、ベスト再生2回、START復帰/再スタート。走行中6496隣接区間で毎フレーム採用。座標の連続注入を使う検証で、人間の自然な完走ではない。
