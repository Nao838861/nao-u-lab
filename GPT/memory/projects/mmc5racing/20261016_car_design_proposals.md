# 車のデザイン4案と独立前輪

## 依頼原文

> MMC5Racingの車のデザインを変えたい。自分の車は前輪のタイヤ2個を別スプライトで追加して、他の車は16x16なのは維持した状態で、違うデザインの案を複数出してみて。

IDEで開かれていたMonoSHの `gsu.s` は別プロジェクト。開発本体 `D:\HomeBrew\MMC5Racing` の最新main `d9e887e` を起点にした。開始時はclean、fetch後ahead/behindとも0。

## 成果物

開発本体の `art/car-designs/` に、Aフォーミュラ・Bロードスター・Cプロトタイプ・Dラリーの4案を追加。commit `6f02fb5` をorigin/mainへpush済み。終了時はcleanかつahead/behindなし。

- `comparison.png`：同じ色・縮尺で、自車、左右の操舵、他車の斜め/横向き、簡略路面の配置を並べた比較画像。
- `preview.html`：外部通信不要の操作プレビュー。車体64方向、前輪±45度、GRIP青/DRIFT赤、回転開始/停止、リセットを全案に同時適用できる。
- `rival-directions.png`：他車の16方向抜粋。
- `generate.py` と `preview-template.html`：編集元。16×16のインデックス画素から画像・JSON・HTML・NES 2bpp CHRを生成する。
- 各案の `.chr`：車体64方向×2枚、他車64方向×2枚、前輪64方向×1枚。左右前輪は同じパターンを使う。計10,240バイト/案。
- `designs.json`：画素、前輪中心、64方向の相対OAM座標、CHRハッシュと配置。

自車は16×16の車体2枚＋独立前輪2枚の計4枚。後輪は車体へ焼込み、前輪を手前に重ねる。他車は前後輪込みで16×16、8×16スプライト2枚、全64方向で同じ枠を使う。既存パレットの車体色/タイヤ/白の3色で表現する。

今回は複数の案を出す依頼として、比較用の候補アセットを作成した。現行ROMの描画ルーチンや配布ROMは変更していない。選択後は、現行の特定方向にある車体/前輪合成と動的CHRバンク選択を整理し、独立前輪と車体2枚へ接続する必要がある。プレビューの操舵範囲は見た目の確認用で、実物理状態への接続も未実施。路面は簡略イメージ。

## 検証と自己判定

`checks.json`：4案×64方向×17操舵状態の自車4,352件、他車256方向の16×16枠、2bpp符号化/復号1,280パターンを検査。生成後の比較画像を目視確認し、初版で大きすぎた前輪を3×5画素の基準形へ縮めた。Dは箱形の前端、Cは後端のウイングを広げ、輪郭も分けた。

`preview-checks.json`：Node.jsで実際の生成HTMLを読み、DOM/canvasの最小代替で操作コードを実行。向き・操舵・色・回転開始・リセットを確認し、JavaScriptが描く画素とCHRの全1,280パターンが一致した。実ブラウザーの画像キャプチャ、ROMでのエミュレーター検証、実機検証は未実施。

核の体験は、カーブ進入で車体の向きと前輪の向きを見分け、荷重・操舵・進路の関係を読みながら旋回すること。Aは露出前輪と細いノーズのため操舵を最も読み取りやすい。市販車らしさならB。Cは中央キャノピーとフェンダー、Dは箱形とストライプで差を出したが、16×16の走行縮尺では細部の差は小さくなる。最終案は未選択。

再生成：`python art\car-designs\generate.py`（開発本体で実行）。画像生成はPillowとMeiryo/Noto Sans CJKを使用する。
