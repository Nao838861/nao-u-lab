## 表示不具合

ユーザーは場外の白帯とGAME OVER表示の崩れを報告し、main修正後にWebへ反映するよう依頼した。以前のGAME OVER修正はmainに存在していた。その後の新タイトルのNMIアニメーションが、静止画面フラグ `$41` のGAME OVERにも実行され、パレットとOAMを壊していた。`$40` の新タイトルだけを動かし、GAME OVERをBGだけの静止経路へ分けた。

白帯は、場外専用のCHR0がミニマップ用CHRに衝突したもの。コース辞書の監査では場外専用パターンを列挙しておらず、回転角の下位2bitが1〜3の時だけ白くなる。264ヘルパーで場外を無地の草地CHR256へ置換。命令サイズと走行時サイクル数は維持。四辺×CHR quarter4値の16姿勢で、前版の白帯12姿勢が修正版ではゼロ。GAME OVERも実衝突・爆発・A/B再試行・START復帰を両モードで確認した。正式入口からの再生成と前版へ修正を適用した候補がbyte一致。証拠は元ゲーム `verification/scene-boundary/`。

## ページと操作

DRIFT→GRIPの順を説明・ランキングの両方へ揃えた。「世界のタイム」を「オンラインランキング」にし、短いタイムが上位の注記とMMC5・128KB RAMの実機注記は削除。冒頭でファミコンでコースが回転することを説明し、4輪の荷重・摩擦円の説明とROMダウンロードを維持した。Enterは「レース開始／タイトルへ戻る」。日英は右上と `?lang=ja|en` で切り替え、設定を保存する。

リプレイボタンは「リプレイ再生」。右下への終了ボタン追加と通常の視聴終了でタイトル復帰する案はユーザーが取り消したため、既存ダイアログと閉じるボタンを維持する。一時停止・音ONボタンは通常画面とリプレイから削除。通常ゲームは視聴中とバックグラウンドだけ止め、閉じる／復帰で自動再開。音声はユーザー操作後に鳴る。

## ゴースト対戦

リプレイの「このゴーストと対戦」は、独立Workerでそのリプレイを最後まで走らせ、タイム・ラップ内訳・最終画像のハッシュを確認してからROMの候補ゴーストを取り出す。自己ベストを更新しない走行でも候補は収録されるので、その走行そのものを使える。

切替時はタイトルへ戻して相手のモードを選ぶ。ダイアログ内に切替時のタイトル復帰を説明する。走行途中の外部メモリー変更を入力リプレイに混入させないための判断。「全画面」の隣に「ゴーストとの対戦を終了」を出し、自分のゴーストへ戻せる。

外部ゴーストは再生用スロット0に置き、自己ベストのジャーナルは変更しない。自分の収録は候補スロット1で続く。自動保存は外部スロットを除いたコピーと自分のゴーストを保存する。終了・再読込・読み込み中の取消で相手のデータを自分のデータとして残さない。`web/battery.js` / `web/ghost.js` / `web/replay-worker.js` を一緒に読む。

QA中、独立コアの内部例外（memory access out of bounds）を一度観測した。原因は確定していない。ゴーストの読込はWASM内部例外だけ新しいWorkerで一度やり直し、版違い・不正データは再試行しない。意図的な初回内部例外をブラウザー試験に加え、回復してから対戦できることを確認する。再失敗・取消でも自分の保存や対戦相手を変更しない。通常の視聴も内部エラー文字列をそのまま出さず、再読込案内にする。

## 作業環境の観測

Python 3.10、Node 22、独立WASMで断続的な実行系例外を観測した。全工程の再生成と入力リプレイ検証はPython 3.12（networkx/Pillow）・Node24.21.0、必要時に子プロセスのCPU affinityを1へ制限して完了。これは原因特定ではなく検証時の環境記録。最終の配布ZIPのゴースト試験はaffinity制限なしでも通過した。

最初のWeb pushでは、ソースZIPのloose object `dc278305b3493969725b418e1d7228d020b36102` がzlibの不正チェックで読めなかった。作業ツリーのZIPは配布manifestのSHA256と一致し、Git blob hashも同じだった。その一つのオブジェクトを `.git/object-repair-20261019/` へ退避し、正しい作業ファイルから同一hashで再生成した。`git fsck --full --no-reflogs` が正常終了した後、CPU affinity1・pack.threads1でpushを完了。Git履歴やcommit hashは変更しなかった。原因は確定していない。
