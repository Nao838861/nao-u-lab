# MonoSHFX2初期移植の録画をMP4へ変換（2026-10-06）

依頼：`D:\HomeBrew\Mesen\Avi\MonoSHFX2_v001_初期移植.avi` をWindowsで見られるMP4にする。

同じフォルダーへ `MonoSHFX2_v001_初期移植.mp4` を作成した。元AVIは保持。映像はH.264・yuv420p、音声はAAC、faststart付き。元の256×224・約60.10fps・87.805398秒を維持し、5277フレーム、出力6737008バイト。FFmpegで全編をデコードし、エラーなしを確認した。Windowsのプレーヤーでの実再生は未確認。

変換設定：`-c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -threads 4 -c:a aac -b:a 192k -movflags +faststart`。既存ファイルの上書きを避けるため `-n` を使用。録画本体は外部フォルダーに置き、gitにはこの作業記録だけを残す。
