# 2026-10-06 JOY1の途中値で誤ポーズへ入る問題の修正

依頼原文：
> 遊んでいるとしょっちゅうフリーズする。ゲーム開始直後から左上と射撃ボタンを押しっぱなしにしていたら、5秒くらいで再現性のあるフリーズが出る

> 使っているMESENはここにあるやつ。ボタンは連射ではなく押しっぱなし

> D:\HomeBrew\Mesen

温度感：通常プレイで頻繁に止まる、明確な再現条件を伴う進行不能の指摘。守る核体験は方向入力を保ちながら射撃・回避して進行すること。操作の制限ではなく入力取得の不備を直す。

失敗した判断：画像提示・VRAM一致が続けばゲームも進むとみなしたこと。画像だけを繰り返す誤ポーズは既存検査を通っていた。最初のA押しっぱなしは通り、Y押しっぱなしで実際に論理更新204回・226field停止を確認した。悪い要約は「GSUがまれに固まる」で、実入力・タイミング・論理停止の区別を落とす。

禁止事項：再現せずGSU watchdogで強制再開する、Startを無効化する、上限方向や押しっぱなしを禁止する等で症状を隠さない。ユーザーのパッド押しっぱなしとエミュレータのTurbo連射を混同しない。

代表値：物理入力Y+左上は0x4A00、途中値は0x1280（偽Start0x1000あり）。取得中のJOY1を読んで、Startがfalseなのにポーズが1になった。CPUはHVBJOY $4212 bit0のbusy消失を待ち、JOY1 $4218/$4219の取得後もbusyを確認して開始境界をまたいだ値を捨てる。誤操作の根を修正する。

検証方法：同じD:\HomeBrew\Mesenのバイナリで、Y+左上の旧ROMが226fieldに誤ポーズへ入ることと修正版が18,000field（約5分）続くことを対にして保存。8方向×Y/A各900fieldでは正しいJOY1、ポーズなし、論理進行を確認。通常入力・Startポーズ/解除・単発・カラーOBJ・三カメラ・profile・全DMAも通過。合計37,680field・3,938回FB/VRAM/guard一致。取得待ちを追加しても序盤59.35fps、最大12KiB+OBJ68bytesは20行完了。

自己評価：根因を実入力と取得値で確認し、操作・判定・地面・カラーを保って修正できた。論理が止まって描画だけ続く状態も検査対象へ加えた。次回は押しっぱなし回帰を省かず、JOY取得変更は両側busy確認まで保存する。
