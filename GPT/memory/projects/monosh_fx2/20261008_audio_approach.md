# BGM・SEの実装前検討

ユーザーは「BGMとSEを追加してほしい。原作同様のものに仕上げたいが、どういうアプローチが取れるか？まずは検討して。」と依頼。調査・方式の比較までで、コード・素材・ROMは変えない。

詳細と一次資料はプロジェクトの`game/v001/AUDIO_APPROACH_20261008.md`。通常SNES＋Super FX2の第一候補は原作の短い楽器BRR＋音符列、SE・ボイスは単発BRR。TADのca65 APIが候補。原作録音の忠実さを優先し追加機能を許容する場合はMSU1 BGM＋SPC SEも候補だが、Super FX併用は未検証。

現行は音源ドライバ未実装。指定動画にはAAC48kHzステレオ99.316秒があるが、音の聴き比べ／分離可能性／全曲の収録は未確認。素材としてBGM・SE単独やチャンネル別出力が望ましい。混音動画から必ず無傷で取り出せるとは扱わない。原作はMAMEのsharrier設定でYM2203＋Sega PCM系。

SPCの8voice・64KiBに収め、TADはSEでBGMのG/Hが一時ミュートされる点を考慮する。CPUはGSU描画中にROMを読まない。APIコード／参照データをWRAMへ置き、曲ロードをGSU STOP中または事前準備buffer経由にする。DBR=7EとI/O bankの前提を確認する。現行のCPUコード領域残り4,132bytes、CPUDATA末尾残り271bytesは定義領域の値であり、WRAM全体の空きではない。

次の試作は、原作から主旋律＋ベース＋ドラム＋射撃音の短い区間を取り、音だけのROMで聴き比べた後に現行ゲームへ統合する案。通常・ボスの提示間隔、連射／多重SE、ループ継ぎ目も検証する。今回は音の再現度や追加後60fpsの動作検証は未実施。
