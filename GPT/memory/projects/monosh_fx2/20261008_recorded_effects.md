# 録画の自弾と二層遠景

依頼の核は「自機を動かさず撃っても発射が見える大きな弾」と「紫の山と緑の森林を別BGで二重スクロール」。原文はプロジェクトの `game/v001/DESIGN_LOG.md` に保持した。

`D:\HomeBrew\MonoSH\tmp\スペースハリアー録画１.mp4` の78.100秒から、水色の横長の輪を抽出した。自機に覆われた中央は同じフレームの露出色と対称部分で補修。56×32、透明0＋最大15不透明色・RGB5で、OBJパレット1へ置く。発射直後は32×32を二枚、40×24の中間は32×32一枚＋16×16二枚。判定・寿命・三発の枠は維持し、反射弾は12×8の小さい輪。自機17poseと全弾をOBJ 16KiBの126枠・16,128byteへ収め、画像を毎フレーム転送しない。

58.000秒の遠景を、BG4の紫の山とBG1の緑の森林へ分離。256px区間を反転して512pxの周期にした。森林の横速度は山の2倍。BG2のFX画像を高優先にして森林より手前へ置き、地面はBG3。山・森林の縦位置と空の21色の間接HDMA6は、地面のカメラに追従する。共用2bpp CHRは220tile・3,520byte。スクロールの共有ラッチへHDMAが割り込まないよう、黒帯内でレジスタを書いている間だけHDMAを停止する。

検証は三カメラの最終PPU RGB全画素、17pose・反転・端・点滅・16弾サイズ、最悪の同一行「自弾三発＋反射弾三発＋自機」。StartFrameではOBJ overflowがリセットされるためEndFrameでも読む。全12KiB＋OAMは21行までに完了、22行OBJ準備・23行表示。旧版の「68byte固定・最遅20行」という値を引き継がない。

現行ROM SHA256は `61c228dd8b7576194756d260e84aa04e236af8e28b01aa99512e560673e049b9`。通常入力18,000fieldで17,934画像。道中平均59.941fps・遅延41/15,585間隔、ボス60.032fps・2/1,802、撃破後60.099fps・0/537。素材追加前の全区間遅延0回の60.10fpsとは異なる。道中の最低約1秒窓は46画像。改善は本依頼の見た目に集中し、少数の提示遅延は測定記録へ残す。
