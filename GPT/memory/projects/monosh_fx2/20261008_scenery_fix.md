# 遠景の地平線・山裾・空の画像修正

ユーザーは森が低く地面を塞ぐ、森の透明部分から固定の空色が見える、グラデーションが短いと指摘した。フィードバック原文はプロジェクトの`game/v001/DESIGN_LOG.md`に保存した。

実地面の開始は`104+offset`。内部の地平線変数`111+offset`と混同しない。山・森の原画末尾map126に対し、旧V=14では画面112まで覆った。新V=23で103に終え、地面104へ接続する。

録画58秒の空だけの列10..44から背景色を測り、森から空の緑を除外する。山裾は稜線より下を不透明にし、森に隠れた部分を録画の近傍の紫・白・青で補完する。白い稜線は2bpp量子化で潰さない。森と山は横2:1のスクロール。

空は録画130..150行、画面75..95行（カメラoffsetを加算）。旧124..144行は紫の一定区間を7行含み、緑の終端を欠いていた。21色84bytes、間接表10bytes×3を維持。位置と色数の定数は`assets/scenery.inc`へ生成する。

前回は間違った配置とマスクをなぞる全画素参照だけでは原作との差を検出できなかった。今回の`scenery`シナリオはキャラなしの実PPU画像とGIFを取得する。三カメラの全RGBに加え、森が地面を覆わない、全512列の山裾に透明穴がない、原作の空色と範囲、山頂の白を独立に検査する。比較画像・結果は`game/v001/results/scenery_fix_20261008/`、説明は`RESULTS_20261008_SCENERY_FIX.md`。

既存の統合最適化571c1d9fを基に背景だけ直した。以前の長時間60.10fpsは以前のROMの履歴として扱い、新しいROMの検証ハッシュは結果の`provenance.json`を正本とする。

最終ROMは`12e300196644619e5b0710859c71fd70d8d3294d2cf9c7cc54c4245523798978`。別チェックアウトからのビルドも一致した。三カメラの二シナリオ・自機弾85標本/PPU66画面・静止射撃1,800field・ボス撃破次周2,600fieldが通った。通常入力6,000field/5,978画像は道中・ボス・撃破後すべて提示遅延0、60.099fps。
