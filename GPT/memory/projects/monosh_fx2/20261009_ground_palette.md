# 地面四色の指定RGB更新

ユーザー指定の暗い順 `112,191,111 / 129,208,128 / 145,223,145 / 159,240,161` を2bpp・60fps版へ反映。原文と結果は [プロジェクトの記録](../../../projects/monosh_fx2/game/v001/RESULTS_20261009_GROUND_PALETTE.md)。

SNESのRGB5展開値に最も近い色は `115,189,107 / 132,206,132 / 148,222,148 / 156,239,165`。同距離は小さい値を選ぶため最暗色のB=111は107になる。暗列1/2・明列4/3と横ペア1/4・2/3を維持。生成元・表示検証・配布manifestを更新。

変更前の再ビルドが配布版01a4c6d6と全byte一致。新ROM SHA256は `38d2fccd3f125c413d019b83073294e5eb47beb2dcda1ebbce8371b002ce560d`。display720、三カメラ計183,552最終RGB画素、FX・OBJの三場面、全1,820色HDMA表を確認。ROM差分11,228bytesは地面色とchecksumだけでCPU/GSU・音源とそれ以外の全byteが一致。新規の長時間60Hz計測は行っていない。

通常 `projects/monosh_fx2/play.cmd` から更新ROMを開く。前回確認した地上爆発先頭の影誤選択は別件として残る。4bpp実験分岐は更新していない。
