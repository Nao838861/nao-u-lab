# 自弾の時間色と地面上2行の訂正

2026年10月9日。[原文・結果](../../../projects/monosh_fx2/game/v001/RESULTS_20261009_GROUND_TIME.md)。ユーザーが前回の解釈を訂正。自弾の色は距離ではなく時間、削る上2ドットは山・森林ではなく奥行きのある地面。山・森林は元の全行を戻し、その分だけ2ドット下へ表示する。

現在は全弾共通の論理時計で4更新/色、16更新周期の水色→薄緑→黄緑→黄色。周期長は仮設定。発射からの経過時刻は使わない。サイズのOBJ記述からpaletteを除き、fx_build_objで一度計算、fastとclip/flipへ同じ属性を渡す。OAM世代へ固定し、ポーズ中は色も止まる。静的160bytesのpaletteのため毎フレームのDMA追加なし。

地面は投影原点104を保持し、見える開始だけ106＋camera offsetへ。上2画面行のスクロールを透明BG3へ向け、その下の投影・横移動・配色を変えない。山・森林の上下削除を全撤回、far/near PNGとscenery_palette.binは誤削除前41f84bfと完全一致。縦スクロール21−offsetで全景を下2ドットへ。遠景共用203tiles。再取込設定はgroundTopClipRows2/downPixels2。

Mesenの五試験：OBJ90場面、76実PPU画像89,101画素、弾16サイズ・四反転・左右端、固定サイズの時間四色／異なるサイズの同時同色、三カメラの地面2行透明と元投影式・元景の全alpha・最終RGB、静止A連射900field/899logic、pauseの属性不変、SELECT二値切替219標本。自機マスク28不透明/4透明/8境界も維持。

GitHub main e8a1f64のBGM即時開始を先に同期。今回GSU・音源は変更せず。通常ROM SHA256 2e2d5b40e5b534c14f262815365037fa3d3b99bf35390cb59924ae8171f06a30。長時間60Hzと実機は未再測定。archive_ground_time.pyで証跡・通常ROM更新。旧archive_shot_horizon.pyコマンドも現行の保存へ誘導する。

失敗の教訓：同じ弾を追う動画では距離と時間が同時に変わるため、どちらが原因か断定できない。仕様の違いを検証するには位置とサイズを固定する。元の山の上端や地面投影を確認せず、実装から生成した参照だけで「一致」を主張しない。
