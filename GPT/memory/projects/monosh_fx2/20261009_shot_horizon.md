# 自弾の距離別四色と遠景の上端2行

2026年10月9日。[原文・結果](../../../projects/monosh_fx2/game/v001/RESULTS_20261009_SHOT_HORIZON.md)。ユーザーは原作と異なる自弾の配色を直し、ノイズに見える遠景の上端2ドットを削り、遠景を2ドット下へ出すよう依頼。

同じ弾の78.2〜78.367秒を追うと、水色→薄緑→黄緑→暖かい黄色へ変わる。発射直後の水色だけを全距離へ使っていたのが原因。原動画から四つの見本を固定し、RGB5パレット4組を生成、論理サイズ9〜16／6〜8／3〜5／1〜2へ対応。境界は録画からの推定。全弾を共通時刻で色変化させず、弾ごとに距離から選ぶ。記述wordのbit9〜11をOAM palette番号へ使い、画面内・clip/反転とも同じ色を選ぶ。

自機palette0はそのまま、弾palette1〜4を起動時にまとめて転送。OBJ paletteは64→160bytes、毎フレームのCGRAM追加なし。CHRの0xc000以後は前版と完全一致し、126枠16,128bytesを保つ。自機の服の176復元画素も維持。

遠景は山map113行・森林118行の最上端から2行を削り、BG1/BG4スクロール23→21。残った最上端は削除2行＋移動2行で4行下から見える。下端を地面104行に合わせてclipする。地面・空・横スクロール速度は変更しない。元RGBAは保存し、ビルド時に表示マスクを生成。source.jsonのsceneryDisplayを原動画の再取込でも維持する。

検証は90 OBJ場面・17姿勢・四反転・弾16サイズ、四色同時表示を含む実PPU76画面88,749画素、三カメラ0/32/64の最終RGBと上端/下端、静止連射900field（899論理更新）、二値切替200標本。後続callbackが閉じたログへ書く試験終了の不具合も直し、error.txtがある試験を終了コード0でも失敗にした。再実行はエラーなし。新しい長時間60Hz測定・実機検証は今回していない。

通常ROM SHA-256 `93c8317ba02835810a62c44591d63e267f5b9697323583e5abe1e4626b253fbd`。生成はtools/build_bullet_colors.pyとbuild_scenery.py、証跡はtools/archive_shot_horizon.py。旧ステートを使わず再起動する。
