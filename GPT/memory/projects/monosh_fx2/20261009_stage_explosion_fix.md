# 60fps版の地上爆発先頭を修正

依頼原文：「爆発も修正して。」前回確認した地上物体の爆発先頭が黒い件を2bpp・60fps版でも修正。`stage.s` の `cmp #4` が残したZ判定を使わず、折り返した位相を `cmp #0` で判定する。六段階の選択は38,39,40,41,40,39から5,39,40,41,40,39へ。

原文・原因・比較・再現手順は [プロジェクトの検証記録](../../../projects/monosh_fx2/game/v001/RESULTS_20261009_STAGE_EXPLOSION.md)。`verify_stage_explosions.py` は実際の地上描画の入口へ状態を注入し、選択結果からGSU・PPUへ通す。修正前が先頭画像38の誤選択で失敗し、修正後はカラー・モノクロ各六位相の全FB589,824画素・不透明PPU2,172画素が一致した。

先ほど変更した地面四色を保持し、display720・三カメラの最終表示も再検証。原画・HDMA色・音源は全byte同一。速度と配布ハッシュの正本は `game/v001/results/stage_explosion_20261009/summary.json` と同所 `natural/performance.json`。4bpp実験分岐の同じ不具合は既に修正済み。

通常入力6,000フィールド（約100秒）でボス到達・撃破・次周まで、5,998画像・5,997間隔すべて1フィールド、60.0988fps、表示遅延0回。更新ROM SHA256 `003f820676f1acb5d3ee189c26f4c15cb265f1d2e2542f370486d7c17aef4a4b`。通常 `projects/monosh_fx2/play.cmd` から起動する。
