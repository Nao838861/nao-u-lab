# MSXSH 撮影用起動

ユーザー依頼: 「MSXSHの動画を撮りたい。最新版を起動できる？」

- プロジェクトは `D:\MSXDev\MSXSH`。`git fetch origin` 後、main は origin/main と一致（`8057d3d`）。開始時からソースに未コミットの修正があり、それを含む現在の内容をビルドした。既存差分はコミットしていない。
- `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` が終了コード0。生成 ROM は `build\artifacts\MSXSH.rom`、262144 bytes。README の128KB表記より現物が新しい。
- 起動は `powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -NoBuild`。C-BIOS MSX2+ と HRA_V9968、通常速度・フレームスキップなしを指定する既存ランナーを使用。
- 実行ファイルは `openmsx-v9968-fixed.exe`。プロセス確認で `openmsx` の完全一致だけを探すと見落とす。
- README の操作: カーソル移動、Z単発、X長押し連射、R上下反転、Pポーズ、O無敵切替。音声は未実装。
