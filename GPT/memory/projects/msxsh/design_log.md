# MSXSH プレイフィードバックと修正記録

## 2026-09-20 自機弾の当たり判定

ユーザー原文:

> NES版に比べて弾のXY判定が大きい気がする。何か違う？
>
> 修正して。

通常敵のYを下端中心の半径で判定したこと、通常敵・背景物へ固定6pxを追加したことが、見えている対象の外でも当たる原因だった。NES版を参照して、通常敵のYを上端〜下端へ戻し、通常敵・背景物の固定余白を撤去した。Zは30Hzの前回〜今回の移動区間をMSXのZ2座標へ換算して検査する。閉じたEM1はNES由来の反射補正（最小幅・高さとZ余白）を残す。ボスのXYは元から点対矩形なので変更せず、専用の間引き処理に対応するZ方針も今回変更しない。敵弾→自機判定も変更しない。

NES側の離散スプライトとMSX側の連続拡縮・投影は異なる。今回揃えたのは自機弾を点として矩形と掃引区間へ照合する規則で、全座標・全フレームのビット単位一致を意味しない。

検証:

- `python tools/test_shot_collision.py`: 実ROMのZ80関数へ境界座標を入力。通常敵・開/閉EM1・背景物の描画中/キャッシュ経路・ボス、全3弾スロット、XY境界内外とZ端点の6,804件が成功。反射と爆発への遷移・爆発Zの保持も検証。
- `stage-shot-test.ps1 -SkipBuild`: 草・木・浮遊岩・遠方EM0の命中、4フィールド以内の応答、3発枠の連射復帰が成功。旧余白へ依存していた注入座標は表示矩形内・正しいZへ変更。
- `reflection-test.ps1 -SkipBuild`: 閉EM1とボス胴体の反射、画面端消滅、遠方ボス頭への命中が成功。
- `gameplay-test.ps1 -SkipBuild`: `sawFarSideBackground=1` のチェックが失敗。今回の変更前ソースを独立ディレクトリでビルドして同じ試験を実行し、同じ失敗と全ログ値の一致を確認。既存の背景表示試験の問題として今回の修正と分離。
- ビルド成功。ボス試験スクリーンショットを目視確認。

開始時から存在した多数の未コミット修正は維持。今回の判定変更だけをHEAD上の実装にも適用した内容をindexへ格納し、そのコミット対象を別ディレクトリでビルドして6,804件の同じ試験を通した。現在の作業ツリーとコミット対象の両方を検証済み。既存差分を丸ごとcommitしていない。

自己判定: 見た目から外れた射撃の誤命中を減らし、NES版に近い照準の必要性を回復した。正常な命中・反射・連射の回帰試験も成功。ゲーム全体試験の既存失敗は残っているため、全試験成功とは報告しない。
