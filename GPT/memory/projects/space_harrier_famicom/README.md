# ファミコン版 Space Harrier：Mode 7 相当 + SuperFX 相当

Nao_u が 2026 年 11 月 8〜11 日に進めたファミコン実機向け移植の開発記録。旧ファミコンの MMC5 版をゲーム処理の基準とし、FxRacing で使った描画方式を応用した。SFC の Super FX2 / SA-1 版、MSX 版は比較元であり、この記録の実行対象ではない。

## 解説動画の起点

1. **何をファミコン側に残したか。** 敵・弾・出現順・当たり判定は旧NES版を基準にする。自機と自弾は通常のファミコンスプライト。地面は Mode 7 相当の走査線ごとの遠近処理、敵や木などの拡縮は FPGA の SuperFX 相当回路で描画して背景に合成する。
2. **なぜクロックだけでは速くならなかったか。** 大きなボス・敵弾の描画、描画命令供給や画面転送が別々に詰まった。Nao_u が「描画を1フレーム遅らせて CPU と描画を並列化できていないのでは」と指摘。透明部の処理、並列化、ボスの描画、OAM コピー、投影表、供給を順に見直した。
3. **少ない色をどう使い分けたか。** 紫の空、緑2色と3色の地面、灰色の幹、暗い目と赤い目、黒い輪郭を試した。8×1の中で透明部から背景が見える場合は背景の色を優先する。最後は Nao_u の提案でパレット共通色を白にし、空側の通常パレットの暗緑を `$09`、地面を `$19` に分けた。一部の赤・黒用パレットは空側にも `$19` が残る。
4. **計測と見た目を混同しない。** 60fpsの録画、専用Mesenでの60Hz表示、ゲーム処理自体の60Hz、ファミコン実機の観察は別。下の測定表を参照。

## 60fps の記録を読むとき

| 系統 | 記録された内容 | 注意点 |
| --- | --- | --- |
| r11 CPU Supply Optimized | 専用Mesenで道中からボス戦中まで6,000/6,000新規表示、別のボス試験も6,000/6,000。移動・射撃ありは道中、ボス各3,000/3,000 | 約30Hzのゲーム処理を補間して60Hzで表示。未撃破の長時間テスト、実機の実測ではない |
| r11 Full60 / Performance Pass 3 | ゲームロジックを60Hzに更新。Pass 3 の専用Mesen試験は約100秒で平均59.90fps、表示遅れ17回 | 全区間の表示欠落がゼロだったという数字ではない |
| 実機 | 11/10、Nao_u が「60fpsで動いている」と報告。11/11に採用した共通白/空 `$09` 版は約30秒の基本動作と、SDへ置いたROM・対応回路の読み戻し一致を記録 | 前者のビルドと後者の採用版を同一の通し測定として扱わない。全編60fpsで完成した版について本人の説明はあるが、該当する実機通し計測のログとビルドの対応はこの資料では未特定 |
