MonoSH NESFX v001 - Windows用の専用Mesen実行セット

【起動】
1. ZIPをすべて展開してください。
2. START.cmd をダブルクリックしてください。
3. ゲーム画面をクリックして操作します。終了はMesenのウィンドウを閉じます。
起動中の黒いウィンドウは閉じないでください。Pythonの追加インストールは不要です。
Mesen.exeの直接起動では専用回路が選ばれないため、必ずSTART.cmdを使ってください。
Windows 10/11 x64向け。通常Mesenのインストール先や設定には触れません。

【操作】
矢印キー: 移動。上キーで下降、下キーで上昇する逆上下操作です。
Z または X: 連射。
Enter: ポーズ/再開。
ゲームパッドを使う場合は、このMesenのInput設定で割り当ててください。

【この版の範囲】
Space Harrierの完成移植ではなく、素材を使った最初の試作です。
専用Mesen 2.1.1コアでMode7地面とGSU物体を合成します。
専用コアによる起動、移動、連射、ポーズの既存ソフトウェア試験は実施済みです。
この配布セットのGUI全体や実機での追加試験は行っていません。
UNTESTEDは実機未確認の意味です。60fps実機性能を保証するものではありません。
MMC5拡張音源がこのモデルでは未実装のため、BGMの一部が鳴りません。
色の制約があります。セーブステートの透明面復元には未対応です。
通常のNESエミュレータではこのROMは動作しません。
