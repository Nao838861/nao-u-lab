MonoSH NESFX v002 B - 専用Mesen実行セット
2026-11-08

■ 起動
ZIPをすべて展開し、START.cmdをダブルクリックしてください。標準は濃い緑の目。
START_BrightEyes.cmd は目の内側4画素だけ明るい緑にした比較版です。
START_DarkEyes.cmd は標準と同じです。
Mesen.exeの直接起動では専用マッパーが選ばれないため、必ず上のCMDを使ってください。
起動中の黒いウィンドウは閉じず、終了時はMesenのウィンドウを閉じてください。
Windows 10/11 x64用。Pythonはプレイには不要です。

■ 今回の変更
共通3色: 濃緑 $09、灰 $10、明緑 $29。
空専用: 紫 $14。地面専用: 横線の中間緑 $19。
FxRacingと同じ既存の空/地面判定を使い、任意8x1パレット選択は追加していません。
敵・木・弾・自機・爆発は専用色を使わず、透過と共通3色だけで構成しています。
元の不透明マスクは保持しており、色変更で穴を開けていません。
木の下部の幹と根を灰色にし、EM1の胸/胴体の元の明るい線を緑へ変更しました。
敵の描画中心と当たり判定を16px上へ移動。木も上端が空をまたぐ位置にしています。
濃い目/明るい目の2版はEM1の内側4画素だけが異なります。まだ採用候補です。
ボス顔の目はこの比較の対象外で、元の素材を共通3色へ整理しています。

■ 色について
同梱Mesenの既定色: 灰RGB(173,173,173)、濃緑(11,72,0)、
明緑(136,216,0)、中間緑(56,135,0)、紫(160,26,204)。
修正モックの灰RGB(152,150,152)とは完全一致せず、NESコード$10の一段暗い灰色です。
NES色のRGBはエミュレータの表示パレットでも変わります。実機で同じRGBを保証しません。
緑は今回の試作候補で、最終色の確定ではありません。

■ 操作
方向キー: 移動。上キーで下降、下キーで上昇する逆上下操作。
Z または X: 連射。Enter: ポーズ/再開。
パッドはこのMesenのInput設定で割り当ててください。

■ 確認範囲と制限
専用MesenCore.dllで各ROMを約32フレーム起動し、描画更新と表示を確認しました。
詳細な回帰試験、配布GUI全体の操作試験、実FPGA、実機60fps、長時間安定性は未確認です。
既存v001、元プロジェクト、SDカード、RBFは変更していません。
UNTESTEDは実機未確認を示します。通常のNESエミュレータでは動きません。
完全移植ではなく、素材1フレーム、32x32素材、固定木、簡易ゲーム進行の試作です。
MMC5拡張音源はこの専用コアで未実装のため、BGMの一部は鳴りません。
専用コアの透過補助面はセーブステート非対応です。
地面と同色の物体の輪郭は場所によって溶けます。色数追加では解決していません。

■ ファイル
2種類のNES ROM、専用Mesen、起動設定、ライセンス、元Mesenソース、
専用コアソース、source/game/の今回のROMソースを同梱。
比較画像と短時間起動結果はpreview/にあります。
source/game/build.pyでROM2版を再ビルドできます。Python 3、Pillow、cc65が必要です。
CC65_BINをcc65/binへ設定し、source/gameを作業ディレクトリとして実行してください。
素材再生成はpython tools/apply_palette_b.py。旧convert_assets.pyはv001の参考資料です。
