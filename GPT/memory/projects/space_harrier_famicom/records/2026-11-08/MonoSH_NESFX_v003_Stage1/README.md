MonoSH NESFX v003 Stage1 / 暗い目版

START.cmdを起動してください。通常のNESエミュレータでは動きません。
Windows10/11 x64用の専用Mesen同梱版です。Mesen.exeの直接起動は不可。
方向キーで移動、上で下降・下で上昇、Z/Xで連射、Enterでポーズ。
ゲームオーバー/一面クリア後のEnterで最初から再開できます。

一面の内容
SFC MonoSH_FX2 main cddff2f016775c4506a2423edb19911900c19a08の一面を参照。
地形155件（茂み98・浮遊石28・木29）、敵33体の全188イベントを移植。
EM0の9種類の経路、EM1の3体編隊、9節ドラゴン・頭16HP・撃破・クリア画面。
元の一面に独立した柱はありません。木・茂み・浮遊石を使用しています。
暗い目の既存6素材は画素単位で保持し、共有3色＋透明のままです。

実装範囲
一面を最初からクリアまで遊べるNES向けアレンジ移植です。完全同一移植ではありません。
32×32の素材、最大128pxの描画、固定カメラ、簡易スクリーン座標の当たり判定です。
EM1は開閉代表画像、敵弾は最大4個、閉じた敵/胴体は弾を遮断します。
原作と同じ跳弾の軌跡・5段階開閉・奥行き付き弾判定は未実装です。
撃破は静止した胴体から順に爆発してクリアへ進みます。
地面・空の既存方式は変更しておらず、任意8×1パレット・赤い目は追加していません。

音と動作条件
元の6502ドライバを保持。通常APUの音は出ますが、専用コアのMMC5拡張音源は未実装です。
BGMは一部のパートが欠けます。動画に後付けの音は足していません。
専用コアはGSU50MHz設定・合成コピータイミングの機能確認用です。
計測はこのMesen上の値であり、FPGA/実機の速度を示しません。
録画は同梱MesenCore.dllのコントローラー入力APIと内蔵AVI録画によるものです。
無敵化・メモリの書き換え・映像補間は使用していません。GUI全操作試験は未実施です。
実機、SDカード、RBFは未変更・未検証。UNTESTEDは実機未検証の意味です。
透過補助面はセーブステート非対応。通常NESハードウェアでは動きません。

ソースと再ビルド
source/gameにソース・入力素材・生成データ・検証/録画スクリプトを同梱。
Python3、Pillow、cc65が必要。CC65_BINをcc65/binへ設定してbuild.pyを実行。
必要に応じtools/generate_stage_assets.py、generate_stage_data.py、generate_render_tables.pyで再生成。
録画スクリプトにはffmpegが必要です。FFMPEG_PATHで実行ファイルを指定できます。
