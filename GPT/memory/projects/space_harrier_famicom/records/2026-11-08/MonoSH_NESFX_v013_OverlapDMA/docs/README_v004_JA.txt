MonoSH NESFX v004 NESLogic / 暗い目版

起動
ZIPをすべて展開し、START.cmdを起動してください。
Windows 10/11 x64用の専用Mesen同梱版です。Mesen.exeを直接起動しないでください。
通常のNESエミュレータ・通常のNES本体では動きません。

ゲーム処理
原作NES版 [REDACTED_HOST_IDENTITY]/MonoSH のC/ASMを取り込み、表示側をMode7+GSUへ接続した版です。
参照コミット: c0e91a8dc5426afad3b4cd56f16fee2c355321fa
https://github.com/[REDACTED_HOST_IDENTITY]/MonoSH
敵・弾・ステージ等のゲーム処理は原作NES版を基礎としています。
ゲーム更新は原作同様NTSCの2フレームに1回、約30Hzです。60Hz化はまだ行っていません。
v003のSFC参考アレンジとは別の実装です。v003の自動連射・残機・ポーズ仕様ではありません。

操作（NESコントローラーのボタン名）
方向キー: 原作の移動
A: 1回押すごとに発射
START: 原作のステージ/ボス切替
SELECT: 原作の無敵切替
物理キーボードやゲームパッドの割り当てはMesenのInput設定で確認してください。

表示
相談済みの共通の緑2色+灰色素材、暗い目、紫の空、緑3色の地面を使用します。
原作のゲーム処理と、現在の描画の再現範囲は別です。
プレイヤーは立ち姿、プレイヤー弾は静止画の素材です。
内部の原作プレイヤーアニメーション状態と弾の挙動を、全コマ同じ絵で再現したという意味ではありません。
原作と完全に同じ見た目・全アニメーションを実装済みという版ではありません。

音と動作条件
6502音源ドライバを保持していますが、専用コアのMMC5拡張音源は未実装です。
BGMには欠けるパートがあります。
専用MesenのGSU 50MHz設定と合成コピータイミングで機能確認する構成です。
エミュレータでの機能確認はFPGA・実機での動作や速度の証明ではありません。
SDカード・RBFは変更していません。実機未検証です。UNTESTEDはその意味です。
透過補助面はセーブステート非対応です。

ソースと再ビルド
source/game にゲームソース、参照NESソース、入力素材、生成データ、ビルド/検証ツールを同梱します。
Python 3、Pillow、cc65が必要です。CC65_BINをcc65/binへ設定し、build.pyを実行してください。
ビルドではWindowsのConsolasフォントを使用します。録画ツールは別途ffmpeg等が必要です。
tools/package_stage1.py、capture_stage1.py等は前版の履歴です。v004の正当性を示すテストではありません。
同梱検証ファイルに記載の対象ROMハッシュと条件を確認してください。
MesenはGPL-3.0-or-laterです。ライセンス、ホストソース、専用コアソースを同梱します。
https://github.com/SourMesen/Mesen2
素材・楽曲等の権利は各権利者に帰属します。一般公開・再配布の許諾を示すものではありません。

再現範囲の補足
地面の前進は原作ground_scrollに同期します。Mode7地面の透視と水平線は相談済みの固定外観です。
原作cameraoffsetに合わせた負のpitchは現在の専用コアでは対応していません。
プレイヤー等の全ポーズ素材への対応付けは未完成で、大きいSTAGE1タイトル画像も未描画です。
元のタイマー、座標、衝突等のゲーム状態は保持しています。
60fps達成版ではありません。表示は約30fpsであり、動画の60Hz出力とは区別してください。
ゲーム状態比較は入力なしの限定条件です。全操作・全ステージの同一性を証明するものではありません。
cc65ソフトウェアスタックの実装予約域は$7f00-$7fff、初期c_spは$7fffです。
