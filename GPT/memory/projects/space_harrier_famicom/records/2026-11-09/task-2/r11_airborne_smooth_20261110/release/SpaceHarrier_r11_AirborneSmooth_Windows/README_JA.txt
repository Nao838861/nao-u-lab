Space Harrier r11 AirborneSmooth / Windows 専用

ZIP 全体を展開し、PLAY_R11.bat または Play_R11.exe を起動してください。
同梱の専用 Mesen と ROM を使用します。古いセーブ状態は読み込まないでください。

操作
・方向キー: 移動
・Z: ショット / X: NES B
・Enter: 通常ステージとボスの切り替え
・右 Shift: 無敵の切り替え
・ウィンドウを閉じる、または Alt+F4: 終了

今回の修正
・浮いている石: 地面と同じ投影基準で位置と高さを計算し、途中での位置反転や表示切れを修正。
・EM0: 丸めで失われていた 1 ピクセル単位の中間移動を復元し、拡大縮小の中間段階を追加。
・ボス: 拡大縮小を 56 段階から半深度単位の 112 段階にし、中間位置の丸めも改善。
・草、木、地面の既存修正を維持。ゲーム進行、AI、当たり判定は変更していません。

確認と制限
・専用 Mesen で通常ステージ 700 世代、ボス 500 世代を比較し、確認対象のゲーム状態、
  カメラ、ネイティブ OAM が修正前と一致しました。表示コマンドは意図した変更を含みます。
・900 フィールドの定位置テストでは平均約 58.10 fps（通常）、57.49 fps（ボス）。
  常時 60 fps の保証や、速度改善を意味しません。重い場面では処理落ちがあります。
・Windows エミュレータ用です。実機、FPGA、長時間の全ゲーム動作は未検証です。
・同梱ランチャーは ROM と DLL の一致を確認します。ファイルを混ぜず、まとめて展開してください。

再現と資料
python source/airborne/rebuild_from_baseline.py OUTPUT.nes
同梱の基準 ROM と確認付きパッチから最終 ROM を再生成できます。
開発用のアセンブリ、ビルドスクリプト、検証結果を source と verification に収録しました。
モジュール別の開発スクリプトには元の開発環境パスが残っています。
Mesen のソース、最新地面修正の差分ソース、GPL ライセンスを source に収録しています。
