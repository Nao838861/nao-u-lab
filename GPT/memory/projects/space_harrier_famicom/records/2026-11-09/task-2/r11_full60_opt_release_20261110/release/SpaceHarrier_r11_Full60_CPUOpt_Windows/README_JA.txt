Space Harrier r11 Full60 CPUOpt / Windows専用

ZIP全体を展開し、PLAY_R11.bat または Play_R11.exe を起動してください。
専用ランチャーから起動し、古いセーブ状態を読み込まずに試してください。

操作
・方向キー: 移動
・Z: ショット、X: NES B
・Enter: 通常ステージ／ボス切り替え
・右Shift: 無敵の切り替え
・ウィンドウを閉じる、または Alt+F4: 終了

変更点と実測
通常プレイの入力、自機、世界座標、敵・ボス、弾、衝突を60Hz目標で更新します。
CPU処理を軽量化しました。常時60fpsを保証するものではありません。
短時間の専用Mesenテストでは、600フィールド中の表示更新は通常594回、ボス568回。
基準60.0988Hzで換算の平均は通常59.50fps、ボス56.89fpsです。
重い場面では処理落ちがあり、ゲーム内の時間の進行も遅くなります。

確認範囲と制限
・AI判断、経路、寿命などは元の実時間のテンポを保っています。
・開始、死亡、転倒など一部の演出や離散的な絵の切り替えは元の30Hz刻みです。
・当たり判定の形は従来のままです。111段階の投影に全面調整したものではありません。
・全ゲームクリア、全入力条件、長時間の安定性は未検証です。
・実機動作は未検証です。この配布物はWindows用です。
・SD、USB、FPGAへの操作は行っていません。
