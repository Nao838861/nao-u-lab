Space Harrier r11 / ゲーム全体60Hz目標の試用版

ZIP全体を展開して PLAY_R11.bat または Play_R11.exe を起動してください。
今回は自機だけでなく、通常プレイの世界移動・敵やボスの座標・弾の移動・衝突も
1fieldずつ進める版です。以前の自機60Hz版は変更せず残しています。

操作
・矢印キー:移動
・Z:ショット、X:NES B
・Enter:ボス/通常ステージ切替
・右Shift:無敵切替
・ウィンドウを閉じるかAlt+F4:終了

短い実行確認
・道中600field:564回表示、約56.5fps。
・ボス600field:552回表示、約55.3fps。
・死亡→着地→復帰を2回と再ヒット、Enterで4回のステージ切替を確認。
・これらの試験で描画エラー、GSU締切ミス、意図しないリセットは0。

制限
・常時60fpsではありません。重い場面では処理落ちし、ゲーム時間も遅くなります。
・敵AI、寿命などは元の実時間の速さを保っています。
・開始・死亡・転倒など一部演出の動きや離散的な画像切替は旧30Hz刻みです。
・木・草の111段階投影を含みますが、従来の当たり判定形状は完全には調整していません。
・全ゲームクリア、全入力条件、長時間の安定性は未検証です。
・実機確認はしていません。SD、USB、FPGAの操作も行っていません。
・このZIPはWindows専用です。専用ランチャーを使い、旧セーブ状態を読み込まず
  起動し直して試してください。
