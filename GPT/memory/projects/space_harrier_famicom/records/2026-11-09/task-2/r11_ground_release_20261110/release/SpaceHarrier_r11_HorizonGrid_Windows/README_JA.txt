Space Harrier r11 / 地平線・地面グリッド修正版 / Windows x64

1. ZIP全体を展開してください。
2. PLAY_R11.bat または Play_R11.exe を起動してください。
3. Mesenのゲーム画面を選択して操作します。導入画面のあとゲームが始まります。
4. ウィンドウを閉じるか、Alt+F4で終了します。

操作: 矢印キーで移動、Zでショット、XがNES B。
EnterはSTART（ボス/通常ステージ切替で、開始ボタンではありません）。
右ShiftはSELECT（無敵切替）。Xbox/XInputの1番パッドにも対応しています。
パッドは起動前に接続し、必要ならOptions > Inputで設定してください。

最大高度時の地平線付近の明るい帯を修正しました。
地面はSFC版に近い密度の横方向周期10texel（1マス5texel）に固定し、
縦方向の模様は変更していません。モアレの完全解消は保証しません。
以前の木の輪郭・拡大縮小・接地・Stage 1タイトル修正を引き継いでいます。
別途調査中の物体/地面の投影補正は、この版には含めていません。

通常はランチャーを使い、runtime/Mesen.exeを直接起動しないでください。
Mesen自身による専用DLLの上書きを防ぎ、ROM/DLLの組合せを検証します。
古いセーブステートや別のDLLを混ぜないでください。Python/.NETの追加導入は不要です。

検証は専用エミュレータとRTL/内部タイミングの範囲です。
実機への転送・書込み・起動・リセット・機器操作は一切していません。
FPGA_NOT_HARDWARE_TESTEDは対応する実機未検証のビルド資料です。
Windowsで遊ぶ場合はその中のファイルを使いません。
詳細な検証範囲と未解決事項はVERIFICATION.txtをご覧ください。
