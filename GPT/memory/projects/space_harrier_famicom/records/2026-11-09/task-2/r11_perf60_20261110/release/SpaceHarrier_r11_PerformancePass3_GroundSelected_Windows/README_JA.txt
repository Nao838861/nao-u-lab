木だけの基調色変更・追加ハイライトは別調整のため、この版には含めていません。
共有パレットを使う木・草・山の該当色も地面と一緒に変わります。

同じ6000 NTSCフィールドの実測（専用Mesen、固定位置・無敵・同じ射撃入力）
元のAirborneSmooth: 57.945fps、処理遅れ205回
前版PerformancePass2: 59.728fps、処理遅れ35回
本版PerformancePass3: 59.898fps、処理遅れ17回
本版の表示待ち20回、キュー破棄1回、GSU期限超過0回。
平均は60fpsに近づきましたが、常時60fpsではありません。

同じ実時間入力ですが、進行速度が変わるため固定窓は完全に同じ敵配置ではありません。

原因と変更
主因はNES CPUの更新・投影・描画命令と素材転送です。GSU計算待ちではありません。
前版の表示待ち37回は、GSUコピーがNMIの2.54～11.36ms前に終了していました。
ボスの転送時間には割り込み時間も含まれます。命令コピーと素材チェック自体は約1.345msです。
カメラの同値計算を短縮し、敵AIの一時的なリスト登録・復元を省略しました。
投影の丸めを積へまとめ、一般描画の重複した計算・引数読みを削減しました。
敵EM1の素材選択を展開し、開閉ポーズ転送の同じ値の書き込みをまとめました。
画像素材、動作・当たり判定、AI/音楽の更新頻度、GSUクロック・転送モデルは維持しています。
自機のOAM表示は別処理で、既存の最新位置表示と安全な5ページ所有権管理を維持しています。

検証
通常3500世代、ボス1000世代のゲーム状態867バイト、描画命令、カメラ、実OAMを比較しました。
NMI実フィールドカウンタと音楽状態43バイトは更新時間が変わるため比較対象外です。
ボスは両方が発行した994パケットを比較し、キュー抑制が異なる6世代のパケットだけ除外しました。
移動900フィールドでエラー・ポーズ競合は0。切替・移動・射撃中の1200NMIと1197DMAも通過しました。
各変更の命令単位差分検証と再構築資料をsource/performance3とverification/pass3へ収録。
敵EM1画像の全3639書き込み境界に割り込みを入れ、4252回の実NMIで状態の一致を確認しました。
境界試験はポーズ0～3と、新規起動したポーズ4の証拠を合成しています。詳細と試験の制限も同梱しています。

残る負荷
密集区間のCPU更新＋描画準備は平均16.44msですが、重い半フレームのピークが残ります。
本版の表示待ち20回のうち14回は描画命令が未完成、6回は命令・カメラ/OAM準備後の転送待ちでした。
射撃なしの追加6000フィールドでも、前版の遅延37回から本版14回へ減っています。
通常プレイのすべての操作で常時60fpsを保証するものではありません。
