Space Harrier r11 / 自機60Hzの試用版

まず ZIP全体を展開して PLAY_R11.bat を起動してください。
自機の通常移動と入力反応を毎fieldに分けた、軽快な標準版です。

操作
・矢印キー:移動
・Z:ショット、X:NES B
・Enter:ボス/通常ステージ切替
・右Shift:無敵切替
・ウィンドウを閉じるかAlt+F4:終了

今回は「自機だけ60Hz化」の第一段階です。
敵・弾・ボス・ゲーム進行・当たり判定は元の30Hzのままです。
ゲーム全体が60Hzになった版ではありません。
自機は通常移動時に半歩ずつ動き、画面には毎field最新の位置を出します。

比較用: PLAY_REFERENCE111.bat
自機60Hzに加えて、木・草の横位置、根元Y、幅、高さを
地面と同じ世界距離で計算する111段階投影を有効にします。
この比較版は処理落ちが増えます。元の判定との見た目の一致も未確認です。
旧投影から横最大38px、幅14px変わる場面があり、画面端で早く消えることもあります。

確認範囲
・標準版の短い操作区間:599field分を599回表示、late/drop/starve 0。
・111比較版の同じ区間:599field分を597回表示。処理落ちは残ります。
・自機の短い入力試験で初回入力待ち後は毎field移動し、PPU上の位置と一致。
・標準版のボス試験では処理落ちがあり、全編60fpsの保証はありません。
・全ゲーム、全入力条件、見た目と判定の整合は未検証です。
・実機、SD、USBの操作はしていません。このZIPはWindows専用です。

更新後はランチャーから起動し直し、旧セーブ状態は読み込まないでください。
以前の版は変更せず残しています。
