Space Harrier r11 / 投影補正の試遊版 / EXPERIMENTAL

ZIP全体を展開し、PLAY_R11.bat または Play_R11.exe を起動してください。
矢印キーで移動、Zでショット、XがNES B。
Enterはボス/通常ステージ切替、右Shiftは無敵切替です。
ウィンドウを閉じるかAlt+F4で終了します。

地平線と地面グリッドの修正に、地上物の横1px単位の配置と、
地面の移動距離に合わせた接地点Yの試験補正を組み合わせました。
遠近で輪郭上端と大きさが逆行しないよう、高さの表も調整しています。

完成版ではありません。横方向の拡大率と幅は以前のZモデルのままなので、
物体と地面が完全に固定されるわけではありません。
接地点・高さは最大約10px変わります。当たり判定のコードは変えていませんが、
見た目と判定の位置合わせは未検証です。多少の処理落ちは残り得ます。

短時間の600fieldsで600回提示、late/drop/starveは0でした。
300回の生成データ比較で茂み996個を確認しましたが、
この短い区間では木の実表示は確認できていません。
全ステージ・実パッド・実機の動作保証はありません。

通常はランチャーを使用し、別のROM/DLLや古いセーブ状態を混ぜないでください。
実機・SD・USBの操作は行っていません。
前のHorizonGrid版はそのまま残してあります。
