Space Harrier r11 木・草の投影変更 試用版

起動できる段階を優先した実験版です。前の地平線・格子版は別に保存しています。

今回の変更
・地平線と横格子の修正を引き継ぎました。
・木・草の横座標を、途中で半解像度に切り捨てず最後に1px単位で丸めます。
・根元Yは、地面の進み方（1 logic更新あたり117/256 world単位）に合わせた距離から投影します。最も手前の根元位置は維持します。
・高さも近端・遠端の上端と単調な拡縮を保つように調整しました。元の表示から根元は最大10px、高さは木10px・草9px変わります。

未完成の部分
・横方向の拡大率と幅は従来のZテーブルです。地面との滑りを完全に解決した版ではありません。横移動や視点変更には違和感が残る可能性があります。
・56段階のZを用いる実装です。112段階の内部Z演算に変更したものではありません。
・ゲーム進行・当たり判定の処理は変更していません。ただし表示位置・高さが変わるため、旧判定との見た目の一致は未検証です。
・処理落ちを許容する試用版です。横補正だけの前段試作は3000field中2999回提示で、1回の待ちがありました。
・実機操作、USB/SDへの転送、実機での確認は行っていません。

確認した範囲
・今回の組み合わせで短い600field操作試験を行い、600回提示、late/drop/starveはすべて0でした。全ゲーム・常時60fpsの保証ではありません。
・300描画サンプルで草996件の根元・高さが新テーブルどおりであること、他オブジェクト1128件とworld/camera値が前段試作と同じであることを確認しました。
・この短区間には木の実出現は含まれません。木の表は全33カメラ×56Zで単調性を確認していますが、長時間の実画面確認は未実施です。
・実際の描画画像を確認しました。

まず木・草の根元と地面の関係を見て試せる段階として出しています。
