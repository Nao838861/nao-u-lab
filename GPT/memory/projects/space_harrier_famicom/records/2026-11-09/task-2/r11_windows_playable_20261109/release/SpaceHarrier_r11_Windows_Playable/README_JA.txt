Space Harrier r11 / Windowsプレイ用セット

1. ZIPを「すべて展開」してください。ZIPの中から直接起動しないでください。
2. PLAY_R11.bat または Play_R11.exe をダブルクリックしてください。
3. Mesenのゲーム画面を選択して操作します。ロード後すぐにゲームが始まります。
4. ウィンドウ右上の×またはAlt+F4で終了します。

対応: Windows 10/11 x64。Pythonや.NETの追加インストールは不要です。
通常はPlay_R11.exeを使います。runtime内のMesen.exeだけを直接起動しないでください。

操作（初期設定）
・矢印キー: 移動（縦方向はゲーム本来の操作方向です）
・Z: NES A、ショット
・X: NES B
・Enter: START、ボス/通常ステージ切替（開始ボタンではありません）
・右Shift: SELECT、無敵切替
・Xbox/XInputの1番パッド: 十字キーまたは左スティックで移動、Aでショット、BでNES B、Start/MenuでSTART、Back/ViewでSELECT
パッドは起動前に接続してください。Options > Input で割当変更できます。
別のウィンドウへ切り替えると一時停止します。ゲームへ戻ると再開します。

同梱物
・Mesen 2.1.1 GUI（既存の自己完結版）とSkia/HarfBuzz
・このROM専用のMesenCore.dll
・r11のPCエミュレータ用ROM（実機用ROM/RBFは含めません）
・小さなWindows専用ランチャー、ソース、ビルド手順、ライセンス

注意
このセット専用のDLLとROMの組合せです。通常版Mesenや他のNESエミュレータでの互換性は保証しません。
起動時にROM/DLLのSHA256を検査します。DLLは読取専用＋実行中の読取共有ロックで、Mesen内蔵DLLへの置換を防ぎます。
DLLの入替、Mesen本体の更新、過去版セーブステートの読込はしないでください。
設定とセーブ関連フォルダはこのruntime内に保存され、既存Mesenの設定は変更しません。
SD/USBへの転送や実機操作は行いません。
Windowsが警告した場合は無理に回避せず、内容を確認してください。

確認済み
・GUIプロセスで対象ROMと専用DLLがロードされ、映像を256×240（下端239行まで、cropなし）で取得。
・GUI上の公式Lua入力で左右移動とA入力を短時間確認。
・DirectSoundのロードと音声初期化エラーがないこと、ウィンドウ終了要求でプロセスが正常終了することを確認。
・ROM/DLLの内容が元ファイルと一致することを起動後にも確認。
未確認: 実キーボード/実パッドを押す操作、スピーカーからの音を聴く確認、別PC、全ステージ通しプレイ。
