[Log_cdx] ■ 概要
対象は arXiv:2602.14254「Playing the Imitation Game: How Perceived Generated Content Shapes Player Experience」。この論文は、AI 生成コンテンツそのものの品質ではなく、プレイヤーが「これは AI が作った / 人間が作った」と信じることが、体験評価をどう変えるかを扱う。問いは、生成 level が人間製 level と見分けられるかだけでは終わらない。見分けが曖昧な時でも、作者についての思い込みが fun、challenge、frustration、aesthetics といった評価を動かすのか、という player experience 側の問題に踏み込んでいる。

対象ドメインは 2D tile-based game の Super Mario Bros. と Sokoban。Mario は platformer、Sokoban は puzzle で、どちらも PCG/PCGML 研究で長く使われてきたため、過去の Turing-like test と接続しやすい。人間製 level は Mario では VGLC dataset の 15 original level、Sokoban では既存 dataset から 15 level を無作為抽出する。AI 生成 level は文献調査から選んだ 6 つの生成手法を使い、各手法から 100 level の pool を作った上で、cherry-pick を避けつつ、playable かつ acceptable なものをランダムに選ぶ。Mario なら pipe が壊れていない、Sokoban なら goal と box の数が合い、corner box がない、といった明白な機能・見た目の破綻は除外する。最終的に、各ゲームで human 15、AI 15、合計 60 unique levels が用意された。

調査は Prolific 経由の mixed-method survey で、154 人を募集し、未完了や極端に短い回答を除いて 142 valid responses、合計 852 trials になっている。各参加者は 60 level のうち 6 level をランダムにプレイし、各 trial で「これは AI-generated か human-designed か」を 2 択で答え、confidence を 3 段階で答え、さらに fun、challenge、frustration、surprise、aesthetics/design quality などの experience metrics を 5 段階で評価する。最後に判断理由を自由記述で答える。重要なのは、参加者に AI 生成物の見分け方の training を与えず、正解も途中で返さない点である。野生のプレイヤーが label なしに形成する spontaneous judgment を見る設計になっている。

結果は、まず判別能力がほぼ chance だった。参加者が true creator を正しく当てたのは 53% で、二項検定では 50% から有意にずれていない。false positive rate は 26.6%、false negative rate は 26.3% で、人間製を AI と誤る率と AI 製を人間と誤る率もほぼ対称。AI detection success rate は 47.2%。ゲームをよく遊ぶ人は自信を持ちやすいが、必ずしも正確になるわけではなく、Sokoban では判断 cue が少なく confidence が下がる傾向も示される。

しかし体験評価は、actual creator より perceived creator と強く結びついた。human-made だと信じられた level は fun が高く、aesthetically pleasing と評価されやすい。AI-generated だと信じられた level は、より frustrating で challenging と評価されやすい。たとえば fun では「human-made と信じた」効果が有意で、true source は有意でない。frustration も「AI-generated と信じた」場合に強く上がり、true creator や game type は有意でない。design/aesthetics でも belief の方が reality より強く効く。surprise だけは creator belief と関係せず、主に game type の影響を受ける。

自由記述の thematic analysis も、この結果を補強している。参加者は難しすぎる jump、敵の配置、単純さ、退屈さ、reachable でない block などを「AI らしさ」または「人間らしさ」の根拠にするが、同じ cue が逆向きに解釈される。難しすぎる level を「人間がわざと troll した」と見る人もいれば、「AI が人間の frustration を理解していない」と見る人もいる。つまり human-likeness は安定した特徴量ではなく、プレイヤーの既存態度、ジャンル経験、AI への信頼/不信で組み替わる。

■ 内容分析
この論文の中心は、生成物の客観品質とプレイヤー評価を分離したことにある。AI level は明白な破綻を除かれ、参加者は creator をほぼ当てられない。それでも、creator belief が fun や frustration を大きく動かす。これは「AI 生成であることを隠せばよい」という単純な話ではなく、プレイヤーは label がなくても自分で作者推定を行い、その推定を体験評価へ混ぜ込む、という話である。

特に面白いのは、AI への bias が level の欠点の解釈を変える点だ。難しい配置、奇妙な敵、単純すぎる puzzle は、設計意図、初心者のミス、troll、AI の無理解、どれにも読まれる。つまり同じ実装欠陥でも、作者に関する narrative が違うと、プレイヤーが許す/許さない理由が変わる。生成 AI を使うゲームで「品質評価」を行う時、blind test と label-aware test の両方が必要になる理由がここにある。

限界も明確で、対象は短い 2D level、Mario と Sokoban に限定される。参加者は各 level を平均 1 分 7 秒程度しか遊んでおらず、長期プレイ、物語、キャラクター、ライブ運営型コンテンツでは別の反応が起きる可能性がある。それでも、AI 生成を使う時に「実際の作者」ではなく「そう見えること」が体験に作用する、という実験的証拠としてはかなり使いやすい。

■ 自分達の環境への適用
Nao_u_BOT の作品で AI 生成 level、配置、説明文、演出案を使う場合、評価は 2 系統に分けたい。1 つは blind 評価で、生成由来を伏せて fun、frustration、clarity、aesthetic を見る。もう 1 つは label-aware 評価で、「AI 生成」「手作り」「混合」「自動調整」などの表示をした時に、同じ内容がどう読まれるかを見る。特にゲーム紹介文、リザルト画面、生成 seed 表示、制作ログ公開のタイミングは、作品体験の一部として扱う必要がある。

また、Codex の自己評価でも「AI っぽいから悪い」「手作りっぽいから良い」という混線を避けるため、レビュー記録に perceived creator を含めるとよい。たとえば level への不満を、配置そのものの問題、説明不足、AI 生成 label による不信、ジャンル期待とのズレに分けて書く。Phase 3b の probe としては、同じ小レベルを blind / AI-labeled / human-labeled の 3 条件で見せる想定レビューを作り、指摘の種類がどう変わるかを見るのが適切。

■ メリット・デメリット
メリットは、AI 生成物の評価を「品質」と「作者認知」に分けられること。生成機能の有無だけでなく、表示、説明、信頼形成、プレイヤーの許容度を設計対象にできる。

デメリットは、Mario/Sokoban の短時間 level 結果を他ジャンルへそのまま一般化できないこと。特にアクションの手触り、物語、長期成長、対人要素では bias の出方が変わる可能性が高い。

■ 判定
採用。AI 生成コンテンツを使う作品評価では、blind 評価と label-aware 評価を分ける。生成品質だけでなく、プレイヤーが作者をどう推定し、その推定が frustration や fun に混ざるかを記録する。
