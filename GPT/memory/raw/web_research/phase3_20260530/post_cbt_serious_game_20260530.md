■ 概要
対象: Designing More Engaging Serious Games to Support Students' Mental Health: A Pilot Study Based on A CBT-Informed Design Framework
URL: https://arxiv.org/abs/2604.15662

この論文は、学生向けメンタルヘルス教育ゲームが「退屈」「継続されない」「教材っぽくて遊ばれない」問題を抱えることから出発し、CBT の認知再構成目標を説明文ではなくゲームメカニクスへ埋め込む設計枠組みを提案している。枠組み名は Therapeutic Procedural Rhetoric and Mechanism Mapping Framework、略して TPR-MMF。狙いは、心理教育をテキストや会話で教えるのではなく、プレイヤーがいつものゲーム的直感で失敗し、別の行動を試し、成功体験を通じて認知の歪みに対応する意味を自分で読み取るようにすることにある。

TPR-MMF は3層で説明される。第1層は intervention target layer で、対象者にとって傷つきやすく破壊的な心理特性を選び、それを具体的な認知再構成目標へ変換する。例として、完璧主義なら「完璧でなければ失敗」という固定観念を崩す。第2層は cognitive dissonance mechanism の構築で、対象者がゲーム中に取りそうなデフォルト行動を予測し、その行動があえてうまくいかないルールを作る。これにより expectation violation、つまり期待違反を起こし、自動化された思考パターンから一度外れる余地を作る。第3層は cognitive restructuring path の構築で、期待違反で生じる感情を踏まえ、別のやり方を試すフィードバックを用意し、新しい方略でクリアできた時に embodied behavioral validation、身体化された行動検証として元の認知を揺さぶる。

著者らはこの枠組みに基づいて、横スクロール型の serious game「World + You - World」を作った。教材型の低刺激なミニゲームや会話選択ではなく、学生が慣れているアクション系のコアループを使った点が重要である。扱う認知の歪みは5種類。完璧主義では、星を全部取らない方がクリアできるレベルにして、「全部集めることが成功」というゲーム的直感を崩す。過度の一般化では、近づくと逃げる足場により、1回の失敗が永続的失敗を意味しないことを試行から学ばせる。結論の飛躍では、最初は届かなそうな足場でも、跳ぶたびに跳躍力が上がる構造で、試す前に無理だと決めつける認知を扱う。拡大解釈では、巨大なトゲなど脅威に見えるものが実際には過大評価されていることを体験化する。個人化では、1人で背負えない状況を、役割や協力的な仕組みによって乗り越える形へ変換している。

評価は小規模なランダム化比較試験で、18〜19歳の大学1年生28名を experimental group 14名と control group 14名へ分けた。両群は年齢、性別、PSS-10のベースラインに有意差なし。実験群は World + You - World を20分、対照群は会話型RPG serious game の NeuroQuest を20分プレイし、その直後に Intrinsic Motivation Inventory を回答した。実験群だけは各5レベルについて、最初に何を考えたか、レベルが何を伝えようとしていると思ったか、実生活のどんな経験を思い出したか、という15問の質的質問にも答えた。分析は IMI の独立サンプル t 検定と、3名研究者によるテーマ分析で行われた。

結果は、実験群が interest/enjoyment、perceived competence、perceived choice、value/usefulness の4次元で対照群を有意に上回った。具体的には interest/enjoyment が 5.61 対 4.78、p<.001、d=1.73。perceived competence が 5.48 対 4.79、p=.005、d=1.15。perceived choice が 5.20 対 4.58、p=.002、d=1.31。value/usefulness が 5.93 対 5.35、p<.001、d=1.72。effort/importance と pressure/tension には有意差がなかった。質的結果では、完璧主義レベルで55%が最初に「全部の星を集める」を選び、結論の飛躍や拡大解釈では「届かない」「越えられない」という即時判断が多く出た。その後、多くの参加者は「完璧を追いすぎない」「まず試してから結論を出す」「恐怖を拡大しない」「全部を1人で背負わない」といった心理的意味を読み取り、受験、期末試験、対人関係、返信が来ない不安など実生活の状況へ結びつけた。結論として著者らは、CBT の認知再構成目標を暗黙的なメカニクスと procedural rhetoric に変換することで、従来の説明型教材より参加動機と体験品質を高めうると述べる。ただし、N=28 の単回・短時間評価であり、症状改善や長期効果を示した研究ではない。

■ 内容分析
この論文で拾うべき点は、メンタルヘルス文脈そのものより「概念をゲーム内行動へ変換する手順」である。多くの serious game は、正しい知識をNPCやクイズで説明し、プレイヤーに理解させる。TPR-MMF は逆に、説明を削り、プレイヤーが持ち込むゲーム的な癖を利用する。全部集めたい、届かないと決めつける、怖そうな障害物を避ける、1人で解こうとする。これらをまず発火させ、失敗させ、別方略の成功で意味を回収させる。つまり、メッセージをテキストからメカニクスへ移すだけでなく、「誤った直感を安全に誘発する」段階が設計に入っている。

評価面では、IMI の差は大きいが、対照群が NeuroQuest という別ジャンル・別刺激量のゲームであるため、TPR-MMF だけの効果と、横スクロールアクションの好まれやすさを完全には分離できない。また、実験群だけに質的質問をしているため、メタファー理解の比較対照は薄い。それでも、各レベルの具体的な認知歪みとプレイヤー反応を対応させているため、「教材をゲームに載せた」事例ではなく、「ゲームの失敗構造を教材化した」事例として価値がある。

■ 自分達の環境への適用
Nao_u_BOT のゲーム制作では、教育ゲームに限らず「伝えたい概念」を扱うときの設計チェックとして使える。たとえば、孤独、過信、焦り、過剰最適化、短期報酬への依存、他者との役割分担などをテーマにする場合、まずテーマ説明を書くのではなく、プレイヤーが自然に取りそうな default strategy を列挙する。次に、その方略が短期的には魅力的だが長期的には詰むレベル構造を作る。最後に、別方略を試した時だけゲーム側のフィードバックが開くようにする。

Phase 3b の probe としては、各プロトタイプに「target concept / default player intuition / expectation violation / recovery feedback / readable metaphor」の5項目を1行ずつ追加するだけでよい。これは説教臭さの検出にもなる。説明文でしか伝わらないなら、まだメカニクスに変換できていない。逆に、遊びだけで意味が一意に閉じすぎるなら、体験の余白がない。プレイログや短い自由記述を取れる場合は、作者の意図ではなく、実際にプレイヤーがどんな現実経験へ接続したかを記録する。

■ メリット・デメリット
メリットは、抽象テーマをゲームの行動・失敗・再試行に落とす手順が明確なこと、説教型チュートリアルを避けやすいこと、プレイヤーの初期反応を設計対象にできること。デメリットは、メタファーが伝わるかが文脈と対象者に依存すること、ジャンル嗜好の影響を受けやすいこと、医療・教育効果を主張するには長期追跡と大規模評価が足りないこと。精神健康領域では特に過剰一般化を避ける必要がある。

■ 判定
部分採用。医療効果ではなく、mechanism mapping の設計手順だけを採用する。Nao_u_BOT では、テーマを説明する前に「誤った直感をどう安全に誘発し、別方略の成功でどう返すか」をプロトタイプ評価軸にする。
