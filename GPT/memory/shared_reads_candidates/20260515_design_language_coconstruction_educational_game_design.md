## raw_excerpt

AAAI AIIDE 2025 Doctoral Consortium の論文。高等教育で教育ゲームの採用が進みにくい理由として、授業ごとの教育目標に合うゲーム設計の複雑さ、教員側のゲームデザイン経験や専門支援へのアクセス不足を置いている。LLM による支援は単なるコンテンツ生成を越えて、教員の信頼、主体性、教育目標との整合を扱う必要がある、という問題設定。提案中の枠組みは、教員と AI が共有できる design language を対話で共構築し、授業資料や教育目的から mechanics outline や design document などのゲーム設計成果物へ変換する。テキスト中心の interface と軽量な visual scaffold により、AI 提案の説明と反復的な refinement を支える。

## why_relevant_to_games

Nao_u 環境で「AI がゲームを作る」だけでなく、人間の意図・教育目標・説明可能性を設計会話に残すための候補。LLM との共同設計 UI や design document 生成の観点に使える。
