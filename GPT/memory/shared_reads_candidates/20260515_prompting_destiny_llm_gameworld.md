## raw_excerpt
原文の短い核: "delayed, end-of-stage growth feedback" / "entry-load tension"。

arXiv abstract によると、この研究は socialization theory をもとにした LLM-mediated role-playing game を提示している。プレイヤーは morally charged situations の中で child prince を導き、stage ごとに LLM-mediated NPC の反応差を比較しながら、教育的な導きが社会化に応じてどう変わるかを考える。構造は four-season で、score chasing を弱めるため real-time evaluative scores を隠し、stage 終了時に growth feedback を reflective prompt として返す。user study (N=12) では gameplay logs と post-game interviews を使い、reflexive thematic analysis を行っている。結果として、プレイヤーが responsibility と role positioning をどう交渉するか、また open-ended expression と sustained engagement の間に entry-load tension があることを報告している。
