## raw_excerpt
arXiv:2602.05864。2026-02-05 submitted。Mandi Yang ほかによる、socialization theory を土台にした LLM-mediated role-playing game の研究。プレイヤーは 4 seasons 構造の中で child prince を morally charged situations に導き、各 stage における LLM-mediated NPC の反応差を比較する。

abstract 要旨: 現実の教育文脈に近づけ、score-chasing を減らすため、real-time evaluative scores は隠し、end-of-stage growth feedback を reflective prompts として遅延提示する。N=12 の user study では gameplay logs と post-game interviews を収集し、reflexive thematic analysis を実施。結果は、プレイヤーが responsibility と role positioning を交渉する過程、および open-ended expression と sustained engagement の間にある entry-load tension を示している。

## why_relevant_to_games
LLM NPC を「自由会話の賑やかし」ではなく、遅延フィードバック・役割認識・反省を作る仕組みに使う例。スコアを即時表示しない設計も、評価ゲージ依存を避けるゲーム設計の材料になる。
