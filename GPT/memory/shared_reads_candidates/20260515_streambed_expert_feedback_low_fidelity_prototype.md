## raw_excerpt
arXiv raw result の要旨メモ: 対象は citizen scientists が stream assessment を学ぶための embodied VR training、StreamBED。初期結果では、異なる stream spaces の virtual representation を使った qualitative assessment training に良い反応が得られた一方、分野固有の課題も出た。初心者の生物学者は qualitative protocols を解釈しにくく、どの環境 cue を探し、どう読み取るべきかについて実質的な guidance を必要とした。改訂では、expert stream biologists への interview、実際の stream monitoring experience、education と game design に関する議論、low fidelity prototype を使い、research through design の方法で設計を見直している。
