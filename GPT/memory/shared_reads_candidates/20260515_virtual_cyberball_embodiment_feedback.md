## raw_excerpt
arXiv raw result の要旨メモ: 対象は Cyberball task を immersive virtual 版として設計し、avatar customization とユーザーフィードバックを入れた研究。まず avatar customization template を作り、Unity3D game engine で作られた Cyberball prototype に追加する。その後、Cyberball を知らない naive participants 五名と、Cyberball paradigm の経験が豊富な social science researchers 十名、合計十五名に in-depth user testing と feedback sessions を行った。報告される design insights は、直感的な使いやすさ、包摂性、研究用途としての再現性や統制、身体化の感じ方などにまたがる。素人参加者と経験研究者で視点が分かれる点も扱われている。

## why_relevant_to_games
プロトタイプのユーザーテストで、初見プレイヤーと熟練評価者の反応を分けて見る候補。アバター、身体性、社会的相互作用を含む小型ゲームの検証に使える。
