## raw_excerpt
arXiv:2505.08515。Pawel Chodkiewicz / Pragya Verma / Grischa Liebel。2025-05-13 submitted。Autism のある子どもは語彙獲得に困難を抱えることがあり、社会的コミュニケーションにも影響する。デジタルツールは予測可能な環境と個別化されたフィードバックを提供できるため語彙学習に有益だが、既存研究では real-world social contexts に近い turn-taking を組み込んだものがない、という問題設定。

提案は cooperative two-player vocabulary learning game の CoVoL。子どもが実社会のコミュニケーション場面に役立つ語彙学習を、協力型ゲームとして行えるようにする。論文は first prototype と evaluation を扱い、研究者・セラピスト 10 名への interview feedback に基づく planned features と final release の evaluation plan も示す。

## why_relevant_to_games
協力ゲームで「順番を待つ」「相手の行動を受けて語彙を使う」など、ゲームルールが学習対象そのものを支える例。教育ゲームやアクセシビリティ配慮のあるチュートリアル設計の候補資料になる。
