## raw_excerpt
arXiv:2512.08551。著者らは、educational context における game design elements の learner preference を調べ、gamification を pedagogical goals と揃えることを目的にしている。手順は、systematic literature review でよく議論される GDE を10種に整理し、それぞれの visual prototype を作り、125 participants に best-worst scaling survey を行う構成。加えて qualitative feedback を集め、motivation の理由を読む。

検索結果の要旨では、好まれた要素として progress bars, concept maps, immediate feedback, achievements が挙げられている。重要なのは、points / badges / leaderboards のような外発的報酬だけではなく、学習の進み具合が見えること、内容との関連が明確なこと、行動可能な feedback が返ることが recurring motivational themes とされている点。短い原文句としては "visible progress", "content relevance", "constructive feedback" が中核になる。

## why_relevant_to_games
レベルアップ、ゲージ、実績、フィードバック演出を足す時に、「報酬っぽいから入れる」ではなく、プレイヤーの学習・上達・次行動を見える化する要素として扱う観点を拾える。
