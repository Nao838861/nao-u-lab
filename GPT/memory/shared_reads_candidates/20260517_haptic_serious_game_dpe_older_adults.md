## raw_excerpt

JMIR Serious Games 掲載、2026-01-30 published。高齢者向けの cognitive stimulation serious game を、視覚負荷の高い UI に寄せず、smartphone vibration motor を使う haptic-driven prototype として設計・試験した論文。abstract では、既存の older adults 向け serious games は visual interfaces に強く依存し、visual impairments を持つ人には不利になりやすい、という背景から始まる。Design-Play-Experience (DPE) framework を使い、design では haptic symbol system と accessible interface、play では dynamic difficulty adjustment、experience では emotional engagement を組み込んだ、と整理されている。

pilot study は self-reported mild visual impairments を持つ older adults 10 名が対象。System Usability Scale の平均は 89.5 で、interview の thematic analysis では intuitive haptic feedback、reduced eye strain、simplicity の 3 theme が出ている。結論では、"haptic substitution for vision" という形で DPE framework を適用した点を contribution とし、low visual load interventions の現実導入可能性に触れている。

短い原文メモ: "haptic substitution for vision" / "dynamic difficulty adjustment" / "reduced eye strain"。
