## raw_excerpt

arXiv abstract からの収集メモ。論文は、社会化、道徳的責任、教育的な立ち位置について内省するための LLM 仲介型ロールプレイングゲームを扱う。プレイヤーは child prince を導き、四季構造の中で道徳的な状況に向き合う。LLM-mediated NPC の反応が段階ごとに変わることで、教育的な導きが社会化に応じてどう変化するかを考える設計になっている。score chasing を避けるため、リアルタイムの評価点は隠し、ステージ終端で delayed growth feedback を reflective prompt として返す。

ゲーム制作向けには、LLM を「何でも答える GM」として使うより、即時採点を隠し、プレイ後の振り返りとしてフィードバックを出す設計が参考になる。成長や道徳判断を扱うゲームでは、数値化を前面に出すと最適化ゲームになりやすい。遅延フィードバックにすると、プレイヤーが行動中は物語・役割・状況判断に集中し、後から意味づけを受け取る構造にできる。

## why_relevant_to_games

LLM GM/RPG の feedback timing 設計候補。即時スコアではなく delayed reflective feedback を使うと、教育・内省・物語選択のゲームで score chasing を避けられる可能性がある。
