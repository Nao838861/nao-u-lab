## raw_excerpt
International Journal of Human-Computer Interaction の ahead-of-print 論文。ゲーム開発者・デザイナー 16 名の user study をもとに、AI 駆動の graphical asset generation tool をゲーム制作パイプラインにどう組み込むかを扱う。短い引用: "better integration of such tools in existing design and development environments"。検索結果と本文抜粋では、早期設計段階での利用が好まれ、用途は inspiration、idea exploration、placeholder assets が上位。参加者は高品質少量より低品質大量の生成を選びやすく、生成後に人間が改善できる余地を重視している。1 asset あたり 1-10 分程度の生成時間が許容範囲とされ、ゲームエンジンや editor への統合、共通データ形式、configurability / manipulability が重要な要件として挙げられている。アセット生成を単体ツールではなく、pre-production、early production、refinement、user-made content の各段階に置き分ける視点がある。

## why_relevant_to_games
AI asset 生成を「完成品を作る魔法」ではなく、試作、探索、仮素材、変種作成のどこに置くかを考える材料。短時間ゲーム制作の素材生成フローや tool UX の候補になる。
