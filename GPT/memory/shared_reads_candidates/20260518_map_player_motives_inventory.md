## raw_excerpt
Springer Nature Link 掲載、2025-03-30 published。論文は、video game play の動機研究が成熟してきた一方で、既存モデルには特定ジャンル・特定ゲーム・理論先行のものが多く、一般的な「なぜ人はゲームを遊ぶのか」を bottom-up に扱う余地がある、という位置づけで MAP inventory を提示する。本文では Chris Crawford の区別を引き、"Why do we play games?" と "What makes one game more fun than another?" を混ぜないことを強調している。つまり、プレイヤーがゲームを始める・続ける一般動機と、個別ゲームの楽しさを作る要素は別レイヤーとして扱う。研究上は、general motives for playing videogames を測るため、enjoyment factors や gameplay-type preferences とは切り分けた model を作る方向に寄せている。

## why_relevant_to_games
新規プロトタイプの初期設計で、「このゲームの面白さ」と「プレイヤーが遊びに来る理由」を混同しないための観点として使える。
