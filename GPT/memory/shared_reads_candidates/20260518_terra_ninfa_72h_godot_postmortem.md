## raw_excerpt
itch.io devlog、2026-03-18 posted。Down2Jam 3 の "Plants" テーマから作られた Godot 製 3D exploration puzzle "Terra Ninfa" の postmortem。記事は、72 時間制作での事前準備、brainstorming、level design、水と植物の logic 実装を順に扱う。pre-jam preparation では Blockbench / Inkscape、同一 Godot version、GitHub repository、Trello、Miro を事前に揃えたことで、jam 中に「環境構築」ではなく制作へ集中できたと書いている。アイデア出しでは、viewer の「上から流れる irrigation、水の splitter/diverter/blocker、どの plants に水が届くか」という提案が core puzzle に変わる。最初は 2D vertical scrolling を考えたが、puzzle mechanic の量を狭めると判断し、小さな 3D world と orbiting camera へ転換した流れも記録されている。
