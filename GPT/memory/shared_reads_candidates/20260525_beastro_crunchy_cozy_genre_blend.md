## raw_excerpt
著作権配慮のため長文引用ではなく、Unreal Engine developer interview の要旨メモとして保存する。2026-04-13 の Timberline Studio / Beastro インタビュー。Beastro は、young chef Panko が village Palo Pori で Caretakers のために料理を作り、彼らが外側の敵と戦えるよう支える構造のゲーム。チームはこの体験を "crunchy cozy" と呼び、cozy fantasy / adventure / deckbuilding / cooking / crafting / puppet-theater battle を混ぜている。

制作上のポイントは、戦う主人公ではなく、英雄を支える料理人という位置取りを中心に、複数ジャンルの要素を「遊びやすい一皿」にまとめようとしている点。13 人規模の小チームが、UE5 の art / animation tools、Control Rig、Blueprints、Lumen などを使い、ビジュアルと戦闘演出の production cost を抑えつつ、puppet theater battles という見た目の特徴を押し出している。

記事は、ジャンル混合を単なる足し算ではなく、core fantasy と制作制約の接続として扱っている。deckbuilding の crunchy さ、cooking/crafting の cozy さ、戦闘を直接操作しない支援者視点、鮮やかなキャラクター表現を同じ体験に束ねる事例として読める。

短い原文句として "crunchy cozy"、"you can't save the world on your own"、"puppet theater battles" を控える。
