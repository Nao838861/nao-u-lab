## raw_excerpt
80 Level 2026-04-28 の Inkblood dev diary 紹介。Inkblood は「solving mysteries without being told how」を前提に、traditional quest structure ではなく systemic investigation experience として設計されている。プレイヤーは Inquisitor として cult-driven conspiracy を追い、複数 location で clue を集め、observation、deduction、experimentation によって結論を組み立てる。目標は単一解へ誘導することではなく、プレイヤー自身が到達できる tool を与えること。interaction model は layered で、環境 inspection、evidence collection、case file 構築、supernatural magnifying glass による past へのアクセスを含む。時間そのものを investigative system の一部にし、scripted storytelling より player-driven discovery に重心を置く。各 case は個別 puzzle に閉じず、interconnected events の network として扱われ、minor clue が larger revelation に接続する。carriage は単なる移動 hub ではなく narrative device でもある。The Case of the Golden Idol と Return of the Obra Dinn から影響を受け、gothic horror と cozy investigative loop を混ぜる方向。
