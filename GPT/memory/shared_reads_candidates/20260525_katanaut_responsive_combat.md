## raw_excerpt

短い引用: "fast, responsive katana combat" / "readability and consistency"

80 Level の 2026-05-19 インタビュー。Katanaut は、数年かけたソロ開発の cyberpunk roguelite で、最初は「操作して気持ちよい高速 katana combat」という小さな prototype から始まり、alpha/beta の community testing を重ねながら system、world、lore を広げたと説明されている。core mechanics は timing、resource management、projectile deflection、attack chaining、offhand ranged weapons の組み合わせ。開発者は、混沌とした高速戦闘でも player expression が残るように、controls が player intent を支え、重すぎる character feel で制限しないことを重視した。challenge/readability については、失敗理由が分からない高速ゲームはすぐ frustration になるため、敵攻撃、projectiles、movement windows、combat effects が clearly enough に伝わることを重視し、blood/gore や sharp pixel graphics が visibility を複雑化する点も課題として挙げている。solo dev 向け助言では、core feel が良くないまま content を足しても直らないので、まず小さく始め core idea を prove することが強調されている。
