## raw_excerpt
Martin Pichlmair and Mads Johansen、IEEE Transactions on Games、2022-06-02。game feel design を moment-to-moment interaction がプレイヤーに与える affective impact の設計として扱い、academic research と practitioner publications 200 件超を survey する。分類結果として、意図する player experience を physicality、amplification、support の 3 domains に整理する。polishing はそれぞれ tuning、juicing、streamlining として現れる。physicality の tuning は cohesion と predictability を作り、movement が level design を知らせる。juicing は empowerment と feedback clarity を支え、streamlining は game が player intention の実行を支える方向で働く。

## why_relevant_to_games
アクション、シューティング、物理系 prototype の「気持ちよさ」を、単なるエフェクト量ではなく physicality / amplification / support に分けて観察する候補軸になる。
