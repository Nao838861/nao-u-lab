## raw_excerpt

SSRN abstract。Sam Davern / Mads Haahr、30 pages、2025-07-16 posted。対象は、探索・論理思考・創造的思考を必要とし、物語の進行や pacing に組み込まれる narrative puzzle。SPHINX 2 は Story Puzzle Heuristics for Interactive Narrative eXperiences 2 の略で、open world video games に実装するための procedural narrative puzzle generation system として説明されている。論文ではシステム設計と、ゲーム Curse of the SPHINX への実装を扱い、探索的 user study で分析している。半構造化インタビューの thematic analysis と miniPXI によるデータでは、参加者が複数の解法を使ったこと、パズル伝達はおおむね機能したこと、楽しさと engagement は一定程度あったこと、open world setting がパズルへの関与に影響したこと、改善点として narrative context の増加や variable puzzle complexity による混乱の緩和が挙げられている。

## why_relevant_to_games

探索型ゲームで「物語進行の鍵」と「空間内の発見」を procedural に接続する時、パズルの伝達・文脈・複雑度のログ項目を作る材料になる。
