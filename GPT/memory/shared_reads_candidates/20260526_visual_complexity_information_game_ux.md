## raw_excerpt
Communications in Humanities Research Vol.107、2026-04-13 published。ゲームUI設計が「情報や装飾が多すぎる」方向と「単純化しすぎる」方向の両極に振れ、どちらも別の形で player experience を損なう、という問題設定。systematic literature review に、Arknights と Deep Palace Melody の case study を加えて、visual complexity と information presentation が game user experience の複数層に与える影響を整理している。

要旨では、複雑すぎる interface は cognitive overload を招き、functional / hedonic experience を妨げる一方、簡略化されすぎた interface は十分な visual expression を欠き、emotional investment や meaningful experience を弱めるとされる。information presentation と visual style consistency は、体験の一貫性を調整する統一された design system を構成する。結論は、game UI の成功は visual richness と information visibility の dynamic equilibrium にあり、その均衡は game type と audience に依存し、普遍的な単一基準はない、というもの。
