## raw_excerpt
University of Glasgow の Enlighten 掲載情報。Wen と Chu による 2026 年の Research in Learning Technology 論文で、DOI は `10.25304/rlt.v34.3746`、Creative Commons Attribution ライセンスの PDF が提供されている。概要では、AI と MDA framework を統合する理論合成・framework development として、generative AI、adaptive learning algorithms、procedural content generation が gameplay をどう強化し、educational game design を進めるかを扱う。constructivist learning principles と AI capabilities を対応させ、personalized、engaging、scalable な game-based learning を支援する枠組みとして説明されている。

## why_relevant_to_games
MDA を AI/PCG/適応学習で拡張する候補。教育ゲームに限らず、Mechanics から Dynamics と Aesthetics へどう検証をつなぐかの設計語彙として使えそう。
