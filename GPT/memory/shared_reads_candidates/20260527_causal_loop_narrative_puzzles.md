## raw_excerpt

著作権配慮のため長文引用ではなく、記事の要点メモとして保存する。PlayStation Blog 2026-04-16 掲載、Mirebound Interactive の Creative Director Kai Moosmann による Causal Loop の開発メモ。中心は、パズルをストーリーから独立した障害物として置かず、世界内で「なぜそのパズルが存在するのか」を説明できる状態に寄せた、という設計方針。

記事では、初期はプロトタイプとしてパズルの mechanics を反復していたが、物語を深くする過程で gameplay が narrative を補完する必要に気づき、既存 puzzle の意味づけを変えたと説明されている。door / gate を開けるための操作ではなく、世界の過去や装置の機能と結びつく問題解決へ寄せた、という流れ。echo system では diegetic interface を採用し、プレイヤーが見る情報は主人公も見ているものとして扱う。UI 上の便宜的な表示をいきなり出すのではなく、物語内でそれを可視化する理由を用意している。

また、puzzle 前後の lead-in / lead-out areas で、物語への集中と gameplay への集中を切り替える構造を作っている。worldbuilding では過剰な説明台詞を避け、collapsed structures、old recordings、past events の痕跡などから、player discovery に寄せた。ただし明確な conveyance、environmental storytelling、dialogue のどれかが欠けると重要情報を誤解されるため、presentation の反復が必要になる。例として、echo だけに作用する force fields が以前は solid barriers に見えてしまい、プレイヤーが通れないと誤認したため、説明しすぎずに clue と clarity を足す調整をしたとされる。

## why_relevant_to_games

パズル・UI・物語を別々に作って後で接続するのではなく、「操作が世界内で何を意味するか」を先に問い直す材料になる。小規模ブラウザゲームでも、mechanics の導入、チュートリアル、演出、level transition を一体で見る観点として使える。
