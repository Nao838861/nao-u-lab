## raw_excerpt
短い原文断片: "soulslike tag wasn't part of the original design document" / "testers telling us it felt like one"

採録メモ: The Outer Zone の Game Director が、Death Howl を「open world Soulslike deckbuilder」として最初から設計したのではなく、学校プロジェクト由来のデッキ構築プロトタイプから始まり、自由探索、グリッド戦闘、カードによるスキル構築、チェックポイント、死亡時の通貨回収、敵行動のパターン学習が重なって、テスターの言葉によって soulslike と認識されていった経緯を説明している。ジャンル名を先に置くのではなく、プロトタイプの核とプレイテスト上の感触が後から分類名を引き寄せた例として読める。
