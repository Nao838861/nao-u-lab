## raw_excerpt
Journal of Games, Game Art, and Gamification 掲載の 2026 年論文。FAIR は Freedom、Autonomy、Immersion、Replayability を軸にした player-centered model として説明されている。既存 framework は motivation、flow、usability など個別側面を扱ってきたが、gameplay の holistic nature を捉える統合モデルには gap がある、という問題設定。引用情報は Kirginas, S. (2026), Journal of Games, Game Art, and Gamification, 11(1), 27-36, DOI `10.21512/jggag.v11i1.14268`。

## why_relevant_to_games
ゲームの評価観点を、自由度・自律性・没入・リプレイ性の四軸で棚卸しする候補。Phase 2 以降で質を見る前提だが、prototype cross_review の観点リスト化に使える可能性がある。
