## raw_excerpt
要旨メモ: Trading Card Game の長期運営で、メタゲーム固定化、選択肢の縮小、反復感が生じる問題に対し、LLM と image diffusion を使ったカード生成を扱う。単なるカード単体生成ではなく、Pokemon case study として関連性、制約、個別化されたカード設計の広がりを議論している。

## why_relevant_to_games
ローグライクのアイテム、敵行動、ビルド選択肢を増やす時に、個別生成物の派手さだけでなく「既存集合との関連性」を見る候補。バランス崩壊や意味の薄い水増しを避ける観点に接続できる。
