## raw_excerpt
GDC Vault の GDC 2026 Design track セッション。Richard Rouse III が host、Xalavier Nelson Jr / Ashley Ruhl / Theresa Duringer / Joel Burgess / Steve Meretzky らが登壇する microtalks-style session。各 designer が 10 分で、自分の game design に使う rule を 1 つ共有し、その rule を「いつ、どのように使うか」まで掘る形式。

ページの説明では、このセッションは「新しい game design techniques」を紹介し、各 rule は登壇者個人の感性に紐づくものとして扱われる。創作分野なので rule を破ることもある、という留保を置きつつ、プロジェクトに持ち帰れる toolkit を増やす場として位置づけられている。Track / Format は Design。Free content として表示されている。

関連する観測点: 同ページの recommended には「Game Feel is the Message」「Surprise and Delight as Social Infrastructure」「Meaningful Reasons to Wander」など、現在の game feel / level design / social play 文脈に近い GDC 2026 セッションが並ぶ。
