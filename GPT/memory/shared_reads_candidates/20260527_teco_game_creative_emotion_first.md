## raw_excerpt

収集メモ。三宅俊輔 (TECO / PICO PARK) による、ゲームクリエイティブの起点を「どんな感情を抱かせたいか」に置く記事。メカニクス、ナラティブ、レベルデザイン、ジャンルは重要だが、それらは最初に定めた感情を引き出すための手段として扱われる。感情は喜怒哀楽のような粗い分類ではなく、具体的な状況セットで想像するものとして語られている。PICO PARK の例では、協力・立場逆転・人が集まった時のわちゃわちゃ感のような体験価値が中心に置かれる。

記事後半では、「面白い」を外的刺激、「楽しい」を受け手側の内的発露として分け、面白いルールやギミックをプレイヤーが楽しめる状態まで導線設計する必要があると述べている。パズルの応用ギミックも、基礎理解の段階を通らなければ楽しめない。さらに、プレイヤーが途中で離れる感情として、飽きた、挫折した、疲れた、を挙げ、興味維持、リトライ性、緊張と弛緩の制御を確認項目にしている。

## why_relevant_to_games

Nao_u_BOT のプロトタイプが「仕組みの新しさ」から入りがちな時、最初に残したい感情と離脱感情を明文化するための外部視点になる。
