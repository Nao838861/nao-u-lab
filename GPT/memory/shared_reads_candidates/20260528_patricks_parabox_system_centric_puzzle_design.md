## raw_excerpt
GDC Vault の Game Developers Conference 2024 セッション。speaker は Patrick Traynor、track は Design、free content と表示されている。Overview では、IGF award-winning puzzle game Patrick's Parabox の開発中に使われた、または学ばれた puzzle game design techniques を共有する talk とされる。

扱う技法は、mechanics を反復するための heuristics、puzzle levels を作る strategies、playtesting 時に注意すべき点。具体例は Patrick's Parabox の開発から取り、core design pillar は recursive puzzle system を見せること、と説明されている。talk の位置づけは、ゲーム全体ではなく design に焦点を当てた mini-postmortem。

## why_relevant_to_games
単一の中核システムを「見せる」ために、メカニクス反復・レベル作成・playtest 観察をどう束ねるかの候補。パズルに限らず、1 mechanic prototype を破綻させず展開する時の参照先になる。
