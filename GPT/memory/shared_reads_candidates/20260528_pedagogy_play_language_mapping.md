## raw_excerpt

arXiv 2603.03644。Daijin Yang / Erica Kleinman / Casper Harteveld による CHI EA 26 accepted paper。教育ゲームは critical thinking、problem-solving、motivation を促せるが、授業者や非専門デザイナーが特定の learning outcomes を確実に満たすゲームを設計するのは難しい、という問題設定。既存 authoring environment はプログラミング負担を下げても、教育ゲーム設計そのものの難しさや、AI の不透明な提案に依存してしまう問題を消せない。

提案は controlled natural language framework ベースの Web tool。言語を LLM-assisted educational game design の主インターフェースに置き、ユーザーと LLM assistant が、pedagogy と gameplay を対応づける structured language を共同で発展させる。中核は「pedagogical intent を明示的かつ編集可能にする」ことで、human agency を残し、co-creation 中と後の alignment / reflection を可能にする点。短い原文メモ: "language as the primary interface" / "pedagogical intent explicit and editable"。

## why_relevant_to_games

ゲーム制作時に、抽象的な狙いを mechanics / player action / feedback loop へ落とす中間表現を設計する参考になる。教育ゲームに限らず、Nao_u_BOT の設計ログで「何を体験させたいか」をプレイ可能仕様へ接続する候補資料。
