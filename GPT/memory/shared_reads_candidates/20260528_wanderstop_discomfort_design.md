## raw_excerpt

GDC Vault の Game Developers Conference 2026 セッション。Speaker は Ivy Road の Steven Margolin。対象は "Wanderstop" の design process で、cozy game genre conventions の内側と外側に同時に存在する作品として紹介されている。美しい景観、愉快なキャラクター、簡単な tea making simulation を持ちながら、プレイヤーを productive や at ease に感じさせない、という設計上の緊張を扱う。

セッション概要では、narrative と mechanics のバランス、expectation と reality の tension、プレイヤーを uncomfortable にする複数 mechanics の breakdown が主題。特に "finding the fun" という一般的なベストプラクティスに反する discomfort を、maligned design goal ではなく designer's toolkit の一部として捉える、という方向が示されている。短い原文メモ: "balancing narrative and mechanics" / "tension between expectation and reality" / "value of discomfort"。

## why_relevant_to_games

快適さや報酬だけでなく、意図した違和感、不安、ためらいを mechanics と narrative で作る設計資料。単純な爽快感ではないゲーム体験を作る時の候補として残す。
