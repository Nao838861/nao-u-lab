## raw_excerpt

Game Developer / Game Developer Collective の 2026-03-06 記事。記事本文では、ゲーム開発者の生成 AI 利用報告が 2025 年前半の上昇後に落ちていることを扱う。短い原文メモ: "only 29 percent" / "year-over-year decrease from 36 percent" / "half of developers feel it's bad for the industry"。

記事の要点メモ: Game Developer Collective と Omdia の調査では、2026 年時点で generative AI tools を使っていると答えた参加者は 29%。前年同時期の 36% から下がっており、2024 年後半 24% から 2025 年前半 36% へ伸びた流れが反転した形として説明されている。開発者感情も併記されており、品質低下への懸念、コスト削減期待の低下、コスト増加懸念の上昇が触れられている。別調査として GDC Festival of Gaming の「約 3 分の 1 が利用、半数が業界に悪いと考える」、日本の CESA/TGS 関連報告の 51%、Google Cloud / Harris Poll の AI agents 利用報告も比較対象として挙げられている。
