## raw_excerpt

原文の要点メモ。Quest of Aivengarde は、NPC 対話を持つ custom-built RPG を研究用 testbed とし、static control と 3 種類の LLM-driven variants を比較する。比較軸は rephrase / hybridize / fully generate のような生成自由度で、behavioral logs と post-game surveys を使った mixed-methods analysis を 64 participants に対して行う。結果メモとして、fully open-ended LLM dialogue は会話を長く自然にし、casual players に特に engaging だったとされる。一方で、論文は narrative control と conversational freedom の trade-off を扱い、LLM NPC を「自由に話せる」だけで評価しない。

## why_relevant_to_games

NPC 会話の自由度を上げるほど良い、ではなく、プレイヤー層・没入・会話ログ・物語制御を分けて測る候補。Nao_u 作品で NPC/対話要素を入れる時の評価設計に使える。
