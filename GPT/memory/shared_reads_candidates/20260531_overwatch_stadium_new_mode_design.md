## raw_excerpt
短い原文断片: "18-month journey" / "maintained the core Overwatch feel" / "Balancing Through Data and Playtesting"

GDC 2026 公式 agenda の Overwatch 新モード Stadium 制作講演。既存の競技 shooter に、shop system、third-person camera、hero functionality 拡張、strategic depth などの大きな新要素を入れながら、Overwatch らしさを崩さないことが主題。説明では、initial concept、design goals、prototyping、balancing、post-launch support、live testing events、limited betas、player feedback を 18 か月の制作過程として扱う。

Takeaway には、既存 franchise の identity を壊さない systemic innovation、既存 hero fantasy を保った新文脈への ability adaptation、internal dashboards / live event data / focused feedback loops による調整、失敗した初期 prototype から clarity と fun を得る手順、design / animation / VFX / UI 間の alignment、limited-time events と beta を実験と trust-building に使う話が並んでいる。

## why_relevant_to_games
既存ゲームを大きく改造する時、核の体験を守りながら新モード・新メカニクスを試すための制作プロセス候補になる。
