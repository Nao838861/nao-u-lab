## raw_excerpt
AIIDE 2025 poster research、published 2025-11-07。Pixie は、level / puzzle / narrative だけでなく rules and mechanics の生成を扱う文脈で、Unity project に install できる game mechanic generation and testing system として提示されている。短い原文抜粋: "a system for generating and testing game mechanics"。既存の mechanic invention 系 PCG が bespoke codebase に寄りがちな問題に対し、simple annotation process で scope と objective を設定し、open-source Unity games 複数で mechanics を生成する。developer perspectives も初期的に議論し、design companion としての有用性を見る。

## why_relevant_to_games
Pulse Relay 系の「既存コアを保ったまま別 mechanic を試す」サイクルで、コードレベルの mechanic 生成をどう制約し、どうテスト対象にするかの外部候補。
