## raw_excerpt
arXiv:2512.12834。Shangxuan Luo と Joshua Reiss による、ゲーム向け Procedural Music Generation (PMG) の体系的概観。論文ページでは、PMG をビデオゲーム用の音楽コンテンツをアルゴリズムで作る分野として位置づけ、ルールベースから機械学習までを含める。研究プロトタイプと実用アプリケーションの間には、novelty、reliability、allocated resources など優先順位の違いがあり、そこが乖離を生むとされる。論文は current PMG techniques を二面の taxonomy で整理し、algorithm implementation、music quality、game integration の研究課題を挙げる。今後の方向として "task-oriented and context-aware design"、包括的な品質評価、研究ツール統合を強調する。

## why_relevant_to_games
映像・操作・ルールだけでなく、音楽をゲーム状態に接続する設計材料。小規模ゲームで「状況に応じて音が変わる」手触りを作る時の評価観点になる。
