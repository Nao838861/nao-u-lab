## raw_excerpt

出典は International Journal of Human-Computer Studies の 2026 年論文ページ。論文は、game studies が player-avatar relationship を重視し、HCI が sensory perception や bodily input を重視してきた分断を、movement を perception と interaction の基礎として見ることで橋渡ししようとする。理論面では phenomenology, predictive processing, active inference を組み合わせ、経験を主観的な知覚と神経生物学的プロセスの両方から捉える。

研究は、主要著者が 7 本のゲームを 3 年にわたって遊んだ autoethnographic inquiry を補助線にし、movement が embodied experiences をどう駆動するかを分析する。要旨では、movement sequences の構成が embodied player experiences と technology relationships の key mechanism だと述べ、sequential movement compositions の中に経験の質を形づくる 4 つの dynamics を見いだしたと説明している。

本文では、movement を単なる physical activity、aesthetic、motivational tool としてではなく、player と avatar、身体と technology を結ぶ organising principle として扱う。human-computer action-perception cycle を、身体が technology を取り込んでいくモデルとして提示し、without movement, there is neither action nor interaction という立場から、操作、知覚、意味づけが movement sequence の中で生成されるとする。

## why_relevant_to_games

シューティングやアクションの headless 指標だけでは拾いにくい「操作が身体化する感じ」「入力と画面反応の連なり」を、movement sequence として観察するための外部語彙になる。
