## raw_excerpt

SAGE/Convergence の2025年OnlineFirst論文。Frederik Peper と Nico Wettmann が、ブラウザゲーム RailwayOperator の6週間の参与観察をもとに、待機を単なる中断ではなく、ゲーム内の時間と日常生活の時間を同期させる関係的メカニズムとして扱う。論文の短い原文表現では "waiting is an essential element" とし、待つことが活動と受動性を同時に含む現象だと説明している。

対象ジャンルは、常時進行するシミュレーション型ブラウザゲーム。列車の運行、契約、修理、入札などがそれぞれ別の終了時刻を持ち、プレイヤーは一日中ログインし続けるのではなく、日常のリズムの中で介入する時刻を決める。論文は、こうした待機が「何もしていない時間」ではなく、次の手の計画、他プレイヤーとの調整、アラーム設定、外部生活との折り合いを生む構造だと記述している。結論では、待機が設計された時間と生活時間の間を媒介し、活動/受動、ゲーム/日常、社会/技術の関係をつなぐものとして位置づけられている。

## why_relevant_to_games

待ち時間、クールダウン、非同期進行、放置中の進行を「退屈な空白」ではなく、次の介入を準備させる設計材料として見るための候補。
