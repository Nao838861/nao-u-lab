## raw_excerpt

原文要点メモ。GDC Vault の 2014 Game Narrative Summit セッション。Microsoft Studios の user research group が、production 早期に story を test する narrative usability method を開発したという内容。ページ説明では、players は好きなゲームの narrative でも大きな瞬間や character を断片的にしか覚えていないことがある、と問題設定する。narrative usability は、機能しない twists や confused conclusions を識別し、理解の blocker を取り除くことで characters を活かす。さらに、player experience に基づく experimental testing、dynamic characters への perception tracking、designer vision と compelling experience の整合確認に触れている。speaker は Deborah Hendersen、company は Microsoft。

## why_relevant_to_games

会話・演出・目的提示がある試作で、プレイヤーが何を覚え、どこで誤解し、どの character perception が変化したかを見る候補。LLM 生成 narrative の検証にも使える。
