## raw_excerpt

原文要点メモ。GDC Vault の 2021 Board Game Design Summit セッション。Root は Leder Games の intricate competitive wargame として紹介され、その usability developer が開発中のうまくいった点と失敗例を話す内容。扱う範囲は rules writing、graphic and component design、user experience research など。説明文では、gestalt principles や cognitive load を知っているかに関わらず、プレイヤーが board games を理解しやすくする方法を学べるとされている。speaker は Joshua Yearsley、company は Leder Games。複雑な非対称ゲームにおいて、ルールの面白さだけでなく、理解可能性、視覚構成、コンポーネント設計、ユーザー調査をまとめて扱う postmortem。

## why_relevant_to_games

非対称性や複雑ルールを入れる時、実装前後の「理解できない面白さ」を検出する観点として使える。ルール文、UI 表示、チュートリアル、コンポーネント配置を同時に見る候補。
