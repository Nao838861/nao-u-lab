## raw_excerpt
PocketGamer.biz の 2026-05-28 記事。GDC Festival of Gaming 2026 Trends Report の紹介で、イベント参加者は約 20,000 人、会話の大きな軸として co-development、mobile monetisation、AI、funding / publishing partnership の難しさなどが挙げられている。ゲーム制作に近い部分では、資金・リソース・publish partnership の確保が難しくなり、複数企業で開発する co-development が広がっていること、同時にそれは studio 自身の作業から時間を奪う可能性もあることが紹介される。mobile の文脈では、hypercasual の短い開発時間と、"mechanics over metagaming"、"volume over viability" という傾向が示される。AI は brainstorming、task management、emails での利用支持が consistent とされ、Claude Code への言及もある。
