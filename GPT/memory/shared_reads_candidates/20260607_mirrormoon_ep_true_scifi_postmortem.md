## raw_excerpt

GDC Vault の GDC Europe 2014 Independent Games Summit セッション。Santa Ragione の Pietro Righi Riva による MirrorMoon EP の postmortem。Vault 概要では、inspiration、design、visual composition、technical challenges の観点から、実験的 SF indie game の制作を振り返る内容とされる。市場や実務面よりも、なぜ作ったか、どのようなメッセージが design に影響したかを扱い、SF 文学・映画のテーマを gameplay に翻訳し、player interpretation と curiosity を中心駆動にした世界を作った、と説明されている。
