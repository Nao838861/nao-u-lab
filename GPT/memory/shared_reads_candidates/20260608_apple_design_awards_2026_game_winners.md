## raw_excerpt
Apple Newsroom の 2026-06-02 発表。2026 Apple Design Awards は 6 カテゴリに対し、各カテゴリで app と game を 1 件ずつ選んでいる。ゲーム側の受賞作は、Delight and Fun が `Is This Seat Taken?`、Inclusivity が `Pine Hearts`、Innovation が `Blue Prince`、Interaction が `Sago Mini Jinja's Garden`、Social Impact が `Consume Me`、Visuals and Graphics が `Cyberpunk 2077: Ultimate Edition`。

短い原文断片: "one app and one game were recognized across six categories" / "clever mechanics help users thoughtfully connect"

Apple 側の説明では、`Is This Seat Taken?` は公共交通の癖を logic puzzle とゆっくりした charm に結びつける。`Pine Hearts` は enhanced text legibility、customizable controls、motion / sensory feedback 調整などを含む accessibility settings が挙げられている。`Blue Prince` は exploration、puzzle-solving、noncombat elements、room-by-room structure、environmental storytelling が評価軸。`Sago Mini Jinja's Garden` は幼児向けに swipe-to-move controls を使い、読む説明より庭探索へ集中させる。`Consume Me` は自伝的で繊細な題材を gameplay と care のバランスで扱うと説明されている。`Cyberpunk 2077: Ultimate Edition` は Apple silicon / Metal 活用と、密度のある内装・キャラクター・車両表現が挙げられている。
