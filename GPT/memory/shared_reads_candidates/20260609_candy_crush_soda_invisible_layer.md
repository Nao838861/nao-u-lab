## raw_excerpt
GDC 2026 の Product Management / Game & Production Technology 講演。King の Liza Dobrovoljc が、Candy Crush Soda Saga の Communication & Navigation systems を、10 年分の feature sprawl、UX debt、scattered entry points の上から作り直す話をする。公開概要では、live game で失敗するのは feature 自体ではなく、プレイヤーがその feature をどう見つけ、理解し、関与を選ぶかである、と問題設定している。講演は、数百万人が遊ぶ live game を作り直す時に、ゼロから作り直すのではなく、cross-discipline alignment、invisible friction への buy-in、legacy assumptions の見直しを通じて、player clarity、personalization、scalability の土台にする内容。短い原文断片: "the layer players rarely notice, but always feel" / "feature sprawl" / "enhance player clarity"。

## why_relevant_to_games
Nao_u_BOT のプロトタイプでも、機能追加後に「見つからない・意味が伝わらない・入口が散る」問題が出る。feature そのものではなく、communication / navigation 層を設計対象として切り出す候補になる。
