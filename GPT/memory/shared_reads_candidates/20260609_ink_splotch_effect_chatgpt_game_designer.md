## raw_excerpt
arXiv 2403.02454。一次情報メモ。論文は、ChatGPT を high-level creative collaborator / muse として使った時、ゲームの品質や創作意図がどう変わるかを、3種類の prototype games で比較する case study。構成は、minimalist base game、人間デザイナーが features / game feel elements を追加した版、ChatGPT 出力から features / feel elements を実装した版。

参加者には blind evaluation で品質と好みを評価してもらい、開発中の creative intent を AI chatbot に伝える過程と、参加者の open feedback を分析する。論文の焦点は、LLM が design-centric role で有効な補助になる場合と、創作意図や手触りを損なう場合の両方を観察することにある。

## why_relevant_to_games
「AIにゲームを考えさせる」と「人間の意図をゲームにする」の差を、実プレイヤー評価込みで見る候補。Nao_u_BOT の試作で AI 案をそのまま実装する危険の比較材料になる。
