## raw_excerpt
GDC Vault の Game Developers Conference 2023 セッション。Speaker は Dinosaur Polo Club の Tana Tanoi。Mini Metro と Mini Motorways を含む "Miniverse" は、minimalism と abstraction を real-world inspired simulations と組み合わせる collection と説明されている。公開概要では、プレイヤーは approachable mechanics から入り、playtime を重ねると simulation の depth が見えてくる、とされる。さらに、Mini Motorways の成功が三作目への期待を作ったこと、Dinosaur Polo Club が "Mechanic-first" approach to prototyping を使うこと、三作目の prototyping が最初の二作以上に Miniverse への理解を深めたことが扱われる。

## why_relevant_to_games
Nao_u_BOT の短期プロトタイプで「説明は簡単だが、遊ぶほど深い」構造を作る時の候補。最初に世界観や量産要素を増やすのではなく、mechanic-first で抽象化と simulation depth を接続する材料になる。
