## raw_excerpt
GDC 2026 の Team Leadership / Production 講演。Carey Littlefield (Blizzard Entertainment, Test Lead II) が、World of Warcraft の QA Lead 経験をもとに、QA をリリース直前の安全確認ではなく、設計判断に早期参加する subject matter expert として扱う話をする。ページ上の説明では、QA を設計の味方にすると、単なる安心感以上のものが得られ、intentional collaboration、visibility、qualitative feedback によって feature がプレイヤーに届く前に改善される、としている。takeaway は、embedded QA SMEs が early playtests、sprint-aligned feedback、design visibility を通じて WoW の features を形作った事例と、QA を development / design cycle に統合する実践策。
