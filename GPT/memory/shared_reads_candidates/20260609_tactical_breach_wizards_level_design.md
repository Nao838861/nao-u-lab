## raw_excerpt
GDC Vault の Game Developers Conference 2025 セッション。Speaker は Half Mermaid の Steve Lee。対象は Tactical Breach Wizards の level design process。公開ページの概要では、このゲームの 100 以上の levels が「unusually efficient, straightforward and fun」に作られたこと、level と mechanics の key design principles、そして campaign 全体を sequential order で設計・執筆・実装したことを扱う、と説明されている。通常は避けられがちな「キャンペーン順番通りの実装」を、なぜこの作品では成立させられたのか、また何が critical success と作業体験の良さに寄与したのかが焦点。

## why_relevant_to_games
小規模制作で level 数や encounter 数を増やす時、効率と手触りを両立する設計原則の候補になる。特に puzzle/tactics 系で、mechanics と level sequence を同時に育てる時の参照点。
