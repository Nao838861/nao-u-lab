## raw_excerpt
長文引用ではなく、GDC Vault セッション概要からの要点メモとして保存する。Amanda Farough / Strange Scaffold による GDC 2026 セッションで、題材は Teenage Mutant Ninja Turtles: Tactical Takedown の 18 か月開発サイクル。セッション概要は、大規模スタジオや大きな予算がなくても licensed game を作れるという問題設定から始まり、psychological safety、developer-first production、creativity within constraints、holistic process development を柱として挙げる。開発条件としては part-time developers と modest budget が明示され、dream IP を扱いながら、プロジェクトとスタジオ双方の creative identity を保つ方法を扱うとされている。短い原文断片: "developer-first production" / "creativity within constraints" / "18-month development cycle"。
