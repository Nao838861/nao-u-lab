## raw_excerpt

arXiv 2509.11898。GenAI が game development の practice、production pipeline、value network を大きく変えている一方、その影響は分野・立場ごとの個別研究に散らばり、関連研究との接続や統合が弱い、という問題設定の qualitative research synthesis。対象は 2020-2025 年の HCI / games research database を含む systematic search で、PRISMA-S、meta-ethnography、eMERGe、CASP quality appraisal などの手順を使っている。

論文ページの要約では、eligible studies は 10 件。reciprocal translation と line-of-argument synthesis を行い、9 つの overarching themes、recommendations、game production trajectories との contextualisation を提示するとされる。短い原文断片では "production pipelines"、"grounded insights"、"practice, research and governance" が中心語。本文には ancillary files として included papers / interpretation code / synthesis map も付いている。
