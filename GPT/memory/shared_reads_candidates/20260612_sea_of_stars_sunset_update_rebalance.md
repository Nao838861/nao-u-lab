## raw_excerpt

GamesRadar+ の 2026-06-09 記事。Sabotage Studio が `Sea of Stars: Sunset Edition` を最終アップデートとして出し、2023 年リリース後の章を閉じる流れを扱っている。記事によると、開発と運用は 7 年超の journey として言及され、無料拡張 `Throes of the Watchmaker` も含む post-release support の最後に位置づけられる。

内容は大規模追加ではなく、冒頭 cinematic の追加、過去の英雄に顔を与える演出、重要 flashback の拡張、Normal / Hard mode の最終 rebalance が中心。難度調整では `Tactician's Mettle` relic の属性を `Tactician's Mettle` と `Ray of Sunset` に分離し、Normal mode により手応えを持たせる形だと説明されている。記事末尾では、Sabotage Studio が次作 `Project Sparrow` の pre-production を 1 年以上並行して進めていることにも触れている。
