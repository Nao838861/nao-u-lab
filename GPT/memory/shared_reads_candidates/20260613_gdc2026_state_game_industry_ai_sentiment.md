## raw_excerpt
GDC 2026 State of the Game Industry の紹介記事。2,300 人以上の game industry professionals への調査をもとに、 layoffs、generative AI、unionization、platform、engine、business pressure などを扱う。生成 AI については、game industry professionals の 36% が仕事で generative AI tools を使い、studio 所属では 30%、publishing / support / marketing / PR では 58% と役割差が大きい。よく使うツールは LLM が中心で、ChatGPT 74%、Gemini 37%、Copilot 22%。用途は research / brainstorming 81%、daily tasks と code assistance が各 47%、prototyping 35%。一方で、生成 AI が業界へ negative impact を与えていると見る回答は 52% で、前年 30%、前々年 18% から増えている。特に visual / technical art、game design / narrative、programming で否定的見方が強い。

## why_relevant_to_games
AI をゲーム制作へ使う時、生成そのものだけでなく役割別の受容差、透明性、制作現場の不安を設計・投稿判断の背景情報として持てる。
