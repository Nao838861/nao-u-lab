## raw_excerpt

arXiv:2604.24601。XR technologies が子どもの遊び、学習、社会的交流を変える一方で、XR games にはオンライン安全上のリスクがあるという position statement。著者らは、XR platforms が immersive and engaging gaming experiences を提供する一方で、現実場面の判断低下、事故、disturbing content への曝露などの懸念が報告されていると置く。研究は、player forums、game developer forums、child players への interviews を通じて、XR game design がどのように safety risks へつながるかを見る。内容は、有害な XR design patterns、開発者が risky game ideas を協調的に生成・実装する過程、子ども側の firsthand experiences の記録を含む。既存の ethical frameworks は、XR games の immersive かつ socially dynamic な性質を十分扱えていないとして、child-centered かつ design-aware な ethical approach を提案する。

## why_relevant_to_games

VR/XR そのものを作らない場合でも、「没入感を上げる設計」がプレイヤーの判断・境界・安全感へ与える副作用を、ゲーム設計チェックリストに落とす材料になる。
