## raw_excerpt

Creative Bloq の 2025-12-26 記事。Demon Tides は Demon Turf の続編で、前作の 2D sprites in a 3D world は retro aesthetic というより、当時チームに 3D character model 経験者がいなかったという technical limitation から生まれたと説明される。続編ではチーム規模が倍になり、3D model と cel-shaded style に移行し、cutscenes や 2D sprites では難しかった gameplay mechanics も可能になった。短い原文断片: "expressive platforming" / "Fabraz Framework"。

記事では、Demon Tides の world design への影響として Super Mario Sunshine、Bowser's Fury、The Wind Waker、Elden Ring が挙げられる。Elden Ring については、隅々に vista、lore、loot など何か見つける価値がある点が参照されている。movement については、「同じ gap を何通りで渡れるか」「movement を通じて自己表現できるか」という問いが中心で、新しい boost ability により bat jump、bounce、spin、drilled down spin jump などの連鎖実験が広がる。制作体制では Unity 上に custom Fabraz Framework を積み、Demon Tides と Bubsy 4D を同時に進める初期セットアップ短縮にも触れている。

## why_relevant_to_games

小規模チームの制約から生まれた見た目を、次作でどの能力増加に合わせて捨てるか、movement の組み合わせ自由度をどう中核に置くか、というプロトタイプ設計の材料になる。
