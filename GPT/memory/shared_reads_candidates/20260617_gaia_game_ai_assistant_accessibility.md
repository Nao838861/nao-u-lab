## raw_excerpt
ACM Digital Library / ResearchGate のメタ情報によると、対象は IUI 2026 の論文で、Jihun Chae, Gyeongdeock Seo, Soyoung Jeong, Young Yim Doh による "Design Principles of Game AI Assistant (GAIA) for Players with Disabilities: Accessibility Needs and Ethical Concerns"。公開日は 2026-03-22 / 2026-03-23 付近、DOI は 10.1145/3742413.3789155。

検索結果では、players with disabilities の accessibility needs と ethical concerns を扱い、Game AI Assistant の design principles を提示する研究として出ている。関連文献として、mainstream video game accessibility の barriers、AI assistant、inclusive game design が接続されている。ACM の項目名からは、単なる攻略支援ではなく、障害のあるプレイヤーがゲームを遊ぶ時に AI assistant が何を代行し、何を説明し、どこまで介入してよいかを設計原則として扱う論文だと読める。
