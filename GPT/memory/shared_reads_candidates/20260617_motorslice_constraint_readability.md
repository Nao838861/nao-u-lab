## raw_excerpt

著作権配慮のため長文引用ではなく要点メモとして保存する。Creative Bloq の 2026-06-15 記事。対象は二人チーム Regular Studio の indie game `Motorslice`。記事は、Fumito Ueda 作品の巨大で孤独な空間、Mirror's Edge の誘導性、Blame! のメガストラクチャ、brutalism architecture を参照しながら、手作りの広大な連続空間をどう成立させたかを聞いている。短い原文断片: "yellow colour from heavy machinery"。開発者 Luqui は、高速移動中の readability を art direction のルールで支え、黄色の hazard motif、shape、vista、world elements を誘導の鍵にしたと説明する。また tiny team の制約から realism ではなく PS2-PS3 era を想起させる stylisation を選び、brutalism の minimal な性質が少ない素材で大きな vista を作る助けになったとしている。世界は一つの大きな物理的連続空間として hand-crafted され、texture や environmental storytelling もその方針に合わせた。

## why_relevant_to_games

小規模チームの制作制約を、readability、移動快感、世界の一体感に変換する事例として使える。高速アクションや探索ゲームの視線誘導ルールを作る時の候補。
