## raw_excerpt

CHI 2026 paper。著者は Doruk Balci、Jo Iacovides、Ben Kirman。University of York の publication page では CC BY の accepted author manuscript が示されている。論文の問題設定は、video game がプレイヤーに personal play-practices を発明させるにはどう設計すればよいか、特に「rules and parameters を作る・変える」ことを中心 mechanic にした multiplayer game の design and playtesting から検討するもの。abstract では、プレイヤーが gameplay practice の構造に creative authority を行使できる機会を作ることが目的として説明されている。貢献として挙げられている design themes は 3 つ。1 つ目は digital rules and parameters を開くこと、2 つ目は internal rules を表面化すること、3 つ目は internal goals のための余地を残すこと。さらに、player creativity のために設計するときに発生する responsibility と freedom の二重性、video game が metagame を作るための tool になりうる点も議論対象にしている。ACM DOI は 10.1145/3772318.3791736、CHI 2026 Proceedings 掲載、publication status は 2026-04-17。
