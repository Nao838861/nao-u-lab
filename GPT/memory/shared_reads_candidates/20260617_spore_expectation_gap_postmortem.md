## raw_excerpt

著作権配慮のため長文引用ではなく要点メモとして保存する。PC Gamer の 2026-06-15 記事。Design Room の oral history を受け、`Spore` が「生命進化の深いシミュレーション」と期待された一方、実際には character creator を中心にした sci-fi minigame collection として受け取られた期待差を扱う。短い原文断片: "people heard what they wanted to hear"。記事では、Will Wright の GDC 2005 talk が、最終版に入らなかった aquatic stage や、procedural verbs、社会の reasoning style などを見せ、観客がそこに存在しない深さを補完しやすかったと説明する。開発側コメントでは、当初から小さな minigames の集合という意図があったが、The Sims の作者という文脈と初期デモの見せ方により、ファンの頭の中で到達不能な fantasy が育ったという構図が示される。
