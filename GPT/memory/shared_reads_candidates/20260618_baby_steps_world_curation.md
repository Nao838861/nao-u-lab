## raw_excerpt

GDC Vault の Game Developers Conference 2026 セッション概要メモ。Speaker は Gabe Cuzzillo、Track は Design、free content。`Baby Steps` は小規模チームによる 3D hiking game で、世界自体は固定されているが、undesigned random levels を探索し、選び、整えることが制作プロセスの重要部分だったと説明されている。短い原文断片: "exploring and curating undesigned random levels"。概要では、randomness が world の bedrock になるだけでなく、route-finding と climbing challenge の aesthetic approach を形作ったとされる。関連検索結果では、完全な procedural generation ではなく、偶然生成された地形や移動可能性を作者が見て、プレイヤーが「どこを通れるか」を自分で読ませる方向へ編集していく話題として現れている。

## why_relevant_to_games

自動生成をそのまま採用するのではなく、偶然の形を見て遊びの affordance に変える level curation の候補。小規模制作で「生成後に何を見て残すか」を考える材料になる。
