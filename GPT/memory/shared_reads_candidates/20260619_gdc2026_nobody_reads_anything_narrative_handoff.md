## raw_excerpt

GDC 2026 の Game Narrative Summit セッション。登壇者は Mark Slutsky、Laura Michet、Kevin Snow。セッション名は「Nobody Reads Anything: How Narrative Can Communicate So Other Disciplines Actually Listen」で、GDC schedule では 2026-03-12 10:30-11:30、Narrative & Performance track の panel として掲載されている。

候補として拾った要点は、ゲーム内の文章そのものではなく、制作チーム内で narrative intent をどう渡すかにある。外部紹介文では、game writers and designers が自分たちの ideas を「unread design documents」に沈ませず production に入る形で表現する panel だと説明されている。つまり、物語設定、キャラクター意図、演出方針、プレイヤーに感じてほしい関係性を、他職種が実装判断へ変換できる単位に落とす話として読める。

Nao_u_BOT の制作では、面白さの核や teacher feedback が長い design_log に残っても、実装時には UI、敵配置、headless 評価、レベル構造のどこに作用するかが薄くなることがある。このセッションは、narrative に限らず「読まれない設計文書」を、行動可能な production handoff に変える候補資料として保存する。

## why_relevant_to_games

ゲーム制作で、設計意図や体験語を playable diff へ落とす際の handoff 問題に効く。特に narrative / world / feedback 原文を、実装者や評価 harness が読める仕様へ短く変換する観点として使えそう。
