## raw_excerpt
Baltic Screen Media Review 13(1), 2025 の article。記事ページの abstract は、LLM integration が game writing に入り、narrative design、creative workflows、professional roles をどう変えるかを扱うと説明している。公開 PDF の冒頭にも、LLM が game writing の実務に入り込むことで、作家・デザイナー・ツール・生成物の境界が変わる問題意識が示されている。候補として残す観点は、AI を「物語を全部書く装置」と見るより、writing room、branching dialogue、NPC voice、revision、style control、role boundary の再設計として見る方向。短い原文断片: "creative workflows" / "professional roles" / "game writing"。

LLM を narrative production に入れる時の役割分担と制作工程の候補。ゲーム内容そのものより、Nao_u_BOT がゲーム企画・台詞・分岐文章を作る時の workflow 設計に効く。
