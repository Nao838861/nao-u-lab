## raw_excerpt

arXiv:2604.15318v1。論文は Soulslike の高難度と頻繁な失敗を、通常の「摩擦を減らす」設計とは別の player experience として扱う。中核語は Resilient Flow で、失敗や frustration が楽しさを壊すのではなく、意味づけられた学習素材として framed される時、プレイヤーの没入が維持されるという整理。Elden Ring、Sekiro: Shadows Die Twice、Dark Souls III の Steam helpful reviews 600 件を質的に分析し、熟練プレイヤーが死を punishment ではなく pedagogy として語ること、combat を violence から rhythm / dance / performance の語彙へ言い換えること、fairness と control consistency が失敗の納得感を支えることを見ている。本文では、unfair frustration と motivating challenge の境界を game feel、precise controls、consistent world、Ethics of Attention に置き、難しさが player agency を壊す時と、mastery へ変わる時の差を扱う。

## why_relevant_to_games

難度・失敗・理不尽さの境界を、弾幕/避けゲー/アクション試作の「死んでも続けたい」設計メモへ落とせる候補。
