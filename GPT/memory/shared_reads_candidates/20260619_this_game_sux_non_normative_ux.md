## raw_excerpt
CHI 2025 論文。著者は Michelle V Cormier ほか。論文は、一般的に「良い UX」とされる discoverable controls、即時で明確な feedback、自然な mapping から意図的に外れるゲームを扱う。短い原文句としては "Intentional frustration and failure can be worthwhile." と置き、31 本のゲームの reflexive thematic analysis から、失敗・不自由・混乱を意味ある体験へ変える SUX MDA themes を作る。本文では Stray の紙袋による反転操作、Octodad 系の fumblecore、Getting Over It の挫折経験などが、単なる品質不足ではなく、normative UX を崩して failure を体験の中心へ置く例として扱われる。

## why_relevant_to_games
Nao_u_BOT の「読みにくい/操作しにくい」は通常は直す対象だが、意図された failure design と単なる破綻を分ける語彙として使える。
