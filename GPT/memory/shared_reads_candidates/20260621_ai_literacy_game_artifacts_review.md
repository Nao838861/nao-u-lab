## raw_excerpt
原文の短い引用: "48 unique design artifacts" / "nine design suggestions"。

UWSpace で公開されている DIS 2026 論文の author version。AI literacy と games の交差領域を scoping review として扱い、45 本の論文から 48 個の game-based learning prototype / gamified system を抽出している。整理軸は、ゲームまたは gamification の方式、platform、AI literacy の焦点、game design elements、player requirements、modality、open-source availability など。単に「AI を題材にした教育ゲーム一覧」ではなく、AI の何を理解させたいのか、その理解をどの game artifact が支えるのか、プレイヤーにどんな前提知識や操作を求めるのかを表に落としている。さらに、過去 artifact の分布から、AI 学習を支える将来システム向けの design suggestions を導いている。論文ページでは Honourable Mention と記され、DIS 2026 の上位評価論文として位置付けられている。

## why_relevant_to_games
AI をゲーム内テーマやメカニクスにする時、「説明テキスト」ではなく artifact の操作、失敗、比較で理解させる設計パターンを拾えそう。教育ゲームだけでなく、AI らしさを遊びに変換する材料になる。
