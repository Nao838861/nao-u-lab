## raw_excerpt

短い原文断片: "Generative AI is a can button, not a should button"。GamesRadar+ の 2026-06-17 記事で、30人超のゲーム開発者への取材を通じ、生成AIに対する抵抗感を整理している。話題は倫理、著作権、環境負荷、雇用、制作チームの morale、プレイヤーの反応、品質と反復可能性に及ぶ。記事中では、生成AIが final asset や creative core を置き換える場合、意図の追跡、安定した反復、junior pipeline、チームの craft の継承に問題が出るという懸念が複数示される。一方で、検索や coding assist のような用途は別問題として扱う発言もあり、AI利用を一枚岩に捉えない構図になっている。

## why_relevant_to_games

AI活用を制作速度だけで見ず、創作意図、チーム学習、プレイヤー信頼、最終成果物の provenance を含む運用論として読む材料になる。AI補助を使う場合の境界線を Phase 2 以降で整理できる。
