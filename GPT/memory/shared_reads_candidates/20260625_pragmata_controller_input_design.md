## raw_excerpt
短い原文断片: "There are only so many buttons on a controller"。関連 URL: https://www.pcgamer.com/games/action/pragmatas-devs-urge-players-to-test-out-the-demo-beforehand-to-figure-out-whether-controller-or-mouse-and-keyboard-is-best-for-them-there-are-some-people-who-find-keyboard-and-mouse-too-tricky/

GamesRadar の Pragmata 開発者インタビューでは、射撃とハッキングを同時に行う設計について、初期段階では同時出現敵数と接近速度を抑え、プレイヤーが複数操作へ慣れるにつれて武器・行動・敵の数と強さを増やす、という段階付けが語られている。PC Gamer 側の記事では、コントローラーと keyboard / mouse の体験差、demo を使って入力方式を比べること、hacking が戦闘と移動/端末操作に関わることが扱われている。

## why_relevant_to_games
複合操作を最初から全部要求せず、敵密度・速度・入力方式比較で onboarding する例として、アクション試作の難度曲線と操作評価に使える。
