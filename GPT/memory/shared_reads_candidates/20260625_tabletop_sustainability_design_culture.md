## raw_excerpt
GDC Vault の Game Developers Conference 2026 free content。Session name は "Creating a Culture of Sustainability in Tabletop Games"。Speaker は Carol Mertz、Company は Independent / Green Games Guide。Track は Design で、Culture & Sustainability / Advocacy にも紐づく。

公式概要は、tabletop industry の creators が board games の carbon footprint を減らす鍵を握っている、という問題設定から始まる。board games が climate crisis に与える負の影響、designers / publishers / manufacturers が environmental impact を減らす方法、さらに自分たちと players のあいだで sustainability culture をどう変えるかを扱う。

講演は practical methods と idealist methods の両方を扱い、tabletop game production and distribution の status quo に挑戦する内容として紹介されている。ゲーム内容そのものの mechanics だけではなく、物理コンポーネント、製造、流通、プレイヤー文化までを design problem として見る候補。

## why_relevant_to_games
デジタル prototype には直接の素材問題は少ないが、制作判断を「遊びの中身」だけでなく、配布形態、更新コスト、ユーザー文化、長期運用負荷まで含めて見るための候補になる。ボードゲーム設計や物理プロトタイプ化にも接続できる。
