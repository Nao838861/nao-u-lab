## raw_excerpt
arXiv:2606.13722。2026-06-11 submitted。Jory He による YeasierAgent の提案。論文は、アプリケーションを固定 GUI レイアウトや端末依存の画面としてではなく、user、agent、world が協働する場として再定義する。中核語は symbiotic agents、narrative worlds、scene-aware interaction。原文では application を "collaborative spaces among users, agents, and worlds" と表現している。

システム上の主張は 2 つ。1 つ目は、agent、scene、dialogue などの platform-agnostic interactive units を使い、cross-platform な agent-native application を素早く作ること。2 つ目は、感情的な companionship と実用的な tool execution を、同じ experiential sandbox に入れること。abstract では、automated generation、user-created worlds、spatial multi-agent collaboration を統合し、chatbot から socially embedded computational environments へ移る整理になっている。

## why_relevant_to_games
ゲームとツールの境界を、scene、dialogue、agent、world の組み合わせとして考える資料。LLM NPC や agent-native な制作ツールを「画面」ではなく「場」として設計する時の候補材料になる。
