## raw_excerpt
短い引用: "Interactive Ideation, Iterative Rulebook Generation, and Individualized Feedback"

短い引用: "Designing a board game demands both thinking as a designer and experiencing as a player"

要旨メモ: AutoBG は、曖昧な初期アイデアからボードゲーム案を作り、ルールブックを反復生成し、個別フィードバックを返す支援システムとして提示されている。arXiv の説明では、現行システムは early ideation から rulebook revision、audience testing までの end-to-end 支援が不足している、という問題設定。構成要素は、対話で制約や構想を引き出す BG-Ideator、構造化ドラフト生成、フィードバックに基づく rulebook refinement、想定プレイヤーからの individualized feedback を扱う流れ。

## why_relevant_to_games
小規模プロトタイプの「ルール案を作る」「説明可能なルールブックに落とす」「想定プレイヤー別の反応を見る」工程の外部事例として使える。
