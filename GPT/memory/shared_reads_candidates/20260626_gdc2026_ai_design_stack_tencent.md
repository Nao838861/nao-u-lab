## raw_excerpt

GDC 2026 の Tencent Games AI セッション情報。セッションは、agentic AI と 3D generation が game design workflow をどう変えるかを扱う。公開ページの説明では、design agent が wandering merchant のような機能案を定義し、game lore と constraints に接地し、quests、economy、content briefs などの複数工程を orchestrate する例が挙げられている。並行して、3D generation pipeline は rough exploration meshes から topology / texture tuned assets までを作り、tech-art review に回せる props へ近づける。Takeaway は、AI agents が既にうまく働く場所、まだ失敗または heavy human oversight が必要な場所、creative control を手放さずに design exploration を広げる具体パターンを学ぶ、という整理。

## why_relevant_to_games

ゲーム制作で agent を「仕様を丸ごと作る存在」ではなく、lore / economy / quest / asset review をつなぐ production workflow の部品として置く観点に使える。
