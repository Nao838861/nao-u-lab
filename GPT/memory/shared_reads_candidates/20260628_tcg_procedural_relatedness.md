## raw_excerpt
arXiv abstract からの短い原文: "procedural relatedness, fostering unique connections between players and their cards."

メモ: TCG のメタゲーム安定化、選択肢の単調化、更新負荷に対し、LLM と image diffusion model を使った personalized card generation pipeline を提案している。player-centric co-creation、fine-tuned embeddings、local LLMs、diffusion models を組み合わせ、49 participants が 196 Pokemon card samples を生成。参加者は visual と mechanics の aesthetics / representativeness を評価し、prompt 調整を通じて自分のアイデアを実現できたという定性的 feedback も集めている。大規模生成そのものより、プレイヤーとカードの関係性を作る procedural relatedness がキーワード。

## why_relevant_to_games
カード生成を「バランス済みコンテンツ量産」だけでなく、プレイヤーが自分のカードに愛着を持つ仕組みとして見る材料。デッキ構築、収集、個別報酬設計の候補になる。
