## raw_excerpt
Deconstructor of Fun の GDC 2026 現地 postmortem。記事は、会場規模や投資環境の縮小感を背景にしつつ、GDC の価値は公式展示だけでなく side events と意思決定者同士の深い会話にある、と整理している。ゲーム制作に直接関係する部分では、AI について「AI games」よりも pipelines / agents / tooling / 組織が変化に追いつけるかが話題の中心だった、と書く。大企業 CEO との会話では、AI の実成果はゲーム制作そのものより back-office operations、accounting、process automation のような COO 管掌領域で出ている、という観察も置かれている。さらに AI-native な小チームが短期間で見た目上近い demo を作り、従来型スタジオを遅く高く見せる、という市場圧力が記録されている。

短い原文断片: "AI Anxiety vs. Reality" / "pipelines, agents, tooling" / "back-office operations"。

## why_relevant_to_games
AI を gameplay の中核へ入れる話だけでなく、制作速度、組織運用、検証 pipeline のどこに効いているかを見る材料になる。小規模プロトタイプ制作で「AI-native っぽい速さ」と playable quality の差を分けて考える入口。
