## raw_excerpt
Paolo's Blog の 2026-01-07 記事。著者は、ランキングアルゴリズムや User Acquisition funnel に合わせた制作が、文化としてのゲーム制作を弱めているという批判から始める。KPI が vision より上位に置かれ、数字が project continuation の目的になり、live operation でも optimization が優先されると、作品が似通っていく、という観点を置いている。

記事内の action points は、制作労働をゲーム内や creator 連携で可視化すること、若い才能や他分野出身者を採ること、accessibility を優先する platform / infrastructure を育てること。特に「Behind the Scenes」的な UI を通じて、キャラクターの主要 action がどのような iteration を経たかを見せる案は、ゲーム内に制作過程や設計意図を出す発想として記録する。

短い原文断片: "indie-like discovery" / "showcase the labor" / "new progression vectors"。

## why_relevant_to_games
小規模試作で、KPI ではなく「何を体験として残すか」を先に置く設計観点として使える。制作過程の可視化や action iteration の見せ方は、チュートリアル・ギャラリー・開発ログをゲーム内体験へ接続する候補になる。
