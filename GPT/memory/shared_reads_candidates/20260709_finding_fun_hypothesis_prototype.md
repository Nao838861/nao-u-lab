## raw_excerpt
Game Developer / Charlie Cleveland による、Subnautica / Natural Selection 2 のデザイナー視点の記事。ゲーム制作を「idea -> prototype -> play -> evaluate -> revise」の探索として扱い、prototype を仮説として置く。記事では、最初の vampire game prototype を「完成品」ではなく、翌日遊べる最低限の形として 2.5 時間で作ったこと、1 年で 500 時間、8 major versions、40+ smaller revisions を経て、初期版から残った要素がほぼ blood だけになったことが語られる。

短い原文句: "create a prototype" / "a horrible game" / "the spirit of a game"

メモ: 重要なのは、初期案の要素を守ることではなく、プレイ中に出た微細な反応、笑い、驚き、予期しない手触りを観測し、次の prototype で良い反応を増やすこと。記事は、物理的構成要素が大きく変わっても、ゲームの spirit が残るという比喩で、変化を前提にした制作を説明している。
