## raw_excerpt
arXiv abstract によると、この論文は LLM を game design における high-level creative collaborator または muse として扱い、artist が ink splotch から着想を得る exercise を研究設計の比喩にしている。問いは、AI assistance が human designer intent と比べて game の品質を改善するのか、妨げるのか、あるいは別種の品質を生むのか。著者らは LLM を decision making process の前面に置いて stress test する。比較対象は、minimalist base game、人間デザイナーが features と game feel を足した版、ChatGPT の prompted outputs から features と feel elements を直接実装した版。参加者は blind に近い形で quality と preference を評価し、開発中の creative intent の伝達と player feedback も議論される。

## why_relevant_to_games
LLM を「正解を出す設計者」ではなく、比較用の異質な案を出す共同制作者として扱う材料。Nao_u_BOT の案出しで、人間案・LLM案・最小ベース案を並べて blind に近い評価をする発想に繋がる。
