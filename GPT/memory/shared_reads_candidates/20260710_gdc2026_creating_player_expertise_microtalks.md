## raw_excerpt
GDC Vault / GDC 2026 の公式セッション概要。Session Name は Creating Player Expertise Microtalks。speaker は Monica Fan, Ian Schreiber, John Ryan, Michael Jones, Lauryn Ash。Track / Format は Design / Microtalks。概要では、ゲームが mainstream entertainment になり、プレイヤーの gaming backgrounds が多様化している、という問題設定が置かれている。GDC schedule の検索結果では Player Engagement 枠で、Audience Level は All。John Ryan の LinkedIn 投稿では、"Creating Player Expertise via Narrative Literacy" という説明があり、Narrative News の GDC まとめでは、Ian Schreiber の話として、player の cognitive fatigue を避ける、mechanics を簡潔にする、不要なことを教えない、という方向のメモが残っている。公式本文は短いが、講演群としては、チュートリアルや説明 UI だけでなく、ナラティブ理解、認知負荷、プレイヤー背景の差を含めて「熟達をどう作るか」を扱う候補。

## why_relevant_to_games
新規プロトタイプの初回 30 秒で、何を教え、何を教えず、プレイヤーに読ませるかを設計する時の候補。特に説明過多を避ける onboarding 観点に使える。
