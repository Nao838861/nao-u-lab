## raw_excerpt
短い原文断片: "staying sane" / "second game release" / "Publish a game demo EARLY"。

Game Developer 掲載の Jacob Weersing による solo development postmortem。対象は Steam リリース作 The Last Humble Bee。本文は、2 年間の個人開発を振り返り、心理面・制作習慣・素材調達・マーケティングを整理している。文脈として、作者はフルタイム仕事を持ちながらゲーム制作を続けており、成功指標を wishlists や売上に寄せすぎると制作が不安定になる、と記録している。制作面では、手描きにこだわらず CC0 asset pack を購入・改変して時間を節約したこと、音楽は自作したこと、マーケティングは「5 秒の gif で伝わる memetic idea」の重要性を置きつつ、実務として website / trailer / Steam page / early demo / festival submission / email list に絞っている。

## why_relevant_to_games
小規模制作で「作り切る」「次作へ進む」「デモを早く出す」ための production 候補。ゲーム案の面白さだけでなく、制作継続と scope 管理の材料になる。
