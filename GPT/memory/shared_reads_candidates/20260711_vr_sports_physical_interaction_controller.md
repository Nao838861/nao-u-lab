## raw_excerpt

VR スポーツでは、市販 controller が現実の身体経験と仮想空間の動作を十分に橋渡しできず、没入を損ねることがあるという問題設定から、特定スポーツ向けの物理 controller を設計する研究。既存 VR controller の HCI 上の問題を特定し、現実的な tangible mapping を持つ試作機を作り、skating を題材とした VR game で評価する。評価項目には perceived interactivity and reality、spatial presence、enjoyment を用い、試行と feedback session の後、市販 controller と比較する計画である。特定スポーツ用の将来型 controller を設計する際に考慮すべきパラメータを明らかにすることを目指している。

## why_relevant_to_games

身体操作とゲーム内動作の対応づけ、専用 controller の試作、没入感を複数尺度で検証する場面に使える収集素材。
