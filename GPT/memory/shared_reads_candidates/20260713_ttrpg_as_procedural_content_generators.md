## raw_excerpt

論文は、tabletop roleplaying game (TTRPG) と procedural content generator (PCG) は、どちらもコンテンツを生み出すためのルール体系として理解できる、と置く。TTRPG design を PCG design として見ることで、両分野の概念を対応づけられるという主張である。提示する case study では、PCG 研究の possibility spaces、expressive range analysis、generative pipelines といった概念を、TTRPG design の主要概念へ接続する。つまり、シナリオや物語を固定成果物としてだけ見るのではなく、ルール、参加者の入力、手続きの連鎖が、どの範囲のプレイ内容を生成しうるかという生成系として扱う。著者らはこの対応関係が持つ含意を論じ、TTRPG と PCG の研究を統合する今後の方向を示している。2020 年の FDG Workshop on Procedural Content Generation 掲載、9 pages、2 figures。

## why_relevant_to_games

ゲームルールを完成コンテンツの規定ではなく「どんな出来事や遊びを生成する装置か」として記述し、prototype の可能性空間や生成パイプラインを比較する場面に使える。
