## raw_excerpt

本研究は、生理データをゲーム入力へ明示的に割り当てる biofeedback を扱い、1 つの game mechanic に 1 センサーを割り当てる unimodal 条件と、2 種類の生理センサーを同時利用する multimodal 条件を比較する。著者は 8 種類の mechanic を備えた FPS を制作し、通常操作、unimodal biofeedback、multimodal biofeedback の 3 条件を用意した。32 人の regular player が各条件を体験し、Fun、Ease of Use、Originality、Playability、Favourite Condition を比較したほか、IMI questionnaire、keyword association、自由記述も収集した。

通常操作は使いやすさで優位だった一方、biofeedback の 2 条件は楽しさで評価された。unimodal 条件は単純さ、multimodal 条件は realism、mechanic の誤作動を避ける activation safety、ゲームへ加わる depth が異なる長所として挙げられた。著者は、multimodal biofeedback の効果は mechanic 内での使い方に依存し、能力使用時の empowerment を強める用途にも、身体的努力を要求して意図的に action を難しくする用途にもなり得るとしている。

原文の短句: “the most fun” / “realism, activation safety” / “added depth”

## why_relevant_to_games

入力方式を便利さだけでなく、能力の手応え、誤発動防止、身体的コストという mechanic の一部として設計し、通常・単一信号・複合信号を同一 prototype で比較する場面に関係する。
