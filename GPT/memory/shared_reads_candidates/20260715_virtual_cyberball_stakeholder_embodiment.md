## raw_excerpt

原文の短い核: “designing for intuitive use, inclusivity, and realistic experiences versus minimalism.”

収集メモ: 著者らは Unity3D 製の没入型 Cyberball prototype に avatar customization template を組み込み、Cyberball を知らない naive participant 5 名と、この実験パラダイムを使ってきた researcher 10 名、計 15 名に対して詳細な user testing / feedback session を行った。両群の意見は、直感的な操作、包摂性、現実感を増す設計と、研究課題を余計な要素で乱さない minimalism の間で分かれた。avatar customization の system design 自体が否定的な経験を生んだり強めたりし得ること、単一の利用者群だけでは拾えない論点があることを報告している。論文は 6 ページ、8 図で、CSCW 2023 Companion Proceedings 掲載。

## why_relevant_to_games

prototype の feedback を初心者と domain expert に分けて採る設計、および avatar customization・没入感・最小構成の衝突を観察する場面に使える。
