## raw_excerpt

Game Developer が Creative Assembly の creative director Al Hope と animation director Simon Ridge に聞いた『Alien: Isolation 2』の設計インタビュー。初代の直後に続編へ進まず12年空いたことで、当初は賛否のあった妥協の少ない stealth survival horror が、配信や長期的な再評価を通じてどこを支持されたのか観察できたという。開発側は初代の成功要素をそのまま複製するのではなく、xenomorph との cat-and-mouse、限られた資源、静的な save station、高リスクな緊張を土台として、緊張と解放の cycle をより広い空間で組み直そうとしている。

続編では、密閉された interior から脱出した時には一時的な安堵を与える一方、屋外では遮蔽物の少なさから露出と脆弱さを感じさせ、今度は屋内へ戻りたくさせる。claustrophobia と exposure の間を往復する emotional seesaw を、場所の切替そのものに担わせる構想である。また初代の adaptive alien が playthrough ごとに異なる encounter を作り、livestream 上で player-made survival story として共有されたことも、続編で伸ばす基盤として挙げられている。長期間に蓄積した audience reaction が、何を残し何を拡張するかを判断する材料になったという内容。

## why_relevant_to_games

続編で既存作の核を複製せず、空間の対比を使って緊張―解放 cycle を拡張する場面と、長期のプレイヤー反応を設計入力へ変える場面に参照できる。
