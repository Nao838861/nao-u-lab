## raw_excerpt

Game Developer の Bryant Francis による分析と Fumi Games 開発者への取材。『Mouse: P.I. For Hire』は、1930 年代の rubber-hose animation と film noir を下敷きにした FPS だが、単なるパロディではなく、失踪事件、殺人事件、shrew の誘拐という三つの謎、登場人物同士の履歴、警察・政治勢力・カルトの思惑を重ねている。開発側は、探偵を主人公にする以上、解くべき謎と hidden agenda を持つ人物が必要だと考え、running and gunning を妨げない detective experience を目指した。登場人物が cheese joke や cartoon physics を日常として真剣に扱うことで、観客だけが可笑しさを受け取る構造を作っている。

また、物語上の pocket dimension “The Unknown” を level design の許可装置として使い、映画スタジオ、riverboat、swamp、gothic locale から false doors、non-Euclidean geometry、cosmic horror へ段階的に展開する。rubber-hose animation の歴史にも horror 表現があったため、異ジャンル混合を単なる唐突な引用にせず、表現史と level setpiece の双方へ接続している。一方で記事は、実在の fascism、警察の加担、少数者迫害を複数の現実史から架空種族へ混ぜた部分では、何を具体的に批評し何を娯楽上の寓意として扱うのかが曖昧になり、fictional species difference が現実の偏見を薄めたり誤って補強したりする危険も指摘する。

## why_relevant_to_games

visual pastiche、登場人物の真剣さ、謎、level setpiece を同じ世界設定へ結ぶ方法と、現実史を架空種族へ圧縮する際に比喩の責任範囲が曖昧になる失敗を、narrative prototype の設計・レビュー材料として使える。
