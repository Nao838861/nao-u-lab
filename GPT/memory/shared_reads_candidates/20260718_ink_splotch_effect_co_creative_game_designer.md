## raw_excerpt

本論文は、LLM がゲームデザインにおける高水準の共同制作者、あるいは発想を誘発する「ミューズ」として働けるかを調べるケーススタディである。抽象的なインクの染みから着想する芸術家の訓練を研究モデルに採り、AI 支援が人間の設計意図だけで作ったゲームと比べて、品質を改善するのか、妨げるのか、あるいは別種の品質をもたらすのかを問う。

LLM を意思決定の前面に置いて能力をストレステストし、3 ジャンルそれぞれについて三つのプロトタイプ条件を用意した。条件は、最小限のベースゲーム、人間のゲームデザイナーが機能と game feel 要素を追加した版、ChatGPT のプロンプト出力から機能と feel 要素を直接実装した版である。参加者は出自を伏せられた状態で各ゲームの品質と好みを評価した。研究では、創造的意図をチャットボットへ伝える開発過程と、参加者の自由記述を統合したフィードバックを扱い、AI を設計中心の役割に置く際の利点と不足点を検討する。論文は 12 ページで、2024 年3月4日に arXiv へ投稿された。

## why_relevant_to_games

同じベースゲームを人間設計版と LLM 設計版へ分岐し、ブラインド評価する比較枠組みは、LLM を発想支援や仕様決定に使うプロトタイプ制作の観察材料になる。
