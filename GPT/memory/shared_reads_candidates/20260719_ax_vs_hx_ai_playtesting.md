## raw_excerpt

publisher abstract から抽出した要点（長文の逐語引用ではない）。研究は、初期 game prototype の評価が依然として時間のかかる human playtest に依存している状況を背景に、AI を player feedback の代理として使う二つの経路を比較する。一つは Artificial Intelligence Experience（AX）で、AI agent が実際に game を play し、player-centric metrics に基づいて feedback を生成する。もう一つは Hypothetical Experience（HX）で、Game Design Document（GDD）を読み、想定される player response を simulation する。両手法を casual game prototype に適用し、design issue の発見と改善提案への利用可能性を調べた。abstract では、AX は gameplay に接地した actionable insight を与え、HX は concept の coherence を検討する助けになると報告される。位置づけは、低コストかつ迅速な early-stage iteration の補助であり、traditional UX testing を置換するものではない。論文は 2025-11-24 に online 公開され、International Journal of Human–Computer Interaction 42(14), 2026 に収録されている。

## why_relevant_to_games

実行 trace を読む headless 評価（AX）と、設計文書だけから行う事前批評（HX）を分ける材料になる。playable build 前後で AI 評価の役割を切り替える制作フローに関係する候補資料。
