## raw_excerpt

Game Developer が Remedy Entertainment の creative director Mikael Kasurinen に、Control Resonant の制作体制を聞いた記事。前作と異なる主人公、銃撃から近接戦闘への変更、New York 規模の環境、重力が歪む世界という複数の新規性を一つの制作チームへ共有するため、Kasurinen は「vision propagation」と呼ぶ流れを使う。初期段階では本人と複数職種の少人数 lead が pillars と high-level concept を一緒にworkshopし、concepting・prototype・iterationと並行して技術・tool・production processを準備する。方向が固まると各leadが自分のteamへ目標を伝え、担当範囲とscopeを調整し、後期にはdirectorがvisionを繰り返し言い直さなくても現場が判断できる状態を目指す。例として、重力が変わるlevelで雨の向きを「上」の手掛かりにする解法が挙げられる。一方、現場が壁に当たり成立しないと分かった案は、上から押し通さず手放して別案を探す。記事では、2019年作の直後からconceptingを始め、長い準備期間を経て本格productionを2〜3年程度にまとめた経緯も説明される。

奇抜な世界観や新mechanicを、抽象的なvision statementだけでなく職種横断の共同決定と局所判断へ伝播させる制作事例として、少人数プロトタイプの設計意図共有にもつながる。
