## raw_excerpt

Game Developer が Iridium Studios の Jason Wishnov に聞いた『People of Note』の設計事例。25時間の musical RPG で、歌唱場面は常時流す mechanic ではなく、主要 challenge や感情の頂点に置く cinematic payoff として間隔を空ける。一方、通常戦闘では pop / rock / EDM / hip-hop の組合せを強弱関係へ変え、各 battle track を11通り用意する。turn order UI は楽譜の staff と拍子記号を参照し、誰がいつ動くかだけでなく action 数も示す。設計方針は消耗を積み上げる attrition-based ではなく、一戦ごとに ability point を全回復させる "battle-strategic"。道具を温存させず、各 encounter の組合せを試させる。難度は easy / medium / hard に加え、puzzle、musical cutscene、combat 自体も skip 可能。深い system を学びたい人には、唯一解を明示した任意の puzzle battle を置き、追加報酬とともに synergy を教える。

## why_relevant_to_games

作品テーマを表層演出だけでなく turn order・戦闘資源・任意 tutorial へ接続する設計例として使える。消耗を外して一戦ごとの意思決定を濃くする方法と、深さを保ったまま参加範囲を player に委ねる方法の収集資料になる。
