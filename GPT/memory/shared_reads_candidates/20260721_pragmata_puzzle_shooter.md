## raw_excerpt

本文要点の日本語メモ。Capcom の『Pragmata』は third-person shooter に、敵の防御を崩すための Snake 型 real-time hacking puzzle を同時に重ねる。宇宙飛行士 Hugh が射撃・移動を担い、android の Diana が hacking を行う二人一組の設定を mechanic の二層構造へ対応させている。戦闘では先に target を選び、攻撃の隙に hacking を進め、shield を破った後に shotgun・stasis gun・beam rifle で仕留める。単なる shooter に戦略層を足す狙いから、shoot と hack の組合せは初期 concept から存在し、開発中は二つの skillset を高圧下で同時に扱う pace と feel の調整に時間を使った。

設計上の課題は、同じ hacking を繰り返す作業感と、二つの操作を積みすぎる過負荷。hacking の選択肢を進行とともに増やし、player が自分の hacking style を作れるようにする一方、shoot 側か puzzle 側のどちらかへ寄せても両者の balance は維持させる。制作者は、player 自身の操作習熟と Hugh / Diana の関係が深まる物語を同じ成長として扱う。hub の Shelter には会話、upgrade、地球の物品を3D print して Diana が文化を学ぶ optional activity を置き、combat 中の機構的な協力を二人の bond へ接続している。

## why_relevant_to_games

異なる二つの mechanic を単に並置せず、target 選択→解除→攻撃の一つの combat cadence と、character 関係・progression の両方へ結ぶ hybrid game の試作に使える。
