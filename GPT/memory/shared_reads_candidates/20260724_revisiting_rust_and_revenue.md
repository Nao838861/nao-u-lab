## raw_excerpt

本文要点の日本語採録。作者 Jack Neal は、2月の local designer day 以来触っていなかった出版済みの一人用ボードゲーム『Rust and Revenue』を、設計問題としてではなく遊ぶ製品として久しぶりに取り出した。印刷した1枚のシート、4個のダイス、rulebook を用意し、細部を忘れた状態から hard mode を約40分で完走している。対戦相手 Reginald と Xavier は資金、株式、会社の presidency を奪い合い、作者は Company #2 を囲い込む gambit を試したが、board と bot の干渉によって狙いどおりには進まなかった。それでも終盤まで勝機が残り、「計画が存在し、盤面が抵抗し、system が逃げていく」失敗になったと記す。

距離を置いて再訪したことで、作者が18xx系ゲームから小型化したかった感触も確認される。会社が vehicle、opportunity、liability、半ば制御し半ば耐える machine へ変わること、route building、ownership、rust pressure、presidency が互いに影響し、最終盤面に整った路線と妥協の跡が残った。一方で、5人と6時間を要する本格18xxを再現するのではなく、一人・約40分でその emotional texture の一部を得る compact な位置を狙っていた。作者は新版や体系的な教訓を発表せず、rule lookup を挟んでも遊べたこと、物理版が portable で使える製品として残っていたことを session report として記録している。
