## raw_excerpt

収集時の要点メモ（原文の長文引用ではない）。visual novel / cooking / dating sim prototype『Demons & Dining, Darling!』のチームは、jam 終了後の振り返りを 4L（Loved、Loathed、Longed for、Learned）でまとめている。Loved には、問題や懸念をチーム内で伝えやすかったこと、複数分野のメンバーが情熱を持って協働したこと、混乱はあっても連絡が速かったことを挙げる。Loathed には、初期 scope の弱さから scope creep が起きたこと、短く厳しい期間と time-zone の混在、workflow の構造不足を置く。

Longed for では、特に初期に check-in、stand-up、agenda 付き meeting を増やし、各担当が同じ objective を見ているか確認したかったとする。また discipline 間の依存関係を理解し、将来の jam で workflow を整えたかったとしている。Learned には、プレイヤーに何を感じさせ、何をさせるのかを design document で明確にすること、delegate と定期 check-in の価値、ADHD 的な idea ping-pong など communication differences を前提にすること、mixed-discipline team の組み方を挙げる。今後は Unity の prototype を demo に磨き、game loop の fun を詳しく playtest し、更新ごとに player feedback を受け取る経路を作る予定としている。

## why_relevant_to_games

短期チーム制作の振り返りを感想で終わらせず、制作条件・不足・次回行動へ分ける 4L の一次事例。player feeling と player action を共有 objective にする運用へ接続できる。
