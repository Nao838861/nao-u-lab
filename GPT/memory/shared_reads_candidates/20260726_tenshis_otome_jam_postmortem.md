## raw_excerpt

短い原文断片: "I worked in various teams as an artist and writer."

本文要点の日本語メモ（長文の逐語引用ではなく、収集時の言い換え）。2025年末頃にゲーム制作を始めた作者が、初参加の Otome Jam で複数チームをまたいで担当した仕事を振り返っている。完成作『Our Light Affliction: Spider's Covenant』では editor と CG artist を務め、mood lighting の練習に加え、pose variation を持つ立ち絵を後工程で扱えるよう layer separation を考えながら彩色・rendering した。

demo『Ember & Sands』では producer と writer を兼任し、20人を超えるチームを共同管理した。二人の protagonist が宿を営む fantasy romance visual novel で、作者は男性視点の章を執筆したほか、member が作業不能になった際には背景を約2時間で代替制作した。記事は programmers を最終的な統合を支える役割として挙げ、企画・writing・art が揃っても build へまとめる工程が必要だったことを記している。

未公開の『Celestine: Part II』では pixel artist として、地面に置かれた crossbow のような俯瞰表現や animation を制作した。作品ごとに editor / CG / producer / writer / pixel artist へ役割を変え、完成、demo、次イベントへの継続制作という異なる到達状態を並べている。final week は強い負荷だったとも記され、複数案件・大人数制作での役割交代と締切直前の代替作業が収集対象となる。

## why_relevant_to_games

小規模・短期チームで、立ち絵の layer 分離、担当者離脱時の代替制作、20人超の writer・artist・programmer 間の受け渡しをどう設計するか考える際の制作事例になる。
