## raw_excerpt

短い原文断片: "Those $0 mines do something interesting. They slow the game down."

収集メモ: Jack Neal は、1人用の鉄道・経済ボードゲーム『Rust and Revenue』用に以前作った procedural map generator を久しぶりに動かした。最初に出た map は、route が頻繁に重なり、高価値の機会が少なく、大きな範囲が実質的な empty space になるものだった。制作当時の選別基準なら即座に捨てていた配置だが、再プレイすると、得点価値が $0 の mine が序盤の scoring pressure を弱め、明白な価値を追う代わりに connectivity と timing を見るよう促していた。

作者は、従来の map 制作では dense scoring、分かりやすい incentive、早い feedback を「良い map」の条件として優先していたと振り返る。一方、この低得点 map は campaign 後半や標準体験には向かなくても、network の骨格を数字の最適化より先に見せる learning space にはなり得ると記す。見た目上の欠陥は、元の用途には合わないだけで、別の役割では機能する可能性がある。記事末では、設計上の前提には有効期限があり、ときどき再検査する価値があると述べている。

## why_relevant_to_games

procedural generation の出力を単一の「良さ」で選別せず、導入・練習・後半 challenge など配置先の役割と対応づける level curation に接続できる。報酬密度を下げて基礎 mechanic を見せる tutorial 設計の参照にもなる。
