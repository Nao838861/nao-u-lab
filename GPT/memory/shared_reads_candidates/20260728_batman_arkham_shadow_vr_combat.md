## raw_excerpt

GDC 2026 の Camouflaj / Meta による講演。『Batman: Arkham』シリーズの full-featured な体験を VR へ移す際、単に題材や見た目を合わせるのではなく、既存作の lore と game design を詳細に調査し、熱量の高い既存 community が「Arkham らしい」と受け取れることを中心条件に置いた。開発中は “Authentic Arkham” を日常的な合言葉とし、IP の核を損なわないことを譲れない条件として扱った。

特に難しい対象として、初代『Batman: Arkham Asylum』以後の action game に広く影響を与えた freeflow combat を VR に翻訳する課題を挙げる。講演者は Design Director の Ryan Darcey と Principal Gameplay Engineer の Troy Johnsen。公開 overview は、freeflow combat を一人称の身体操作へ移した方法に加え、locomotion や gadgets など、戦闘を支える core support system の翻訳も扱うとしている。

講演は Game Developers Conference 2026 の Design セッションで、free content として掲載されている。公開 overview の範囲では、調査、既存 fan の期待、combat、移動、gadget を一体の adaptation 問題として提示している。

## why_relevant_to_games

既存作品の mechanics を異なる入力・視点・身体性へ移植するとき、表層ではなく体験の同一性をどう保つかを検討する材料になる。
