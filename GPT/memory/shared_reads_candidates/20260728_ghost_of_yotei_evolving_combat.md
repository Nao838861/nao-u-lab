## raw_excerpt

GDC 2026 の Sucker Punch Productions、Theodore Fishman による講演。前作を改善しながら、その作品を成立させていた良さを壊さない sequel 制作の難しさを、『Ghost of Yōtei』の combat design を通して扱う。『Ghost of Tsushima』の戦闘が持っていた中心的な feel と fantasy を残しつつ、続編として期待される新しい領域へ進み、同じ基盤から独自の identity を持つ戦闘へ発展させる過程を説明する。

公開 overview が挙げる内容は、戦闘について最初に定めた high-level pitch、残す mechanics と探索する mechanics の切り分け、新 mechanics と iteration の詳細である。具体例として、player と enemy の武器を disarm する仕組み、複数の melee weapon を stance system と統合する設計、enemy variety を増やすための core system 変更、theme と weapon swap の利用が含まれる。

さらに、通常戦闘で導入した要素を boss fight に集約し、「Yōtei 6」に対する player の期待と合わせる方法も扱う。講演ページでは Game Developers Conference 2026 の free content、Game & Production Technology / Design セッションとして掲載されている。

## why_relevant_to_games

続編や既存 prototype の大規模改修で、前作の体験の核を維持しながら武器・敵・boss へ新規 mechanics を展開する設計過程を参照できる。
