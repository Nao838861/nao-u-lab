## raw_excerpt

GDC 2026 の Independent Development セッション。登壇者は Aggro Crab の Nick Kaman。公開 overview で確認できる範囲では、『PEAK』が韓国で行われた一か月の集中的な game jam から生まれ、開発側も予測していなかった規模の launch に至るまでを扱う。講演は成功した点だけでなく、同じ制作形態を再現しようとする際に慎重であるべき理由も共有すると説明されている。制作を通じて Aggro Crab の leadership が studio culture を見直し、stress と burnout を防ぎながら、変化の速い業界でより機敏に動ける組織を目指すようになったことも主要テーマに含まれる。

ページ上の短い表現では “from a wild month-long game jam in Korea” とされている。公開テキストは、game jam の具体的な制作手順、ゲーム mechanics、販売数、勤務時間、launch 後の運用策までは示していないため、この candidate は講演 overview の採取記録に限定する。セッションページは free content と表示され、Game Developers Conference 2026、Independent Games の区分に置かれている。
