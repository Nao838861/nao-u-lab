## raw_excerpt

以下は本文の重要箇所を日本語で抄録したもの（逐語引用ではない）。Raph Koster は、MMO 固有の素材を「永続世界」と「大人数」の組合せに置き、固定クエスト中心ではなく、プレイヤーの行為が地形・生態系・集落・経済へ残り続ける世界を説明している。Stars Reach では地形と物体を静的 mesh とせず server から stream し、森林の再生、河川、火災、採掘跡、建造物などを変化可能な simulation として扱う。大規模な変更は個人の一操作より、多数の行為の蓄積や共同作業で起こるようにし、土地の claim、修復、生態系を守る guild、森林の再生、掘削跡が土へ戻る仕組みを recovery path として備える。一方、洪水・埋没・溶岩など間接的な加害を検出する難しさも挙げる。

成長は固定 class ではなく活動別 skill track とし、序盤に全 track を試す機会を与え、気に入った活動へ進ませる。chef と rifleman のような異なる役割を同一の戦闘尺度で競わせず、需要の空白を経済が埋める構造を想定する。過去作で一部の成功者が市場を独占した経験から、店舗・鉱山・都市を拡大するほど維持費と崩壊 risk が増える push-your-luck 型を導入する。近くで同じ活動をするだけで XP bonus を得る soft grouping、他者の蘇生を leadership progression へ接続する仕組みなど、小さな非ゼロ和 incentive を積み重ねる。Early Access は PvE と基盤 simulation を先に置き、政治・PvP などをその上へ段階的に足す方針としている。

## why_relevant_to_games

永続的に改変できる sandbox で、創発性と荒廃防止、役割自由度と進行の明瞭さ、経済成長と独占 risk を同じ system 内で扱う設計例として参照できる。
