## raw_excerpt

Unity が 2025 年に実施した engine・team size・地域横断の game developer 300 人調査と、Unity ecosystem を利用した約 500 万 developer の proprietary data をもとに、2026 年の制作動向を五つに整理した記事。52% が risk reduction の主手段として小規模 project を優先し、67% は prototyping phase を 3 か月以内としている。Unity project の median development time は 2022 年 1 月の 91 時間から 2025 年 12 月の 21 時間へ低下したと報告する。

AI は front-end generation より back-end productivity を重視する傾向があり、用途は coding assistance 62%、writing / narrative 44%、利点は efficiency 73%、decision-making 62%。回答者の 50% が MCP server を利用し、用途は game engine / editor connectivity 90%、production / project management 74% とされる。市場面では platform analytics 90%、industry research 73% が意思決定に使われる。online multiplayer 対応は 83%、うち 2–9 人の小規模 session に注力する studio が 55%、cross-play 優先は 72% で、device 間の一貫した体験が主要課題として挙げられる。収益・到達経路では、24% が core sales 以外の partnership、in-game monetization、platform expansion を試している。

## why_relevant_to_games

prototype の期間と規模、AI/MCP の配置、少人数 multiplayer・cross-play・platform 展開について、制作計画を立てる際の外部ベースラインとして参照できる。
