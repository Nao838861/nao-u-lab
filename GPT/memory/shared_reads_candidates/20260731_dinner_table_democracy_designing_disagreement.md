## raw_excerpt

GDC 2026 の Design セッションで、game designer の Jennifer Estaris が、意見の対立を敵対や勝敗だけへ寄せず、playful・safe・unexpectedly joyful な体験として構造化する方法を扱う。題材は 2025 Citizens' Assembly Game Jam と、その後も開発を続けている VoxPop。VoxPop は政治的な論点を dysfunctional family の夕食時の議論に見立てた daily political puzzle であり、講演では structured friction、role-based empathy、comedic realism を設計技法として取り上げる。

セッション後半では、会場参加者が Sensible Mum や Chaos Cousin のような誇張された archetype を演じ、段階的に難しくなる prompt の解決を試みる Dinner Table Democracy の実演を行う。最終的な対立相手は Grandma とされ、talk、social experiment、dinner theatre を混ぜた形式で、conflict・humor・empathy を同じ play system の中に保持するための道具を提示する。GDC Vault 上では free content、Design / Culture & Sustainability / Advocacy の各領域に分類されている。

## why_relevant_to_games

協力・交渉・social deduction・narrative puzzle で、対立を単なる失敗条件にせず、役割、摩擦、笑い、共感を同時に成立させる mechanic と playtest の観点を集める入口になる。
