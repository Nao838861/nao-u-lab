## raw_excerpt

GodotCon Boston 2026 の公式セッション情報。Godot community の開発者による複数の短い postmortem を一枠にまとめ、異なる制作期間と公開目標を比較できる構成になっている。Josh Anthony の『Dice Gun Commando』は 2026年3月に制作を開始し、4月16日に public demo を公開した事例として、短期間で実際に release へ到達する方法と、その工程から得た考えを扱う。

syzygy.systems の報告は、1年間に毎月1本のゲームを作る計画を始めた二人が、18か月後に振り返る内容である。Cory Darby の『A Game About Feeding A Black Hole』は、25万本超を販売した共同制作から三つの教訓を説明する。公式概要が挙げる主題は、すでに売れているものから出発すること、三つの core pillar を中心に構成すること、大きな着想よりも早期 validation と強い scope control を優先すること。セッションは 2026-07-22 の70分枠で、現時点の取得範囲は公式 program と登壇者ページの概要であり、講演映像や全文 transcript は未取得。

## why_relevant_to_games

短期 demo、反復的な月次制作、商業的に成功した小規模作品という異なる制作単位から、release 速度・検証・scope 制御の記録を集められる。
