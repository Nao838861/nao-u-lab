## raw_excerpt

GDC 2025 の Design セッション。登壇者は Tencent Games の Xuwei Yu と Huishu Zheng。セッション概要は、playtest で得られる player feedback が常に制作判断へ直結するとは限らず、率直な体験反応と、後付けで合理化された説明や批評家のようなコメントを区別する必要がある、という問題を置く。講演は、実例を通じて誤解を招きやすい feedback の型と、それが core gameplay の反復を誤った方向へ導く過程を扱い、game designer と user researcher が real insight を抽出するための5つの実践的な tip を提示する構成とされる。範囲には、playtest を体系的に設計する方法、honest opinion を得るための test tool、player の emotional experience を調べる観点、単純な「好き／嫌い」「満足／不満」を越えた質問法、得られた観察と発言を gameplay improvement へ変換する分析法が含まれる。公開ページで確認できるのは講演概要までで、5項目それぞれの詳細はセッション本編の確認対象。
