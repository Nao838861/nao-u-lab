## raw_excerpt

Game Developer が Devolver Digital 共同創業者 Nigel Lowrie と作者 Ojiro Fumoto に取材した記事。『Poinpy』は 2022 年に Netflix Games 独占で公開され、契約期間の終了後に同サービスから消えたが、契約は時限独占だったため、Devolver と作者は自分たちで mobile 版を再公開できた。サービス外で動かすため leaderboard などを調整し、再公開版は広告や in-app purchase を入れず、希望者だけが支払う小さな tip option を採用した。Fumoto は Netflix の支援がなければ制作できず、通常の publisher では届かなかった利用者へ作品を届けられたと振り返る一方、記事は独占期間終了後に作者側が再公開できる契約条件の意味も扱っている。

制作の起点は mechanics ではなく、artist が描いた “Poinpee” の sketch と「Poinpy」という名前だった。その後、touchscreen 向けの pull-and-release 2D platformer 操作、combo、juicing、追跡する beast へと要素が加わり、開発中に大きく変化した。作者は迷った時に “What sort of a game would one named ‘Poinpy’ be?” と問い、タイトルを完成形の仕様ではなく、変化する試作を同じ感触へ戻す判断軸として用いたと説明している。

## why_relevant_to_games

小規模ゲームで、配信サービスとの契約・サービス終了後の再公開経路・外部機能の切離しを制作前から考える場面と、mechanics が変わっても作品の感触を保つ短い design compass を置く場面に参照できる。
