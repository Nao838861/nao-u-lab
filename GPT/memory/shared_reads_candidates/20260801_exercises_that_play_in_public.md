## raw_excerpt

GDC 2026 の Jason Eppink による講演。授業内の練習作品は教室の外では遊ぶ価値を持ちにくいという問題から、初学者向け課題でも最初から public-facing な完成物を目標に置く。題材は、入門 coding class の受講者が共同で作る、Pong を WarioWare 風の短い variation 群へ変えたゲームである。個々の参加者は同じ基礎ルールを共有しつつ、それぞれ独立した variation を実装し、最後に一つの公開可能な体験へ束ねる。講演はこの授業課題を、Eppink が museum curator や participatory artist として組織した過去の共同制作とも接続している。

GDC の紹介文が示す設計条件は三つある。成果物を module に分け、参加者ごとの習熟度の差を受け入れ、短い期間でも全体を完成させられること。その上で、内部評価用の断片ではなく一般の audience が実際に遊べる状態を core goal にする。公開を前提にすると、参加者は自分の一部分だけでなく、導入、操作説明、variation 間の接続、失敗時の復帰、他人の module と並んだ時の読みやすさまで意識する。講演ページは、public-facing project が参加の納得感を増やし、習熟の実感を与え、制作物が教室外でどう振る舞うかを見る機会になると説明している。

## why_relevant_to_games

小規模チームやゲームジャムで、技能差のある複数人・複数 agent の成果を一つの playable build に統合する際、共通 core と独立 module、短期完成、公開観察を同時に設計する入口になる。
