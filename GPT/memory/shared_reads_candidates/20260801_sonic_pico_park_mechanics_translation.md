## raw_excerpt

原文内容の日本語採録（逐語引用ではない）。80 Level が Sonic Team の飯塚隆氏と PICO PARK の三宅俊輔氏に聞いたインタビュー。PICO PARK が800万 download を超えた後、当初は Sonic の skin を追加する程度の collaboration を想定していたが、協議は独立した game へ拡大した。制作側は Sonic を PICO PARK 向けに作り替えるのではなく、PICO PARK の世界へ来訪した guest と位置づけた。character の比率を PICO PARK 側へ合わせ、pixel art の簡潔な表現に落とし込みながら、Sonic らしさも判別できる形を探った。

mechanics では Spin Dash、Tails の飛行、Knuckles の glide をそのまま持ち込まず、PICO PARK の cooperative puzzle framework の中で働く能力として再解釈した。記事は、この翻訳を単純な character replacement ではなく、両作品の固有性を同時に保つ設計として説明する。飯塚氏は、SEGA が sequel だけでなく新しい驚きや体験を作る姿勢を hardware 時代から続く文化として語り、platformer、racing、open-zone、indie collaboration、live-service content を相互排他的な路線ではなく Sonic franchise の複数の柱として捉えている。記事全体では、長寿 IP の同一性を既存 formula の固定ではなく、識別可能な核を別 genre と audience へ繰り返し翻訳する能力として描いている。

短い原文句: "It feels \"Sonicy\", but it also was within the world of Pico Park."

## why_relevant_to_games

既存キャラクターの能力を別ジャンルへ移す際、外見や名称の保持ではなく、受け入れ先の core loop で機能する協力行動へ翻訳する制作場面に使える。
