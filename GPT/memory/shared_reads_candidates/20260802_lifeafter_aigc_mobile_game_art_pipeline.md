## raw_excerpt

公式 GDC 2026 agenda の内容を日本語で採録する。NetEase Games の Xiudong Zhang と Zhaoxing Yang による講演で、研究段階の AIGC 技術と実際のゲーム制作工程の間にある隔たりを、モバイルゲーム『LifeAfter』での導入事例から扱う。提示される柱は、人と AI が協働する workflow の構築、制作上の価値を基準にした technical service、複数領域をまたぐ integration strategy の三つ。creative design、art production、asset management、performance optimization を対象に、AI asset optimization toolchain と workflow transformation を production-ready な形へ接続したと説明している。

公式説明では、具体例として texture optimization、model enhancement、environment enrichment を挙げ、AI 導入機会を識別する方法、新しい AIGC workflow の作り方、施策の効果を数値で追う evaluation framework を持ち帰り項目としている。講演側の報告値は、cost saving が 600 万ドル超、efficiency improvement が 50%。単発の生成ツール紹介ではなく、導入上の共通障害、評価方法、既存制作工程への組み込みを含む体系的な pipeline 事例として位置づけられている。なお GDC Vault の slide PDF は収集時に 403 となったため、この候補では公式 agenda と NetEase Games の公式告知で確認できる範囲のみを記録し、slide 内の工程図や内訳は未採録とする。

## why_relevant_to_games

生成 AI を game art の単発出力ではなく、texture・model・environment・asset management・performance を横断する制作工程へ組み込む事例として、ゲーム制作 pipeline の設計場面に接続できる。報告された費用・効率の測定方法と human-AI workflow の具体構造は、後続フェーズで原資料を取得できた時の確認対象になる。
