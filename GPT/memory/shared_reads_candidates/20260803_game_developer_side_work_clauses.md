## raw_excerpt

本文要点の日本語メモ（長い原文引用は避けて要約）: Game Developer の Chris Kerr が、ゲーム会社の雇用契約に含まれる side work / moonlighting 条項を、AAA 経験者、indie developer、art director、米国の雇用法専門家への取材から整理した記事。Double Fine が Microsoft 傘下へ入った後、個人端末・私的時間で作った企画でも将来会社が再検討する可能性を理由に境界が曖昧になる事例を導入に置く。匿名の AAA 経験者は、ゲーム、講演、教育、mentoring まで広く conflict of interest とみなす承認制があり、申請が拒否または長期放置されることで、収入源だけでなく技能習得や創作継続も妨げられると述べる。

Alice Ruppert は、雇用交渉時に個人プロジェクトを先に開示し、一社では競合範囲を smartphone controller を使う PC party game に限定、別の会社では Outside Interests を文書化することで条項の削除・限定に成功した。一方 Louise Meijer-Åström は、採用時に口頭承認された worldbuilding project が注目を集めると会社から loyalty を疑われ、書面例外も拒否されたため、社内学習会を止めて退職したと説明する。法律家 Wendy Stryker は、職務範囲内の成果は会社帰属となり得る一方、地域法・契約文言・競合性で境界が変わるため、個人活動を会社業務から明確に区別し、開示と書面許可を得ることが重要だとする。ただし layoffs が多い業界では交渉力に大きな差があることも記事は示している。

## why_relevant_to_games

個人ゲーム制作、game jam、外部講演、教育活動を続けながらスタジオで働く際の権利・知財・制作継続リスクを具体例で確認できる。共同制作や採用時に、使用機材、勤務時間、競合範囲、既存作品、書面例外をどう分離するか考える素材になる。
