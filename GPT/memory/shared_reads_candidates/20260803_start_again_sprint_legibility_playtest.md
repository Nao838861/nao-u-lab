## raw_excerpt

turn-based strategy game『Start Again』の無料 Sprint preview に関する開発記録。作者は、初期版を人前に出し、どこが説明なしで読めるか、どこが過剰な説明を要求するかを観察して、simplify、rebalance、clarify を繰り返している。特に Spiral phase から Grid phase へ移る構造は、一度理解すれば単純でも first impression では伝わりにくく、phase shift が実際に理解されたかを playtest の質問にしている。

作者が同時に読ませようとしているのは pressure、economy、territorial play の三つで、layered decision を残しつつ、presentation や rule の不備で opaque になった部分を区別しようとしている。公開 preview では、混乱した場所、満足した場所、fiddly に感じた場所を短い感想でも求めている。preview は意図的に slice に限定され、faction powers、policy cards、banking / economy の深い層、military options、full campaign は段階的に開放する予定とされる。これは未実装だから伏せるのではなく、foundation の理解と feedback を先に確認するための公開範囲として説明されている。

## why_relevant_to_games

戦略ゲームの「深さ」と「説明不足による複雑さ」を、phase transition、pressure、economy、territory の初見理解と公開 playtest の質問へ落とした収集例として参照できる。
