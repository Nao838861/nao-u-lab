## raw_excerpt

GDC 2026 の公式セッション概要を日本語で採録する。Sandfall Interactive の Tom Guillermin と Florian Torres が、『Clair Obscur: Expedition 33』の広い feature / content scope を少数の programmer で支えた技術・制作判断を扱う。programming は当初一人で始まり、制作の直近三年間に四人へ拡大した。一方、作品の規模は30時間超の story content に加え、同程度の side content を持つ。technical team は個々の content を直接実装し続けるのではなく、designer が gameplay element を作り、組み合わせられる状態を用意することで creative freedom を最大化しようとした。講演では、その目的を支えた technical choice、途中で遭遇した challenge、実際の gameplay system と content から取った具体例を紹介する。takeaway としては、限られた programming resource で大規模な機能と内容を届ける方法、Unreal Engine を "vanilla-first" の考え方で使う approach、programmer が designer の content authoring を可能にする方法、制約下で各 system を実装する考え方、small team 向けの production tips と methodology が挙げられている。

## why_relevant_to_games

少人数制作で programmer が全 content のボトルネックになるのを避け、designer が既存要素を組み合わせて量産できる境界をどう作るか、engine 拡張をどこまで抑えるかの参考になる。
