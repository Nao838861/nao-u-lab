## raw_excerpt

GDC 2026 の公式セッション概要を日本語で採録する。AdHoc Studio の共同創業者 Nick Herman と Dennis Lenart が、Telltale Games での経験から studio 設立と debut title『Dispatch』へ至る流れを共有する講演である。case study の中心は、story-driven game の長年の fan が期待するものを満たしながら、従来この genre を遊ぼうと思わなかった player も迎え入れる設計。既存形式を否定して別物にするのではなく、何が機能していたかを残し、機能しにくかった部分を再検討し、structure、agency、visual-first production pipeline に新しい考え方を導入した過程を扱う。公式 takeaway は、確立済みの game format を評価して発展させるための見方と、実績ある土台を利用しつつ innovation と production reality の均衡を取る実務的な insight。対象は game developer、creative lead、studio founder で、cinematic branching game の知識は役立つが必須ではないとされる。

## why_relevant_to_games

既存ジャンルの表面を捨てるのではなく、残す約束と変える構造を分け、player agency と制作 pipeline を同時に設計し直す際の参照になる。
