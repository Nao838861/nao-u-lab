## raw_excerpt

Game Developer Podcast の 2026-06-12 回。Senior Editor の Bryant Francis が、game writer の Emma Kidwell と narrative designer の Harrison Pink に、物語を第一の目的にしないゲームで narrative content がどんな役割を持つかを聞いている。対象として挙げられるのは 4X strategy、puzzle、multiplayer、ARPG などで、プレイヤーは英雄譚を読むためというより、複雑な gameplay problem を解いたり反射神経を試したりするために遊ぶと整理される。記事導入は、game writing が長く core development team の周辺業務として扱われてきた一方、story-first な single-player 作品の成功によって認識が変化した経緯を置き、そのうえで story-first ではない領域へ問いを広げる。両ゲストの実務経験から、こうした作品でも、複雑な gameplay system を補完するごく小さな物語にプレイヤーが反応することを扱う対話である。本文ページは podcast episode の紹介と埋め込み音声への入口で、詳細な逐語 transcript は掲載していない。

## why_relevant_to_games

システム主導のゲームで、短い文章・設定・キャラクター反応が mechanics の理解や継続動機へどう接続するかを調べる入口になる。パズルやアクション試作で narrative を独立レイヤーとして後付けせず、複雑なルールを補完する設計を考える際に使える。
