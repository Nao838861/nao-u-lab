## raw_excerpt

GDC 2026 の公式セッション概要を日本語で採録する。Hazelight のデザイナー Hannes Gille が、『Split Fiction』終盤の dual-world level を題材に、同スタジオにとって過去最大級となった協力設計上の難題と、その解決過程を説明する講演である。『A Way Out』『It Takes Two』に続く協力専用作品の中でも、この level 固有の仕掛けは制作負荷と体験上の理由から game 全体へ広げず、最後まで温存された。二つの世界をまたぐ構造の中で、player 同士の communication と collaboration を自然に促し、驚きの瞬間を作るために用いた複数の technique が扱われる。講演は concept の見せ方、満足できる co-op puzzle を構成する材料を反復の中でどう発見したか、そして複雑さを増すのではなく設計を単純化することで player が驚きを受け取る余地をどう広げたかを辿る。公式 takeaway は、co-op game 固有の設計課題への理解と、協力者間の会話を誘発するための道具を持ち帰ること。終盤内容を詳細に扱うため spoiler warning が付されている。

## why_relevant_to_games

協力プレイを「二人が同時に操作する」だけで終わらせず、情報分割・会話・共同実行へ接続する level design と、高コストな核アイデアを一作品のどこへ配置するかという scope 判断の参照になる。
