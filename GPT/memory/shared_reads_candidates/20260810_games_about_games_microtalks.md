## raw_excerpt

GDC Festival of Gaming 2026 の Design トラックで行われた microtalks セッション。公式説明は、ゲームの歴史・文化・開発そのものを自己言及的に扱う「games about games」が近年増えていることを出発点にしている。題材には developer、player、medium の歴史が含まれ、実在の出来事を扱う nonfiction から、架空の人物像や架空 console を作る作品、両者の境界をぼかす作品までが並ぶ。Nick Lives、Jon Perry、Adam Pype、Lucas Immanuel、Jonny Hopkins、Flan Falacci、Juan Hernandez、Gurn Group、mut moochi が短い講演を分担し、この種の作品を作る際に生じる production 上の制約と narrative 上の課題を、independent game development の複数事例から検討する構成である。公式 takeaway は、過去作品を参照しがちな媒体だからこそ、game self-reflexivity を複数の立場から見直すことで、産業史や制作工程の捉え方を更新し、将来のゲーム制作手法にも接続できるというもの。対象 audience は、実験的な indie game design に関心がある designer / artist と、この潮流を検討する writer / educator とされている。

## why_relevant_to_games

ゲーム内で「ゲームを作る・遊ぶ・記録する」行為を扱うとき、mechanics と narrative の自己言及をどう組み合わせるかを考える資料になる。過去作品への参照を模倣で終わらせず、架空史・開発工程・player 文化を遊びへ変換する設計場面に接続できる。
