## raw_excerpt

GDC Festival of Gaming 2026 の公式 session 概要。NetEase Games の Guangyun Chen が、『Marvel Rivals』で既存の Marvel character を hero shooter の操作・能力・対戦構造へ変換した設計過程を扱う。題材として Spider-Man、Hulk、Iron Man が挙げられ、85 年分の lore を mechanic へ圧縮しながら、プレイヤーが期待する character の本質を失わないことが中心課題として置かれている。

公開概要では、superpower を単なる演出や既存 shooter kit の装飾として追加するのではなく、core gameplay element として統合し、それが hero shooter という genre の可能性を広げるように設計する、と説明される。短い原文断片は "distill 85 years of Marvel lore" と "superpowers as core gameplay elements"。講演の後半は、強い character fantasy を維持したまま strategy-rich encounter を成立させ、継続的な roster 追加や運用にも耐える long-term balance methodology を扱う。

公式 takeaway は、複雑な character の core essence を gameplay へ組み込む方法と、楽しく戦略性のある superhero 対戦を長期的に保つ balance methodology の理解。対象 audience は hero design、game mechanism、character-based competitive game の長期 balance に関心を持つ開発者とされている。

## why_relevant_to_games

既存キャラクターの「らしさ」を能力セットへ翻訳する character design と、個性を均しすぎず対戦の長期 balance を維持する live-service 設計の収集材料になる。
