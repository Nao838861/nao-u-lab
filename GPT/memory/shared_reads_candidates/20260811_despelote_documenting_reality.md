## raw_excerpt

GDC Vault の Game Developers Conference 2026 公式セッション概要。登壇者は independent developer の Julian Cordero、対象作品は 2001 年の Ecuador・Quito を舞台にした slice-of-life soccer game `despelote`。概要は、現実世界を記録する媒体として photography、film、literature が想起される一方、video games はほとんど想起されない、という問題意識から始まる。Cordero は本作の制作を通じて、ゲームは現実を捉えるための媒体になり得ると考えるようになったと説明する。

制作素材として挙げられているのは、3D scans、improvised dialogue、archival footage、ambient sound recordings である。これらを組み合わせることで、単に場所を再現するのではなく、生活されていると感じられる世界を作る。さらに personal memories と real places を基に、ゲームを time、space、feeling の collage として構成する。公式概要の結びは、ゲーム制作をコンピューター内だけの作業に閉じず、現実世界へ出て素材を集める行為として捉えている。セッションの中心は、サッカーの競技ルールそのものより、実在の都市、記憶、会話、記録映像、環境音を playable な体験へ束ねる制作過程にある。

## why_relevant_to_games

短期プロトタイプでも、実在の場所や個人的記憶を、地形・会話・映像・環境音という複数の playable 素材へ変換する world-building 手順の参照になる。
