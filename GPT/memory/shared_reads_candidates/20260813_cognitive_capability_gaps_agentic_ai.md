## raw_excerpt

arXiv:2608.02553（2026-08-03投稿、15 pages、4 figures）。Taye Akinrele、Sindhuja Penchala、Noorbakhsh Amiri Golilarz ほか。要旨は Cognitive AI を、言語生成や単発の自律 task execution から、持続的推論、適応行動、永続記憶、自己調整を備えた system へ進める研究領域として置く。生成 AI と agentic AI は幅広い task で能力を示す一方、基本的な cognitive function が断片化または未発達であり、長い時間軸で信頼できる動作を妨げているとする。

survey は既存研究を、persistent state modeling、goal-directed autonomy、self-monitoring and control、environment interaction、learning and adaptation の五つの次元で整理する。各次元について近年の進展、繰り返し現れる制約、未解決課題をまとめ、その上で概念的な Adaptive Cognitive Intelligence Architecture（ACIA）と cognition-centric evaluation の方向性を提示する。taxonomy、architecture、evaluation framework を組み合わせ、長期推論、適応的意思決定、継続学習を評価・設計するための共通枠を作ることが要旨上の狙いである。一次資料: https://arxiv.org/abs/2608.02553

## why_relevant_to_games

長時間プレイする NPC や headless playtest agent を、単発の勝率だけでなく、状態保持・目標追跡・自己監視・環境操作・経験適応に分けて観察する評価観点の候補になる。
