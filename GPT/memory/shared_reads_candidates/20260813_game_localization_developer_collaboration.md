## raw_excerpt

著作権に配慮し、長い逐語引用ではなく記事ページの要点を日本語で採取する。Game Developer Podcast が 2026 年 8 月 7 日に公開した、Concha Fernandez Alvarez、Aurelie Perrin、Guido Di Carlo を迎えたゲーム・ローカライズ回。記事は、海外地域でゲームを販売するうえでローカライズは価値の高い専門分野である一方、十分に評価されず、クレジットから外される、crunch を求められる、生成 AI や機械翻訳で代替可能だと圧力を受ける、といった制作上の問題を挙げる。また、平均的なゲーム開発者からはローカライズ工程が遠い black box に見えやすく、localizer と広い開発チームが直接やり取りする機会も少ないと説明する。Podcast の目的は、この分断を埋め、異なる言語へゲームを移す仕事を単語置換ではなく、ゲーム固有の文脈・創造性・情熱を扱う craft として開発者側へ伝えることにある。ページ本文は導入のみで、具体的な workflow、実例、失敗例は埋め込み音声側で扱われる構成。

## why_relevant_to_games

UI 文字量、変数・文脈の受け渡し、クレジット、開発工程との接続など、プロトタイプを多言語化可能な構造で作る段階と、外部協力者を production loop に入れる段階の収集材料になる。
