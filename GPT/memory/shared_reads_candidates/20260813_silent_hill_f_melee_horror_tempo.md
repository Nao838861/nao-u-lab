## raw_excerpt

GDC Festival of Gaming 2026 の公式セッション概要。Neobards Entertainment の Studio Creative Director であり本作の game director でもある Al Yang が、『SILENT HILL f』をシリーズ初の melee-only 作品として設計した理由と、そのために従来の horror combat をどう分解・再構築したかを扱う。公式説明は、従来の ranged horror game combat には戦闘テンポを調整する重要な仕組みが含まれており、本作では射撃を外した後も pacing を保つため、既存システムを適応するか新規に作る必要があったと述べる。講演では key combat systems、progression、enemy AI、主人公 Hinako の visual / mechanical design までを、直接的な system / mechanic comparison と設計判断の過程で示す予定。Takeaway は、ジャンル内で当然視されている仕組みが combat tempo をどう規定するかを分析し、それを別方向の設計へ複製・変奏する方法にある。公式文の要点は “preserve combat pacing” と “analyzed, replicated, and created variations” である。

## why_relevant_to_games

ジャンルの主要入力手段を置き換える時、表面的な武器差ではなく、旧システムが暗黙に担っていた pacing regulator を列挙し、新しい mechanics / progression / AI / character design に再配置する設計事例として使える。
