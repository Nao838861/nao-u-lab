## raw_excerpt

Game Developer が 2026-08-03 に公開した、シリーズプロデューサー Motoi Okamoto と game director / lead writer Jon McKellan への取材。『Silent Hill: Townfall』は 1996 年の架空のスコットランド離島 St. Amelia を舞台に、American protagonist の Simon Ordell が失踪した Zoe を探す一人称心理ホラーとして設計されている。町では労働組合と企業組織の対立が破綻し、現実と妄想が混ざっていく。制作側は一人称視点を単なるカメラ変更ではなく、Simon の脆弱さとその時々の精神状態へプレイヤーを拘束する手段として使い、発話を抑えつつ、画面上の inner thoughts で内面を示す。登場人物同士も一度だけ交差する存在ではなく、本人たちがまだ理解していない因果で深く接続される。

もう一つの中心は、portable television を物語、小道具、探索、危険察知へまたがらせる設計である。携帯 TV は周囲の怪異を警告し、霧や壁の向こうの敵を映し、正しい周波数へ real time に tuning しないと十分に機能しない。pharmacy の puzzle では建物内の数字の手掛かりを cryptic recording として流し、Zoe からの clue や会話も同じ装置へ載せる。McKellan は『Alien: Isolation』で古い技術と motion tracker の UI を担当した経験を踏まえ、VHS / analog horror の見た目を gimmick で終わらせず世界の一部にすることを重視している。記事は、信頼しきれない旧式機器へ生存と物語理解の両方を依存させ、lo-fi feed 越しに世界を見る行為そのものを不安へ変える構成を紹介している。一次資料: 上記 URL。

## why_relevant_to_games

一人称カメラ、内面テキスト、危険察知、謎解き、NPC 通信を別機能に分散させず、一つの不完全な diegetic device へ束ねて心理状態と操作を一致させる設計例として、ホラーや探索ゲームの prototype に使える。
