## raw_excerpt

Game Developer が GDC Festival of Gaming 2026 の Aaron Keller 講演をまとめた収集メモ。Overwatch は初代発売時に完成度が高かった一方、継続的に変化させる live-service としては停滞し、Overwatch 2 への 5v5 移行、長期開発した PvE の中止、PvP からの人員移動、Steam での低評価が重なった。チーム内では士気低下と離職も進み、プレイヤーが「このゲームの将来を任せられる」と感じる信頼を失ったという。

再建時には patch note だけでなく、Director's Take などの長文 blog、変更理由、今後の予告、roadmap の修正を継続的に公開した。重要なのは危機時だけ反応する広報ではなく、目立つ成果と同じように日常的な判断も伝え、完全に整った message を待たず一定の頻度で姿を見せることだった。記事は player feedback を無条件に採用したとは述べていない。PvE 要望へ引かれて core PvP の更新が弱くなった経験も挙げ、運営を experimentation、analysis、communication の往復として説明する。記事掲載時点で Steam 全体評価はなお肯定的ではないが、recent reviews は Mixed まで回復し、team が issue を認識し対処していることを可視化する継続 communication が信頼回復の一部になったと報告している。

## why_relevant_to_games

長期運営ゲームで、player feedback・開発判断・roadmap 変更を core experience の更新と結びつけて伝える制作ループ、および失敗後の信頼回復過程を収集する材料になる。
