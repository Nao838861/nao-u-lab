## raw_excerpt

GDC 2026 Community Tools Summit の公式講演概要。登壇者は Ubisoft の UX Director、David Lightbown。対象はゲーム内の player telemetry ではなく、デザイナー、technical artist、programmer、QA などが日常的に使う game development tools の利用状況をどう計測し、改善へ接続するかである。公式説明は、telemetry がより良い tools の開発を助ける一方、実際に users が作業する様子を観察せずに数値だけを読むと、深く誤解を招き得る、と問題を置く。

講演では real-world examples を使い、telemetry が何を示せて何を示せないか、tool に telemetry system を追加する時に何を考慮すべきか、時間経過に伴う tool UX の改善をどのように追跡するかを扱う。takeaway として、telemetry 導入時の検討事項、data の有効な使い方、避けるべき common pitfalls、tools development process への telemetry data の組み込みが挙げられている。対象 audience には tools / engine developers、tools designers、technical artists、technical directors、technology managers、tools QA が明記され、計測を独立した dashboard 作りではなく、制作ツールの改善サイクルへ入れる実務講演として位置づけられている。

## why_relevant_to_games

ゲーム制作 harness や editor 補助ツールの使用回数・完了率・滞在時間を、実際の操作観察と組み合わせて読むための収集候補。自動計測が示す行動と、制作者が詰まった理由を分離する検証設計に使える。
