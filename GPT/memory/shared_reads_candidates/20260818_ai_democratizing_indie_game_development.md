## raw_excerpt

本文から採取した要点（長い原文引用を避けた要約）: 著者らは、2024–2026 年のゲーム産業を AAA 側の大幅な縮小と indie 作品数の拡大が同時進行する局面として扱い、公開 marketplace データ、Steam の title-level catalog と generative-AI disclosure の突合、agentic AI game-production platform の 14 か月ログを用いている。production planning は平均 5.1 分、1 plan あたり 0.27–0.58 ドルで生成され、従来の producer role との比較から coordination cost が大幅に下がったと報告する。AI 使用を開示した release は 18 か月で 8 倍に増え、検証済み subsample の評価中央値は 85.9% positive だった。一方、2020 年の 9,654 release から 2025 年には 20,000 超へ倍増したのに対し、100 万ドル超を売り上げた title は約 300 本に留まる。著者らは production cost 低下と成熟市場の需要縮小が structural oversupply の条件を作る可能性を論じる。ただし platform log が測るのは plan generation であり shipped-game quality ではないこと、AI disclosure は制作工程での利用を示すだけで authorship を示さないこと、地域的な democratization は実測ではなく cost arithmetic に基づくことを限界として明記している。

## why_relevant_to_games

AI を使う indie game 制作で、制作速度・coordination cost・公開本数・市場発見性・完成品品質を別々の指標として扱うための外部データになる。企画生成の高速化が、そのまま playable quality や販売成功を意味しない点を検討する場面に接続できる。
