## raw_excerpt

Grey Alien Games が長年作ってきた solitaire design と、Night Signal Entertainment の1990年代 analog horror 表現を組み合わせた『Forbidden Solitaire』の制作経緯。通常の Klondike より速く combo を作れる tri-peaks / golf 系 rule を核にし、layout を片付ける感触、shop、decoration、power-up、RPG 的 combat などを複数作にわたって足してきた。『Shadowhand』では turn-based combat と equipment、『Ancient Enemy』では elemental attack や spell へ展開し、その combat system を本作でさらに反復したという。記事は、一作だけの奇抜な混合ではなく、1995年からの solitaire 制作、17本の game、過去作の data を背景にした genre refinement として整理している。

本作は Night Signal 側の一枚 proposal から始まり、visual・audio・writing と、game design・programming を studio 間で分担した。完成 gameplay がない初期に teaser trailer を公開したところ拡散し、Steam wishlist が一晩で7,000に達した。開発者は horror が強い Steam 市場と、既存 solitaire engine を組み合わせる可能性を見ていた。release 後は48時間で10,000本、同時接続880を記録し、過去の solitaire 作の peak 98・20を上回った。記事では、外見に惹かれた audience が既存の card loop と独自 twist に留まったこと、成功後に過去作の販売も増えたことが述べられている。

## why_relevant_to_games

既知の mechanic を長期反復で磨き、別 genre の presentation と audience signal を接続する制作例として、core loop を捨てずに新しい入口を作る企画・prototype 段階の材料になる。
