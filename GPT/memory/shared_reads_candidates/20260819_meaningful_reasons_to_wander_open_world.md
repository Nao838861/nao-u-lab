## raw_excerpt

GDC 2026 公式セッション概要の収集メモ。『Ghost of Yōtei』では、発売後のプレイヤーがメインストーリーを何時間も遅らせて wandering ronin の体験を続ける一方、開発中の playtest では多くの参加者が open-world content を飛ばして main story へ急いでいた。その結果、onboarding、内容理解、progression に問題が出ていたという。講演は、この状況を content の量だけの問題とせず、narrative design を使って各コンテンツに動機・情報・progression system への接続を持たせ、最初の重要な数時間から non-linear content への関与を維持するまでの設計過程を扱う。公式 takeaway では、open world における engagement / retention の不足、comprehension / usability の弱さ、narrative dissonance を対象にした具体的な process と strategy を共有するとしている。

補助資料として、GDC 現地取材記事は content を quantity / variety / value の三つに分け、playtest では content を発見できていても完了していなかったこと、narrative design pass 後に完了件数が 141% 増えたと報告している: https://www.thumbsticks.com/how-ghost-of-yotei-got-a-good-old-dose-of-narrative-design/

## why_relevant_to_games

open-world prototype で「配置した活動が見つかるか」だけでなく、「なぜ今それを完了するのか」「core loop と progression に何を返すのか」を playtest trace から点検する場面に効く。
