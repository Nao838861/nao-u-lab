## raw_excerpt

GDC Vault の公式概要によると、『Wanderstop』は美しい風景、ユーモラスな登場人物、簡単な茶作り simulation を備え、cozy game の約束を外形として持ちながら、プレイヤーを生産的にも安らかにも感じさせない作品として説明されている。Lead designer の Steven Margolin は、物語と mechanics の釣り合い、genre expectation と実際の体験のずれ、開発中の逸話、プレイヤーを不快にする複数 mechanics を扱う。公式概要は中心命題を “Discomfort is an often maligned design goal” と置き、一般的な “finding the fun” の実務観に反する discomfort も designer の道具になりうる、という講演の射程を示している。セッションは Game Developers Conference 2026 の Design track に属し、Ivy Road の作品を単一事例として、快適さを期待させる表現と不快さを生む interaction を同時に扱う構成である。採取できた公開本文はセッション概要までで、各 mechanic の具体例、比較条件、playtest 結果は動画本編側にある。

## why_relevant_to_games

cozy genre の期待、物語上の葛藤、操作や進行 mechanics を意図的に食い違わせる設計を調べる入口になる。快適さ以外を目標にした player-experience 設計や、期待と現実の差を mechanics へ落とす場面に接続できる。
