## raw_excerpt

GMTK Game Jam 2026 の4日間で、3人チームがリズムゲーム『Antempo』を制作した記録。事前に One Button Jam へ参加してチーム作業を試した一方、テーマ発表前に作った mood board は実際の「Countdown」案には使われなかった。初日は50案以上を出し、Sokoban、園芸、蟻の行進を題材にした rhythm game の3案へ絞り、programmer が最も作りたい案を採用した。画面上の player が小さいことから題材を蟻に決めたが、ant と grid の寸法など基本仕様の合意にも時間を使った。

2日目は、全面が playable area になるため背景を抑えつつ vegetation frame を足し、scroll する複雑な level に備えて seamless background を制作した。作者は序盤20〜40%では art direction の良否を自分で判別しにくかったが、反復を経て main menu で方向性が固まったと記す。4日目、tutorial build を友人に渡したところ、最初の level が簡単すぎ、面白い mechanic が不足しているとの反応があり、team はその日の大半を gameplay の修正に使った。19時頃の build で難度を上げる mechanic が入り、満足できる gameplay cycle になったという。終盤は narrative video、UI、obstacle、music、SFX、level 1〜3 を並行してまとめた。作者は毎晩の social break が burnout を抑えたこと、jam art の経験により方向性が曖昧でも反復を続けられたことを振り返っている。記事は WIP と明記されている。

## why_relevant_to_games

短期制作での案の絞り込み、画面構成と art direction の反復、deadline 直前の外部 playtest が core mechanic と難度変更へつながる時系列資料として参照できる。
