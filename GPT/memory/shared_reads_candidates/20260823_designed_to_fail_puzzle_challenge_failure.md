## raw_excerpt

FDG 2026 の Game Design track に掲載された研究。従来の failure 研究は、ゲームが定義した fail-state にプレイヤーが遭遇する状況を中心に扱ってきたが、speedrun のように community が独自の目標を作る場合は、何を failure と呼ぶか自体が変わる。本研究は、ゲームを作る側が「プレイヤーが何度も失敗しながら楽しめる challenge」をどう捉えるかを調べるため、puzzle game developer 20名に semi-structured interview を実施し、inductive thematic analysis で設計思想、challenge の作り方、failure の概念、puzzle quality の基準に共通する主題を抽出した。

要旨では、開発者は incorrect attempt や performance の低さを中心的な failure と見なさず、プレイヤーが完全に disengage することを design failure と捉えていたと報告する。個々の setback は、解法へ近づくための experimentation と理解を促す意図的な learning mechanism として位置づけられる。また、player expectation と goal の置き方によって、探索のために「失敗してよい」という許可を与えることが重要だとされる。収録情報は FDG 2026 abstract page と ACM DOI metadata に基づく。

## why_relevant_to_games

puzzle や action game の失敗を死亡回数だけで数えず、再試行・実験・離脱まで含む設計対象として記録する際の外部事例になる。
