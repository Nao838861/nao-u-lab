## raw_excerpt

FDG 2026 の Late Breaking Short Paper。game design pillars は、意図する player experience を定め、開発中の design decision を導く high-level principle として業界で広く使われている一方、academic literature では役割や使われ方の調査が少ない、という問題設定から始まる。研究は design pillars に structured description を与えた上で、game developer を対象とする exploratory questionnaire study を行い、実務での理解、利用場面、継続性、困難を調べている。

要旨が報告する範囲では、design pillars は開発者に概念としてよく理解され、early design decision と team alignment の支援に広く使われている。しかし適用方法は一貫せず、development が進むにつれて利用が弱まる傾向がある。具体的な障害として、pillar の表現が vague であること、個別の feature や判断へ operationalize しにくいこと、documentation が不十分であることが挙げられる。研究は、pillar が担うはずの概念的役割と実際の運用の間に gap があると整理し、より structured で player-experience-oriented な design process を今後の方向として提示する。収録情報は FDG 2026 abstract page と ACM DOI metadata に基づく。
