## raw_excerpt

Game Developer の Bryant Francis が、Adam Saltsman の GDC 2026 講演と、1 年かけて短いゲームを多数作った CorgiSpace の制作実践を紹介した記事。各作品は意図的に短く、短い開発サイクルで作られている。記事が拾う中心語は、実装上は容易だが発想として自明ではない選択を探す “easy, but not obvious”、着想の核と最初の prototype / implementation / design doc に当たる formula を区別すること、そして使用中の tool や process が持つ「木目」に沿って作ること。Saltsman は idea を制作開始時の熱源や動機、formula をその idea の痕跡を写そうとする初期実装として説明し、実際に手を動かすと idea は概して強い一方、formula はそのままでは弱いことが多いと述べる。Dust Bunny などの小作品を例に、計画を先に固定するより、制作中に起きた挙動へ気づき、発見をゲームへ残す姿勢を示す。また、仕事や家庭の隙間で小作品を作る実践が負担ではなく回復になったと振り返り、完成まで関心を保ち、特別な核を掘り当てるには、制作者自身が作る行為を楽しんでいる必要があるという論点につなげている。

## why_relevant_to_games

短い playable prototype を量産する際の scope 制御、着想と初期実装の切り分け、偶発的な挙動を発見へ変える観察方法の参照になる。完成規模を増やさず制作サイクルを継続する場面に接続できる。
