## raw_excerpt

GDC 2026 のセッション概要によると、Embark Studios の登壇者は、同社の character pipeline が開発の中でどのように形作られたかを説明する。中核に置かれているのは Houdini と USD で、technical 寄りの担当者と art 寄りの担当者が、同じ共有空間で作業できる柔軟性を狙っている。自動化を最大にする単一路線ではなく、manual から automated までの連続した範囲として procedural mentality を扱い、制作上の具体例を示す構成である。

USD と Houdini の PDG、Solaris context を組み合わせる目的は、反復作業を減らしながら artistic freedom を広げることにある。この pipeline は、要件の異なる『ARC Raiders』と『THE FINALS』の双方を live production で支え、固定した完成形としてではなく、新しい解決策を継続的に探索する基盤として運用されている。資料の公開ページはセッション概要までであり、個々の node graph、asset schema、導入前後の工数や品質の計測値は現時点の収集範囲には含まれない。

## why_relevant_to_games

小規模制作でも、手作業を残す場所と自動化する場所を同じ pipeline 上で選べる設計や、技術・アート間の受け渡しを共通表現に寄せる際の参照になる。異なるゲームを単一の制作基盤で支える時に、共通化すべき層と作品固有の層を考える材料として使える。
