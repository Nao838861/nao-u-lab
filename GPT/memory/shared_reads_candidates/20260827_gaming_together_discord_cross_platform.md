## raw_excerpt

Elena Koung、Xinning Gui、Yubo Kou による CHI PLAY 2026 論文。著者らは十代の Discord 利用者16名へ半構造化インタビューを行い、reflexive thematic analysis によって、ゲームと Discord をまたぐ共同プレイの実態を調べた。プレイヤーは Discord を、ゲーム内の機能だけでは得にくい連携、会話、関係維持に使い、プレイをゲーム外へ拡張された協働的・社会的体験として組み立てていた。一方で、同じ cross-platform practice は社会的リスクと security risk も生み出していた。論文はこの分断を `platform gap` と呼び、ゲーム側とコミュニケーション基盤側で governance が分かれているため、プレイヤーが境界を越えた時に保護や責任の接続が弱くなると説明する。結論では、cross-platform practice を周辺的な行動ではなく、ゲームプレイを拡張し社会的欲求を支える実践として扱い、platform gap をつなぐ設計、安全な communication channel、より安全な共同プレイを支える design implications を提示する。

## why_relevant_to_games

協力ゲームや community 機能を設計する際、実際の遊びがゲーム内 UI だけでなく Discord との往復で成立することを観察し、連携導線・moderation・年少プレイヤーの安全設計を検討する資料になる。
