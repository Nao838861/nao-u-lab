## raw_excerpt

原文からの収集メモ（長文引用を避けた要約）。Unity が GDC で Strange Scaffold の Creative Director、Xalavier Nelson Jr. に行ったインタビュー。スタジオは過去6年で18作を出し、全員を part-time とし、精密な予算・期間・資源配分を使う「constellation model」で、必要に応じて人が集まり分かれる体制を採る。各 project は、対象 player、開発期間、予算、narrative arc、aesthetic、gameplay loop と、player／team の双方へ何を満たすかを定めた business case ができるまで始めない。

feature や意思決定の評価には DIDIT を使う。内訳は Direction、Impact、Dependencies、Iteration、Time であり、候補が project の目標に沿うか、player に何をもたらすか、team の条件で持続可能かを照合する。Nelson はこれを多数ある「can」の button に対する “should” button と表現し、generative AI が実装可能性を増やしても、実装すべきかの判断は別に必要だと述べる。また最新作では、緩く表現力のある運転操作と、sandbox city を走り回るだけでも気持ちよい navigation を制作中の核として挙げている。

## why_relevant_to_games

prototype や追加 feature の着手前に、作品の方向、player への効果、依存関係、反復余地、時間を同じ入口で記録する素材になる。小規模チームで「作れる機能」が増えた時の scope 選択と、core feel を早期に確認する制作場面に接続できる。
