## raw_excerpt

GDC Festival of Gaming 2026 の公式セッション説明。Sucker Punch Productions の programmer Roland Munsil は、『Ghost of Tsushima』出荷前の段階で、次作では脚本制作工程を大きく変える必要があると認識していた。従来は script をゲームへ組み込むための手作業が多く、writer には自分の文章が実際の game 内でどう使われるかを知る文脈が不足していたという。『Ghost of Yōtei』では新しい tool を一から作り、writer が “scripts directly into mission rigging” できるようにした。狙いは manual busywork を減らし、writer を design process の近くへ置くことだった。

公式説明では、この tool は writer と designer の両方を支援しただけでなく、開発中に対象範囲が広がり、recording、auditing、script review、localization の管理にも使われたとされる。講演は成功点だけでなく、設計や工程上のつまずきも扱い、dialogue producer、writer、tools programmer が writing、rigging、recording をつなぐ pipeline を考えるための事例として構成されている。2026年3月12日の中級者向け講演で、Vault recording がある。

## why_relevant_to_games

物語テキストを別工程の納品物にせず、mission 実装・収録・監査・localization と同じ制作経路へつなぐ事例。会話のある小規模ゲームでも、writer が実行時文脈を見ながら反復できる tool と source of truth を設計する場面に活用できる。
