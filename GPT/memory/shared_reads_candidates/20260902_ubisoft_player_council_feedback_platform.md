## raw_excerpt

Ubisoft News の 2026年8月26日付記事を基にした日本語採取メモ（逐語引用ではない）。The Player Council は、開発者と参加プレイヤーを直接つなぎ、PC 向けゲームの初期 concept、prototype、既存 live game の更新案までを遊んで feedback できる基盤として soft launch された。開始時の対象は、初期 prototype の Codename Split Point と Codename Rook、live game の Riders Republic と Atomega。秋には Codename Decagon と Codename Harlequin も追加予定とされる。

参加希望者は無料登録時に NDA へ同意し、各 project へ応募する。開発チームに受け入れられると build を遊び、feedback を共有し、他の参加者とも改善案を話し合える。開発者側も、feedback を評価して iteration する際の意思決定を参加者へ説明する。参加履歴は Member、Insider、Shaper の access tier に接続され、継続的な play、constructive feedback、他参加者との協働によって、より機密性が高い project や早期 content に触れる機会が増える。

Split Point は時間制限下の tactical decision を扱う online 1v1 turn-based concept で、core loop と市場投入に必要な feature について意見を集める。Rook は planning と adaptability を軸にした single-player strategy concept で、core gameplay loop の refinement が収集目的。Atomega は9年ぶりの更新に向け、新しい idea、variation、depth、play style を試し、community input を今後の content へ反映する。prototype の test は無料で、live game content の test は対象 game の所有者向け。基盤には Ubisoft Connect と Games2Gether が使われる。

## why_relevant_to_games

初期 core loop と live-ops 更新を同じ参加基盤で扱い、NDA、参加者 tier、開発者からの判断説明まで含めて継続 playtest を運用する事例として、prototype の feedback 導線を設計する場面に接続できる。
