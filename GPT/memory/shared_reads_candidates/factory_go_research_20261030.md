# ファクトリ囲碁調査（2026-10-30）

状態: ローカル調査メモ。Slack未投稿。公開資料の調査であり、実プレイ・実装検証は未実施。

## 確認できたこと

ひらじ氏の無料ブラウザゲーム。2026年10月21日初公開、24日itch.io正式公開。公式ページはCPU4段階、同端末対戦、オンラインのランダム対戦・合言葉対戦、棋譜リプレイを案内する。

石を工場、呼吸点を排気口、二眼を煙突2つの大型工場に対応させる。排気口を塞ぐと爆発するため、捕獲の条件を世界観の因果として理解しやすい。

重要な版差: 10月26日の作者告知では、終局時に大型工場以外をすべて爆発させる仕様へ変更。初期紹介の「囲碁そのもの」「相手の石を実際に取り切る必要がある」を、そのまま現行版の説明に使わない。告知本文はXの第三者ミラーで確認したもので、現行実装との一致は未検証。

日本囲碁規約第9条では双方の着手放棄で対局停止、その後死活と地を確認して合意すると終局する。初心者には合法手の理解に加えて、打ち続けた場合の結果を見通す判断が必要になる。セキによる生きもあり、二眼を明示的に完成していないことと死石であることは同義ではない。

## 考察

この作品は、抽象的な状態を工場の危険・爆発・進化へ対応させ、何を守り何を目指すかを盤面上で知らせる設計例として有用。特に二眼を「取られなくなる性質」から「完成させたい建物」へ変換した点に注目する。

終局の変更は、通常の囲碁の死活を完全に自動判定したという意味ではない。大型工場という明示的な達成条件へ寄せる設計と解釈できる。取り切る手間を減らす一方、大型工場への完成を忘れると失う負担がある。通常囲碁への学習転移と、独立したゲームとしての明快さは分けて評価する必要がある。

制作への応用仮説: 状態の説明文を増やす前に、危険の原因と回避行動を世界観・表示・結果演出で対応させる。ただし、この作品の学習効果を対照実験で実証した資料は今回確認していない。
