■ 概要
この研究は、複数のLLMを組み合わせる時に「個々の性能」だけでなく、モデル内部の表現空間が互いにどれだけ似ているかが、協力と創造性を予測するのではないかと検証したものだ。人間では神経反応が近い相手ほど社会的な親密さや協力成功が高く、異質な相手との交流は革新を生みやすいという知見がある。著者らはこの関係をLLMへ移し、8系統・23個のopen-weight model、全276 pairを対象に、協力4課題と新規性4課題を実行した。

表現類似性は、同じ文章を各modelへ入力して各層の最終token activationを取り出し、異なるarchitectureや層数でも比較できるlinear CKAで測る。probe datasetは一般言語のWikiText、数学のGSM8KとMATH、真実性のTruthfulQAの4種で、全層組合せのCKAを平均するglobal averageと、各層の最も近い対応層を平均するmaximum-aligned scoreの双方を確認した。CKA計算はagent interactionとは独立しており、結果を見てから似ていると判定したわけではない。

協力課題は、26文字それぞれで一語hintから秘密語を当てるWord Guessing、各自100ドルから公共potへ拠出し1.3倍後に均等配分するPublic Good、要求額合計が1ドル以下なら受け取れるDivide-a-Dollar、相手の推論を読み2人の平均の3分の2へ近づけるKeynesian Beauty Contestである。後3課題は5 round、各pairにつき少なくとも4 sample、temperature 0.7で実行し、0.3でも再検証した。model固有の能力差と同一modelが複数pairへ現れる非独立性を扱うため、pair outcomeを目的変数、CKAを固定効果、各modelをrandom effectとするmixed-effects regressionを使った。

結果は、表現が近いpairほど4課題すべてで協力成績が高い。CKAが0から1へ増える回帰上の相対変化は、WikiText条件でWord Guessingが88.2%、Public Goodが34.8%、Divide-a-Dollarが29.9%、KBCが4.5%だった。KBCの効果が小さいのは、両者が0を選ぶ一意なNash equilibriumがあり、相手との共有理解がなくても固定解へ収束できるためだ。

新規性課題では、2 modelが別々にbrainstormし、案を結合してから各自が物語、架空人物伝、俳句、休暇の利点を書く。各pair 10生成を取り、内容の異なるcluster数でuniqueness、reward modelでquality、単独案と共同案のmutual informationで相手から得た新規性を測った。類似性が高いほどcluster数は一貫して減り、特に俳句で強かった一方、qualityには系統的な低下がなかった。つまり異質なpairは、少なくともこの短文課題では品質を犠牲にせず出力の幅を増やした。

この傾向はmodel性能差、同一model pair、同一family、tokenizer共有、size差を統制しても残り、early one-third layersの類似性が中層・後層より強く関連した。著者らは、基礎的な語彙・意味groundingの共有が意思疎通を安定させ、そこからの隔たりが共同案の新規性を増やす可能性を示す。ただし結論は因果ではなく、表現類似性をagent編成の有力な予測変数として扱える、という段階である。

■ 内容分析
重要なのは、「同じmodelを複数立てると協力しやすい」という既知の運用感を、family名やparameter数より細かい連続量へ落とした点だ。同一familyでもCKAには幅があり、逆に設計要因を統制した後もCKAが最も強いpredictorだった。非公開のtraining data overlapや内部設計を直接知れなくても、probeへのactivationが取れるopen-weight modelなら、組合せ選定前に相互作用の性質を見積もれる。

一方、協力と呼ばれる四指標は同じ能力を測っていない。Word Guessingは共有語彙と相手のhint解釈、Public Goodは利他的拠出、Divide-a-Dollarは要求の調整、KBCは相手の再帰推論予測である。全課題で正方向だったことは強いが、KBCでは行動差を統制すると表現類似性が有意でなくなった。固定最適解が強い課題では内部の近さより、同じ数値行動へ収束した事実が支配する。したがって「協力agentは似たmodelで統一する」という一般則ではなく、相手の曖昧な意図を復元する仕事ほど効果が出やすい、という条件付きの読みが妥当だ。

創造性側も「作品が良くなる」とは示していない。測ったのは10出力のcluster数と、単独brainstormから共同brainstorm後の出力がどれだけ離れたかである。異質pairは違う案を増やしたが、その案が人間にとって面白い、遊べる、制作可能であることは別問題だ。qualityが低下しなかったのは有望だが、reward modelによる1〜10評価であり、ゲーム企画のmechanic qualityや長期制作価値の保証ではない。

early-layer結果も機構の証明ではない。語彙・意味groundingが原因という説明は整合的だが、CKAは表現空間の一側面しか捉えず、training data、post-training、token distributionなど未測定要因のproxyかもしれない。論文自身も、課題によって効果が消失・反転し得ること、類似性と相互作用の普遍則はまだないことを認めている。よってCKA値を絶対的な人員表へせず、工程と課題を固定した比較実験の仮説生成に使うべきだ。

■ 自分達の環境への適用
直接使えるのは「常時同じ編成」ではなく、制作工程ごとに必要な相互作用を分けることだ。仕様の整合、既存設計の読み合わせ、再現手順の受け渡し、同じheadless traceからの不具合特定は、共有groundingが効く収束課題である。ここでは同じmodel・近いprompt・共通schemaを使い、誤解と伝達lossを減らす。逆にmechanic探索、失敗原因の別解、既存案への反証、意外なtheme接続は探索課題なので、model familyだけでなく観測形式、評価rubric、初期資料をずらし、同じ発想への早期収束を防ぐ。

小さな検証では、同一のprototype briefに対して三条件を作る。Aは同model・同promptのpair、Bは異model・同prompt、Cは異model・異なる評価役割とする。探索段階では、提案mechanicのsemantic cluster数、既存案との重複率、実装可能条件を満たした非重複案数を測る。収束段階では、仕様矛盾の検出率、同じtraceから同じfailure causeへ到達する率、修正後のtest pass率、統合に必要な往復数を測る。作品評価と発散量を混ぜず、探索では幅、収束では合意精度を見る。

headless評価でも編成を固定しすぎない。play botとjudgeが同じmodel・同じ説明文に依存すると、同じ盲点を共有し、安定した高scoreを返しても人間の違和感を落とす可能性がある。まず近いagentでdeterministicなrule violationと再現性を確認し、その後に異質なjudgeへreplay、screenshot、event logだけを渡して、別の失敗分類が出るかを見る。ただし異なるmodelを置くだけでは独立性は保証されないため、観測入力と合格条件も分離する。

記憶システムには、agent名より「どの工程で何の差を作ったか」を残す。candidateやatomへ、探索／収束、model family、prompt差、参照資料差、生成案の重複率、最終採用理由を記録すれば、後から多様性が実際に成果へ寄与したか追える。CKAを直接計算できないclosed model中心の環境では、出力の語彙分布、失敗分類の一致率、同じ入力への案clusterなどをbehavioral proxyにし、因果を主張せず運用上の比較値として使う。

■ メリット・デメリット
メリットは、agent編成をmodel単体のleaderboardからpairの相互作用へ移し、協力安定性と発想幅のtrade-offを同じ軸で説明したことだ。23 model・276 pair・8課題、複数probe、二種類のCKA集約、temperature変更、性能差やfamily等の統制があり、単一benchmarkの偶然より頑健である。探索と収束で編成を切り替える設計仮説は、追加実装なしでもpromptと担当の分離から試せる。

デメリットはopen-weight modelのactivation取得を前提とし、closed modelへCKAを直接適用できないこと、短い二者課題を長期のゲーム制作teamへ一般化できないことだ。創造性の指標は作品価値ではなく出力多様性で、協力指標も安全性や真実性を測らない。さらに相関研究なので、CKAが高いmodelを選べば必ず協力が改善するとは言えず、多様性を増やせば有用案が増える保証もない。

■ 判定
部分採用。表現類似性そのものを選抜基準にはせず、「収束工程は共有groundingを揃え、探索工程はmodel・観測・rubricの差を意図的に作る」という切替仮説を採用する。次回の企画探索とheadless reviewで同質／異質条件を比較し、案の非重複数と統合往復数を別々に記録する。
