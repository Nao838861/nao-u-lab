■ 概要
GENSTRAT は、LLM の戦略能力をポーカーなど少数の既知ゲームの勝率で測ると、訓練データ混入、ベンチマーク飽和、未知環境への外挿不能が同時に起きるという問題から出発する。提案の核は、二人零和・不完全情報の generalized betting game（GBG）を、整数 seed から手続き生成して評価対象そのものを分布化することだ。生成器はカード枚数だけでなく、賭け、同時手、競売、観測、条件分岐などの phase graph、手札、順番、公開情報、勝敗条件まで組み替える。12,351 seed を候補にし、random agent による各 2,000 episode の検査で、長すぎる対局、ほぼ発火しない phase、死んだ分岐を除外して 2,000 ゲームを採択。その中から 6 軸空間の farthest-point sampling で 50 ゲームを選んだ。

6 軸は、観測情報状態数の対数で見る state space、序盤の判断が後の payoff 分散へ及ぼす temporal depth、最善手が私有情報で変わる information sensitivity、相手方策に応じて best response が変わる opponent modeling、期待値最大手と下方安全手の隔たりを見る risk、方策の 3% を乱した時の利得変化を見る brittleness である。これは生成器の直接ノブではなく、Monte Carlo から算出したゲーム側の診断量である。

評価は frontier / open-weight 9 モデル、50 ゲーム、36,937 match rows。席順を交換し同一のカード乱数を共有する paired matches を組み、勝敗ではなく chips/game の符号付き margin を additive paired-comparison model で推定した。全体順位は概ね安定した一方、model×game interaction は全 9 モデルで model main effect の 0.49 倍、外れ値の最下位モデルを除くと 1.29 倍に達した。つまり平均順位が近くても、どのゲームで強いかは平均差と同程度に変わり得る。著者らは各モデルの 6 軸回帰 profile に加え、軸空間で近いゲーム間の性能変動を jaggedness として測り、総合力と局所安定性を分けて報告する。結論は「強いモデルを一つ選ぶ」より、配備先に近い能力 profile と局所的な滑らかさを併記すべき、という評価設計への転換である。

■ 内容分析
この研究の価値は、procedural generation を単なる問題数増加ではなく、評価の独立変数を設計する道具として使った点にある。50 問を更新できるだけなら汚染耐性の話で終わるが、GENSTRAT はゲーム生成、軸による層別化、対戦 margin、近傍変動を一つの測定系に接続した。特に「平均が同じ二モデル」を区別できる。上位三モデルは brittleness が増すほど他モデルとの差を広げたが、その形は同じではない。あるモデルは state space と opponent modeling にも広く伸び、別のモデルは brittleness の寄与へ集中した。平均値だけなら交換可能に見えるモデルが、精密実行を要する環境と相手適応を要する環境では交換不能になる。

jaggedness も重要である。モデルごとの game strength から全体 strength を引き、ゲームごとの stake scale で標準化し、6 軸空間の各ゲームと最近傍 3 ゲームからなる局所集合の標準偏差を平均する。これにより「軸上では似ているのに性能が跳ぶ」度合いを得る。上位モデルにも高平均・高変動と高平均・低変動があり、強さと予測可能性が別物だと示した。さらに per-game ranking の反転は 50 ゲーム中 15 件で noise-only null を FDR 5% 水準で上回った。ただし反転は難しいゲームではなく、上位と中位の margin が縮む易しい tertile に集中した。局所破綻の探索を最難関ケースだけに寄せると、モデル固有差をむしろ見逃すという示唆がある。

一方、指標を額面通りに能力の実体と読んではいけない。軸は完全直交ではなく、state space と information sensitivity の相関は 0.65。能力 profile は 50 ゲーム上の多変量 OLS で、ゲーム族外への因果的説明ではない。jaggedness の分母は当該 tournament の対戦群から得た margin 分散なのでゲーム固有定数ではなく、profile の滑らかな急勾配や per-game 推定ノイズも残る。結果は sum-to-zero 制約下の 9 モデル内相対値で、絶対的な戦略能力を校正する solver baseline は tractable な 5 seed に限られる。自然言語 rulebook も約 8,600〜39,000 文字と幅があり、長さを統制しても slope は安定したが、記述順や曖昧さまで除けたわけではない。この論文が確立したのは万能な 6 能力尺度ではなく、生成分布上で局所差を測る実用的な枠組みである。

■ 自分達の環境への適用
直接持ち込むべきなのはカードゲーム生成器ではなく、「変種群→診断軸→平均性能→近傍差」の評価 packet である。headless 自動プレイヤーについて、単一 build の平均 score や到達率だけを採点せず、同じゲームの seed・rule・観測・時間制約を系統的に変えた sibling cases を作る。軸の初期候補は、観測欠損、行動分岐数、報酬遅延、敵挙動への依存、損失の裾、入力精度への感度でよい。各軸は名称だけ先に固定せず、episode trace から再現可能に計算できる定義を与える。例えば入力精度感度なら、訪問確率が合計 3% になる decision contexts だけ action を代替し、score / survival / objective 達成の差を測る。

最小 probe は、既存の一つの playable build から 24〜40 cases を作ることだ。完全な手続き生成器を先に作らず、8 基準 seed に対して観測、時間深さ、リスク条件を一つずつ小変更する。各 case は同じ乱数列で baseline bot と候補 bot を往復実行し、seat/order に相当する初期条件差を相殺する。出力は平均 score だけでなく、合法手 fallback、停止、目的未認識、局所 stuck、回復時間を保存する。ケース特徴を正規化し、近い 3 ケース内で候補 bot の baseline 比 residual が大きく跳ぶ箇所を列挙する。ここでは単一の jaggedness 値をランキングに使うより、「どの sibling change で壊れたか」を trace へ戻せることを優先する。

記憶システムにも同じ構造を移せる。recall の平均 hit 数だけでなく、問い合わせを時間距離、固有名詞依存、複数 atom 統合、原文証拠要求、矛盾含有などで変種化し、近い query 間で evidence precision が跳ぶ地点を記録する。制作サイクルでは、その局所破綻を恒久ルールへ即昇格させず、次 cycle の可逆 probe として一件だけ再試験する。GENSTRAT の evergreen 性を、毎回ランダム問題を増やすことではなく、既知ケースへ過適合した改善を held-out sibling で見破る仕組みとして使う。

■ メリット・デメリット
メリットは三つある。第一に、固定ケース合格を能力と誤認しにくい。第二に、同じ平均点の実装を failure shape で区別でき、改善対象を具体化できる。第三に、seed と変種生成規則を残せば、playable diff の前後比較を再現しつつ、新規 held-out cases も追加できる。平均性能と局所安定性を別々に持つことで、「普段は強いが近い条件変更で崩れる」bot を安全側に扱える。

デメリットは、軸設計そのものが新しいバイアス源になることだ。二人零和カードゲームの private information や chip margin は、real-time action game の知覚遅延、連続制御、探索、楽しさを覆わない。ケース数が少ないまま 6 軸回帰や近傍統計を使えば、精密そうな不安定値を作るだけになる。また、局所変動には本当の破綻だけでなく、乱数、対戦相手構成、測定 scale、特徴量に表現されない差が混ざる。したがって数値を品質ゲートへ直結せず、paired run、bootstrap、trace 再生を伴う異常候補抽出器として扱う必要がある。生成器の整備がゲーム制作そのものを食い始める危険もあるため、最初は手作業で意味の分かる sibling cases に限定する。

■ 判定
部分採用。採るのは、評価対象を更新可能な変種分布にし、平均値・能力 profile・局所変動を分離する設計である。6 軸の名称、カードゲーム生成器、単一 jaggedness 順位は移植しない。まず 1 build・24〜40 cases の paired headless probe で、平均では見えない破綻が trace と結び付くかを検証し、有効だった軸だけ残す。
