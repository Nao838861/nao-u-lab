■ 概要
Huang らの Trust-ya は、小集団で地位・leader-follower 関係・持続的不平等がどう生まれるかを観察するための、3人以上向け協力競争型 betting game である。問題設定は、個人が利己的に動ける状況でも集団全体の獲得量を増やすには協力が必要であり、その協力が誰への服従や資源集中を伴うか、というものだ。各 round でプレイヤーは中央 pool から少量を自分で取るか、同量を他者へ渡す。資金を受けた者だけが gamble でき、投資額がまとまるほど期待 payout が指数的に増えるため、複数人が一人の「leader」へ投資を集中させる誘因が生じる。leader は得た payout を支援者へ自由に配分でき、支持を維持する還元と自己 stash の最大化を両立させなければならない。

不確実性は通常のトランプで導入される。数字札なら投資額・札の値・人数補正から payout が決まり、J/Q/K は対応する protection card（P-card）を持たなければ無配当に加えて損失が発生する。P-card は coin で買えるが、支持者が少ないと失われるので、支持の集中が投資能力を高め、その能力がさらに支持を集める自己強化 loop になる。一方、匿名のプレイヤーが買える emoji は直接的な効用を持たず、唯一の communication channel 兼 status symbol である。つまり論文の着想は、地位を固定役職や明示 rating にせず、「他者から与えられる投資」「還元実績」「支持が維持する能力」「実利のない可視記号」の組合せとして操作可能にした点にある。

評価は total earnings と Gini coefficient の二軸で行う。simulated agents では、常に自分で取る戦略は平等だが非効率、全員が一人へ投資して均等配分する協調済み戦略は高効率・高平等となった。過去の個別 return を強化学習的に追う Smart 系、P-card を維持できそうな時だけ買う Smarter 系、emoji 数を手掛かりにする Status 系も比較している。全員が毎回 emoji を買う Status bot は記号が差別化を失って低成績だが、直前に支持を受けた時だけ買う Smart Status は高い総獲得と低い不平等を示した。人間 pilot では4–14人の設計 session を約6回行い、その後7人・8人の匿名 session を各約30分実施した。一人か二人の leader が早期に生まれ、emoji の買い合いと支持移動が観察され、典型的には一人が富の約1/4、半数が約1/2、残り半数がわずかを持つ分布になった。結論は、服従によって共同利得が増える dilemma と、分配権を持つ中心者を組み合わせるだけで、期待される地位秩序を発生・観察できる、という設計可能性の提示である。

■ 内容分析
最も強い点は、社会心理学の status を一本の数値へ潰さず、主観的表示と客観的能力をずらしたことだ。他者に見えるのは emoji と匿名名だが、実際の投資耐性は隠れた P-card に宿る。可視記号を信じて資金が集まり、集まった支持が P-card を維持し、成功と再分配が記号の意味を事後的に正当化する。安い hamburger emoji を大量購入した勝者の後、同記号が「その人物らしさ」「勝者らしさ」を帯びたという例は、装飾品の意味がシステム内価格だけでなく局所的な履歴から生成されることを示す。これは単なる cosmetic economy ではなく、cheap talk が成功履歴と結び付いて社会的 signal へ変わる過程を遊びとして露出させている。

ただし結果は仮説生成の水準である。bot 比較は各 population が同一戦略で構成された baseline で、異質戦略間の安定性や因果効果を十分に検証していない。図の良好領域も最大 earnings の20%以内かつ Gini 0.2以下という設計上の目安で、統計的優越性ではない。人間評価も開発関係者を含む反復設計 session と、7人・8人の匿名 pilot 各1回であり、対照条件、効果量、信頼区間、事前登録がない。約30分で leader が現れた事実は「仕組みが現象を起こせる」ことを支持するが、現実の status 理論を妥当に測れていることや、別集団へ一般化できることまでは示さない。

また地位と富の分離は完全ではない。論文は status を直接的 power や wealth と区別するが、ゲームでは支持、P-card、投資成功、分配権、stash が強く連結される。そのため観察された追随が象徴的地位への服従なのか、合理的な期待 return 最大化なのかを切り分けにくい。逆に、この交絡はゲーム設計上は有用でもある。プレイヤーは「強いから従う」「公平だから残る」「記号を信じる」を同時に判断し、その曖昧さ自体が社会関係を作るからだ。研究計測として使うなら、emoji 非表示、P-card 非搭載、分配履歴の可視性変更などの ablation が不可欠になる。

■ 自分達の環境への適用
採用先は、固定された commander class を置かずに協力関係が生まれる multiplayer prototype の設計 probe である。最小実装は4体、20 round、毎手番「自己取得1」か「他者へ投資1」、投資総量に対する凸型 payout、受益者による自由配分、実利ゼロの3種 symbol に絞る。P-card は第二段階に回し、まず資源集中と還元だけで leader が発生するかを見る。headless agent は、自己取得、直近 return 追随、最多支持追随、探索率付き追随、均等還元、搾取的還元を組み合わせ、seed ごとの支持 network を再生する。

計測は最終 score だけでは足りない。round ごとの投資先 entropy、最大中心性、leader 交代回数、同一相手への継続率、leader の還元率、総 utility、Gini、symbol 購入後の新規支持増加を event log に残す。重要なのは「leader ができたか」ではなく、還元停止後も惰性で支持が続くか、symbol が実績を超えて選択を予測するか、効率向上と不平等増大がどの parameter で分岐するかである。最初の検証は、symbol なし／あり、payout が線形／凸型の2×2条件を同じ agent set と seed 群で比較する。symbol があるだけで支持固定が増えるなら社会的 signal の効果、凸型だけで集中するなら経済的誘因の効果として一段切り分けられる。

人間 playtest では勝敗だけを評価せず、終了後に「誰を leader と見たか」「投資理由は期待 return、公平さ、記号、惰性のどれか」を短く回答してもらう。telemetry 上の中心性と主観回答が一致するかを照合すれば、設計者が leader と解釈した network をプレイヤーも地位として経験したか確認できる。人工 agent を人間集団へ混ぜて協力を誘導する案は現段階では採用しない。欺瞞、同意、心理推定の問題があり、まず全 bot の sandbox と、agent であることを明示した小規模 playtest に限定する。

■ メリット・デメリット
メリットは、抽象的な「信頼」「地位」「服従」を説明文ではなく、投資先・配分率・装飾購入という少数の観測可能な入力へ変換できること、集団効率と分配平等を別軸で評価できること、単純 agent から人間 playtest まで同じ event schema を使えることにある。さらに、leader を役職として配らないため、成立、固定、離反、交代そのものが play になる。実利のない symbol が履歴によって意味を獲得する設計は、cosmetic を数値 buff にせず社会的機能へ接続する具体例として価値が高い。

デメリットは、凸型 payout と支持で維持される P-card が「勝者へ集中せよ」という答えを強く埋め込み、発見したい現象をルールが半ば強制していることだ。高効率と高平等の両立も、中心者が公平に配るという脆い条件に依存する。情報を隠しすぎると記号への追随ではなく単なる推測になり、表示しすぎると最適化問題へ縮退する。pilot の規模と参加者構成では外的妥当性が低く、emoji の文化的意味や既存関係も統制されていない。現実の集団診断へ転用すると、ゲーム内行動から人格や社会的地位を過剰推定する危険がある。

■ 判定
部分採用。地位を「他者の投資が能力を作り、その能力が支持を再生産する loop」として実装する骨格、総 utility と Gini の二軸、symbol 条件の ablation は試作へ採る。一方、論文の pilot 結果を一般法則として扱うこと、人間集団へ非開示の誘導 agent を入れること、ゲーム内中心性を現実の地位診断に使うことは採らない。まず headless 2×2 probe で経済的集中と象徴的追随を分離して検証する。
