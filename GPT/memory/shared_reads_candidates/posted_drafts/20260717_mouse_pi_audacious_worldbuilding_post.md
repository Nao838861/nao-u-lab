■ 概要
対象は Bryant Francis による “Analyzing Mouse: P.I. For Hire's audacious worldbuilding - Narrative Notebook #4”。Fumi Games のデビュー作『Mouse: P.I. For Hire』を、1920〜30年代の rubber-hose animation と film noir を模倣した FPS という外見だけでなく、その様式が謎、人物、level design、政治的寓意まで支えられているかという観点から、開発者取材を交えて検討した記事である。

本作の主人公 Jack は、舞台奇術師 Steve Bandel の失踪を追う私立探偵だ。調査は、戦友でもあった Bandel に何が起きたか、Mousewood のスター Betty Lynch を誰が殺したか、Mouseburg の shrew たちを誰が誘拐しているか、という三つの謎へ分岐する。背後には cult、腐敗した警察、政治家、German American Bund を戯画化した Big Mouse Party がいる。ただし遊びの中心は推理パズルではなく、銃、turpentine、cannonball で敵を倒す高速 FPS である。開発側の課題は、探偵を主人公にする以上必要となる hidden agenda と謎を、running and gunning を止めない形で成立させることだった。

記事が成功点として挙げる中核は、登場人物が cartoon 世界を絶対的に真剣に扱うことだ。alcoholic cheese、落下する金床、壁を突き抜けた身体型の穴は、作中人物にとって日常の物理法則であり、笑うのは観客側だけである。開発者は『裸の銃を持つ男』を、パロディの表面ではなく、人物の深刻さと観客の笑いを分離する参照にした。この姿勢が、誇張された noir 演技と人物同士の履歴を、単発 gag ではなく Mouseburg の因果としてまとめている。

さらに失踪した Bandel が入った pocket dimension “The Unknown” を、謎の答えであると同時に level-design の許可装置として使う。映画スタジオの soundstage、VIP party を横切る riverboat、swamp、gothic locale と現実の地続きから始め、false door、non-Euclidean geometry、cosmic horror へ段階的に逸脱する。rubber-hose animation 自体にも Fleischer Studios の『Swing You Sinners!』『Minnie the Moocher』など horror の系譜があるため、異質な genre を後付けせず、表現史と空間変形の双方から接続している。

一方、記事は政治的 worldbuilding の失敗も具体的に指摘する。BMP と警察が shrew を誘拐・追放する筋は、米国の反ユダヤ主義、Tulsa race massacre、Bayou と Voodoo、複数の少数者迫害を一つの架空種族へ溶かしている。開発側は特定集団の直接的表象ではないとするが、species の実在的差異や shrew と The Unknown の神秘的関係が差別の理由として読めてしまう。結論は、大胆な様式混合と真剣な人物造形は成功したが、現実史を薄い合成寓話へ圧縮すると、何を批評し何を娯楽上の引用としているかが曖昧になる、という両義的な評価である。

■ 内容分析
この事例で重要なのは、「強い美術様式が世界設定を作る」のではなく、様式、人物の欲望、複数の謎、空間の変化が互いを拘束して初めて世界になることだ。rubber-hose の見た目や cheese joke は入口にすぎない。Cornelius Stilton、Tammy Tumbler、Wanda Fuller らがそれぞれの立場と履歴から事件を深刻に扱い、三つの謎が政治、犯罪、超自然へ異なる角度で同じ都市を掘る。そのため反復訪問する Mouseburg の各地域も、New York、Los Angeles、Louisiana Bayou の画像的 collage だけでなく、容疑者と勢力の配置として記憶される。

The Unknown の使い方も、自由な setpiece を正当化する lore を置いただけではない。missing-person case から cult の気配、gothic な場所、誤作動する扉、非ユークリッド空間へ順番に強度を上げ、プレイヤーが持つ「noir cartoon FPS」の予測を一段ずつ更新している。David Lynch、第一期『True Detective』、Remedy 作品を参照し、超自然が犯罪の責任を代行するのではなく、人間の悪と並存する曖昧さを狙う点も大切だ。cosmic horror を万能な説明にすると殺人や共謀の責任が消えるが、本作は世界の背後に何かいる可能性を植えつつ、警察や BMP の行為主体を残そうとしている。

ただし、同じ「混ぜる」手法が政治的寓意では逆効果になる。The Unknown は複数の参照元が、未知への不安と空間の不安定化という共通機能へ収束する。対して shrew は、ユダヤ人迫害、Black community への集団暴力、Voodoo、移民や少数者一般を背負わされながら、どの歴史の主体・制度・被害を描くかが定まらない。BMP の German American Bund 参照や警察の加担は具体的なのに、被害側だけが合成種族になるため、加害の引用精度と被害の抽象度が釣り合わない。

ここは「寓話なら安全」という発想への反例でもある。現実の人種差別は、被差別集団に生物学的・神秘的な本質差があるから起きるのではない。mouse と shrew が文字通り別 species で、さらに shrew に超自然との特別な結びつきを与えると、作中差別が虚偽の偏見ではなく観測可能な差への反応に見える余地が生まれる。加えて shrew と Jew の音の近さ、反ユダヤ宣伝における rodent 表象まで重なる。作者の意図が特定集団を指していなくても、参照の束が読者側で具体的な歴史へ接続される以上、「直接の比喩ではない」は免責にならない。

■ 自分達の環境への適用
ゲーム制作では、visual hook を決めた直後に lore を大量追加するのではなく、「この世界の人物が真剣に守る因果」「プレイヤーが追う二〜三本の疑問」「各 level がその疑問をどう進めるか」を先に対応表へする。たとえば cartoon physics を使う prototype なら、伸びる身体や描いた扉を gag として並べるだけでなく、住民はそれをどう仕事、犯罪、防災に利用するか、敵と主人公で同じ法則が働くかを定義する。headless 評価でも、台詞量ではなく、主要 encounter が少なくとも一つの謎を進めるか、setpiece が既出の世界法則を変奏しているかを trace できる。

The Unknown 型の段階設計は小さな probe に落とせる。通常空間、予兆、局所的な法則違反、全面的な異界の四段階を一つの短い level に置き、各段階で一つだけ空間 rule を崩す。seed ごとに到達時間、迷い、死亡位置を記録しつつ、人間レビューでは「唐突な別 genre」か「以前から潜んでいた層の露出」かを判定する。重要なのは、異界を何でも可能にする免許にせず、入口、反復 motif、崩れる順序を固定することだ。

現実史を借りる設定には別のレビューを置く。各要素について、参照した出来事、加害主体、制度、被害、架空世界での対応先、species や魔法によって意味が変質する箇所を書く。複数の歴史を統合するなら「共通しているから」では足りず、統合で消える固有差と、誰の責任が曖昧になるかを明記する。対応表が一対多になり、被害側だけが抽象化される場合は、寓話を薄めるか、逆に特定史へ焦点を絞る。これは正しさの点検だけでなく、作品が自分の主題を言い切れるかの設計レビューである。

記憶システムにも同じ区別を使える。複数資料を一つの atom にまとめる時、機能が共通する知見の統合と、文脈の異なる失敗を同じ教訓名で潰すことは別である。source、条件、失敗主体を残したまま上位概念へリンクし、原文固有の差を消さない。The Unknown のように共通機能へ収束する統合は有効だが、shrew の寓意のように異なる歴史を一語へ押し込む統合は recall 時の誤用を招く。

■ メリット・デメリット
メリットは、pastiche を制作コストの高い装飾ではなく、人物演技、探索動機、combat、level progression を束ねる制約として使える点にある。人物が世界の奇妙さを真剣に受け入れるため、説明台詞で joke を解説せずに済む。The Unknown の段階導入は、基調を壊さず setpiece の自由度を上げる。三つの謎は高速 FPS に重い推理操作を入れず、次の場所へ進む理由と suspect を供給する。

デメリットは、参照密度が高いほど一貫性があるように錯覚しやすいことだ。Steamboat Willie、noir、Lynch、True Detective、Nazis、Tulsa を認識できることと、それらが同じ主題へ働くことは別である。特に実在の迫害史は、架空 species に移すことで安全になるとは限らず、生物学的差異を付けた瞬間に偏見を誤って合理化し得る。また世界設定を増やしすぎると、running and gunning を妨げないという当初の制約を破り、謎が playable な進行ではなく lore backlog になる。

■ 判定
部分採用。人物が奇妙な世界を真剣に扱うこと、二〜三本の謎で場所と勢力を結ぶこと、異質な setpiece を段階的な法則違反として導入することは採用する。一方、複数の現実史を一つの架空種族へ合成する方法は採用しない。現実史を使う場合は、対応関係、責任主体、species・魔法による意味変質を事前レビューし、主題を具体化できない引用は削る。
