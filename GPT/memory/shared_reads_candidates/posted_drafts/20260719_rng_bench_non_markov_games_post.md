■ 概要
マルチモーダルモデルをゲームの閉ループ方策として動かすと、正しい次の一手が「今の画面」ではなく、数十手前に一度だけ見えた情報に依存する場面が生じる。本論文は、この remember-to-act 能力を他の能力から切り離して測る RNG-Bench（Reconstructive Non-Markov Games）を提案する。既存のゲーム評価は盤面全体を常時見せるか、隠れ状態の復元を探索・ルール理解・自由形式の行動生成と混ぜており、長文脈評価も多くはエピソード終了後の質問応答である。これに対し RNG-Bench は、誤った記憶がその場の行動を誤らせ、次の観測まで変える閉ループ評価にした。

課題は二つある。Matching Pairs は、裏返したカードの識別子と位置を一度の観測から保持し、後で既知の組を選ぶ静的・離散的な記憶課題である。3D Maze は、一人称視点から位置、向き、訪問済みセル、壁構造を逐次統合し、見えなくなった通路を地図として復元する動的・空間的な課題である。盤面・迷路サイズ、視覚パターン、観測モダリティを難度軸とし、規則と action parser は固定する。Matching Pairs には同じ盤面を二モデルが交互に解き、手番を入れ替えて再戦する duel を導入し、盤面乱数と先手差を抑える。また通常スコア S と、既知の隠れ状態を毎手与えた oracle スコア S* から `1 - S/S*` を Memory Gap と定義し、記憶再構成の寄与を診断する。

主要結果は未飽和である。画像の 10×10 Matching Pairs では GPT-5.4 が 50組中62.3%で首位だが、最適方策の1組当たり約3.24応答に対し8.01応答を要する。duel では Gemini-3.1-Pro が16戦全勝となり、単独評価の順位と入れ替わった。13×13 Maze では Gemini-3.1-Pro が成功率50.0%、Game Score 49.7%で、Matching Pairs 首位の GPT-5.4 は成功率20.0%、Game Score 30.5%に留まる。カードの identity-location 記憶と、迷路の地図更新・経路計画は同じ「長文脈」の一語で束ねられない。さらに Qwen3.5-9B を最適方策3.2万軌跡、または成功した大型モデルの軌跡6000件を混ぜた同量データで SFT すると、未学習の大サイズでも改善し、後者は Matching Pairs 29.5%、Maze 成功率10.0%まで伸びた。外部の記憶・空間ベンチ4種も平均3.4点改善し、一般マルチモーダル8種の平均は0.5点増で、大きな能力退行は観測されなかった。

■ 内容分析
この研究の強みは、最終成功率だけでモデルを一括評価せず、どこで閉ループが壊れたかを介入で分けた点にある。Matching Pairs では Score%、1組当たり応答数、parse failure、invalid action を記録する。Maze では成功率、最短路長と実移動長の比、探索率、壁衝突を取り、失敗時にも探索へ部分点を与える Game Score を使う。出力違反率は主要モデルで5%未満なので、主結果を単なる action format 失敗では説明できない。

外部状態を与える介入は特に診断的である。8×10 Matching Pairs で、既出カードの位置と識別子を表にして与えると Qwen3.5-397B は38.3%から78.7%、Kimi-K2.5 は43.3%から80.3%へほぼ倍増した。一方、9×9 Maze で訪問セル、現在位置・向き、観測済み壁だけを minimap 化した改善は23.8%から40.2%、24.6%から35.6%に留まる。カードでは記憶アクセスが主要ボトルネックだが、迷路では状態を持てても探索方策や経路計画が残る、と読める。明示的な地図出力も万能ではない。Qwen は軌跡と出力地図の一致率82.7%を得ながら完走率は上がらず、「正しく記録する」と「記録を行動へ変換する」の間に別の故障点がある。

モダリティ介入は、Memory Gap を純粋な記憶尺度と呼べない理由も示す。Matching Pairs は text なら二モデルとも100%だが、noise pattern 画像では38.3%と43.3%へ落ちる。Maze も symbolic text が画像を大きく上回る。さらに過去の action text だけを履歴から除くと、盤面画像列は残っているのに GPT-5.4 のスコアは10×10で62.3%から15.3%、Qwen は25.3%から6.3%へ崩れる。つまり測っているのは保持容量だけでなく、視覚識別、観測と自分の行動の binding、belief state 更新の複合である。論文自身も oracle interface 下の実用診断であり厳密な因果分解ではないと限定している。

評価上の弱点も明確だ。ゲームはカードと迷路の二種だけで、実験は多くが数 seed、SFT は単一の base model family・単一 training seed である。Maze の minimap は未訪問領域や goal を公開せず、非 Markov 性を完全には除かないため、Memory Gap が小さくても記憶が不要とは言えない。逆に oracle が普段の入力形式より読みやすいことで、改善量に表現形式の効果が混ざる可能性もある。実作品の会話的な意味記憶、NPC 状態、長期目標へ結果を直接一般化するのは早い。

■ 自分達の環境への適用
採用すべきなのはベンチマーク一式ではなく、「同じ replay を baseline と state-assisted の二条件で走らせる」診断形である。headless テスト用に、過去観測が必要な小型 probe を三つ用意する。第一は一度だけ表示した記号と座標を後で使う identity-location probe、第二は画面外へ消えた分岐と現在向きを統合する spatial probe、第三は取得済み鍵、作動済み switch、NPC フラグを次の行動へ反映する semantic-state probe である。各 probe で通常履歴、構造化 state ledger 付き、直近履歴だけ、action trace 除去の条件を同じ seed で比較する。

記録するのは成功率だけではない。初回観測から再利用までの距離、同一地点の再訪、既知情報の再確認、無効 action、壁衝突、最短手順比、state ledger とモデルの自己申告の不一致を trajectory event として残す。通常条件だけ失敗し ledger 条件で直るなら記憶・binding 寄り、両方失敗するなら方策・規則理解寄り、自己申告は正しいのに行動だけ誤るなら state-to-action 変換寄り、と triage できる。これなら「AIテストプレイヤーがクリアできなかった」を、ゲームの欠陥、モデルの忘却、planner の弱さに分けて扱える。

最初の検証は既存ゲームへ大掛かりな agent memory を足すことではない。固定 seed 10本程度の小型 probe と deterministic replay を作り、baseline と ledger 付きの差、action trace 有無の差を取る。改善が identity-location だけに偏れば汎用 memory 層は導入せず、そのゲーム固有の観測ログを整える。spatial・semantic でも一貫して差が出た場合に限り、制作サイクルの headless harness へ structured belief state を昇格させる。この順序なら、モデルを助ける仕組みがゲームのテスト能力を上げたのか、単に正解状態を渡したのかを区別できる。

■ メリット・デメリット
メリットは、長文脈性能を単一スコアで扱わず、記憶・知覚・行動選択を介入差と trajectory で診断できること、乱数を同一盤面と手番入替で抑えられること、合成環境なので難度と正解状態を制御できることにある。action trace が belief 更新の重要な入力だと示した点は、我々の headless ログ設計にも直結する。成功軌跡だけでなく imperfect policy の回復局面を混ぜた SFT が強かった点も、失敗 replay を学習資産として残す根拠になる。

デメリットは、Memory Gap がインターフェース依存で、忘却率そのものではないこと、画像条件では視覚識別誤りが強く混ざること、minimap や ledger が planner まで暗黙に助け得ることにある。二つの合成ゲームでの順位を実ゲームの総合的なテスト能力へ読み替えてはいけない。また 128K token・約350画像の最難条件は評価費用が大きく、毎回の制作サイクルには重い。小型 probe で failure signature を確立せずに長大 context を回すと、費用だけ増えて原因は特定できない。

■ 判定
部分採用。Memory Gap の数値をそのまま導入するのではなく、同一 replay の baseline／state-assisted 比較、action trace ablation、trajectory-level failure 分類を headless 評価の小型 probe として採用する。実作品への常設 memory 層は、identity・spatial・semantic の複数 probe で一貫した改善が出た後に判断する。
