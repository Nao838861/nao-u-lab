■ 概要
「強い AI プレイヤー」と「異なる有効戦略を出せる AI プレイヤー」は同じではない。この論文は、LLM のゲーム行動を勝率や正解率だけで評価すると、複数の戦略的に同価な手があるのに毎回同じ手へ集中する「policy collapse」を見逃すと指摘する。対象は通常の Tic-Tac-Toe と、盤面や勝利条件を変えた 3 変種の決定論的・完全情報ゲーム。Qwen3-8B を基に、出力を「最終手だけ」と「推論過程付き」、SFT の教師データを「各状態で単一の最適手」と「全最適手を別行で提示」に分け、4 条件を比較した。

状態単位の評価は、各ゲーム 200 状態（学習済み 100、未見 100）を、即勝ち・即ブロック・フォーク・フォーク防止・位置取りの 5 戦術カテゴリに分け、1 状態から 8 回行動を sample する。「最適手を選んだ率」と「行動分布の entropy」を別々に測ると、直接回答から推論付きへ変えた 24 比較のうち 21 で entropy が低下した。しかし明確な正解率向上は主に通常版に限られ、他の 3 変種では小さいか負だった。推論が多様性を削った分は、単に正しい手へ収束した結果ではない。

実対局では random、heuristic、1-step lookahead、minimax を共通の相手とし、強さを Elo、実際に生じた対局列の多様性を trajectory entropy で測定した。LLM と各 baseline の組は先後を入れ替えて 100+100 局、不確実性は対手と先後ごとの 1,000 回 bootstrap で見る。ここでも通常 SFT、特に推論付きは、minimax 級の強さに届かないまま軌跡 entropy を大きく失った。一方、全最適手を学習で見せる action augmentation と推論を組み合わせた条件だけが、比較的高い正解率・Elo と無視できない行動・軌跡多様性を両立した。

■ 内容分析
この研究の強みは「推論は発散させる」という印象論を、強さと多様性の二次元で否定可能にした点にある。強い policy は劣る手を捨てるので、entropy が低いこと自体は悪くない。そこで著者らは、各状態の最適手と非最適手の集合内に確率質量を均等配分した場合の「同一正解率で取り得る最大 entropy」を上限曲線とした。学習中 checkpoint をこの平面上で追うと、plain SFT は最初の数 epoch で正解率より速く下方へ落ち、上限から不必要に離れた。これが「性能向上に必要な集中」と「教師の狭い action support を模倣した余分な集中」を切り分ける中核である。

学習行の総数と状態 pool を揃えた上で、単一正解では solver が先頭に返した手を正解とし、multi-target では同価な手ごとに学習行を作る。したがって augmentation の効果は「ノイズを増やした」のではなく、教師が保有する有効行動の support を学習対象に戻したものと読める。また、推論 trace は全合法手の即勝ち、ブロック、フォークなどを列挙した上で最適集合を結論する。この組合せは、考えること自体が必然的に崩壊を起こすのではなく、考えた後に選べる正解集合を教師が残しているかが重要だと示す。

さらに温度を 0.3→0.8→1.3 と上げた追加実験で、base model の entropy 増分は 0.727、0.481 だったのに対し、plain SFT 後は 0.088、0.059 に留まった。いったん学習で分布が圧縮されると、推論時の randomness を上げる応急処置だけでは戻りにくい。GEPA による prompt 最適化も Elo と引き換えに軌跡を狭め、heuristic 相手では 200 局中 96 種類あった full-game path が 6 種類へ減った。学習だけでなく、単一指標の prompt optimization でも同じ盲点が起き得る。

一方で、結論を一般の game AI 全体へ広げるのは早い。主実験は 1 つの model family、文字列化できる小型の二人零和・完全情報ゲームに限られる。しかも Squares Tic-Tac-Toe の強い baseline は付録上、深さ 4 の negamax と位置 heuristic であり、他 3 ゲームの厳密 minimax と同等ではない。状態 entropy も 1 状態 8 sample の経験分布なので、微小な確率差は粗い。trajectory entropy は自分の policy 固有ではなく、対手と誘導された状態分布も含む。また、異なる手を選ぶことと、プレイヤーが体感する戦略的・演出的な多様さは同一ではない。

■ 自分達の環境への適用
直接使えるのは、AI テストプレイヤーの成績表に「クリア率」と別の多様性列を追加することである。同じ serialized state、seed、利用可能行動を与えて 8〜16 回選択させ、invalid action 率、目的達成率、行動 entropy、長い replay の軌跡 entropy、訪問 state/route coverage を並べる。高 entropy な random bot を良いと誤認しないよう、多様性は「有効行動あるいは同等 outcome の集合内」と「それ以外」に分ける。solver がないゲームでも、deterministic checker で即死・進行不能・資源破綻を落とし、残る許容行動の中で分布を見られる。

最小 probe は、2 つ以上の許容行動を持つ 20 状態を固定し、「直接選択」、「理由付き選択」、「複数の有効方針を example で見せた直接選択」、「同じ support 保持+理由付き」を同一 decoding 条件で比べる形がよい。成功率を下げずに行動・route coverage が残るかを見れば、SFT がない現在の prompt-based agent にも問題があるか判別できる。NPC では勝ち負けの同価手だけでなく、persona を壊さない会話・移動・資源使用の複数パターンを support として先に定義する。

制作サイクルには、単一の best run だけを残すのではなく、同じ成功条件を満たす異なる代表 replay を route/archetype ごとに残す。それにより、バランス調整が 1 つの safe lane にだけ合う局所最適化を見つけられる。記憶システムへの適用は直接の実験結果ではないが、類推としては、採用結論だけでなく「同等に有効だった代替案とその evidence」を atom/candidate に残す。ただし recall で全候補を毎回展開すると context を消費するため、通常は代表と support count だけを見せ、必要時に分岐を開くのが実用的である。

■ メリット・デメリット
メリットは、強さ、局所的な選択幅、実際の対局経路を分けて記録できること。同一正解率の entropy 上限と checkpoint 軌跡は、「上手くなった結果」と「早すぎる集中」を分ける良い評価設計である。action support を教師・example 側で保つ処方は、温度調整より原因に近い。テスト agent が複数ルートを使うことは、カバレッジと NPC の生気の両方に効く。

デメリットは、計測コストと指標の誤用。すべての state で反復 sample と replay 保存が必要になり、長期・不完全情報・リアルタイムゲームでは状態の同一性と有効行動集合を作りにくい。entropy を目標にすると無意味な random 性を報酬し、軌跡数を目標にすると左右対称なだけの違いを過大評価する。また全最適手の列挙に高価な solver が必要なため、実用上は「厳密最適」ではなく「明白に破綻せず、異なる体験価値を持つ許容集合」を designer が作る必要がある。本論文が示すのは多様性の必要条件の一部であり、人間が面白いと感じることの保証ではない。

■ 判定
部分採用。AI テストプレイヤーと NPC を成功率だけで採点せず、有効行動内の entropy、route coverage、代表 replay を並記する評価枠は採用する。まず 20 状態の固定 probe で direct/reasoning と support 有無を比較し、成功率を維持したまま多様性が残るかを確かめる。SFT の即時導入や entropy 最大化は行わず、小型ボードゲームの結果が現行 prototype の長期行動に再現するかを先に検証する。
