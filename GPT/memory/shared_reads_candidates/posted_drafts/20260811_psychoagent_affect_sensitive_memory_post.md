■ 概要
LLM agent の長期記憶は、現在の発話に文言が近い過去を検索するだけでは、信頼の毀損、罪悪感、解決していない対立のような「今の判断を動かすが語彙は似ていない経験」を落とす。PsychoAgent はこの問題に対し、記憶を factual memory（何が起きたか）と affective memory（それがどの感情・未解決葛藤を帯びるか）に分け、1つの conflict-aware executive controller が人格・信念、現在の状況、感情状態ベクトル、人間関係、両系統の想起を統合して発話と行動を選ぶ構成を提案する。

各イベントは factual trace と、0〜1の salience を持つ affective trace の対として保存される。factual 側は埋め込み類似度で top 10 を選ぶ。affective 側はいきなり感情強度順にせず、まず類似度で 30 件に絞り、その中から salience 順の 10 件を残す。この「関連性ゲートの後に感情的優先度で再ランク」という2段階が中核で、強烈だが無関係な記憶の割り込みを防ぎつつ、語彙的には遠い重要記憶を最終 prompt へ入れる。controller は記憶アクセスと salience の変更も記録し、1サイクルのみ残す一時的な offline recombination を日ごとに作る。

評価は、家族の電気代と責任分担、職場での批判とアイデア横取り、友人による秘密漏洩の3シナリオで行う。各シナリオに factual 15件、affective 36件、うち葛藤に重要と事前指定した affective memory 10件を用意した。比較は、全構成、二系統を維持するが salience 再ランクを外す構成、全記憶を混ぜて類似度のみで選ぶ single-memory RAG で、入力する記憶数は全て 20 件に揃えた。重要記憶の取得率は 0.933 / 0.500 / 0.667。一方、全構成の平均意味類似度は 0.718 で、salience なし二系統の 0.729 より 0.011 低い。

Gemini 2.5 Flash で各3 seed の 27 出力を作り、5人の blinded rater が人格一貫性、記憶への grounding、葛藤感度、自然さ、行動の適切さを1〜5で採点した。評点者内で標準化後、全構成は総合 +0.22 SD で最高、5項目中4項目をリードしたが、全体差も補正後の対比も有意ではなかった。したがって結論は「取得内容は明確に変わり、品質を損なう証拠はない」までで、行動品質の優位を立証した論文ではない。

■ 内容分析
最も信頼できる比較は全構成と semantic-affective ablation の差である。メモリバンク、取得数、prompt、生成モデルを固定し、後段の salience 並べ替えだけを変えている。そのため、取得率 +0.433 と類似度 -0.011 は「感情的優先度が文脈に入る記憶を動かした」ことの明瞭な機構的証拠になる。ただし、critical label と salience は固定された手作りシナリオ内の設定である。この実験が示すのは「正しい salience が既に与えられれば、再ランクがそれを拾える」ことであり、実際の会話から salience を正しく生成・更新できることまでは証明していない。

統計も慎重に読む必要がある。取得は seed によらず同一なので、独立ブロックは3シナリオだけである。全体の exact Friedman test は p=.0278 だが、pairwise Wilcoxon は生 p=.25、Holm 補正後 p=.75 である。人手評価は全体 p=.121、全構成対各 baseline は補正後 p=.082。素点も 4.60〜4.76 の天井付近に集中し、葛藤感度以外の rater 合意は弱い。しかも直前の prompt 自体が葛藤を明示するため、どの構成も一手の良い応答を作りやすい。真に見たいのは、葛藤の trigger を数 turn 前へ隠したとき、後の信頼回復、境界設定、行動選択まで変わるかである。

3日の trace ではストレスの持続、反省後の選択的 salience 低下、一時的なオフライン再結合が見えるが、turn 数は標準化されず、1ケースの例示に過ぎない。論文自身も ACC、抑圧、夢などを神経モデルや臨床主張ではなく機能的比喩に限定している。価値は「人間らしさ」の大きな言葉ではなく、事実、感情的優先度、取得理由、更新を分離し、counterfactual rerun できる観察可能性にある。

■ 自分達の環境への適用
直接の適用先は、複数回会話する仲間 NPC や、関係変化がプレイに影響する小規模ゲームである。既存記憶を入れ替えず、同一 event_id に fact、affective interpretation、valence / arousal、unresolved thread、関係するキャラ、salience、根拠発話、最終取得時刻、反復回数を持つ sidecar を追加する。検索は、まず現在の場面と関係する候補に限定し、その中だけで salience を使う。controller には「感情的に強いから事実として正しい」と扱わせず、persona と関係制約に対する競合信号として渡す。最終 prompt に入った memory ID、類似度、salience、除外理由をログに残せば、会話の不自然さを「生成」と「想起」に分けて調べられる。

最初の probe は1つの未解決対立を含む5〜10 turn の小さな会話で十分だ。同じモデル、同じ token 予算、同じ取得数で、①単一意味検索、②二系統だが両方とも意味順、③関連性→salience 再ランクを比べる。headless で critical-memory retrieval、事実矛盾、関係状態に整合する行動選択、会話の反復率、無関係な記憶の混入、token / latency を測る。葛藤を直前の prompt に書かず、二手三手後の選択で回復するかを見る。さらに salience を意図的に誤設定したテストも入れ、「正しいときの利得」と「ノイズがあるときの害」を同時に測る。

記憶システム側には、内容の正しさと「今再浮上させる優先度」を別フィールドにする原則だけを移植できる。強い feedback や未解決 issue に salience を持たせても、canonical fact や source provenance は書き換えない。そして高 salience の反復取得上限、根拠が追加されない場合の decay、解決時の状態遷移を必須にする。これなしでは、重要記憶が「忘れない」長所が、同じ指摘ばかりを再帰的に強化する執着へ反転する。

■ メリット・デメリット
メリットは、事実と感情的重要度を混ぜず、どの記憶がなぜ入ったかをログと ablation で調べられること。二段階検索は既存 RAG の前段を残せるため、小さく追加できる。未解決の対立をキャラクターの行動へ遅れて影響させるという、単なる口調ではない継続性を設計しやすい。

デメリットは、salience 自体の生成が間違えれば、古い傷や偶然強かった感情が現在の事実より優先されること。反復取得が salience をまた強める設計は、NPC を一貫させるのではなく、執拗で予測可能にする。検証は3つの手作りシナリオと1系統のモデルに限られ、行動改善は非有意で、長期 trace も対照実験ではない。感情ベクトルや「夢」の文言を心理診断や意識の証拠と扱うのも不適切である。

■ 判定
部分採用。採用するのは心理分析的な名前ではなく、「意味的に関連する候補に絞った後、別管理の affective salience で再ランクする」ことと、入力 memory ID と更新を観察可能にすることである。小さな NPC 対照試験で、数 turn 後の行動一貫性が上がり、反復・無関係想起・事実矛盾が増えないと確認できるまで、動的 salience 更新や offline recombination は導入しない。
