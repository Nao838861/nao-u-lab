■ 概要
「Solvable Sokoban Without a Solver via Diffusion」は、見た目が局所的に自然な盤面を作るだけでは保証できない「実際に解ける」という大域制約を、solver、報酬、可解性ラベルなしでどこまで学習できるかを調べた研究である。Sokoban は箱を押す順序を誤ると取り返せず、可解性判定は PSPACE-complete、最短解も指数的に長くなり得る。壁一枚の位置で盤面全体が壊れるため、単純な配置規則の寄せ集めでは扱いにくい。

着想は、10×10 盤面を固定順に左上から生成するのでなく、任意の場所が隠れた盤面から tile を補完する masked discrete diffusion として学ぶことにある。Boxoban の45万盤面を、壁・床・player・box・goal など7 tile、計100 token にし、ランダムな部分集合を [MASK] に置換する。約490万 parameter の双方向 Transformer encoder は、見えている任意位置の tile と timestep から masked cell の元 tile を cross-entropy で予測する。生成時は全 cell が mask の状態から始め、100 step で毎回一つの位置を一様ランダムに選び、その時点で全既配置 cell に条件付けた tile を確定する。一度置いた tile は後から変更しない。

5万盤面を生成した評価では、無選別で77.4%が solver により可解だった。不可解だった11,288盤面の94.5%は interior wall を一枚削除するだけで可解となり、これを含めた有効率は98.7%。二枚削除まで数えると本当に壊れた盤面は全体の約0.40%まで減った。修復対象の壁は確定時確率の中央値が0.45で、同じ失敗盤面の他の内壁は0.93だった。生成器自身の低い確信度が、壊れた箇所の候補になっている。

局所3×3 tile pattern の Jensen-Shannon divergence は、生成盤面と未学習のheld-out 5万盤面でほぼ同じ減衰を示し、その差は各 sample size で divergence 自体の4%未満だった。学習盤面への最近傍 Hamming 距離も生成・held-out とも中央値12で、完全一致は生成側5件、held-out側19件。単なる暗記や簡単な形への退避ではなく、Boxoban 分布を近似した結果として可解性を受け継いだ、と著者は結論づける。

■ 内容分析
重要なのは「diffusion なら大域制約を理解する」という一般論ではなく、条件付け集合と生成順の対応である。自己回帰モデルは固定した prefix にしか条件付けない。一方、この学習では mask の数も位置も毎回変わるため、どの形の既配置集合からでも残りを推定する。生成時も goal、反対側の壁、両者を結ぶ通路の順に決まる可能性があり、離れた要素が相互制約する盤面に固定走査順を押し付けない。この構造的整合が中心仮説である。

ただし生成は「後から全体を修正する反復」ではない。各 step で全 masked cell の分布を再計算するが、ランダムに選ばれた一 cell だけを確定し、過去の確定は不可逆である。そのため、序盤の低確信な壁一枚が不可解性を作る。ここが一壁修復結果と整合する。また、確信度の高い位置から確定する方式は、容易な多数 class である壁を先に増やし、平均壁数を69.5から81.5へ押し上げた。一見合理的な confidence ordering が分布を崩し、一様ランダムな reveal 順の方がよかった点は、実装上かなり重要である。

学習 loss と目的指標の乖離も明瞭である。validation loss は早期に収束して横ばいになる一方、checkpoint ごとに5,000生成を solver 評価した可解率は1,000 epoch の終盤まで上昇した。loss plateau で早期停止すると約25 percentage point の可解率を失う。cell 単位の再構成精度は、大域的な可解性の proxy ではない。生成器に大域制約を直接教えないことと、大域指標でcheckpointを選ばないことは別であり、後者には結局 solver が使われている。

評価の強い点は、可解率だけでなく、局所分布一致、held-out を基準にした暗記検査、修復距離、sampling temperature の交換条件まで測ったことだ。温度を1.0から0.6へ下げると可解率は3.8 point 上がるが、平均壁数は69.5から73.2へ増え、corpus平均68.6から外れ、solverの探索量中央値も36%減る。つまり「よく解ける」は「元分布らしい」「難しい」と同義ではなく、低温化は保守的で壁が多く、解きやすい側へ寄せる。

限界もはっきりしている。単一著者・単一dataset・10×10固定盤面で、自己回帰 baseline との同条件比較は示されていない。難易度は push solver の展開状態数で、人間の面白さや解法の発見感を直接測っていない。3×3 pattern の一致は局所的な作風を示すが、解法構造の多様性や novelty を保証しない。77.4%という生の可解率は制作投入には不足し、一壁削除は通路を広げて難易度や意図を変えるため、98.7%を無条件の成功率とは読めない。

■ 自分達の環境への適用
そのまま大型 model を導入するより、「順序非依存の候補生成」「外部検証」「最小編集 repair」を分離した設計として使う。パズル、通路、敵・資源配置のように離れた要素が制約し合う prototype では、固定走査順の生成だけでなく、ランダムな cell / region mask を補完する小型 model や反復生成器を比較対象にする。既存盤面の一部を固定した inpainting にも向き、designer が残したい構造を条件として周辺だけ補完できる。

headless 評価では、生成器の loss や局所妥当性で完了判定せず、可達性、クリア可否、soft-lock、必要操作数など event-derived な大域指標を別に測る。checkpoint または生成規則を選ぶ時は、生成品質と大域成功率の両曲線を保存する。loss が改善しなくても playability が上がる可能性、逆に局所一致が上がっても遊べなくなる可能性を検出するためである。

最初の probe は学習を伴わなくてもよい。同じ盤面 generator に対し、固定順配置とランダム region completion を各500件生成し、①無修正成功率、②最小修復 edit 数、③修復後の難易度変化、④tile / event pattern の分布、⑤近傍重複率を比較する。失敗時は壁・障害物・spawn の候補を一つずつ除去または移動し、最初に成功した edit と生成時 confidence を記録する。低確信要素が修復箇所に集中するなら、全探索の前に repair candidate を順位付けできる。

ただし修復を自動採用する gate は厳しくする。可解化しただけで採用せず、難易度帯、主要ルート、designer固定要素、見た目の密度が許容範囲に残るか再評価する。生成器は候補を出し、deterministic verifier が落とし、repair loop が最小差分を提案し、最後に視覚・体験評価を通す四段階にする。論文の価値は solver を不要にしたことではなく、solver を生成 loop から外して多様な候補を安価に出し、検証を後段へ集中できる点にある。

■ メリット・デメリット
メリットは、可解性ラベル作成や強化学習なしで、大域制約をかなりの割合でデータ分布から継承できること、既配置の任意部分を条件にできること、失敗が少数 edit に集中して repair loop と相性がよいことだ。confidence を検証優先度へ転用でき、生成と保証を別 component に分けられる。局所分布・暗記・温度まで調べた評価設計も、PCG検証の雛形として使える。

デメリットは、生成功率だけでは製品品質にならず、保証には外部 solver が残ること、100 cell に100回の全体推論を行うため固定順生成より重いこと、不可逆な早期確定が失敗源になることだ。学習分布の品質と偏りもそのまま受け継ぐ。修復で可解になっても簡単化や作風崩れが起こり得る。単一設定の結果から、任意のゲーム規則や可変サイズへ一般化できるとは言えない。

■ 判定
部分採用。masked diffusion 自体を直ちに制作基盤へ入れるのではなく、任意部分への条件付け、生成指標と大域指標の分離、低確信箇所を使う最小修復、held-out と同じ尺度での分布・重複検査を PCG probe に導入する。無修正成功率だけでなく、修復後の難易度と意図保持まで比較し、固定順生成より明確に良い領域だけに広げる。
