■ 概要
この論文は、LLMが多言語で同じ知識問題に答えられるかではなく、「同じゲーム状態から同じ技能を行動として出せるか」を測る。静的ベンチマークでは、翻訳文への正答率が違っても、入力理解・推論・方策選択のどこで差が生じたか分かりにくい。そこで著者らは、同一モデルの二つのインスタンスを対戦させ、モデル、相手、ルール、状態空間、合法手、報酬、遷移を固定し、各プレイヤーに提示する言語だけを変える multilingual self-play を構築した。

基盤はTextArenaの多言語拡張で、公開資源全体として65ゲーム・193言語を用意し、本実験では母語話者が確認した8言語（英語、中国語、スペイン語、フランス語、ドイツ語、マレー語、アラビア語、ヘブライ語）と6ゲームに絞った。ゲームは、TicTacToeの空間認識、Nimの既知最適戦略、SimpleTakの経路形成、Colonel Blottoの資源配分、Kuhn Pokerの不完全情報下のリスク選択、反復囚人のジレンマの協調と適応を分担して測る。対象はGemma-4-E4B-it、Qwen3-4B、Ministral3-3B-Instruct-2512の同規模open-weightモデル3種。各モデル・各ゲームで全言語対を両方の手番配置で400試合ずつ回し、合計518,400試合を評価した。生成条件はtemperature 1.0、top_p 0.95、top_k 64で、最終行動を定型記法から抽出する。invalid action は訂正機会後も直らなければ即敗北となる。

主指標は、言語AとBの両手番をまとめた勝数−敗数を総試合数で割る role-pooled win–loss margin で、先手有利を相殺する。さらに各言語が他の7言語へ示す平均marginと、ゲーム横断平均を計算した。同一モデルでも英語は3モデルで概して強く、ヘブライ語は弱く、Qwenで言語階層が最も大きかった。ゲーム別の最大−最小言語差は、3モデル平均でColonel Blotto 1.07、Nim 0.45、TicTacToe 0.38、SimpleTak 0.38、反復囚人のジレンマ0.34、Kuhn Poker 0.13だった。

差は勝率だけでなく失敗の形にも現れた。空間ゲームでは英語の敗北方向が比較的均等なのに対し、アラビア語・ヘブライ語では列や斜線の取り違えに偏った。Kuhn PokerのQwenでは最弱カードJでのbluff率が英語23.3%、中国語45.0%、アラビア語47.4%と倍以上変化し、Ministralではinvalid actionが英語9.3%からヘブライ語20.9%まで開いた。NimではQwenが最適初手を実行した割合が英語80.8%に対しフランス語24.6%、ヘブライ語4.0%だった。戦略への言及数と実行成功も一致せず、「知っている」と「行動できる」を分ける必要が示された。

さらにインターフェース言語を固定し、途中推論の言語だけを変えた。GemmaのTicTacToeではドイツ語提示・ドイツ語推論のmargin −0.22が、英語推論で+0.20となり、英語提示の上限との差の89.4%を回復した。SimpleTakでも−0.21から+0.05へ60.5%回復したが、Kuhn Pokerは最大49.3%で非単調だった。結論は、言語が状態解釈、知識検索、途中推論、行動選択の複数段階へ別々に影響し、平均ベンチマークが高いモデルでも言語間の方策一貫性は保証されない、というものだ。

■ 内容分析
実験設計の強さは、同一モデル同士の対戦で能力差を相対化し、両手番を入れ替えて構造的有利を消した点にある。抽象盤面や数値、固定アクション記法は共通なので、文化知識の差だけでは説明しにくい。しかも、勝敗→invalid action→盤面上の敗北方向→カード別方策→最適戦略の言及と実行、という順に観測を分解している。これにより「日本語版は少し弱い」で終わらず、状態を誤読したのか、知識を呼び出せないのか、知識は言えたが操作へ変換できないのかを切り分けられる。

途中推論言語の介入も重要である。提示文を翻訳し直さず性能が戻るなら、少なくとも一部は入力翻訳品質ではなく内部処理経路の問題である。ただし英語推論を万能策と読むべきではない。Kuhn Pokerで回復が限定的かつ非単調だったこと、英語が全指標で常に最良ではなかったことは、方策の差が推論だけでなく状態解釈や最終行動にも埋まることを示す。英語へ迂回すると性能が上がっても、ローカルな表現、対話の自然さ、相手メッセージの理解を犠牲にする可能性がある。

外的説明も限定的だ。言語別marginはGlobal MMLUとモデルごとにr=0.73〜0.92、Belebeleとr=0.71〜0.79、公開webテキスト量の代理指標と平均r=0.79で相関したが、8言語しかなく、学習データ自体は非公開である。マレー語はデータ量予測より強く、中国語は英語より約20倍少ない代理データ量でもQwenとMinistralで英語近傍だった。著者自身も3B〜4Bモデルに限られ、大規模モデルへスケール不変と一般化できないとする。またself-playのmarginは絶対的なゲーム能力ではなく、その評価集合内の相対値であり、同じ偏りを共有する二者が引き分けても正しい方策とは限らない。

■ 自分達の環境への適用
LLMをNPC、対戦相手、チュートリアル役、自動テスターに使う場合、ローカライズQAを文章一致だけで終えない。英語版と日本語版で同じseed、同じ状態列、同じ合法手、同じ相手を与え、勝敗、draw、invalid action、訂正成功、行動分布、重要局面の方策一致を別々に記録する。対戦ゲームでなくても、探索なら到達状態、会話NPCなら選択肢遷移、QAボットなら実行tool列を「行動」として比較できる。

最小probeは三段階にする。第一段は同言語self-playで役割固有の基準値を取る。第二段は英語対日本語を両役割で回し、差が大きい局面を抽出する。第三段は日本語提示を固定して、途中推論だけ日本語／英語に切り替える。英語推論で戻ればreasoning-path候補、戻らず用語置換で戻ればstate interpretation候補、説明には正解戦略が出るのに行動が違えばaction selection候補として保存する。単一の総合scoreではなく、原因仮説と再現seedを一緒に残す。

headless評価には、勝率より先にinvalid actionと重要局面の方策差を置く。勝率は相手分布で動くが、合法手違反、盤面の行列取り違え、最強カードのfold、唯一の最適初手の失敗は局所的で再現しやすい。制作サイクルでは、モデル更新、system prompt変更、翻訳更新のたびに言語別matrixを回し、平均性能と最大言語gapを別の回帰ゲートにする。記憶には「日本語で弱い」と丸めず、model version、sampling、interface language、reasoning language、role、seed、failure stageを保持する。これで後からモデル差・翻訳差・推論経路差を再評価できる。

■ メリット・デメリット
メリットは、既存のheadlessゲーム環境をそのまま多言語の行動一貫性テストへ転用でき、勝敗だけでは見えない方策・違反・知識実行の差まで測れることだ。両手番、同seed、局所指標を組み合わせれば、翻訳レビューより強いローカライズ回帰試験になる。

デメリットは、全言語対のself-playが二乗で増え、論文規模では50万試合を超えること、samplingを使うため分散管理が必要なことだ。小型open-weightモデルと短いtext gameの結果を、画像入力、長期記憶、tool useを含む製品へそのまま移せない。英語推論への迂回を既定化すると、症状を隠し、遅延・費用・説明言語の不一致を増やす危険もある。

■ 判定
採用。言語別の平均品質ではなく、同一状態からの行動一貫性を測る評価設計をheadless基盤へ入れる。まず英語／日本語の両役割、invalid action、重要局面方策、推論言語介入の小規模matrixから始め、差が再現する場合だけ言語数と試合数を増やす。
