# カンジ工房 v001

対象は小学4年生。ひらがなの部品名で漢字の構成を答えてから、形を選ぶかペンで書いて確かめるWebアプリ。

## 試す

[カンジ工房を開く](https://kanji-kobo-nao-20261105.nao-u.chatgpt.site)。既存のSites所有者限定URLを継続使用する。

ローカルでは `run_kanji_kobo.cmd` を実行し、表示された `http://127.0.0.1:8765` を開く。Pythonが必要。追加のインストールやビルドは不要。HTMLの直接ダブルクリックではなく、HTTP経由で開く。

## 今回の学習フロー

1. 語例・読み・例文を見て、ひらがなの部品名を6候補から選び、左右・上下へ配置する。この段階では完成漢字や部品の形を見せない。
2. 正しい構成が言葉で並ぶ。その下で、保存されたモードのまま形を出す。
3. 形を確かめ、次のお題へ。一回3文字。図鑑から一文字だけでも遊べる。

- **形から選ぶ**：12個の部品から選んで配置する。正解2個と誤答候補10個。名前ラベルや正解色は付けない。
- **ペンで書く**：白い欄へ入力。ペンタブ・指・マウスを想定したPointer Events。筆跡の取り消し・全消去、形の近似チェックを実装。
- モードは毎問選択するものではなく、前回の設定を引き継ぐ。学習画面上部の切替をいつでも使える。切替でも選択中の部品・筆跡を保持する。
- ヒントは部品ごとの「名前と読み上げ→形→書き順」。分からない部品だけを練習し、元のお題へ戻れる。
- 部品の専用モードは「形→名前」と「名前→形」。18部品を収録し、形側では同じペン／形選択の設定を使う。
- 書いた形が判定されない場合も、見本確認で進める。見本を閉じて再挑戦することもできる。
- 紙のテストなしで通常サイクルを完了できる。マイク入力・登録・広告はない。

収録漢字は小学4年生の12字：材・松・梅・折・清・信・働・泣・浴・仲・灯・念。

## 記録と判定の意味

名前で構成できた、12候補の形から組めた、ペンの形チェックが通った、見本確認を区別する。ヒントの段階、誤答、日付、形の候補を見た後のペン入力も保存する。旧版の記録を保持し、新モードの成功へ移さない。保存キーは旧版 `kanji-kobo-v001`、新版 `kanji-kobo-name-first-v2`。旧版キーは上書きしない。

ペンの確認は、KanjiVGの筆画と入力の形を比較する端末内の近似判定。筆順、とめ・はね・はらい、書字の習得を厳密に採点する機能ではない。正しい手書きを拒否したり、似た形を通したりする可能性がある。構成文付きなので、自由想起の書き取り成功とも区別する。

ミチムラ式・さかもと式を参考にした独自の試作で、公式教材ではない。学習効果・楽しさ・継続性は未検証。名前・配置・形の対応を操作として扱い、つまずいた部品を短く学び直せるところまでを今回実装した。

結果・設定は同じブラウザーのlocalStorageへ保存する。筆跡は一問の間だけ保持し、外部へ送信しない。記録のJSON書き出し・読み込みで別端末へ移せる。公開URLとローカルURLの記録は別。端末の保存制限・データ削除では記録が残らない場合がある。

## 開発と検証

```powershell
npm.cmd test
node --check dist/app.mjs
```

テスト用依存がない時だけ `npm.cmd ci` を実行する。linkedomは開発用で、アプリ本体は外部ライブラリーを要求しない。端末の日本語フォントで表示する。

32件の自動テストを通過。全12字の名前→形の実イベント、3文字サイクル、上下構成、12候補、モード保存、筆跡保持、キャンセル、段階ヒント、部品練習からの復帰、旧データ、保存禁止を確認した。形比較では、拡縮・軽い座標のずれ・筆順変更を許し、収録12字の相互取り違え、白紙・点・線・鏡像・片側のみ・網目を拒否することを確認した。これは実際の子供の手書きによる精度評価ではない。

ローカルHTTPでHTML・CSS・JavaScript・アイコンの200応答を確認。ブラウザー接続ホストが利用できず、Windows Computer Useも現在URLを安全に特定できないと判断して停止した。以後の画面操作は行わない。実画面レイアウト、iPad、ペンタブ、音声は未確認。

筆画の再取得は `python -X utf8 prepare_glyphs.py`。通常起動には不要。字形データはKanjiVG由来のCC BY-SA 3.0。[出典](dist/ATTRIBUTION.txt)を参照。
