# カンジ工房 v001

対象は小学4年生。紙・鉛筆の準備なしで、漢字の部品を組み、覚え、見本なしで組み直す学習アプリ。

## 試す

[カンジ工房を開く](https://kanji-kobo-nao-20261105.nao-u.chatgpt.site)。Sitesの所有者限定で配置済み。

ローカルでは `run_kanji_kobo.cmd` を実行し、表示された `http://127.0.0.1:8765` を開く。Python が必要。

HTMLを直接ダブルクリックするのではなく、上記のHTTPサーバー経由で開く。追加の依存パッケージやビルドは不要。

## 初版の範囲

- 小学4年生の12字：材・松・梅・折・清・信・働・泣・浴・仲・灯・念。
- 1回3文字。図鑑から1文字だけ選んで遊ぶこともできる。
- 見本ありの組み立て→任意の30秒暗記→見本なしの部品・構造再構築→結果→図鑑。
- タップ・クリック・キーボード操作に対応。部品はドラッグでマスに置くこともできる。
- 左右／上下の選択、6部品の候補、段階的ヒント、見本を確認して進む経路。
- 成功時の小さな演出と、任意の効果音・読み上げ。マイク入力は要求しない。
- 端末内の進捗保存、要復習の選択、記録のJSON書き出し・読み込み。
- 通常サイクルは完全にアプリ内で完結。紙のテストをしなくても全機能を利用可能。

ミチムラ式・さかもと式を参考にした独自の試作で、公式教材ではない。さかもと式の書き取りテストを部品再構築に変えているため、原法の効果がそのまま得られるとは扱わない。

## 記録の意味

練習中の成功は図鑑の自力記録に入れない。チャレンジの初回正答かつヒントなしを「見本なしで組めた」とし、ヒントや誤答後は「ヒントと組めた」、完成見本を確認した場合は「見本でたしかめた」として保存する。いずれも漢字との出会いとして図鑑には残し、没収しない。

異なるローカル日付で自力成功した記録を区別する。同日の回数を増やしても「別の日にも組めた」にはならない。復習間隔は試作の仮設定であり、最適と検証された値ではない。

部品候補のある再構築課題で、自由な手書きの能力は測っていない。学習効果・楽しさ・継続性は本人の利用を通じた検証が必要。

## 開発と確認

```powershell
node --test test_engine.mjs
node --check dist/app.mjs
python -X utf8 prepare_glyphs.py
```

字形の再取得は最後のコマンドで行う。普段の起動には不要。筆画はKanjiVGから抽出し、学習に使う二部品に分けている。詳細は [出典](dist/ATTRIBUTION.txt)。字形の派生データは CC BY-SA 3.0。

DOMでの学習フローの結合テストも実行する場合は、開発用依存を `npm.cmd ci` で入れ、`npm.cmd test` を実行する。linkedomはテスト専用で、アプリの配信・起動には不要。

UI・教材・ロボットのイラストはこの試作のために作成。Webフォント以外の実行時外部依存はない。フォントを取得できなくても端末の日本語フォントで遊べる。学習記録の外部送信・ユーザー登録・広告は実装していない。

保存は同じブラウザー・同じオリジンの localStorage に限定。プライベートモード、保存制限、ブラウザーデータ消去では記録が残らない場合がある。公開URLとローカルURLの記録は別なので、移す場合は書き出し・読み込みを使う。

## 検証の制約

ブラウザー接続ホストが利用できず、Windowsの画面確認ツールも現在URLを安全に特定できないため停止した。別経路でのブラウザー操作は行わない。実画面のレイアウト・ドラッグ・音声・モバイルでの操作は未検証である。自動テストとHTTPでの配信確認は実行して記録する。

設計判断とユーザー指示原文は [設計ログ](design_log.md) に保存。
