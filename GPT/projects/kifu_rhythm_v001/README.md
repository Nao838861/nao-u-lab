# 棋譜ビート v001

対象: 囲碁の知識なしで、知っている曲に合わせて石を置きたい人。

プレイURL: https://kifu-beat-v001.nao-u.chatgpt.site （Sites、所有者限定配信）

「歓喜の歌」の軽快な合成アレンジに合わせて、自作の練習棋譜48手を並べる60秒のブラウザゲーム。黒白は自動。9路盤に2回の捕獲がある。正式な囲碁対局の勝敗判定は行わない。

## 遊び方

1. `site/dist/index.html`をブラウザで開く。または下記のローカルサーバーを使う。
2. 「交点をタップ」または「どこでも / Space」を選ぶ。
3. 「音を出して、はじめる」を押す。4拍の導入後、赤い輪が中心の輪に重なる時に入力する。
4. 交点モードは予告の交点をタップ。1キーモードは盤のどこでもタップ、またはSpace。押し続けでは連打にならない。
5. ミスした手は補助で進む。全ミスでも曲と棋譜は完走する。結果は成功・補助・コンボを分けて表示。

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory projects/kifu_rhythm_v001/site/dist
```

http://127.0.0.1:8765/ を開く。ブラウザを別タブへ切り替えると演奏は停止する。音量は随時変更可能。判定オフセットは開始前に設定し、音に合わせた入力が遅い判定になる場合はプラスへ調整する。

## 構成と検証

- `site/dist/core.js`: 合法手・捕獲・コウ・棋譜・入力判定・旋律。
- `site/dist/game.js`: Web Audio合成、盤面描画、操作、進行。
- `test_core.cjs`: 全成功、全ミス、部分ミス、捕獲、無効入力など9テスト。
- `design_cycles.md`: 設計反復3回。
- `references.md`: 先行事例30件。
- `self_judgment.md`: 自己評価と検証できた範囲。

Node.jsがある環境で `node projects/kifu_rhythm_v001/test_core.cjs` を実行する。ビルド・外部パッケージ・外部音源は不要。

音楽: Ludwig van Beethoven『歓喜の歌』主題を音符データから独自に合成した簡易アレンジ。着手音、伴奏、旋律ともWeb Audioで生成。既存録音や歌詞は使用しない。
