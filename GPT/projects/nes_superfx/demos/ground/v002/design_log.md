# MMC5Racingコースへの差し替え

2026年10月16日。既存の地面比較ROMに対するコースデータの改修。対象は2方式を同じコースで比較する開発者。描画と入力の根源仕様、およびv001の3回の設計評価を引き継ぐ。

## 依頼原文

> コース形状をMMC5Racingにあわせて

前版は小さな楕円で描画経路を確認した。今回は既存コースの長い斜め直線、左側の折り返し、中央の逆向きカーブ、右下の大きなカーブを比較に含める。「似たコース」へ描き直すのではなく、既存CPU車の32点の中央ルートと道路幅を入力にし、確認用マップとの形状差を測る。

## 実装前の判断

| 評価 | 反映方針 |
|---|---|
| 既存の32点ルートを参照できる | 原座標をsnapshotに保存し、出典のhashを記録 |
| 全32断面の4輪郭は現RAMに収まらない | 直線の中間点から除き、19断面へ簡略化 |
| カーブを一律に間引くと別の形になる | 元の点から線分への最大距離が小さい順に除く |
| 道路幅の変化は別コースに見える | 路肩込み80px、アスファルト64pxを一様縮尺し、路肩は白で表示 |
| 元の道路マスクは周回判定にも使われる | 表示用確認マップの色から道路領域も取得し、面積一致を測る |
| 楕円の自動周回では道路から外れる | 元の32点の経路を64地点へ距離で再標本化 |
| 区間ごとの向きの急変は比較を妨げる | 元の接線を補間し、カメラと自車へ共有 |
| 固定の頂点64・地面48面という仮定がある | 断面数から自車頂点と地面面数を指定する |
| 2方式で形を別々に編集すると差が出る | 同じ4輪郭からポリゴンと画像を生成 |
| 旧版の数値と出力を上書きしたくない | v002として保存し、通常ランチャーを最新版へ向ける |

R-Aの既存の曲がり方を読めること、R-Eのデータを正本から直すこと、R-Fの同じ条件で測ることを使う。操作・勝敗・物理を追加する改修ではない。消える比較操作はない。

## 確認する条件

全64地点が元の中央ルート上にあり、生成した路面内に収まること。19点への簡略化誤差、確認用道路画像との一致率、2方式・4視点・全64地点の画素、実ROMの切り替え・停止・位置送りを確認する。性能値は新しい形状で測り直す。

初期の17断面は元ルートに対する最大誤差8.03pxだった。比較用の固定車1台を外し、19断面＋自車へRAMを配分すると、最大誤差1.325pxまで下がるためこちらを採用する。自車、4視点、切り替え操作は維持する。

## 実装と確認

- 元の確認マップでは左直線の灰色部分が64px、茶色と白線を含む全幅が80pxだった。道路領域の比較には路肩まで含め、4色版では路肩を白にまとめた。周回判定用マスクをそのまま表示境界と見なさず、検証済みマップ画像で照合した。
- 19断面の共通輪郭、57地面四角形、自車8頂点を生成。GSUへ自車の先頭頂点と地面面数を渡すようにした。元の中央ルートを64地点へ距離で再標本化し、視点ごとに同じ自車姿勢を共有する。
- 元画像の道路領域とのIoU95.82%、元の32点からの最大誤差1.325px、全64地点の路面内収容を確認。原座標へ戻した周回姿勢の誤差は最大0.023px。
- 25／50MHz × 4視点 × 2方式 × 64地点の1,024画像が画素一致。実ROM128画像のPPU RGB、長押し、視点一周、停止中の方式変更、左右送りが通過した。v001を再生成したROMのhashも既存配布版と一致。
- 判定：コースの差し替えとして提出可能。曲線近似と画像64×64の差を残し、レース本体や30fps達成の認定へは広げない。
