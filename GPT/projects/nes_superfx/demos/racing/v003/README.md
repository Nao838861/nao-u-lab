# 道路・車の配色と空パレットの分離

`run_racing_3d.cmd` の標準をv003に更新。直線の白線をなくし、カーブの縁を赤白、車体を赤、車体後部を赤とグレーの市松模様にした。音ありv002の物理・音を維持する。

道路メッシュの直線5区間は両端の帯を緑にする。カーブの帯はポリゴン表示では画面座標の4画素周期、テクスチャ表示では道路方向の原座標8px周期で赤白を繰り返す。赤白模様の位相は両方式で一致する仕様ではない。道路メッシュ・走行判定・車体寸法は変更しない。車体後部にはGSUの標準ディザ機能を使い、1画素ずつ赤とグレーを交互に描く。

## 空の専用パレット

道路・車のBGパレット0は赤・緑・グレー・白。空のBGパレット1は共通背景色の赤に加えて、緑・白・青を持つ。パレットRAM `$3F05/$3F06/$3F07` が `$1A/$30/$21`。現在の空領域は青で塗る。下段HUD背景はグレー。

専用マッパーに次の開発用レジスターを追加した。この表示には更新した専用コアが必要。

- `$4FF4` 書込み：次の表示画像の空の高さ。8画素単位、上限192。読取り：現在表示中の高さ。
- `$4FF5` 読取り：対応コアは1を返す。
- `$4FE2` のVBlank画像交換時に、空の高さも同時に確定する。

ネームテーブル読取りで保持した8×8タイル座標から、attribute読取り時にパレット0/1を選ぶ。通常の固定attribute表とは異なる専用マッパー側の選択である。空と地面の境界を8画素に揃え、4視点の空の高さを88/72/56/0にした。端数の空行は遠景の緑になる。道路や車が空パレットへ入らないようにしている。状態保存には表示中／予約中の高さと有効フラグを含む。

## 確認

4視点×地面2方式で撮影し、空の全画素が青、専用パレットの緑・白・青が設定済み、表示中の視点と空の高さが一致することを検査。表示faultは0、物理と音の更新数は一致。視点・地面・モード切替、START、範囲外からの復帰も通過。画像と記録は `results/`。

```powershell
python tools/build_racing_colors.py --cc65-bin <cc65のbinフォルダー>
python tools/build.py
python tools/setup_runtime.py --mesen-dir <Mesen2.1.1のフォルダー> --rom <診断ROM>
python tools/verify_racing_colors.py
python tools/verify_racing_controls.py --version 003
```

GSUのアセンブルには固定版casfxの `casfx.inc` が必要（既存 `build_cube.py` と同じ版・ハッシュ）。v001/v002 ROMは保持し、`tools/launch_racing.py --version 002` で音移植時の表示に戻せる。
