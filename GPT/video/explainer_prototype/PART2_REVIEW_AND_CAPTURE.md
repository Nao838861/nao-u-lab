## 全体レビュー

前半は「約8msしかない」という課題を入口に、背景の投影、描画順、敵の移動、衝突判定を順に解く。最後のC09で、それらが2フレームのどこに入るかを示す。長くなったC08・C08b・C09は重複した説明を削り、技術の中核と前半まとめを残した。

後半は実行中の処理から開発の手順へ切り替える。C言語とアセンブリの関係、数値の範囲、背景Xの例外、Houdiniによる軌跡作成、AI抽出の失敗を説明する。その後、人が目印を付けてAIが補間する改善策、開発中に変わったAIへの任せ方へ進み、実行時の計算を事前準備へ移す工夫をまとめて締める。

## 再生成

```powershell
python tools/prepare-part2.py
node tools/generate-narration.mjs --manifest=part2-cuts.json
node tools/transcribe-part2.mjs
python tools/align-part2.py
node tools/render-part2-review.mjs --output=part2_with_ai_and_summary_720p60.mp4
```

原稿変更カットは音声生成に `--cut=P2Cxx --force` が必要。文字起こしは原稿との対応を確認する補助で、誤認識も含む。発音・抑揚の最終評価はレビュー動画の試聴で行う。表記揺れと読み落とし候補は `out/part2_audio_review.md` に記録する。

最新の出力先は `out/part2/part2_with_ai_and_summary_720p60.mp4`。AI活用と結末まで収録したレビュー版。C12とC15は模式図の仮映像。C16も実際の操作録画ではなく、制作記録に基づいた手順の模式再現として明示する。以前の `part2_review_720p60.mp4` は初回版として残す。

## 初回制作の検証記録

- 16カット、29,686フレーム、約8分14.77秒。1280×720、60fps。
- 全音声の実測尺が各カット内に収まること、カット間の欠落・重複がないこと、文境界が単調増加することを `tools/verify-part2.py` で確認。
- 全カットの25%・70%地点の計32枚で画面を確認。白い木同士の重なりは説明用の色を分け、表と並べた図の消失点の位置を補正した。
- 背景の倍率・サイズ番号・地面高さは実装から抽出。敵のZは4倍精度なので、図中は前のバケツ図と同じ56段階の単位へ換算した。
- 文字起こしと全文を照合。65535の読み違い候補は発音用本文を「六万五千五百三十五」へ補正し、再生成後の文字起こしで数値を確認した。bit／ビット、漢字／数字などの表記揺れは類似度に影響する。
- 動きと文境界を同期した切り替えを組み合わせた初回実装。図の細かな間や音声の抑揚は、レビュー動画の試聴でさらに詰める。
- 動画・WAV・大量の確認用画像はローカル出力とし、Gitには原稿・manifest・実装・文境界・再生成スクリプトを保存する。
- 出力MP4をffprobeで確認：H.264、1280×720、60fps、29,686フレーム、AAC音声あり、38,143,445 bytes。全編のデコード検査はエラーなし。最終動画から投影図・敵テーブル・後半冒頭を抜き出して、修正後の表示を確認した。
