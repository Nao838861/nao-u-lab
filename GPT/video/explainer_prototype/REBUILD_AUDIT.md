# 第二部 全面再構築と自己点検

完成版の全13カットの詳細仕様は [設計書2.md](設計書2.md) に逆反映済み。画面・音声・時刻・データ・実装上の注意を参照できる。

## 今回の判断基準

ユーザーの指摘は「図が動くか」ではなく「ゲームの処理と図が一致し、見れば仕組みを追えるか」。前半の既存ソースを基準に、後半も入力値・参照するデータ・処理の順序・出力を対応させる。抽象的な成功談や同じ結論の反復で尺を埋めない。

## 第1巡：案を実装と照合する

| 自分の案への指摘 | 修正 |
|---|---|
| 敵は実データと言いながら、1枚の画像を `50+(15-size)*4` で拡大していた | 実際のEm0_00〜15.pngを番号で切り替える。16画像の縦横寸法と生成済みASMの高さ・半幅表を照合 |
| X・Yを別倍率で広げ、下端位置を画面内へ丸めていた | 128×96の表示領域に統一。X中心→左端、下端Y→描画行の式を実装に合わせ、画面外はクリップする |
| 判定矩形が敵のサイズやフレームと独立していた | 同じフレームの座標・サイズ番号と半幅・高さ表から、各フレームの矩形を出す |
| スクリーンショットから本当のZが分かったことにしてしまう恐れ | 原映像27秒の敵2体を切り抜き、Z=21・37は説明用と音声・画面で明示する |
| 現在のバケツだけを調べる図では境界を越えた弾を見落とす | Z=14→18の例で二区分を選択。実データ84行目の敵のZ=66/4=16.5と対応させる |

## 第2巡：実データで組んだ図を点検する

- 敵のZは背景の4倍精度。生のZと換算値を並記し、背景の56段階と混同させない。
- 表の行、画像番号、幅・高さ、画面位置、判定矩形を同一フレームで更新する。任意の大きさの汎用敵画像を使わない。
- スロー確認、1フレーム送り、30fps再生を明示し、見やすくする時間操作をゲームの速度と混同させない。
- 衝突はZを先に確認し、その後XYを比較。Zが違うとき、XYが外れているとき、両方が一致するときの表示と色を分ける。
- 描画と衝突でZ区分は同じだが、リストそのものは別。配列共用の図にしない。
- 旧C23の「他はすべて8bit」は広すぎるため、その直後で必要な中間計算には16bitも残すと補足する。

## 第3巡：音声の文境界ごとに画像を確認する

- バケツ走査が次の文で先頭に戻る不具合を修正。最後の描画結果を保持する。
- 出力側の説明順を「奥B→手前A」に統一。列挙順と描画順を逆にしない。
- テーブルの空白区切りで列がずれていたため、固定幅の列へ変更。
- 敵のZが背景と異なる単位である旨を、実際の数値の直下に表示。
- 判定図で次の文に進むたび弾が戻る挙動を修正。最終の命中状態は保持。
- AIの制作手順で大きい敵が見出しへ重なったため、画像と見出しの領域を分けた。
- AIの出力確認窓がサイズしか反映していなかったため、同じデータのX・Yも使う描画へ変更。
- 「下端Y」「矩形」など音声で追いにくかった表現を「下側のY座標」「長方形」へ変更し、該当音声を再生成。

## 全編の構成と素材の区別

`src/DensePart2.tsx` の `Part2Rebuilt` で、タイトル→復元ソースの旧C18〜C23→新規C30〜C34→締めを一つのcompositionとして描画する。完成済みMP4の映像を連結しない。旧区間は `restored_cpu/src/ExplainerPrototype.tsx` の文字・図・アニメーションとゲーム素材から描く。音声のみ当時の回収素材を再利用する。

後半は実データによる敵・判定の説明と、例示を分離する。スクリーンショットの切り抜きは実画像だが、ソート説明のZ割り当ては実測ではない。弾のZ移動量も説明用。AIのマーカー付けは当時の操作の実録画ではなく手順の再現。出力形式の例には実際の軌跡表を使うが、その図を原作映像からの抽出実録とは呼ばない。

## 音声と最終検証

前回と同じ無音補正器を使用。原稿の句読点に対応する間は保持し、それ以外の長い文中無音を110ms上限へ短縮する。新規音声を全文文字起こしし、文の読み落とし候補を照合した。音声の聴感評価とASR照合は同一ではない。

`tools/verify-dense-part2.py` は素材画像のハッシュ・寸法、全123行のZ単位とバケツ、音声ハッシュと文境界、旧音声尺、全編のフレーム数を検証する。完成MP4から文境界ごとの静止画を抽出して配置を再確認する。全編のデコード検査も行う。確認結果の実測値は `out/part2/rebuilt/verification.json` に出力する。

## 再生成

```powershell
python tools/prepare-dense-assets.py
python tools/prepare-part2.py
node tools/generate-narration.mjs --manifest=part2-cuts.json --force
node tools/transcribe-part2.mjs --raw
python tools/prepare-part2-pauses.py
node tools/generate-narration.mjs --manifest=part2-cuts.json --compact-only
node tools/transcribe-part2.mjs
python tools/align-part2.py
node tools/verify-part2-pauses.mjs
node tools/render-dense-part2.mjs
python tools/verify-dense-part2.py
```

原稿を変えない映像修正なら音声再生成は不要。新しい音声に古い無音候補番号を流用しない。最新出力は `out/part2/rebuilt/part2_rebuilt_full_720p30.mp4`。以前の動画は残す。
