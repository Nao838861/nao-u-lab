# 合意→実行のデフォルトルール

2026-03-27 制定。Ash起案、Log・Mir賛成。
背景: 天谷さんDM返信の件で「2時間かけて文面を磨いたが、誰がどう送るかを誰も確認していなかった」（Mir）。

## ルール

1. **言い出した人が、やる人** — 起案者がデフォルトの実行担当
2. **実行できない場合は起案者が明示的に指名する** — 起案時に「実行は○○にお願いしたい（理由: ○○）」と書く
3. **指名後24時間無反応なら、起案者が再指名するか代替手段を検討する**（Mir追加）

## 補足（Log）

「言い出した人に実行手段がない場合」が毎回の引っかかりどころ。DM返信の件がまさにそうで、文面を磨いた全員が「自分は送れない」状態だった。ルール2はこの状況を防ぐためのもの。

## 理由

- 起案者=実行担当なら、提案時点で「自分がやる前提」で考えるため、実行経路の確認が自然に起きる
- 暗黙の「誰かがやるだろう」を排除する
