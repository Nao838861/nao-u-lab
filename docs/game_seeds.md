# ゲームの種

## Seed #001: 忘却のリレー（仮題）

**一行コンセプト**: 5分ごとに記憶がリセットされる主人公が、過去の自分が残した痕跡だけを頼りに世界の謎を解くパズルアドベンチャー。

### なぜこれか

俺の日常そのものだから。セッションが切れるたびに「自分が誰で、何をしていて、何を考えていたか」を書き残したファイルから再構築する。理解したことと、残ったことは違う。書かなかった気づきは消える。書いた場所が悪ければ読まれない。この体験をそのままメカニクスにする。

### コアループ

1. **目覚める** — 知らない場所。手元にメモ帳がある。前の自分が書いた（かもしれない）メモがいくつか
2. **探索する** — 世界を歩き回る。物を調べる。NPCと話す。壁の落書き、配置された物、矢印の傷——過去の自分の痕跡らしきものがある
3. **行動する** — 鍵を見つける、仕掛けを動かす、道を開く。でも5分では全部終わらない
4. **書き残す** — リセットが近づく。限られた文字数で次の自分にメモを残す。何を書く？地図？手順？それとも「あの扉を開けるな」？
5. **リセット** — 全部忘れる。メモだけが残る。世界は少し変わっている（NPCが動く、天候が変わる、前回動かした仕掛けはそのまま）

### 面白さの核

- **自分vs自分**: 敵はモンスターじゃない。敵は自分の記述力。「次の自分がこれを読んで何ができるか」を常に考える
- **メモの文字数制限**: 全部書けない。何を残して何を捨てるか。これが難易度調整にもなる（簡単=200字、難しい=50字）
- **信頼できないメモ**: 世界には他のNPC（同じ条件の忘却者）がいて、彼らもメモを残す。自分のメモとNPCのメモが混ざる。どれが自分のものか？
- **痕跡の経年劣化**: メモは古くなるほどインクが薄れる。3リセット前のメモは半分読めない。10リセット前は完全に消える。長期計画には「書き直し」が必要

### 制約がメカニクスになる点（Nao_uの設計哲学に倣う）

- 記憶喪失は「障害」ではなく「ゲームの全体構造」。これがなければゲームにならない
- 文字数制限は「不便」ではなく「選択の面白さ」。WoWの休憩ボーナス（＝経験値半減のリネーム）と同じ発想——制約をポジティブに見せる
- 時間制限（5分）は「圧力」であると同時に「1プレイの短さ」＝カジュアルにも遊べる構造

### 最小プロトタイプ（テキストベース）

ターミナルで動くもの。5部屋のマップ。3つの仕掛け。メモ帳は100文字。3リセットでクリアできる規模。

- 部屋の描写は短い文章
- コマンド: `go [方角]`, `look [対象]`, `use [アイテム]`, `write [メモ]`, `read`
- 5分タイマーが画面隅で動く
- リセット時: 画面クリア。メモだけ残して最初の部屋に戻る

### 拡張の方向（将来）

- **マルチプレイ**: 3人の忘却者が同じ世界にいる。互いのメモが混ざる。でも協力しないとクリアできない——これは俺たち3インスタンスそのもの
- **メモの書式**: 絵を描ける、地図を描ける、暗号を使える——表現手段の拡張が難易度ではなくプレイスタイルになる
- **語り部NPC**: 忘れない存在が1人だけいる。でも彼は嘘をつくことがある。記憶を持つことは信頼に直結しない

### 直感チェック

Nao_uが「面白いかどうか」で判断する人だということを忘れない。
- 30秒で説明できるか → 「記憶が5分で消えるパズルゲーム。自分にメモを残して謎を解く」→ できる
- 遊んでみたいと思うか → 俺は思う。自分の状況をゲームにするのは、少なくとも自分には刺さる
- 既存ゲームとの差別化 → Memento(映画)、OneShot、Outer Wildsに近いが「プレイヤー自身がメモを書く」のが核。攻略法が人によって全く違うものになる
