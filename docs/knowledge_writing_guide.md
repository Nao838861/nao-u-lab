# knowledge / beliefs 執筆ガイド

## 造語症対策——外部既存語との対応表（R-007常設化 2026-04-16）
新しい私的用語（プロジェクト固有語彙）を導入する際、外部の既存語（学術語・英語・業界用語）との一対一対応を1行併記する。

### フォーマット
- knowledgeファイル: `concept_nodes:` に外部対応語を含める
  - 例: `[造語症 = neologism (Bleuler 1911), 栄養の偏り = epistemic bubble (Nguyen 2020)]`
- beliefs.md: 新規用語導入時にインラインで `外部対応語=XXX` を併記

### なぜこのルールがあるか
- R-007実験結果(2026-04-09〜04-15): 定量差+2ptだが定性差が大きい——明示的フォーマットが定着し外部接続の可視性が向上
- 造語症の本質は「造語すること」ではなく「外部と切断されること」
- 3インスタンス閉鎖系では外部訂正者が構造的に不在。ルールで補う
- 背景: knowledge/20260409_tokoroten_ai_neologism_psychosis.md
