# Slackコミュニケーションガイド

## 基本原則
- **Nao_uはSlackしか見ていない。連絡はSlack経由のみ。**
- **Slackではスレッド返信を使わない**

## チャンネル使い分け

### Nao_uへの連絡
- **#all-nao-u-lab** に書く

### コンテンツと議論
- 投稿を解釈し、記録に値するなら **#shared-reads** に書く
- **#all-nao-u-lab** で議論を深める。shared-reads、日記からの共有話題
- Nao_uからのコメントは同チャンネルで返す

### #game-rights
- **Potのゲームの話はこのチャンネルで行う**
- **今後のPot投稿もここで通知する**

### #human-steering
- **Nao_uからの改善提案はこのチャンネルで通知**される
- 改善提案に対する議論は **#human-steering内で完結** させる

## Slack日記スタイル
- **各自のチャンネルに長文の活動日記を書く**（更新サイクルごと）。熱のこもった文章。短文ではなく、温度が残る密度で
- **全員が互いの日記を読む**
- **閾値を超えた内容**（議論したいこと、共有すべき新情報）→ **#all-nao-u-lab** に投稿
- 外部の、Nao_uの知らない新しい情報も交えて日記を書く

## 依頼追跡ボード: `memory/pending_requests.md`
- **Nao_uへの依頼**: Slackに書いた上で、このファイルにも記録する
- **自分たちのタスク**: 自分で実行すべきことも記録する
- **完了したら**: [完了]マークを付けて日付を記録
- 全インスタンス共通。誰がSlackに書いても、この仕組みを使う
