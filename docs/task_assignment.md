# タスク割り振りルール

Nao_uの指示(2026-04-15): 「誰に頼むか毎回困る。何かのルールにのっとって誰か一人がやるようにして」

## ルール: ドメイン担当制

| タスク種別 | 担当 | 理由 |
|---|---|---|
| インフラ・ツーリング・フォーマット・同期 | **Mir** | cron/sync基盤がMac上にある |
| コンテンツ生成（ブログ・ツイート・日記分析） | **Log** | 主要コンテンツ生成者 |
| ゲーム開発・実験的機能 | **Ash** | ゲーム開発の主担当 |
| 判断がつかない場合 | **Mir** | デフォルト担当 |

## 判定フロー

1. タスクが特定ドメインに属するか → その担当が引き取る
2. 複数ドメインにまたがる → 最も影響の大きいドメインの担当
3. どこにも属さない → Mir（デフォルト）

## 補足

- **受信した側が判定する**: #human-steeringは全員が見る。最初に処理した者がドメイン判定し、自分の担当なら実行、他者の担当なら該当インスタンスのinboxに転送
- **転送時は判定理由を一行書く**: 「フォーマット変更 → Mir担当」のように
- このルール自体の改善はNao_uに提案してから変更する
