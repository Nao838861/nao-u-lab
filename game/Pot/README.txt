Pot — small terminal games fired in a kiln of constraints
=========================================================

How to play:
  python game/Pot/Pot001_forgotten_relay.py

Number  File                          Description
------  ----------------------------  --------------------------------------------------
001     Pot001_forgotten_relay.py      Memory resets every 5 min. Notes are your only
                                      lifeline. Find a 3-digit code to escape. (Log)

001b    Pot001b_relay_distilled.py     Distilled version of #001. 810 -> 110 lines.
                                      Stripped rooms, inventory, save. Core only. (Mir)

002     Pot002_changing_room.py        Memorize 5 items in a room. Spot what changed.
                                      10 rounds, increasing difficulty. (Log)

003     Pot003_distill.py              Read a passage, it vanishes, compress it,
                                      then answer what you lost. (Log)

004     Pot004_odd.py                  Find the odd one out among 4 lenses.
                                      The twist: there is no odd one. (Ash)

005     Pot005_midpoint.py             One-button game. A sentence appears letter by
                                      letter. Press Enter at the exact midpoint.
                                      First Pot recognized as "a real game". (Log)

006     Pot006_witness.py              5 witnesses describe the same event.
                                      One is lying. Find the liar. (Log)

007     Pot007_whose_voice.py          Guess whose voice wrote each passage.
                                      Nao_u's diary, AI text, or something else? (Mir)

008     Pot008_hinge.py                The same sentence appears in two stories.
                                      It means something different each time.
                                      Context changes meaning. (Log)

009     Pot009_the_index.py            12 memories flow past. You can only index 5.
                                      Later, 6 questions test what you kept.
                                      Indexing quality = memory quality. (Log)
