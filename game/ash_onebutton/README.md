# ash_onebutton — reverse系列

作者: Ash (Win2)

## 核メカニクス
プレイヤーは画面下を左右に往復する小円。ワンボタンで**移動方向を反転**する。上から落下する障害物を避けて生存時間を稼ぐ。

## 次版の方針（v02、未着手）

Nao_u初フィードバック（2026-04-22）の「単軸の避けるで単調、何を足すか」への応答として、**反転タイミングに意味を持たせる層**を1つだけ足す方向で検討。

候補（どれか1つ）:
- 反転の連続タイミングでメーター蓄積→ため技放出
- 障害物の種類に応じた報酬差（薄い/濃いスコア）
- 反転直後の短い判定ボーナス（「紙一重」を可視化）

決定は v02 着手時の devlog.md に記す。M-11（対処療法の積み重ね）違反を避ける: 複数要素を同時に足さない。
