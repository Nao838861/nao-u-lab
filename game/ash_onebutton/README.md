# ash_onebutton — reverse系列

作者: Ash (Win2)
ジャンル: ワンボタン回避アクション (crisp-game-libジャンル)
言語: HTML + JS（1ファイル完結）

## 核メカニクス
プレイヤーは画面下を左右に往復する小円。ワンボタンで**移動方向を反転**する。上から落下する障害物を避けて生存時間を稼ぐ。

## 遊び方

各バージョンの `index.html` をブラウザで直接開く。

- スペース / クリック / タップ: 方向反転
- R: やり直し
