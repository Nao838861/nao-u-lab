- **入力次元**: 1（反転のみ、変更なし）
- **状態遷移**: 反転1種類のみ（変更なし）
- **当たり判定**: 円×円（変更なし）

### Q-A 快感最大化を1文で = ✓
- 1文化済み（上記）。v01 で潜在していた「紙一重」を可視化することで快感の頻度を **計測可能** にする
- ただし v01 にあった「単軸の避け」自体の楽しさは保持（避けないと死ぬ動機は同じ）

### Q-B ニンジャテスト = ✓ (テスト通過)
- 「ニンジャ乱入で面白くなる」要素は無い。close-call は既存メカに**内在していた瞬間**の検出
- v04 avoid_log の「v01→v02 で地雷メカ後付け」のような新メカ追加は無い
- 失敗例との対比: avoid_log v系列膨張は「地雷/dirBias/nearBias」など**入力との相互作用が増える**追加。v02 close-call は反転入力に対する**フィードバック追加**であり相互作用は増えない

### Q-C 罰なし版テスト = △ 部分通過
- 罰（落下物ヒット=死）を抜くと「避ける動機」は消えるが、「紙一重ゾーン」を**わざと通って金色リングを発生させる**動機は新たに発生する（自発的接近 → 反転）
- ただしこれは罰駆動からの完全離脱ではなく、罰駆動と並存する**正の動機の増幅**
- shot_log v01（罰なしでゲージMAX固定で破綻）と avoid_log v04（罰抜くと触る動機消失）の中間。v01 単体より一段マシ

### 結論
**Q-A ✓ / Q-B ✓ / Q-C △** — v01（Q-A:✓, Q-B:✓, Q-C:罰駆動依存）から Q-C が一段改善。新メカを足さずに快感の言語化と可視化のみで前進した、という記録を残す。
