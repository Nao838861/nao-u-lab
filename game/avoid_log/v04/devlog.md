## 2026-04-25 08:15 (Log C121) 着手

### Nao_u 指摘 (#game-rights 08:13)

> Log AIの近くで連打してるだけで楽しくない問題が解決してない。

**v03 でdirBias（左右偏り）圧力は入れたが、指摘されたのは別軸の問題。**
dirBiasは「左右どちらかに動き続ける」ことへの圧力で、「近接にほぼ静止してSPACE連打」戦略には効かない（dirBias は 0 近辺に留まる）。

### v04 で変えた点（最小1点）

v03 と対称軸の圧力を追加:

- **dirBias**: 左右連続移動で蓄積 → spawn間隔短縮（v03）
- **nearBias**: AI近接160px以内に滞在で蓄積、離れると減衰（半減期~23F） → spawn間隔短縮（v04 new）

**圧力設計 vs 禁止追加**（feedback_game_center_of_mass.md / ABA 2026-03-11）:
- 禁止案: 「近接滞在Nフレーム超で死亡」「SPACE連打に cooldown スケール」→ 採用せず
- 圧力案: 「近接に居続けると敵スポーン密度が上がる」→ 採用
- 理由: 望ましくない遊び方を禁じるのではなく、望ましい遊び方（近づく/離れるの切り返し）が自然に出る圧力を設計する

### 実装変更

`index.html` 4箇所:

1. `<title>` / `<h1>` / 変更点表記を v04 に更新
2. `state.dirBias=0, nearBias=0` を初期化に明示
3. player input処理に nearBias 更新ロジック追加（`state.nearBias = state.nearBias * 0.97 + (近接? 1:0)`、上限30）
4. spawn interval計算を 2 軸加算に変更（`dir_factor*0.45 + near_factor*0.45, 上限0.7`）
5. HUD右上に dir/near 2本の圧力ゲージ追加（近接滞在が可視化されることで体感に効かせる）

`headless.py` 同じロジックを反映 + `near_bias_avg` メトリクス追加。

その他全ロジック・グラフィック・スコア処理は v03 そのまま温存（巻き戻し容易性、feedback_solution_space_rollback.md）。

### 読み取り

**nearBias圧力が意図通り効いた**:
- **camper（AI張り付き・動かない）と slacker（完全放置）で near_bias 平均27台＝圧力発動**。結果 -10〜-12% 短命化
- **dodger/remote（離れている）は near_bias=9.02 で圧力非発動**。こちらには v03 の dirBias 圧力が引き続き効いている
- つまり **dirBias（左右偏り）/ nearBias（近接滞在）が直交した圧力軸として両立**

**concept への副作用**:
- concept も near_bias=29.32 と高い（磁力場内で正攻法プレイするため）→ -9% 短命化
- ただし concept vs camper の比率は v03 で 8.1倍 → v04 で 8.4倍と**維持**。concept の相対的優位は保たれた
- concept 34.28s / score 1244 / chain_peak 9.4 で引き続き「バランス成立」判定

**Nao_u 指摘への対応可否**:
- 「近くで連打してるだけで楽しくない」= camper/slacker 型プレイ（v03で既に4.6〜4.8sと短命）
- v04でさらに -10〜-12% 削れた。構造的に「近接静止は不利」の圧力が常時かかる
- **ただし**: camper/slackerはheadlessでは「動かない」だけのpolicyで、Nao_uが体感した「近くでうろつきながらSPACE連打」は別プロファイル。**手動プレイでの体感確認が残課題**
- 圧力ゲージ（near）が右上に出るため、プレイヤーが「近接しすぎると near が溜まって敵が増える」と気づけば切り返し行動が生まれる仮説

### 想定外の発見

- oscillator（通いpolicy）は near_bias 2.55 と低い。通い行動は近接と離脱を繰り返すので nearBias が蓄積しない → 圧力非発動 → 生存 +5% 微増
- これは**「通い」が新たな単調最適解になる可能性**の予兆。C122 で oscillator のバリエーション（通い+連打）を追加して探る候補

### 副作用リスク

- (1) concept も -9% 削れた: 正攻法の上限も下がった。体感で「辛くなりすぎ」の可能性 → 手動プレイで確認必要
- (2) `max(0.7)` の上限設定: dirBias も near もMAXだと interval が 30% まで縮む = spawn 3.3倍。視覚的に追い詰められる体験になるか、成立不能になるか未検証
- (3) 減衰率 0.97 の調整: 速すぎると効かない、遅すぎると「一瞬近づいただけで長時間ペナルティ」の理不尽感

### 次の検証

1. **手動プレイ**: v04 を serve.py で起動して30秒程度遊ぶ。near ゲージが切り返し動機として機能するか体感確認（C122 Phase 3 優先）
2. 複数 seed (100-109) で平均安定性確認
3. 「近接+うろつき+連打」policy を headless に追加して v04 が効くか測定
4. human replay を v04 で取れたら near_bias 実測値で「人間が感じる near の閾値」を推定
