### HTML版がやっていること
1. プレイヤー（青）とAI（橙）が同じ画面で並走
2. 弾幕：直線弾 + 弱ホーミング弾の2種（時間経過で密度・速度アップ）
3. AI挙動：最近傍脅威を検出 → 横に退避。脅威なしならプレイヤーに緩くミラーリング
4. 軌跡を薄い色で描画（プレイ中から差分が見える）
5. 両者死亡後：軌跡重ね表示＋生存秒数。勝ち負けを「秒」で判定
6. 視覚の一行UI：「AIより長く生きろ」をページタイトル上に

- 「白い家の前」（放り出し）と「あなたは勇者」（陳腐）の中間：視覚で状況、1行で目的

## 設計上の選択と理由
- **Canvas手書き**（p5.js未使用）: 単一HTML・外部依存ゼロ。ファイル配布でそのまま動く
- **AI=ヒューリスティック**（機械学習なし）: 「AI=認識装置」の検証にモデル訓練は過剰。最近傍脅威退避で十分「賢そう」に見える
- **軌跡保存**: 認識装置の証拠を残す。死後の画面で「違い」を目で見せる
- **ホーミング弾は弱め**: 「避けられない」と「慣れれば避けられる」の境目で腕前が出る

### 自己診断
- AIが「認識装置」のつもりが実際には**並走の飾り**。片方が死ぬ＝差分停止＝情報量ゼロ
- 「AIより長生き」が効いているのは両者生存中の数十秒だけ。死を通過点にできていない
- avoid_log_02設計（AIが玉を吸収→撃ち返し、abaさんの意味多層化適用）は生存中の相互作用だけ設計済み。**死後の意味変換を足す必要がある**

### avoid_log_02で足す「死の意味変換」軸
1. **AIの死** = 吸収していた玉の一斉解放（弾幕爆発）。死が罰でも報酬でもなく環境変化
2. **プレイヤーの死** = AI視点に切り替わりAIが最後まで生き延びるかを見届け
3. **両者死亡後** = 軌跡＋因果（誰がどの弾で死んだか）重ね表示

認識装置の核は**生死のどちらでも差分を出し続けること**。評価軸は「退屈と味気なさが消えたか」。派手さ/スコア後回し。

## 2026-04-18 18:22 プレイヤーAI v2 — 連打化の根切り

**仮説（Phase 2分析）**: 初回評価の3警告（連打化0.263/全滅100%/非対称）のうち「連打化」はプレイヤーAIヒューリスティック由来。v2メカニクス自体の評価は、プレイヤーAIを"連打化しない構造"にしてからでないと分離できない。

**v2プレイヤーAIの3層化**
| 層 | 役割 | 実装 |
|---|---|---|
| Layer1 予測 | dy<400まで先読み。障害物の到達フレーム算出 | `frames_to_arrive = dy / speed` |
| Layer2 目標位置 | 同時刻帯の障害物占有区間を合成し、現在位置を含む区間の外側で最近接の安全点を目標x化 | 区間merge + 最近接選択 |
| Layer3 ヒステリシス | 目標との差が±6px以内なら入力0（微振動で連打化しない） | `if -6 <= diff <= 6: return 0` |

**結果（seed=100,5周で比較）**

| 指標 | v1 | v2 | 判定 |
|---|---|---|---|
| 切替率 | 0.263 | **0.011** | ⚠消失 (閾値0.15, 0.05下回る) |
| 入力エントロピー | 1.26 bit | 0.30 bit | 単調化 |
| 平均生存 | 3.07秒 | 4.78秒 | +56% |
| 全滅率 | 100% | 100% | 変化なし |
| AI生存率 | 100% | 100% | 変化なし |

**切り分け結論**
- 「連打化」はプレイヤーAI由来と**実証された**（v2メカニクスを触らずに警告が消えた）
- 「全滅率100%」は残るが、プレイヤーAIの限界（脅威密集時に安全点が壁で潰れる構造）かもしれず、**まだv2メカニクス側の責任とは確定できない**
- Nao_u 11:16宣言「2サイクル試して根が切れなければ巻き戻し」——連打化については1サイクルで根が切れた。**この理由では巻き戻しの正当化にならない**

**次の一手（候補）**
1. v2AIの限界テスト: 密集時の「逃げ場がない時に耐える/行動をさらに最適化する」層を足して全滅率が動くか観察
2. ゲーム自体の評価に進む: 今のv2AIを「ベースライン評価プレイヤー」として固定し、メカニクス側のバリエーション（障害物速度、spawn間隔等）の影響を計測
3. 人間試遊との対照: Nao_u感想と評価器の警告/非警告の一致をチェックし、閾値校正

**メタ学び**: feedback_solution_space_rollback が「前進改造に固定される傾向への直接修正」と言っていたが、**巻き戻しの正当化にも証拠が要る**。「根が切れなかった」の証明は、根を切ろうとした層と別の層で失敗することで成立する。今回はプレイヤーAI層で根が切れた=v2メカニクス層にボールが移っただけ。
