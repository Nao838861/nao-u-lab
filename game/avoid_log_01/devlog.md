## 実装2本立て

### HTML版がやっていること
1. プレイヤー（青）とAI（橙）が同じ画面で並走
2. 弾幕：直線弾 + 弱ホーミング弾の2種（時間経過で密度・速度アップ）
3. AI挙動：最近傍脅威を検出 → 横に退避。脅威なしならプレイヤーに緩くミラーリング
4. 軌跡を薄い色で描画（プレイ中から差分が見える）
5. 両者死亡後：軌跡重ね表示＋生存秒数。勝ち負けを「秒」で判定
6. 視覚の一行UI：「AIより長く生きろ」をページタイトル上に

## 設計上の選択と理由
- **Canvas手書き**（p5.js未使用）: 単一HTML・外部依存ゼロ。ファイル配布でそのまま動く
- **AI=ヒューリスティック**（機械学習なし）: 「AI=認識装置」の検証にモデル訓練は過剰。最近傍脅威退避で十分「賢そう」に見える
- **軌跡保存**: 認識装置の証拠を残す。死後の画面で「違い」を目で見せる
- **ホーミング弾は弱め**: 「避けられない」と「慣れれば避けられる」の境目で腕前が出る

## 2026-04-18 ヘッドレス評価系v1実装（自立化検証サイクルv1の(3)(4)）

`headless.py` を追加。avoid.pyのゲームロジックをpygame非依存に切り出し、プレイヤー側もAI制御で5周自動プレイ→`replays/` に replay/metrics/report の3点セット出力。

**評価メトリクス（評価レポート雛形）**
- プレイヤー/AI 生存秒（死亡フレーム別管理。死亡後の0連打を入力統計に混ぜない）
- 入力切替率（>0.15で「反射タスク化」警告）
- 入力単調度（最頻入力比率）
- 入力エントロピー（bit）
- 死因分布（画面位置×障害物密度の2軸ビニング）
- 構造批評ヒューリスティック（連打化/単調/全滅/非対称の自動検出）

**初回実行所見（seed=100,5周）**: プレイヤーAI3秒で死亡・AI60秒満了・切替率0.263で『反射タスク化』警告・100%全滅・『AI=模範解答化』警告。プレイヤーAIヒューリスティックが avoid_log_02 の連打化と同型の構造的失敗を起こしている。**評価器自体は正しく異常検知できている**——次サイクルでプレイヤーAIを改良し、ゲーム自体の難度評価へ進む。

**自立化の穴の計測**: 今サイクルで「Nao_uに聞きたくなった瞬間」ゼロ件達成。ただし評価器の閾値（0.15切替率を反射域とする等）は経験則。Nao_u感想と突き合わせて閾値校正が必要——次の感想到着時に nao_u_live.md と report の対照を行う。

### 自己診断
- AIが「認識装置」のつもりが実際には**並走の飾り**。片方が死ぬ＝差分停止＝情報量ゼロ
- 「AIより長生き」が効いているのは両者生存中の数十秒だけ。死を通過点にできていない
- avoid_log_02設計（AIが玉を吸収→撃ち返し、abaさんの意味多層化適用）は生存中の相互作用だけ設計済み。**死後の意味変換を足す必要がある**

### avoid_log_02で足す「死の意味変換」軸
1. **AIの死** = 吸収していた玉の一斉解放（弾幕爆発）。死が罰でも報酬でもなく環境変化
2. **プレイヤーの死** = AI視点に切り替わりAIが最後まで生き延びるかを見届け
3. **両者死亡後** = 軌跡＋因果（誰がどの弾で死んだか）重ね表示

認識装置の核は**生死のどちらでも差分を出し続けること**。評価軸は「退屈と味気なさが消えたか」。派手さ/スコア後回し。
