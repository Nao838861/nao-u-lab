## 「最良」確信宣言

希望的観測語禁止、判定ハーネスの出力で正当化:

1. **A=10 は5振幅中で唯一「視認性 ≥ 1.5x」と「最大ガイド誤差 < 23px (物理境界)」を両立する** — 数値根拠
2. **物理境界 23px = BR_W/2+BALL_R は「ガイドが指す位置と実ブロックがズレてもボールは予測ブロックに当たる」最大値** — ガイド機構が嘘をつかないことの定義
3. **5振幅で並列比較した上で結論したため、A=10 が「中庸」ではなく「物理的に最良」だと自分で説明できる** — 任意の振幅に対して同様の判定ができる再現性
4. **判定機構自体が再利用可能** — 速度系/応答系の他ゲームでも同パターンで使える
5. **過去 mental simulation の失敗 (v04 過小, v05 過大) は判定機構の不在に帰責** — v06 の根拠は機構の出力、self_judgment の推測値 (14-16px) からも修正済

→ **本ラウンドで A=10 / 200f は構造的に最良。Nao_u プレイ前に出す**。
