# brick_log v06 — M-40 判定ハーネスで校正された動的標的

## 起点（Nao_u 2026-05-01 09:58 #game-rights）

> 人間のプレイに依存せず、ちゃんと自分で判断できるようになって。でないと進歩がない。

v04 (5px) は「動いて見えない」(Nao_u 09:46 直接指摘)、v05 (22px) は self_judgment.md で「ガイドが嘘をつく可能性」を自己診断したが、**自己判定の根拠が弱かった**（mental simulation のみで定量化なし）。

v06 では **判定機構そのものを構築** し、その出力に基づいて振幅を自己決定した。

## 判定機構（M-40 / `../v06_compare/`）

### 判定書 `../v06_compare/judgment.md`

数値 + 視覚から自己結論。

## 「最良」確信宣言

希望的観測語禁止、判定ハーネスの出力で正当化:

1. **A=10 は5振幅中で唯一「視認性 ≥ 1.5x」と「最大ガイド誤差 < 23px (物理境界)」を両立する** — 数値根拠
2. **物理境界 23px = BR_W/2+BALL_R は「ガイドが指す位置と実ブロックがズレてもボールは予測ブロックに当たる」最大値** — ガイド機構が嘘をつかないことの定義
3. **5振幅で並列比較した上で結論したため、A=10 が「中庸」ではなく「物理的に最良」だと自分で説明できる** — 任意の振幅に対して同様の判定ができる再現性
4. **判定機構自体が再利用可能** — 速度系/応答系の他ゲームでも同パターンで使える
5. **過去 mental simulation の失敗 (v04 過小, v05 過大) は判定機構の不在に帰責** — v06 の根拠は機構の出力、self_judgment の推測値 (14-16px) からも修正済

→ **本ラウンドで A=10 / 200f は構造的に最良。Nao_u プレイ前に出す**。

## 2026-05-01 13:07 Nao_u 指摘 — 設計方向の再評価

> 「ちょうど良い振動周期ができたとして、それはゲームが面白くなったと言えるのか？全てのブロックが揺れた結果、止まっている時よりゲームのコアの楽しさがすごく上がったと言えるか？ブロック崩しで動く物体って、先行事例はない？」

### 先行事例調査結果

| 事例 | 動かすもの | 設計意図 |
|------|------------|----------|
| Arkanoid (1986) | 敵キャラ(UFO/分子)・パドル拡張・分裂ボール | 外発緊張(M-19) + 報酬ループ拡張 |
| Cascade mode 系 | ヒットでブロック群が下降 | プレイヤーへの脅威=外発緊張 |
| Game Developer 記事 "Breaking Down Breakout" | oscillating motion 推奨 | **ただし「everything moves at once predictably」を悪パターンと明示警告** |

URL: https://www.gamedeveloper.com/design/breaking-down-breakout-system-and-level-design-for-breakout-style-games

### v06 への当てはめ

v06 = 全ブロックが同振幅・同周期・同位相で揺れる = **記事の悪パターン「everything moves at once predictably」そのもの**。

- ✓ 振幅校正 (M-40 物理実体の実証) としては成功
- ✗ 全ブロック同位相揺れがコアの楽しさを上げる証明はできていない
- ✗ メッシュ状のボール捕獲構造も時間軸での評価変化も生まれない (記事が示す oscillating の本来価値が発生しない)

### 自分の盲点

M-37 (Q-H-7) で「自明な快感を装飾UIで上書きしていないか」(Q-H-8) は問うていたが、**対称形「自明な快感を機構介入で毀損していないか」を問えていなかった**。
着手前 brainstorm に Q-H-8b として併設する必要あり (memory/feedback_mechanism_damage_pleasure.md)。

## 次の問い（v07 以降） — M-38 ブレスト必須

v07 単一案直実装は禁止。先行事例3パターンが示唆する候補:

- (a) **位相非対称揺れ** — 列ごと/グループごと位相ずらし、メッシュ状にボールが挟まる瞬間
- (b) **動くのは特定ブロックのみ + 静止ブロックとの対比** (Arkanoid 流)
- (c) **下降圧力** (Cascade流、Space Invaders的、外発緊張 M-19)
- (d) **外発緊張側の追加** — ブロックを動かす代わりに敵キャラ追加 (Arkanoid 流)
- (e) v04 brainstorm F-3 連鎖/コンボ
- (f) 揺れの2軸化(左右＋上下)+ 応答系(ボール接近で硬度↑)

`game/brick_log/v07/brainstorm.md` を作り MPS採点 + Q-H-8b + 「最良」確信宣言まで終わってから初実装。
