## 採用案: ボール接近応答（パッシブ）

### コア仕様

| 要素 | 値 |
|---|---|
| 警戒トリガー距離 | ボール中心から **100px 以内**（ボール半径 6px、ブロック高 16px の約 6 倍） |
| 警戒判定 | 毎フレーム、ボールに最も近い 1〜3 ブロックが警戒状態 |
| 警戒の視覚表現 | ブロック色が **明度 +30%**、輪郭白枠 1px |
| 警戒中の物理変化 | **後退 -2px**（ボールから遠ざかる方向に微小シフト） |
| 警戒中の効果 | 当てた瞬間のスコア倍率 **×2**（破壊扱いは通常通り） |
| 警戒解除 | ボールが 120px 以上離れる、または 0.5 秒経過 |

| 軸 | v04-v06 | v07 |

## M-39 人間プレイ前 結果予測（30 秒以内 / 0-5 秒 / 5-30 秒 / 30-60 秒）

### 0-5 秒
- ボールがブロック群に近づく → 最も近い 1〜3 ブロックが白縁＋明色化、わずかに後退
- プレイヤーが「動いた！」と気づく
- 予測ガイドは追従して描画（後退分も含めて）

### 5-30 秒
- 警戒中のブロックを当てる体験 → スコア倍率 ×2 が表示
- 「警戒中を狙うと倍率」のメカが学習される
- 警戒解除タイミング（0.5 秒）を読みつつ複数を連続で当てる挑戦

### 30-60 秒
- 達人層: 警戒中を連続でヒット、倍率累積
- 初級層: 警戒のリズムを掴む段階、ガイドで狙えるが倍率を逃す

### 遊ぶ前にわかる懸念 3 点

1. **警戒判定がチラつく**（距離境界で頻繁に on/off） → 距離 100px 警戒、120px 解除のヒステリシス設計で対処
2. **複数ブロックが同時警戒で混乱**（最大 1〜3 個に制限） → 距離順 Top 3 のみ警戒
3. **後退 -2px で隣接ブロックと隙間** → -2px は隣接ブロック間隔（4px ギャップ）の半分以下、視覚的に許容
