## 1. v4 失敗の構造分析（何を「全部 X1 の天井」と誤認したか）

### v04-v06 で実装した X1 の1パターン

| 軸 | v04-v06 での選択 |
|---|---|
| 動きの単位 | **全ブロック** |
| 位相関係 | **同位相（同期）** |
| 動きのトリガー | **時間（無関係）** |
| 動きの方向性 | **三角関数 sin（無方向）** |
| 動きの予測性 | **完全予測可能** |
| プレイヤー行動との関係 | **無関係** |

→ Game Developer "Breaking Down Breakout"（[https://www.gamedeveloper.com/design/breaking-down-breakout-system-design-and-level-design-of-breakout-games](https://www.gamedeveloper.com/design/breaking-down-breakout-system-design-and-level-design-of-breakout-games)）の "everything moves at once predictably" 警告は、**この6軸全てが「全部・同期・無関係・無方向・予測可能・無関係」に振れた1パターン**への警告。

### X1 の枝（軸ごとに別の選択がある）

| 軸 | v04-v06 | 別選択肢 |
|---|---|---|
| 動きの単位 | 全ブロック | 個別 / 群（行/列） / ボール周辺局所 / 特定種別のみ |
| 位相関係 | 同位相 | 個別位相 / リレー位相 / トリガー時に発生 |
| 動きのトリガー | 時間 | **ボール接近** / プレイヤー入力 / 別ブロック破壊 / スコア |
| 動きの方向性 | sin（無方向） | 横スライド / 降下 / 回避 / 後退 |
| 動きの予測性 | 完全予測 | 確率的 / イベント駆動 / 段階的 |
| プレイヤー行動との関係 | 無関係 | **応答** / 反応 / 連鎖 |

→ **6軸全てが v04-v06 と違う分岐がいくつもある**。v04-v06 凍結 = X1 全凍結 ではなかった。

### 検索語彙（grep+web）

`Breakout dynamic blocks / Breakout block movement / Arkanoid moving blocks / brick breaker reactive blocks / Krakout responsive enemies / breakout proximity reaction / paddle game block animation`

### Game Developer "Breaking Down Breakout" 再読（v06 では凍結根拠としてしか引かなかった）

該当節「If everything moves at once predictably, the player loses agency」の正確な反対パターン:

- **Local motion**: 一部だけ動く（ボール接近で局所動的化）
- **Reactive motion**: ボールに応答する動き（イベント駆動）
- **Phased motion**: 段階的に増える動き（v01静止 → v07局所応答 → v08群応答 → ...）
- **Directed motion**: 明確な方向性ある動き（隊列スライド、降下）

→ **v04-v06 はこの反対パターンを全て選ばなかった**。1つでも選んでいれば天井は違った。

## 3. v04 brainstorm の枝の中で「v4 と違う」分岐の精査

v04 brainstorm.md の Q-3「B2 静止標的への手法」M2-1〜M2-4 + Q-5「X1 動的標的化」の中で、v04-v06 が実装したのは X1 の最も狭い1点。残りの枝:

### 候補 A: ボール接近応答（イベント駆動局所動的化）

**仕様**:
- ボールが特定距離内（例: 60-100px）に接近 → そのブロックが「警戒状態」（色変化＋数 px 後退/震え）
- 警戒中に当てると倍率↑（×1.5〜×2）または硬度+1（複数回当て必要）
- 警戒は約 0.3-0.5 秒で解除

**v4 との構造差**:
- ◎ 動きの単位: **局所**（v4=全ブロック）
- ◎ トリガー: **ボール接近**（v4=時間）
- ◎ プレイヤー行動との関係: **応答**（v4=無関係）
- ◎ 方向性: **意図のある動き**（v4=三角関数）

**MPS（解決問題群）**:
- B2 静止標的 ◎
- B3 戦略選択肢（警戒解除待ちか中で稼ぐか） ◎
- B5 スコア意味（倍率に意味） ◎
- B16 反応しない ◎
- B6 連鎖の伏線（隣接伝染で接続可能）

**先行事例**: Krakout 応答ブロック / Arkanoid 鋼鉄ブロック / Wizorb ボス / Ricochet 磁石

### 候補 B: 隊列横スライド（方向性ある群動）

**仕様**:
- ブロック群全体が左右にゆっくり横スライド（数 px/sec、行ごとに方向違う）
- 端に達したら反転、または壁にぶつかった列のみ消失（Space Invaders 型）

**v4 との構造差**:
- ◎ 方向性: **線形運動**（v4=三角関数）
- △ 動きの単位: **群（行）**（v4=全だが行単位なら多少分離）
- × トリガー: 時間（v4 と同じ）
- × プレイヤー行動との関係: 無関係（v4 と同じ）

**MPS**: B2 ◎ / B16 ○（応答性は限定的）

**先行事例**: Arkanoid DOH It Again（直接） / Space Invaders（同型）

### 候補 C: 降下圧（終局圧で攻める動機を作る）

**仕様**:
- 一定時間ごとにブロック群が1段降下（Space Invaders, Holedown）
- パドルラインまで届いたら終了
- 攻めるほど降下が遅くなる（撃破でリセット）

**v4 との構造差**:
- ◎ 方向性: **降下**（v4=三角関数）
- ◎ プレイヤー行動との関係: **撃破でリセット = 弱応答**
- ◎ B1 死ななくなった: **直接解決**（時間切れで死ぬ）

**懸念**: feedback_no_passive_punishment 違反候補（時間で死ぬ＝自然減衰ペナルティ）。「攻めれば防げる」が能動報酬化できるか。

**MPS**: B1 ◎ / B14 時間圧 ◎ / B16 ○ / B22 失敗ペナ ○

**先行事例**: Space Invaders / Holedown / Arkanoid 一部ステージ

### 候補 D: 個別位相揺れ（最低限の差別化、v4 の最小修正版）

**仕様**:
- 各ブロックがランダム初期位相で揺れる（揺れ量は同じだが同期しない）

**v4 との構造差**:
- × 動きの単位: 全（v4 と同じ）
- × トリガー: 時間（v4 と同じ）
- ◎ 位相関係: **個別**（v4=同期）
- × プレイヤー行動との関係: 無関係（v4 と同じ）

→ **v4 の最小修正、構造的には依然 "moves at once predictably" の延長**。鉱脈の見込み薄。

### 候補 E: パワーエサ式反転（イベント駆動全体変化）

**仕様**:
- 通常時は v3 の達人プレイ（静止標的）
- 特定ブロック破壊で短時間（5秒）「全ブロック1撃破壊状態」に反転
- その間にどれだけ稼ぐかの瞬発勝負

**v4 との構造差**:
- ◎ トリガー: **イベント駆動**（v4=時間）
- ◎ 方向性: 状態遷移（v4=三角関数）
- ◎ B1 死ななくなった: 反転中の駆け抜け緊張で部分解決

**懸念**: 通常時は v3 のままなので「死ななくなった」は反転中以外で残る。

**MPS**: B1 △ / B2 △ / B22 ○

**先行事例**: パックマン パワーエサ / 各種反転局面ゲーム

### 候補 F: 連鎖駆動（X2 寄り、近隣応答）

**仕様**:
- ブロック破壊で隣接が変色 / 硬化 / 一時的に脆くなる
- 1反射で複数破壊するとリレーボーナス

**v4 との構造差**:
- ◎ プレイヤー行動との関係: **完全応答**（破壊→隣接変化）
- × 動きの単位: 個別状態変化（揺れではない）

→ X1（動的標的化）というよりは X2（連鎖駆動レイアウト）。本ブレストの主筋から外れるが、A との組み合わせで使える素材。

## 5. 案セット相乗効果検討

### A 単独 vs A+F の組み合わせ

- **A 単独**: ボール接近で警戒、当てると倍率↑、解除すると元に戻る
- **A+F**: A に加え、警戒中に当てると隣接ブロックも警戒に変化（連鎖伝染）

A+F のメリット:
- リレー連鎖が成立可能（B6 解決）
- 「狙う順序に意味」が出る（B3 強化）
- 達人プレイの再定義: 「警戒のリレーをつなぐ」

A+F のデメリット:
- 独自要素が2つになり守破離の守 (M-35) 違反リスク
- M-37 懸念が増える

→ **v07 = A 単独、v08 = A+F 検討**の段階順序。守破離の守維持。

## 7. 「最良」確信宣言（希望的観測語禁止）

### v07 = 案 A（ボール接近応答 / イベント駆動局所動的化）を「最良」と判断する根拠

1. **v4 失敗の構造的反転として最も明確**: 6軸（単位/位相/トリガー/方向性/予測性/プレイヤー関係）のうち4軸が v4 と反対方向。"everything moves at once predictably" の正確な反対は「局所・イベント駆動・応答・意図ある動き」=A。
2. **Q-1 コア快感「予測線→操作→確定」を破壊しない**: 警戒応答は「狙う対象を選ぶ」段階に作用、裏抜け予測線・反射シミュレーションを維持。
3. **守破離の守 (M-35) 維持**: 独自要素1つ（接近応答）、ボール/パドル物理は不変、ガイド機構は v03 から不変。
4. **先行事例が複数ある**: Krakout 応答ブロック / Arkanoid 鋼鉄ブロック / Wizorb ボス / Ricochet 磁石。**M-41「先行事例ゼロは不採用」をクリア**。
5. **MPS 6 で Top**: B2/B3/B5/B6/B13/B16 を一手で。
6. **M-37 5件全て可**: 装飾UI問題、ガイド嘘問題、B1 解決問題、装飾レイヤ評価問題、Q-H-8b 機構毀損問題、全て解決設計あり。
7. **v04-v06 の「全揺れ同位相」が掘り尽くせなかった理由を構造で吸収する**: イベント駆動・局所・応答・意図ある動き、v4 が一切持たなかった性質を全て持つ。

→ **v07 は構造的に A が最良。実装に進んでよい。**

## 8. v07 README で確定すべき仕様の項目

1. 警戒トリガー距離（例: 80-120px、ボール速度に応じて）
2. 警戒状態の表示（色変化のみ / 微小振動 / 後退量、ガイド整合性確認）
3. 警戒中の効果（倍率 / 硬度+1 / 連鎖トリガー、本実装は **倍率のみ** に絞る = 守破離の守）
