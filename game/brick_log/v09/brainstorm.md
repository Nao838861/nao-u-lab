## 1. 類似ゲーム類似事例調査（M-41 必須・最低30本）

> 「数値のチューニングはあくまで微調整しかできない。面白くない仕様をいくら調整してもすぐに低いレベルめ頭打ちになるので無駄。アイデアを考える時は必ず類似ゲームの類似事例を広く検討してからの方が絶対に良い。」(Nao_u 2026-05-01 13:18)

### A. ブロック崩し直系（Arkanoid lineage）

- URL: https://en.wikipedia.org/wiki/Breakout_(video_game)
- **敵仕様**: 敵なし。純粋にボール反射でブロック破壊のみ
- **Power-up**: なし
- **ボス**: なし
- **設計含意**: 元祖は「敵なし」で成立 → 敵を入れるなら**それ自体がコア快感を上げる積極的理由**が必要
- **brick_log v09 への射影**: 敵を加える=Breakout からの「破」。守破離の守として Arkanoid 系列の敵仕様を参照することで型を確保

#### A-2. Super Breakout (Atari, 1978)
- URL: https://en.wikipedia.org/wiki/Super_Breakout
- **モード3種**: Cavity (上に空洞があり中にボールが浮遊、追加ボール獲得)、Progressive (画面が下に向かって進む)、Double (パドル2本)
- **敵仕様**: なし

- **採用余地**: Progressive の「画面が下がってくる時間圧」は敵代替として有効候補

### E. 「やらなかったゲーム」枠 / 失敗事例 / 過去30年動かさなかった負の証拠

#### E-1. 「敵を撃つ Power-up を主軸にしたブロック崩し」が定着しなかった
- **観察**: Arkanoid 本家の L=レーザー Power-up は **一時的取得アイテム**であり、「敵を撃つ」を主軸にしたブロック崩しは商業成功していない (DX-Ball 2 / Wizorb 等で部分採用に留まる)
- **推定理由**: 「ボール反射のコア快感」と「能動射撃」の二軸が認知負荷で衝突、ボール反射に集中できなくなる
- **brick_log v09 への含意**: 「パドル射撃機能」枝は不採用 (M-37 で却下軸)

#### E-2. 「敵 HP 多段で長期戦」が主流にならなかった
- **観察**: Wizorb のボス HP は他のブロック崩しと比べ多段だが、シリーズ続編が出ていない (商業継続に至らず)
- **推定理由**: HP 多段だと**反射角コントロール**の達成感が「あと何回当てればいいか」の作業感に置き換わる
- **brick_log v09 への含意**: HP 多段敵 (HP=3+) は採用候補から下げ、**HP=1で軌道変更役**を Arkanoid 本家準拠に

#### E-3. 「リアルタイムでパドルを攻撃する敵」がブロック崩しの主流にならなかった
- **観察**: Krakout は商業中堅、シリーズ化なし。続編で攻撃敵を弱めた作品多数
- **推定理由**: パドルが敵から逃げる必要 → ボール反射のコントロールが甘くなる、コア快感の毀損
- **brick_log v09 への含意**: 攻撃敵 (パドル直接攻撃) は不採用

#### E-4. 「敵を入れずに Power-up + ステージ多様化のみ」が逆に成功した枝
- **観察**: DX-Ball / Holedown / 多くのモバイルブロック崩しは敵を持たず Power-up + ステージ構造で成立
- **推定理由**: 敵がなくてもブロックの配置・破壊条件・Power-up で動的標的化を生成できる
- **brick_log v09 への含意**: **「敵なし枝」を v09 でも候補に残す**。ガイド機構強化 + Power-up 拡張のみで天井を上げる選択肢

### 引き算系5案の明示照合（akiraxtwo 11v11 分析からの適用）

「動かす技術」が commodity 化した前提では、追加で動かす案だけを上位に残すと infrastructure 側の競争に寄る。v09 では以下の引き算系を、敵/ボス追加案と同じ候補空間に明示的に置く。

| 引き算案 | 何を減らすか | v09 への射影 | 採用判定 |
|---|---|---|---|
| 動かないブロック | 敵・ボスの自律移動 | ガイド維持 + 静的特殊ブロックで狙う順序だけを変える | 候補残し。A-1/A-11 系「敵なし」枝と接続 |
| 減速領域 | ボール速度の一様性 | 一部ブロック/敵がボールを遅くし、狙い直す余地を作る | 候補残し。Power-up S / Shatter 重力場と比較 |
| 自機停止で敵停止 | 同時処理量 | パドル停止中だけ敵/降下圧も止め、狙いを読む時間を報酬化する | 保留。テンポ低下と達人プレイ純度を M-37 で審問 |
| 逆方向重力 | 直線反射の単純さ | 一定領域でボールを上方向に戻し、裏抜け予測を延命する | 候補残し。E-14 重力場敵の低密度版 |
| 弾返し | 攻撃の一方向性 | 敵弾/障害をパドル反射で返す。撃つ要素を足さず反射快感に寄せる | 保留。Breakout型をSTG化しないか審問 |

**結論**: v09 の候補空間に「敵を増やす」だけでなく「動きを減らす / 判断時間を作る / 反射だけで返す」枝を残した。採用案セットを決める時、上位10件に入らなくても最低1案は M-37 で理由付き棄却する。

## 7. 採用案セット（相乗効果検討）

単独で良い案より、組み合わせて相乗効果が出る案セットを優先。

### 候補セット A: 「ガイド相互作用 + Power-up」

- **E-12 (ガイド断ち) + E-13 (ガイド延長) + E-10 (Power-up ドロップ)**
- 相乗効果: ガイドが動的に変化 (断つ/延びる) + 撃破報酬で Power-up
- 達人プレイ: 「いつガイドが断たれるか/延ばされるか」を読みに含めて反射角設計
- MPS 実効: P1 ガイド天井 ◎ + P3 報酬 ◎ + P4 ガイド情報過多 ◎ + P7 Power-up軸 ◎ = 4
- リスク: ガイド機構の信頼性低下 (毎回ガイドが変動)

### 候補セット B: 「動的標的 + 撃破報酬」

- **E-8 (分裂敵) + E-9 (連鎖発火) + E-10 (Power-up ドロップ)**
- 相乗効果: 撃破自体が次の撃破を生む (分裂 / 連鎖)、撃破時 Power-up
- 達人プレイ: 「分裂後の軌道」「連鎖の起こし方」「Power-up の取得タイミング」三軸
- MPS 実効: P2 動的標的化 ◎ + P3 報酬 ◎ + P7 Power-up ◎ + P8 上達 ◎ = 4
- リスク: 画面が敵で埋まる、認知負荷

### 候補セット C: 「リスク選択 + ガイド相互作用」

- **E-26 (ペナルティ敵) + E-12 (ガイド断ち) + E-25 (ボム敵)**
- 相乗効果: リスク敵を通過 vs 撃破の判断、ガイドが動的、ボムで範囲効果
- 達人プレイ: リスク管理 + ガイド読み + ボム狙い
- MPS 実効: P1 ◎ + P2 ◎ + P6 能動 ◎ + P8 上達 ◎ = 4
- リスク: 設計複雑、初プレイヤー脱落

### 候補セット D: 「最小構成 = E-10 単独 + v08 既存」

- **v08 既存 (E-1直線降下 + E-2sin揺れ + B-1横振りボス) + E-10 (Power-up ドロップ)**
- 相乗効果: v08 の動的標的化に「撃破報酬」を追加
- 達人プレイ: v08 + Power-up タイミング
- MPS 実効: v08 = 2 + E-10 = 5 → 重複除去 6
- リスク: 最小、Arkanoid 本家直訳

### 候補セット E: 「敵なし枝 = ガイド機構強化のみ」

- **敵を入れず、ガイド機構を 段階的に解放 (1反射 → 2反射 → 3反射)**
- 相乗効果: ガイド精度が上がるごとに「読み」の深さが上がる
- 達人プレイ: ガイド精度に応じた反射角設計
- MPS 実効: P1 ガイド天井 ◎ + P4 情報過多 ◎ = 2 (動的標的化なし、報酬なし)
- リスク: v07 と機能差が薄い、退行候補

|---|---|---|---|---|
| **A** ガイド相互作用 + Power-up | 4 | 中 | 中 (E-12/E-13は新規) | 中 |
| **B** 動的標的 + 撃破報酬 | 4 | 中 | 高 (Pang+Peggle+Arkanoid) | 中 |

## 9. M-39 結果予測（人間プレイ前ゲート、実装前事前予測）

### 起動 30 秒以内の予測

- **0-5秒**: パドル左右移動 → ボール射出 → 上部ブロック反射、v07/v08 と同じ初動。**ガイド機構が表示されている**ことが「読む」コア快感
- **5-10秒**: 敵 (E-1 直線降下) が初出現、ガイドに敵が含まれて軌道予測延伸、ボールを当てて撃破。**30%でPower-upカプセルがドロップ**(初体験のサプライズ)
- **10-30秒**: パドルで Power-up 取得 → 効果発動 (拡張/分裂玉/スロー)、ボール処理が変化、新たな反射角発見。**Power-up タイミング選択**(取得 vs 既存ボール処理優先)
- **30-60秒**: ステージ 2 で敵 E-2 (sin揺れ)、Power-up 連鎖 (連続取得で効果切替)、ステージ 3 ボス (Power-up なし、純粋反射戦)

### 「遊ぶ前にわかること」リスト（コード/設計から予測可能な懸念）

1. **Power-up 落下速度 50px/s が遅すぎ**: パドルで簡単に取れすぎ、緊張感薄い → 自明 → 投下前に再調整 (75px/s で再self-judgment)
2. **拡張効果中もガイドが基準点固定**だとパドル端で取れるはずのボールが取れない錯覚 → 自明 → 投下前に拡張時ガイド更新確認
3. **分裂玉が3個になるとガイドが3本になる**情報過多 → 自明 → 投下前にガイド最大2本表示制限 (主玉+1副玉) を実装
4. **Power-up ドロップ率 30% が低すぎ**: ステージ 1 (敵6体) で平均 1.8 個 → ほぼ取れない → 50% に上げる
5. **敵 HP=1 撃破直後に Power-up が真下から出ると視覚的にぶつかる** → 自明 → 敵位置から少し下にスポーン

### 自明な問題の直し（実装前 / 実装中に潰す）

- (1) Power-up 落下速度 50→75px/s
- (3) ガイド最大2本表示制限
- (4) Power-up ドロップ率 30→50%
- (5) Power-up スポーン位置を敵から下に20pxオフセット
