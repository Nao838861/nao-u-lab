## Nao_u指摘の構造的原因（反対思考より先に良い点を書くテンプレを破る——ここは原因究明が主目的）

### 1. 「相互供述」が相互になっていない原因

**該当箇所**: `ending_mutual` (line 1450-1503) と Phase 3 trigger (`beat_phase_3_trigger`, line 815-988)

**構造の事実**:
- Phase 3 で「正直に答える」を選択した瞬間に、刑事側の供述（"殺していない人間の声だと思った" "信じている"）が**ほぼ完了**している（line 902-904）
- ENDING H に到達した時点で残された語りは彼女側のみ。刑事は黙って受け止める（line 1456-1493）
- `detective_admitted = True` フラグはあるが、ENDING H 内では参照されず、刑事側の追加告白は出力されない

**結果**:
- "相互" 供述という名前だが、実装上は Phase 3 で刑事が一度答え → ENDING H で彼女が一方的に告白する **二段独白**
- Nao_uが期待した「相互＝二人が同時に丸裸になる瞬間」は時間軸上で分散・希薄化
- design.md自身が予言していた「Phase 3 の逆転自体がニンジャテスト的派手要素になっていないか（基盤が薄い）」が的中。Phase 3 trigger が"反転シーン"として機能してしまい、ENDING H は事後の鎮静化になっている

**なぜニンジャに負けるか**: ENDING H 突入時点で「相互」のピーク体験が既に過ぎている。プレイヤーは「ここで何かが起きるはず」と待つが、実装は静かな帰結を提供する。期待と出力のギャップ＝意外性の欠如。

### 2. 「椅子の座り心地が悪い」が機能していない原因

**該当箇所**: `detective_condition` (line 112-122) と各エンディング

**構造の事実**:
- 共犯度40-59 で表示される身体症状。`s.header()` で世界観UIとして並ぶ（共犯度ゲージのテキスト変換）
- 椅子メタファーは Phase 3 trigger (line 844 "椅子のこちら側"), 沈黙ルート (line 982 "椅子の向こう側とこちら側が入れ替わっていた"), ENDING G 共犯 (line 1336 "椅子が小さく軋んだ") で**3回回収**される
- しかし ENDING H には椅子の言及が**ない**
- かつENDING H到達条件 = `detective_admitted=True かつ trust>=50`。共犯度の高低は条件に入らない。共犯度<40 で ENDING H に到達するルートでは、そもそも detective_condition に「椅子の座り心地が悪い」が一度も表示されない可能性がある

**結果**:
- プレイヤーが「椅子の座り心地が悪い」テキストを見ても、それがエンディング体験を分化する材料になっていない＝雰囲気装飾化

**なぜ Nao_u が指摘したか**: 「機能していない感じ」=出てきた割に何にも繋がらないテキストへの違和感。逆に共犯ENDING系で椅子が回収される時には機能感がある（推測：Nao_uは ENDING H 後のレビューで言及している）。

## 次作・改修に活かす設計候補（具体）

### A. ENDING H に "刑事側の固有真実" を追加する（最小改修）
- 彼女の告白に対して、刑事も自分の人生から個人的な真実を返す
- 例: 「実は私も、10年前に同じような取調をした。あの時は突きつけて自白を取った。でも――その人は無実だった」
- → "相互" の語義を実装する。彼女だけが語るのではなく、刑事も語る
- リスク: 刑事のバックストーリーが取って付けた印象になる可能性。design.md Q-C「キャラクターの深み」で予告された刑事側の描写不足を埋める形で書けば自然になる

### B. ENDING H に "もう一つの真実の崩壊" を仕込む（中改修・サプライズニンジャ準拠）
- 彼女が告白した後、刑事が「待ってください」と止める
- 手帳に書いていた**矛盾の最後の一つ**——例えば「指紋」——が、彼女の告白でも説明がつかないことに気づく
- → 第三者の存在 / 時間の食い違い / 別の誰かの介在が示唆される
- ENDING H が「終わり」ではなく「次の謎の入口」になる。ニンジャ＝期待を超える追加情報
- リスク: シナリオの整合性とエンディングの数（8種維持）が複雑化。Phase 4 を仕込むのと同等のコスト

### C. 椅子メタファーの ENDING H 統合
- ENDING H 突入時に、刑事が初めて椅子の座り心地に気づく描写を入れる
- 共犯度に関わらず、"相互"が成立した瞬間に立場が等しくなる→椅子の差がなくなる、を体感装置にする
- 例: 「気がつくと、椅子の座り心地が気にならなくなっていた。彼女と私の椅子の差が、もう存在しなかった」
- 最小コストで M-17 と整合（コンセプト「相互」の快感を椅子で物理化）

### D. ENDING H の発動条件にもう一段ゲートを足す（次作用）
- `detective_admitted` だけでなく、`detective_showed_notebook` も真である時のみ ENDING H に分岐
- → 「正直に答える＋手帳を見せる」の二重コミットメントが ENDING H の前提になる
- 手帳を見せた瞬間に Phase 1〜2 の選択履歴が彼女に晒される＝もう一段の遡及的反転
- リスク: ENDING 数が変わる/分岐ロジックの整合確認が必要
