### 違う切り口の選定（着手前思考）

候補:
1. **GRAZE**（敵弾至近通過でゲージ）：BACKLASH の defensive=0% を構造反転で解く
2. CHARGE（押しっぱなしで充填→解放）：BOMB と機構が近い、差別化が弱い
3. LANE（3レーン切替式）：操作型が違うが快感ループが新規構築になりリスク大
4. REFLECT（弾反射）：STG というよりアクション寄りで M-22「型の中で蓄積」から外れる

→ **GRAZE 採用**。理由:

- BACKLASH headless 観測（C127 Phase 3）で発見した「defensive 3way 0%」問題を**構造的に**解く設計。罰追加（避けるとペナルティ）でなく**報酬経路の追加**（避けると報われる）= `feedback_game_center_of_mass` 圧力設計側
- M-22「型の中で蓄積」遵守: 縦STG というジャンルの型は維持、ゲージ蓄積源だけ反転
- M-25 認知枠組み利用: graze は STG ファンには自明な概念（東方等）。説明不要で「ニアミスで光る」が伝わる
- BACKLASH の auto-shoot / SPACE=BOMB / 段階式被弾 / 区切りで表現 / 一般的UI 等の**学びは丸ごと適用可能**（M-22 適用）
