## 2. M-40 二層分離（追補 2026-05-03）に照らした v02 の罪状

| 層 | v02 で何を書いたか | 何を書くべきだったか |
|---|---|---|
| **自動化可能層** (balance / bug / skill_gap / rule_clarity) | Lv3 到達 0% / 60秒 0% を絶対値として記載 | **AI 質基準を README で先に明記** (例「Lv3 到達は 50% 以上の seed で発生すべき」)、未達なら絶対値を「構造証拠」として書くのを禁止 |
| **厚み層** (コア快感天井 / 「面白い」判定) | 一度も書いていない | mental simulation 30秒録画 / brick_log・avoid_log との快感天井比較 / Cave 系・Touhou との比較で「v02 のコア快感天井」を在庫から自己判定 |

### 厚み層の自己判定を遡及で書く

**mental simulation 30秒録画 (graze_seek policy)**:
- 0-5秒: intro_med 出現、自機の真横を抜ける弾を 1〜2発 graze、ポップアップ +10。**触った感がある**
- 5-12秒: 撃破入って Lv2 候補。だが graze_seek policy は最近接1発しか見ていないので、複数 eb が同時に来ると 12s 前後で死亡（headless 計測通り）。**Lv3 到達せず終わる**
- 12秒〜: AI が死ぬので何も観測できない

**人間プレイ想定（Nao_u 想定）**:
- 0-30秒: 3段階パワーアップに到達するまでは graze 取りに行く（Nao_u 5/4「3段階までは取りに行く」）
- 30秒〜: Lv3 到達後、リスクの高い graze をやる動機が消失 → 普通の STG として遊ぶ → 単調 → 永久に死なない → 飽きて自殺終局（Nao_u 5/4「面倒になってわざと死んで終わらせた」）

**過去自作との快感天井比較**:
- avoid_log: 「避ける」だけで終わる。コア快感天井は明確に低い（Nao_u 評価済）
- brick_log v?? (Log): 反射ガイドで「読んで打つ」の達人プレイ余地が見えた
- graze_log v02: graze の「ギリギリで取る」は触覚があるが、**Lv3 到達後に graze をやる動機が消える** = 達人プレイの上限がパワーアップ完了で打ち切られる構造

→ **v02 のコア快感天井は brick_log < v02 ≦ avoid_log。30秒で天井が見える**。これを v02 出荷前に書いていたら「Nao_u プレイで『単調』『面倒』が出る」は予測できた。

### 自動化可能層 (headless) の罪状再分解

私が v02 README で書いた「Lv3 到達 0% → 構造証拠」「60秒生存 0% → 構造証拠」は、**M-40 二層分離・追補 2026-05-04 で禁止された書き方**そのもの。AI 質基準（「Lv3 到達 50% 以上で発生すべき」相当）を立てずに絶対値を構造証拠として読んだ → AI が下手なだけで「コンセプト完成前死亡」と読んでしまった。

**正しい書き方**:
- ✗ 「Lv3 到達 0% → Lv3 演出が機能していない構造証拠」
- ✓ 「Lv3 到達 0%（AI 質基準未設定 = この絶対値は AI 起因か構造起因か区別不能）」
- ✓ 「graze_seek score 150 vs corner_safe score 30 → graze 軸が *存在する*（差分は AI 質と独立に検出可能）」← 唯一構造的に言えること

## 3. なぜ M-40 を踏まなかったか — 真因

「v02 は装置追加で短いから自己判定要らない」と判断した。**これが間違い**。装置追加でも、その装置の出力を README で「構造証拠」と読んだ瞬間、それは「v02 はコンセプト完成前死亡を引き起こすゲーム」という設計判断の発信になる。発信した瞬間に M-40 は発火する。

**短絡の構造**: 「自己判定 = ゲーム挙動を変えた時に必要」と狭く解釈していた。「**設計判断を発信するすべての瞬間に必要**」が正しい射程。次回からは「README で何かしら設計上の主張を書くなら self_judgment.md 必須」と運用する。
