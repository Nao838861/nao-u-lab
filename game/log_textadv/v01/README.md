## 4ゲート試筆（次作4ゲート契約準拠）

### ゲート1: 一番楽しい瞬間を1文（M-14）

**閉館後の暗い客席を降りて「業務ドア」を開けた瞬間、ロビー側とはまったく違う従業員動線の景色（むき出しの配管、非常灯の青、映写室への狭い階段）が現れる瞬間。**

—— Zork純系として「場の転換」を核に据える。独自メカニクスは持たない。

### ゲート2: 主人公identityシート

- **名前**: 無名（「あなた」）
- **職業**: 特定しない（20代〜30代の会社員を想定、ただしゲーム中に明示しない）
- **世界観**: 現代日本、地方都市のレトロ単館映画館（昭和築）
- **プレイヤー視点との距離**: 1人称・近接。プレイヤー本人と一致する普通の観客
- **開始状態**: 終電直前、最終上映のレイトショーで席でうたた寝 → 目覚めたら館内消灯、スタッフ退社済み、館内誰もいない
- **能力獲得の由来**: 特別な能力なし。所持品は携帯（低バッテリー）、財布、コートのみ

### ゲート3: パラメータ→選択肢マッピング表

| パラメータ | 値 | 閾値 | ロック/unlock対象 |
|---|---|---|---|
| ターン残数 | 5 → 0 | 0 | 警備員見回りで発見、敗北終了 |
| 携帯バッテリー | あり/なし | なし | 「携帯ライトで照らす」選択肢 lock |
| コート所持 | あり/なし | なし | 「センサーを布で覆う」選択肢 lock |
| 業務ドア発見フラグ | false→true | true | 「裏通路を進む」選択肢 unlock |
| 鍵開け成功フラグ | false→true | true | 「非常口から外へ」選択肢 unlock |

**5ターン構成の典型チェイン**:
T1「周囲を見回す」→ 業務ドア発見(フラグtrue)
T2「携帯ライトで業務ドアを照らす」→ 通路内アイテム視認
T3「裏通路を進む」→ 従業員ロッカーで鍵発見
T4「非常口の鍵を開ける」→ 鍵開け成功フラグtrue
T5「非常口から外へ」→ 勝利終了

### ゲート4: 極端プレイ3想定の手動検証

**極端1（最短突破）**: T1「非常口へ直行」→ 鍵がかかっている(unlock条件未達)→ 選択肢グレイアウトで無効/ターン消費のみ → 想定どおり「正解チェインを踏まないと突破できない」。破綻なし。

**極端2（全look消化）**: 全ターン「周囲を見回す」「調べる」のみ選択 → 業務ドア発見までは進むが、T2-T4の能動アクションを取らず T5=ターン残数0で警備員発見敗北 → 想定どおり敗北終了。破綻なし。

**極端3（誤誘導追従）**: T1で非常口を試す→鍵ロック → T2-T3で非常口を蹴る/叩く系の選択肢に流れる → 進展なくターン消費 → ターン残数0で敗北 → 想定どおり「誤誘導は行き詰まる」。破綻なし。

**検証結論**: 3想定全てで設計破綻なし。パラメータ→選択肢マッピングとターン制限が正しく噛み合っている。**opening.md 着手可条件を満たす**。
