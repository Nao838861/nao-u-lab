# log_textadv_01「映画館の閉館後」— オープニング原稿

**設計原則**: 30秒内で「これは脱出ADV」の型認識 + 「なぜここに」の謎フック同時提示。独自要素なし（Zork純系）。

**4ゲート準拠**: ゲート1「業務ドアを開けた瞬間の場転換」を核、5ターン制、携帯/コート/発見/鍵の4パラメータ、極端プレイ3想定破綻なし（README参照）。

---

## Beat 1（0-10秒）放り出し

```
   目を覚ます。

   スクリーンは真っ黒。館内灯は落ち、暗い。
   左肘が肘掛けに食い込んでいる。
   口の端が乾いて張り付いている。

   最終上映のレイトショーだった、と思い出す。
   観客は、もう、誰もいない。

   [残り行動: 5]

   >
```

**意図**: in medias res。「映画館」「閉館後」を説明せず、席で目覚めた身体感覚から始める。**誰もが知っている場所の裏側**だから状況説明が要らない——Zork型の30秒オンボーディングに素直に乗るための題材選定の報酬をここで回収する。「[残り行動: 5]」で脱出ADV型を0秒目に確定。

---

## Beat 2（10-20秒）最初の探索

プレイヤーが `周囲を見回す` を選んだ場合:

```
   暗い。非常灯の緑だけが通路を照らしている。

   - スクリーン側の壁、座席列の右端に、開きかけの扉がある。
     「関係者以外立入禁止」。業務ドアだ。
   - ロビー方向の入口扉は、シャッターが下りている。
     金属の重い気配。
   - 胸ポケットに携帯。バッテリーの赤ランプが弱く明滅。
     コートは隣の席に畳んである。

   [残り行動: 4]

   >
```

プレイヤーが `携帯を確認する` を選んだ場合:

```
   ロック画面。02:47。
   バッテリー残量 4%。
   電波は立っているが、発信する気にはなれない。

   通知は、ない。

   [残り行動: 4]

   >
```

**意図**: 3選択肢（業務ドア/ロビーシャッター/所持品）を最初の探索で可視化。**業務ドアの「開きかけ」**はゲート3マッピング表の「業務ドア発見フラグ」を即トリガーする描写。シャッター側を先に試す誤誘導も成立させる。携帯バッテリー4%は**残りパラメータの温度**——後でライト使用すると切れる伏線。

---

## Beat 3（20-30秒）最初の壁と裏側

プレイヤーが `ロビーへ向かう` を選んだ場合（誤誘導ルート）:

```
   ロビーへ続く通路を進む。
   シャッターの前に立つ。

   金属が冷えている。手をかけて押してみる——
   微動だにしない。

   足元に、警備員の巡回表が貼ってある。
   「次回巡回: 03:00」。

   残り、13分。

   [残り行動: 3]

   >
```

プレイヤーが `業務ドアを開ける` を選んだ場合（正解ルート）:

```
   「関係者以外立入禁止」。
   開きかけの扉に手をかける。軋む音。押し開ける。

   ——ロビー側とは、まったく違う景色。

   むき出しの配管が天井を這い、非常灯の青が壁に落ちる。
   右手に、映写室へ続くらしい狭い鉄階段。
   左手の突き当たりに、非常口の緑サイン。

   従業員動線。
   映画館の、裏側。

   [残り行動: 3]

   >
```

**意図**: ゲート1の「一番楽しい瞬間」を Beat 3 の正解ルートに配置。**むき出しの配管／非常灯の青／鉄階段**の3要素で場の転換を物質化——ロビー側の「観客のための空間」と対極の「機能のための空間」を対比で見せる。**この beat で得られる景色のためだけにこのゲームは存在する**、と言い切れる密度で書く。

誤誘導ルートの「残り13分」は、パラメータ「ターン残数」の物語的翻訳。時計回りのメタファーで残量感を出す。

## 23:17チェックリスト確認（Nao_u 2026-04-17 指示）

1. ✅ 既存の型: Zork系脱出ADV（Beat 1 で「[残り行動: 5]」提示、Beat 2 で3選択肢可視化）
2. ✅ 謎フック: 「なぜ寝過ごして起きられなかったか」「映写室への階段の先」は Beat 4以降で回収余地
3. ✅ 記憶テーマなし: 「記憶」「断片」「物語が立ち上がる」を持ち込まない——Beat 1-3 の温度を確認した
4. ✅ 独自要素: 入れない。Mir v02 と同じ Zork純系構造
5. ✅ 認知の裏切り/信頼できない語り手: 主役に置かない
6. ✅ 冒頭3秒: Beat 1 の3行で「暗い映画館の席で目覚めた」を完成
