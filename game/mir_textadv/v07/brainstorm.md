## 0. 主軸宣言: 第二層（感情整合性）主軸を取る

C158 Phase 2 で #32 punsukabooks（小林靖子→ジョジョ脚本）と #46 denfaminicogame（サーガ＆シーカー）を統合分析した結果として、v07 の最初の設計判断を以下に固定する。

| 軸 | 第一層主軸（設定整合性をAIが保持） | **第二層主軸（キャラの譲れない筋をAIが保持）** |
|---|---|---|
| 中核 | 設定・年表・能力の論理的一貫性 | 各キャラの譲れない筋（3行以内で書ける核） |
| プレイヤー体験 | 無限ロールプレイ／組み合わせ | 感情の筋の発見・照合・突きつけ |
| 失敗モード | キャラが薄まる | フラグが破綻する（が許容） |
| 型としての成熟度 | 商業展開中・競合多数（サーガ＆シーカー他） | 脚本術として確立・ゲーム実装は希少 |
| Mir 既存資産との親和性 | 低 | 高（concept_graph・連想記憶は感情軸で動く） |

**根拠**:
- 小林靖子「設定に矛盾はあってもキャラの感情に矛盾がなければ問題なく読める」（出典: ジョジョ脚本論）
- nyaa_toraneko「2000年代以降フラグ管理破綻＋ユーザー分岐疲れ」（外部裏付け）
- feedback_shuhari_clone_first.md「型通りのものすら面白く作れていない」→ 型 = ジョジョが体現する「キャラの筋を最優先する書き方」
- M-17 サプライズニンジャ理論 = 第二層の局所適用。小林靖子は同じことを脚本術全体で先行。

**v07 で却下する案（再掲）**: 第一層主軸での無限ロールプレイ、共犯END延長、第N章メタ枠、視点遷移2段以上、プレイヤー精読強制。

## 1. 比較対象12本（第一層型／第二層型／混合型を意識的に混ぜる）

数値10-15本は下限。各エントリは「何を借りるか／借りないか」を1行で固定し、後段でブラッシュアップする叩き台。

### 第二層型（感情整合性主軸 — 主に借りる対象）

1. **逆転裁判**（カプコン）— 借: 矛盾を引き出して突きつける即決リズム、章末「次の証言が嘘か本当か」の引き。借りない: 法廷劇の章跨ぎ伏線、声優演技。devlog C149 Q-taste 通過済。
2. **Her Story**（Sam Barlow）— 借: 供述ビデオの照合 = 感情整合性の発見をプレイヤー側に委譲する設計、検索キーワードでの非線形進行。借りない: 実写映像、データベース検索UI（テキストのみで再構成）。
3. **Disco Elysium**（ZA/UM）— 借: スキルチェック失敗が物語を駆動する設計、内なる声=キャラの譲れない筋の擬人化。借りない: スキル木の規模、CRPG装備系。
4. **Tangle Tower**（SFB Games）— 借: 容疑者全員の供述を相互照合する構造、容疑者ごとに「譲れない筋」が明確。借りない: イラスト演出への依存。
5. **13 Sentinels: Aegis Rim**（Vanillaware）— 借: 13人の視点切替で感情整合性を多層化、章末フックの密度。借りない: SLGパート、世界観の壮大さ（v07 は単発取調セット粒度）。
6. **Obra Dinn**（Lucas Pope）— 借: 部分情報から全体像を推論する快感、推論が間違っていても進行可能な設計。借りない: モノクロビジュアル、60名規模の人物管理。
7. **428: 封鎖された渋谷で**（チュンソフト）— 借: 複数人物の視点が時間軸で交差する構造、選択がキャラ感情に直結する瞬間設計。借りない: 実写ノベルADVのフォーマット、TIPS過剰。

### 第一層型・AI管理型（差別化のため理解する対象）

8. **サーガ＆シーカー**（denfaminicogame記事より、AI TRPG）— 借: AIに「設定の重荷」を丸投げする発想（Mir のメモリ階層との親和）。借りない: 第一層主軸そのもの、無限ロールプレイ路線。**比較軸として最重要、別サイクルでデモ動画/レビュー記事を external_notes_mir.md へ取得予定**。
9. **AI Dungeon**（Latitude）— 借: LLM ベース自由分岐の限界事例として研究。借りない: フラグ管理放棄、キャラの一貫性が薄れる失敗モード。
10. **Suck Up!**（Proxima Enterprises）— 借: LLMキャラとの会話でゴール達成する設計、説得という単一動詞で深さを作る。借りない: VRチックUI、ゴア/コメディ路線。

### 混合型・参照価値あり

11. **Outer Wilds**（Mobius Digital）— 借: プレイヤーの「知識」が進行のフラグになる設計（フラグ管理を裏方化）、22分ループの章リズム。借りない: 3D探索、宇宙SF設定。

## 2. 12本から抽出した「第二層主軸で v07 が借りるべき4つの素材」

各12本を横断して「v07 取調1セット粒度」に落とせる素材を抽出。

1. **譲れない筋の事前定義**（Tangle Tower / Disco Elysium / 13 Sentinels）— 被疑者1名につき「絶対に守る信条 / 絶対に譲れない関係 / 絶対に隠したい過去」の3項を3行以内で先に書き、フラグ表より上に置く。
2. **矛盾の外発露出ロジック**（逆転裁判 / Her Story）— 被疑者の供述に「譲れない筋」と整合しない発言を1点だけ仕込み、プレイヤーが掴むまで進行は止めない（ただしページターナー的フックで誘導）。
3. **章末の引き＝筋の揺らぎ予告**（13 Sentinels / 428）— 取調セット末尾は「次に被疑者の譲れない筋が試される」予告で締める。物証出現や信頼変動はその出力装置。
4. **失敗の許容**（Disco Elysium / Obra Dinn）— プレイヤーが矛盾を掴み損ねても進行する。失敗が「別の譲れない筋が浮上する」契機として機能する設計。

## 3. v07 取調1セット最小単位（実装レベルへの橋渡し）

devlog §3 の L-1 脚本術3本（ページターナー / 情報非対称性 / scene/sequel）と本 brainstorm の「第二層4素材」を合流させた最小単位:

```
[シーン]
  目標: 被疑者Xの譲れない筋（例: 弟は無実だと信じている）を引き出す
  衝突: 被疑者Xは譲れない筋を直接語らない。供述の中に矛盾の種が混ざる
  結果: プレイヤーは矛盾を掴むか/泳がせるか判断 → 信頼ゲージ変動

[シークエル]
  反応: 被疑者Xの一瞬の動揺 / 場の緊張変化（1-2行）
  ジレンマ: 次に何を聞くか（選択肢2つ、ただし両方とも前進）
  決断: プレイヤー選択 → 次シーンの目標が決定

[章末フック]
  最終1行で次セットの予告（被疑者Xの譲れない筋が次セットで試される / 新しい物証 / 信頼ゲージ閾値接近のいずれか）
```
