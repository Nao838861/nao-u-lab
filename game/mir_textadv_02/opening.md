# mir_textadv_02「脱出」— オープニング原稿

**設計原則**: 30秒内で「これは脱出ADV」の型認識 + 「なぜここに」の謎フック同時提示。

---

## Beat 1（0-10秒）状況の放り出し

```
   目を開ける。
   真っ暗。

   床は冷たく、石のような感触がある。
   右手に何か握っている——冷たい金属。小さい。
   遠くで、規則的な滴の音。

   [制限時間: 60ターン]

   >
```

**意図**: Zork型の in medias res 開始（説明なし、状況だけ）。制限時間を即提示することで「脱出ADVの型」を0秒目で確定させる。手に握った「小さい金属」と滴の音は次beatのフック。

---

## Beat 2（10-20秒）最初の探索

プレイヤーが `look` を入力した場合:

```
   闇に目が慣れてくる。
   ここは狭い部屋だ。石壁、石床、天井は見えない。

   - 北側の壁に、鉄の扉がある。鍵穴が一つ。
   - 東の隅に、水が溜まっている（滴の音の源）。
   - 握っているのは、小さな真鍮の鍵のようだ。

   [残り: 59ターン]

   >
```

プレイヤーが `examine key` を入力した場合:

```
   真鍮製の小さな鍵。古い。
   持ち手のところに、数字が刻まれている——「3」。

   [残り: 59ターン]

   >
```

**意図**: 最初の探索で選択肢が見えるようにする（扉・水・鍵）。ただし「鍵を扉に使う」だけでは解けない仕掛けを隠す（「3」の意味は解釈余地）。

---

## Beat 3（20-30秒）最初の壁

プレイヤーが `use key on door` と入力した場合:

```
   鍵を鍵穴に差し込む。
   回らない。鍵穴の形は合っているが、何かが足りない。

   鍵穴をよく見ると、内側に小さな文字が彫ってある——
   「第三の鍵を差せ」。

   [残り: 58ターン]

   >
```

**意図**: 30秒時点で「鍵1本では足りない」という制約を突きつける。ここからが本番——プレイヤーは部屋の中で「第二・第三の鍵」を探す（水の中、天井の闇、etc.）。残り58ターンという具体数字で「時間との勝負」の型認識を完成させる。
