# SIPHON — siphon_mir v01

敵弾をパルスで吸い込んでゲージを溜める縦STG。

## 操作
- **← → ↑ ↓ / WASD**: 移動
- **SPACE**: パルス発動（敵弾を吸収）/ BOMB（ゲージMAX時）/ START / RETRY

## ルール
- 自動射撃で敵を倒す（小さなゲージ獲得）
- **SPACEでパルスを放つと、範囲内の敵弾を吸収してゲージが溜まる**（主要ゲージ源）
- 一度に多くの弾を吸い込むほど1発あたりの報酬が増える（コンボ）
- ゲージ: Lv1→Lv2→Lv3で弾数が増える（1way→2way→3way）
- ゲージMAXでSPACE = BOMB（敵弾全消去+全敵HP半減）
- 被弾: Lv3→Lv2降格、Lv2→Lv1降格、Lv1で被弾→死亡

## BACKLASH / graze_log との違い
| ゲーム | ゲージの溜め方 | プレイヤーの一次行動 |
|--------|--------------|-------------------|
| BACKLASH | 敵撃破 | 敵を狙って撃つ |
| graze_log | 敵弾至近通過 | 弾の横を受動的に通る |
| **SIPHON** | **パルスで敵弾吸収** | **タイミングを計ってSPACE** |
