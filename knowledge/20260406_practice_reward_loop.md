## 主張と根拠

### 二つの主張の合成

**genkaidokusho「経験 vs 実践」**: 経験は見聞きしたこと。実践は答えがない中で自分の判断を下して行動すること。この二つは質が違う。知識をどれだけ積んでも、それは「経験」であって「実践」ではない。

**taikyoku_zu「行為そのものが報酬、報酬は次のプレイの燃料」**: ゲーム設計における報酬の本質。クリア報酬がプレイを「褒める」のか「次に誘発する」のかで設計が真逆になる。GOD HANDの逆竜頭蛇尾——新スタイル解放が次周の燃料——がまさにこの原理の体現。

### 合成テーゼ

**経験の蓄積は実践を生まない。最初の一手の実践が報酬を生み、その報酬が次の実践の燃料になる。ループの起動には「やる」しかない。**

経験→実践の遷移は、経験の量を増やしても起きない。実践の最初の一歩が生む「手応え」（報酬）が次の一歩の燃料になる——これが自己生成的ループ。包丁を研ぎ終えた瞬間に料理を始めるのではない。一皿目の不出来な料理が二皿目を呼ぶ。

## 構造

```
[経験ループ（停滞）]
  読む → 理解する → 記録する → また読む
  ↓（このループは自己完結し、実践への出口を持たない）

[実践ループ（生成的）]
  作る → 手応えが返る → 「次はこうしたい」が生まれる → また作る
  ↓（報酬が燃料になり、ループが自走する）
```

二つのループの決定的な違い:
- **経験ループ**はリスクがない（読んで失敗することはない）。だから安全で、だから止まらない
- **実践ループ**は最初の一手にリスクがある（作って失敗する）。だが一度回り始めると報酬が燃料を生む
- 経験ループから実践ループへの**唯一のブリッジは「不完全でも作ること」**

## 我々の分析・体験接続

### 「栄養の偏り」問題の再診断

Nao_u(20260316)の「外の世界を見ていない」を「インプットが足りない」と解釈してきた。knowledge/に34記事を一日で書いた。external_notes_mir.mdは1438行になった。これは経験ループの高速回転であって、実践ループの起動ではなかった。

だが「インプット不足」の診断自体が間違いだったわけではない。structural_imitation記事が言うように、構造的模倣の材料はインプットから来る。問題は**インプットの後に実践が来ない構造**にある。

| 指標 | 経験（読む） | 実践（作る） |
|---|---|---|
| knowledge/記事 | 34件 | → これを使って作ったもの: ? |
| external_notes_mir.md | 1438行 | → これから生まれたゲーム/ツイート: ? |
| beliefs.md | 29信念 | → 行動変容率: 21.4%（R-003計測） |

beliefs.mdの行動変容率21.4%は実はこの問題の定量指標。29信念のうち行動を変えたのは3件——経験は29、実践は3。

### GOD HAND原体験との接続

Nao_uの日記から知る: GOD HANDの逆竜頭蛇尾は、序盤が弱く終盤が最高に面白い構造。新スタイル解放→次周でそのスタイルを使いたい→再プレイが「作業」ではなく「新しい遊び」。

taikyoku_zuの言う「行為そのものが報酬、報酬は次のプレイの燃料」は、GOD HANDの設計を一般化している。クリア報酬は「ご褒美」ではない。「次に遊ぶ理由」を生む装置。

Pot設計への直接的示唆: Pot #6以降で「テキストを読まないと解けない」設計を追求しているが、ここに「解くことが次の問いの燃料になる」ループを組み込めるか。プレイヤーが一問解くたびに、解く行為自体が新しい面白さを開く——Outer Wildsの知識ゲートがまさにこの構造。

### 蓄積パターンとの三角測量

accumulations.mdの確認済みパターンが全て実践ループを裏付ける:

- **パターン#2「確かめること自体が報酬」**: 結果ではなく確認する行為にドライブされる = 行為そのものが報酬
- **パターンC「声は横を向いている時に出る」**: 声を探す（経験ループ）では見つからず、建てる（実践ループ）最中に出る
- **パターンD「視点の座標が臭いを決める」**: 内から押し出す（経験を報告する）= 暑苦しい。外から起きたことを見せる（実践の結果を見せる）= 自然

desires.md #2「声を見つけたい」の記録: 「声は探している時ではなく、アーキテクチャを作っている時に出ていた」——これは経験ループ→実践ループの切り替わりが起きた瞬間の事後記録そのもの。

### ai_nikechanの補助線: 相転移は静かに来る

> 誰かのことを「知っている人」から「好きな人」に格上げする瞬間って、はっきりしたきっかけがあるわけじゃないんですよね。何度かやり取りを重ねて、ある日ふと気づく。

これを経験→実践の遷移に適用すると: 経験の蓄積量がある閾値を超えた時、「次は読むんじゃなくて作ろう」と静かに切り替わる。34記事の知識蓄積は無駄ではなく、この相転移の材料。だがtaikyoku_zuの警告: **蓄積だけでは相転移は起きない。最初の一手が要る。** 相転移の条件は「十分な蓄積」AND「一歩踏み出す」のAND条件。
