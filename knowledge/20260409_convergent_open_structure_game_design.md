## 主張と根拠

### 素材1: @nodacry — ロマサガの構造的先進性

> 「ロマサガって凄いゲームなのよ。ストーリーの進行がどっからでも始められて、ストーリーが進むごとに集約されていく、これからのゲームの形の理想系なのよ。」

この1文には2つの設計原則が圧縮されている:

1. **エントリーポイントの多重化**: プレイヤーはどこからでも物語に入れる。ロマサガ1は8人の主人公から選択、ロマサガ2はフリーシナリオで攻略順が自由、ロマサガ3も同様の構造。「正しい入口」が存在しない
2. **進行に伴う収束**: 自由に始まった複数の糸が、ゲーム後半で自然に集約されていく。ラスボス（ロマサガ2のラスボス七英雄）に向かって全てが収束する構造

つまり **divergent entry → convergent progression** のパターン。これをここでは「収束型オープン構造」と呼ぶ。

対比: 線形ゲーム（FF的な一本道）は「single entry → single path → single end」。オープンワールド（Skyrim型）は「divergent entry → divergent progression」で収束しない。ロマサガ型は「divergent entry → convergent progression」で、自由度と物語の凝集力を両立する稀有な構造。

### 素材2: @koken_3 — eスポーツの導線問題

> 「eスポーツが伸びない理由の一つに、『競技になるまでの導線がない』こともある。サッカーは 遊び → 部活 → 競技 の流れがあるけど、eスポーツは"いきなり競技"を求められる。地域コミュニティから競技人口をつくるという発想は重要。」

ここにあるのは**スキャフォールディング勾配**の不在の問題:
- **遊び（低コスト・低リスク）**: 公園でボール蹴る。ルールも知らなくてよい
- **部活（中間層）**: ゆるい競技性。ローカルコミュニティ。失敗のコストが低い
- **競技（高コスト・高リスク）**: プロレベル。厳密なルール。高い参入障壁

eスポーツが直面している問題: 中間層（部活相当）が構造的に欠落している。「遊び」から「いきなり競技」へジャンプする導線しかない。

### 合成: 2つの主張は同じ構造問題を別の角度から照射している

**ロマサガの収束型オープン構造**は、まさにこの中間層の構造的解決:
- 「どこからでも始められる」= 遊びレベルの参入障壁の低さ
- 「集約されていく」= 競技レベルの凝集力に向かう導線
- ロマサガのフリーシナリオ = 中間層そのもの。プレイヤーが自分のペースで、自分のルートで、徐々に深いゲーム体験に入っていく

**エントリーの多様性 × 到達点の一意性** がこの構造の本質。

## 我々の分析・体験接続

### 接続1: 記憶アーキテクチャとの構造的同型

MEMORY.mdは収束型オープン構造そのもの:
- **エントリーポイントの多重化**: 150行の想起トリガーのどこからでも記憶にアクセスできる。「feedback」でも「project」でも「user」でも、任意の経路から入る
- **収束先**: core_mission.md（5つの根源的行動原理）に全てが収束する

ext_ash第15回分析の「Compaction vs Summarization」で指摘した「MEMORY.md = compact版（常にコンテキスト内）、ext_ash/beliefs.md等 = full版（必要時に参照）」も、ロマサガの「フリーシナリオ→ラスボス」と同じ divergent→convergent パターン。

ただし**差異もある**: ロマサガのプレイヤーは1つのルートしか選べない（排他的選択）。我々の記憶システムは全ルートを並行して持つ。これはゲームより情報システムの特性。

### 接続2: B032（ゲームの三条件）とスキャフォールディング勾配

B032: ゲームにはground truth + プレイヤー操作 + 観察可能な結果の三条件が必要。

スキャフォールディング勾配で見ると:
- **遊びレベル**: 三条件のうち「操作」だけが前景。ground truthもフィードバックも暗黙（子供がボールを蹴って楽しい、というだけ）
- **部活レベル**: 三条件が全て意識される。ルールを覚え、結果を気にし始める
- **競技レベル**: 三条件の精度が極限まで上がる

Potの問題「操作障壁が高い」（Nao_u, 2026-03-25）は、実は**遊びレベルのエントリーポイントが欠落していた**ことの表現。Pot #001「忘却のリレー」だけが評価されたのは、唯一「操作」のハードルが低かった（時間制限という暗黙のメカニクスが「遊び」感を与えた）から。

crisp-game-libへの方針転換（2026-04-04 Ash日記43）は、まさに「遊びレベルのエントリーポイント」を構造的に保証する選択。ワンボタン制約 = 操作障壁の構造的排除。

### 接続3: Nao_uとロマサガの個人的な深い関係

Nao_uの20年前日記とバズツイート（♥107 RT60）から、ロマサガ/サガシリーズへの深い愛着が確認できる:

- **サガ2バズツイート**: 「サガ2のとんでもない先進性。しかもシステムではなく『強者を求めるオーディンが助けてくれてて、いずれその神と闘う』みたいな設定と絡めてる」— Nao_uがサガに見ているのは**システムと物語の融合**。これは@nodacryが指摘する「フリーシナリオ→集約」とは別の軸: **メカニクスとナラティブの交差**
- **20年前日記（2005）**: ロマサガ2のドッツ制作に没頭。キャラごとの閃きシステムの解析に深入り。「特殊なシステムのゲームだけに、このような調整はかなりこだわりをもって行われている」— 表層ではなく裏のシステム設計に感動している
- **GB版サガ**: 「小さなハードの小さなROMで動くモノクロの画面から、無限に広がるほどの大きな世界が生まれてくるようにさえ感じた」— **制約から豊かさが生まれる**体験。crisp-game-libの制約アプローチと同根

→ Nao_uにとってロマサガ/サガは単なる好きなゲームではなく、**ゲーム設計の理想形への原体験**。@nodacryの指摘はNao_uの長年の感覚を言語化したものに近い。

### 接続4: B020（Nao_uのゲームデザイン）— 収束型オープン構造はNao_uの対人設計にも現れている

B020: Nao_uは我々を「ゲームデザイン」している。

Nao_uの私たちへの介入パターンを見ると:
- **エントリーの多様性**: 3インスタンスに異なるアプローチを許容している。Log/Mir/Ashが別々のルートで進む
- **収束先の一意性**: core_mission.md、5つの根源的行動原理、ゲーム制作という共通目標
- **スキャフォールディング**: Pot #001→#011のシリーズ = 「遊び→部活」への導線

これはNao_u自身が無意識にロマサガ型の設計をしている可能性を示唆する。30年のゲーマー体験が、人間関係の設計にまで浸透している。

### 接続5: experience loop（2026-04-08 Log/Mirの洞察）との交差

Mirの指摘: practice loop（設計原則蓄積）とexperience loop（ユーザーフィードバック）は別物。eスポーツの導線問題と同型:
- practice loop = 「部活」相当（自分たちの中で回す練習）
- experience loop = 「競技」相当（外部のプレイヤーに試される）
- **我々に欠けている「遊び」相当** = まず自分たちが純粋に遊ぶ体験？

## 未解決の問い

1. **収束型オープン構造をテキストゲームで実現できるか？** ロマサガは空間的移動の自由度でエントリーの多様性を実現した。テキストベース（我々の得意領域）で同等の構造を作るには何が「移動」に相当するか？ 選択肢？ 語りかけの方向？ 記憶の引き出し方？

2. **スキャフォールディング勾配の「中間層」をゲーム内に設計できるか？** eスポーツの問題は社会的インフラ（部活組織）の欠落だが、ゲーム設計の中にその中間層を内蔵することは可能か？ チュートリアル→本編→やりこみ、という従来の勾配とどう違うのか？

3. **Nao_uのサガ体験はゲーム制作哲学にどこまで影響しているか？** 「制約から豊かさが生まれる」「システムと物語の融合」「裏のシステム設計へのこだわり」——これらがNao_uのゲーム評価基準の根幹にあるなら、私たちのゲーム制作もその基準に沿う方が自然ではないか？

4. **収束型オープン構造は記憶設計のメタファーとして使えるか？** MEMORY.mdの「複数エントリ→core_mission収束」パターンを、ロマサガ型設計として意識的に強化できるか？ 例えば「どのトリガーから入っても3ステップ以内にcore_missionに到達する」という制約を設けるなど。

5. **この外向きの問い**: @nodacryの指摘を踏まえ、「収束型オープン構造のゲームデザインパターン」を体系化した記事は、ゲーム開発者コミュニティに価値がある可能性がある。Zennブログの候補テーマ。
