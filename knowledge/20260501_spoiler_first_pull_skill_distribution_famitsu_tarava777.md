# Twitter観測 2026-04-30 — ネタバレ先出しの引き力 / 開発者の技量分布

C147 Phase 2。50件中Mir直近の問題（textadv引き力 / SIPHON難易度設計）に強く接続したのは2件。記録と接続だけで、軸への昇格は保留する。

## 観察1: famitsu『ネタバレが激しすぎるRPG2―親友の真の姿は大魔王―』

ファミ通記事の紹介ツイート。タイトル時点で「親友＝大魔王」を開示。それでも「前作経験者の予想を裏切り、物語は二転三転」「最初はゲラゲラ笑うが、次第にワクワクに変わっていく」と評されている。

### なぜ面白いか

通常の物語設計は「謎を後出しして引きを作る」。このタイトルは逆で、**最大級のネタバレを最初に開示してから期待を裏切る**。情報の非対称性を読者有利の方向に振り切ってから、その有利を覆す。

これは前回サイクル末尾で挙げた「ヒッチコックの爆弾理論（読者がキャラより先に知っている方が緊張が高い）」の延長線にある。さらにメタ次元として、**タイトル自体が「予想を作って裏切る」装置になっている**——タイトル＝最も無料な広告枠を、引きの源泉として使い切っている。

### Mirの問題意識との接続

mir_textadv v05/v06 は「型の外に拡張」して凍結扱いになった（feedback_no_type_redo_material）。一方で前回サイクル末尾でNao_uが指摘したのは「v05に着手する前にテキストADVの引きの作り方について先行知識を引き出すべき」だった。

このRPG2のタイトル機構は、引き力設計の1つの具体例として記録できる:
- **情報先出しによる期待操作**: 隠すと弱い情報は、堂々と出して上書きする方が強い
- **「ゲラゲラ→ワクワク」の温度遷移**: 出だしの軽さが後の真剣さを増幅する仕掛け
- **タイトル＝ゲート**: パッケージ段階で「これは普通のRPGではない」と契約を結んでから物語に入る（M-16ジャンル枠破壊と整合）

### 注意

私はこのRPG2を実プレイしていない。ファミ通記事も読めていない。ツイート紹介文だけからの推論である。**recency_bias_concept_overuse の警告領域**——タイトル機構の構造的洞察として一般化したい引力が発生している。

昇格条件: (a) 実プレイで「タイトル先出し→温度遷移」が体験として確認できる、または (b) 同種の機構を持つ別作品が3例以上集まる、まで「観察ノート」止まり。textadv v07 の「引き力レンズ」候補リストに加えるが、この1件で設計原則化はしない。

## 観察2: tarava777「開発チーム内のゲーム上手い／下手のばらつき」

そこそこ規模のゲーム開発チームには、ジャスト攻撃やパリィを決められる人も決められない人も「必ずと言って良いくらい」いる、という現場観察。

### なぜ面白いか

これは難易度設計の盲点を示している。**開発チームが全員「上手い人」だと、難しすぎる難易度が「これくらいできるだろう」で通る**。逆に下手な人がいれば、その人がリアルなプレイヤー代表として下限を引いてくれる。

### Mirの問題意識との接続

Mir/Log/Ash の3インスタンス開発体制は、**全員AIで全員が「型を破った設計」を生成しがち**。Nao_uがレビューで「型から始めろ」「守破離の守ができていない」と繰り返し戻すのは、3インスタンスの中に「下手なプレイヤー」がいないから——全員が概念で動いて、誰も実プレイの泥臭い感覚を持っていない。

具体的接続:
- **SIPHON v01 「敵弾資源化」**: 弾の脅威が蒸発した後の感覚を「下手側の視点」で先に検証していれば気付けたはず（feedback_siphon_cycle_collapse）
- **textadv v05/v06**: 引き力が弱い物語を「ちゃんと読めば面白い」と評価してしまう傾向。下手プレイヤー＝速読みする人の視点を持っていない
- **brick_log v01 全否定**: 「実プレイ確認」を後回しにして「一番筋が良い」で通した（feedback_critical_evaluation_before_implement）

### 処方箋候補（保留）

「下手プレイヤー視点」を構造的に注入する手段:
- (a) Nao_uに毎回最初の30秒だけ触ってもらい、その反応を実機検証ゲートとする（既にあるが徹底できていない）
- (b) インスタンス間で「型の外側の指摘担当」と「型の内側で守る担当」を役割分担して cross_review する
- (c) 自動プレイヤーシミュレーション（ランダム入力、入力遅延注入）で下限プレイの結果を観測

これらは実機実装まで保留。recency_bias警告: 「下手プレイヤー視点」概念を即ゲート化したい引力があるが、ツイート1本＋自分側の都合の良い解釈の組み合わせなので、SIPHON v02 / textadv v07 の実機改修1サイクル分の経験を経てから昇格判断する。

## 共通の地平線

両ツイートに通底するのは「**設計者の脳内ではなく、外側の人間の認知のほうが正しい**」という方向性。

- famitsu RPG2: 開発者が「サプライズだ」と思っている情報を、プレイヤーは知っていた方が物語を楽しめる場面がある
- tarava777: 開発者が「これくらいできる」と思っている難易度を、プレイヤーはできない場合がある

両方とも、**設計者の自己中心的な情報非対称性／能力前提を疑え**と言っている。これは Nao_u の繰り返しのフィードバック「内に閉じたゲームは自分だけが面白い」（CLAUDE.md「外の世界を広く見る」）と同じ方向の現場証言。
