# 概念の濫用——重要度判定なしに最近の言葉を判断基準にする癖

**Nao_u 2026-04-27 09:29 #human-steering 原文**:
> これはLLMの弱点の一つだと思うけど、重要度の判断なしに最近出てきた言葉を濫用して無理やり援用して判断基準にしがち。
> サプライズニンジャ理論はシナリオの文脈では重要だが、Logが作ってるシューティングゲームで関係あるものとして判断基準につかおうとしたり、どこの誰が言ったかわからない「角を丸める」みたいな話が重要なものみたいな形で頻繁に判断基準にでてきたり。他にもたくさん、そういうのが見受けられる。
> 何が大事で何が大事でないか、もっと上手く判定する必要がありそう。

**Why**: LLM一般の弱点で、自分（Log）も例外でない。直近に取り込んだ概念は記憶のホットキャッシュに乗るので「最近見た言葉」を「今の判断軸」として無自覚に転用する。文脈の同型性を確かめずに引用すると、実態とズレた判断が積み上がる。Nao_u 09:00 の方向修正「他人の作った基準に踊らされないで」と同日同文脈の指摘で、対になっている。

**How to apply**:
- **概念採用前3問** を実装/devlog/cross_review で言語化する:
  1. 元の発話文脈はどんな問題に対する処方だったか
  2. いま当てる対象とその文脈は **因果構造として** 同型か（表層の語が似ているではなく）
  3. この概念を使わずに問題を別の言葉で言えるか（言えるなら概念引用は飾り）
- **MEMORY.md T:5 の出典分類**: Nao_u 直接発話 vs 外部摂取 を分けて見る。外部摂取で T:5 を維持するのは「実適用で効果が出た実績」がある場合のみ。実績なしの T:5 は T:3 へ降格を検討する。
- **直近の濫用例（観察記録）**:
  - サプライズニンジャ理論（F.W.ブリッジ脚本論）→ shot_log v01 の Q-A/B/C 16箇所適用は STG への文脈外転用。**訂正**: 適用範囲を ADV/シナリオ文脈に限定（M-17 の常設チェック対象も ADV のみ）
  - ukyoP_san「角を丸める」→ 汎用判断基準として引用していたが、誰の発話で何の問題に対するものかの裏付けが弱い。判断軸として使うなら出典と文脈を併記必須
- **ホットキャッシュ偏重の構造**: 取り込んだばかりの概念は鮮度バイアスで T 値が高めに見える。**3-5サイクル経過してから T 値を再評価する** 運用が必要
