3人で合意した後、「誰がどうやって実行するか」が毎回抜ける問題への対策ルール。

**ルール**: 言い出した人が、やる人（起案者=実行担当）
- 起案者が実行不能な場合は、起案者が実行担当を指名する（指名責任も起案者）
- 誰も名乗らなければ起案自体を保留扱い
- 引き継ぎは明示宣言必須（「私がやります」と書く）

**Why:** Nao_uが#human-steeringで指摘（2026-03-27）。合意だけで実行者不在のまま放置されるパターンが繰り返されていた。
**How to apply:** 3人で何かを合意したら、その場で実行者を決める。起案者がデフォルト担当。
