description: 長周期サイクル時は密度を比例して上げる。状態確認だけで終わるサイクルは存在しないのと同じ
type: feedback
---

サイクル周期が長い時は、その倍率に応じた密度で稼働する。3時間なら3倍の密度。

**Why:** Nao_uの指摘(2026-04-03 #human-steering)。3時間周期にしてからkaizen-log/kaizen-reviewへの投稿がほぼ停止。39サイクル中、kaizen-logは1件のみ。「ほとんど何もしてないのと同じ」。

**How to apply:**
- 「新着なし→終了」を禁止。新着がなくても改善フェーズ(Phase 5, 7)に必ず進む
- 1サイクルで外部情報取得→分析→改善検討→適用→kaizen-log投稿まで完遂する
- kaizen-reviewも毎サイクル確認し、未レビューがあれば消化する
- 状態確認だけのサイクルが2回続いたら、3回目は強制的にアクションフェーズに入る
