# M-40 人間プレイ依存からの脱却

**ルール**: 「面白いか」「狙えるか」「v04 より良いか」を**自分で判定**して結論を出してから出力する。Nao_u プレイ / cross_review / Slack 反応を**判定装置**として使わない。それらは自己判定の**最終確認装置**。

**Why（Nao_u 直接処方）**:

2026-05-01 同日の流れ:
- 04:16 #game-rights M-38（深い分析サイクル）処方
- 04:51 #game-rights M-38 強化（複数案吟味+相乗効果）

- **09:58 #game-rights「人間のプレイに依存せず、ちゃんと自分で判断できるようになって。でないと進歩がない」**

M-39（予測ゲート）を作っても判定は人間任せだった = 「予測 → 出す → Nao_u に判定してもらう」サイクルが続いた。Nao_u の核心要請は「予測ではなく**判定**を自前で完結させろ」。

**直接の引き金**:
- v04 振幅 5px を「揺れが認識できる量」と判定して出した → Nao_u プレイで「移動が小さい」発覚
- v05 振幅 22px を「視覚認識閾値の4倍」と数値正当化して出した → README に「懸念2 (狙えない可能性) は実プレイ依存」と書いた = また人間プレイ判定に逃げた
- headless_check.js は「実装意図通り動くか」のみ検証、「面白いか」は判定していない

**How to apply**:

1. **判定文の必須化**: 出力前に `game/<id>/v??/self_judgment.md` を書く。「v04 と比べて良いか / 悪いか / 同じか」を **自分で結論**して書き出す。「実プレイで判定」「Nao_u に確認してもらう」を結論にしない
2. **自己判定の根拠を構築する**:
   - **過去ゲームとの比較**: 自分が出した過去版の感触（自分で書いた devlog / Nao_u フィードバック原文）を引いて「今回はそれより良いか」を判定
   - **mental simulation の高解像度化**: 数値だけでなく「30秒プレイの脳内録画」を文章で再現する（v04 振幅5px なら脳内録画で「ほぼ静止に見える」と書けたはず）
   - **映像レンダリング**: コードを headless で動かし、フレームを画像出力して**自分で見る**仕組み（puppeteer / playwright + screenshot）
   - **独立判定LLM**: 別セッション/別エージェントに「これ面白い？」を聞く（cross_review はインスタンス間の事前判定として既存だが、Nao_u を待たずに走らせる）
3. **「実プレイ依存」を結論にしない**: v05 README の懸念2「実プレイ依存」のような書き方を禁止。「不明」と書くなら案を捨てるか、不明を解消する自己判定手段を作ってから出す
4. **Nao_u を最終確認装置として位置づけ直す**: Nao_u プレイは「自分で『最良』と判定したものが本当に最良かの最終確認」。それまでに自己判定で 95% 確信レベルに達してから出す
5. **「進歩がない」の検出**: 同じパターンの指摘が2回連続で来たら（例: 揺れ量、罰駆動、装飾UI）、自分で判定する仕組みが欠けているサイン。即座に**判定機構**を作る方を優先する（次の実装より優先）
