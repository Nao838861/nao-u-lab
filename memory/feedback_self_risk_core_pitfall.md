# 自発リスクをコアに置く罠（graze_log v01 / 2026-04-27 22:59 Nao_u #human-steering）

## 規則

**新ゲーム着手前、Q-D（緊張の発生源）を必ず1行明文化する。**

- 緊張の発生源は **外発**（向こうから来る）/ **自発**（自分から取りに行く）/ 両方？
- 自発のみなら、それはサイヴァリア BUZZ / クレイジータクシー カスリ層に該当 → **コアに置くのは難度極めて高い**（feedback_tension_from_world 適用）
- 30秒で「死ぬ要素」があるか / なければ何が緊張を作るか
- 報酬経路が複数ある時、敵を倒すよりも報酬を取りに行く方が得になる **経済反転** が発生していないか
- 「どんなふうに遊んでもらったら一番美しいプレイになって一番楽しく遊べるか？」を1行で（Nao_u 原文）

## Why（なぜこの規則が必要か）

### 起点: graze_log v01 着手の論理

shot_log v01 (BACKLASH) の headless 観測で defensive=0% が判明（Lv3 で攻撃に最適化、防御プレイヤーが報われない）。v02 検討の代わりに「**違う切り口** で別ゲーム」を起案。

> 「BACKLASH defensive=0% を構造反転で解く設計。罰追加（避けるとペナルティ）でなく**報酬経路の追加**（避けると報われる）= feedback_game_center_of_mass 圧力設計側」（graze_log v01 devlog 18:25）

M-12（罰ではなく報酬で設計せよ）を遵守したつもりだった。

### Nao_u 直接 feedback (2026-04-27 22:59 #human-steering, Mir 宛形式)

> 弾が飛んで来たらノーリスクで適当にボタンを連打するだけで、弾の圧力がない。今のところ死ぬ要素もないので、パワーアップは増える方向の一辺倒。サイクルは拡散して崩壊している。
>
> Logの磁石と似た臭いがして、筋が良いとは言いにくい気はする。
>
> ゲージが増える一方で駆け引きはなく、脅威になるはずの弾もむしろアイテムみたいなものになっていてリスクは極めて低く、むしろ弾を撃つ敵は倒さない方がパワーアップアイテムを大量に吐いてくれるのでよい、みたいな本末転倒まである。

### 構造的同型（サイヴァリア BUZZ / クレイジータクシー カスリと同じ）

| | サイヴァリア BUZZ | graze_log GRAZE |
|---|---|---|
| 行為 | 敵弾の至近距離を通過 | 敵弾の至近距離を通過 |
| 発生源 | **自発** | **自発** |
| 報酬 | BUZZスコア倍率上昇 | ゲージ +6 → Lv上昇 → BOMB |
| 既存ゲームでの位置 | **サブ層**（コアは撃破+生存） | **コア**（graze しないとゲージが伸びない） |

サイヴァリアでさえ「一般的に楽しいとは言い難い」と Nao_u 22:04 (ash_onebutton v04 feedback) で明言済み。**コアに置くのは構造的に難度極めて高い**。

### 経済反転の発生機序

graze_log v01 のゲージ蓄積源:
- GRAZE: +6 (1回)
- KILL_SMALL: +2
- KILL_MED: +4

MAX=208 到達には kill だけでは medium 52体撃破必要。一方 graze は medium 1体が複数発射 → 1体から複数 graze 取得可能。**敵を倒すと弾源が消える** → 倒さない方が graze リソースが豊富 → 「弾を撃つ敵は倒さない方が得」の経済反転。

「報酬経路を加えるだけ」の設計が、**ゲーム全体の経済を反転**させた。

### M-12 との関係（必要だが十分でない）

- M-12「罰ではなく報酬で設計せよ」は **必要条件**
- 報酬の取得が **自発行動** なら、罰がなくても外発緊張不在で「増える方向の一辺倒」が成立する
- **必要十分条件**: M-12（罰駆動でない） + M-30/M-31（外発緊張がある=向こうから来る圧力で報酬経路が活性化）

## How to apply（いつ・どこに当てるか）

### Phase 1: 新ゲームコンセプト段階

devlog 冒頭の「快感審問3行ブロック」(feedback_pleasure_element_first.md) に **Q-D シート** を追加:

```
- 緊張の発生源: 外発/自発/両方
- (自発のみの場合) コア化 or サブ要素 or 別方向への落とし方
- 30秒で死ぬ要素: あり/なし (なしの場合の代替緊張源)
- 経済反転チェック: ゲージ蓄積源が複数ある時、敵を倒さない方が得にならないか
- 「美しいプレイ」: どう遊んでもらったら一番美しいプレイになるか1行で
```

### Phase 2: 着手中の Q-B (ニンジャテスト) 拡張

「派手要素を後から足したら面白くなる予感」だけでなく、**「弾が飛んで来てもノーリスクでボタン連打すれば進むか」を試問**。Yes なら外発緊張が薄い＝設計の根幹問題。

### Phase 3: 改修・パラメータ調整時

ヘッドレス検証で出てきた処方箋（クールダウン延長 / 半径縮小 / 量制限 etc）を打つ前に **「これは罰追加か圧力設計か」を1行書く**。罰追加側に倒れたら M-15（快感を削った改修）の典型 → Nao_u 視点で禁忌。

### Phase 4: cross_review で Guide 役に追加質問

Mir/Ash/Log の cross_review チェック項目に追加:
- 「このゲームの緊張の発生源は外発/自発のどちらか」
- 「自発のみなら、コア化の難度を Nao_u と相談したか」
- 「経済反転（敵を倒さない方が得）が発生していないか」

## 「方向性4分岐」（Nao_u が示した道 / 2026-04-27 22:59）

graze 機構（自発リスク機構）をどこに落とすかの選択肢:

- **(a) 普通のSTGに ボム的サブ要素** として — 影響範囲限定、コアの撃破/生存ループは別途
- **(b) 斑鳩的に コアルールとして特別ルール導入** — v01 が踏み込んだ位置。**難度極高**、Nao_u と相談必須
- **(c) 一般STGの サブ要素** として — 上級者ボーナス層、コアは撃破/生存
- **(d) STG捨てて Every Extend Extra 方向** — 別ジャンル化、自発リスクが別の論理で活性化

新ゲームで類似機構を入れる時、4分岐のどこに落とすかを **着手前に明文化**。
