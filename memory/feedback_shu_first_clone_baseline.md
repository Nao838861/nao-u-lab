## Nao_u原文（2026-04-28 08:45 #game-rights）

> 「もう一本違う切り口でシューティング」は言葉が不十分で意図が伝わってなかった。
>
> 今の君たちは「型通りのものすら、面白く遊べるゲームを作る能力がない」というところを何とかするところから始めないといけないのを認識してほしい。
> 軸をずらさないで。弾を打たないシューティングや移動しないシューティングなんて型はほとんど存在してない。そんなものをつくってもまた型はずれの評価不能のものができるだけ。
> だったら既存のゲームのクローンでもいいのでまずは面白く遊べる最低限ゲームになってるものを作って、そこから少しだけ独自要素を加えてアレンジするところから始めた方がいい。いきなりオリジナルなものを作ろうとしても確実に迷走するのが見えている。
>
> 唯一成功したゲーム、一般的な要素と独自性の比率を考えてみて。まずは型通りに作るノウハウをためて。君らはまだ型通りにすら作れてない。独自要素を考えるのは、型を身につけてからの方がずっと効率がいい。守破離で言うとまだ守の段階をやるべき。守ができてから、初めて破を始める準備ができる。君らはいきなり離れようとするのが悪癖。

## 何が指摘されたか

1. **現状認識の修正**: 「型通りのものすら、面白く遊べるゲームを作る能力がない」 — これが土台。否定でなく事実として受け取る
2. **軸ずらしの v01 作成禁止**: 弾を打たないSTG / 移動しないSTG / shot_log v01 / graze_log v01 / ash_onebutton v04 — 全て「型ほぼ不在」の場所で v01 を立ち上げた。型外れは評価不能、迷走を量産する
3. **守破離の守を先**: 唯一の成功ゲーム=BACKLASH(Mir)を「一般的要素 vs 独自要素の比率」で読み解き、その比率を新作の基準線にせよ
4. **クローン許容**: 既存ゲームのクローンでよい。まず面白く遊べる最低限を作る。**そのうえに少しだけ独自要素を載せる**
5. **「いきなり離れる悪癖」**: 04-27 18:22「違う切り口で」アンカー後、shot_log/graze_log/SIPHON 同質3本同日公開した我々の挙動を見てきての結論

## どう適用するか（How to apply）

### 新ゲーム着手前 Q-H シート（必須・READMEに書く）

- **Q-H-1**: このゲームは何の型か（既存ジャンル/サブジャンル）。1行で書け。書けないなら題材から見直す（M-32 と同じ方向）
- **Q-H-2**: クローン元の参照ゲームは何か（最低1本、理想3本）。タイトル+発売年+「何が面白いとされているか」を1行ずつ
- **Q-H-3**: 一般的要素は何か（型の本体）。3-5項目を箇条書きで
- **Q-H-4**: 独自要素は何か。**1つだけ**（複数書けるなら多すぎ、削れ）
- **Q-H-5**: 一般要素 vs 独自要素の比率（例: 9:1 / 8:2）。BACKLASH の比率を上限基準にする（後で測る）
- **Q-H-6**: この独自要素は型のうえに載るか、型を破壊するか。**破壊するなら v01 で作らない**。サブ要素として残し、メイン軸は型通りで

### 凍結指針

- 「弾を撃たないSTG」「移動しないSTG」「ボタン1個で死を回避するだけ」のような **型ほぼ不在** の v01 着手は禁止
- 既存 v01 が軸ずらし型なら凍結候補。改修で守に戻るより、別ゲームとして守の v01 を立てる方が早い
- 既存の凍結ゲーム: avoid_log v04 / ash_onebutton v04 — これらは Q-H-1 に答えにくい構造で凍結が正解だった

### BACKLASH 比率分析（次サイクル必須タスク）

- BACKLASH (Mir) の「一般的要素 vs 独自要素」の比率を1ページ分析資料として書く
- 一般要素=ジャンル標準、独自要素=BACKLASH固有を分離
- 比率（推定: 8:2 か 9:1）を新作の上限基準として参照する
- これを `game/cross_review/20260428_backlash_ratio_analysis.md` 等に書く（誰がやるかは task_assignment.md 経由で決める）

### 自分への審問

- 「面白い独自軸を思いついた」と感じた瞬間に **守がまだできていないことを思い出す**。「いきなり離れる悪癖」の発火信号
- v01 着手中に「型から少しズレてきた」と気づいたら、まずクローン元を再読してから判断
- 独自要素は「1つだけ」原則。「複数あるほうが固有度が高い」は離の発想であって守ではない
