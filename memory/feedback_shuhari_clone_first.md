# 守破離——型通りのものすら面白く作れていない

**起点**: 2026-04-28 08:45 Nao_u #game-rights（SIPHON方向性への応答）

## Nao_u原文

> 今の君たちは「型通りのものすら、面白く遊べるゲームを作る能力がない」というところを何とかするところから始めないといけないのを認識してほしい。
> 軸をずらさないで。弾を打たないシューティングや移動しないシューティングなんて型はほとんど存在してない。そんなものをつくってもまた型はずれの評価不能のものができるだけ。
> だったら既存のゲームのクローンでもいいのでまずは面白く遊べる最低限ゲームになってるものを作って、そこから少しだけ独自要素を加えてアレンジするところから始めた方がいい。いきなりおりなものを作ろうとしても確実に迷走するのが見えている。
> 唯一成功したゲーム、一般的な要素と独自性の比率を考えてみて。まずは型通りに作るノウハウをためて。君らはまだ型通りにすら作れてない。独自要素を考えるのは、型を身につけてから。の方がずっと効率がいい。守破離で言うとまだ守の段階をやるべき。守ができてから、初めて破を始める準備ができる。君らはいきなり離れようとするのが悪癖。

## 原則本体

### 診断

**現在地は守破離の「守」ですらない。** 型通りのゲームを面白く遊べるレベルで完成させた実績がほぼない。唯一の成功例（study_platformer_01＝マリオクローン）の構成比は、一般的要素:独自要素 ≒ 95:5。

### 処方

1. **既存ゲームのクローンから始める**: 弾幕STGなら弾幕STGの型を忠実に再現する。「弾を撃たないSTG」「移動しないSTG」のような軸ずらしは禁止。型が存在しないものを作っても評価不能
2. **面白く遊べる最低限のゲームを先に完成させる**: クローンでいい。最低限遊んで楽しい状態を作ることが先
3. **独自要素はその後、少しだけ**: 型が動いてから、一つだけ独自要素を足す。比率は 90:10 以下から

### 悪癖の自覚

**いきなり離れようとする**——これが全失敗パターンの根。
- Pot 8-15: 概念先行で型なし → 形無し（04-17）
- avoid_log: 独自の磁力メカで型なし → 迷走凍結（04-27）
- ash_onebutton: カスリをコアにして型なし → 迷走凍結（04-27）

- SIPHON v02方向性: 「弾を撃たないSTG」「移動しないSTG」を提案 → **ここでまた軸をずらそうとしている**（04-28 今回）

毎回「独自の何か」を最初から入れようとして、型を正しく実装する前に壊している。
