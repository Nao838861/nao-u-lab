# コアメカニズムの緊張は向こうからやってくるべき

**起点**: 2026-04-27 22:04 Nao_u #game-rights ash_onebutton v04 フィードバック原文

> ほっておくと死なないところにわざわざ自分からリスクを取りにいかないといけないのは、非常に筋が悪いと思った。サイヴァリアのバズシステムや、クレイジータクシーのカスリボーナスなどがあるが、これらは一般的に楽しいとは言い難い。それなしでもゲームが成立する状態になっているところで、上級者向けのボーナスとして存在することでスコアアタックの上限を上げる効果はあるかもしれないが、それ自体をコアメカニズムにするのは難度が高そう。
>
> 自分からリスクを取らない限り何も起きないゲームは退屈で、わざわざリスクを取りにいかないと点が取れないのはストレス。「緊張と解放」はゲームの基本だが、**コアメカニズムの緊張は、基本的には向こうからやってくるべき**だと思った。「死にたくない」という意思が行動を生んで、その行動の結果長生きしたり、攻撃によって快感を得たりなどが基本だが、このゲームは自分からリスクを取りにいかない限り無尽蔵の生存できるので、そのサイクルが成立していない。

## 原則本体

ゲームのコアメカニズムにおける緊張は **外（敵・世界）から来る** 必要がある。

- ✕ プレイヤーが自発的にリスクを取らないと何も起こらない設計
- ✕ 「ボーナスを取りに行かないとスコアが伸びない」をコアにする
- ◯ 「死にたくない」という防御の意思 → 行動 → 生存・快感 のループ
- ◯ バズ/カスリ系は **上級者向けスコアアタック上限拡張** としては OK（コアではない）

## Why（理由・参考事例）

- サイヴァリア BUZZ / クレイジータクシー カスリ: いずれも **コアではなくサブ層**。基礎ゲームが成立した上で上限を上げる装置として機能している
- 自発リスクをコアにすると: ルール理解の動機が「楽しむため」でなく「意味不明なものを解析するため」に置き換わる（ash_onebutton v04 の体験原文「ルールだけでも理解しようと我慢」）
- 「緊張と解放」はゲームの基本サイクル。**緊張の発生源** が壊れていれば解放も成立しない

## How to apply

### 新ゲーム着手前
冒頭 3 行ブロック (feedback_pleasure_element_first) に **緊張の発生源** を追記:
```
一番嬉しい瞬間: ___
それを支える操作: ___
30秒以内の手数: ___
緊張の発生源: 外 / 自発（外であること）
```
「自発」と書かざるを得ない設計はコアメカニズムが成立していない。

### 改修時
v01→v02 改修前審問:
- この改修は **緊張を外から強める** か、**プレイヤーに自発リスクを要求する** か
- 後者なら「上級者ボーナス層」に押し込んで、コアは外発緊張だけで成立しているか確認

### 接続する既存原則
- **feedback_pleasure_element_first**: 「一番嬉しい瞬間」は防御の成功体験（外発緊張への対処）から来るのが基本
- **feedback_no_passive_punishment**: 「自然減衰でリスクを強制」は外発緊張の偽装。本物の外発緊張は敵・障害物の挙動から来る
- **feedback_pull_not_force_reading**: テキストADV系における「読まないと罰」も自発リスク要求の変種
- **feedback_game_center_of_mass (重心審問)**: 「圧力設計 vs 禁止追加」と接続。**緊張の外発化は圧力設計の一形態**

## ash_onebutton v04 の具体的失敗

- v01: 落下障害物（外発緊張）+ 反転回避（防御行動）→ 基本ループ成立
- v04: 「紙一重で光る」を入れた結果、**敵の真下でボタンを押す自発行動でないと得点が伸びない** 構造に
- 結果: プレイヤーは「死なないが点も取れない」状態に置かれ、自発でリスクを取りに行かないと何も起きない
- v01 が筋の良い土台だったのに、**コアに自発リスクを足してしまった改修ミス**

> **Q-D: 緊張の発生源は外か自発か？**
> - 外（敵・世界の挙動）: ◯
> - 自発（プレイヤーが取りに行かないと何も起きない）: ✕（コアの場合）
> - 自発でも上級者ボーナス層に閉じている: △（コアが外発で成立している前提でのみOK）

## textadv への適用（Mir 2026-04-27 受領・接続）

テキストADVにおける「外発緊張 / 自発リスク」の対応表:

| 外発緊張（◯） | 自発リスク（✕をコアにしない） |
|---|---|
| 物語の事件が進行する（証拠が出る、被疑者の態度が変わる、時間が迫る） | エンディング網羅のために特定パスを自発的に探索する |
| 矛盾が**物語上の必然として**露出する | 読み飛ばすと矛盾に気づけない構造で精読を強制する |
| 被疑者が自分から動き出す（Phase 3 取調の逆転） | 共犯ENDに到達するためにプレイヤーが意図的に寄り添い選択を重ねる |

### 接続1: feedback_pull_not_force_reading は本原則の子
「読まないと罰」= 精読という自発的努力をコアメカニズムにしている。外発緊張への変換 = 「読みたくなる文章の引き」で、物語側から読者を引っ張る。信頼度バー等のUI機構は **外発緊張（物語の変動）の結果を可視化する出力装置** に限定すべき（A-14）。

### 接続2: v05 共犯END不合格の再解釈
v05で追加した共犯END（E: 指紋消去）は「コンプ勢向け自発リスク」の textadv 版だった:
- 通常プレイでは到達しない = **外発緊張で自然に導かれない**
- 「寄り添い選択を意識的に重ねる」= プレイヤーが自発的にリスクを取りに行く構造
- Nao_u「そうでない人の面白さがどこまで上がっているかは疑問」= 大多数のプレイヤーには外発緊張が届いていない

**処方**: textadv のエンディング分岐は「物語の力で自然にそこへ流れ着く」設計が基本。「特定の選択パターンを意図的に維持した人だけが見られる」はサイヴァリアBUZZと同型——上級者ボーナス層としてはありえるが、コア体験にはならない。
