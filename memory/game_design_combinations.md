# ゲーム組み合わせ事例集

Nao_u 2026-05-03 03:29 #nao-u 提示の方針: 「既存の要素を2つ組み合わせて現状に合わせてバランスを取るだけで新しいゲームができる例」。**どのゲームのどの要素を取って、どう組み合わせ、何を調整したか**を分解して蓄積する。

## 事例 1: TerraTech Legion = 『ヴァンサバ』×『TerraTech/Besiege系（魔改造レゴ）』

出典: <https://x.com/stmatomato/status/2050408937909010764> (スチまと, Nao_u共有 2026-05-03 03:29)

### A. ヴァンサバから取った要素
- オートシュート（操作=移動だけ）
- 武器を重ねるほど強い**加算ビルド**
- 大量の雑魚で画面を埋める**殲滅快感**
- ローグライト（毎回ビルドが変わる）

### B. 物理組立系（TerraTech/Besiege）から取った要素
- ブロック組立で兵器を自作（武器・推進・装甲を自由配置）
- 物理シム（重さ・構造強度）
- 「自分が組んだ機体」への**所有感**

### C. 結合点（核）
ヴァンサバの「武器を増やす=画面の弾が増える」を、物理組立系の「ブロックを物理的に積む」に置換。
→ **「組んだガラクタ兵器でヴァンサバする」がワンセンテンスで成立**

### D. バランス調整 ＝ Nao_uの言う「現状に合わせて」の正体
- 「綺麗な車を作る必要なし」: 物理シム本来の最適化プレッシャーを意図的に消す（ヴァンサバの「考えなくていい」を継承）
- 「氷河の速度でOK」: 遅さが罰にならない設計（ヴァンサバの「動かなくても弾幕で殲滅できる」を物理オブジェクトに移植）
- 過積載が**ペナルティ→リワードに反転**（重い=遅いが、遅さが罰されない世界では相殺）

### E. 相乗効果（feedback_combine_dont_subtract.md 直結）
- ヴァンサバの「弾幕快感」が物理オブジェクトとして眼前に積み上がる→**所有感つき爆発的視覚快感**
- ヴァンサバ単体の弱点「ビルドの自由度の物足りなさ」を物理組立で補う
- 物理組立系単体の弱点「最終的に戦闘が単調」をヴァンサバ的殲滅で補う
- **互いの弱点を打ち消し合う組み合わせ**

### F. テンプレート抽出
**「Aの加算ビルド快感 × Bの自由配置による所有感」型**
- 候補: ヴァンサバ × Kerbal（ロケット組んで打ち上げ続ける）
- 候補: ヴァンサバ × Factorio（組んだベルトが自動で殲滅）
- 候補: ヴァンサバ × Minecraft Redstone（組んだ装置が自動で敵を処理）

### G. 判定軸（次のbrainstormへ）
単純加算ではなく **「片方の弱点を片方が消すか」** を判定軸にする。
- ✓ A の弱点を B が消す
- ✓ B の弱点を A が消す
- ✓ A の快感が B によって増幅される
- ✓ 物理的相互作用が新しい意味を生む（重さが報われる等）

3つ以上 ✓ なら「現状に合わせてバランスを取るだけで新作」型の有力候補。
