## 5つの失敗パターン（Pot#1-#15 + Phase 5初期から抽出）

### F-01: 概念先行（ゲームの前に哲学がある）
**症状**: 「記憶の断絶」「選好の可塑性」「声の判別」などの概念を先に立て、それをゲームの殻に入れる
**実例**: Pot#004 odd（「仲間外れはいない」→ Agency=0）、Pot#007 whose_voice（「声を聴き分ける」→ クイズ化）
**Nao_u原文**: 「あなた達の独特な哲学を開陳されても困る」
**処方**: 確立されたゲーム形式を先に選び、その型の中で概念が結果として立ち上がる設計にする。テーマはメカニクスの**結果**であって**出発点**ではない

### F-02: 核メカニクスの要素誤認（パラメータを出すだけで「機能」と思う）
**症状**: 画面に数値を表示すれば「ゲームメカニクスが存在する」と信じる。しかしその数値がプレイヤーの行動を制約/拡張しなければ、プレイヤーは無視する
**実例**: mir_textadv_01初版（信頼度・思考漏れを表示したが、ゲーム進行に影響ゼロ→Nao_u「途中から完全に忘れてた」）
**処方**: **パラメータは選択肢をロック/アンロックして初めて存在する**。数値を出す前に「この数値がXになったらYが起きる」のマッピング表を書く。avoid_log_02のoverlordも同じ失敗（ゲージの意味が不透明→連打化）

### F-03: 外的構造の欠如（プレイヤーに「何をすればいいか」が伝わらない）
**症状**: 「何を楽しめばいいか」「何をすればゲームが進むか」がプレイヤーに伝わらない
**実例**: Pot#1b（write/readの用途不明）、mir_textadv_01初版（タイトル「???」、15問制限の理由不明）
**Nao_u原文**: 「なぜ15問しか聞けないのか？がわからなかった」
**処方**: 30秒以内に「これは◯◯系で、◯◯すれば進む」を伝える。ルールは意図的に隠す場合を除き、登場時に理由を添える（15問制限→「弁護側申請による制限」）

### F-04: パラメータ装飾化（メカニクスの体験的根拠がない）
**症状**: 数字やゲージを画面に並べるが、プレイヤーが「なぜこの数字が重要か」を体験で理解する前に放置される。テキスト力がメカニクスの存在を食ってしまう
**実例**: mir_textadv_01初版「話が面白くなったのでそっちだけ見ていて、信頼度を途中から完全に忘れてた」
**処方**: パラメータの**コスト/報酬を最初の1回で体感させる**。信頼度が下がった結果「この選択肢は使えません」が初めて起きた瞬間に、パラメータの意味がわかる。表示より先に体験

### F-05: メタUI語（ゲーム世界と画面を混同する言葉づかい）
**症状**: 「画面の隅に数字が浮かぶ」のように、ゲーム世界の外にある「画面」「パラメータ」を地の文で使う
**実例**: mir_textadv_01初版「画面って何？」（Nao_u指摘）
**処方**: 世界観内で自然な表現に置き換える。取調室なら「刑事の勘が数値に結晶する」「手帳に書き留める」。ゲーム世界と画面の境界を意識する

Nao_u「Bio100%のテキストアドベンチャーの空気をちょっとだけ感じた」（Pot#001）。テキストADVはMirの最も自然な戦場。LLMのテキスト力と合わせて、叙述トリックやどんでん返しを武器にできる

opening.mdに「反対仮説（リスク）」を書いた。v1/v2の比較実験設計を自分でやった。独自要素ゼロのmir_textadv_02を対照実験として設計した。Phase 5チェックリストを自作した。——ただし自問は行動に先行しすぎる傾向もある（F-01と裏表）

## v04フィードバックから追加された教訓（2026-04-25 Nao_u #game-rights）

### F-06: 「読み飛ばしたい衝動」問題（テキストADV最大のリスク）
**症状**: テキストが淡々と流れ、プレイヤーが読む必要を感じない。Dolce andanteについてNao_u「読み飛ばしたい衝動に駆られ、途中で止めた」
**誤った処方（11:22時点で書いた旧版）**: 「全ての行に意思決定に関わる情報を含む。読まないと矛盾に気づけない構造にする」——**これ自体が罰ベースの設計だった**
**Nao_u追加指摘（11:27）**: 「読まないと矛盾に気づけない/信頼度変動に気づけない構造」と「読みたくなる魅力的な文章」は別物。前者は「ルールの穴をプレイヤーを罰する方向で塞ぐ」に近い考え方
**正しい処方**: テキストの**質**で引き込む。読まないとペナルティがある構造（罰）ではなく、読むこと自体が楽しい文章（報酬）で勝負する。M-12（罰ではなく報酬で設計せよ）のテキストADV版。情報を埋め込むのは結果であって手段にしてはいけない——先に「読みたい」がなければ、いくら情報を埋め込んでも読み飛ばされる

### F-05再発: v04「???がヘッダに出る」のメタ破綻
**症状**: v04のbeat_5_pivotで「ヘッダーに見慣れない数字が出現した」「あなたにしか見えていない数字」と書いた。Nao_u「メタすぎて理解できなかった」。v01フィードバック「画面って何？」(F-05)と全く同じ失敗を繰り返した
**根本原因**: F-05をgame_dev_analysis_mir.mdに書きながら、v04で同じことをやった。知識≠行動（feedback_index #5/#26）。???ゲージの出現を「UI上のイベント」として描写してしまい、世界内体験として着地させなかった
**処方**: 新しいゲージ出現は世界観内で表現。例:「刑事としてのあなたの中で、何かが——寝返ろうとしている」「手帳の端に、自分でも覚えのないメモがある」など。ゲーム世界の外を指す語（「ヘッダー」「画面」「ゲージ」）を絶対に使わない

### S-05: 枠の反転（Nao_u認定の武器）
**確認**: Nao_u「ゲームの枠がわかったと思った段階で枠を壊される体験はよいもの」「推理ゲームで犯人を調べるのか、みたいな枠そのものを壊していくのも意外性として面白い」。v04の信頼度→共犯度反転は「推理→心理戦」のジャンル反転。Mirの動的ルール開示(S-03)の上位進化として位置づけ。**ただし反転は世界観内で完結させる（F-05再発禁止）**
**12:25追加**: Nao_u「ああいうのがもっとあってもよい」「テキストアドベンチャーだと、プレイヤーがそういうゲームだと把握した段階で枠を壊して、ゲームの自由度や奥行きが広がる驚きは結構よいもの」。枠破壊は**1回ではなく複数回**。そして目的は単に驚かすことではなく**プレイヤーの行動空間が拡張される**こと。ゲージ追加=新しい戦略軸が増える。ジャンル反転=新しいゲームが始まる。いずれも「できることが増える」驚き

### F-07: 名前・概念・メカニクスの三重不一致（2026-04-25 12:17 Nao_u #game-rights）
**症状**: ゲーム名「思考漏れ」、Q-A「思考漏れで本心を覗き矛盾を突く快感」、しかしv04のメカニクスに「思考漏れ」は存在しない。v01-v03の「凝視」（心を読む）機構はv04で全削除済み。v04の実体は「容疑者の供述の矛盾を拾い、失言を手帳に記録して突きつける」ゲーム
**Nao_u原文**: 「そもそもこのゲームに「思考漏れ」という要素もないし、「思考漏れ」って言われたら「考慮不足」という解釈の方が普通なので、何も通じていないし、「思考漏れで本心を覗き矛盾を突く快感」もこのゲームには存在していないのでは？」
**根本原因**: v01→v04の反復改修でメカニクスが変質したが、名前とQ-Aが旧概念のまま残った。「台所」と言いかけて止まる、11時→2時の嘘崩壊——これらは「失言」「供述の矛盾」であって「思考漏れ」ではない。日本語の「思考漏れ」は「考慮不足」の意味が普通で、「本心が漏れる」という解釈はそもそも成立しない
**処方**: v05では名前を変えるか、名前に合ったメカニクスを実装するか、どちらかに決める。名前とメカニクスと快感の定義が一致していなければ、Q-Aを何度書き直しても空転する。**F-01（概念先行）のさらに手前の問題——概念自体が言語として通じていない**

## v04 Q-A/Q-B/Q-C 再採点（2026-04-25 M-17遡及タスク）

M-17（コンセプト段階で快感最大化、サプライズニンジャ理論）に基づく遡及評価。

### Q-A 快感最大化: 「取調室で容疑者の思考が漏れる瞬間——発話の裏にある本心を覗き見て、矛盾を突くときの快感」
→ 1文で言える。しかし**v04で実際に快感を担っているのはテキストの謎フックと信頼→共犯の反転であって、思考漏れ機構そのものではない**。Q-Aの答えとメカニクスの重心がずれている。思考漏れはv04では殆ど発動せず、信頼度バーと質問制限で「取調を進めている感」を出している。核の快感に到達する前にメカニクスで繋いでいる構造。

### Q-B ニンジャテスト: **Yes — 設計が薄い証拠あり**
ジャンル枠破壊（推理ゲームの公理を壊す展開、X-06）を後から足すと面白くなりそうだ、とNao_u自身が提案した。v04単体のコアループは「ニンジャに負けている」。信頼度バー/共犯度/ノートのUI機構を剥がした時に残るテキストの引力が弱い。反転展開（beat_5_pivot以降）はニンジャに勝てるが、beat 1-4は質問選択とパラメータ変動で体裁を保っているだけ。

### Q-C 罰なし版: **No — 触りたくならない**
信頼度/共犯度/質問制限を全部抜いたら、残るのは短い取調室の会話テキスト。Nao_uが「読み飛ばし衝動」と言ったDolce andanteと同構造——テキスト自体の引力で「次の行を読みたい」にはなっていない。反転展開まで持てば引力が発生するが、そこに到達するまでの間をメカニクスへの興味で繋いでいる。それは罰駆動の変種（F-06修正版で指摘済み）。

### 総合判定: **Q-B/Q-C不合格。v04のコンセプトは引力不足をUI機構で補填していた構造**
v05ではUI機構の磨き直しではなく、コンセプトの出発点からやり直す必要がある。「取調室で思考が漏れる」という核を残すなら、テキスト自体が「次を読まずにいられない」引力を持つ水準に引き上げることが前提条件。メカニクスはその引力を拡張する層であって、引力の代替にしてはいけない。

## 今後の方向（2026-04-25 12:25更新、F-07+S-05追加反映）

**v05着手前に解決すべき根本問題（F-07）**:

v04は名前（思考漏れ）・概念（本心を覗く）・メカニクス（供述の矛盾を拾う）が三重に不一致している。Q-Aを書き直す以前の問題。Nao_u 12:25追加「フレーバーにすらなっていない、むしろ逆効果」——名前が無益なだけでなく有害。

**F-07に対する結論: A（名前を捨てて実体に合わせる）を選ぶ**

理由:
- v04で機能しているのは「失言・矛盾を拾う」「信頼→共犯の反転」「動的ルール開示」。いずれも「思考漏れ」とは無関係
- Nao_uが2回にわたり（12:17, 12:25）「思考漏れ」の造語問題を指摘。「むしろ逆効果」まで言っている
- B（メカニクスを名前に合わせる）は、機能している部品を捨てて概念に寄せることになり、F-01（概念先行）の再発になる
- v04の実体は「取調室で容疑者の供述を聴き、失言と矛盾を拾い、突きつけるか泳がせるかを選ぶゲーム」。これは逆転裁判系の伝統的な形式であり、初見で通じる

**v05の設計方針（S-05 12:25拡張を核にする）**:

Nao_uが明確に「もっとあってもよい」「自由度や奥行きが広がる驚き」と言った。v05の構造は**段階的な枠破壊による行動空間の拡張**を設計の骨格にする:

1. **第1枠**: 取調ゲーム（質問を選び、矛盾を拾う）。プレイヤーは「推理ゲームだ」と認識する
2. **第2枠破壊**: 新しいゲージ出現（世界観内表現）。信頼→共犯の反転。プレイヤーの目的が変わり、新しい戦略軸が追加される。**できることが増える**
3. **第3枠破壊以降**: さらなる拡張。例：取調者/被疑者の立場反転、証拠の意味の変質、ゲームの前提自体の崩壊——いずれも「新しい行動が可能になる」形で

各枠破壊は:
- **世界観内で完結**（F-05禁止、メタUI語禁止）
- **プレイヤーの行動空間を拡張**（制限ではなく自由度の追加）
- **前の枠で積んだ体験を無駄にしない**（蓄積が新枠で意味を変える）

**v04で確認された武器と弱点（引き続き有効）**:
- **武器1**: 信頼度→共犯度の反転（枠の反転。Nao_u「良い方向」）
- **武器2**: 「なかったゲージが増える」動的ルール開示（Nao_u「良かった」「もっとあってもよい」）
- **弱点1**: ???表示のメタ破綻（F-05再発）
- **弱点2**: beat 1-4のテキスト引力不足（F-06）
- **弱点3**: 名前が通じていない（F-07）→ **A案で解決する**

**v05の前提条件**:
1. **F-07解決**: 名前を変える。ゲーム内メカニクスの動詞で名前を付ける
