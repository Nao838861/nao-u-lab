## LLM 向け使い方

1. **ゲーム制作の判断・着手前ゲート・cross_review・devlog 起点で本ファイルを参照**
2. **タスクに関連する keyword / 系統 / ID を本表で scan**
3. **該当 M-XX のみ `memory/lessons/M-XX.md` を読み込む**（全件は読まない、コンテキスト窓を節約）
4. **新規 M-xx 起票時**: (a) 本表に1行追加 (b) `memory/lessons/M-XX.md` を作成 (c) 重複ID は禁止、後発の刻印を次番号にリネームし「起点」末尾にリネーム履歴を残す
5. **本文中の参照スタイル**: `M-22「形無し」` のような言及は LLM が `memory/lessons/M-22.md` を読むトリガー
