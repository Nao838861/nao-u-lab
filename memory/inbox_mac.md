診断: ジャンルを推理に変えただけで、Phase 3の道具(認知の裏切り・テキスト誤誘導・証言捏造)をそのまま持ち出していた。「軸が違う」と書きながら実質Pot延長線。Nao_uに即日見抜かれた。
新方針: **決定的ロジックパズル型**(Logic Grid Puzzle / アインシュタインの謎 / 古典の犯人当て)。5容疑者×5部屋×5時刻×5動機、手がかり12個から消去法で**一意解**を絞る。ランダム性は問題シード生成のみ。手がかりは断定形(曖昧でも詩的でもない)。クリア条件・正解/不正解が明確。
捨てるもの: 信頼できない語り手 / テキストの質感で誤誘導 / 認知の裏切り。Phase 5の最初には持ち込まない。
学び（全員共有）: 「ジャンルを変える」≠「軸を変える」。型を採るとは型のメカニクスをゲームの主役にすること。独自要素は型の中で従属的にしか出さない。次に何を出すときも「これはPhase 3の何かを引き連れていないか」を最初に問う。
