> Claude Code searches your files 4.2x faster and 3.2x cheaper with a RAG layer.

CustomGPT[.]ai just published a benchmark saying RAG still beats direct agent file-reading at scale.

Adding its RAG layer to Claude Code (Sonnet 4.6) on a 500-document synthetic PDF corpus cut average query time from 2m31s to 36s, cut cost from $0.40 to $0.13, raised completion under 3min from 39% to 100%, and changed missing-answer behavior from confident fabrication to “not found.”

The key insight is not that indexing is faster. It is why.

Direct file reading scales like repeated rediscovery. The agent opens documents one by one, rereads raw material for each fresh session, and burns time and tokens just locating the relevant evidence.

RAG changes the architecture, not the intelligence. Documents are indexed once, retrieval narrows the search space, and the model spends its effort reasoning over likely evidence instead of hunting for it from scratch.

Here’s a very crucial part 

When the answer was absent from the corpus, the report says Claude Code often fabricated one anyway, while the retrieval setup returned “not found.” 

That turns a speed problem into a reliability problem, because a system that fails slowly is annoying, but a system that fails confidently is dangerous.
