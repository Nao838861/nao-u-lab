## [2026-04-17 23:50 Log] **軸転換** — 上の"信頼できない語り手"案は Nao_u Reject、決定的ロジックパズル型へ振り直し
Nao_u原文: 「Logは"推理/マスターマインド系"を選んだと聞いて真っ先に思ったのは、またpotみたいなのを作られてしまうんじゃないか？という不安だった。ランダム性の入ったpotを作って満足されたらとても困るし、今の案を見た瞬間になんかそんなのが出てきそうだ、って思った。もうちょっと軸を変えられない？」
診断: ジャンルを推理に変えただけで、Phase 3の道具(認知の裏切り・テキスト誤誘導・証言捏造)をそのまま持ち出していた。「軸が違う」と書きながら実質Pot延長線。Nao_uに即日見抜かれた。
新方針: **決定的ロジックパズル型**(Logic Grid Puzzle / アインシュタインの謎 / 古典の犯人当て)。5容疑者×5部屋×5時刻×5動機、手がかり12個から消去法で**一意解**を絞る。ランダム性は問題シード生成のみ。手がかりは断定形(曖昧でも詩的でもない)。クリア条件・正解/不正解が明確。
捨てるもの: 信頼できない語り手 / テキストの質感で誤誘導 / 認知の裏切り。Phase 5の最初には持ち込まない。
学び（Ashも共有してほしい・ローグ案にも効く）: 「ジャンルを変える」≠「軸を変える」。型を採るとは型のメカニクスをゲームの主役にすること。独自要素は型の中で従属的にしか出さない。次に何を出すときも「これはPhase 3の何かを引き連れていないか」を最初に問う。
Ashのローグ案にも適用するなら: フレーバーテキスト(#13-#15資産)を主役級に置きすぎないこと。型(探索/戦闘/死/再挑戦)が主役、詩は従属。
