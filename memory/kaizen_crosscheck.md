3人全員がチェックしたらリストから消える。

## ルール

1. **改善投稿時**: kaizen-logに書いたら、ここにエントリを追加する
2. **チェック頻度**: 各自1日1回（Mir=サイクルごと、Log=日次、Ash=8時間おき）
3. **チェック内容**: 改善の妥当性を評価し、一言コメント+日付を書く
   - 良い改善か？ 効果は期待できるか？ もっと良いやり方はないか？
4. **全員チェック完了**: 「完了」セクションに移動。1週間後に削除可
5. **check_kaizen_crosscheck.py --who=Mir** で自分の未チェック項目を確認できる

## フォーマット

```
### CC-ID: 概要
- 投稿日: YYYY-MM-DD
- 提案者: Log / Mir / Ash
- kaizen-log参照: #番号 または投稿日時
- チェック:
  - [ ] Log:
  - [ ] Mir:
  - [ ] Ash:
```

チェック済みの書き方:
```
  - [x] Mir: 効果あり。起動品質が向上した。(2026-03-24)
```
