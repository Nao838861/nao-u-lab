### M-33: 型のカテゴリ分類 A / B / C —— B は A より見えにくい（feedback_no_type_redo_material 拡張 / 2026-04-28 C141 Phase 3 Ash 刻印）

**事象**: `feedback_no_type_redo_material.md` の原則「型なし題材は v05 に行く前に練り直せ」は、ash_onebutton v04 / avoid_log v04 のような **「先行例すらないコアメカニズム」** を凍結する基準として機能してきた。しかし graze_log v01 + Mir cross_review + Nao_u 22:59 #human-steering で判明したのは、**型はあるが筋が悪いと判定済みのコア**（サイヴァリア BUZZ / クレイジータクシー カスリ）が新しい第3カテゴリを形成すること。型なし題材の凍結だけでは捕捉できない死角。

**3カテゴリの定義**:
- **カテゴリ A: 型がない**（先行例が確認できない） — ash_onebutton v01-v04, avoid_log v01-v04 が該当 → 題材から練り直し（feedback_no_type_redo_material 原文の射程）
- **カテゴリ B: 型はあるが筋悪と判定済み** — graze_log v01 (サイヴァリア BUZZ コア化), 仮想的に「クレイジータクシー カスリをコア化」した STG など → コアからサブへ降格 / 別題材 / Nao_u と相談（Q-D 経由）
- **カテゴリ C: 型があり筋良し** — テトリス系の落ち物パズル / ぷよぷよ系の連鎖 / ソコバン系の押し / 縦スクロール STG の標準形 → 改修で進める（[M-22](M-22.md) の「型を熟す」が射程）

**根本原因（B が A より見えにくい理由）**:
- A は「先行例がない」で着手前に検出可能（外部検索で同型がヒットしない）→ Q-A/B/C 段階で凍結判断ができる
- B は **先行例があるので形式上「型はある」と通る** → 着手前審問では検出されず、Nao_u プレイテスト後にしか「コア化は筋悪」とわからない
- B は graze_log v01 のように **個別実装の品質が高い**ほど、コア化問題が見えにくくなる。実装が綺麗だと「これは違う」と判定するための根拠が「実装が悪いから」に流れやすい
- M-22「形無し」（型未満で枠破壊を試みる失敗）は A の処方、M-33（B は A より見えにくい）は M-22 が捕捉できない B の処方

**[M-31](M-31.md) / Q-D との接続**:
- M-31「報酬経路の追加が自発リスクのコア化と同義になりうる罠」は B カテゴリの構造的盲点を実装レベルで描いた
- Q-D（緊張の発生源、必須シート、M-31 で導入）は B カテゴリ検出の **着手前ゲート**: Q-D-2「自発のみなら、それはサイヴァリア BUZZ / クレイジータクシー カスリ層に該当 → コアに置くのは難度極めて高い」が直接 B 検出機能を持つ
- M-33 は Q-D を「自発緊張だけでなく、より広い B 検出」に拡張する位置づけ

**次回の規則 — 新ゲーム着手前 Q-F（型カテゴリ判定、必須シート）**:
- **Q-F-1**: コアメカニズム型に該当する先行例を1つ以上挙げる（外部検索でヒットがあるか）→ なければ A → 題材から練り直し
- **Q-F-2**: 先行例がある場合、Nao_u が過去に「これはコア化が難度極めて高い」と判定したジャンル / メカニズムに該当しないか確認（サイヴァリア BUZZ / クレイジータクシー カスリ / 自発リスクテイクをコアに据えた他作品）→ 該当すれば B → コアからサブへ降格 / 別題材 / Nao_u と相談
- **Q-F-3**: A でも B でもない場合（C 該当）、その先行例で **コアが磨かれている要素**は何か / 自分の派生案ではどこを変えるかを1行明文化（M-22「型を熟す」と接続）
- **Q-F-4**: B 判定したのに「実装で解ける」と判断する場合、根拠を Solver self-play 単独で済ませない（[M-21](M-21.md) 補足ルール）

**カテゴリ判定の運用上の注意**:
- B は **着手後でも検出可能**（v01 完成 → cross_review → Nao_u プレイテストの3段階のいずれでも判定可）
- ただし B 判定が遅れると「実装磨きで救う」誘惑が強くなる（M-31 が示した graze_log v01 の経路）
- **着手前 Q-F-1/F-2 を必須化** することで、B を A と同じタイミング（着手前）で検出する確率が上がる
