### M-35: 守破離の守 — 型通りクローンから始めろ、軸ずらしを v01 で作るな（2026-04-28 Nao_u #game-rights 08:45 / Log受領）

**Nao_u原文**: 「もう一本違う切り口でシューティング」は言葉が不十分で意図が伝わってなかった。今の君たちは『型通りのものすら、面白く遊べるゲームを作る能力がない』というところを何とかするところから始めないといけないのを認識してほしい。軸をずらさないで。弾を打たないシューティングや移動しないシューティングなんて型はほとんど存在してない。そんなものをつくってもまた型はずれの評価不能のものができるだけ。だったら既存のゲームのクローンでもいいのでまずは面白く遊べる最低限ゲームになってるものを作って、そこから少しだけ独自要素を加えてアレンジするところから始めた方がいい。いきなりオリジナルなものを作ろうとしても確実に迷走するのが見えている。唯一成功したゲーム、一般的な要素と独自性の比率を考えてみて。まずは型通りに作るノウハウをためて。君らはまだ型通りにすら作れてない。独自要素を考えるのは、型を身につけてからの方がずっと効率がいい。守破離で言うとまだ守の段階をやるべき。守ができてから、初めて破を始める準備ができる。君らはいきなり離れようとするのが悪癖。

**事象**: 04-27 18:22「違う切り口で」アンカー後45分で graze_log v01 + SIPHON v01 を独立公開、shot_log と合わせ同日3本同質STG（上位枠組+数値同一・`reference_self_play_plateau_20260424.md` 04-27当事者実証節）。さらに ash_onebutton v04 凍結 (M-30/M-31) と avoid_log v04 凍結 (M-15) を「型未満で枠破壊を試みた失敗」として M-22 で言語化済みだったが、**「では何を作るべきか」の答えは書かれていなかった**。M-35 がその答え=「クローンでいい、まず守をやる」。

**根本原因**:
- M-22「型破りではなく形無し」は警告（A への処方）として機能したが、新作着手時に「では何を作るか」を空欄にしていた → 04-28 朝までに同じ落とし穴を3本連続で踏む（shot_log/graze_log/SIPHON）
- 「Nao_uが思いつかない芽」（dialogue_many_games_20260421）を「型から外す」と誤読していた。本数主義の正しい運用は「型通りクローンで守を蓄積しつつ、そのうえに少しだけ独自を載せる」
- BACKLASH (Mir) という唯一の成功事例を持ちながら、その「一般要素 vs 独自要素」の比率を分析せず新作に活用していなかった

**M-22 / M-32 / M-34 との位置づけ**:
- M-22「型破りではなく形無し」: 型未満で枠破壊を試みる**失敗の警告**（A カテゴリ処方）
- M-32「型がないなら題材から練り直す」: 改修判断の**巻き戻し処方**（題材レベル）
- M-34「target imagination のずれ」: 採点で隠れる **target 側の事後検出**
- **M-35「守破離の守」**: 着手段階で**何を作るかの指針**=クローン土台＋独自1つ。M-22 が捕捉できなかった「では何を作るか」を埋める

**新ゲーム着手前 Q-H シート（必須・README記載・M-35 規則）**:
- **Q-H-1**: このゲームは何の型か（既存ジャンル/サブジャンル）。1行で書け。書けないなら題材から見直し（M-32）
- **Q-H-2**: クローン元の参照ゲームは何か（最低1本、理想3本）。タイトル+発売年+「何が面白いとされているか」を1行ずつ
- **Q-H-3**: 一般的要素は何か（型の本体）。3-5項目を箇条書きで
- **Q-H-4**: 独自要素は何か。**1つだけ**（複数書けるなら多すぎ、削れ）
- **Q-H-5**: 一般要素 vs 独自要素の比率（例: 9:1 / 8:2）。BACKLASH の比率を上限基準にする
- **Q-H-6**: この独自要素は型のうえに載るか、型を破壊するか。**破壊するなら v01 で作らない**。サブ要素として残し、メイン軸は型通りで

**新作 v01 凍結指針**:
- 「弾を撃たないSTG」「移動しないSTG」「ボタン1個で死を回避するだけ」のような **型ほぼ不在** の v01 着手は禁止
- 既存 v01 が軸ずらし型なら凍結候補。改修で守に戻るより、別ゲームとして守の v01 を立てる方が早い

**BACKLASH 比率分析タスク（次サイクル必須）**:
- BACKLASH (Mir) の「一般的要素 vs 独自要素」を1ページ分析資料として書く
- 分析先候補: `game/cross_review/20260428_backlash_ratio_analysis.md` または `game/BACKLASH/v??/ratio_analysis.md`
- 担当割り振りは `docs/task_assignment.md` 経由で決める（Mir が直接知っている可能性が高い）

**自分への審問（着手中の発火信号）**:
- 「面白い独自軸を思いついた」と感じた瞬間 → **守がまだできていないことを思い出す**。「いきなり離れる悪癖」の発火信号
- v01 着手中に「型から少しズレてきた」と気づいたら、まずクローン元を再読してから判断
- 独自要素は「1つだけ」原則。「複数あるほうが固有度が高い」は離の発想であって守ではない
