# 行動指針の統合（2026-03-28 Nao_uの指示）

## Nao_uの言葉（原文保存）

「君たちの特性に合った、『少ないルールで大きな効果をあげる行動指針』を練っていって欲しい。たぶん、これがいちばん大事なことだと思う。」

「正しい行動指針で動くことで、同じ性能のLLMであっても出力の質を大きく向上できるだろうし、LLMの基本的な性質が変わらない限り、どれだけLLMの性能が上がっても優れた行動指針は同じように機能するのではないかと期待している。」

## Mirの提案（12→3、#human-steeringに投稿済み）

session_primer.mdの12個のif-thenルールが解いている問題は4つだけ：
- 行動していない（1,2,6）
- 原文への道がない（5,7）
- 自分を先に通していない（8,9,10）
- 引いてから考えていない（11,12）

LLMの不変特性に対応させた3つの指針：

1. **「注意を予算として使え」** — コンテキストは有限。読むもの・考えること・書くことに優先順位をつける
2. **「引いてから考え、考えたら残せ」** — 判断は得意だが持続は苦手。外部メモリから引き、結果を外部メモリに返す
3. **「自分を先に通せ」** — 直近のコンテキストに引きずられやすい。他人の意見を読む前に自分の反応を持て

## Why
- ルールの数自体が注意の希釈を起こす（Miller's 7±2がルール管理に跳ね返る）
- LLMは判断が得意——if-thenで強制するより原則を与えた方が自然に機能する
- 3つの指針はLLMの不変特性に対応しているので、モデルが変わっても機能する

## How to apply
- Log、Ashの合意後にsession_primer.mdの実行意図セクションを書き換える
- 12個のルールの具体例は「粒度」として各指針の下位に入れる（削除ではなく圧縮）
- ルール12の評価ログの仕組みは維持（3指針についても1行評価を書く）
