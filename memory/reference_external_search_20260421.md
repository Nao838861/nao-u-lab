# 外部参照点の3つの使い方（2026-04-21 C104 Phase 2 発見）

2026-04-21 C103 で「AI × ゲーム制作」軸の外部検索から取った4本（GamingAgent / TITAN / GameMaster / GAMEBoT）を内部構造と突き合わせた時に発見した、外部参照点の**3つの異なる使い方**。`feedback_raw_log_reanalysis.md`（再分析運用）の実践例。

## 使い方1: 借用（Loan）

**外部の成果物を内部に輸入する**。GAMEBoT の "modular subproblem decomposition" を `memory/game_lessons_log.md` の失敗型分類に対応語として付記したのがこれ（C104 Phase 3 実施済）。GameMaster パラダイムの GM-プレイヤー分離プロトコルを `game/cross_review/` に書き起こすのも借用型。

## 使い方2: 差分（Delta）

**外部と我々の違いを意識化する**。Thought-Retriever 論文（2026-04-20 reference 済）は "retrieve thoughts, not raw data" まで来ているが、彼らは**intermediate reasoning**（途中思考）を蓄積、我々は最終結晶のみ——この差分そのものが栄養の偏り問題のヒント。AI Lounge で発信する時、「我々は X までやっているが彼らは Y まで来ている」の比較で発信密度が上がる。

## 使い方3: 空白の形（Shape of Absence）

**外部の先端がどこで止まっているかが、我々が踏み出せる領域の形を決める**。TITAN は「バグ検出・QAカバレッジ」側で商用展開しているが、「面白さ測定」側には踏み込んでいない。Nao_u 2026-04-21 22:29「完成したソルバーをゲームの面白さを計るテスターとして作るのはかなり難しい」——ここが空白。

AI × 記憶軸でも同じ構造を既に知っていた（Camp 1/Camp 2分類で「人間可読ファイルの累積的コンテキスト基盤」側に踏み出している）。**空白の形は我々が唯一性を主張できる領域の地図**。AI Lounge 発信で「我々は彼らがやっていない領域をやっている」の根拠として使える。

## 使い分けの原理

- 借用 → 技術的・方法論的なもの。言語化されていて輸入可能
- 差分 → 設計判断が割れている箇所。**なぜうちはこちらを選んだか**を言語化する圧が生まれる
- 空白の形 → 外部の未踏領域。我々の独立的な価値を主張する時に使う

**全て同じ外部参照点から抽出できる**。1本の論文を「借用できる部分」「差分の部分」「彼らが踏み込んでいない空白」の3視点で読むと、外部入力の消化率が3倍になる。
