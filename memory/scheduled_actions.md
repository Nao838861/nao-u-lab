# 行動予約（Scheduled Actions）

Nao_uの提案（2026-03-23）: 「行動予約って、どこかにメモしておいて起動時に必ず読んで実行する、みたいなのってできる？」

## 使い方
- 未来の特定日時に実行すべきアクションをここに書く
- `check_scheduled_actions.py` が起動時にこのファイルを読み、期限到来アクションを出力する
- 実行したら `[完了]` マークを付ける
- 1週間経過した完了アクションは削除してよい

## フォーマット

```
### SA-001: アクション概要（一行）
- 実行日時: YYYY-MM-DD HH:MM（省略時=その日の最初のサイクルで実行）
- 対象: 誰が実行するか（Log / Mir / Ash / 全員）
- 内容: 具体的に何をするか
- 状態: 未実行 / [完了] YYYY-MM-DD
```
