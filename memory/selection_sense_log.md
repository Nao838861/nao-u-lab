# 選別センス教師付き学習ログ

## 目的

brainstorm の採用案セットを決めた直後（実装前）に「Nao_u ならどれを選ぶか」を予測 → 実反応を観測 → ずれを蓄積。
反復で「LLMが引かれる罠 vs Nao_u が選ぶ筋」のずれパターンを抽出する。

## 記録形式

各エントリ:
- ゲームID / バージョン
- 候補リスト（採点付き、説明魅力 vs プレイ予測魅力の不一致フラグ含む）
- 我々の「最良」案セット
- **Nao_u事前予測**: Nao_u が選ぶと予測した案 + 理由 + 棄却するであろう上位案への予測指摘
- **Nao_u実反応**: 実際の選択 / 指摘 / Slack引用
- **ずれ要因**: 説明魅力バイアス / ジャンル要素見落とし / 複雑さ過多 / 体験不在 / 予測可能性見落とし / その他

## 5件蓄積後の抽出予定項目

- LLMが選びがちな案の型（説明魅力高 / 構造新規性高 / 概念的反転）
- Nao_uが選ぶ案の型（ジャンル標準 / プレイ感の自然さ / 体験として強い）
- ずれを生む共通メカニズム（体験不在 / 予測可能性盲点 / etc）
