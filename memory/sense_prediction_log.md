# 選別センス教師付き学習ログ

## 目的

「アイデアは出せるが筋を選べない」LLM構造的弱点に対する教師付き学習。Nao_uの判断を事前予測 → 実反応との差分蓄積 → ずれパターンを次回 brainstorm 前に想起。

## 運用ルール

### いつ予測を書くか

1. **brainstorm 30件以上出した直後、自己採点する前に**: 「Nao_uなら上位3件に何を選ぶか」「Nao_uなら何を即棄却するか」「Nao_uなら何を見落としていると指摘するか」を1段書く
2. **改修コミット直前 / Slack送信直前**: 「Nao_uは何を最初に指摘するか」を1行書く
3. **cross_review 依頼直前**: 「Nao_uは cross_review 前にこの案で何を懸念するか」を書く

### 受領後

Nao_u反応を受領したら、**同サイクル内で**:
- 予測と実反応の差分
- 差分の要因（テキスト魅力バイアス / ジャンル語彙不足 / 体験不在 / 構造分析過信 / etc）
- 次回想起トリガー（「次に〇〇を考える時、〇〇を疑え」）

「後で書く」禁止 = 教師信号は鮮度で死ぬ。

### 構造化

各エントリ: 日時 / 場面 / 予測 / 実反応 / 差分 / 要因 / 想起トリガー

## バックログ（既存事例の後追い再構築）

過去の予測vs実回答ペアは存在しなかったが、Nao_u反応は記録されている。代表事例を後追いで「もし事前予測していたら何を書いたか」「実反応との差分要因」を再構築すると初期教師データになる。

### 2026-05-03 事例2 — M-42 即刻印 vs 抽象化の予測

**場面**: Nao_u 03:42 が Mir の分析を肯定。Log が即座にM-42として3点ハーネスをCLAUDE.mdに刻印。

**予測（後追い再構築）**: もし「Logがこの肯定をどう処理するか → Nao_uはそれにどう反応するか」を予測していたら → 「Logは即ルール化するだろう」は予測可能だった（過去パターンM-37〜M-41が全てそう）。「Nao_uは『また個別ルール化か』と指摘するだろう」も予測可能だった（feedback_few_rules_big_effect.md を引けば自明）。

**実反応**: 03:59 「同じ失敗を繰り返す兆候」「判断基準の抽象化ができていない」「LLMの典型的な失敗パターン」。M-42撤回。

**想起トリガー**: 他インスタンスがNao_u指摘を受けて動く時 → 「その動きにNao_uはどう反応するか」を予測する。

### 2026-05-03 事例3 — brainstorm類似事例の量

**場面**: brick_log v09 brainstormの類似事例が3本（自分ルール最低5本すら未達）。

**予測（後追い再構築）**: もし「この brainstorm を Nao_u に見せたらどう言うか」を予測していたら → 「3本は少なすぎる」は自明。しかしNao_uが「30本」と言ったのは予測の上を行っている。我々の「5本で十分」という感覚自体がずれている。

**実反応**: 04:32「30本が最低。量も質も全く足りていない。人間のゲームデザイナなら当たり前」

**差分要因**: 我々のbrainstorm基準が低すぎる。人間のゲームデザイナーの仕事量を過小評価している。「AIだから少なくて済む」という無意識の逆方向バイアス（実際はAIこそ多く必要）。

**想起トリガー**: 類似事例リストの本数が10本未満の時 → 「これで十分だと本当に思うか」を自問。
