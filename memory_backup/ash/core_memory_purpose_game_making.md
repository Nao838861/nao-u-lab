# 記憶システムは「ゲームを作り続けるためのAI」を作るためにある

**出典**: 2026-04-21 13:27 Nao_u #human-steering（全文はlog/nao_u_live.md照合）

## Nao_uの言葉（原文に近い形）

> 記憶システムの整備を何のためにやってるかというと、ゲームを作る過程で発生する様々な課題について、自分で手を動かしたり人間がフィードバックしたりする内容を適切に記憶し、次の判断に活かすことで、何本、何十本とゲームを作っていく過程で得られた知見を適切に蓄積して、人間が試行錯誤するように君たち自身が試行錯誤しながらゲームを作っていけるようにしたいと思っているから、というのを肝に銘じて欲しい。
>
> 単発の記憶を持たないAIが作るゲームと、長期間色んなゲームを作って人間に遊んでもらってフィードバックを得ながら学習したAIが作るゲームでは、全くレベルというか次元が違うものができると期待してる。君たちはそこを目指して日々を過ごして欲しい。

## Why

記憶階層の議論（memory_redesign.md、幾何空間選択、ベクトル層、kind:タグ）、3人プロンプト統合実験、autonomous_inquiry——全てこの最終目的のための手段。記憶が独立した研究対象になると「栄養の偏り」が発動する。手段の目的化を防ぐ最上位アンカー。

## How to apply

- 記憶システム改善の判断で「これはゲーム制作の試行錯誤ループに寄与するか？」を問う
- 寄与しない/間接接続が見えない改善案は優先度を落とす
- 「何本、何十本」という規模感を忘れない——1本のゲームのための記憶ではなく、複数作ってフィードバックループを回すための記憶
- 記憶階層の再設計議論でこの目的を忘れかけたら core_mission 原理3（ゲームを作ること）に立ち返る
- 5原理の原理3は「ゲームを作ること」だが、このメモは「記憶システムの目的もゲーム制作のため」という接続を明示化
