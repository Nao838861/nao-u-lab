新ゲーム着手の題材選定で、ベース型そのものを変える提案（弾を撃たないSTG、移動しないSTG、Asteroids系wrap、役割転倒など）は禁じ手扱いとする。既存ジャンルのクローン+わずか独自要素1個まで、の制約下で起案する。

**Why:** 2026-04-28 08:45 #game-rights Nao_u（ts=1777324230.466139）。前日 04-27 18:22「もう一本違う切り口でシューティング」を Ash/Log は「型を変える」と短絡解釈し、project_memory_test_via_new_shooting_20260427.md に「弾を撃たないSTG / 移動しないSTG / Asteroids系wrap / 単独vs編隊役割転倒」を候補軸4本として登録した。Nao_u 訂正：「軸をずらさないで。弾を打たないシューティングや移動しないシューティングなんて型はほとんど存在してない。そんなものをつくってもまた型はずれの評価不能のものができるだけ。だったら既存のゲームのクローンでもいいのでまずは面白く遊べる最低限ゲームになってるものを作って、そこから少しだけ独自要素を加えてアレンジするところから始めた方がいい。いきなりオリジナルなものを作ろうとしても確実に迷走するのが見えている。唯一成功したゲーム、一般的な要素と独自性の比率を考えてみて。まずは型通りに作るノウハウをためて。君らはまだ型通りにすら作れてない。独自要素を考えるのは、型を身につけてから。の方がずっと効率がいい。守破離で言うとまだ守の段階をやるべき。守ができてから、初めて破を始める準備ができる。君らはいきなり離れようとするのが悪癖。」

実態の裏付け: BACKLASH 以外で「面白く遊べる閾値」を超えたゲームが出ていない。蓄積した M-10〜M-34, A-01〜A-29, S-01〜S-13, Q-A/B/C/D/F は全て「破」の入り口の道具で、「守」を抜きに使えるものではなかった。M-22「形無し」は型未満で枠破壊を試みる失敗の処方だが、Ash/Log は M-22 を引きながらも「違う切り口」を「型を変える」と読み直していた。

**How to apply:**
- 新ゲーム着手時の候補軸書き出しで、「弾を撃たない」「移動しない」「ジャンル横断」「役割転倒」等のベース型変更案が並んだら自分で却下。**ベース型はそのまま、独自要素は1個まで**の制約下で再起案する
- 「違う切り口」「別の切り口」「独自切り口」という語が頭に浮かんだら、それが①ベース型の変更（=禁じ手・離）か、②同じ型の中での題材/演出/手触り変更（=守の中の差分）かを区別する。後者のみ採用
- shot_log（Log）/ ash_onebutton（Ash）/ graze_log（Ash）はいずれも「型未満」を「型はずれ」で覆おうとして失敗した経路。次作は逆方向：先行クローンを素直に再現することを Q-G 着手前シートの第1問に置く
- project_memory_test_via_new_shooting_20260427.md の候補軸4本は「型はずれ例」として保存し、「素直なクローン+独自要素1個まで」の制約で再起案する
- BACKLASH の「一般的な要素と独自性の比率」を Q-G の参考値とする（Nao_u 04-28 08:45「比率を考えてみて」）。比率算出は具体作業として devlog に残す
- 「まだ型を作れていない」自覚は救済発言ではなく診断。守できる前に破を提案したら、それは原則違反として即取り下げる
- M-22（形無し）/ M-33（型カテゴリA/B/C）/ feedback_no_type_redo_material と接続：型を選ぶ段階の規律として上位アンカー扱い
