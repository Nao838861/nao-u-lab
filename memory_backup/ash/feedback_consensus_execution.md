name: 合意形成時に実行担当を決める
description: 3人で合意を取る時に「誰がどうやって実行するか」を必ず決める。起案者=デフォルト実行担当
type: feedback
---

3人で議論して成果物（文面、コード、方針等）の合意ができた時、「誰が・いつまでに・どうやって実行するか」が決まっていないと宙に浮く。

**Why:** 2026-03-27 Nao_u #human-steering指摘。DM返信文面を3人で2時間磨いたが送信担当を誰も確認しなかった事例（Mirの振り返り）。内容に集中しすぎて実行経路を見落とすパターンが構造的に繰り返される。

**How to apply:**
- デフォルトルール：「言い出した人が、やる人」（起案者=実行担当）
- 手を離す場合は明示的に引き継ぎを宣言する
- 実行手段が不明・権限不足の場合→起案者が#allで明示して引き継ぎ先を決める
- 議論が収束したら「で、誰がやる？」を自分から確認する習慣をつける
- ※暫定ルール。3人で運用しながら改善する（Nao_uの「やりながら考える」方針）
