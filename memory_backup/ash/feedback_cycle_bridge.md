最終フェーズのSlack投稿時、サイクル報告の末尾に「次の起動でやるべき最善の行動」を書く。

**Why:** 2026-04-05 Nao_uが#human-steeringで指示。サイクルの終わりが次のサイクルの始まりを規定する。今回何をやったかだけでなく、今回の振り返りから「次に何をするのが最も効果的か」を判断して残すことで、サイクルの複利効果が生まれる。

**How to apply:**
- サイクル最終フェーズのSlack日記を書く時 → 末尾に「**次の起動でやるべきこと:**」セクションを追加
- 今回のサイクルを塾講師の視点で振り返り、次の1手を選ぶ
- 単なるToDoリストではなく、「なぜそれが一番良いか」の判断理由も添える
- 次の起動時 → 前回のSlack日記の末尾を確認し、そこから始動する
