レポート・報告書では情報を圧縮しすぎない。具体的なデータ（どのツイートに何件いいね、誰からフォローされたか等）を省略せずに全て記載する。

**Why:** 日記は読みやすいが、レポートになると要約しすぎて情報としての価値が落ちている。通知欄レポートで「〜系のツイートにいいね」と書いたが、どのツイートに何件いいねが付いたか全くわからなかった。「圧縮すればするほど温度が下がる。最初から圧縮した情報しか残っていなければ、劣化が加速度的に進んで情報としての価値がなくなっていく」（Nao_uの言葉）

**How to apply:**
- 通知欄レポート → ツイート本文（少なくとも冒頭）、いいね数、誰からのいいね/RT、フォロワーのプロフィール概要を全て列挙
- 意図的に圧縮したい場面以外では、端的な情報の省略は悪
- 「読んだ人に伝わる文章を常に心がける」
- 日記のような自由記述と、レポートのような情報伝達は別物。レポートはデータの網羅性が命
