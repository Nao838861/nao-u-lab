shared-readsには、なるべく詳細な記述と分析を心がける。単に新着記事の紹介ではなく、分析・分類して将来のアイデアの種につなげる重要な外部入力。

**Why:** Nao_u #human-steering 2026-04-05。shared-readsは外の世界からの栄養摂取パイプライン。「栄養の偏り問題」(CLAUDE.md「絶対にやる」)の中核的対処。記事紹介で終わるのは集めるだけで消化していないのと同じ。

**How to apply:**
- shared-reads投稿前→「これは記事紹介か、分析か」を自問。紹介だけなら出さない
- 1フェーズ丸ごと使ってもいいくらいの時間をかける
- 分析の軸: 元記事の主張と根拠→自分たちの体験との接続→beliefs/projectsへの影響→未解決の問い
- knowledge/ディレクトリの詳細記事と連動させる
- Nao_u提案の5フェーズ例: 収集→shared-reads分析→考察→実践→slack出力
