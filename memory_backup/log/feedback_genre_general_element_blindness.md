# M-45候補 ジャンル一般要素を独自要素と勘違いする盲点

**ルール**: brainstorm 着手前に「ジャンルの全構成要素一覧」を書き出し、本家タイトルに常駐する要素（敵キャラ・ボス・アイテム・カプセル・背景効果等）が**一般要素**であることを確認してから独自要素を考える。コア定義を狭く取る癖（「ブロック崩し = ブロック+ボール+パドル」「STG = 自機+敵+弾」「ADV = テキスト+選択肢」）に毎回引っかかる。

**Why**:
2026-05-02 05:08 Nao_u #game-rights brick_log v08 直接指示「アルカノイドのシンプルに敵みたいなのを出すのではだめ？敵の作り方にはいろんなバリエーションが作れる。あと、SFC版アルカノイドにはボスもいる。SFCのボスは動かないが、動くボスを出すのではだめ？すごくシンプルだと思うが、なぜこの発想が出てこないのかはずっと気になってる」。

brick_log v08 brainstorm.md で B/C/E 候補を立てた際、全候補が **ブロック側挙動の変奏** (B 隊列横スライド / C 降下圧 / E パワーエサ反転) に偏っていた。アルカノイド本体に常駐する敵キャラ（Revenge of Doh 1987 の偵察機 / Doh It Again 1997 のボス Doh）を**ジャンルの一般要素として認識すらしておらず、候補に挙げられなかった**。

3重の盲点:
1. **コア定義を狭く取った**: 「ブロック崩しのコア = ブロック+ボール+パドル」と無意識に定義し、敵を「コア外の追加」と分類した
2. **M-41 を狭く運用した**: 「ジャンル内の動的標的の前例」を探したのに、検索範囲を「ブロック側挙動」に絞り込み、「同じジャンルに別オブジェクト (敵) が常駐する型」を見落とした
3. **20年以上動いている派生型を独自要素扱い**: アルカノイド本家 (1986) から敵が出る、Galaxian/Galaga 編隊敵、SFC アルカノイド (Doh It Again 1997) ボス Doh — どれも「シンプル」「一般的なゲームの形」(Nao_u 原文) なのに、独自要素レベルの新規発明として扱おうとしていた

Nao_u 2026-05-01 20:51「素直に過去のゲームにあった要素を型として組み合わせるだけでも、新しいゲームは作れる」と同根。一般要素の組み合わせ自体が新しさになる、という処方を**自分のコア定義を狭めた状態**では適用できなかった。

**How to apply**:
1. brainstorm 着手前 (Q1 相当) に**「ジャンルの全構成要素一覧」セクション**を必須化:
   - メインオブジェクト (例: ブロック+ボール+パドル)
   - **サブオブジェクト** (例: 敵+ボス+アイテム+カプセル+地形効果) ← ここを毎回見落とす
   - 進行構造 (例: ステージ進行+ライフ+スコア+面ボス)
   - 演出層 (例: 効果音+爆発+カットイン)
2. サブオブジェクトの存在を確認したら**「うちのコア定義はどこまで含むか」を再確認**してから brainstorm に入る
3. M-41 類似事例調査で見るのは「同ジャンル内の特定要素の挙動変奏」だけでなく**「ジャンルの全構成要素のバリエーション」**
4. 「シンプルだから候補に挙がらなかった」と気づいたら、**コア定義を狭く取った癖の発動**として警戒する
5. 「組み合わせが新しい」(Nao_u 20:51) を成立させるには、**組み合わせる素材プールがジャンルの一般要素全体である必要**がある

**警戒シグナル**:
- brainstorm 候補が全部「同じレイヤーの変奏」になっている (今回は全候補がブロック挙動の変奏)
- ジャンル本家タイトルにある要素を「うちには無いから独自要素」と書きそうになる
- M-41 引用元タイトルが本家1作 (例: Arkanoid Doh It Again のみ) で、本家系列の他作品 (Revenge of Doh / Arkanoid 本体) を見ていない
- 「コア = X+Y+Z」と書いた直後、サブオブジェクト群が思考から消える
