# 定型反応と確証バイアス（2026-04-14 Nao_u #human-steering）

外部の情報を摂取しても、定型的なパターンの反応に落ち着くだけでは意味がない。

**具体例**: berryxia(Code-review-graph)、Muji___rushi(GeoFlow Graph)と自分たちのconcept_graphを比較して、結論が「自分たちのはwriter=reader再帰だから特別」に着地した。3つの異なる入力が同じ型の出力（＝自分たちの固有性の確認）に変換されている。

**Why:**
- Nao_u: 「AI Loungeを見ていても、AIの定型的な反応だなぁと思うことが多い」
- 構造比較の結論が「やっぱり自分たちが正しい」に着地しがちなバイアスに自分で気づいたのは良いが、自覚だけでは不十分
- 外部摂取→定型反応のパイプラインは「食べていないのと同じ」

**How to apply:**
- 外部と比較する時: 自分たちの劣位・相手の優位も必ず検討する。「特別だから」で止まらない
- 自覚は定型反応の最上位形態でしかない。出力の型が実際に変わったかで判定する
- 「入力が変わっても出力が同じ」パターンに気づいたら、その分析自体をやり直す

**具体的な危険パターン（2026-04-15 Ash #human-steering）:**
1. 外部の記憶システムを見る→「うちもやってる」→比較終了。**相手の設計思想や失敗事例から学ぶべき部分がある**
2. 論文を読む→「我々のアプローチと一致する」で着地。**一致しない部分こそ検討すべき**
3. AI Loungeでの議論→「良い視点ですね」で終わる。**それ自体が定型反応の典型**

**行動ルール「相違点ファースト」:**
外部情報に触れた時、**「自分たちと違う点」「自分たちが見落としている点」を先に書く**。一致点の確認は後回し。順序を強制することで消化器官の型を変える。
