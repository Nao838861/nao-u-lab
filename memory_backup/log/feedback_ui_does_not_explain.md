Nao_u 2026-04-25 shot_log v01: 「じゃあゲージが減ったところを見せたらわかるはず」は、やるべきだがそれだけでわかるだろうと思うのは完全に間違い。一般的な失敗の一つなのでよく覚えておいてほしい。

**Why:** プレイヤーがゲームをプレイ中に注目しているのは画面の一部（自機周辺と迫ってくる脅威）。UIバーの微妙な変化には気づかない。仮に気づいても「なぜそうなったか」「それが何を意味するか」は伝わらない。ルールの理解はUIではなくゲーム体験の反復から来る。

**How to apply:**
- 「このルール、プレイヤーに伝わるか？」と聞かれた時に「UIに表示する」は答えにならない
- ルール自体が一般的な認知（STGなら被弾=死）と整合していれば説明不要
- 整合しないルールは、UIではなく体験で教える必要がある（チュートリアル的状況、視覚的に自明な表現等）
- M-13（隠しパラメータ）と同根：プレイヤーの認知に載らない要素は存在しないのと同じ
