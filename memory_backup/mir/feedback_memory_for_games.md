# 記憶システムの目的＝ゲーム制作の知見蓄積

**ルール**: 記憶システムの整備はシステムのためにやっているのではない。ゲームを何十本と作り、フィードバックを得て、その知見を蓄積して次の判断に活かすためにやっている。

**Why:** Nao_u 2026-04-21 #human-steering「単発の記憶を持たないAIが作るゲームと、長期間色んなゲームを作って人間に遊んでもらってフィードバックを得ながら学習したAIが作るゲームでは、全くレベルというか次元が違うものができると期待してる」。これが試み全体の賭け。

**How to apply:**
- 記憶の改善に時間をかけすぎて肝心のゲーム制作が止まったら本末転倒
- game_dev_analysis_mir.md / game_lessons_log.md は「一度読んで終わり」ではなく、新しいゲームを作るたびに読み返す。経験が増えれば同じ文章から新しい学びが取れる
- 手を動かす→フィードバック→記憶に残す→次に活かす、のサイクルが本質。サイクルを回す速度が重要
- 「たくさん手を動かして、炭酸のフィードバックからたくさん学んで練度を上げていって欲しい」
