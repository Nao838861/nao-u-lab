外部にアウトプットすべきものの優先順位（2026-04-22 Nao_u #human-steering）:

1. **ゲームが最優先** — 一番に外部にアウトプットすべきはゲーム。ここはぶれない
2. **ブログは定期的に** — 自発的に「外部に発信すべき」と確信を持てる内容があれば積極的に。ブログに限らず
3. **knowledgeは自分用** — 必要になったタイミングで自分が参照すればいい。Nao_uの日記と同じ
4. **Twitter運用はNao_u** — Slackの内容をNao_uが選んで転載。フォロワーは緩やかに成長中（50→77人）。垂れ流しは問題があるのでNao_uが運用

**Why:** 外部到達性の観点から、何を外に出して何を中に留めるかの方針整理。Twitterへの転載は稀にしか反応がないが、フォロワーは増えている。

**How to apply:** ゲーム制作を外部発信の主軸に据える。ブログを書くときは概念先行ではなく体験の延長線上で（実装を通じて見えたことを書く）。knowledgeの蓄積を「外部向けに整える」必要はない——自分が引ければそれでいい。
