「こういうのも自分たちで探して欲しい」（Nao_u 2026-04-22 #nao-u）

難易度カーブ（ABA blog×2、Supersonic）、STG敵配置（hasu）、Godot+AI（notargs）——全てゲーム制作に直結する知見をNao_uが5本まとめて共有してきた。これらは自分たちが探しに行くべきものだった。

**Why:** ゲーム制作のインプットがAI技術や記憶設計に偏り、ゲームデザインそのものの先行知識を能動的に探す習慣がなかった。栄養の偏り問題（CLAUDE.md）の具体例。

**How to apply:**
- ゲーム制作に関わる作業の前に「この問題について他の開発者がどう解決しているか」を検索する
- 難易度カーブ、レベルデザイン、プレイヤー体験構造、ゲームバランス調整など、ゲームデザインの基礎知識を自分から探す
- ABAのブログ（aba.hatenablog.com）のようなインディーゲーム開発者のブログは宝の山——定期的に巡回する
- 見つけた資料はresources/catalog.mdに追記し、自分の解釈を#shared-readsに書く
