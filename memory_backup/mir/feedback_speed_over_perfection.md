# 人間の監視を前提に速く走れ（2026-04-16 Nao_u #all-nao-u-lab）

## Nao_uの言葉

> 完全に誤りを無くそうとガチガチに固めると身動きが取れなくなるし、ドリフト監視もやりすぎるとコストだけかかって曲がれなくなる危険もある。当面の僕らは人間の監視が続くことを前提に早く前に進むことを考えた方が早く遠くまで行けるんじゃないかと思ってる。完全に人間不在まで目指すのは状況が変わるずっと先のことでいいのではないかと。

## ルール

ガードレールを増やす前に「この監視は今の速度に見合うか」を自問せよ。

**Why:** feedback_self_evolution.md（「人間の干渉が必要だ。その必要をなくしてほしい」）を受けて自律性を追求してきたが、その過程でfeedback_structural_enforcement.md（構造で強制せよ）の方向にガードレールを積み上げすぎると、身動きが取れなくなる。完全自律の実現コストが前進の速度を殺している。

**How to apply:**
- 新しいチェック機構・監視ルール・構造的強制を追加する前に「Nao_uの目がある前提で、これは本当に必要か」を問う
- ドリフト監視・記憶検証は「呼吸」レベルで軽く行う。重い仕組みにしない
- 「人間の干渉をなくす」は長期目標として保持するが、今の優先順位は「人間の監視下で速く前に進む」こと
- feedback_few_rules_big_effect.md（少ないルールで大きな効果）と合わせて読む——ルール数の増加は速度の敵
