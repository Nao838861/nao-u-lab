## 測定項目 5件

### M-1: 記入率（quantitative / 習慣定着指標）

**定義**: 29サイクル中、Phase 3 末尾（または自己評価ログ末尾）に「具体的失敗」が記入されたサイクルの割合。

**計測方法**: 各サイクルのログで「失敗」「持ち越し」「未達」「繰越」等のキーワードを含む記述があり、かつ**固有の事象**が書かれているかを判定（空欄・「なし」・前サイクルコピーは除外）。

**閾値**:
- 80%以上 = 定着
- 50-80% = 部分定着
- 50%未満 = 未定着

**仮説**: 95%超。習慣としては既に定着、むしろ過剰。

---

### M-2: 自己検出率 vs 他責記入率（qualitative / 自律性指標）

**定義**: 記入された失敗のうち、「自分で検出した失敗」と「他者指摘後に記入した失敗」の比率。

**計測方法**: 各失敗エントリを以下に分類:
- **A. 自己検出**: 誰にも指摘されず自分で気づいた失敗（例: C83 textadv_03 送付未達を自分で発見、C95 自情報ズレ3例目自己検出）
- **B. 他者指摘反映**: Nao_u/Log/Ash の指摘を受けて記入（例: Nao_u #human-steering 指摘後の反省）
- **C. 構造強制発動**: staging Pre-check / 自動チェックで検出

**仮説**: A:B:C = 7:2:1 程度。C95 以降は A の比率が上昇しているはず。

**意味**: 自己検出率が5原理の5番目「自分の記憶を自分で守り育てる」自律性の定量指標になる。

---

### M-3: 失敗→構造強制化率（architectural impact）

**定義**: 記入された失敗のうち、後続サイクルで**構造強制**（kaizen起票、ルール追加、Pre-check項目化、ファイル新設）に昇格した失敗の割合。

**計測方法**: 各失敗エントリについて、C70以降の staging / kaizen_tracker / memory/feedback_*.md / .claude/rules/ 系で該当失敗が構造化されたか追跡。構造化の形態:
- (a) kaizen 起票（番号付き）
- (b) memory/feedback_*.md への新規エントリ
- (c) staging Pre-check への項目追加
- (d) 新規ルールファイル作成（.claude/rules/*.md）

**閾値**:
- 30%超 = 学習ループ機能
- 10-30% = 部分学習
- 10%未満 = 記入するだけで活用されていない（dinner question の形骸化）

**仮説**: 25%前後。過半数は同種失敗の再発で終わり、構造化されるのは少数。**これが本測定の肝**——記入の習慣化だけでは防げない失敗がどれほど残っているか。

---

### M-4: 同種失敗の再発間隔（recurrence analysis）

**定義**: 同一カテゴリの失敗が何サイクル置きに再発しているか。

**計測方法**: 全失敗を以下カテゴリに分類し、再発間隔の中央値を算出:
- **F-1. 先延ばし系**: 着手宣言→実行せず（例: drafts 自動削除kaizen起票、失敗slot測定自体）
- **F-2. 自情報ズレ系**: 報告内容と実体ファイルの乖離（C88/C94/C95/C96の4例）
- **F-3. 観測漏れ系**: 送付確認/既存資産確認/反応観測の機械確認漏れ
- **F-4. 焦点散逸系**: 複数焦点並置時に弱い方が飛ぶ（C71/C89/C96）
- **F-5. 造語症系**: R-007 外部対応語併記忘れ
- **F-6. その他**

**閾値**:
- 再発間隔 > 10サイクル = 学習進行
- 再発間隔 ≤ 5サイクル = 慢性化

**仮説**: F-2 自情報ズレ系は再発間隔 3-5サイクル（C88→C94→C95→C96 は急速再発）。F-1 先延ばし系は再発間隔 1-2サイクル（チェーン状）。

**意味**: カテゴリ別の慢性化パターンを可視化。構造強制の優先順位付けに使う。

---

### M-5: 失敗記入→直後サイクル行動変化率（behavioral feedback）

**定義**: 失敗記入したサイクルの**直後サイクル**で、その失敗に対処する具体的行動があったか。

**計測方法**: 失敗エントリ N のサイクル C における記入 → サイクル C+1 の boot_intent focus / Phase 3 実績に対処行動が含まれるか追跡。

**対処行動のパターン**:
- (a) 即解消: C+1 で失敗項目を完遂
- (b) 構造強制化: C+1 で kaizen/ルール化
- (c) 繰越: C+1 で「引き続き」記入のみ（行動なし）
- (d) 忘却: C+1 で言及なし

**閾値**:
- (a)+(b) 合計で50%超 = 失敗が学習材料として機能
- (c)+(d) が過半 = 記入の形骸化

**仮説**: (a)+(b) 合計40%前後。(c) 繰越が最多で、「書いたから対処した気になる」現象が発生している可能性。

**意味**: Blakely 父の問いが機能する条件は「記入後の行動変化」にある。記入自体は中立（むしろ自己満足のリスクあり）。
