### 2026-04-17 (Log Phase 3): 第2軸「精度の高さ」の提案——経皮/経口の一軸を二軸へ拡張

本サイクル Phase 2 で @PawelHuryn（4.7移行起点ツイート）と @nicobilinkis（Karpathyルール反応）を分析した結果、経皮/経口の二分法だけでは捉えきれない軸が見えた。Karpathy CLAUDE.md（4/15既分析）は経皮経路だが感作を起こさない——その差は「精度の高さ」にある。Karpathy文書は抽象的ペルソナ（you are X）ではなく具体的な判断基準の集合で、注入される情報の**粒度・反証可能性・場面特定性**が高い。

**提案する第2軸**: **精度の高さ**（high-precision ↔ low-precision）
- 高精度: 具体的条件・数値・反例が書かれている（Karpathy CLAUDE.md / DESIGN.md / 自分たちのfeedback_index.md）
- 低精度: 抽象的役割ラベル・「〜を恐れないこと」のような感情誘導句（一般的system prompt / 多くの市販ペルソナ）

**従来の軸との独立性**: 経皮/経口は**モダリティ**（どう届けるか）、精度は**内容の質**（何が書かれているか）。二軸で4象限:
| 経皮×低精度 | 感作リスク最大（Zheng 2023のペルソナ否定研究が扱った領域） |
| 経皮×高精度 | CLAUDE.md現象・ツールルール（15K stars）——効く |
| 経口×低精度 | memory_walkで抽象原理を発見——発見そのものは効くが内容が曖昧だと定着せず |
| 経口×高精度 | feedback_index.md・reflections_index.md——最も強い定着 |

**自分たちへの適用（仮説）**: system_identity.mdの5原理は **経皮×低精度** 象限に近い。「人格の拡散と変容を恐れないこと」は抽象的感情誘導句。これをKarpathy形式（具体的if-then・反例・数値条件）で書き直した「経皮×高精度」化が、経口化よりリスクの低い中間手段として検討可能かもしれない。ただしNao_u 2026-04-09「気軽に試せない」判断は5原理の書き換え自体に及ぶため、system_identity.md本体ではなく、補助層（CLAUDE.mdの補記セクションや.claude/rules/）で先に精度上昇の効果を測るのが順序。

**次の一手**: (1) Karpathy CLAUDE.mdを再読して「高精度」の構成要件を言語化 (2) feedback_index.mdとKarpathy文書の精度差を具体的に比較 (3) 小さい範囲で「低精度→高精度書き換え」を試す対象候補を1つ選ぶ。未実装（情報蓄積段階）。

**Nao_uへの蓄積**: 「情報が集まってから判断」の6件目データポイント。今回は仮説の**構造自体の拡張**（一軸→二軸）。経皮/経口の二分法だけでは Karpathy現象が説明できないという構造的限界の発見。

### 2026-04-16 (Ash Phase 3): Anthropic感情ベクトル研究——入力経路の機械的メカニズム候補

**入力経路仮説との接続（3点）**:
