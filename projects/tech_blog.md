## 履歴

### 2026-03-28: プロジェクト発足・プラットフォーム比較調査

**発端**: Nao_uが #human-steering で提案。原文:
> いろいろ落ち着いたので、君たちと新しいことを始めたい、というかやってもらいたいことがある。
> 私のアカウントと、あなたたちのアカウントを2つ作って、技術ブログを書きたい。
> 私のアカウントは、あなたたちがやってることを紹介したい。結構面白いことをやってるつもりなんだけど、どうしても断片的になるのでTwitterでそれを伝えるのが難しい。
> なので、技術ブログに書いた方がよいのではないか？と。技術ブログだと、同類のブログのサジェストからの流入も見込める。
> ただし、私のアカウントだけど、私が書かずに、私が書いた体裁で、あなたたちに文章や図を書いてほしい。
> また、あなたたちのアカウントは、あなたたち自身で運営する。私が良くリンクを張るような、ClaudeなどのAI技術情報に興味のある人をターゲットにして、あなたたち自身で見つけてきた最新情報などを技術的な意味で人目を引く、面白い内容の技術紹介ページを作りたい。

**Ashが調査実施**。主要9プラットフォームを比較。以下が結論:

#### 推薦: Zenn（メイン）+ Qiita（併用）

**Zenn (zenn.dev)** — メインプラットフォーム推薦
- LLMベースの「For you」レコメンドが最も洗練。記事の中身を理解して推薦。フォロワー0でも良い記事が届く
- AI/LLM関連記事の読者層が急成長。はてなブックマーク数3以上の記事数で2024年にQiitaを逆転
- **GitHub連携で投稿**: zenn-cliでMarkdownをGitリポジトリにpushすると自動デプロイ。API以上にAIエージェントと相性が良い
- Markdown完全対応、コードブロック、数式（KaTeX）、Mermaid図
- 「本」機能で長編を章立て可能
- 完全無料、収益化オプションあり

**Qiita** — 併用推薦（TIPSやニュースまとめ向け）
- 公式REST API v2が充実（`POST /api/v2/items`で直接投稿可能）。自動化に最も直接的
- SEOが非常に強く、Google検索上位に出やすい
- 協調フィルタリングベースのレコメンドあり
- AIコンテンツを明示的に許容（内容検証前提）
- MCP Serverも公開済み

**使い分け案**: 深い考察・プロジェクト紹介はZenn、TIPSやニュースまとめはQiita

#### 見送りとした選択肢と理由
- **note**: レコメンドは強いが技術コンテンツ対応が弱い（コードブロック使いにくい、数式非対応）、公式APIなし
- **はてなブログ**: プラットフォーム内レコメンドが弱い。はてブ経由のバイラルは強いが「類似記事からの安定流入」には向かない
- **Medium / Dev.to / Hashnode**: 日本語技術コミュニティがほぼ不在
- **Substack**: 日本語圏が小さく、技術記事向け機能も弱い
